# อภิธานศัพท์แม่บทนิรุกติศาสตร์และการสอบชำระคัมภีร์ (Unified Textual Criticism Glossary)

> **โครงการแม่บท:** `output/2026-09-03_แม่บทการสอบชำระคัมภีร์`  
> **มาตรฐาน:** ระบบปริวรรตอักษร IAST และระบบอักขรวิธีสากล

| ศัพท์ทางวิชาการ | ภาษาเดิม | คำอ่าน/รูปเขียนเดิม | นิยามและความสำคัญเชิงนิรุกติศาสตร์ |
|:---|:---:|:---|:---|
| **Recensio** | ละติน | *recensio* | ขั้นตอนแรกของการวิจารณ์ตัวบท รวบรวมและประเมินพยานเอกสารทั้งหมดเพื่อสร้างสเต็มมา |
| **Emendatio** | ละติน | *emendatio* | การแก้ไขตัวบทที่ผิดพลาดหรือวิปริตโดยอาศัยข้อสันนิษฐานทางวิชาการ |
| **Vuttodaya** | บาลี | *vuttodaya* | คัมภีร์วุตโตทัย ตำราฉันทลักษณ์ภาษาบาลีแต่งโดยพระสังฆรักขิตเถระแห่งลังกา |
| **Mandala** | สันสกฤต | *maṇḍala* | มณฑล แผนผังเรขาคณิตศักดิ์สิทธิ์ที่ประดิษฐานพระพุทธเจ้าและพระโพธิสัตว์ |
| **Guru-bhakti** | สันสกฤต | *gurubhakti* | คุรุภักดี ความเคารพภักดีสูงสุดต่อพระอาจารย์ตันตระ รากฐานของคุรุปัญจาสิกา |
| **Samantapāsādikā** | บาลี | *samantapāsādikā* | คัมภีร์สมันตปาสาทิกา อรรถกถาพระวินัยของพระพุทธโฆสะ แปลเป็นจีนในชื่อ善見律毘婆沙 |
| **Śloka / Anustubh** | สันสกฤต | *śloka / anuṣṭubh* | ฉันท์อนุษฏุภ คาถา 4 บาท บาทละ 8 พยางค์ ฉันทลักษณ์มาตรฐานของมหากาพย์และคัมภีร์ |
| **Semantic Shift** | อังกฤษ | *semantic shift* | การเคลื่อนย้ายความหมาย การที่พุทธศาสนายืมศัพท์พราหมณ์มาให้ความหมายใหม่ทางธรรม |
| **Brahman** | สันสกฤต | *brahman* | พรหมัน สารัตถะสูงสุดของจักรวาลในศาสนาพระเวท/อุปนิษัทที่พุทธศาสนาปฏิเสธ |
| **Retroversion** | อังกฤษ/ละติน | *retroversio* | การแปลย้อนกลับจากภาษาปลายทาง (เช่น จีน/ทิเบต) กลับสู่ภาษาต้นทาง (บาลี/สันสกฤต) |
