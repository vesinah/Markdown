## 3. โครงสร้างบทบังคับ (Template)

```markdown
# บทที่ X: [ชื่อบทเต็ม]

[บทนำ 300-600 คำ — นำเข้าสู่เนื้อหา เชื่อมโยงกับบทก่อนหน้า]

---

## X.1 [หัวข้อย่อยที่ 1]
[เนื้อหา + เชิงอรรถ [N] ทุกข้อเท็จจริง]

## X.2 ...

## X.N ...

---

## สรุป
[200-600 คำ — สรุปประเด็นสำคัญ เชื่อมไปบทถัดไป]

---

### เชิงอรรถ

[1] Author, *Title*, ed./trans. (Place: Publisher, Year), pages. URL (accessed date).
[2] ...
```

- หัวข้อย่อย 5-8 หัวข้อ ใช้เลข X.1-X.N
- เชิงอรรถเรียง [1][2][3]... ตามลำดับการปรากฏในเนื้อความ ต่อเนื่องไม่มีช่องว่าง รายการท้ายบทครบทุกหมายเลข

## 4. รูปแบบการอ้างอิง Chicago/Turabian Notes-Bibliography

| ประเภท | รูปแบบ |
|:---|:---|
| หนังสือ | Author, *Title*, ครั้งที่ (สถานที่: สำนักพิมพ์, ปี), หน้า. |
| บทความ | Author, "ชื่อบท," *Journal* เล่ม, ฉบับ (ปี): หน้า. DOI/URL. |
| บทในหนังสือ | Author, "ชื่อบท," ใน *Book*, ed. Editor (Place: Publisher, Year), หน้า. |
| วิทยานิพนธ์ | Author, "ชื่อ" (PhD diss., University, Year). DOI. |
| ออนไลน์/โครงการดิจิทัล | Author/Project, "Page," Site Name, URL (เข้าถึงเมื่อ 2026-08-25/26). |
| ต้นฉบับดิจิทัล | *ชื่อคัมภีร์/MS* (shelfmark, หอสมุด), URL. |

- อ้างเป็นภาษาดั้งเดิมของแหล่ง ห้ามแปลชื่อเรื่อง
- งานที่มีเพียง metadata (paywalled) ให้อ้างตามจริงและระบุข้อจำกัดในเนื้อความเมื่อจำเป็น

## 5. ภาษาและการจัดรูปแบบ

- ไทยวิชาการระดับสูง ไม่ใช้ภาษาพูด; ประโยคเชื่อมต่อปกติ **ห้ามเว้นวรรคกลางคำเพื่อนับคำ**
- ศัพท์ต่างประเทศ/คำโรมัน: *italic*; ชื่อหนังสือ/คัมภีร์/วารสาร: *italic*; เน้นศัพท์สำคัญ: **bold**
- การถอดรูป: สันสกฤต/บาลี = IAST (*padapāṭha*); ทิเบต = Wylie (*sa bcad*); จีน = พินยิน+ตัวเต็ม (*zhù* 注); ญี่ปุ่น = Hepburn (*kunten* 訓点); เกาหลี = McCune-Reischauer/RR (*gugyeol* 구결); อาหรับ = romanization มาตรฐาน (*tarjuma*)
- ครั้งแรกที่ใช้ศัพท์: `[คำแปลไทย] (*romanization*: อักษรเดิมถ้ามี)` แล้วใช้รูปเดิมตลอดบท
- ห้าม: emoji, HTML tags, รูปภาพ, bullet ลอยที่ไม่มีเนื้อหารองรับ

## 6. ข้อห้ามเด็ดขาด

1. ห้ามอ้าง Wikipedia/Wikidata/Wikisource/Baidu Baike เป็นแหล่ง (keyword-finding เท่านั้น)
2. ห้ามมโนข้อมูล — ไม่มีใน findings = ไม่เขียน หรือเขียนแบบ "ยังไม่พบข้อมูลยืนยัน..."
3. ห้าม copy ข้อมูลจาก `output\2026-08-25_คำแปลแทรกโบราณสากล\` (โปรเจกต์ขนานอื่น — ห้ามแตะ)
4. ห้ามอ้าง URL ที่ไม่ปรากฏใน findings/documents ของลูปจริง
5. Documented negatives จากงานวิจัย (เช่น Sultan Alauddin Qur'an, hyeonmun term, Reichenau Psalter OHG phantom) ให้รายงานสถานะจริง — ห้ามเขียนกลับเป็นข้อเท็จจริงที่เคยเชื่อกันโดยไม่ระบุการแก้ไข

## 7. กระบวนการทำงาน

1. อ่าน briefing นี้ + glossary.md
2. อ่าน findings.md ของทุกลูปสนับสนุนที่ระบุในคำสั่งมอบหมาย (+ แถวที่เกี่ยวใน master table)
3. อ่าน documents เจาะลึก 5-8 ไฟล์
4. วางโครงหัวข้อย่อย 5-8 หัวข้อ ครอบคลุมขอบเขตที่อนุมัติ
5. **เขียนเป็นหลายส่วน**: ใช้ Write สร้างไฟล์เริ่มต้น แล้ว Edit เพิ่มส่วนต่อส่วน — ห้ามพยายามเขียนทั้งไฟล์ใน call เดียว
6. ตรวจความยาว: `python d:\01_APP\Research\.agent\scripts\count_words.py "<draft path>"` — ถ้าต่ำกว่า 10,000 คำ ให้ขยายหัวข้อที่มีข้อมูลหนาแน่น (ไม่ใช่เติมน้ำ)
7. ตรวจเชิงอรรถครบถ้วน: ทุก [N] ในเนื้อความมีรายการท้ายบท และไม่มีรายการที่ไม่ถูกอ้าง
8. รายงานท้ายงาน (ใน reply): จำนวนคำสุดท้าย, จำนวนเชิงอรรถ, ลูป/ไฟล์ที่ใช้, ศัพท์ [PENDING] ที่เสนอ, ช่องว่างที่ mark ไว้
