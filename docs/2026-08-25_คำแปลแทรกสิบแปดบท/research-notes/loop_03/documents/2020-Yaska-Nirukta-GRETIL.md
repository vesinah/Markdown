## เนื้อหาสำคัญที่ดึงมา (ข้อความสันสกฤตถอดอักษร ตามไฟล์ GRETIL)

### 1) Nirukta 1,1 — นิยามของ samamnaya/nighantava และการจำแนก "pada" 4 จำพวก
```
1,1: tam.imam.samamnayam.nighantava.ity.acaksate
1,1: nighantavah.kasman.nigama.ime.bhavanti
1,1: chandobhyah.samahrya.samahrya.(samahatya.ra).samamnatah
1,1: tad.yany.[etani.Bh].catvari.pada.jatani.nama.akhyate.ca.upasarga.nipatas.ca.tani.imani.bhavanti
1,1: tatra.etan.nama.akhyatayor.laksanam.pradisanti
1,1: bhava.pradhanam.akhyatam.sattva.pradhanani.namani
```
- ยัสกะเรียกชุดคำที่รวบรวมจากพระเวทว่า samamnaya หรือ nighantava (คลังคำ) — คือ "glossary" ของคำพระเวท
- จำแนกคำเป็น 4 จำพวก: nama (นาม), akhyata (กริยา), upasarga (อุปสรรค/คำขยายหน้า), nipata (นิบาต) — เป็นการวิเคราะห์ไวยากรณ์ระดับต้นของโลก

### 2) Nirukta 1,15 — เหตุผลว่าด้วยความจำเป็นของการอรรถาธิบายความหมาย
```
1,15: atha.api.idam.antarena.mantresv.artha.pratyayo.na.vidyate
1,15: artham.apratiyato.na.atyantam.svara.samskara.uddesah
1,15: yadi.mantra.artha.pratyaya.anarthakam.bhavati.iti.kautso.anarthaka.hi.mantrah
```
- หากไม่เข้าใจความหมาย (artha-pratyaya) ของมนต์ การกำหนดสวระ/การอ่านก็ไม่แน่นอน — บันทึกข้อโต้แย้งของ Kautsa ว่า "mantrāḥ anarthakāḥ" (มนต์ไร้ความหมาย) แล้วหักล้างไว้

### 3) Nirukta 1,16 — หลักว่าคำมีความหมายโดยสามัญ
```
1,16: arthavantah.sabda.samanyat
1,16: yatho.etan.niyata.vaco.yuktayo.niyata.anupurvyo.bhavanti.iti.laukikesv.api.etad
```

### 4) Nirukta 1,18 — บทกว่าด้วยผู้ท่องเวทโดยไม่รู้ความหมาย
```
1,18: sthanur.ayam.bhara.harah.kila.abhud.adhitya.vedam.na.vijanati.yo.artham.
1,18: yo.arthajna.it.sakalam.bhadram.asnute.nakam.eti.jnana.vidhuta.papma.
1,18: yad.grhitam.avijnatam.nigadena.eva.sabdyate.
1,18: anagnav.iva.suska.edho.na.taj.jvalati.karhicit.
```
- "เขาผู้นี้เป็นเพียงท่อนไม้ (sthāṇu) ที่แบกภาระ" — ผู้ท่องพระเวทแต่ไม่รู้ความหมาย; วรรคนี้เป็นที่มาเชิงอุปมาของปรัชญาการอรรถาธิบาย (glossing) ฝ่ายอินเดีย

### 5) Nirukta 1,20 — ที่มาของอรรถาธิบายจากฤษีถึงคนภายหลัง
```
1,20: saksat.krta.dharmana.rsayo.babhuvuh
1,20: te.avarebhyo.asaksat.krta.dharmabhya.upadesena.mantrant.sampraduh
1,20: upadesaya.glayanto.avare.bilma.grahanaya.imam.grantham.samamnasisure.vedams.ca.veda.angani.ca
```
- ฤษีผู้ "เห็นธรรมโดยตรง" สืบทอดมนต์แก่คนภายหลังผู้ไม่เห็นโดยตรง ด้วยการ upadeśa (สอน); ผู้สืบทอดจึง "รวบรวมเป็น grantha (เล่ม/บท)" ทั้งพระเวทและเวทางคะ เพื่อการสอนและเพื่อ "bilma-grahaṇā" (การคว้าที่จับ/รากฐาน)

### 6) Nirukta 2,1 — วิธี nirvacana (การแผลงคำอรรถาธิบาย)
```
2,1: atha.nirvacanam
2,1: atha.ananvite.arthe.apradesike.vikare.artha.nityah.parikseta.kenacid.vrtti.samanena
2,1: avidyamane.samanye.apy.aksara.varna.samanan.nirbruyan.na.tv.eva.na.nirbruyat
```

### 7) Nirukta 2,3 — จรรยาบรรณของผู้อรรถาธิบาย
```
2,3: evam.taddhita.samasan.nirbruyat
2,3: na.eka.padani.nirbruyat.na.avaiyakaranaya.na.anupasannaya.anidamvide.va
```
- ห้ามอรรถาธิบายให้ผู้ไม่ใช่ไวยากรณ์ (avaiyākaraṇa) ฟัง ฯลฯ — แสดงว่า glossing เป็นกิจกรรมเชิงวิชาชีพที่มีกติกา

## ความเชื่อมโยงกับหนังสือ (loop 03 / บทที่ 1, 12, 17)
- Nirukta คือตัวอย่างแกนของ "การอรรถาธิบายคำ" (glossing) ในอินเดียโบราณ ทำงานบน Nighantu (คลังคำ) และใช้เทคนิค nirvacana คู่ขนานกับ padapatha และ pratisakhya
- ข้อความ 1,15-20 ให้เหตุผลสำคัญของการศึกษาต้นฉบับก่อน ค.ศ. 14: อ่านโดยไม่เข้าใจ = ไม่ได้อะไร (sthāṇu-bhārahāra)
