# คลังศัพท์เฉพาะทางและศัพท์กลาง (Project Glossary & Philological Matrix)
## โครงการ: การสืบสวนข้อเท็จจริงทางอักขรวิทยา นิติวิทยาศาสตร์ และประวัติศาสตร์นิพนธ์ ในสุสานตุตันคามุน (KV62)

## 1. พระนามและสมัญญานามภาษาอียิปต์โบราณ (Royal Names & Epithets)

| อักษรปริวรรต (Transliteration) | ภาษาอียิปต์โบราณ (Hieroglyphs / Meaning) | คำแปลไทย | ความสำคัญเชิงประวัติศาสตร์และหลักฐานใน KV62 |
|:---|:---|:---|:---|
| *ꜥnḫ-ḫpr.w-rꜥ* | Ankhkheperure ("รูปปรากฏแห่งชีวิตของสุริยเทพเร") | อังค์เคเปรูเร | พระนามครองราชย์ (Prenomen) ของกษัตริย์ปริศนาปลายยุคอามาร์นา ปรากฏเป็นรอยจารึกเดิมใต้พระนามของตุตันคามุนบนโลงชั้นกลาง หน้ากากทองคำ และโลงจำลองคาโนปิก |
| *nfr-nfr.w-jtn* | Neferneferuaten ("ความงดงามอันเป็นเลิศแห่งอาเตน") | เนเฟอร์เนเฟรูอาเตน | พระนามประสูติ (Nomen) ของฟาโรห์หญิง ซึ่งสัมพันธ์ใกล้ชิดกับพระนามเดิมของพระนางเนเฟอร์ติติ (*Nfr-nfr.w-jtn Nfr.t-jjtj*) |
| *nb-ḫpr.w-rꜥ* | Nebkheperure ("เจ้าแห่งรูปปรากฏของสุริยเทพเร") | เนบเคเปรูเร | พระนามครองราชย์ (Prenomen) ของฟาโรห์ตุตันคามุน ซึ่งถูกสลักทับลงบนคาร์ทูชเดิมของอังค์เคเปรูเร |
| *twt-ꜥnḫ-jmn* | Tutankhamun ("รูปเหมือนที่มีชีวิตของอามุน") | ตุตันคามุน | พระนามประสูติหลังการฟื้นฟูลัทธิเทพอามุน (เดิมคือ ตุตันคาทอน: *Twt-ꜥnḫ-jtn*) |
| *s-mnḫ-kꜢ-rꜥ ḏsr-ḫpr.w* | Smenkhkare Djeserkheperu ("ผู้ทำให้ดวงวิญญาณแห่งเรเข้มแข็ง ผู้มีรูปปรากฏอันศักดิ์สิทธิ์") | สเมนข์คาเร ดเจเซอร์เคเปรู | กษัตริย์ร่วมหรือผู้สืบทอดบัลลังก์ของอักเฮนาเตน ซึ่งเดิมเคยถูกสันนิษฐานว่าเป็นเจ้าของโบราณวัตถุที่ถูกนำมาใช้แทน |
| *Ꜣḫ.t-n-hy-s* | Akhet-en-hyes ("ผู้ทรงคุณประโยชน์แด่พระสวามีของพระนาง") | อาเคต-เอน-ฮีเอส | สร้อยพระนามเพศหญิงอย่างชัดเจนที่สลักไว้ในคาร์ทูชของโลงจำลองคาโนปิก ยืนยันว่าผู้ครองบัลลังก์อังค์เคเปรูเรองค์นี้เป็นสตรี |
| *mry-nfr-ḫpr.w-rꜥ* | Mery-Neferkheperure ("ผู้เป็นที่รักของเนเฟอร์เคเปรูเร [อักเฮนาเตน]") | เมรี-เนเฟอร์เคเปรูเร | สร้อยพระนามที่ปรากฏบนหน้ากากทองคำใต้รอยสลักทับ ชี้ว่าฟาโรห์หญิงพระองค์นี้มีความสัมพันธ์แนบแน่นกับอักเฮนาเตน |
| *mry-wꜥ-n-rꜥ* | Mery-Waenre ("ผู้เป็นที่รักของวาเอนเร [อักเฮนาเตน]") | เมรี-วาเอนเร | สร้อยพระนามอีกรูปแบบหนึ่งของอังค์เคเปรูเร เนเฟอร์เนเฟรูอาเตน |

## 2. ศัพท์เทคนิคทางไอยคุปต์วิทยาและนิติวิทยาศาสตร์โบราณคดี (Egyptological & Forensic Terms)

| ศัพท์ภาษาอังกฤษ | ศัพท์ภาษาเดิม (เยอรมัน/ฝรั่งเศส) | คำแปลไทย | คำอธิบายเชิงวิชาการ |
|:---|:---|:---|:---|
| **Palimpsest** | *Palimpsest* (เยอรมัน/ฝรั่งเศส) | รอยจารึกทับ / ข้อเขียนลบทับ | เอกสารหรือพื้นผิวโบราณวัตถุที่ข้อความเดิมถูกขูดลบ ขัดออก หรือสิ่วทับ แล้วเขียนหรือสลักข้อความใหม่ลงไปทับรอยเดิม |
| **Usurpation** | *Usurpierung* (เยอรมัน) / *Usurpation* (ฝรั่งเศส) | การช่วงชิง / การนำมาสวมสิทธิ์ใช้แทน | การนำโบราณวัตถุ สุสาน หรืออนุสาวรีย์ที่สร้างขึ้นสำหรับบุคคลหนึ่ง มาดัดแปลงสลักพระนามใหม่เพื่อใช้งานสำหรับอีกบุคคลหนึ่ง |
| **Re-use / Repurposing** | *Wiederverwendung* (เยอรมัน) / *Réutilisation* (ฝรั่งเศส) | การนำมาใช้ซ้ำ / การดัดแปลงใช้งานใหม่ | กระบวนการนำสิ่งของที่มีอยู่เดิมมาแปรสภาพเพื่อตอบสนองความจำเป็นเฉพาะหน้า โดยเฉพาะในภาวะฉุกเฉินของการฝังพระศพ |
| **Middle Coffin** | *Zweiter Sarg* (เยอรมัน) / *Second cercueil* (ฝรั่งเศส) | โลงพระศพชั้นกลาง (Carter 254) | โลงไม้ปิดทองฝังกระจกหลากสีและหินสี ซึ่งมีพระพักตร์แบบอามาร์นาคลาสสิกและรอยคาร์ทูชเดิมของอังค์เคเปรูเร |
| **Canopic Coffinette** | *Kanopensarg* (เยอรมัน) / *Miniature cercueil canope* (ฝรั่งเศส) | โลงจำลองคาโนปิก (Carter 266g) | โลงทองคำขนาดเล็ก 4 ใบสำหรับบรรจุอวัยวะภายในพระบรมศพ ซึ่งพบรอยสลักทับพระนามหญิงอย่างชัดเจนที่สุด |
| **Quartzite Sarcophagus** | *Quarzitsarkophag* (เยอรมัน) / *Cuve en quartzite* (ฝรั่งเศส) | โลงหินควอตซ์ไซต์ (Carter 240) | หีบหินสี่เหลี่ยมผืนผ้าขนาดใหญ่สลักรูปเทพีพิทักษ์ประจำมุม ซึ่งพบว่ารูปสลักและจารึกเดิมถูกปรับเปลี่ยน |
| **Earlobe Piercing** | *Ohrloch* (เยอรมัน) / *Perce-oreille* (ฝรั่งเศส) | รอยเจาะติ่งหู / รอยเจาะพระกรรณ | รูเจาะสำหรับใส่ต่างหู ในศิลปะราชสำนักอียิปต์โบราณใช้เฉพาะกับสตรีและเด็ก ไม่พบในประติมากรรมพระบรมศพของฟาโรห์บุรุษเต็มวัย |
| **Soldering Seam** | *Lötnaht* (เยอรมัน) / *Soudure* (ฝรั่งเศส) | รอยเชื่อมต่อโลหะ | แนวเชื่อมต่อระหว่างแผ่นพระพักตร์กับส่วนเนเมสบนหน้ากากทองคำ ซึ่งใช้ทองคำที่มีค่ากะรัตต่างกัน |
| **Reflectance Transformation Imaging (RTI)** | *RTI-Verfahren* (เยอรมัน) / *Imagerie RTI* (ฝรั่งเศส) | การถ่ายภาพแปลงการสะท้อนแสง | เทคนิคการถ่ายภาพดิจิทัลขั้นสูงที่ควบคุมทิศทางแสงเพื่อสร้างแบบจำลองพื้นผิว 3 มิติความละเอียดสูง เผยร่องรอยการสลักทับที่มองไม่เห็นด้วยตาเปล่า |
