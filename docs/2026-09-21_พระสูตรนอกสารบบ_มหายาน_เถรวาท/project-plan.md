## 1. บทนำ วัตถุประสงค์ และขอบเขตโครงการ

### 1.1 วัตถุประสงค์โครงการ
โครงการวิจัยนี้มุ่งศึกษา สังเคราะห์ และผลิตรายงานวิชาการระดับสูงว่าด้วยวิวัฒนาการการจัดระบบพระสูตร (Sūtra Taxonomy) กระบวนการสถาปนาสารบบคัมภีร์ (Canon Formation) และปรากฏการณ์การเกิดขึ้น การจัดประเภท และบทบาทหน้าที่ของ "พระสูตรนอกสารบบ" (Apocryphal and Paracanonical Sūtras) ในสองจารีตใหญ่ของพระพุทธศาสนา ได้แก่ ฝ่ายมหายาน (Mahāyāna) และฝ่ายเถรวาท (Theravāda) โดยอาศัยหลักฐานทางประวัติศาสตร์ โบราณคดี จารึกวิทยา วัสดุศาสตร์ และเอกสารตัวเขียนโบราณข้าม 6 ภาษาสำคัญของโลกวิชาการพุทธศาสตร์ และ 4 ภาษาคัมภีร์ปฐมภูมิ

### 1.2 โครงสร้างรายงานและเป้าหมายความยาวคำ
รายงานแบ่งออกเป็น 3 บทหลัก ประกอบด้วย 12 หัวข้อย่อย (Micro-Sprints) ควบคุมความยาวขั้นต่ำตามสูตรสากล (อักขระตัดช่องว่าง ÷ 5.0):
1. **บทที่ 1: ทบทวนวรรณกรรมการศึกษาการจัดระบบพระสูตรเถรวาทบาลี สันสกฤต จีน ทิเบต และญี่ปุ่น**
   - รหัสหัวข้อย่อย: `ch01_sec01` ถึง `ch01_sec04` (4 sections)
   - เป้าหมายความยาว: **ไม่น้อยกว่า 10,000 คำ** (กรอบประมาณการ: 10,000–12,000 คำ)
2. **บทที่ 2: การจัดระบบพระสูตร และพระสูตรนอกสารบบของพุทธศาสนาฝ่ายมหายาน**
   - รหัสหัวข้อย่อย: `ch02_sec01` ถึง `ch02_sec04` (4 sections)
   - เป้าหมายความยาว: **ไม่น้อยกว่า 10,000 คำ** (กรอบประมาณการ: 10,000–12,000 คำ)
3. **บทที่ 3: การจัดระบบพระสูตร และพระสูตรนอกสารบบของพุทธศาสนาฝ่ายเถรวาท**
   - รหัสหัวข้อย่อย: `ch03_sec01` ถึง `ch03_sec04` (4 sections)
   - เป้าหมายความยาว: **ไม่น้อยกว่า 10,000 คำ** (กรอบประมาณการ: 10,000–12,000 คำ)
4. **ความยาวรวมทั้งโครงการ:** **ไม่น้อยกว่า 30,000 คำ** (กรอบประมาณการ: 30,000–36,000 คำขึ้นไป)

### 2.2 เกณฑ์การยกระดับ Tier 2 สู่ Tier 1 (Promotion Trigger)
ภาษาในกลุ่ม Tier 2 (ญี่ปุ่น, ฝรั่งเศส, เยอรมัน, รัสเซีย, พม่า) จะได้รับการยกระดับเป็น Tier 1 ทันทีเมื่อ:
1. พบหลักฐานชั้นต้นหรือเอกสารตัวเขียนสำคัญที่มีเฉพาะในภาษานั้น (เช่น ตัวเขียนนานัตสึเดระในญี่ปุ่น หรือสารบัญปิฏกัตตะสะมุ่ยในพม่า)
2. เป็นงานวิจัยแม่บทที่ไม่มีการแปลเป็นภาษาอังกฤษ และมีอิทธิพลชี้ขาดต่อข้อถกเถียง (เช่น งานสำรวจอี๋เว่ยจิงของ Makita Tairyō หรือการชำระตัวเขียนตูร์ฟานของ Ernst Waldschmidt)

### 4.1 ระยะที่ 1: รับโจทย์ สำรวจภูมิทัศน์ และวางโครงร่าง (Inception, Reconnaissance & Blueprint)
- **การปฏิบัติ:** สำรวจภูมิทัศน์วิชาการเบื้องต้น (Preliminary Landscape Foraging) ผ่าน CrossRef, Scholar API, Web Search สังเคราะห์ข้อมูลเป็น `project-plan.md`, `glossary.md`, และ `outline-proposal.md`
- **[GATE 1: Outline Gate]** ตรวจสอบโครงสร้าง 3 บท 12 sections ครบถ้วนตามข้อกำหนด R1–R3 และได้รับอนุมัติจากผู้ใช้ก่อนเริ่มขั้นตอนต่อไป

### 4.2 ระยะที่ 2: ฮาร์เวสเอกสาร สกัดข้อความ และกำหนดค่า OCR (Systematic Harvesting & OCR Routing)
- **การปฏิบัติ:**
  1. ดาวน์โหลดเอกสารงานวิจัย บทความวิชาการ หนังสือ และคัมภีร์ฉบับเต็ม (Full-text PDFs & EPUBs) ลงในโฟลเดอร์ `research-notes/pdf/` หรือเชื่อมโยงจาก `documents/` ผ่านเครื่องมือสืบค้นโอเพนแอกเซส
  2. ดำเนินการตรวจสุขภาพไฟล์เอกสารทุกไฟล์ด้วยคำสั่ง:
     ```powershell
     python .agent/scripts/document_to_markdown.py --check "research-notes/pdf/paper.pdf"
     ```
  3. สกัดข้อความเป็น High-Fidelity Markdown บันทึกลงใน `research-notes/extracted-texts/*.md` โดยคงโครงสร้างหัวข้อ ตาราง ตัวหนา ตัวเอียง และเลขคั่นหน้าจริง `<!-- Page X -->`
  4. หากไฟล์เอกสารมีสถานะ `LOW-TEXT` หรือแบบอักษรเพี้ยน ให้กำหนดค่าคอลัมน์ **Language** และ **Script (อักษร)** ใน `source-index.md` แล้วสั่งรัน OCR 300 DPI ด้วย PyMuPDF + Tesseract Engine เช่น:
     - ภาษาสันสกฤต: `-l san+hin`
     - ภาษาพม่า: `-l mya`
     - ภาษาไทย: `-l tha`
     - ภาษาเยอรมัน/ฝรั่งเศส: `-l deu` / `-l fra`
  5. ซิงค์ดัชนีแหล่งข้อมูลกลางผ่านคำสั่ง:
     ```powershell
     python .agent/scripts/source_index_builder.py --project output/2026-09-21_พระสูตรนอกสารบบ_มหายาน_เถรวาท
     ```
- **[GATE 2: Saturation Gate]** ยืนยันความครอบคลุมของเอกสารต่อทุกหัวข้อย่อย หากมีเอกสารแม่บทคลาสสิกที่ติดกำแพงสิทธิ์ ให้จัดทำตาราง Manual Download Handoff เพื่อประสานงานต่อไป

### 4.3 ระยะที่ 3: วิเคราะห์เอกสาร สกัดโควทด้วยสคริปต์ และตรวจความแท้ (Dossier Production & Verification)
- **การปฏิบัติ:**
  1. จัดทำ Source Analysis Dossier 1 แหล่งข้อมูล = 1 แฟ้ม (`S-YYYY-author-chXX.md`) ใน `research-notes/sources/` ตามแม่แบบ 4 ส่วนมาตรฐาน:
     - ส่วนที่ 1: ข้อมูลบรรณานุกรม & Ready-to-paste Chicago Footnote
     - ส่วนที่ 2: การจัดสรรเข้าสู่บทและหัวข้อย่อย (Chapter & Section Mapping)
     - ส่วนที่ 3: สาระสำคัญเชิงลึกและจุดยืนทางวิชาการ (Thesis, Arguments & Historiography)
     - ส่วนที่ 4: คลังข้อความอ้างอิงตรงและคำศัพท์เฉพาะ (Verbatim Quotes Bank พร้อมเลขหน้าจริง)
  2. สกัดโควทตรงตัวและเลขหน้าจริงจาก `<!-- Page X -->` ใน `extracted-texts/*.md` ด้วยสคริปต์:
     ```powershell
     python .agent/scripts/quote_extractor.py md extracted-texts/paper.md --keywords "terms" --dossier
     ```
  3. ดำเนินการตรวจสอบความถูกต้องแท้จริงของโควทผ่านคำสั่ง:
     ```powershell
     python .agent/scripts/verify_dossier.py output/2026-09-21_พระสูตรนอกสารบบ_มหายาน_เถรวาท/research-notes/sources/S-YYYY-author-XX.md
     ```
- **[GATE 3: Anti-Hallucination Gate]** Dossier ต้องผ่านการตรวจ Multi-Layer Exact Substring Match 100% หากไม่ตรงแม้แต่ตัวอักษรเดียว สคริปต์จะสั่ง REJECT ทันที และห้ามนำเข้าสารบบเด็ดขาด เมื่อผ่านแล้วจึงอัปเดตลงใน `reading-progress.md`

### 4.4 ระยะที่ 4: ยกร่างเนื้อหารายสปรินต์ (Dossier-Driven Drafting Sprints)
- **การปฏิบัติ:**
  1. แบ่งการยกร่างออกเป็น 12 Micro-Sprints ลงใน `drafts/sections/chXX_secYY.md` ควบคุมเพดานความยาวคำที่ **2,500–3,000 คำต่อรอบ**
  2. **กฎเหล็ก Strict Dossier-Driven Drafting Only:** ผู้เขียนได้รับเฉพาะ Dossiers ใน `sources/` ที่ผ่าน Gate 3 แล้วเท่านั้น **ห้ามเปิดอ่านไฟล์ PDF หรือ Raw Texts ดิบโดยตรงขณะเขียนเด็ดขาด** เพื่อตัดปัญหา Context Bloat และป้องกันอาการหลอน
  3. คัดลอก Chicago Footnote จาก Dossier ส่วนที่ 1 มาวางในเชิงอรรถ `[1]`, `[2]`
  4. ตรวจสอบความยาวและความหนาแน่นของข้อมูลด้วยคำสั่ง:
     ```powershell
     python .agent/scripts/count_words.py --file drafts/sections/chXX_secYY.md
     ```
- **[GATE 4: Section Quality Gate]** ตรวจสอบว่าแต่ละ section มีความยาวอยู่ในเกณฑ์ 2,500–3,000 คำ ความหนาแน่นของเชิงอรรถไม่น้อยกว่า 4 จุดต่อ 1,000 คำ และบันทึกผลลงใน `drafting-progress.md`

### 4.5 ระยะที่ 5: รวมบท จัดเรียงเชิงอรรถ และชำระล้างรหัส (Assembly, Footnote Engine & Sanitization)
- **การปฏิบัติ:**
  1. รวมไฟล์ `drafts/sections/chXX_sec*.md` เป็นบทสมบูรณ์ใน `drafts/assembled/chXX.md`
  2. รันโปรแกรมจัดเรียงเชิงอรรถและชำระล้างรหัสระบบ:
     ```powershell
     python .agent/scripts/footnote_engine.py output/2026-09-21_พระสูตรนอกสารบบ_มหายาน_เถรวาท/drafts/assembled/ch01.md
     ```
  3. **Sanitization Protocol:** ตรวจสอบว่าไม่มีรหัส `S-YYYY-author-XX` หรือนามสกุล `.md` หลงเหลืออยู่ในเนื้อหาและเชิงอรรถ 100%
- **[GATE 5: Chapter Audit Gate]** ตรวจสอบความยาวของบทสมบูรณ์ไม่น้อยกว่า 10,000 คำ และย้ายไฟล์ที่ชำระแล้วเข้าสู่ `final/0X-บทที่X.md`

### 4.6 ระยะที่ 6: ประกอบเล่ม บรรณานุกรมรวม และส่งมอบ (Final Assembly & Handover)
- **การปฏิบัติ:**
  1. รวบรวมเชิงอรรถทั้งหมดจัดทำ `final/references.md` ตามมาตรฐาน Chicago Notes & Bibliography จำแนกเป็นแหล่งปฐมภูมิ ทุติยภูมิ และคลังข้อมูลดิจิทัล
  2. จัดทำ `final/00-สารบัญ.md`
  3. คำนวณความยาวคำรวมทั้งโครงการด้วยคำสั่ง:
     ```powershell
     python .agent/scripts/count_words.py --project output/2026-09-21_พระสูตรนอกสารบบ_มหายาน_เถรวาท
     ```
- **[GATE 6: Final Sign-off Gate]** ยืนยันความยาวรวมไม่น้อยกว่า 30,000 คำ ปราศจากข้อมูลเท็จ 100% ปราศจาก emoji 100% และจัดส่งมอบรายงานฉบับสมบูรณ์

## 6. เกณฑ์ชี้วัดคุณภาพเชิงวิชาการ (Academic Quality KPIs)

| ตัวชี้วัด (KPI) | เกณฑ์มาตรฐานบังคับ | เครื่องมือตรวจสอบ / การประเมิน |
|:---|:---:|:---|
| **ความยาวคำรวมทั้งเล่ม** | $\ge 30,000$ คำ (อักขระตัดช่องว่าง ÷ 5.0) | `python .agent/scripts/count_words.py --project <path>` |
| **ความยาวคำรายบท** | $\ge 10,000$ คำ ต่อบท (3 บท) | `python .agent/scripts/count_words.py --file <chapter>` |
| **ขนาดสปรินต์ยกร่าง** | 2,500–3,000 คำ ต่อ section (12 sections) | `python .agent/scripts/count_words.py --file <section>` |
| **การตรวจสอบโควทตรงตัว** | **100% Exact Substring Match** | `python .agent/scripts/verify_dossier.py <dossier>` |
| **การชำระล้างรหัสระบบ** | **100% Zero Internal Codes** (`S-YYYY-`, `.md`) | `python .agent/scripts/footnote_engine.py <chapter>` |
| **ความถูกต้องแท้จริงของแหล่งข้อมูล** | **100% Zero Hallucination** (มี URL/DOI จริง) | CrossRef, OpenAlex, WorldCat, ดัชนี `source-index.md` |
| **จำนวนผู้แต่งอิสระต่อบท** | $\ge 8$ คน ต่อบท | ตรวจสอบจากดัชนีใน `source-index.md` |
| **สัดส่วนหลักฐานปฐมภูมิต่อทุติยภูมิ** | $\ge 1 : 3$ | ตรวจสอบประเภทเอกสารใน `source-index.md` |
| **สัดส่วนเอกสารภาษาต่างประเทศ (Tier 1/2)** | $\ge 25\%$ | ตรวจสอบคอลัมน์ Language & Script ใน `source-index.md` |
| **ความหนาแน่นของเชิงอรรถ** | $\ge 4$ จุด ต่อ 1,000 คำ | รายการเชิงอรรถท้ายบท / `footnote_engine.py` |
| **สุขภาพไฟล์เอกสารฉบับเต็ม** | 100% PASS หรือ LOW-TEXT (ไม่มี CORRUPT) | `python .agent/scripts/document_to_markdown.py --check` |
| **การห้ามใช้อิโมจิ** | **0% Zero Emoji** ในเอกสารทุกฉบับ | ตรวจสอบอัตโนมัติด้วย Regular Expression |
