# ข้อตกลงบัญชีคำศัพท์วิชาการร่วม (Common Academic Glossary Protocol)

บัญชีคำศัพท์ทางวิชาการเพื่อใช้เป็นมาตรฐานในการเรียบเรียงรายงานวิจัย หลีกเลี่ยงความสับสนของชื่อเฉพาะ สถานที่ราชการ และตำแหน่งทางการปกครอง

## 1. คำทับศัพท์ชื่อภูมิศาสตร์และสถานที่สำคัญ (Geographical & Toponymic Terms)
* **Singora / Singgora / Sangora** -> "ซิงกอรา" หรือ "นครรัฐสุลต่านสงขลา" (หลีกเลี่ยงการใช้คำว่า "สงขลา" ลอย ๆ ในบทความตอนที่กล่าวถึงช่วงศตวรรษที่ 17 เพื่อป้องกันความสับสนเชิงยุคสมัย)
* **Hua Khao Daeng** -> "หัวเขาแดง" (ศูนย์กลางทางยุทธศาสตร์และป้อมค่ายดั้งเดิมของซิงกอรา)
* **Ligor** -> "ลิกอร์" หรือ "นครศรีธรรมราช"
* **Bordelong / Bordelongh** -> "บอร์เดอลุง" หรือ "พัทลุง"
* **Chaiya** -> "ไชยา" (เมืองทางตอนเหนือที่เป็นแหล่งลี้ภัยและปกครองของทายาทสุลต่านสุไลมานสายมุสตาฟา)
* **Pattani / Patani** -> "ปัตตานี" (นครรัฐมลายูคู่แข่งทางการค้าและพันธมิตรทางยุทธศาสตร์ในบางสมัย)

## 2. นามบุคคลสำคัญและตำแหน่งขุนนาง (Key Historical Figures & Royal Titles)
* **Datuk Mogul / Dato Mogol / Datuk Mughal** -> "ดาโต๊ะโมกอล" (ผู้ก่อตั้งรัฐซิงกอราและปกครองระหว่างปี 1605–1620)
* **Sultan Sulaiman Shah / Sultan Suleiman** -> "สุลต่านสุไลมาน ชาห์" (ผู้ประกาศเอกราชและสถาปนาตนเองเป็นสุลต่านแห่งซิงกอรา ครองราชย์ปี 1620–1676)
* **Sultan Mustapha / Mustafa** -> "สุลต่านมุสตาฟา" (บุตรชายคนโตของสุลต่านสุไลมาน ครองราชย์สั้น ๆ ระหว่างปี 1676–1680 ก่อนเสียเมืองและถูกย้ายไปปกครองที่ไชยา)
* **Hasan / Hassan** -> "ฮัสซัน" หรือ "พระยาราชบังสัน (ฮัสซัน)" (บุตรชายคนเล็กของสุลต่านสุไลมาน ผู้สวามิภักดิ์ต่ออยุธยาและเป็นผู้บัญชาการทหารเรือ/กองอาสาจาม ถูกประหารชีวิตภายหลังเนื่องจากช่วยผู้ว่าการเมืองนครศรีธรรมราชที่แข็งเมืองหลบหนี)
* **Hussein / Husain** -> "ฮุสเซน" หรือ "พระยาพัทลุง (ฮุสเซน)" (บุตรชายคนที่สองของสุลต่านสุไลมาน ผู้ดำรงตำแหน่งเจ้าเมืองพัทลุงต้นตระกูล ณ พัทลุง)
* **Farisi** -> "พระยาฟาริซี" (น้องชายของสุลต่านสุไลมาน ผู้ดูแลการสร้างป้อมปราการที่ชัยบุรีในพัทลุง)
* **Mahmud / Mud** -> "มะห์มูด" หรือ "เจ้าพระยาจักรีแขก (นายหมุด)" (ผู้สืบสายตระกูลของฮัสซัน ดำรงตำแหน่งจักรีขวาในสมัยกรุงธนบุรีและเป็นแม่ทัพเรือของพระเจ้าตากสินในการรบทางใต้)
* **Wu Rang / Hao Yiang** -> "อู่รัง" หรือ "เหาเยี้ยง" (ปฐมตระกูลขุนนางฮกเกี้ยนผู้ได้รับสัมปทานรังนกปี 1750 และสถาปนาตระกูล ณ สงขลา)

## 3. หน่วยงานและตำแหน่งทางการปกครอง (Administrative & Military Terms)
* **Krom Asa Cham** -> "กรมอาสาจาม" (หน่วยทหารอาสาสมัครมุสลิม เชื้อสายจามและมลายู สังกัดฝ่ายทหารกลาโหม มีผู้บัญชาการตำแหน่งพระยาราชบังสัน)
* **Phraya Racha Wangsan / Phraya Racha Bangsan** -> "พระยาราชบังสัน" (ตำแหน่งผู้บัญชาการทหารเรือของกองอาสาจามและกองเรือรบฝ่ายใต้)
* **Chao Phraya Chakri Khaek** -> "เจ้าพระยาจักรีแขก" (ตำแหน่งเสนาบดีมหาดไทยฝ่ายมุสลิมในสมัยกรุงธนบุรี)
* **Yokkrabat / Yokrabat** -> "ยกกระบัตร" (ตำแหน่งผู้สอดส่องและผู้ตรวจการฝ่ายตุลาการที่ราชสำนักส่งมาควบคุมเมืองท่าฝ่ายใต้)
* **Kanlapana** -> "กัลปนา" (การพระราชทานที่ดินและเลกวัดเพื่อทำนุบำรุงศาสนสถาน)
