# อภิธานศัพท์แม่บทโคดิโคโลยีและวิทยาการเอกสารโบราณ (Unified Codicology Glossary)

> **โครงการแม่บท:** `output/2026-09-03_แม่บทเอกสารโบราณและโคดิโคโลยี`  
> **มาตรฐาน:** ระบบปริวรรตอักษร IAST สำหรับภาษาสันสกฤต/บาลี และระบบถอดเสียงราชบัณฑิตยสภา

| ศัพท์ทางวิชาการ | ภาษาต้นทาง | คำอ่าน/รูปเขียนเดิม | นิยามและความสำคัญเชิงโคดิโคโลยี |
|:---|:---:|:---|:---|
| **Codicology** | ละติน/กรีก | *codicologia* | วิทยาการเอกสารตัวเขียน ศาสตร์ที่ศึกษากายวิภาคทางวัตถุของหนังสือโบราณ |
| **Paleography** | กรีก | *palaiographia* | บรรพชีวินวิทยาอักขระ ศาสตร์ว่าด้วยการอ่าน ตีความ และกำหนดอายุอักษรโบราณ |
| **Pothi** | สันสกฤต/ปรากฤต | *pustaka / pothī* | รูปเล่มเอกสารโบราณทรงยาวแบบใบลาน เจาะรูร้อยเชือก ประกบด้วยไม้ประกับบน-ล่าง |
| **Bhurjapatra** | สันสกฤต | *bhūrjapatra* | ภูรชบัตร แผ่นเปลือกต้นเบิร์ชหิมาลัย (*Betula utilis*) ใช้บันทึกคัมภีร์ในเนปาลและแคชเมียร์ |
| **Tālapattra** | สันสกฤต | *tālapatra* | ใบลาน ใบของต้นลานตระกูลปาล์ม (*Corypha*) สื่อบันทึกหลักของพุทธศาสนาในเอเชียใต้และอุษาคเนย์ |
| **Iron Stylus** | อังกฤษ/บาลี | *lekhanī* | เหล็กจาร อุปกรณ์โลหะปลายแหลมสำหรับกดขีดผิวใบลานให้เป็นร่องตัวอักษร |
| **Soot Ink** | อังกฤษ/สันสกฤต | *masi / kajjala* | หมึกเขม่า หมึกคาร์บอนที่ทำจากเขม่าควันไฟผสมกาวธรรมชาติและยางไม้ |
| **Stemma Codicum** | ละติน | *stemma codicum* | แผนภูมิต้นไม้สายเลือดเอกสาร แสดงลำดับวิวัฒนาการและการคัดลอกส่งผ่านของตัวเขียน |
| **Archetype** | กรีก | *archetypon* | ต้นฉบับบรรพบุรุษร่วมสมมติ ซึ่งเป็นรากเหง้าของเอกสารพยานทั้งหมดที่หลงเหลืออยู่ |
| **Codex Unicus** | ละติน | *codex unicus* | เอกสารตัวเขียนฉบับเดี่ยวที่รอดพ้นกาลเวลามาเพียงฉบับเดียวในโลกสำหรับงานชิ้นนั้น |
| **Śruti** | สันสกฤต | *śruti* | วรรณกรรมที่ได้ยินได้ฟัง (มุขปาฐะศักดิ์สิทธิ์) หมายถึงพระเวท ห้ามบันทึกเป็นลายลักษณ์ในยุคแรก |
| **Smṛti** | สันสกฤต | *smṛti* | วรรณกรรมที่ระลึกได้ ธรรมศาสตร์และคัมภีร์ชั้นรองที่เปิดให้บันทึกเป็นลายลักษณ์อักษรได้ |
