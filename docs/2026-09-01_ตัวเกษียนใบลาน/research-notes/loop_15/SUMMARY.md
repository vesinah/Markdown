# Loop 15 Summary — Sannaya Layout Investigation

## Core Finding

**Sinhala sannaya manuscripts use CONTINUOUS BITEXT layout, NOT interlinear gloss.**

### Evidence
- **Primary source:** Direct visual examination of Brahmajala Sutta Sannaya palm leaf manuscript (c. 19th century, RAS collection)
- **2 folios analyzed:** Both show consistent horizontal bitext format
- **Layout:** 7 lines per folio; Pali-Sinhala alternating **inline** within same line; single script size; no vertical layering

### Key Distinctions

**Continuous Bitext (✅ what sannaya IS):**
- Two languages flow horizontally in same line
- Single script size (no hierarchy)
- Pali phrase → Sinhala translation → next Pali phrase (alternating)

**Interlinear Gloss (❌ what sannaya is NOT):**
- Large main text with small glosses above/below
- Vertical layering of two text sizes
- Main text readable independently

### Terminology Issue
Some scholars may call sannaya "interlinear" referring to **translation method** (phrase-by-phrase, word-for-word) rather than physical **layout**. This creates confusion. Codicologically, sannaya is a **running bitext**, not an interlinear gloss.
