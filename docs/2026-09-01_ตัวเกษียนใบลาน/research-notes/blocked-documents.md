## Access Alternatives & Recommendations

### Immediate Actions (for report completion)

1. **UC Berkeley Bancroft images:** Submit request via Aeon system (https://aeon.berkeley.edu/) — requires institutional affiliation or fee
2. **DLNTM new interface:** Search https://iiif.crossasia.org/s/lanna for "Dhammapada" or "interlinear" keywords
3. **Thai-language sources (Kongkaew 2001, 2002):** 
   - Contact Chulalongkorn University Library / Siam Society Library
   - Check Thai Digital Collection (tdc.thailis.or.th) or ThaiLIS
   - Alternative: cite as "unavailable" and note as limitation in report

### Long-term Research Infrastructure

1. **VPN/proxy:** Many DNS failures (cdn.calisphere, SOAS) suggest network-level blocks; institutional VPN recommended
2. **Interlibrary loan (ILL):** Ruiz-Falqués 2017 (JBS), Smith 2009 (Glossa Ordinaria), Blackburn 1999
3. **Direct author contact:** Aleix Ruiz-Falqués (nissaya), Anne Blackburn (sannaya), Justin McDaniel (Thai bitexts)
4. **Thai scholarship integration:** Collaborate with Thai universities (Chulalongkorn, Silpakorn, CMU) for vernacular sources
