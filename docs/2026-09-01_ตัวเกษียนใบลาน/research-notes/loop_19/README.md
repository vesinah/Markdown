## Key Findings

### Four Major Trends Identified:

1. **AI/ML Revolution in HTR**
   - Transformer models replace traditional approaches
   - Focus on low-resource scripts
   - Multi-domain adaptation

2. **Human-AI Hybrid Workflows**
   - Recognition that full automation insufficient
   - Human-in-the-loop essential
   - Ground truth annotation quality critical

3. **Infrastructure Critique**
   - DH tools don't match scholar workflows
   - Standards (TEI, IIIF, W3C) not integrated
   - Need for holistic platforms

4. **Global/Comparative Turn**
   - Beyond Euro-centric manuscripts
   - CSMC Hamburg as major hub
   - Asian, African, Middle Eastern focus growing

### Five Gaps Identified (= Project Opportunities):

1. **Southeast Asian manuscripts** underrepresented
2. **Interlinear gloss** in historical MSS (vs. computational linguistics IGT)
3. **Palmleaf manuscripts** limited coverage
4. **Annotation semantics** beyond spatial/visual
5. **Standards integration** in practice
