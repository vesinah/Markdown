## Visual Layout Analysis (Based on Walker Description)

**Layout characteristics of Thai interlinear gloss (khaam hvăt / t́vă kṣien):**

1. **Placement:** Small characters written above and below the main Pali text line
2. **Script:** Special abbreviated script distinct from standard Thai
3. **Content elements (per Walker Fig. 1 diplomatic transcription):**
   - Numerals indicating syntactic rearrangement order (1-14 in example)
   - Vernacular grammatical particles (e.g., "mè~ị̄ ö")
   - Pali amplifications/glosses (e.g., "maḥ yathā", "maḥ dhanuto")
   - Direction markers ("↓" down, "↑" up)
4. **Function:** Word-by-word philological analysis providing:
   - Lexical equivalents
   - Morphological parsing
   - Syntactic rearrangement
   - Semantic disambiguation
5. **Corpus:** Limited to core monastic curriculum texts (7 texts listed above)
6. **Chronology:** Most common in late 18th-19th century; earlier examples from 17th-18th century

**Contrast with nissaya (continuous bitext):**
- Nissaya: Pali word → vernacular translation → Pali word → vernacular (continuous horizontal flow)
- Khaam hvăt: Pali main line + small interlinear annotations above/below (vertical stacking)
