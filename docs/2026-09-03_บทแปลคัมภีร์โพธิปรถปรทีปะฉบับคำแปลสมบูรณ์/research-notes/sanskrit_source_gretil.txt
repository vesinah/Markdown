praṇipatya cāpi / bodhiprabheṇa kathito viśadīkaromi śiṣyottamena khalu bodhipathapradipam

// Bpp_2 //
puruṣāstrividhā jñeyā uttamādhamamadhmāḥ / likhyate lakṣaṇaṃ teṣāṃ sphuṭaṃ pratyekabhedataḥ

// Bpp_3 //
upāyena tu kenāpi kevalaṃ saṃsṛteḥ sukham / svasyaivārthe ya īheta jñeyaḥ so puruṣo 'dhamaḥ

// Bpp_4 //
pāpakarmanivṛttātmā bhavasukhāt parāṅmukhaḥ / ātmanirvāṇamātrārthī yo naro madhyamastu saḥ

// Bpp_5 //
svasantānagatairduḥkhairduḥkhasyānyasya sarvathā / sarvasya yaḥ kṣayaṃ kāṅkṣeduttamaḥ puruṣastu saḥ

// Bpp_6 //
kāṅkṣanto hi varāṃ bodhiṃ sattvānāmuttamāstathā / darśitān gurubhistebhyaḥ sadupāyāṃ pracakṣmahe

// Bpp_7 //
sambuddhacitramūrtyādistūpasaddharmasammukhaḥ / puṣpaidhupaiḥ padārthaiśca yathāprāptaiḥ supūjayet

// Bpp_8 //
samantabhadracaryoktā pūjā saptavidhāpi ca / bodhisārasya paryantam avaivartikacittataḥ

// Bpp_9 //
suśraddhayā triratneyaḥ bhumau saṃsthāpya jānunī / bhūtvā kṛtāñjaliścāpi triścādau śaraṇaṃ vrajet

// Bpp_10 //
tataḥ samastasattveṣu maitrīcitta puraskṛtaḥ / durgatitrayājanmādisaṅkrāntimaraṇādibhiḥ

// Bpp_11 //
dṛṣṭvāśeṣaṃ jagaddukhaṃ duḥkhena dukhitāyāśca / duḥkhahetostathā duḥkhāt jagatāṃ muktikāṅkṣayā

// Bpp_12 //
bodhicittaṃ samutpādyamanāpāyipratijñayā / evaṃ praṇidhicittānām utpādetu guṇāśca ye

// Bpp_13 //
te gaṇḍavyūhasūtreṣu maitreyeṇa prabhāṣitāḥ / sūtrasya tasya paṭhanācchravaṇād gurorvā sambodhicittaguṇakāni nirantakāni

// Bpp_14 //
vijñāya tasya khalu saṃsthitārarṇāna / cittaṃ tathā samudayeta muhurmuhaśca / vīradattaparīpṛcchāsūtre puṇyaṃ pradarśitam

// Bpp_15 //
yattacślokatrayeṇaiva samāsenātralikhyate / bodhicittāddhi yatpuṇyaṃ tacca rupi bhavedyadi

// Bpp_16 //
ākāśadhātuṃ sampūrya bhuyaścottari tadbhavet / gaṅgāvālikasaṅkhyāni buddhakṣetrāṇi yo naraḥ

// Bpp_17 //
dadyātsadratna pūrṇāni lokanāthebhya eva hi / yaścaikaḥ prāñjalirbhūtvā cittaṃ bodhāya nāmayet

// Bpp_18 //
iyaṃ viśeṣyate pūjā yasyānto 'pi na vidyate / utpādyabodhipraṇidhānacittaṃ naikaprayatnaiḥ parivardhitavyam

// Bpp_19 //
janmāntare 'pi smaraṇārthamasya śikṣā yathoktā paripālanīyā / prasthānacitte svayamātiriktaṃ samyagbhavenna praṇidhānavṛddhiḥ

// Bpp_20 //
sambodhisaṃvāra vivṛddhikāmaḥ tasmād dhruvaṃ cainamavāpnuyāta / saptadhāprātimokṣaiśca sadānyasaṃvarānvitaḥ

// Bpp_21 //
bhāgyaṃ bodhisattvānāṃ saṃvarasya na cānyathā / saptadhā prātimokṣeṣu bhāṣiteṣu tathāgataiḥ

// Bpp_22 //
brahmacaryaśriyaḥ śreṣṭhāḥ bhikṣusaṃvara iṣyate / śīlādhyāyoktavidhinā bodhisattvasya bhumiṣu

// Bpp_23 //
saṃvaraḥ sadgurorgrāhyaḥ samyaglakṣaṇayuktataḥ / yaḥ saṃvaravidhau dakṣaḥ svayaṃ ca saṃvare sthitaḥ

// Bpp_24 //
kṛpāluḥ saṃvare śaktaḥ jñātavyaḥ sadgurustu saḥ / tatra yatnena na prāpto guruścaitādṛśo yadi

// Bpp_25 //
saṃvaragrahaṇasyānyo vidhiḥ tasmāt samuyacte / ambararājabhutena pūrvaṃ mañjuśriyā yathā

// Bpp_26 //
bodhicittaṃ samutpādi suspaṣṭaṃ cātra likhyate / mañjuśribuddhakṣetrālaṅkārasūtroktivat tathā

// Bpp_27 //
utpādayāmi sambodhau cittaṃ nāthasya sammukham / nimantraye jagatsarvaṃ dāridyānmocitāsmi tat

// Bpp_28 //
vyāpādakhilacittaṃ vā īrṣyāmātsaryameva va / adhyāgre na kariṣyāmi bodhiṃ prāpsyāmi yāvatā

// Bpp_29 //
brahmacaryaṃ cariṣyāmi kāmāṃstyakṣyāmi pāpakān / buddhānāmānuśikṣiṣye śīlasaṃvara saṃyame

// Bpp_30 //
nāhaṃ tvaritarupeṇa bodhiṃ prāptumihotsahe / parāntakoṭiṃ sthāsyāmi sattvasyaikasya kāraṇāt

// Bpp_31 //
kṣetraṃ viśodhiṣyāmi aprameyamacintim / nāmadheyaṃ kariṣyāmi daśadikṣu ca viśrutam

// Bpp_32 //
kāyavākkarmaṇī cāhaṃ śodhayiṣyāmi sarvaśaḥ / śodhayiṣye manaskarma kartāsmi nāśabham

// Bpp_33 //
svakāyavākacittaviśuddhihetu, prasthānacittātmayamasthitena / triśīlaśikṣāpariśiyeta cet, triśīlaśikṣāsu mahādarasyāt

// Bpp_34 //
śuddhasambodhisattvānāṃ tasmāt saṃvarasaṃvṛtau / yatnāt sambodhisambhāraḥ paripūrṇo bhaviṣyati

// Bpp_35 //
puṇyajñānasvabhāvasya sambhārasya tu pūrtaye / sarvabuddhamatoheturabhijñotpāda eva hi

// Bpp_36 //
pakṣavṛddhiṃ vinā pakṣī khe noḍaḍetuṃ yathā kṣamaḥ / tathābhijñābalairhīnaḥ sattvārthakaraṇe 'kṣamaḥ

// Bpp_37 //
abhijñasya divārātrau yāni puṇyāni santi vai / abhijñāyāśca rāhitye naiva janmaśateṣu ca

// Bpp_38 //
śīghraṃ sambodhisambhāraṃ sampūrayitumicchati / nirālasyena yatnenābhijñāṃ saṃsādhayettu saṃ

// Bpp_39 //
śamathasiddhayabhāve 'bhijñānaṃ na jāyate / ataḥ śamathasiddhayarthaṃ yatitavyaṃ punaḥ punaḥ

// Bpp_40 //
śamathaṅgaprahīṇatve tadyatnairbhāvite 'pi ca / saṃvatsarasahasraiśca samādhirnaiva setsyati

// Bpp_41 //
ataḥ samādhisambhārādhyāyoktāṅgasamāśritaḥ / kasmiṃścit alambane 'pi puṇye saṃsthāpayenmanaḥ

// Bpp_42 //
yoginaḥ śamathe siddhe 'bhijñānaṃ cāpi setsyati / prajñāpāramitāyogaṃ vinā nāvaraṇakṣayaḥ

// Bpp_43 //
kleśajñeyāvṛtestasmāt prahāṇārthamaśeṣataḥ / prajñāpāramitāṃ yogī sopāyaṃ bhāvayet sadā

// Bpp_44 //
upāyarahitā prajñāpyupāyaḥ prajñayā vinā / yato bandha iti proktau praheyaṃ nobhayaṃ tataḥ

// Bpp_45 //
kā prajñā ka upāyaśca śaṅkāmiti nirāsitum / upāyasya ca prajñāyāḥ bhedaḥ samyak prakāśyate

// Bpp_46 //
prajñāpāramitāṃ tyaktvā dānapāramitādayaḥ / sarve hi kuśalāḥ dharmāḥ upāyāḥ jinabhāṣitāḥ

// Bpp_47 //
upāyābhyāsavaśyātmā yo hi prajñāṃ vibhāvayet / śīghraṃ sa labhate bodhiṃ na nairātmyaikabhāvanāt

// Bpp_48 //
skandhāyatanadhātūnāmanutpādāvabodhinām / svabhāvaśūnyatājñānaṃ prajñeti parikīrtitā

// Bpp_49 //
sadutpattirayuktāsti asaccāpi khapuṣpavat / dvayordoṣaprasaṅgatvāt udbhāvo na dvayorapi

// Bpp_50 //
anutpannaḥ svato bhāvo parato nobhayorapi / ahetuteśca no tasmāt niḥsvabhāvaḥ svarupataḥ

// Bpp_51 //
athavā sarvadharmāṇāṃ caikānekavicāraṇe / svarupāprāpyamāṇatvāt niḥsvabhāvatvaniścayaḥ

// Bpp_52 //
śunyatāsaptau yuktau mūlamadhyamakādiṣu / siddho bhāvasvabhāvastu śunyatāyāṃ bhāṣitaḥ

// Bpp_53 //
granthasya gauravo yasmāt atra tasmānna vistaraḥ / siddhasiddhāntamātraikaṃ bhāvanārthaṃ prabhāṣitam

// Bpp_54 //
tasmādaśeṣadharmāṇāṃ svabhāvanāmalābhataḥ / nairātmyabhāvanā yā hi sā prajñāyāstu bhāvanā

// Bpp_55 //
prajñayā sarvadharmaṇāṃ yatsvabhāvo na dṛṣṭavat / yuktayā parīkṣya tāṃ prajñāṃ so 'vikalpena bhāvayet

// Bpp_56 //
bhavo vikalpobhūto 'yaṃ tadvikalpātmakastataḥ / sarvakalpaparityāgaḥ nivārṇaḥ paramo 'sti hi

// Bpp_57 //
evamapyuktaṃ bhagavatā - - mahāvidyā vikalpo hi saṃsārārṇavapātakaḥ / nirvikalpasamādhisthe 'vikalpo bhāsate khavat

// Bpp_58 //
avikalpapraveśadhāraṇyāmapi uktam - - cintitenirvikalpe 'smin saddharme jinaputrakaiḥ / vikalpaṃ durgamaṃ tīrtvāvikalpo prāpsyate kramāt

// Bpp_59 //
niścayīyāgamayuktibhyāṃ svabhāva rahitān tathā / sarvān dharmānutpannānavikalpaṃ bhāvayet

// Bpp_60 //
bhāvayannidamevetthaṃ prāpyoṣṇatvādikaṃ kramāt / labhate pramuditvādiṃ buddhabodhirna lambitā

// Bpp_61 //
sādhitairmantraśaktayā hi śāntivistarakarmabhiḥ / bhadrakumbhādisiddhāṣṭamahāsiddhibalena ca

// Bpp_62 //
abhīṣṭā bodhisambhāraparipūrtiḥ sukhena cet / kriyācaryādi tantrokam guhyācaraṇabhiṣyate

// Bpp_63 //
tadācāryabhiṣekārthaṃ mahāratnādidānataḥ / sadguruṃ prīṇayed bhaktayā sarvāñjñādipālanaiḥ

// Bpp_64 //
prasanne ca gurau bhūte pūrṇācāryābhiṣekataḥ / sarvapāpaviśuddhātmā siddhibhāgī bhaviṣyati

// Bpp_65 //
ādibuddhamahātantre prayatnena niṣedhataḥ / guhyaprajñābhiṣekastu na grahyā brahmacārariṇā

// Bpp_66 //
so 'bhiṣeko gṛhītaścet brahyacaryatapaḥ sthitaiḥ / niṣiddhācaraṇatvāt tattapaḥ samvarakṣayaḥ

// Bpp_67 //
jāyante vratinastasya pārājikavipattayaḥ / saḥ pateddurgatau nūnaṃ siddhirnaiva kadācana

// Bpp_68 //
sarvatantraśrutau bhāṣye homayajñādikarmāsu / labdhācāryābhiṣekaśca tattvavida naiva duṣyati

// Bpp_69 //
dīpaṅkaraśriyā bodhipathaḥ proktaḥ samāsataḥ / dṛaṣṭvā sūtrādidharmoktiṃ bodhiprabhanivedanāt
