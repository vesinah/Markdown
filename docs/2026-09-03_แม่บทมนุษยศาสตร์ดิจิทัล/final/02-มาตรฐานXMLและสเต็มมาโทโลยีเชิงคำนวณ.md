# บทที่ 2: มาตรฐาน XML และสเต็มมาโทโลยีเชิงคำนวณ (XML Standards & Computational Cladistics)

## 1. การปะทะและประสานของมาตรฐานข้อมูล: PAGE XML vs ALTO XML vs TEI

ในการสร้างคลังข้อมูลเอกสารโบราณระดับสถาบัน การเลือกใช้มาตรฐานการจัดเก็บข้อมูลเชิงโครงสร้าง XML มีความสำคัญยิ่งต่อความยั่งยืนและการแลกเปลี่ยนข้อมูล (Interoperability) การวิเคราะห์เปรียบเทียบใน [`output/2026-06-05_คู่มือมาตรฐานเอ็กซ์เอ็มแอล`](file:///d:/01_APP/Research/output/2026-06-05_คู่มือมาตรฐานเอ็กซ์เอ็มแอล/04_ตารางเปรียบเทียบ_Tag_ฉบับสมบูรณ์.md) ชี้ให้เห็นถึงบทบาทเฉพาะของแต่ละมาตรฐาน[^1]:

| มาตรฐาน XML | องค์กรผู้พัฒนา | โครงสร้างเด่น | ความเหมาะสมสูงสุด |
|:---|:---|:---|:---|
| **PAGE XML** | PRImA Group (อังกฤษ) | ใช้โพลีกอนพิกัดหลายจุด (`<Baseline points="...">`) ละเอียดสูง | เหมาะที่สุดสำหรับ **HTR เอกสารโบราณ** และภาพสแกนที่มีบรรทัดคดเคี้ยว |
| **ALTO XML** | Library of Congress | ใช้กรอบสี่เหลี่ยมมุมฉาก (`HPOS, VPOS, WIDTH, HEIGHT`) | เหมาะสำหรับ **OCR เอกสารสิ่งพิมพ์สมัยใหม่** และหนังสือพิมพ์ |
| **METS XML** | Library of Congress | อภิข้อมูลระดับเอกสาร (โครงสร้างโฟลเดอร์ แฟ้มภาพ และ XML) | เหมาะสำหรับการทำหน้าที่เป็น **ปลอกหุ้มแม่บท** (Packaging Wrapper) |
| **TEI XML** | Text Encoding Initiative | การเข้ารหัสเชิงความหมาย ไวยากรณ์ การสอบเทียบ และวรรณกรรม | เหมาะสำหรับ **งานวิจัยนิรุกติศาสตร์และฉบับสอบชำระดิจิทัล** |

การออกแบบสถาปัตยกรรมสารสนเทศที่ดีจึงต้องใช้ **"ท่อส่งข้อมูลแบบบูรณาการ" (Pipeline Synergy):** ใช้ PAGE XML ในการสกัดข้อความจากโมเดล Kraken HTR -> บรรจุลงใน METS XML เพื่อการจัดเก็บถาวร -> และแปลงข้อความเข้าสู่ TEI XML เพื่อการศึกษาวิจัยเชิงตัวบทต่อไป

## 2. พันธุศาสตร์คัมภีร์วิเคราะห์ (Phylogenetic Stemmatology) และแบบจำลองเบย์เซียน

นวัตกรรมที่ล้ำสมัยที่สุดด้านนิรุกติศาสตร์เชิงคำนวณใน [`output/2026-06-05_พันธุศาสตร์คัมภีร์วิเคราะห์`](file:///d:/01_APP/Research/output/2026-06-05_พันธุศาสตร์คัมภีร์วิเคราะห์/drafts/Chapter_3_Phylogenetic_Stemmatology.md) คือการนำทฤษฎีและอัลกอริทึมจากชีววิทยาวิวัฒนาการมาประยุกต์ใช้ในการศึกษาสายเลือดของเอกสารตัวเขียน (Phylogenetic Stemmatology)[^2]:

1. **ความคล้ายคลึงเชิงภววิทยา (Ontological Parallel):**
   - การจำลอง DNA ของสิ่งมีชีวิต $\longleftrightarrow$ การคัดลอกข้อความของอาลักษณ์
   - การกลายพันธุ์ของยีน (Genetic Mutation) $\longleftrightarrow$ ข้อผิดพลาดในการคัดลอก (Scribal Copying Errors)
   - การคัดเลือกโดยธรรมชาติ (Natural Selection) $\longleftrightarrow$ ความนิยมและการสูญหายของคัมภีร์ในประวัติศาสตร์
2. **การก้าวข้ามวิธีวิทยาแบบลัคมันน์ด้วย BEAST 2:**
   การสร้าง Stemma แบบดั้งเดิมมักล้มเหลวเมื่อเผชิญกับการปะปนทางสายเลือด (Contamination) แต่การใช้โมเดล **Bayesian MCMC (Markov Chain Monte Carlo)** ผ่านซอฟต์แวร์ BEAST 2 ช่วยให้นักวิจัยสามารถประเมินความน่าจะเป็นของต้นไม้สายวิวัฒนาการนับล้านรูปแบบ พร้อมคำนวณ "นาฬิกาชีวภาพโมเลกุล" (Molecular Clock) เพื่อประเมินอัตราความเร็วในการเปลี่ยนแปลงข้อความของอาลักษณ์ในแต่ละยุคสมัย

## 3. การประเมินวรรณกรรมที่สูญหายด้วยแบบจำลองนิเวศวิทยา (Unseen Species Models)

หนึ่งในคำถามที่ท้าทายที่สุดในประวัติศาสตร์คือ "มีเอกสารและวรรณกรรมโบราณสูญหายไปมากน้อยเพียงใด?" โครงการวิจัยได้นำ "แบบจำลองสายพันธุ์ที่มองไม่เห็น" (Unseen Species Models) จากสาขานิเวศวิทยา (Chao1 estimator) มาคำนวณสถิติของต้นฉบับโบราณ:
- การเปรียบเทียบอัตราส่วนระหว่างเอกสารที่เหลือรอดเพียงฉบับเดียว (Singletons) กับเอกสารที่เหลือรอดสองฉบับ (Doubletons) ทำให้สามารถประมาณการทางคณิตศาสตร์ได้ว่า มีผลงานและสำเนาคัมภีร์ในยุคกลางสูญหายไปมากกว่า 70–90%
- การค้นพบนี้เตือนให้นักวิจัยตระหนักถึง "อคติของผู้รอดชีวิต" (Survivorship Bias) และไม่ด่วนสรุปประวัติศาสตร์วรรณกรรมจากพยานเอกสารที่เหลือรอดอยู่ในมือปัจจุบันเพียงอย่างเดียว
