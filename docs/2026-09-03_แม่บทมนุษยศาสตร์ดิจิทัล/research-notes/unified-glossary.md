# อภิธานศัพท์แม่บทมนุษยศาสตร์ดิจิทัลและ HTR (Unified Digital Humanities Glossary)

> **โครงการแม่บท:** `output/2026-09-03_แม่บทมนุษยศาสตร์ดิจิทัล`  
> **มาตรฐาน:** ศัพท์บัญญัติสากลด้านสารสนเทศศาสตร์และคอมพิวเตอร์วิทัศน์

| ศัพท์ทางวิชาการ | ตัวย่อ/คำเดิม | คำอธิบายและความสำคัญเชิงเทคนิค |
|:---|:---:|:---|
| **Handwritten Text Recognition** | HTR | เทคโนโลยีการรู้จำข้อความลายมือเขียนโบราณจากภาพสแกนโดยใช้แบบจำลองปัญญาประดิษฐ์ |
| **Baseline Segmentation** | Baseline | เส้นพื้นฐานของแนวการเขียนอักษร ใช้เป็นแกนอ้างอิงตำแหน่งข้อความใน Kraken และ eScriptorium |
| **Character Error Rate** | CER | อัตราความผิดพลาดระดับตัวอักขระ คำนวณจาก (ลบ+แทรก+แทนที่)/จำนวนอักขระทั้งหมด x 100 |
| **PAGE XML** | PAGE | มาตรฐาน XML พัฒนาโดย PRImA สำหรับจัดเก็บพิกัดขอบเขตตัวอักษร รูปทรงเรขาคณิต และข้อความ |
| **ALTO XML** | ALTO | Analyzed Layout and Text Object มาตรฐาน XML ของหอสมุดรัฐสภาอเมริกันสำหรับข้อมูล OCR |
| **TEI XML** | TEI | Text Encoding Initiative ข้อกำหนดมาตรฐานระดับโลกสำหรับการเข้ารหัสวรรณกรรมและตัวบทโบราณ |
| **Phylogenetic Stemmatology** | - | การประยุกต์ใช้โมเดลวิวัฒนาการทางพันธุศาสตร์ในการสร้างแผนภูมิต้นไม้สายเลือดเอกสารโบราณ |
| **Bayesian MCMC** | MCMC | ระเบียบวิธีคำนวณความน่าจะเป็นของต้นไม้สายวิวัฒนาการที่มีความเป็นไปได้นับล้านรูปแบบใน BEAST 2 |
| **Ground Truth** | GT | ชุดข้อมูลภาพที่จับคู่กับข้อความเฉลยที่ถูกต้องสมบูรณ์ 100% เพื่อใช้ในการเทรนและทดสอบโมเดล AI |
| **Connectionist Temporal Classification** | CTC | ฟังก์ชันการสูญเสียใน Neural Network ที่ช่วยจับคู่ลำดับเวลาของภาพกับลำดับตัวอักษรโดยไม่ต้องตัดแบ่งอักขระ |
