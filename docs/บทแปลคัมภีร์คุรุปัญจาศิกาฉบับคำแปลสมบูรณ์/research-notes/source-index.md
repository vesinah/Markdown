# ดัชนีแหล่งสืบค้นปฐมภูมิ (Primary Source Index)

เอกสารทุกชิ้นในโครงการนี้สืบค้นและดึงสดจากฐานข้อมูลพระไตรปิฎกและคัมภีร์วิชาการระดับสากลบนอินเทอร์เน็ต 100% ปราศจากการดึงข้อมูลจากความจำภายใน (Zero Internal Knowledge) และไม่พึ่งพาข้อความแปลเดิมในระบบ

### 1.1 ฉบับแปลภาษาสันสกฤต สำนวนที่ 1
- **ชื่อคัมภีร์:** *Gurupañcāśikā* (गुरुपञ्चाशिका)
- **ผู้รจนา:** พระอัศวโฆษ (*Aśvaghoṣa*)
- **ฐานข้อมูล:** Göttingen Register of Electronic Texts in Indian Languages (GRETIL), Niedersächsische Staats- und Universitätsbibliothek Göttingen
- **URL ต้นทาง:** `https://gretil.sub.uni-goettingen.de/gretil/corpustei/sa_azvaghoSa-gurupaJcAzikA.xml`
- **ไฟล์ข้อมูลดิบในระบบ:** `research-notes/sanskrit-raw-gretil-dsbc.txt`
- **บทปณามพจน์:** ปรากฏในแท็ก `<p>om namo buddhāya /</p>` ก่อนเริ่มโศลกที่ 1
- **สถิติ:** บทปณามพจน์ + 50 โศลก (ฉันทลักษณ์อนุษฏุภและศารทูลวิกรีฑิตะ)
- **วันที่ดึงข้อมูล:** 3 กันยายน 2026

### 1.2 ฉบับแปลภาษาสันสกฤต สำนวนที่ 2 (GRETIL HTML Transformation Recension)
- **ชื่อคัมภีร์:** *Gurupañcāśikā* (GRETIL Live Recension)
- **ผู้รจนา:** พระมหาอาจารย์อัศวโฆษ (*Mahācāryāśvaghoṣa*)
- **ฐานข้อมูล:** Göttingen Register of Electronic Texts in Indian Languages (GRETIL), SUB Göttingen
- **URL ต้นทาง:** `https://gretil.sub.uni-goettingen.de/gretil/corpustei/transformations/html/sa_azvaghoSa-gurupaJcAzikA.htm`
- **ไฟล์ข้อมูลดิบในระบบ:** `research-notes/sanskrit-raw-gretil-corpustei.html` และ `research-notes/sanskrit-raw-gretil-corpustei.xml`
- **ลักษณะเด่นของตัวบท:** การสะกดอักขรวิธีตามขนบนาครีต่อเนื่อง (Continuous Sandhi orthography), มีเครื่องหมายวิพากษ์ตัวบทดั้งเดิม `[` ในโศลกที่ 34, และมีบทปิดท้ายคัมภีร์คู่ระบุชื่อเรื่องและผู้แต่งชัดเจน
- **สถิติ:** บทปณามพจน์ + 50 โศลก + บทปิดท้ายคัมภีร์ 2 โคลอฟอน
- **ไฟล์รายงานฉบับสมบูรณ์:** `final/01_คุรุปัญจาศิกา_ฉบับแปลภาษาสันสกฤต_ฉบับที่2.md`
- **วันที่ดึงข้อมูล:** 3 กันยายน 2026

## 2. ภาษาจีนโบราณ (Classical Chinese Primary Source)

- **ชื่อคัมภีร์:** 《事師法五十頌》 (*Shì Shī Fǎ Wǔ Shí Sòng*)
- **ผู้รจนา / ผู้รวบรวม:** พระมหาโพธิสัตว์อัศวโฆษ (馬鳴菩薩 集)
- **ผู้แปลสู่ภาษาจีน:** พระสมณทูตจากอินเดีย ราชวงศ์ซ่งเหนือ นามพระอาจารย์รื่อเฉิง (西天譯經三藏朝散大夫試鴻臚少卿宣梵大師賜紫沙門臣日稱等奉詔譯)
- **ฐานข้อมูล:** Chinese Buddhist Electronic Text Association (CBETA) / SAT Daizokyo
- **รหัสพระไตรปิฎก:** Taishō Tripiṭaka Vol. 32, No. 1687 (T32n1687)
- **URL ต้นทาง:** `https://raw.githubusercontent.com/cbeta-git/xml-p5a/master/T/T32/T32n1687.xml`
- **ไฟล์ข้อมูลดิบในระบบ:** `research-notes/chinese-raw-cbeta-t1687.txt` และ `chinese-raw-cbeta-t1687.xml`
- **สถิติ:** 50 คาถา (ร้อยกรอง 4 วรรคต่อบท วรรคละ 5 หรือ 7 อักษรจีน) รวม 1,315 อักขระ
- **วันที่ดึงข้อมูล:** 3 กันยายน 2026

## 3. ภาษาทิเบต (Tibetan Primary Source)

- **ชื่อคัมภีร์:** བླ་མ་ལྔ་བཅུ་པ (*Bla ma lnga bcu pa*)
- **ชื่อภาษาสันสกฤตกำกับในคัมภีร์:** *Gurupañcāśikā* (གུ་རུ་པཉྩ་བིཾ་ཤི་ཀ)
- **ผู้รจนา:** พระอาจารย์ศูระ / อัศวโฆษ (སློབ་དཔོན་དཔའ་བོ / རྟ་དབྱངས)
- **ผู้แปลสู่ภาษาทิเบต:** พระบัณฑิตปัทมากรวรรมัน (*Padmākaravarma*) และ พระมหาโลจาวะ รินเชน ซังโป (*Lo chen Rin chen bzang po*)
- **ฐานข้อมูล:** Derge Tengyur (sde dge bstan 'gyur) / Resource for Kanjur & Tanjur Studies (rKTs) / Asian Classics Input Project (ACIP/ALL)
- **รหัสคัมภีร์:** Derge Tengyur Toh. 3721 (D3721 / rKTs-T2543), rgyud 'grel
- **URL ต้นทาง:** `http://www.rkts.org/etexts/complete.php?id=D3721&coll=T` (Wylie) และ `complete2u.php?id=D3721&coll=T` (Tibetan Uchen)
- **ไฟล์ข้อมูลดิบในระบบ:** `research-notes/tibetan-raw-wylie.txt` และ `tibetan-raw-uchen.txt`
- **สถิติ:** 50 คาถา (ฉันทลักษณ์ 7 พยางค์ต่อบาท) พร้อมบทนมัสการและบทลงท้าย (Colophon)
- **วันที่ดึงข้อมูล:** 3 กันยายน 2026
