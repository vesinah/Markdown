Gurupañcāśikā
om namo buddhāya /

śrīvajrasattvapadavīpratilambhahetornatvā yathāvidhi guroścaraṇāravindam /
tatparyupāstiramalā bahutantragītā saṃkṣipya kathyata iyaṃ śṛṇutādareṇa // 1 //

abhiṣekāgralabdho hi vajrācāryastathāgataiḥ /
daśadiglokadhātusthaistrikālametya vandyate // 2 //

trikālaṃ parayā bhaktyā sapuṣpāñjalimaṇḍalaiḥ /
paryupāsyo guruḥ śāstā śirasā pādavandanāt // 3 //

saddharmādīn puraskṛtya gṛhī vā navako 'pi vā /
vandyo vratadharairbuddhyā lokāvadyāvahānaye // 4 //

sukhāsanaṃ samutthānamarthakriyādigauravam /
sarvameva vratī kuryāt tyaktvā cārcanavandanam // 5 //

prāk śiṣyācāryasaṃbandhaḥ kāryaḥ parīkṣya sūribhiḥ /
samānasamayabhraṃśo doṣo hi guruśiṣyayoḥ // 6 //

niṣkṛpaṃ krodhanaṃ krūraṃ stabdhaṃ laghumasaṃyatam /
svotkarṣakaṃ ca no kuryād guruṃ śiṣyaṃ ca buddhimān // 7 //

dhīro vinīto matimān kṣamāvānārjavo 'śaṭhaḥ /
mantratantraprayogajñaḥ kṛpāluḥ śāstrakovidaḥ // 8 //

daśatattvaparijñātā maṇḍalālekhyakarmavit /
mantravyākhyākṛdācāryaḥ prasannaḥ syājjitendriyaḥ // 9 //

taṃ nāthaṃ yo 'vamanyeta sa buddhebhyo 'vamanyate /
sarvabuddhāvamānena nityamāpnoti duḥkhatām // 10 //

māhendrabhayamutpannaṃ durādhivyasanaṃ tathā /
graharogaviṣāghātā rājadaṇḍādbhiriṣyate // 11 //

vyāḍapretābhibhūtāśca corānalasamudbhavaiḥ /
mṛtyumāpnoti durmedhā daurātmyena patatyadhaḥ // 12 //

kadācidapi no kuryādācāryasya manobhidām /
mohena yadi vā kuryāt pacyate narake dhruvam // 13 //

narakeṣu ca yaḥ prokto ghoro 'vīcirmahānapi /
ācāryamavamanyante te vasanti sughātinaḥ // 14 //

tasmāt sarvaprayatnena vajrācāryaṃ mahāmatim /
kalyāṇaguṇasaṃpūrṇaṃ na vilangheta karhicit // 15 //

pūjāṃ kuryāt prayatnena gurave satataṃ mudā /
na pīḍyate bhavaiḥ kleśairvyādhibhirvā kathañcana // 16 //

samayaṃ cātmanaḥ kuryānnityameva samāhitaḥ /
satataṃ tarpayed buddhabimbānācāryameva ca // 17 //

ātmasattvaviniṣpattau kiṃ punarvibhavaiḥ calaiḥ /
jīvitamadhiyā kuryācchāsane sthitaye rataḥ // 18 //

yasmāt kalpasahasrāṇi prāpyate bodhiruttamā /
pratyakṣaṃ dīyate seyaṃ janmanyasmin prayatnataḥ // 19 //

samayaṃ cātmano rakṣeccāturmāse tathāgate /
tatrāpi guruṇā deyaṃ dānaṃ sarvavidhaṃ sadā // 20 //

akṣayaṃ padamāpnoti yad yad rocate vastunā /
viśiṣṭaṃ cāpi tat sarvamācāryāya nivedayet // 21 //

taddattaṃ sarvabuddheṣu nityaṃ bhavati dānataḥ /
puṇyasaṃbhāra evaiṣa saṃbhārāt siddhiruttamā // 22 //

tasmācchiṣyo dayānvīto dāntaḥ śīlaguṇānvitaḥ /
ācārye vajradhariṇi na kuryādbhinnamānasaḥ // 23 //

caityalaṅghanabhītyā vā chāyāyāmapi laṅghayet /
upānahau ca pādukāṃ yānādīni ca kā kathā // 24 //

mahāmatiḥ prayatnena mudā guruvacaḥ śṛṇu /
aśaktaṃ yuktyā vācā ca nivedya vinivārayet // 25 //

gurorlabhati siddhiṃ ca svargaṃ vā padamavyayam /
tasmāt sarvaprayatnena gurorvākyaṃ na laṅghayet // 26 //

gurosdravyaṃ yathā prāṇān dāradravyān yathā gurum /
tasyaiva dāradravyāṇi mānayet satataṃ mudā // 27 //

sayanaṃ cāsanaṃ dhyānaṃ ghaṇṭāṃ cāpi maṇiṃ tathā /
pādāsanaṃ karamālaṃ stambhaṃ cāpi na laṅghayet // 28 //

utthite gurau nottheyaṃ tiṣṭhantyapi ca nāsayet /
satataṃ tatkriyāyoge sādhu dakṣo bhaved vratī // 29 //

kṣepanaṃ niṣṭhīvanaṃ ca tathāsane pādaprasāraṇam /
caṅkramaṃ kalahaṃ cāpi guroragre na kārayet // 30 //

aṅgamardanamudvṛttaṃ nṛtyaṃ gītaṃ ca vādanam /
kathāyogasya bahulaṃ śrutvāgre na samācaret // 31 //

natvā samutthānaṃ kuryādbhaktyā cāsanaṃ kalpayet /
niśitoyabhaye mārge śrute 'gre tu samācaret // 32 //

ācāryadarśanādagre kuryānnāṅgavikalpanām /
stambhādīn saṃśrayennaiva na kuryādaṅgumoṭanam // 33 //

kṣālanaṃ pādadhāvanaṃ mardanodvartanādikam /
namaskṛtya puraskṛtya kuryācchatkṛtya sarvadā // 34 //

tannāmoccāraṇaṃ kuryāt sādareṇāntakriyām /
anyeṣāṃ gauravārthāya viśiṣṭavacanairapi // 35 //

ācāryājñāṃ gṛhītvā ca kuryāttad vacanaṃ mudā /
baddhāñjaliḥ prasannātmā śṛṇuyādgurubhāṣitam // 36 //

hāsakāsādidvāreṇa mukhaṃ haste samāvṛṇot /
kṛtakārye sthito vākyamṛdunā sādhu saṃvṛṇot // 37 //

agrato vinīto vā bhūtvā vastrādi yuktam /
jānubhyāmañjaliṃ baddhvā śraddhānvesī trirarthayet // 38 //

vilāsamayīṃ ceṣṭāṃ tyajecchāstari saṃmukhe /
anyāṃśca tādṛśān doṣāṃ suparīkṣya parityajet // 39 //

pratiṣṭhāṃ maṇḍalaṃ homaṃ śiṣyasaṃgrahamākhyayā /
gurorvāse pure deśe nābhyanujñāto na kārayet // 40 //

pratiṣṭhādau labhyate yat tad dadyādgurave sadā /
tena dattaṃ tu gṛṇhīyādanyāṃśca toṣayenmudā // 41 //

guruśiṣyaṃ na kurvīta svayaṃ śiṣyatvahetunā /
na cāpi guroragre tu satkārādyucitocitam // 42 //

ācāryāya nivedyaiva yad dadyādgururātmanā /
baddhāñjalipuṭaṃ kṛtvā gṛṇhīyād gauravānvitaḥ // 43 //

avismṛtaḥ sadā kuryāt sarvacaryāṃ samāhitaḥ /
premṇā svabāndhave doṣān muditāvinivārayet // 44 //

rugṇastu gurukāryeṣu natvā cāpyanujñayā /
niṣiddhaṃ yadyapi kuryānnaivaṃ bhavati pāpabhāk // 45 //

kimanyat kathitenātra toṣayed guruṃ sarvadā /
avahelanaṃ sadā tyaktvā caryā kāryā prayatnataḥ // 46 //

ācāryānugāminī siddhirityukteḥ paramātmanaḥ /
jñātvā sarvaprakāreṇa gurutoṣāya yatnavān // 47 //

śuddhāśayo 'tha saddharmapātrakaḥ śaraṇaṃ gataḥ /
gurvanugamaśīlasya dadyād granthaṃ mudā budhaḥ // 48 //

tato mantrādidānena saddharmabhājanaṃ kṛte /
mūlāpattīścaturdaśa paṭhed dhārayed sadā // 49 //

iti gurumanugataśiṣyasya suhitavṛddhimanavadyam /
saṃcitaṃ yanmayedaṃ kuśalapadam anantamāśu tena //
vijitasugatabhāvā drāk susiddhiṃ labhantām /
sarvasatvāḥ prayatnāt paramasukhanidhānāḥ // 50 //
