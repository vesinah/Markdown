# คู่มือปฏิบัติสำหรับทีมจัดทำ Dossier (Dossier Agent Instructions) — อ่านก่อนทำงาน

## เป้าหมาย
สร้างไฟล์ Dossier 1 ไฟล์ต่อ 1 เอกสารใน `research-notes/sources/S-YYYY-author-short.md` ตามแม่แบบ และผ่านการตรวจ `verify_dossier.py` ทุกไฟล์

## แม่แบบ 4 ส่วน (บังคับ)
โครงสร้างไฟล์ Dossier ต้องมี 4 ส่วนเหมือนไฟล์ตัวอย่าง `research-notes/sources/S-2015-estrella-death-gold.md`:

1. **ส่วนที่ 1: ข้อมูลบรรณานุกรม** — Source ID (`S-YYYY-author-short`), ชื่อไฟล์ PDF, ชื่อไฟล์ Extracted Text (.md), ประเภทเอกสาร, ภาษา, อักษร (Script), Source URL (จาก manifest ของชุดฮาร์เวสหรือหน้าแรกของไฟล์), การอ้างอิงฉบับเต็ม Chicago (Note form + Bibliography form) — ห้ามแต่งข้อมูล: ใช้เฉพาะที่เห็นในตัวไฟล์หรือ manifest
2. **ส่วนที่ 2: แผนผังการจัดสรรเข้าบท** — ระบุบท (1-13) ที่เนื้อหาเอกสารรองรับ
3. **ส่วนที่ 3: บทวิเคราะห์สาระสำคัญ** — วิทยานิพนธ์หลักของผู้เขียน, บริบท, สาระเชิงประจักษ์สำคัญที่เกี่ยวกับแผ่นทองปิดศพ/สุสาน/การค้า/เทคโนโลยี
4. **ส่วนที่ 4: คลังข้อความอ้างอิงตรง (Verbatim Quotes Bank)** — จุดชีวิตของงาน

## กฎส่วนที่ 4 (Quotes Bank) — สำคัญที่สุด
- โควทต้องอยู่ในรูป: `> "ข้อความจากไฟล์ทุกตัวอักษรตรงเป๊ะ" (p. XX)`
- รายการ 3–8 โควทต่อเอกสาร เน้นประเด็นที่รองรับบทปลายทาง (แผ่นทองปิดศพ, หลุมศพ, ภูมิทัศน์, เครื่องเคลือบจีน, อายุ C-14/องค์ประกอบโลหะ, เทียบเคียงเวียดนาม/กัมพูชา/อินโดนีเซีย/จีน, คติความเชื่อ)
- **ต้องคัดลอกข้อความจาก `extracted-texts/<id>.md` ทุกตัวอักษร** ห้ามพิมพ์ใหม่จากความจำ ห้ามแก้คำ เครื่องหมาย หรือเว้นวรรค
- เลขหน้า (p. XX) ต้องเอาจากตัวช่วย `<!-- Page N -->` ที่อยู่เหนือโควทในไฟล์ .md จริง
- ถ้าไฟล์ .md ไม่มีเลขหน้าพิมพ์จริง ให้ใช้เลขหน้า PDF (`<!-- Page N -->`) และเขียนกำกับว่าเป็นหน้า PDF
- โควทที่ยาวตัดได้แต่ต้องตัดให้ "จบคำตรงช่วงที่ยังต่อเนื่องในไฟล์" (ตัดหัว-ท้ายเท่านั้น ไม่ตัดกลางคำ) — ความยาวโควท 60–350 ตัวอักษรเหมาะสม
- ตามด้วยบรรทัด `  - **คำแปลสรุป/ความหมาย:** ...` เป็นภาษาไทย

## เทคนิคอ่านไฟล์ขนาดใหญ่ (สำคัญ)
ไฟล์ .md บางไฟล์ใหญ่มาก (0.3–1.7 MB) ห้ามอ่านทั้งไฟล์เข้า context:
1. ใช้ `grep -n "คำค้น"` บนไฟล์ .md เพื่อหาบรรทัดที่เกี่ยว (คำค้น: gold, mask, eye, nose, burial, grave, jar, Oton, Butuan, Cebu, Prohear, gold mask, radiocarbon, XRF, Song, Yuan, Ming, céramique, liao, 遼, 金面, death, orifice, ฯลฯ)
2. ใช้ Read tool แบบระบุ offset/limit เพื่ออ่านเฉพาะช่วงรอบบรรทัดที่เจอ (±60 บรรทัด)
3. คัดโควทจากช่วงนั้นโดยคัดลอกตรงตัว (ต้องคำนึงว่า markdown มีตัวหนา/ตัวเอียง `*` ปะปน — คัดลอก "ตามที่เห็นในไฟล์" ระบบ verify มี Layer ตัด markdown styling ให้ แต่ตัวอักษร/คำต้องตรง)

## การตรวจและวงจรแก้ไข
หลังเขียน Dossier แต่ละไฟล์ รัน:
```
python .agent/scripts/verify_dossier.py "research-notes/sources/S-YYYY-author-short.md"
```
(ทำงานจาก D:\01_APP\Research) — ต้อง exit 0 (PASS) ทุกไฟล์ ถ้า FAIL ให้เปิดไฟล์ .md ต้นทางเทียบแล้วแก้โควทให้ตรงจนผ่าน

## ห้ามเด็ดขาด
- ห้ามแต่งเลขหน้า ชื่อ ปี หรือข้อความใดที่ไม่ได้มาจากไฟล์ .md หรือ manifest
- ห้ามใช้ Abstract-only (ทุกไฟล์ในรายการมีข้อความเต็มแล้ว)
- ห้ามเขียนโควทโดยไม่ได้อ่านช่วงนั้นจากไฟล์จริง
- ห้ามเปิดอินเทอร์เน็ต (งานนี้ใช้ไฟล์ในเครื่องเท่านั้น)

## การส่งมอบ
รายงานท้ายงาน: ตาราง ชื่อ dossier | verify PASS/FAIL | จำนวนโควท | หมายเหตุความเกี่ยวข้องกับบท
