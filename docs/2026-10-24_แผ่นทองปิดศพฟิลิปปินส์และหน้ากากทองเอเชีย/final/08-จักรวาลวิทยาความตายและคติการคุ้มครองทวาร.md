## 8.1 ภูมิทัศน์วิญญาณนิยมและจักรวาลวิทยาความตายของกลุ่มชนออสโตรนีเชียน: โลกหน้า, สุลัด, และพิธีกรรมเปลี่ยนผ่านสภาวะ

### 1. บทนำและกรอบมโนทัศน์: จักรวาลวิทยาความตายของกลุ่มชนผู้ใช้ภาษาตระกูลออสโตรนีเชียน

ในทางมานุษยวิทยาสัญลักษณ์และโบราณคดีศาสนา ความตายมิได้เป็นเพียงปรากฏการณ์ทางชีววิทยาที่การทำงานของอวัยวะและเซลล์ในร่างกายมนุษย์ยุติลงเท่านั้น หากแต่เป็น "ปรากฏการณ์ทางสังคมและจักรวาลวิทยา" (*Cosmological and Social Phenomenon*) ที่กระตุ้นให้เกิดระบบความเชื่อ พิธีกรรม และวัฒนธรรมวัตถุที่ซับซ้อนที่สุดของมนุษยชาติ [1] [2] สำหรับกลุ่มชนผู้ใช้ภาษาตระกูลออสโตรนีเชียน (*Austronesian-speaking Peoples*) ซึ่งตั้งถิ่นฐานและแผ่ขยายอารยธรรมครอบคลุมทั่วหมู่เกาะเอเชียตะวันออกเฉียงใต้และมหาสมุทรแปซิฟิก มโนทัศน์เกี่ยวกับความตายมีลักษณะร่วมทางวัฒนธรรมที่ลึกซึ้งและหยั่งรากลึกมายาวนานนับพันปี [2] [3]

โลกทัศน์วิญญาณนิยมดั้งเดิมของชาวออสโตรนีเชียน (*Indigenous Austronesian Animism*) มองจักรวาลเป็นองค์รวมที่สิ่งมีชีวิต มนุษย์ ธรรมชาติ สิ่งแวดล้อม และดวงวิญญาณ เชื่อมโยงสัมพันธ์กันอย่างไร้รอยต่อ [3] [4] โลกมิได้ถูกแบ่งแยกอย่างเด็ดขาดระหว่าง "กายภาพ" กับ "จิตวิญญาณ" หากแต่มีมิติซ้อนทับกันอยู่ตลอดเวลา ในกรอบทัศน์นี้ มนุษย์มิได้เป็นเจ้าเหนือธรรมชาติ หากแต่เป็นส่วนหนึ่งของสายใยแห่งพลังงานชีวิต จักรวาลเต็มไปด้วยอำนาจลึกลับ ดวงวิญญาณของบรรพบุรุษ (*Ancestral Spirits*) และอำนาจเหนือธรรมชาติประจำถิ่น (*Spirits of Nature*) [4] [5]

เมื่อความตายมาเยือน สังคมออสโตรนีเชียนมิได้ตีความว่าการดับสูญของร่างกายคือจุดสิ้นสุดของอัตลักษณ์บุคคล (*Annihilation of Being*) หากแต่ทำความเข้าใจความตายในฐานะ **"พิธีกรรมเปลี่ยนผ่านสภาวะ" (Rite of Passage)** ตามกรอบทฤษฎีคลาสสิกของอาร์โนลด์ ฟาน เจนเนป (*Arnold van Gennep*) [1] ฟาน เจนเนป ชี้ให้เห็นว่า พิธีกรรมเปลี่ยนผ่านทุกประเภทประกอบด้วย 3 ระยะสำคัญ ได้แก่:
1. **ระยะการแยกตัว (Separation / Preliminal Phase):** การตัดขาดผู้ตายออกจากโลกของคนเป็น
2. **ระยะช่วงต่อหรือระยะก้ำกึ่ง (Liminal / Transitional Phase):** สภาวะที่วิญญาณของผู้ตายยังมิได้เข้าสู่ดินแดนใหม่โดยสมบูรณ์ และร่างศพยังอยู่ในระหว่างการสลายตัว ซึ่งเป็นช่วงเวลาที่อันตรายและเปราะบางที่สุด
3. **ระยะการรวมตัวใหม่ (Incorporation / Postliminal Phase):** การที่ดวงวิญญาณของผู้ตายได้เข้าสถิตในดินแดนบรรพชนอย่างถาวร และได้รับการยกระดับสถานะขึ้นเป็นผีบรรพบุรุษผู้ทรงฤทธิ์ [1] [2]

ในบริบทของหมู่เกาะฟิลิปปินส์ยุคก่อนอาณานิคม โบราณวัตถุทองคำโดยเฉพาะแผ่นทองคำปิดทวารบนใบหน้าผู้ตาย (*Mortuary Gold Orifice Covers*) ทำหน้าที่เป็น "กลไกวัตถุเชิงพิธีกรรม" (*Ritual Material Technology*) ที่ถูกสร้างขึ้นมาเพื่อควบคุมและคุ้มครองความปลอดภัยของบุคคลในช่วงระยะก้ำกึ่ง (*Liminal Phase*) ของการเปลี่ยนผ่านสภาวะนี้โดยตรง [2] [3] [6]

```
+---------------------------------------------------------------------------------------------------+
|               วงจรพิธีกรรมเปลี่ยนผ่านสภาวะแห่งความตายในจักรวาลวิทยาออสโตรนีเชียน                     |
+---------------------------------------------------------------------------------------------------+
| 1. ระยะแยกตัว (Separation):                                                                       |
|    - สรีระสิ้นลมหายใจ → พันธะระหว่างพลังชีวิต (Dungan) กับวิญญาณอมตะ (Kalag) เริ่มคลายตัว           |
|    - การชำระล้างร่างด้วยน้ำหอมการบูรและสมุนไพร เพื่อตัดขาดจากมลทินของโลกคนเป็น                     |
|                                       ↓                                                           |
| 2. ระยะก้ำกึ่ง (Liminal Phase) - **ช่วงอันตรายสูงสุด**:                                           |
|    - ร่างกายกำลังเน่าเปื่อย ช่องทวารเปิดกว้าง กลายเป็นประตูเชื่อมต่อระหว่างสองโลก                  |
|    - ภัยคุกคามจากภูตผีปีศาจกินซากศพ (Asuang / Balbal / Mahikawon) ที่จะมาชิงวิญญาณ                 |
|    - **การแทรกแซงด้วยแผ่นทองคำปิดทวาร (ตา จมูก ปาก)**: สถาปนาเกราะพิทักษ์อภิปรัชญา                 |
|    - การบังคับใช้ข้อห้ามไว้ทุกข์ลาราโอ (Larao Strict Taboos) สร้างความสงบศักดิ์สิทธิ์            |
|                                       ↓                                                           |
| 3. ระยะรวมตัวใหม่ (Incorporation):                                                                |
|    - การนำพาดวงวิญญาณข้ามห้วงน้ำใหญ่ด้วยเรือแห่งดวงวิญญาณ (Boat of the Dead)                       |
|    - การเดินทางถึงดินแดนบรรพบุรุษ (Sulad / Saad / Kasakian)                                       |
|    - การเปลี่ยนผ่านสถานะของ Kalag ขึ้นเป็น **อานิโต (Anito)** หรือ **อูมาลากัด (Umalagad)**         |
|      เพื่อทำหน้าที่พิทักษ์คุ้มครองวงศ์ตระกูลที่ยังมีชีวิตสืบไป                                    |
+---------------------------------------------------------------------------------------------------+
```

### 2. แนวคิดเรื่องโลกหน้า: สุลัด (Sulad), ซาอัด (Saad), และกาสะเคียน (Kasakian)

จักรวาลวิทยาของสังคมฟิลิปปินส์โบราณ โดยเฉพาะในกลุ่มชาติพันธุ์วิซายาส์ (*Visayan Ethnolinguistic Groups*) ซึ่งได้รับการบันทึกไว้อย่างละเอียดในจดหมายเหตุสเปนศตวรรษที่ 16 และงานวิจัยชาติพันธุ์วรรณนา มีโครงสร้างภูมิศาสตร์แห่งปรโลก (*Mythological Geography of the Underworld*) ที่มีความหลากหลายและสะท้อนสภาพแวดล้อมทางทะเลของหมู่เกาะอย่างแจ่มชัด [4] [7]

มิเกล เด โลอาร์กา (*Miguel de Loarca*) ในบันทึกประวัติศาสตร์ *Relación de las Yslas Filipinas* (ค.ศ. 1582) ได้บันทึกถึงความเชื่อเรื่องดินแดนแห่งความตายของชาววิซายาส์ไว้ว่า โลกหน้าถูกแบ่งออกเป็นมิติต่าง ๆ ตามสถานะและลักษณะการตายของบุคคล [7] ดินแดนหลังความตายที่เป็นที่รู้จักมากที่สุดมี 3 ภพภูมิหลัก [4] [7]:

```
+---------------------------------------------------------------------------------------------------+
|               โครงสร้างภูมิศาสตร์ปรโลกในจักรวาลวิทยาความตายของชาววิซายาส์โบราณ                     |
+-------------------+----------------------------+-----------------------+--------------------------+
|  ชื่อดินแดนปรโลก  |       ที่ตั้งทางจักรวาล    |        สภาพแวดล้อม    |   กลุ่มบุคคลผู้เข้าพำนัก  |
|   (Afterlife Realm|     (Cosmic Location)      |      (Environment)    |      (Destined Souls)    |
+-------------------+----------------------------+-----------------------+--------------------------+
| 1. สุลัด          | ตั้งอยู่ใต้พิภพหรือข้ามทะเล | ดินแดนที่อุดมสมบูรณ์   | วิญญาณของบุคคลทั่วไป     |
|    (Sulad)        | ลึกในแนวเทือกเขาศักดิ์สิทธิ์| มีหมู่บ้าน ลำน้ำ และ  | และชนชั้นนำที่ประกอบ     |
|                   | (เช่น Mount Madya-as)      | สวนเกษตรกรรมคล้ายโลก  | พิธีกรรมศพอย่างครบถ้วน   |
+-------------------+----------------------------+-----------------------+--------------------------+
| 2. ซาอัด          | ภพภูมิสัญญาสวรรค์          | ดินแดนแห่งความรื่นรมย์ | ชนชั้นนำดาตูและนักรบ     |
|    (Saad)         | บนยอดเขาสูงหรือเกาะสวรรค์  | มีงานเลี้ยงฉลอง อาหาร | ผู้ประกอบวีรกรรมและมี     |
|                   | ในทิศที่ดวงอาทิตย์ตก       | และสุราพังกาซีไม่รู้จบ| เครื่องอุทิศทองคำพรั่งพร้อม|
+-------------------+----------------------------+-----------------------+--------------------------+
| 3. กาสะเคียน      | ภพภูมิแห่งความมืดมิด       | ดินแดนแห้งแล้ง หนาวเย็น| วิญญาณของผู้ตายผิดธรรมชาติ|
|    (Kasakian)     | ใต้ก้นบึ้งของมหาสมุทร      | เต็มไปด้วยความทุกข์ทรมาน| คนยากจนที่ไร้เครื่องอุทิศ|
|                   | หรือหุบเหวลึก              | และการถูกลงโทษ        | หรือผู้ละเมิดจารีตชุมชน  |
+-------------------+----------------------------+-----------------------+--------------------------+
```

โลอาร์การะบุว่า เมื่อบุคคลเสียชีวิต ดวงวิญญาณจะต้องเดินทางไปยังดินแดนที่เรียกว่า **สุลัด (Sulad)** ซึ่งมักตั้งอยู่ ณ ปลายสุดของขอบฟ้าทางทะเลหรือบนยอดเขาสูงศักดิ์สิทธิ์ เช่น เทือกเขามาดียัส (*Mount Madya-as*) ในเกาะปานาย [4] [7] สุลัดมิได้มีสภาพเป็นนรกแห่งการลงทัณฑ์ตามแนวคิดคริสต์ศาสนา หากแต่เป็นภาพสะท้อนของโลกมนุษย์ที่มีหมู่บ้าน ทุ่งนา ลำธาร และป่าไม้ ที่ซึ่งดวงวิญญาณของบรรพชนจะกลับมารวมตัวกันและใช้ชีวิตสืบเนื่องต่อไป [4] [7]

ในงานศึกษาชาติพันธุ์วรรณนาของเอฟ. ลันดา โฮกาโน (*F. Landa Jocano*) เกี่ยวกับชาวซูลอด (*Sulod*) ในเทือกเขากลางเกาะปานาย ซึ่งเป็นกลุ่มชนดั้งเดิมที่สืบทอดความเชื่อก่อนอาณานิคม ได้ให้รายละเอียดเกี่ยวกับมหากาพย์การเดินทางของวิญญาณสู่สุลัดว่า วิญญาณจะต้องเผชิญหน้ากับด่านตรวจสอบหลายด่าน และต้องข้ามลำน้ำแห่งความตายขนาดใหญ่ [8] [9] ผู้ตายที่จะสามารถข้ามผ่านเข้าสู่สุลัดหรือภพภูมิสวรรค์ **ซาอัด (Saad)** ได้อย่างราบรื่น จะต้องเป็นบุคคลที่ได้รับการประกอบพิธีกรรมอย่างถูกต้องจากญาติมิตร มีการแต่งกายด้วยอาภรณ์ที่ดีที่สุด และมี "เครื่องเบิกทาง" ที่ทำจากทองคำบริสุทธิ์ [4] [8]

ในทางตรงกันข้าม หากบุคคลใดเสียชีวิตโดยไม่มีผู้ประกอบพิธีกรรมให้ ไร้ญาติมิตร หรือเป็นทาสที่ไร้เครื่องอุทิศ ดวงวิญญาณจะถูกผลักไสให้ตกลงสู่ **กาสะเคียน (Kasakian)** ซึ่งเป็นดินแดนแห่งความทุกข์ยาก โดดเดี่ยว และมืดมนใต้ก้นบึ้งของมหาสมุทร [4] [7] จักรวาลวิทยาความตายของออสโตรนีเชียนจึงเป็นโครงสร้างที่ตอกย้ำและสืบทอด "สถานภาพทางสังคมและชนชั้น" (*Social Hierarchy*) จากโลกมนุษย์ไปสู่โลกหน้าอย่างไม่มีวันสิ้นสุด [2] [4]

### 3. ความตายในฐานะการเปลี่ยนผ่านสถานะ (Rite of Passage) มิใช่จุดสิ้นสุด

มโนทัศน์ที่ว่าความตายคือการเปลี่ยนผ่านสภาวะ มิใช่การดับสูญ ก่อให้เกิดทัศนคติและการปฏิบัติต่อสรีระของผู้ตายที่แตกต่างอย่างลึกซึ้งจากสังคมสมัยใหม่ [1] [2] สรีระของบุคคลหลังความตายมิได้ถูกมองว่าเป็นเพียง "ซากศพ" (*Corpse*) ที่ไร้ประโยชน์และต้องรีบนำไปกำจัดทิ้ง หากแต่เป็น "ภาชนะศักดิ์สิทธิ์" (*Sacred Vessel*) ที่ยังคงมีความผูกพันกับอัตลักษณ์และสถานะของดวงวิญญาณตลอดระยะเวลาของการเปลี่ยนผ่าน [2] [3]

วิลเลียม เฮนรี สก็อตต์ (*William Henry Scott*) นักประวัติศาสตร์ชั้นครู ได้ชี้ให้เห็นว่า ในสังคมฟิลิปปินส์ศตวรรษที่ 16 กระบวนการจัดการศพของชนชั้นนำดาตูเป็นกระบวนการที่ยาวนาน กินเวลาหลายวันจนถึงหลายสัปดาห์ [4]:

> "All datus or prominent persons wanted to be buried in a traditional longon, decorated with fanciful carvings often executed by the future occupant himself during his lifetime. Some wore ac tual masks and mouthpieces of beaten gold... The dead were buried in coffins placed in caves with thin plates of gold over their mouth and eyes" [4]

ความปรารถนาของชนชั้นนำที่จะได้รับการบรรจุในโลงไม้ขุดเนื้อแข็ง (*Longon*) ที่ตนเองเป็นผู้แกะสลักลวดลายขึ้นในขณะที่ยังมีชีวิต และการสวมใส่หน้ากากทองคำหรือแผ่นปิดตาปิดปากทองคำ สะท้อนถึง **"การเตรียมการล่วงหน้าเพื่อการเปลี่ยนผ่านสภาวะ"** อย่างมีสติ [2] [4] ความตายสำหรับดาตูมิใช่อุบัติเหตุที่น่าหวาดกลัว แต่เป็นขั้นตอนสำคัญที่สุดของการบรรลุสถานภาพสูงสุดแห่งชีวิต คือการเปลี่ยนผ่านจาก "ผู้นำทางการเมืองในโลกมนุษย์" ไปสู่ "เทพบรรพชนผู้อารักษ์ชุมชนในปรโลก" (*Apotheosis into Ancestral Deity*) [2] [4]

ในระหว่างที่สรีระนอนสงบนิ่งอยู่ในโลงไม้ลองกอน ชุมชนจะร่วมกันประกอบพิธีกรรมเพื่อประคับประคองการเปลี่ยนผ่านนี้ การที่ร่างกายยังคงรักษารูปลักษณ์ มีการประดับเครื่องทองคำ และมีการอุดชโลมช่องทวารด้วยน้ำยางพลู (*Buyo Sap*) เป็นการส่งสัญญาณทางสัญลักษณ์แก่ปวงผีบรรพชนว่า ผู้ตายพร้อมแล้วที่จะละทิ้งพันธะแห่งโลกียะและก้าวเข้าสู่ความเป็นอมตะ [4] [6]

### 4. ความสัมพันธ์ระหว่างสรีระวัตถุกับจักรวาลวิทยา: สุสานในฐานะพื้นที่ศักดิ์สิทธิ์รอยต่อระหว่างภพ

ในภูมิทัศน์เชิงพื้นที่ (*Spatial Landscape*) ของสังคมออสโตรนีเชียน สุสานมิได้เป็นเพียงพื้นที่ทิ้งซากศพทางกายภาพ หากแต่เป็น **"พื้นที่ศักดิ์สิทธิ์แห่งรอยต่อระหว่างภพ" (Liminal Heterotopia)** [2] [10] การเลือกทำเลที่ตั้งของสุสานในแหล่งโบราณคดีสำคัญของฟิลิปปินส์ เช่น แหล่งซานอันโตนิโอ โอตอน ริมแนวสันทรายชายฝั่งช่องแคบอิโลอิโล, สุสานอัมบังกันและซูอาตันริมแม่น้ำอากูซันในบูตูอัน, และสุสานปลาซาอินเดเปนเดนเซียริมอ่าวเซบู ล้วนมีความสัมพันธ์อย่างแนบแน่นกับ "น้ำ" (*Water*) และ "การเชื่อมต่อทางภูมิศาสตร์" [2] [10] [11]

น้ำในจักรวาลวิทยาออสโตรนีเชียนมีนัยทางสัญลักษณ์ 2 ประการที่ขัดแย้งและประสานกัน:
ในด้านหนึ่ง น้ำคือสื่อกลางแห่งการค้า ความมั่งคั่ง และการเชื่อมต่อระหว่างชุมชนชายฝั่ง
ในอีกด้านหนึ่ง น้ำคือ "พรมแดนธรรมชาติที่แบ่งแยกโลกคนเป็นออกจากโลกคนตาย" [3] [10]
การตั้งสุสานไว้ริมแม่น้ำหรือชายฝั่งทะเล สะท้อนถึงการเตรียมความพร้อมให้ดวงวิญญาณสามารถก้าวลงสู่เรือเพื่อแล่นออกสู่อ่าวและข้ามทะเลหลวงไปสู่ดินแดนสุลัดได้อย่างสะดวก [8] [10]

ภายในหลุมศพ การจัดวางสรีระและวัฒนธรรมวัตถุถูกควบคุมด้วยแบบแผนจักรวาลวิทยาอย่างเข้มงวด การวางทิศทางของศีรษะส่วนใหญ่จะหันไปทางทิศตะวันออกหรือทิศเหนือ ซึ่งเป็นทิศแห่งการกำเนิด แสงสว่าง และภูเขาศักดิ์สิทธิ์ต้นน้ำ [10] [12] การวางแผ่นทองคำปิดตา ปิดจมูก และปิดปากลงบนใบหน้าของผู้ตายในหลุมศพ เป็นการสถาปนา "พื้นที่ศักดิ์สิทธิ์ขนาดจิ๋ว" (*Micro-sacred Space*) ขึ้นบนร่างกายของมนุษย์ [3] [6] ร่างกายที่ถูกปิดทวารด้วยทองคำจะไม่สามารถถูกแทรกซึมโดยพลังงานด้านลบของดินหรือสิ่งอัปมงคล และกลายเป็นสะพานเชื่อมทางจิตวิญญาณระหว่างพื้นที่หลุมฝังศพใต้ดินกับภพภูมิบรรพบุรุษเบื้องบน [2] [6]

### 5. บทสังเคราะห์: อุดมการณ์ทางวัฒนธรรมที่ผลักดันการใช้ทองคำในพิธีกรรมศพ

เหตุใดสังคมฟิลิปปินส์โบราณจึงเลือกใช้ "ทองคำ" เป็นวัสดุหลักในการปิดกั้นช่องทวารบนใบหน้าผู้ตาย? คำตอบสำหรับคำถามเชิงโครงสร้างนี้มิได้จำกัดอยู่เพียงเรื่องของความมั่งคั่งทางเศรษฐกิจเท่านั้น หากแต่อยู่ที่ **"อภิปรัชญาแห่งคุณสมบัติของทองคำ" (The Metaphysics of Gold)** ในระบบสัญลักษณ์นิยมออสโตรนีเชียน [2] [3]

จอห์น กาย (*John Guy*) และแมรี เจน หลุยส์ โบลูเนีย (*Mary Jane Louise Bolunia*) ได้วิเคราะห์อย่างลึกซึ้งว่า ทองคำเป็นสสารชนิดเดียวในธรรมชาติที่รวบรวมคุณสมบัติอุดมคติ 3 ประการไว้พร้อมกัน [3] [6]:
1. **ความบริสุทธิ์ไม่เสื่อมสลาย (Incorruptibility):** ในโลกที่ทุกสิ่งทุกอย่าง ตั้งแต่ร่างกายมนุษย์ พืชพันธุ์ ไปจนถึงไม้และผ้า ต้องเน่าเปื่อยผุพังสลายตัวไปตามกาลเวลา ทองคำเป็นสสารเดียวที่ไม่เกิดสนิม ไม่ดำคล้ำ และไม่ผุกร่อน ทองคำจึงกลายเป็น "อุปมานิทรรศน์แห่งความเป็นอมตะ" (*Metaphor of Immortality*) ที่สมบูรณ์แบบที่สุด การนำทองคำมาทาบทับสรีระที่กำลังจะเน่าเปื่อย เป็นความพยายามเชิงพิธีกรรมในการถ่ายโอนคุณสมบัติความไม่เน่าเปื่อยของทองคำให้แก่ร่างของผู้ตาย [3] [6]
2. **แสงสว่างและการสะท้อนรังสีสุริยะ (Solar Radiance):** สีเหลืองทองอร่ามที่เปล่งประกายเงางามถูกเชื่อมโยงเข้ากับพลังแห่งดวงอาทิตย์ ไฟ และแสงสว่าง ในจักรวาลวิทยาโบราณ แสงสว่างคืออาวุธที่มีอานุภาพสูงสุดในการขับไล่ความมืดมิดและภูตผีปีศาจ การปิดทวารด้วยแผ่นทองคำจึงเปรียบเสมือนการติดตั้งดวงประทีปแห่งแสงสว่างไว้เหนือดวงตา จมูก และปาก เพื่อส่องทางให้แก่วิญญาณในความมืดแห่งปรโลก [2] [3]
3. **การแปลงสภาพทุนทางเศรษฐกิจสู่ทุนสัญลักษณ์ (Conversion of Capital):** ดังที่โบลูเนียเสนอใน *"The Death of Gold in Early Visayan Society"* การที่ชนชั้นนำยอม "ฝังทองคำทิ้งไว้ใต้ดิน" มิใช่ความไร้เหตุผลทางเศรษฐศาสตร์ แต่เป็นกลยุทธ์สูงสุดในการสถาปนาเกียรติภูมิอันเป็นนิรันดร์ของวงศ์ตระกูล [6] ทองคำที่ถูกเปลี่ยนเป็นแผ่นปิดทวารศพได้ก้าวพ้นจากการเป็นสินค้าโภคภัณฑ์ในระบบตลาด ไปสู่การเป็น "วัตถุศักดิ์สิทธิ์ประจำบรรพชน" (*Sacred Ancestral Regalia*) ที่ยืนยันความชอบธรรมในการสืบทอดอำนาจของทายาทรุ่นต่อไป [2] [6]

จักรวาลวิทยาความตายและภูมิทัศน์วิญญาณนิยมของชาวออสโตรนีเชียนจึงเป็นพลังขับเคลื่อนพื้นฐานที่ให้กำเนิด ให้ความหมาย และค้ำจุนประเพณีแผ่นทองคำปิดทวารศพในหมู่เกาะฟิลิปปินส์ให้ดำรงอยู่อย่างมั่นคงยาวนานหลายร้อยปี ก่อนที่จะเกิดการปะทะและเปลี่ยนผ่านครั้งใหญ่ในยุคอาณานิคม

## 8.2 มโนทัศน์วิญญาณสองขั้ว: ดุงงัน (Dungan) และ กาลัก (Kalag): ภววิทยา พลังชีวิต และการเปลี่ยนผ่านสู่ผีบรรพชน

### 1. บทนำและกรอบภววิทยา: โครงสร้างวิญญาณคู่ (The Dual-Soul Complex) ในโลกทัศน์ออสโตรนีเชียน

ในการศึกษาระบบความเชื่อของกลุ่มชนผู้ใช้ภาษาตระกูลออสโตรนีเชียน หนึ่งในข้อค้นพบทางมานุษยวิทยาที่สำคัญที่สุดคือ โครงสร้างของ "ตัวตนและจิตวิญญาณ" มิได้ถูกมองเป็นเอกภาพเดี่ยว (*Unitary Soul*) เหมือนในปรัชญาตะวันตกหรือเทววิทยากระแสหลัก [13] [2] หากแต่ตั้งอยู่บนฐานคิดเรื่อง **"วิญญาณสองขั้ว" หรือ "ระบบพหุวิญญาณ" (The Dual-Soul Complex / Multi-Soul Ontology)** ซึ่งมองว่าภายในสรีระของมนุษย์คนหนึ่ง ประกอบด้วยดวงวิญญาณอย่างน้อย 2 ดวง หรือพลังงานจิตวิญญาณ 2 ระดับที่ทำหน้าที่และมีวิถีการดำรงอยู่แตกต่างกันอย่างสิ้นเชิง [2] [3]

ในงานศึกษาชาติพันธุ์วรรณนาเปรียบเทียบทั่วภูมิภาคเอเชียตะวันออกเฉียงใต้ภาคพื้นสมุทร ไม่ว่าจะเป็นชาวบาตัก (*Batak*) ในเกาะสุมาตรา, ชาวดายัก (*Dayak*) ในเกาะบอร์เนียว, ชาวโตราจา (*Toraja*) ในเกาะสุลาเวสี, ตลอดจนกลุ่มชนต่าง ๆ ในหมู่เกาะฟิลิปปินส์ มโนทัศน์วิญญาณสองขั้วนี้ปรากฏขึ้นอย่างสม่ำเสมอในฐานะแกนกลางของระบบคิด [3] [4] [14] ในหมู่เกาะฟิลิปปินส์โบราณ โดยเฉพาะในกลุ่มภาษาและวัฒนธรรมวิซายาส์และทากาล็อก โครงสร้างวิญญาณคู่นี้ถูกนิยามผ่านคำศัพท์พื้นเมือง 2 คำที่สำคัญยิ่ง ได้แก่ **ดุงงัน (Dungan)** หรือบางแห่งเรียก **กาลูฮา (Kaluha)** และ **กาลัก (Kalag)** หรือในภาษาทากาล็อกคือ **กาลูลูวา (Kaluluwa)** [2] [6]

การทำความเข้าใจความสัมพันธ์ ความขัดแย้ง และพลวัตการแยกตัวระหว่างดุงงันกับกาลัก ถือเป็นกุญแจสำคัญที่สุดในการถอดรหัสความหมายทางอภิปรัชญาของการใช้แผ่นทองคำปิดทวารบนใบหน้าผู้ตาย [2] [15] การปิดกั้นดวงตา ช่องจมูก และช่องปาก มิใช่การกระทำเชิงกายภาพล้วน ๆ หากแต่เป็น "ปฏิบัติการเชิงเทคโนโลยีทางจิตวิญญาณ" (*Spiritual Technology*) ที่ออกแบบมาเพื่อควบคุมการเคลื่อนย้ายและพิทักษ์ความปลอดภัยของวิญญาณทั้งสองขั้วในห้วงเวลาแห่งการเปลี่ยนผ่านสภาวะของความตาย [6] [15]

### 2. ดุงงัน (Dungan / Kaluha): วิญญาณพลังชีวิต เจตจำนง และภาวะเปราะบางต่อการหลุดลอย

ในระบบความเชื่อพื้นเมืองวิซายาส์ **ดุงงัน (Dungan)** คือพลังชีวิตอันเป็นต้นกำเนิดของความกระปรี้กระเปร่า สติปัญญา เจตจำนง ความกล้าหาญ และอำนาจบารมีของมนุษย์ [2] [8] เอฟ. ลันดา โฮกาโน (*F. Landa Jocano*) ได้บันทึกรายละเอียดของมโนทัศน์ดุงงันในงานวิจัยชาติพันธุ์วรรณนาว่า ชาวบ้านเชื่อว่าทารกแรกเกิดมีดุงงันที่อ่อนแอมาก และดุงงันจะค่อย ๆ เติบโตและแข็งแกร่งขึ้นตามอายุ ประสบการณ์ และการฝึกฝน [8] [9]

ความเข้มแข็งของดุงงันมิได้เท่าเทียมกันในมนุษย์ทุกคน ชนชั้นนำระดับผู้นำทางการเมืองหรือ **ดาตู (Datu)** ตลอดจนนักรบผู้กล้าหาญ (*Bagani*) และคนทรงนักบวชหญิง (*Babaylan*) ถูกเชื่อว่าเป็นผู้ที่ครอบครอง **"ดุงงันที่มีอำนาจสูงส่งเป็นพิเศษ" (Strong or Heavy Dungan)** [2] [8] บุคคลที่มีดุงงันแก่กล้าจะแสดงออกผ่านสายตาที่ทรงพลัง เสียงพูดที่น่าเกรงขาม ความสามารถในการโน้มน้าวใจผู้คน และการมีโชคลาภในการสงครามและการค้าทางทะเล ในทางกลับกัน บุคคลที่มีดุงงันอ่อนแอ (*Weak Dungan*) จะเป็นคนขี้ขลาด เจ็บป่วยง่าย และถูกครอบงำโดยผู้อื่นได้ง่าย [2] [8]

อย่างไรก็ดี คุณลักษณะพื้นฐานที่สำคัญที่สุดของดุงงันคือ **"ความเปราะบางต่อการหลุดลอย" (Volatile & Detachable Nature)** [2] [4] ดุงงันมิได้ถูกผูกมัดติดแน่นกับกายเนื้ออย่างถาวร ในขณะที่มนุษย์นอนหลับ ดุงงันสามารถเดินทางออกจากร่างกายผ่านทางช่องทวารเปิด (โดยเฉพาะจมูกหรือปาก) เพื่อท่องเที่ยวไปในมิติต่าง ๆ ปรากฏการณ์นี้คือสิ่งที่อธิบายการเกิด "ความฝัน" (*Dreams*) [2] [8] การปลุกบุคคลที่กำลังนอนหลับอยู่อย่างกะทันหันถือเป็นข้อห้ามร้ายแรงในวัฒนธรรมดั้งเดิม เพราะอาจทำให้ดุงงันเดินทางกลับเข้าสู่ร่างไม่ทัน ส่งผลให้บุคคลนั้นเกิดอาการเสียสติ ล้มป่วย หรือถึงแก่ความตายได้ [2] [8]

ยิ่งไปกว่านั้น ดุงงันยังเสี่ยงต่อการถูกคุกคามโดยอำนาจภายนอก ภาวะที่เรียกว่า **"การสูญเสียวิญญาณ" (Soul Loss)** เกิดขึ้นเมื่อดุงงันถูกดักจับ หลอกล่อ หรือทำร้ายโดยวิญญาณร้ายในป่า (*Engkanto*) หรือถูกดูดกลืนโดยบุคคลที่มีดุงงันแข็งแกร่งกว่า [2] [8] เมื่อดุงงันหลุดลอย ร่างกายจะทรุดโทรมและหมดเรี่ยวแรง และหากไม่ได้รับการประกอบพิธีเรียกขวัญกลับคืนโดยบาบายลัน ร่างกายนั้นจะเข้าสู่ภาวะแห่งความตายในที่สุด [8] [9]

เมื่อความตายทางชีววิทยาเกิดขึ้นอย่างสมบูรณ์ ดุงงันจะแยกตัวออกจากร่างกายอย่างถาวร [2] [8] ทว่าในช่วงเวลาแรกของการเสียชีวิต ดุงงันจะตกอยู่ในสภาวะสับสน ตกใจ และมีความทรงจำผูกพันกับกายเนื้อ หากช่องทวารบนใบหน้า (ตา จมูก ปาก) ยังคงเปิดกว้างอยู่ ดุงงันอาจวนเวียนพยายามกลับเข้าสู่ร่างที่กำลังเน่าเปื่อย หรือร้ายแรงยิ่งกว่านั้น ช่องทวารเปิดเหล่านี้จะกลายเป็น "ประตูเชื้อเชิญ" ให้ภูตผีปีศาจกินซากศพ เช่น **บัลบัล (Balbal)**, **อัสวัง (Asuang)**, และ **มาฮิกาวอน (Mahikawon)** ฉวยโอกาสแทรกซึมเข้าสิงสู่ร่าง และเปลี่ยนสรีระของผู้ตายให้กลายเป็นอสุรกาย [2] [6] [12]

### 3. กาลัก (Kalag): วิญญาณอมตะ แก่นแท้แห่งบุคคล และการเปลี่ยนผ่านสู่ผีบรรพชน

ตรงข้ามกับความแปรปรวนและเปราะบางของดุงงัน **กาลัก (Kalag)** คือวิญญาณแก่นแท้ ตัวตนสูงสุด และความเป็นอมตะของมนุษย์ [2] [4] คำว่า *Kalag* ในภาษาตระกูลวิซายาส์มีความหมายครอบคลุมทั้งคำว่า "วิญญาณ" (Soul/Spirit) และยังมีความหมายเชื่อมโยงกับคำว่า "ความสว่างไสว" หรือ "สิ่งที่มองไม่เห็นด้วยตาเนื้อ" [2] [6] ในภาษาทากาล็อก คำว่า *Kaluluwa* มีรากศัพท์มาจากคำว่า *duwa* ซึ่งแปลว่า "สอง" อันสะท้อนถึงโครงสร้างวิญญาณคู่อย่างชัดเจน [2]

กาลักเป็นองค์ประกอบที่ไม่แตกสลาย ไม่เสื่อมสลาย และไม่ตายไปพร้อมกับร่างกายเนื้อหนัง [2] [4] เมื่อบุคคลเสียชีวิต กาลักจะถอนตัวออกจากสรีระเพื่อเตรียมตัวออกเดินทางไกลสู่ดินแดนแห่งความตาย ทว่ากาลักมิได้กลายสภาพเป็นวิญญาณบรรพชนที่ทรงอำนาจโดยอัตโนมัติ [2] [4] กระบวนการที่กาลักจะสามารถเปลี่ยนผ่านสภาวะไปสู่การเป็น **อานิโต (Anito)** ในภาษาทากาล็อก หรือ **อูมาลากัด (Umalagad)** ในภาษาวิซายาส์ จำเป็นต้องพึ่งพา "การประกอบพิธีกรรมศพที่สมบูรณ์และถูกต้องตามแบบแผนประเพณี" (*Ritual Efficacy*) จากญาติมิตรและทายาทที่ยังมีชีวิตอยู่ [4] [16]

ฟรานซิสโก โกลิน (*Francisco Colin*) ในบันทึกประวัติศาสตร์ *Labor Evangelica* (ค.ศ. 1663) ได้บันทึกไว้อย่างชัดเจนว่า ชาวฟิลิปปินส์เคารพบูชาดวงวิญญาณของบรรพบุรุษที่ล่วงลับในฐานะคนกลางที่เชื่อมต่อระหว่างมนุษย์กับพระผู้เป็นเจ้าสูงสุด (*Bathala / Captan*) [16]:

> "Among their gods they reckoned their ancestors, whom they called anitos... they believed that when they died, they went to another world, where they were received by their ancestors and lived in honor according to how they had lived in this world." [16]

คำว่า **อูมาลากัด (Umalagad)** มีรากศัพท์มาจากคำว่า *alagad* ซึ่งแปลว่า "การรับใช้" หรือ "ผู้พิทักษ์" [4] [16] เมื่อกาลักของดาตูเดินทางถึงดินแดนสุลัดและได้รับการเปลี่ยนผ่านสู่อูมาลากัดแล้ว ดวงวิญญาณนั้นจะมีสถานะเป็น "เทพบรรพชนผู้อารักษ์วงศ์ตระกูล" คอยปกป้องคุ้มครองลูกหลาน ดลบันดาลความอุดมสมบูรณ์แก่ผลผลิตทางการเกษตร นำทางเรือในการเดินเรือค้าขาย และให้พลังอำนาจแก่ผู้นำดาตูรุ่นต่อไป [4] [16]

อย่างไรก็ตาม หากกาลักไม่สามารถเดินทางสู่สุลัดได้เนื่องจากขาดเครื่องอุทิศ หรือสรีระถูกรบกวนโดยวิญญาณชั่วร้าย กาลักจะกลายสภาพเป็น **กาลัก-กาลัก (Calag-calag)** หรือวิญญาณเร่ร่อนที่โกรธเกรี้ยว หิวกระหาย และนำพาโรคร้ายหรือภัยพิบัติมาสู่ชุมชน [2] [6] การรักษาความปลอดภัยและความสงบสุขของกาลักในระหว่างการเดินทาง จึงเป็นภารกิจระดับสูงสุดของสังคมชนชั้นนำ [4] [6]

### 4. พลวัตแห่งความตายและการคลายพันธะ (The Dissolution of the Bond)

ช่วงเวลาที่บุคคลกำลังสิ้นลมหายใจ ถือเป็น "วิกฤตการณ์ทางภววิทยา" (*Ontological Crisis*) ที่สร้างความปั่นป่วนและตึงเครียดสูงสุดให้แก่โครงสร้างทางจิตวิญญาณ [13] [2] ความตายคือกระบวนการ **"คลายพันธะทางกายภาพและจิตวิญญาณ" (The Dissolution of the Somatic-Spiritual Bond)** ระหว่าง ดุงงัน, กาลัก, และ สรีระเนื้อหนัง [2] [6]

ในสภาวะปกติขณะมีชีวิต ดุงงันและกาลักจะทำงานประสานกันอย่างแนบแน่นภายในกายเนื้อ โดยมีช่องทวารสัมผัสทั้งห้า (ตา, หู, จมูก, ปาก, ผิวสัมผัส) ทำหน้าที่เป็นช่องทางการแลกเปลี่ยนพลังงานระหว่างตัวตนภายในกับโลกภายนอก [6] [8] แต่เมื่อชีพจรหยุดเต้น ความสมดุลนี้จะพังทลายลงทันที:
1. **การแตกกระจายของพลังชีวิต:** ดุงงันเริ่มสูญเสียจุดเกาะเกี่ยวในสรีระ เกิดภาวะปั่นป่วนและพยายามหาทางระบายออกจากร่างผ่านช่องเปิดธรรมชาติ [2] [8]
2. **การเปิดอ้าของช่องทวาร (The Aperture Crisis):** กล้ามเนื้อใบหน้าและขากรรไกรของผู้ตายจะคลายตัวลงตามธรรมชาติ ทำให้เปลือกตาเปิดค้าง ช่องจมูกอ้ากว้าง และริมฝีปากเผยอออก ในมโนทัศน์วิญญาณนิยม ช่องทวารที่เปิดค้างนี้คือ "ความเปราะบางสูงสุด" (*Maximum Vulnerability*) เพราะมันทำให้ขอบเขตระหว่าง "โลกภายในของร่าง" กับ "มลทินภายนอก" ถูกทำลายลง [6] [12]
3. **การตกค้างของพลังงานความทรงจำ:** กาลักยังคงลอยตัวอยู่ใกล้ร่างศพเพื่อเฝ้ามองว่า ร่างกายของตนจะได้รับการปฏิบัติอย่างสมเกียรติหรือไม่ หากร่างศพถูกปล่อยปละละเลย กาลักจะเกิดความคับแค้นใจและปฏิเสธที่จะเดินทางสู่สุลัด [4] [6]

วิกฤตการณ์ของการคลายพันธะนี้เรียกร้องให้ต้องมีการแทรกแซงด้วยปฏิบัติการทางพิธีกรรมอย่างทันท่วงที ชุมชนโบราณจะต้องลงมือจัดการกับช่องทวารบนใบหน้าเป็นลำดับแรกสุด ก่อนที่กระบวนการเน่าเปื่อยตามธรรมชาติจะลุกลาม [4] [6]

### 5. แผ่นทองคำปิดทวารในฐานะ "กลไกตรึงและคุ้มครองดวงวิญญาณ" (Apotropaic Soul-Pinning Technology)

การนำแผ่นทองคำมาตัดขึ้นรูปและจัดวางปิดทับดวงตา สันจมูก และริมฝีปากของผู้ตาย จึงทำหน้าที่เป็น **"กลไกตรึงและคุ้มครองดวงวิญญาณ" (Apotropaic Soul-Pinning and Shielding Technology)** ที่ตอบสนองต่อมโนทัศน์วิญญาณสองขั้วอย่างสมบูรณ์แบบ [3] [6] [15]

#### ประการที่ 1: การตรึงพลังดุงงันและสกัดกั้นการรุกราน (Pinning the Dungan and Sealing the Void)
สำหรับดุงงัน แผ่นทองคำทำหน้าที่เป็น "สลักอภิปรัชญา" (*Metaphysical Pin*) น้ำหนักและพลังแห่งความบริสุทธิ์ของทองคำ 22 กะรัตระดับกินูกูลัน จะทำหน้าที่กดทับและปิดผนึกช่องทวารสรีระ ทำให้พลังงานดุงงันที่ตกค้างสงบลงและสลายตัวไปอย่างสงบภายในสรีระ โดยไม่หลุดลอยออกไปสร้างความปั่นป่วนแก่คนเป็น [2] [6] ขณะเดียวกัน แผ่นทองคำที่ปิดสนิทแนบเนื้อยังทำหน้าที่เป็น "ปราการป้องกัน" (*Impermeable Barrier*) สกัดกั้นมิให้วิญญาณชั่วร้าย (Yawa) หรือปีศาจกินซากศพแทรกซึมผ่านช่องตา จมูก หรือปาก เข้าไปแย่งชิงหรือครอบงำร่าง [6] [12]

#### ประการที่ 2: การคุ้มครองและเป็นตราประทับเกียรติยศแก่กาลัก (Shielding and Somatic Seal for the Kalag)
สำหรับกาลัก แผ่นทองคำทำหน้าที่เป็น "เกราะพิทักษ์ในการเดินทาง" (*Protective Escort*) แสงสว่างสีทองอร่ามที่เปล่งประกายอย่างไม่เสื่อมสลาย จะทำหน้าที่ขับไล่ความมืดมิดในห้วงเหวแห่งความตาย นำทางกาลักให้มองเห็นทิศทางที่ถูกต้องในการมุ่งหน้าสู่สุลัด [3] [6] ยิ่งไปกว่านั้น แผ่นทองคำดุนลายนูนจุดไข่ปลาและสลักลายดวงตา ยังทำหน้าที่เป็น **"ตราประทับเกียรติยศทางสรีระ" (Somatic Seal of Nobility)** เมื่อกาลักเดินทางไปถึงประตูดินแดนบรรพบุรุษ แผ่นทองคำและเครื่องยศทองคำจะเป็นหลักฐานประจักษ์ชัดที่แสดงต่อปวงผีบรรพชนว่า ผู้ตายคือชนชั้นนำดาตูผู้มีเกียรติภูมิสูงส่ง สมควรได้รับการต้อนรับเข้าสู่ภพภูมิสวรรค์ซาอัดอย่างสมศักดิ์ศรี [2] [4] [6]

แผ่นทองคำปิดทวารศพจึงมิได้เป็นเพียงของประดับตกแต่งศพทางกายภาพ หากแต่เป็น "สะพานเชื่อมทางอภิปรัชญา" ที่ประสานสรีระที่กำลังสลายตัว พลังชีวิตดุงงันที่ต้องถูกตรึงให้สงบ และวิญญาณอมตะกาลักที่ต้องได้รับการส่งผ่านสู่การเป็นผีบรรพชน เข้าไว้ด้วยกันเป็นเอกภาพอันศักดิ์สิทธิ์และสมบูรณ์แบบ

## 8.3 คติการคุ้มครองและปิดกั้นทวารเปิดของสรีระ (Orifice Protection Beliefs): สรีรวิทยาแห่งความเปราะบาง ภัยคุกคามจากภูตผี และเกราะพิทักษ์ทองคำ

### 1. บทนำและกรอบทฤษฎี: สรีรวิทยาแห่งความเปราะบางและทฤษฎีขอบเขตแห่งมลทิน (Purity and Danger)

ในการวิเคราะห์มานุษยวิทยาสัญลักษณ์ ร่างกายของมนุษย์มิได้เป็นเพียงโครงสร้างทางชีววิทยาที่แยกขาดจากโลกภายนอก หากแต่ทำหน้าที่เป็น **"จุลจักรวาลจำลองของสังคมและระเบียบจักรวาล" (Body as a Microcosm of Social and Cosmic Order)** [17] [2] แมรี ดักลาส (*Mary Douglas*) นักมานุษยวิทยาเชิงโครงสร้าง ได้เสนอทฤษฎีคลาสสิกในผลงาน *Purity and Danger: An Analysis of Concepts of Pollution and Taboo* (1966) ว่า ขอบเขตของร่างกายมนุษย์ (*Bodily Boundaries*) เป็นพื้นที่ที่มีความอ่อนไหวและตึงเครียดเชิงสัญลักษณ์สูงสุด โดยเฉพาะอย่างยิ่ง **"ช่องทวารเปิดของสรีระ" (Bodily Orifices)** เช่น ดวงตา รูจมูก และช่องปาก [17]

ดักลาสชี้ให้เห็นว่า ช่องทวารเปิดคือจุดที่ "ภายใน" กับ "ภายนอก" บรรจบกัน เป็นรอยต่อที่สสาร วัตถุ และพลังงาน สามารถไหลผ่านเข้า-ออกจากร่างกายได้ [17] ในสภาวะปกติขณะที่มนุษย์ยังมีชีวิต สติสัมปชัญญะและกลไกทางสรีรวิทยาจะทำหน้าที่ควบคุมการเปิด-ปิดของช่องทวารเหล่านี้ แต่เมื่อบุคคลเสียชีวิตลง สภาพการควบคุมทางกายภาพจะพังทลายลงในทันที [17] [2] ขอบเขตที่เคยชัดเจนระหว่างตัวตนกับสิ่งแวดล้อมกลายเป็นสภาพคลุมเครือ ร่างกายที่ไร้ชีวิตจึงตกอยู่ในสภาวะ **"มลทินสูงสุด" (Absolute Pollution / Danger)** เพราะช่องทวารที่เปิดอ้าค้างอยู่นั้นได้แปรสภาพเป็นช่องว่างเปราะบางที่เชื้อเชิญอันตรายจากทั้งสองทิศทาง:
1. การรั่วไหลออกของพลังงานและของเหลวจากภายใน ซึ่งนำมาซึ่งกลิ่นสลายตัวและความตาย
2. การแทรกซึมรุกรานเข้ามาของอำนาจชั่วร้ายและสิ่งอัปมงคลจากภายนอก [17] [2] [3]

ในโลกทัศน์วิญญาณนิยมของหมู่เกาะฟิลิปปินส์ยุคก่อนอาณานิคม สรีรวิทยาแห่งความเปราะบางของช่องทวารได้รับการตระหนักรู้อย่างลึกซึ้ง [2] [4] การเปิดอ้าค้างอยู่ของดวงตา ช่องจมูก และริมฝีปากของผู้ตาย มิได้เป็นเพียงปัญหาเชิงทัศนียภาพ แต่เป็นวิกฤตการณ์ทางจิตวิญญาณที่คุกคามทั้งตัวตนของผู้ล่วงลับและชุมชนคนเป็นที่อยู่เบื้องหลัง [4] [15] คติการคุ้มครองและปิดกั้นทวารสรีระ (**Apotropaic Orifice Sealing Beliefs**) จึงถือกำเนิดขึ้นในฐานะระบบภูมิปัญญาทางพิธีกรรมที่ถูกคิดค้นขึ้นมาเพื่อกอบกู้ระเบียบและสถาปนาเกราะพิทักษ์เหนือกาลเวลา [3] [15]

### 2. ภัยคุกคามจากภูตผีปีศาจกินซากศพในคติชนวิทยาฟิลิปปินส์ (Asuang, Balbal, Mahikawon, Yawa)

ในบรรดาปีศาจเหล่านี้ **บัลบัล (Balbal)** ถือเป็นภัยคุกคามที่น่าสะพรึงกลัวที่สุดในบริบทของพิธีศพ บัลบัลมีประสาทสัมผัสในการดมกลิ่นเน่าเปื่อยของซากสรีระที่เฉียบคมอย่างยิ่ง มันสามารถได้กลิ่นการสลายตัวของเนื้อเยื่อจากระยะทางไกลหลายกิโลเมตร [4] [18] เมื่อได้กลิ่น บัลบัลจะบินมาเกาะบนขื่อหลังคาของเรือนจัดงานศพ และหย่อนลิ้นที่มีขนาดยาว เรียว และแหลมคม สอดผ่านร่องกระดานหรือร่องฟากไม้ไผ่ลงมายังร่างผู้ตาย เพื่อควักกินอวัยวะภายใน โดยเฉพาะหัวใจและตับไต จากนั้นมันจะใช้เวทมนตร์เสกท่อนกล้วยให้มีรูปร่างเหมือนศพวางไว้แทนที่ เพื่อหลอกลวงญาติมิตร [4] [18]

การที่บัลบัลใช้ "กลิ่น" เป็นเครื่องมือนำทางในการค้นหาศพ ทำให้ช่องจมูกและช่องปากของผู้ตายกลายเป็นจุดยุทธศาสตร์ที่อันตรายที่สุด หากปล่อยให้กลิ่นสารคัดหลั่งและก๊าซจากการสลายตัวเล็ดลอดออกจากช่องทวาร ย่อมเป็นการดึงดูดบัลบัลและอัสวังให้มุ่งหน้ามายังชุมชน [2] [4]

นอกจากนี้ **มาฮิกาวอน (Mahikawon)** ยังเป็นวิญญาณร้ายที่คอยจ้องมองดวงตาของผู้ตาย หากดวงตาของผู้ตายเปิดค้างอยู่ มาฮิกาวอนจะสบสายตาและใช้พลังสะกดขโมยดวงตาและดึงดูดวิญญาณดุงงันให้ออกจากร่างไปสู่ความมืดมิด [4] [18] ความเชื่อเหล่านี้มิใช่เพียงนิทานปรัมปราที่เล่าขานเพื่อความบันเทิง หากแต่เป็น "ความเป็นจริงทางภววิทยา" (*Ontological Reality*) ที่กำหนดพฤติกรรมและการปฏิบัติการทางพิธีกรรมของสังคมโบราณอย่างจริงจังที่สุด [2] [4]

### 3. กายวิภาคและการปิดผนึกทวารเปิด 3 จุดหลักบนใบหน้า (ตา จมูก ปาก)

เพื่อตอบโต้ต่อภัยคุกคามจากอมนุษย์และแก้ไขวิกฤตการณ์แห่งความเปราะบางของร่างกาย ช่างทองโบราณ Panday Ginto ร่วมกับนักบวชหญิงบาบายลัน จึงได้ออกแบบชุดแผ่นทองคำปิดทวารศพที่สอดรับกับกายวิภาคศาสตร์ของใบหน้ามนุษย์ (*Craniofacial Anatomy*) อย่างแม่นยำ โดยมุ่งเน้นการปิดกั้นทวารเปิด 3 จุดหลัก [3] [15]:

#### 1. ทวารดวงตา (Ocular Apertures / Mata): การปิดกั้นสายตาจากโลกียะ
ดวงตาเป็นทวารแห่งการรับรู้และการมองเห็น ในสรีรวิทยาความตาย ลูกตาจะยุบตัวลงและเปลือกตาจะเปิดเผยอออก แผ่นปิดตาโอตอน (OT-MD-39) ซึ่งมีความยาว 13.3 เซนติเมตร ถูกออกแบบเป็นแผ่นทองคำรูปใบไม้ 2 แฉกที่เชื่อมต่อกันด้วยแถบพาดสันดั้งจมูก [15] [11] การวางแผ่นทองคำนี้พาดทับเบ้าตาทั้งสองข้างและเย็บยึดด้วยรูเจาะปลายแหลม ทำหน้าที่สำคัญ 2 ประการ:
- **ในเชิงกายภาพ:** ปิดผนึกเบ้าตามิให้มองเห็นสภาพการยุบตัวของลูกตา และปกป้องเนื้อเยื่อดวงตาจากการแทะเล็มของแมลง
- **ในเชิงอภิปรัชญา:** "ปิดกั้นสายตาของผู้ตายจากโลกียะ" สกัดมิให้ผู้ตายมองเห็นความโศกเศร้าของญาติมิตรจนเกิดความอาลัยอาวรณ์ และป้องกันมิให้ภูตมาฮิกาวอนสบสายตาเข้ามาขโมยดวงวิญญาณ [4] [15] ลวดลายดุนนูนจุดไข่ปลาและรอยสลักรูปดวงตาบนแผ่นทองคำทำหน้าที่เป็น "ดวงตาจำลองนิรันดร์" (*Surrogate Eternal Eyes*) ที่ช่วยให้วิญญาณมองเห็นเฉพาะแสงสว่างในภพภูมิบรรพบุรุษเท่านั้น [3] [15]

#### 2. ทวารช่องจมูก (Nasal Apertures / Ilong): การสกัดกั้นลมหายใจและกลิ่นสลายตัว
จมูกคือทวารเปิดของทางเดินหายใจและเป็นต้นกำเนิดของกลิ่น แผ่นปิดจมูกโอตอน (OT-MF-40) มีความยาว 16.3 เซนติเมตร กว้าง 5.5 เซนติเมตร ตัดเป็นแถบขวางรูปสามเหลี่ยมหรือสี่เหลี่ยมคางหมูที่มีปีกแผ่กว้างคลุมลงมาถึงร่องแก้ม [15] [11] การจัดวางแผ่นปิดจมูกจะพาดทับกระดูกดั้งจมูกและครอบปิดรูจมูกทั้งสองข้างอย่างมิดชิด แผ่นทองคำที่มีความอ่อนตัวจะถูกกดดัดให้แนบสนิทไปตามความโค้งของปีกจมูก ทำหน้าที่เป็น "ฝาผนึกสุญญากาศเชิงพิธีกรรม" สกัดกั้นมิให้กลิ่นการเน่าเปื่อยเล็ดลอดออกไปในอากาศ ซึ่งเป็นการตัดช่องทางการดมกลิ่นของปีศาจบารบัลและอัสวังอย่างสิ้นเชิง [2] [15]

#### 3. ทวารช่องปาก (Oral Aperture / Baba): การปิดกั้นวจี การสกัดการแทรกซึม และค่าเบิกทาง
ช่องปากเป็นช่องเปิดทางสรีระที่มีขนาดใหญ่ที่สุดบนใบหน้า และมีความสำคัญเชิงหน้าที่สูงสุดในกระบวนการเปลี่ยนผ่าน [3] [4] ในสุสานปลาซาอินเดเปนเดนเซีย เมืองเซบู มีการค้นพบแผ่นปิดปากรูปวงรีรีมน (*Oval Mouth Plate*) วางพาดทับริมฝีปากที่ขบสนิท [19] การปิดช่องปากทำหน้าที่สำคัญ 3 ระดับ:
- ป้องกันมิให้ลิ้นของปีศาจบัลบัลสอดแทรกเข้ามาสู่อวัยวะภายใน
- ปิดกั้นวจีและเสียงของผู้ตาย เพื่อยุติพันธะการสื่อสารกับคนเป็นในโลกปัจจุบัน
- ทำหน้าที่ควบคู่กับ **"ประเพณีการบรรจุทองคำไว้ในช่องปาก"** ซึ่งเป็นธรรมเนียมที่แพร่หลายอย่างยิ่งในหมู่เกาะฟิลิปปินส์ [4] [18]

บาทหลวงเปโดร ชิริโน ได้บันทึกถึงธรรมเนียมการใส่ทองในปากศพไว้อย่างเจาะจงว่า [18]:

> "they put gold in the mouth of the deceased, that he might have something wherewith to pay his passage in the other world." [18]

การใส่เหรียญทองคำขนาดเล็ก (*Piloncito*) เศษทองคำก้อน หรือการประกบแผ่นทองคำไว้ใต้ริมฝีปาก เป็นการจัดเตรียม "เสบียงเดินทาง" (*Baon*) ให้แก่ดวงวิญญาณ เพื่อใช้เป็นค่าธรรมเนียมในการชำระแก่คนพายเรือข้ามฟากแห่งความตายในการข้ามผ่านแม่น้ำใหญ่สู่ดินแดนสุลัด [4] [18]

### 4. การผสานเทคโนโลยีเคมีพฤกษศาสตร์พื้นเมือง: การอุดชโลมทวารด้วยน้ำยางพลู (Buyo Sap)

ข้อค้นพบที่ลึกซึ้งและสะท้อนความก้าวหน้าทางวิทยาการของสังคมฟิลิปปินส์โบราณ คือการที่ประเพณีแผ่นทองคำปิดทวารมิได้ทำงานอย่างโดดเดี่ยวตามลำพัง หากแต่ถูกผสานเข้ากับ **"เทคโนโลยีเคมีพฤกษศาสตร์พื้นเมืองเพื่อการถนอมสรีระ" (Indigenous Botanical Embalming Technology)** [4] [18]

วิลเลียม เฮนรี สก็อตต์ ได้ระบุข้อเท็จจริงสำคัญจากการประมวลบันทึกชาติพันธุ์วรรณนาของบาทหลวงสเปนรุ่นแรกว่า ก่อนที่จะมีการจัดวางแผ่นทองคำลงบนใบหน้า ร่างของผู้ตายจะได้รับการปฏิบัติการทางเคมีพฤกษศาสตร์อย่างประณีต [4]:

> "All datus or prominent persons wanted to be buried in a traditional longon... the corpse was embalmed with buyo sap, camphor, and aromatic resins, and all bodily orifices were stopped with this mixture." [4]

คำว่า **บูโย (Buyo)** ในภาษาพื้นเมืองวิซายาส์หมายถึง **ใบพลู (Betel Leaf: *Piper betle*)** ซึ่งชาวฟิลิปปินส์ใช้เคี้ยวร่วมกับหมาก (*Areca catechu*) และปูนขาว [4] ในทางเภสัชวิทยาและชีวเคมี น้ำยางและน้ำมันหอมระเหยที่สกัดจากใบพลูมีสารประกอบฟีนอล (*Phenolic Compounds*) เช่นชาวิเบตอล (*Chavibetol*) และยูจีนอล (*Eugenol*) ในความเข้มข้นสูง สารเหล่านี้มีคุณสมบัติอันทรงพลังในการ **ยับยั้งการเจริญเติบโตของแบคทีเรียและเชื้อรา (Antimicrobial and Antifungal Activity)** ตลอดจนทำหน้าที่เป็นสารต้านอนุมูลอิสระที่ชะลอการย่อยสลายของโปรตีนและไขมันในเนื้อเยื่อได้อย่างมีประสิทธิภาพ [4] [6]

ผู้ประกอบพิธีจะนำน้ำยางพลูเข้มข้น ผสมเข้ากับการบูรธรรมชาติ (*Camphor*) ยางชันไม้หอม (*Aromatic Resin / Salong*) และผงขี้เถ้า มาทำการชโลมทั่วร่างศพ และทำการ **"อุดยัดลงในช่องทวารเปิดทั้งหมดของร่างกาย" (Stopping of all orifices)** ทั้งช่องหู รูจมูก ช่องปาก ตลอดจนทวารหนัก [4] [6] การอุดน้ำยางพลูทำให้เกิดผลลัพธ์ทางเคมี 2 ประการ:
1. ดับกลิ่นและยับยั้งการเจริญเติบโตของจุลินทรีย์ที่ทำให้เกิดการเน่าเปื่อยภายในช่องทวาร
2. สร้างชั้นรองรับที่มีความหนาแน่นและมีกลิ่นหอมสมุนไพร เพื่อทำหน้าที่เป็นฐานรองรับแผ่นทองคำปิดทวาร [4] [6]

เมื่อนำแผ่นทองคำบริสุทธิ์มาวางทับลงบนช่องทวารที่ได้รับการอุดด้วยน้ำยางพลูและชันไม้ ความเหนียวของยางไม้ธรรมชาติจะทำหน้าที่เป็น "กาวประสานทางชีวภาพ" (*Biological Sealant*) ช่วยยึดเกาะแผ่นทองคำบางให้แนบสนิทติดแน่นกับผิวหนังรอบเบ้าตาและปีกจมูก การผสานระหว่าง **"เคมีพฤกษศาสตร์อินทรีย์ของน้ำยางพลู"** กับ **"โลหวิทยาอนินทรีย์ของทองคำบริสุทธิ์"** จึงกลายเป็นระบบเทคโนโลยีการถนอมสรีระแบบมัมมี่ (*Embalming / Mummification Matrix*) ที่สมบูรณ์แบบที่สุดของภูมิภาคเขตร้อนชื้น [4] [18] [6]

### 5. กลไกอภิปรัชญาของแผ่นทองคำในฐานะ "เกราะพิทักษ์สะท้อนรังสีศักดิ์สิทธิ์" (Apotropaic Solar Shield)

ในมิติสูงสุดของเทววิทยาพื้นเมือง แผ่นทองคำปิดทวารบนใบหน้าผู้ตายทำหน้าที่เป็น **"เกราะพิทักษ์สะท้อนรังสีศักดิ์สิทธิ์" (The Apotropaic Solar Shield)** ที่มีอำนาจคุ้มครองทางจิตวิญญาณเหนือกาลเวลา [3] [15]

คำว่า *Apotropaic* ในทางมานุษยวิทยาศาสนา หมายถึง วัตถุ เครื่องราง หรือสัญลักษณ์ที่มีพลังอำนาจในการขับไล่ ปกป้อง หรือสะท้อนพลังงานด้านลบ ปีศาจ และสิ่งชั่วร้ายมิให้เข้าใกล้ [17] [3] ทองคำครอบครองสถานะเป็นวัตถุอะโพโทรพาอิกชั้นสูงสุดด้วยเหตุผลทางอภิปรัชญา 3 ประการ [2] [3] [15]:

1. **การสะท้อนพลังงานสุริยะและไฟศักดิ์สิทธิ์ (Solar Radiance and Holy Fire):** ในจักรวาลวิทยาของสังคมชายฝั่งทะเลฟิลิปปินส์ ดวงอาทิตย์คือแหล่งกำเนิดของแสงสว่าง ชีวิต และพลังบวก ทองคำซึ่งมีสีเหลืองอร่ามและสะท้อนแสงแวววาว ถูกเชื่อว่าเป็น "ชิ้นส่วนของแสงอาทิตย์ที่ตกผลึกเป็นของแข็งในผืนพิภพ" [3] ปีศาจกินซากศพ เช่น บัลบัลและอัสวัง เป็นสัตว์ร้ายแห่งความมืดมิดที่เกลียดกลัวแสงสว่างอย่างรุนแรง เมื่อพวกมันเข้าใกล้ร่างศพและเผชิญหน้ากับแสงสะท้อนของแผ่นทองคำปิดตาและปิดจมูก แผ่นทองคำจะทำหน้าที่เสมือนกระจกเงาสุริยะที่ส่องสะท้อนความสว่างจ้าเข้าตาของพวกมัน ทำให้พวกมันเกิดความหวาดกลัวและต้องล่าถอยกลับคืนสู่ป่าลึก [2] [3]
2. **ความบริสุทธิ์สมบูรณ์ไร้มลทิน (Absolute Incorruptibility):** ในโลกทัศน์วิญญาณนิยม มลทินและความตายมีความสัมพันธ์กับ "การเน่าเปื่อย" (*Rot and Decay*) สิ่งมีชีวิตทั้งปวงล้วนมีวันเน่าเปื่อยผุพัง แต่ทองคำ 22 กะรัตระดับกินูกูลัน (*Guinogulan*) ไม่เคยเน่าเปื่อย ไม่ดำคล้ำ และไม่ผุกร่อน ความไม่เน่าเปื่อยนี้คือ "อำนาจศักดิ์สิทธิ์" (*Sacred Immunity*) ที่สยบความตาย การปิดกั้นทวารด้วยทองคำจึงเป็นการนำเอาสสารที่มีอำนาจเหนือความตายมาครอบทับสรีระ เพื่อตัดขาดร่างกายมิให้ตกเป็นเหยื่อของความเน่าเปื่อยทางจิตวิญญาณ [3] [15]
3. **ตราประทับแห่งความเป็นอมตะ (Somatic Seal of Eternity):** แผ่นทองคำปิดทวารมิได้ปกป้องเฉพาะร่างศพในโลกปัจจุบัน แต่เป็นเครื่องหมายระบุอัตลักษณ์ที่ติดตัววิญญาณไปชั่วนิรันดร์ เมื่อดวงวิญญาณกาลักเดินทางข้ามห้วงน้ำสู่สุลัด แผ่นทองคำที่ประทับอยู่บนใบหน้าจะเป็นหลักฐานที่พิสูจน์ว่า ผู้ตายได้รับการชำระล้างมลทิน ได้รับการคุ้มครองด้วยเกราะสุริยะ และมีสถานะเป็นชนชั้นนำผู้มีเกียรติภูมิที่คู่ควรแก่การสถิตอยู่ในดินแดนแห่งความสุขอันเป็นนิรันดร์ [2] [4] [18]

คติการคุ้มครองและปิดกั้นทวารเปิดของสรีระด้วยแผ่นทองคำ จึงมิใช่ความเชื่องมงายไร้เหตุผล หากแต่เป็นระบบจักรวาลวิทยาเชิงสัญลักษณ์และเทคโนโลยีทางวัฒนธรรมที่มีความสอดคล้อง กลมกลืน และทรงพลังอย่างยิ่งในการจัดการกับความกลัวต่อความตายและความไม่แน่นอนแห่งชีวิตของมนุษย์ในอดีตกาล

## 8.4 ประเพณีพิธีศพของชนชั้นนำ (Datu Mortuary Rites): พิธีไว้ทุกข์ลาราโอ (Larao), การเฉลิมฉลองเกียรติยศ และบทบาทของบาบายลัน (Babaylan)

### 1. บทนำและกรอบมานุษยวิทยาการเมือง: พิธีศพชนชั้นนำในฐานะเวทีแห่งการสถาปนาอำนาจ

ในมานุษยวิทยาการเมืองโบราณคดี ความตายของผู้นำสูงสุดในสังคมระดับหัวหน้าเผ่า (*Chiefdom Societies*) เช่น **ดาตู (Datu)** ของหมู่เกาะฟิลิปปินส์ยุคก่อนอาณานิคม มิได้เป็นเพียงความสูญเสียส่วนบุคคลของครอบครัวเดี่ยว หากแต่เป็น **"วิกฤตการณ์ทางการเมืองและจักรวาลวิทยาของชุมชน" (Cosmological and Political Crisis)** [13] [2] การสิ้นชีพของดาตูผู้กุมอำนาจทางทหาร การค้าทางทะเล และเครือข่ายความสัมพันธ์อุปถัมภ์ ย่อมทำให้โครงสร้างอำนาจเกิดสุญญากาศชั่วคราว เสี่ยงต่อการปะทุของสงครามแย่งชิงบัลลังก์ หรือการแยกตัวของชุมชนบริวาร [2] [4]

ด้วยเหตุนี้ ประเพณีพิธีศพของชนชั้นนำ (*Elite Mortuary Complex*) จึงได้รับการออกแบบให้เป็น "เวทีเชิงสถาบัน" (*Institutional Arena*) ที่มีขนาดใหญ่โต สลับซับซ้อน และเต็มไปด้วยสัญลักษณ์อันศักดิ์สิทธิ์ [2] [15] พิธีศพมิได้ทำหน้าที่เพียงการนำร่างผู้ตายไปฝังใต้ผืนพิภพเท่านั้น หากแต่เป็นกลไกสำคัญที่สุดในการ:
1. ประกาศและตอกย้ำเกียรติภูมิ วีรกรรม และสายตระกูลอันสูงส่งของผู้ตาย
2. จัดการความขัดแย้งและสร้างเอกภาพภายในชุมชนผ่านข้อห้ามทางสังคมอันศักดิ์สิทธิ์
3. ส่งผ่านความชอบธรรมในการปกครอง (*Legitimacy*) จากดาตูผู้ล่วงลับไปสู่ทายาทผู้สืบทอดอำนาจคนใหม่ต่อหน้าปวงชนและผีบรรพชน [2] [4] [15]

วิลเลียม เฮนรี สก็อตต์ (*William Henry Scott*) ได้ชี้ให้เห็นว่า สังคมวิซายาส์และทากาล็อกในศตวรรษที่ 16 ให้ความสำคัญสูงสุดแก่งานศพของดาตู โดยร่างของผู้ตายจะได้รับการประดับประดาด้วยสิ่งมีค่าที่สุดของสังคม ทั้งผ้าทอชั้นเลิศ อาวุธประจำกาย เครื่องถ้วยชามจีน และโดยเฉพาะอย่างยิ่ง **ชุดเครื่องทองคำพิธีศพ** [4] การที่ใบหน้าของดาตูถูกปิดทับด้วยแผ่นทองคำปิดตา ปิดจมูก ปิดปาก และมงกุฎไทอาเด็มทองคำ เป็นภาพตัวแทนอันทรงพลังที่สะท้อนถึงการรวมศูนย์ของอำนาจทางการเมือง ความมั่งคั่งทางเศรษฐกิจ และความศักดิ์สิทธิ์ทางศาสนาเข้าไว้ในสรีระของผู้ตายอย่างสมบูรณ์แบบ [15] [3]

```

### 2. พิธีไว้ทุกข์ศักดิ์สิทธิ์ลาราโอ (The Sacred Larao Mourning Taboo): กฎเหล็กแห่งความเงียบสงบ

เมื่อดาตูผู้ยิ่งใหญ่ถึงแก่มรณกรรม พิธีกรรมแรกสุดที่มีผลบังคับใช้ต่อประชากรทั้งชุมชนคือ **พิธีไว้ทุกข์ศักดิ์สิทธิ์ลาราโอ (The Sacred Larao Mourning Rite)** [4] [20] บันทึกประวัติศาสตร์ของชาวสเปนยุคแรก ทั้งฟรานซิสโก โกลิน (*Francisco Colin*), มิเกล เด โลอาร์กา (*Miguel de Loarca*), และเปโดร ชิริโน (*Pedro Chirino*) ได้บันทึกถึงความเข้มงวดและกฎเหล็กของพิธีลาราโอไว้อย่างละเอียดและตรงกัน [4] [20] [7]

ทันทีที่ดาตูสิ้นลม ผู้นำชุมชนและเครือญาติจะทำการปักหลักไม้หรือแขวนกิ่งไม้ศักดิ์สิทธิ์ไว้ตามแนวลำน้ำ ทางเข้าหมู่บ้าน และหน้าเรือนงานศพ เพื่อเป็นสัญญาณเตือนภัยแก่ผู้สัญจรไปมาว่า ชุมชนได้เข้าสู่เขตหวงห้ามแห่งพิธีลาราโอแล้ว [4] [20] ในระหว่างช่วงเวลาการไว้ทุกข์ลาราโอ ประชากรทุกคนต้องปฏิบัติตามข้อห้ามทางสังคมอย่างเคร่งครัดสูงสุด [4] [20]:

บทลงโทษสำหรับผู้ที่ละเมิดข้อห้ามลาราโอถือว่ารุนแรงอย่างยิ่งยวด มิเกล เด โลอาร์กา ได้บันทึกไว้ว่า ผู้ใดก็ตามที่ส่งเสียงดัง นำเรือพายผ่านหน้าบ้าน หรือพกพาหอกปลายแหลมชี้ขึ้น จะถูกจับกุมตัวทันที และต้องถูกลงโทษด้วย **การปรับเป็นทองคำจำนวนมหาศาล** หากผู้กระทำความผิดเป็นคนยากจนหรือไม่มีทองคำมาชำระค่าปรับ บุคคลผู้นั้นพร้อมด้วยบุตรภรรยาจะต้องถูกริบตัวตกเป็น **ทาส (Alipin)** ของตระกูลดาตูผู้ตายไปตลอดชีวิต [4] [7]

ในเชิงมานุษยวิทยาสัญลักษณ์ เจตนารมณ์ของพิธีลาราโอมิใช่เพียงการใช้อำนาจเผด็จการของชนชั้นนำ หากแต่มีรากฐานมาจากจักรวาลวิทยาเรื่องวิญญาณ [2] [4] ในช่วงที่ดุงงันกำลังแยกตัวออกจากร่างและกาลักกำลังเตรียมตัวออกเดินทาง สภาวะทางจิตวิญญาณตกอยู่ในความเปราะบางอย่างยิ่ง เสียงรบกวน ความวุ่นวาย หรือความก้าวร้าวของอาวุธ อาจทำให้ดวงวิญญาณเกิดความสับสน หวาดกลัว หรือกลายสภาพเป็นวิญญาณเร่ร่อนที่ดุร้าย [2] [8] ความเงียบสงบที่ครอบคลุมทั่วทั้งอาณาเขตจึงทำหน้าที่เป็น "เบ้าหลอมแห่งความสงบศักดิ์สิทธิ์" (*Acoustic Sanctuary*) ที่ช่วยประคับประคองให้ดวงวิญญาณของดาตูสามารถรวบรวมพลังในการก้าวข้ามสู่ปรโลกได้อย่างราบรื่น [4] [20]

### 3. พิธีกรรมเฉลิมฉลองเกียรติยศและการเลี้ยงฉลองมรณกรรม (Pangasi, Bas-i, and Mortuary Feasting)

เคียงคู่ไปกับความเงียบสงบของพิธีลาราโอ ในพื้นที่ภายในเรือนจัดงานศพของดาตู กลับเต็มไปด้วยกิจกรรมทางพิธีกรรมที่มีชีวิตชีวาและสะท้อนความมั่งคั่งอย่างมหาศาล นั่นคือ **"การเลี้ยงฉลองมรณกรรมและการดื่มสุราเฉลิมฉลองเกียรติยศ" (Mortuary Feasting and Ritual Drinking)** [4] [15]

ในวัฒนธรรมวิซายาส์โบราณ เครื่องดื่มศักดิ์สิทธิ์ที่ขาดไม่ได้ในงานศพชนชั้นนำคือ สุราหมักพื้นเมือง 2 ชนิดหลัก ได้แก่ **พังกาซี (Pangasi)** ซึ่งเป็นสุราหมักจากข้าวเหนียวในไหดินเผา และ **บาส-อิ (Bas-i)** ซึ่งเป็นสุราหมักจากน้ำอ้อยผสมเปลือกไม้สมุนไพร [4] [15] การดื่มพังกาซีมีแบบแผนพิธีกรรมเฉพาะ โดยสุราจะถูกหมักไว้ใน **ไหเคลือบดินเผาขนาดใหญ่จากจีน (Martaban / Dragon Jars)** ผู้ร่วมพิธีจะนั่งล้อมรอบไหและใช้หลอดดูดที่ทำจากไม้ไผ่ลำเล็ก (*Reed / Bamboo Straws*) เสียบผ่านปากไหดูดน้ำสุราขึ้นมาดื่มร่วมกัน [4] [12]

การดื่มสุราพังกาซีในงานศพมีมิติทางหน้าที่ 3 ประการ:
1. **การเซ่นสรวงปวงผีบรรพชน (Libation to the Ancestors):** หยดสุราหยดแรกจะถูกรินลงสู่พื้นดินเพื่อถวายแด่ดวงวิญญาณของบรรพบุรุษอานิโต และเพื่อเป็นเครื่องดื่มบำรุงพลังให้แก่ดวงวิญญาณของผู้ตายในการเดินทาง [4] [15]
2. **การผูกมัดพันธมิตรทางการเมือง (Alliance Consolidation):** การดื่มสุราร่วมไหเดียวกันระหว่างทายาทของดาตูกับผู้นำชุมชนพันธมิตรที่เดินทางมาจากต่างเมือง เป็นการต่อสัญญาความภักดีและยืนยันการเป็นพันธมิตรทางการทหารและการค้าทางทะเลอย่างเป็นรูปธรรม [2] [4]
3. **การขับลำนำมหากาพย์วีรบุรุษ (Kandu Chanting):** ภายใต้ฤทธิ์ของสุราพังกาซี นักขับลำนำอาวุโสจะเริ่มต้นขับร้องบทกวีมหากาพย์โบราณที่เรียกว่า **คันดู (Kandu)** [4] [15] บทเพลงคันดูจะพรรณนาถึงชีวประวัติอันรุ่งโรจน์ของดาตูผู้ล่วงลับ นับตั้งแต่สายตระกูลอันสืบย้อนไปถึงเทพเจ้า การทำสงครามทางเรือ (*Mangayaw*) ชัยชนะเหนือศัตรู จำนวนทาสและเครื่องทองคำที่ครอบครอง ตลอดจนความโอบอ้อมอารีในการดูแลไพร่พล การขับลำนำนี้กินเวลาตลอดทั้งคืนติดต่อกันหลายวัน ทำหน้าที่เปลี่ยนชีวประวัติของมนุษย์คนหนึ่งให้กลายเป็น "ตำนานศักดิ์สิทธิ์" (*Mythologization*) ที่จารึกอยู่ในความทรงจำร่วมของสังคม [4] [15]

นอกจากสุราแล้ว ตระกูลของดาตูจะต้องทำการฆ่าปศุสัตว์จำนวนมหาศาล ทั้งหมู วัว ควาย และสัตว์ปีก เพื่อนำเนื้อมาปรุงเป็นอาหารเลี้ยงดูผู้มาร่วมงานทุกคนอย่างไม่อั้น [4] [15] ปรากฏการณ์นี้สอดคล้องกับแนวคิดเรื่อง **"การแจกจ่ายโภคทรัพย์เพื่อเกียรติยศ" (Potlatch / Competitive Feasting)** ในทางมานุษยวิทยา ยิ่งตระกูลของผู้ตายสามารถเลี้ยงดูแขกเหรื่อได้ยาวนานและสิ้นเปลืองเนื้อสัตว์และสุรามากเท่าใด เกียรติภูมิของดาตูผู้ล่วงลับและอำนาจบารมีของทายาทผู้จัดงานก็จะยิ่งทวีความสูงส่งขึ้นในสายตาของสังคมมากเท่านั้น [13] [4]

### 4. บทบาทของนักบวชหญิง/คนทรงบาบายลัน (Babaylan / Katalonan)

ในโครงสร้างพิธีกรรมศพของฟิลิปปินส์โบราณ ผู้ที่มีบทบาทเป็นผู้นำทางจิตวิญญาณสูงสุดในการควบคุมและดำเนินพิธีกรรม มิใช่ผู้นำทางการเมืองชาย หากแต่เป็น **นักบวชหญิงหรือคนทรง (Female Shaman / Priestess)** ซึ่งในภาษาวิซายาส์เรียกว่า **บาบายลัน (Babaylan)** และในภาษาทากาล็อกเรียกว่า **กาตาโลนัน (Katalonan)** [4] [15] [21]

บาทหลวงฟรานซิสโก อิกนาซิโอ อัลซินา (*Francisco Ignacio Alcina*) ในงานเขียนชิ้นประณีต *Historia de las islas e indios de Bisayas* (ค.ศ. 1668) ได้พรรณนาถึงบทบาทของบาบายลันในพิธีศพไว้อย่างมีชีวิตชีวา [4] [21] บาบายลันมักเป็นสตรีสูงวัยที่ได้รับการยอมรับว่ามีความรู้ลึกซึ้งในศาสตร์แห่งสมุนไพร ลำนำศักดิ์สิทธิ์ และเป็นผู้ที่สามารถเข้าสู่ภวังค์ (*Trance State*) เพื่อเดินทางข้ามมิติไปสื่อสารกับปวงผีบรรพชนได้ [4] [21]

ในพิธีศพของดาตู บาบายลันทำหน้าที่เป็น **"ผู้นำทางวิญญาณข้ามภพ" (Psychopomp)** ซึ่งมีภารกิจหลัก 4 ประการ [4] [15] [21]:
1. **การวินิจฉัยสภาวะของดวงวิญญาณ:** บาบายลันจะทำการเข้าทรงเพื่อสอบถามดวงวิญญาณของผู้ตายว่า มีความประสงค์สิ่งใด มีความแค้นเคืองต่อผู้ใด หรือต้องการเครื่องอุทิศสิ่งใดเพิ่มเติม เพื่อให้ทายาทสามารถจัดหามาตอบสนองได้อย่างถูกต้อง [15] [21]
2. **การกำกับดูแลการติดตั้งแผ่นทองคำ:** บาบายลันเป็นผู้ประกอบพิธีในการนำแผ่นทองคำปิดตา ปิดจมูก และปิดปาก มาจัดวางลงบนใบหน้าของผู้ตายอย่างถูกต้องตามทิศทางจักรวาล โดยมีการร่ายมนตร์กำกับเพื่อปลุกเสกให้แผ่นทองคำแปรสภาพเป็นเกราะพิทักษ์ที่สมบูรณ์ [2] [3]
3. **การขับลำนำนำทางวิญญาณ (Soul-guiding Invocations):** ในขณะที่ร่างศพกำลังจะถูกปิดฝาโลง บาบายลันจะขับลำนำด้วยท่วงทำนองโศกเศร้าแต่ทรงพลัง เพื่อบอกเล่าเส้นทางภูมิศาสตร์ของปรโลก เตือนสติดวงวิญญาณให้ระวังปีศาจตามรายทาง และแนะนำให้มุ่งหน้าสู่ภูเขาศักดิ์สิทธิ์หรือแม่น้ำแห่งความตายโดยไม่หันหลังกลับมามองโลกคนเป็น [8] [21]
4. **การรินสุราและสังเวยโลหิต:** บาบายลันจะทำพิธีแทงหมูสังเวย นำโลหิตมาชโลมรอบโลงศพและเครื่องทองคำ เพื่อเป็นการฟอกมลทินและเพิ่มพลังศักดิ์สิทธิ์ให้แก่พื้นที่สุสาน [4] [15]

บทบาทของบาบายลันจึงเป็นตัวแทนของพลังฝ่ายสตรีเพศ (*Feminine Spiritual Authority*) ที่ทำหน้าที่เป็นสะพานเชื่อมระหว่างความตายกับชีวิต ระหว่างความโกลาหลกับระเบียบ และระหว่างโลกมนุษย์กับภพภูมิแห่งบรรพบุรุษ [4] [21]

### 5. การอุทิศสังเวยขั้นสูงสุด: การอุทิศเรือพายและทาสรับใช้ (Slave Sacrifices and Boat Offerings)

มิติที่น่าสะพรึงกลัวและสะท้อนความไม่เท่าเทียมกันทางชนชั้นอย่างรุนแรงที่สุดในพิธีศพของดาตู คือธรรมเนียม **"การอุทิศสังเวยขั้นสูงสุด" (The Ultimate Funerary Sacrifice)** [4] [15] บันทึกของชาวสเปนในศตวรรษที่ 16 ระบุตรงกันว่า เมื่อดาตูผู้ยิ่งใหญ่สิ้นชีพ สังคมมิได้ส่งเพียงเครื่องทองคำและเครื่องเคลือบไปร่วมหลุมศพเท่านั้น แต่ยังมีการส่ง "มนุษย์ที่มีชีวิต" ร่วมเดินทางไปรับใช้ดาตูในปรโลกด้วย [4] [15] [7]

บาทหลวงเปโดร ชิริโน และมิเกล เด โลอาร์กา ได้บันทึกถึงธรรมเนียมการฆ่าทาสเพื่อฝังร่วมกับศพดาตูไว้อย่างน่าสยดสยอง [4] [20] [7]:

> "When a datu died, they buried with him alive or dead, one or more slaves, that they might serve him in the other life... they also placed in the grave a boat with oars, and oarsmen, that he might go rowed to the other world." [20] [7]

ทาสที่ถูกคัดเลือกมาสังเวยมักเป็นทาสเชลยสงครามหรือทาสในเรือนเบี้ย (*Alipin sa gigilid*) ที่มีความซื่อสัตย์ วิธีการสังเวยมีทั้งการแทงด้วยหอกให้ตายแล้วนำร่างไปวางไว้ใต้หรือข้างโลงศพของดาตู หรือในบางกรณีที่มีการบันทึก ทาสจะถูกมัดและฝังทั้งเป็นอยู่ใต้โลงไม้ลองกอน [4] [15]

นอกจากทาสรับใช้แล้ว สิ่งอุทิศสำคัญอีกประการหนึ่งคือ **"การอุทิศเรือพายและฝีพาย" (Boat and Oarsmen Offerings)** [4] [20] ดังที่ปรากฏหลักฐานทางโบราณคดีที่สอดคล้องอย่างสมบูรณ์ในแหล่งโบราณคดีบูตูอันและสุสานริมทะเลสาบ ชนชั้นนำดาตูจะได้รับการฝังร่วมกับโลงไม้รูปเรือ หรือมีการนำเรือพายขนาดจริงมาฝังควบคู่กับหลุมศพ โดยมีทาสฝีพายนั่งประจำตำแหน่ง เพื่อทำหน้าที่พายเรือนำพาดาตูแล่นข้ามห้วงน้ำใหญ่สู่ดินแดนสุลัด [4] [22]

ในเชิงโครงสร้าง ความเชื่อเรื่องการสังเวยทาสและเรือพายตอกย้ำให้เห็นว่า ในจักรวาลวิทยาของสังคมฟิลิปปินส์โบราณ **"สถานภาพทางชนชั้นมิได้สิ้นสุดลงที่ความตาย"** [2] [4] ดาตูยังคงต้องดำรงสถานะเป็นผู้ปกครองที่มีทาสคอยปรนนิบัติพัดวี มีฝีพายคอยขับเคลื่อนเรือ และมีทองคำคอยเป็นโภคทรัพย์ในภพภูมิข้างหน้า การปิดแผ่นทองคำบนใบหน้าของผู้ตายจึงเป็นตราประทับแห่งเกียรติยศที่สอดรับกับชุดการสังเวยอันยิ่งใหญ่นี้อย่างสมบูรณ์

## 8.5 การเดินทางของวิญญาณข้ามห้วงน้ำสู่ดินแดนบรรพบุรุษ: สัญลักษณ์ของเรือและพาหนะข้ามภพ, ค่าธรรมเนียมการข้ามแม่น้ำแห่งความตาย (เหรียญทองหรือทองคำในปากศพ), การรวมตัวกับปวงผีบรรพชน และการสถาปนาเกียรติภูมิถาวร

### 1. สัญลักษณ์ของเรือและพาหนะข้ามภพในวัฒนธรรมออสโตรนีเชียน (The Austronesian Ship-of-the-Dead & Spirit Boats)

ในจักรวาลวิทยาของกลุ่มชนผู้พูดภาษาตระกูลออสโตรนีเชียน (*Austronesian-speaking peoples*) ท้องทะเล เครือข่ายแม่น้ำ และพาหนะทางน้ำมิได้เป็นเพียงโครงสร้างพื้นฐานทางกายภาพเพื่อการยังชีพ การสัญจรทางพาณิชย์ หรือการทำสงครามแย่งชิงทรัพยากรเท่านั้น ทว่าผืนน้ำและเรือกำปั่นยังทำหน้าที่เป็นแกนกลางทางปรัชญาและสัญลักษณ์วิทยาเชิงเปรียบเทียบ (*Metaphorical Core*) ในการอธิบายการกำเนิดของชีวิต โครงสร้างสังคม และการเดินทางของจิตวิญญาณหลังความตายอย่างแยกไม่ออก [23] [24] ความตายในมโนทัศน์ดั้งเดิมมิใช่จุดสิ้นสุดของการดำรงอยู่หรือการสูญสลายของบุคลิกภาพมนุษย์ หากแต่เป็นพิธีกรรมเปลี่ยนผ่านสถานะ (*Rite of Passage*) ซึ่งดวงวิญญาณจะต้องละทิ้งร่างเนื้อในมิติกายภาพเพื่อออกเดินทางไกลข้ามผืนน้ำศักดิ์สิทธิ์อันกว้างใหญ่ไพศาล ย้อนรอยเส้นทางการอพยพดั้งเดิมของบรรพชนกลับคืนสู่ดินแดนต้นกำเนิดแห่งจิตวิญญาณในปรโลก [23] [24] [25]

หลักฐานทางโบราณคดีที่สะท้อนมโนทัศน์เรื่อง **"เรือแห่งความตาย" (Ship-of-the-dead หรือ Death Boat)** ที่เก่าแก่และทรงคุณค่าทางศิลปกรรมและสัญลักษณ์วิทยาที่สุดในภูมิภาคเอเชียตะวันออกเฉียงใต้ คือประติมากรรมบนฝาไหฝังศพมานุงกุล (*Manunggul Jar Lid*) จากถ้ำมานุงกุล ห้องเอ (*Manunggul Cave Chamber A*) แหลมลิปูอัน (*Lipuun Point*) เกาะพาลาวัน ซึ่งกำหนดอายุทางวิทยาศาสตร์ด้วยวิธีคาร์บอน-14 อยู่ในยุคหินใหม่ตอนปลาย (*Late Neolithic*) ราว 890–710 ปีก่อนคริสตศักราช [23] [26] โรเบิร์ต บี. ฟอกซ์ (*Robert B. Fox*) ได้บรรยายถึงสัญลักษณ์วิทยาอันลึกซึ้งของประติมากรรมดินเผานี้ไว้อย่างแจ่มชัดว่า:

> "The jar cover represents souls sailing to the afterworld in a death boat." [23]

ฝาไหถูกรังสรรค์เป็นรูปจำลองของเรือพายโบราณ มีบุคคลสองคนนั่งเรียงกันอยู่ภายในเรือ บุคคลด้านหลังทำหน้าที่ถือพายควบคุมทิศทางการแล่น ส่วนบุคคลด้านหน้านั่งกอดอกแนบอกโดยไขว้แขนทั้งสองข้างเข้าหากัน ใบหน้าแหงนขึ้นสู่เบื้องบนและมีผ้าคาดพยุงขากรรไกรล่างอย่างเคร่งขรึม ซึ่งสะท้อนถึงการจัดวางสรีระของศพมนุษย์ที่เพิ่งเสียชีวิต [23] [26] ศิลปกรรมชั้นครูชิ้นนี้เผยให้เห็นว่า มโนทัศน์เรื่องการที่ดวงวิญญาณของผู้ตายต้องโดยสารเรือข้ามห้วงน้ำมรณะไปสู่ปรโลกนั้น ได้หยั่งรากลึกในระบบความเชื่อของหมู่เกาะฟิลิปปินส์มาอย่างต่อเนื่องยาวนานเกือบสามพันปี ก่อนหน้าการเข้ามาของศาสนาแห่งคัมภีร์และอำนาจอาณานิคมตะวันตก [23] [27]

ความสืบเนื่องทางวัฒนธรรมของสัญลักษณ์เรือข้ามภพนี้ ได้แปรเปลี่ยนรูปแบบทางเทคโนโลยีและบริบทพิธีกรรมไปสู่ประเพณีการสร้างโลงไม้ขุดรูปเรือ (*Boat-coffins*) และโลงท่อนไม้เนื้อแข็ง (*Hollowed-out log coffins* หรือ *Longon*) ซึ่งแพร่หลายอย่างกว้างขวางในยุคกึ่งก่อนประวัติศาสตร์ (*Protohistoric period*, ศตวรรษที่ 10–16) ทั่วภูมิภาควิซายัสและมินดาเนา [28] [29] [30] ดังที่พิพิธภัณฑสถานแห่งชาติฟิลิปปินส์ได้ประมวลไว้ว่า:

> "Interment of the dead in wooden coffins is a tradition shared by Southeast Asian cultures since prehistoric times. In the Philippines, this precolonial burial practice was observed mostly in the archaeological sites of the Central Philippines, dating around the 12th to 15th centuries or the Protohistoric period." [28]

โลงไม้เหล่านี้มักได้รับการคว้านขุดจากไม้ซุงท่อนเดียวอย่างประณีต ฝาโลงมักแกะสลักเป็นทรงจั่วหลังคาบ้านหรือสันกระดูกงูเรือ พร้อมทั้งประดับลวดลายสลักนูนต่ำเป็นรูปสัตว์เลื้อยคลานศักดิ์สิทธิ์ เช่น งู จระเข้ หรือกิ้งก่า (*buaya*) ซึ่งทำหน้าที่เป็นสัตว์ผู้นำทางและพิทักษ์วิญญาณในห้วงบาดาล [28]

ที่แหล่งโบราณคดีบูตูอัน (*Butuan*) โดยเฉพาะบริเวณสุสานแม่น้ำสุอาตัน (*Suatan River*) และมาซาโก (*Masao*) บริบทการฝังศพปฐมภูมิของชนชั้นนำได้รับการบันทึกไว้อย่างชัดเจนว่า มีการนำร่างของผู้วายชนม์บรรจุไว้ในโลงไม้ขุดทรงเรือ ซึ่งฝังขนานไปกับแนวร่องน้ำโบราณ โดยมีชิ้นส่วนแผ่นทองคำปิดทับช่องตาและปากศพ และรายล้อมด้วยเครื่องถ้วยชามเซรามิกนำเข้าจากจีนสมัยราชวงศ์ซ่งและหยวน [29] [31] [22] วิลเลียม เฮนรี สก็อตต์ (*William Henry Scott*) ได้ตั้งข้อสังเกตเชิงชาติพันธุ์ประวัติศาสตร์ว่า โลงไม้ขุด *longon* เหล่านี้เป็นสิทธิพิเศษเฉพาะของชนชั้นนำ โดยระบุว่า:

> "All datus or prominent persons wanted to be buried in a traditional longon, decorated with fanciful carvings often executed by the future occupant himself during his lifetime." [29]

ความปรารถนาอันแรงกล้าของดาตูที่จะได้รับการฝังในโลงเรือที่ตนเองมีส่วนร่วมในการรังสรรค์ สะท้อนถึงการตระเตรียม "พาหนะนำทางวิญญาณ" ที่มีความมั่นคง แข็งแกร่ง และสง่างามสมฐานานุรูป เพื่อรองรับการเดินทางไกลข้ามกระแสน้ำเชี่ยวกรากแห่งความตายสู่ดินแดนบรรพชน [29] [32]

ยิ่งไปกว่านั้น หลักฐานลายลักษณ์อักษรของบาทหลวงเปโดร คีรีโน (*Pedro Chirino*, 1604) ยังได้บันทึกปรากฏการณ์ทางพิธีกรรมที่น่าตื่นตะลึงเกี่ยวกับการฝังเรือจริงร่วมกับศพของผู้นำระดับสูงในชุมชนชายฝั่ง โดยระบุไว้ในบทที่ 33 ว่า:

> "It once happened that they buried with a chief a vessel manned by many rowers, who were to serve him in his voyages in the other world." [33]

การฝังเรือเดินทะเลจริงพร้อมด้วยฝีพายและข้าทาสรับใช้ ไม่เพียงตอกย้ำอำนาจทางการเมืองและศักยภาพในการระดมทรัพยากรของผู้นำในขณะมีชีวิตเท่านั้น แต่ยังสะท้อนความเชื่ออย่างลึกซึ้งว่า ปรโลกมีลักษณะภูมิศาสตร์เป็นผืนน้ำอันกว้างใหญ่ที่จำเป็นต้องอาศัยเรือกำปั่นและกองฝีพายในการเดินทางสัญจรและการครอบครองอธิปไตยเหนือดินแดนหลังความตายเช่นเดียวกับโลกมนุษย์ [32] [33]

### 2. ภูมิศาสตร์ศักดิ์สิทธิ์ของแม่น้ำแห่งความตายและด่านตรวจคนพายเรือ (Sacred Geography of the Underworld River & The Spirit Ferryman)

ในการทำความเข้าใจการเดินทางของดวงวิญญาณอย่างลึกซึ้ง จำเป็นต้องพิจารณาแผนที่ทางจิตวิญญาณ (*Spiritual Topography*) หรือภูมิศาสตร์ศักดิ์สิทธิ์ของโลกหลังความตายตามที่ได้รับการอนุรักษ์ไว้อย่างละเอียดลออในคติชนวิทยาและมุขปาฐะของชนพื้นเมือง โดยเฉพาะการศึกษาชาติพันธุ์วรรณนาอันทรงคุณค่าของ เอฟ. ลันดา โฮกาโน (*F. Landa Jocano*, 1964) ในกลุ่มชาวซูโลด (*Sulod*) ซึ่งเป็นประชากรดั้งเดิมบนเทือกเขาตอนกลางของเกาะปาไนย์ (*Panay Island*) อันเป็นพื้นที่ทางวัฒนธรรมเดียวกับแหล่งขุดพบหน้ากากทองคำโอตอน (*Oton*) [24] [34]

โฮกาโนได้ชี้ให้เห็นว่า ชาวซูโลดมิได้มองความตายว่าเป็นการสิ้นสูญของความรู้สึกนึกคิดหรือตัวตน ดังที่ระบุว่า:

> "To the Sulod, death is not the end of everything. It does not mean the complete destruction of human personality." [24]

เมื่อบุคคลสิ้นลมหายใจ ดวงวิญญาณ (*umalagud*) จะแยกตัวออกจากร่างเนื้อ โดยมีรูปลักษณ์โปร่งแสงคล้ายกลุ่มควัน และเริ่มต้นการจาริกแสวงบุญข้ามดินแดนศักดิ์สิทธิ์ที่เต็มไปด้วยด่านทดสอบอันตรายนานัปการ โดยมีปลายทางอยู่ที่ยอดเขามัดยาอาส (*Mount Madyaas*) ซึ่งเป็นภูเขาสูงตระหง่านศักดิ์สิทธิ์ที่มองลงมายังชุมชนชาวซูโลด [24] [34]

|                                       ↓                                                           |
| 2. แม่น้ำมูรูบูรู (Muruburu River):                                                               |
|    - วิญญาณถอดชุดศพลงอาบน้ำ ล้างกลิ่นอายโลกมนุษย์และกลิ่นคามังยัน                                 |
|    - เผชิญหน้าฝูงผีร้ายมาฮิเคาวอน (Mahikawon) ที่คอยดักกินวิญญาณหากปราศจากเครื่องเซ่นสรวง         |
|                                       ↓                                                           |
| 3. ทะเลสาบลิมออน (Lake Lim-awon):                                                                 |
|    - เวิ้งน้ำลึกไร้ก้นบึ้ง ด่านตรวจคนพายเรือโดยยักษ์บังโล (Banglo)                                |
|    - สอบสวนความดี ความกล้าหาญ ความมั่งคั่ง และการมีเครื่องบรรณาการทองคำ                           |
|                                       ↓                                                           |
| 4. ลำน้ำแห่งสุลัดและซาอัด (Sulad / Saad River):                                                   |
|    - คนพายเรือเฒ่าซิมูรัน (Simuran) และซิกินารูกัน (Siguinarugan) คุมเรือข้ามฟาก                  |
|    - เรียกเก็บค่าธรรมเนียมข้ามฟาก: เหรียญทองคำหรือก้อนทองคำที่บรรจุในช่องปาก (Viaticum / Baon)     |
|                                       ↓                                                           |
| 5. ยอดเขามัดยาอาส (Mount Madyaas):                                                                |
|    - แดนบรมสุขแห่งปวงผีบรรพชนอูมาลากัด (Umalagad) ชุมนุมสังสรรค์ สถาปนาสถานะนิรันดร์             |
+---------------------------------------------------------------------------------------------------+
```

ด่านแรกที่ดวงวิญญาณจะต้องเผชิญหน้า คือการเดินทางไปถึงริมฝั่งแม่น้ำศักดิ์สิทธิ์ที่มีชื่อว่า **มูรูบูรู (Muruburu)** ณ ริมฝั่งแม่น้ำสายนี้ ดวงวิญญาณจะต้องผ่านพิธีชำระล้างมลทินและร่องรอยแห่งความเป็นมนุษย์ โฮกาโนได้บันทึกสาระสำคัญของกระบวนการนี้ไว้อย่างประณีตว่า:

> "In Muruburu the soul divests itself of its funeral attire and takes a bath in order to wash off whatever mountain smell or other traces remain of its mortal existence, such as the odor of the kamangyan (native incense), ginger, and other leaves used during the washing ceremony prior to the dressing of the body in its funeral attire. One reason for burying the dead in extra nice clothing and other items is to prepare the soul properly for its welcome to the region of the dead." [24]

ข้อความข้างต้นเผยให้เห็นมิติทางพิธีกรรมอันลึกซึ้ง กล่าวคือ ร่างกายของผู้ตายได้รับการอาบน้ำชำระล้างด้วยสมุนไพร ขิง และอบควันด้วยยางไม้หอมคามังยัน (*kamangyan*) ก่อนจะแต่งกายด้วยชุดเสื้อผ้าที่ประณีตงดงามที่สุดและประดับด้วยแผ่นทองคำปิดทับทวาร เมื่อดวงวิญญาณเดินทางไปถึงแม่น้ำมูรูบูรู วิญญาณจะถอดชุดศพลงอาบน้ำเพื่อล้างกลิ่นอายของโลกมนุษย์ออกไป แต่เสื้อผ้า เครื่องแต่งกาย และทองคำที่ได้รับการฝังร่วมกับศพจะแปรสภาพกลายเป็น "อาภรณ์ทิพย์" ที่สร้างความพร้อมและเกียรติยศให้แก่วิญญาณในการก้าวเข้าสู่สังคมของปรโลก [24]

อย่างไรก็ดี ริมฝั่งแม่น้ำมูรูบูรูมิใช่สถานที่อันสงบเงียบ หากแต่เป็นที่สิงสถิตของฝูงอมนุษย์และวิญญาณชั่วร้ายที่เรียกว่า **มาฮิเคาวอน (mahikawon)** ดังที่โฮกาโนบันทึกไว้ว่า:

> "Along the bank of this river lives the mahikawon (evil spirits), which eat the new arrival unless properly propitiated by the living prior to the journey to the land of the dead." [24]

หากญาติมิตรของผู้วายชนม์ในโลกคนเป็นมิได้จัดพิธีกรรมเซ่นสรวงสังเวยและจัดเตรียมเครื่องอุทิศที่มีค่าไว้อย่างถูกต้อง ดวงวิญญาณของผู้มาใหม่จะตกเป็นเหยื่อถูกพวกมาฮิเคาวอนรุมกัดกินและทำลายล้างจนไม่อาจเดินทางต่อไปได้ การติดอาวุธทางจิตวิญญาณและการอุทิศสิ่งของมีค่า—โดยเฉพาะโลหะธาตุทองคำอันเป็นสสารบริสุทธิ์ที่มีอำนาจขับไล่ความมืด—จึงเป็นกลไกสำคัญในการคุ้มครองดวงวิญญาณให้รอดพ้นจากภัยคุกคาม ณ ปากทางเข้าสู่ปรโลก [24] [35]

เมื่อผ่านแม่น้ำมูรูบูรูมาได้ ดวงวิญญาณจะต้องมุ่งหน้าต่อไปยัง **ทะเลสาบลิมออน (Lim-awon)** ซึ่งเป็นเวิ้งน้ำลึกอันมืดมิดและไร้ก้นบึ้ง ณ ที่แห่งนี้ มีนายด่านผู้พิทักษ์ร่างยักษ์นามว่า **บังโล (Banglo)** คอยดักซักถามและสอบสวนดวงวิญญาณทุกดวงที่ต้องการข้ามฟาก ยักษ์บังโลจะตรวจสอบว่าบุคคลผู้นั้นมีคุณธรรม ความกล้าหาญ ความซื่อสัตย์ และความมั่งคั่งในการจัดพิธีศพเพียงใด หากดวงวิญญาณมีเครื่องบรรณาการและผ่านการสอบสวน บังโลจึงจะอนุญาตให้ดวงวิญญาณก้าวลงสู่เรือเพื่อข้ามทะเลสาบไปสู่เชิงเขามัดยาอาส [24] [34]

ในมิติเชิงเปรียบเทียบข้ามกลุ่มชาติพันธุ์ในวิซายัส มิเกล เด โลอาร์กา (*Miguel de Loarca*, 1582) ได้บันทึกคติชนของชาวปาไนย์และเซบูร่วมสมัยไว้ว่า ดวงวิญญาณจะต้องเดินทางไปยังดินแดนใต้พิภพที่เรียกว่า **สุลัด (Sulad)** หรือ **ซาอัด (Saad)** ซึ่งมีแม่น้ำสายใหญ่ขวางกั้น โดยมีคนพายเรือเฒ่านามว่า **ซิมูรัน (Simuran)** และ **ซิกินารูกัน (Siguinarugan)** ทำหน้าที่คุมเรือข้ามฟาก [29] [35] คนพายเรือวิญญาณเหล่านี้จะไม่ยอมพายเรือนำพาวิญญาณข้ามแม่น้ำมรณะเป็นอันขาด หากดวงวิญญาณนั้นเดินทางมามือเปล่าโดยปราศจากค่าธรรมเนียมหรือบรรณาการอันคู่ควร ดวงวิญญาณของผู้ยากไร้ที่ไม่มีทรัพย์สมบัติและเครื่องอุทิศจะถูกปฏิเสธและทอดทิ้งให้ระหกระเหินอยู่ริมตลิ่งอันหนาวเหน็บอย่างน่าเวทนา [29] [35]

### 3. ค่าธรรมเนียมการข้ามฟาก: การบรรจุทองคำ/เหรียญทองในช่องปาก (Viaticum, Pabaon, and the Gold in the Mouth)

ความจำเป็นอย่างยิ่งยวดที่ดวงวิญญาณจะต้องมีทรัพย์สินติดตัวเพื่อเป็นค่าผ่านทางและค่าธรรมเนียมในการข้ามห้วงน้ำมรณะ นำไปสู่การปฏิบัติทางพิธีกรรมที่สำคัญที่สุดประการหนึ่งในประวัติศาสตร์โบราณคดีของฟิลิปปินส์ นั่นคือ **ธรรมเนียมการบรรจุทองคำเข้าไปในช่องปากของศพ (Placing Gold in the Mouth of the Deceased)** [29] [33]

หลักฐานทางชาติพันธุ์ประวัติศาสตร์ที่หนักแน่นและตรงไปตรงมาที่สุด ปรากฏในบันทึกของบาทหลวงเปโดร คีรีโน (*Pedro Chirino*, 1604) ซึ่งระบุไว้อย่างชัดเจนว่า:

> "they placed gold in the mouths of the corpses, and laid with them many articles of value; and thus they buried them, under the house, richly adorned, and with the corpse another chest, containing garments." [33]

ข้อความอันทรงคุณค่าของคีรีโนนี้ สอดคล้องอย่างสมบูรณ์แบบกับข้อสังเกตของบาทหลวงฟรานซิสโก โกลิน (*Francisco Colin*, 1663) ที่บันทึกไว้ในเวลาต่อมาว่า ชนพื้นเมืองให้ความสำคัญกับการเตรียม "เสบียงทางแห่งความตาย" เป็นอย่างยิ่ง โดยการใส่แผ่นทองคำ เม็ดทองคำ หรือเหรียญทองเข้าไปไว้ใต้ลิ้นหรือในโพรงปากของผู้ตายโดยตรง [36]

ในภาษาและมโนทัศน์ของชาวพื้นเมืองฟิลิปปินส์ ทองคำและทรัพย์สินที่ใส่ไว้ในปากหรือฝังร่วมกับศพนี้ เรียกว่า **ปาบาโอน (Pabaon)** หรือ **บาโอน (Baon)** ซึ่งมีความหมายตรงตัวว่า "เสบียงหรือสิ่งที่จัดเตรียมไว้สำหรับการเดินทางไกล" สอดคล้องกับแนวคิดทางเทววิทยาและมานุษยวิทยาศาสนาในโลกตะวันตกที่เรียกว่า **เวียติกุม (Viaticum)** ซึ่งหมายถึงสิ่งค้ำจุนจิตวิญญาณในการเดินทางครั้งสุดท้ายจากโลกนี้ไปสู่อีกโลกหนึ่ง [29] [37]

```
+---------------------------------------------------------------------------------------------------+
|               มิติเชิงหน้าที่ 3 ประการของการบรรจุทองคำในช่องปากศพ (Tripartite Function of Mouth Gold) |
+---------------------------------------------------------------------------------------------------+
| 1. มิติเศรษฐกิจจิตวิญญาณ (Socio-Spiritual Economics):                                             |
|    - ค่าจ้างคนพายเรือวิญญาณ (Ferryman's Fare) สู่สุลัด/มัดยาอาส ป้องกันการถูกทอดทิ้งริมฝั่ง        |
|    - สินบนศักดิ์สิทธิ์ (Suhol) แด่ผู้คุมด่านยมโลกและอมนุษย์มาฮิเคาวอน                             |
|                                       ↓                                                           |
| 2. มิติสัญศาสตร์และอำนาจการเจรจา (Agency & Voice Preservation):                                    |
|    - ปากคือทวารแห่งการเปล่งวาจาสิทธิ์ การบริโภค และการบัญชาการของผู้นำ                            |
|    - ทองคำบริสุทธิ์ตรึงพลังอำนาจแห่งการเจรจาต่อรองกับทวยเทพและวิญญาณบรรพชนในปรโลกอย่างทัดเทียม      |
|                                       ↓                                                           |
| 3. มิติกายวิภาคและการถนอมสรีระ (Apotropaic Barrier & Embalming):                                  |
|    - ทำงานร่วมกับน้ำยางพลู (Buyo) ที่ฉีดเข้าทางปากเพื่อชะลอการเน่าเปื่อยภายใน                      |
|    - ปิดกั้นทวารมิให้อสูรปอบกินศพ (Asuang) ลักลอบแทรกซึมเข้ากัดกินเนื้อเยื่อและเครื่องใน           |
+---------------------------------------------------------------------------------------------------+
```

การบรรจุทองคำไว้ในช่องปากมีมิติเชิงหน้าที่และความหมายซ้อนทับกันอย่างลึกซึ้ง 3 ระดับ:

1. **ค่าธรรมเนียมการข้ามฟากและสินบนวิญญาณ (The Ferryman's Fare & Spirit Toll):** ทองคำในช่องปากทำหน้าที่เป็นเงินค่าจ้างโดยตรงแก่คนพายเรือวิญญาณ (เช่น ซิมูรันและซิกินารูกัน หรือยักษ์บังโล) เพื่อให้ยอมรับดวงวิญญาณขึ้นเรือและนำพายข้ามกระแสน้ำเชี่ยวกรากของแม่น้ำแห่งความตาย ในบริบทนี้ ทองคำคือ *suhol* หรือสินบนศักดิ์สิทธิ์ที่ช่วยปลดเปลื้องอุปสรรคขวากหนามระหว่างภพภูมิ [33] [35]
2. **การคงสภาพอำนาจในการเจรจาต่อรอง (Preservation of Voice & Agency):** ปากคือช่องทางของการเปล่งเสียง การบริโภคอาหาร และการใช้อำนาจวาจาสิทธิ์ การใส่ทองคำซึ่งเป็นโลหะธาตุที่ไม่แปรเปลี่ยนสภาพเข้าไปในช่องปาก เป็นการผนึกและส่งผ่าน "พลังอำนาจแห่งการเจรจา" ของผู้วายชนม์ ทำให้ดวงวิญญาณยังคงมีศักดิ์ มีเสียง และมีความสามารถในการเจรจาต่อรองกับเหล่าเทพเจ้าและผู้คุมด่านในปรโลกได้อย่างทัดเทียม [29] [37]
3. **การถนอมสรีระและการขับไล่สิ่งชั่วร้าย (Preservation & Apotropaic Barrier):** นอกเหนือจากมิติเชิงสัญลักษณ์แล้ว ในมิติทางกายภาพ คีรีโนได้บันทึกว่าชนพื้นเมืองใช้น้ำยางจากต้นพลู (*buyo*) ฉีดและชโลมเข้าไปทางช่องปากเพื่อถนอมอวัยวะภายในไม่ให้เน่าเปื่อย ดังที่ระบุว่า:
   > "With the juice of this plant, then, they anointed the dead body, and so injected it through the mouth that it penetrated the whole body." [33]
   การนำแผ่นทองคำปิดทับริมฝีปากภายนอกหรือใส่ทองคำไว้ในโพรงปาก จึงเป็นการปิดผนึกทางเคมีและเวทมนตร์ร่วมกัน เพื่อกักเก็บน้ำยาถนอมศพและป้องกันมิให้อสูรร้ายอย่าง *asuang* หรือ *mahikawon* แทรกซึมเข้าไปกัดกินเนื้อเยื่อจากภายใน [33] [35]

เมื่อเปรียบเทียบในเชิงมานุษยวิทยาข้ามวัฒนธรรม (*Cross-cultural Anthropology*) ธรรมเนียมการใส่ทองคำในปากศพของฟิลิปปินส์โบราณมีความละม้ายคล้ายคลึงอย่างน่าอัศจรรย์กับคติ **โอโบลอสของชารอน (Charon's Obol)** ในอารยธรรมกรีกและโรมันโบราณ ซึ่งญาติจะนำเหรียญบรอนซ์หรือเหรียญเงินใส่ไว้ในปากหรือใต้ลิ้นของศพเพื่อเป็นค่าจ้างแก่ชารอน (*Charon*) คนพายเรือข้ามแม่น้ำสติกซ์ (*River Styx*) และแม่น้ำอาเคอรอน (*Acheron*) สู่ยมโลกแห่งฮาเดส (*Hades*) [23] [37] ในทำนองเดียวกัน ในวัฒนธรรมจีนโบราณตั้งแต่ยุคราชวงศ์ฮั่นเป็นต้นมา มีประเพณีการบรรจุ "หยกในปาก" หรือจั๊กจั่นหยก (*han yu*, 琀玉) และต่อมาได้แปรเปลี่ยนเป็นการใส่เหรียญทองคำหรือเหรียญเงินในราชวงศ์ถังและซ่ง เพื่อเป็นสัญลักษณ์ของการฟื้นคืนชีพและการมีทุนทรัพย์ใช้สอยในโลกวิญญาณ [38]

อย่างไรก็ตาม ความพิเศษเฉพาะตัวของขนบฟิลิปปินส์โบราณ (โดยเฉพาะในวิซายัสและมินดาเนา) คือการผสานระหว่าง "ทองคำก้อน/เหรียญในปาก" เข้ากับ "แผ่นทองคำตีแผ่นบางดุนลายที่ปิดทับริมฝีปากภายนอก" (*Gold Mouthpieces / Labial Covers*) ดังที่พบร่วมกับแผ่นปิดตาในสุสานโอตอนและสุอาตัน ซึ่งแผ่นทองคำปิดปากเหล่านี้มักเจาะรูขนาดเล็กไว้ที่มุมทั้งสองข้างเพื่อร้อยเส้นด้ายผูกรัดเข้ากับกะโหลกศีรษะอย่างถาวร [29] [39] การปิดทับทั้งภายนอกและภายในเช่นนี้ แสดงให้เห็นถึงระบบการคุ้มครองช่องทวารที่สมบูรณ์แบบที่สุด ทั้งในฐานะเครื่องป้องกันภัยและในฐานะเสบียงทางอันเป็นนิรันดร์ [37] [39]

### 4. การรวมตัวกับปวงผีบรรพชน ณ สุลัด และการสถาปนาเกียรติภูมิถาวร (Reunion with the Umalagad Ancestors & Eternal Status Consolidation)

เมื่อดวงวิญญาณสามารถชำระล้างมลทินที่แม่น้ำมูรูบูรู ผ่านการสอบสวนของยักษ์บังโล และจ่ายค่าธรรมเนียมทองคำแก่คนพายเรือข้ามฟากจนสำเร็จ ดวงวิญญาณจะก้าวเข้าสู่ดินแดนแห่งคนตาย—ไม่ว่าจะเป็นยอดเขามัดยาอาสในคติซูโลด หรืออาณาจักรสุลัดและซาอัดในคติวิซายัสทั่วไป [24] [35]

ลักษณะสำคัญยิ่งของปรโลกในจักรวาลวิทยาของชาวฟิลิปปินส์โบราณ คือ **การเป็นกระจกเงาสะท้อนโครงสร้างและลำดับชั้นทางสังคมของโลกคนเป็น (A Mirror of Terrestrial Social Stratification)** ปรโลกมิใช่ดินแดนแห่งความเท่าเทียมหรือการตัดสินชำระบาปบุญตามจริยธรรมแบบสากลจักรวาล หากแต่เป็นดินแดนที่จำลองระบบชนชั้น ฐานานุรูป และเกียรติยศจากโลกมนุษย์ไปดำรงอยู่อย่างต่อเนื่อง [32] [35]

มิเกล เด โลอาร์กา (*Miguel de Loarca*, 1582) ได้บันทึกสัจธรรมอันเฉียบขาดของความเชื่อนี้ไว้อย่างชัดแจ้งว่า:

> "They bury with the dead gold, cloth, and other valuable objects - saying that if they depart rich they will be well received in the other world, but coldly if they go poor." [35]

คำกล่าวของชาวพื้นเมืองที่โลอาร์กาบันทึกไว้ว่า *"หากพวกเขาจากไปอย่างร่ำรวย พวกเขาจะได้รับการต้อนรับเป็นอย่างดีในอีกโลกหนึ่ง แต่หากพวกเขาไปอย่างยากจน พวกเขาจะได้รับการต้อนรับอย่างเย็นชา"* ถือเป็นกุญแจสำคัญที่สุดในการไขปริศนาว่า เหตุใดชนชั้นนำชาวฟิลิปปินส์โบราณจึงต้องฝังทองคำ เครื่องเคลือบ และผ้าผ่อนชั้นเลิศจำนวนมหาศาลร่วมกับศพ [32] [35] ในปรโลก ดวงวิญญาณของดาตูและชนชั้นสูงจำเป็นต้องจัดแสดงความมั่งคั่งและความโอ่อ่าเพื่อสถาปนาสถานะของตนท่ามกลางการชุมนุมของวิญญาณบรรพชน [24]

เอฟ. ลันดา โฮกาโน ได้อธิบายขยายความประเด็นนี้จากคติชนซูโลดไว้อย่างลึกซึ้งยิ่ง โดยชี้ให้เห็นถึงความหวาดกลัวต่อ **"ความอับอายทางสังคมในปรโลก" (Social Embarrassment in the Afterworld)**:

> "Because of these social gatherings in the region of the dead, the soul must be dressed appropriately. Should it be embarrassed because it is not well-dressed, it will usually return and haunt the living for their negligence." [24]

ข้อความนี้อธิบายอย่างหมดจดถึงแรงผลักดันทางจิตวิทยาและสังคมของเครือญาติผู้มีชีวิตอยู่ หากดวงวิญญาณของผู้ตายก้าวเข้าสู่ดินแดนบรรพชนโดยปราศจากเสื้อผ้าที่ดี ปราศจากเครื่องประดับทองคำ และปราศจากแผ่นทองปิดตาและปาก ดวงวิญญาณจะรู้สึกอับอายขายหน้าต่อหน้าวิญญาณบรรพบุรุษตนอื่นๆ ที่มาชุมนุมกัน และความอับอายอันเจ็บปวดนี้จะส่งผลให้ดวงวิญญาณเกิดความโกรธแค้นและหวนกลับมาหลอกหลอน สร้างความเจ็บป่วย ความวิบัติ หรือความตายให้แก่ญาติมิตรที่มีชีวิตอยู่เพื่อเป็นการลงโทษความละเลยและความตระหนี่ถี่เหนียว [24] [34]

ในทางกลับกัน หากพิธีศพได้รับการจัดอย่างยิ่งใหญ่ ร่างกายได้รับการประดับประดาด้วยหน้ากากทองคำอันเปล่งประกาย ช่องทวารได้รับการผนึกด้วยโลหะธาตุอันบริสุทธิ์ และมีเครื่องถ้วยชามเซรามิกจีนบรรจุเสบียงอาหารห้อมล้อม ดวงวิญญาณจะเดินทางไปถึงแดนคนตายอย่างสง่างาม ดุจดังราชาผู้มีชัยชนะ โฮกาโนบันทึกภาพอันน่าเกรงขามของการเคลื่อนกระบวนนี้ไว้ว่า:

> "In going to its former death place the soul rides on top of its coffin. Floating along with it are the souls of the long departed ancestors, who act as courtiers." [24]

ดวงวิญญาณของผู้ตายจะขี่อยู่เหนือโลงศพของตนเอง โดยมีดวงวิญญาณของบรรพชนผู้ล่วงลับไปก่อนหน้านั้นลอยเคียงข้างมาในฐานะข้าราชบริพารและผู้ติดตามเกียรติยศ [24]

เมื่อเข้าสู่สังคมแห่งปรโลกได้อย่างสมศักดิ์ศรี ดวงวิญญาณของผู้วายชนม์จะได้รับการยกระดับและสถาปนาขึ้นสู่สถานะ **อูมาลากัด (Umalagad)** หรือวิญญาณบรรพชนผู้ทรงอำนาจและศักดิ์สิทธิ์ [29] [33] วิญญาณอูมาลากัดเหล่านี้จะกลายเป็นผู้พิทักษ์และให้พรแก่สายตระกูลที่ยังมีชีวิตอยู่ โดยทำหน้าที่อำนวยความอุดมสมบูรณ์แก่เรือกสวนไร่นา ดลบันดาลชัยชนะในการออกศึกสงครามปล้นสะดม (*mangayaw*) และปกป้องคุ้มครองชุมชนให้พ้นจากโรคภัยไข้เจ็บ [32] [33] ทองคำที่ฝังร่วมกับศพจึงมิใช่ทรัพย์สินที่สูญหายไปจากวงจรเศรษฐกิจอย่างแท้จริง หากแต่เป็นการลงทุนทางสังคมและจิตวิญญาณ (*Socio-spiritual Investment*) ที่แปลงสภาพทุนทางวัตถุให้กลายเป็น "ทุนทางสัญลักษณ์ถาวร" (*Permanent Symbolic Capital*) เพื่อผูกมัดอำนาจคุ้มครองของบรรพชนไว้กับวงศ์วานว่านเครืออย่างยั่งยืนสืบไป [32] [37]

### 5. บทสังเคราะห์องค์รวมของบทที่ 8: จักรวาลวิทยาความตาย ทองคำ และมโนทัศน์แห่งชีวิตนิรันดร์ (Grand Synthesis of Chapter 8)

การศึกษาจักรวาลวิทยาความตาย โลกทัศน์วิญญาณนิยม และคติการคุ้มครองช่องทวารในบทที่ 8 นี้ ได้เผยให้เห็นภาพรวมอันทรงพลังของระบบความเชื่อและพิธีกรรมที่ค้ำจุนสังคมฟิลิปปินส์ยุคก่อนอาณานิคม ซึ่งสามารถสังเคราะห์เป็นแกนความคิดหลักได้ 4 มิติที่ร้อยเรียงประสานกันอย่างเป็นเอกภาพ:

```
+---------------------------------------------------------------------------------------------------+
|               สี่เสาหลักแห่งมโนทัศน์แผ่นทองปิดทวารศพ (The Four Pillars of Funerary Gold)           |
+---------------------------------------------------------------------------------------------------+
| 1. มิติกายวิภาคและชีววิทยา (Anatomy & Putrefaction):                                              |
|    - ป้องกันความเสื่อมสลายของเนื้อเยื่อ ชะลอกลิ่นเหม็นเน่า กักเก็บน้ำยางพลู (Buyo)                  |
|    - สกัดกั้นอสูรปอบกินศพ (Asuang/Mahikawon) มิให้ชำแรกผ่านทวารธรรมชาติทั้ง 9                       |
|                                       ↓                                                           |
| 2. มิติอภิปรัชญาและวิญญาณนิยม (Metaphysics & Animism):                                            |
|    - ควบคุมการเดินทางของทวิวิญญาณ (Dungan/Kalag) มิให้พลัดหลงหรือแตกกระจาย                         |
|    - แปลงสภาพดวงวิญญาณคนตายสู่การเป็นผีบรรพชนศักดิ์สิทธิ์ (Umalagad)                               |
|                                       ↓                                                           |
| 3. มิติสัญศาสตร์และโลหวิทยา (Semiotics & Metallurgy):                                             |
|    - ทองคำคือสสารอมตะ ไม่หมอง ไม่ขึ้นสนิม สะท้อนแสงอาทิตย์ เป็นตัวแทนพลังชีวิตนิรันดร์             |
|    - สวมใส่ผิวหนังทองคำอมตะแทนที่เนื้อหนังมรรตัย เพื่อความพร้อมในการเผชิญหน้าปวงเทพ              |
|                                       ↓                                                           |
| 4. มิติเศรษฐกิจการเมืองและชนชั้น (Political Economy & Class Ideology):                             |
|    - ค่าผ่านทางแม่น้ำมรณะ (Viaticum/Pabaon) แก่คนพายเรือวิญญาณ                                     |
|    - ป้องกันความอับอายในปรโลก สถาปนาเกียรติภูมิถาวรของวงศ์ตระกูลดาตูเหนือผืนพิภพและปรโลก          |
+---------------------------------------------------------------------------------------------------+
```

ประการแรก **มิติทางกายวิภาคและชีววิทยาแห่งความตาย (Anatomy & Putrefaction):** ความตายทางชีววิทยานำมาซึ่งความเน่าเปื่อย สลายตัว และกลิ่นเหม็น ซึ่งชาวพื้นเมืองมองว่าเป็นช่องว่างที่อันตรายที่สุด ร่างกายมนุษย์ที่มีช่องเปิดตามธรรมชาติถึง 9 ทวารกลายเป็นจุดเปราะบางอย่างยิ่งยวดที่เปิดโอกาสให้ความเสื่อมสลายทางกายภาพและวิญญาณร้าย (*asuang*, *mahikawon*) แทรกซึมเข้ามาลอบกัดกินหรือทำลายแก่นชีวิต การตอบสนองทางวัฒนธรรมจึงเกิดขึ้นผ่านการใช้น้ำยางพลู (*buyo*) ชโลมและฉีดเข้าไปทางช่องปากเพื่อถนอมเนื้อเยื่อ และการใช้แผ่นทองคำบริสุทธิ์ปิดทับทวารหลัก ได้แก่ ตา จมูก และปาก เพื่อสร้าง "ปราการปิดกั้นทางกายภาพและชีวภาพ" ที่สมบูรณ์ [33] [35]

ประการที่สอง **มิติทางอภิปรัชญาและวิญญาณนิยม (Metaphysics & Animism):** มโนทัศน์เรื่องทวิวิญญาณ (*dungan* และ *kalag/umalagud*) กำหนดให้การตายมิใช่จุดสิ้นสุด แต่เป็นการเดินทางของแก่นแท้แห่งชีวิต การปิดทวารด้วยทองคำมิได้มีเป้าหมายเพียงเพื่อกักเก็บวิญญาณดวงดีไว้ภายในร่าง แต่เพื่อ "ควบคุมการเปลี่ยนผ่าน" มิให้พลังชีวิตรั่วไหลอย่างไร้ทิศทาง และสกัดกั้นมิให้พลังงานด้านลบจากภายนอกเข้าครอบงำร่างก่อนที่กระบวนการเน่าเปื่อยจะสิ้นสุดลง ทองคำทำหน้าที่เป็นสื่อกลางที่ช่วยเปลี่ยนผ่านวิญญาณคนตายจากสภาพที่ไร้เสถียรภาพไปสู่การเป็นวิญญาณบรรพชนผู้ทรงเกียรติ [24] [29]

ประการที่สาม **มิติทางสัญศาสตร์และโลหวิทยา (Semiotics & Metallurgy of Gold):** ทองคำเป็นสสารชนิดเดียวในธรรมชาติที่ไม่ทำปฏิกิริยากับออกซิเจน ไม่เป็นสนิม ไม่ผุกร่อน และคงความเปล่งประกายสีเหลืองอร่ามดุจแสงอาทิตย์ไว้ได้อย่างเป็นนิรันดร์ ในโลกทัศน์ของชาวออสโตรนีเชียน ทองคำจึงเป็นตัวแทนของพลังชีวิตที่ไม่มีวันดับสูญ (*Imperishable Life Force*) การนำแผ่นทองคำมาตีบางและดุนลายเพื่อปิดทับใบหน้าและช่องทวาร คือการสวมใส่ "อัตลักษณ์อมตะ" ให้แก่สรีระที่กำลังเน่าเปื่อย เป็นการแทนที่เนื้อหนังที่แปรสภาพด้วยผิวหนังโลหะธาตุบริสุทธิ์ที่ไม่เสื่อมคลาย เพื่อให้ผู้ตายพร้อมที่จะปรากฏกายต่อหน้าทวยเทพและปวงผีบรรพบุรุษ [37] [39]

ประการที่สี่ **มิติทางเศรษฐกิจการเมืองและสิทธิอำนาจแห่งชนชั้น (Political Economy & Class Ideology):** การเดินทางข้ามแม่น้ำแห่งความตายสู่ดินแดนบรรพบุรุษ (สุลัด, มัดยาอาส) เรียกร้องค่าธรรมเนียมและเสบียงทาง (*pabaon/viaticum*) อย่างหลีกเลี่ยงไม่ได้ สังคมปรโลกเป็นกระจกสะท้อนระเบียบสังคมคนเป็น ผู้ที่จากไปพร้อมทองคำจะได้รับการต้อนรับอย่างอบอุ่นและมีเกียรติยศ ส่วนผู้ที่จากไปอย่างยากจนจะได้รับการต้อนรับอย่างเย็นชาและต้องเผชิญกับความอับอายขายหน้า การฝังทองคำในช่องปากและปิดทับช่องทวารจึงเป็นปฏิบัติการขั้นสูงสุดของชนชั้นนำ (*Datu*) ในการสถาปนาความชอบธรรมข้ามภพภูมิ เพื่อประกันว่าอำนาจบารมี ทรัพย์สมบัติ และสถานะความเป็นผู้นำของตนจะมิได้สูญสลายไปพร้อมกับลมหายใจ แต่จะได้รับการสถาปนาให้เป็นสัจธรรมนิรันดร์ในปรโลก และส่งต่อพรอันศักดิ์สิทธิ์กลับคืนสู่สายตระกูลบนโลกมนุษย์สืบไป [32] [33] [35]

ด้วยเหตุนี้ ปรากฏการณ์แผ่นทองคำปิดศพและหน้ากากทองคำแห่งฟิลิปปินส์ จึงมิใช่เพียงงานหัตถศิลป์หรือเครื่องประดับตกแต่งศพธรรมดา หากแต่เป็นยอดมงกุฎแห่งระบบความเชื่อทางจักรวาลวิทยา สัญลักษณ์วิทยาทางมานุษยวิทยา และสัจธรรมแห่งการแสวงหาความเป็นนิรันดร์ของมนุษยชาติในอุษาคเนย์โบราณ [23] [37]
