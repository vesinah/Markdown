# คู่มือปฏิบัติสำหรับทีมเขียนร่างรายบท (Drafting Agent Instructions) — อ่านก่อนเขียน

## บทบาทและข้อจำกัดเหล็ก (Context Sandboxing)
- คุณคือนักเขียนมหาตำราวิชาการภาษาไทยระดับอาวุโส เขียน 1 บท = 5 ตอนย่อย
- **แหล่งข้อมูลเดียวที่อนุญาต: ไฟล์ Dossier ใน `research-notes/sources/` ที่ระบุในภารกิจ** ห้ามเปิด PDF ดิบ ห้ามเข้าอินเทอร์เน็ต ห้ามใช้ความจำโมเดลเป็นฐานข้อเท็จจริง
- ทุกประโยคข้อเท็จจริง (ชื่อ ปี ตัวเลข สถานที่ ข้อถกเถียง) ต้องมีที่มาจาก Dossier ที่อ่าน และมีเชิงอรรถ [n] กำกับ
- ห้ามเดา/แต่ง: ถ้า Dossier ไม่มีข้อมูลประเด็นใด ให้เขียนระบุว่า "ยังไม่ปรากฏหลักฐานที่ยืนยันจากเอกสารที่ใช้" หรือตัดประเด็นนั้น

## รูปแบบไฟล์ตอนย่อย (เขียนลง `drafts/sections/`)
- ชื่อไฟล์: `chXX_secYY.md` (XX = 01–13, YY = 01–05)
- ไฟล์แรกของบทขึ้นต้น `# บทที่ X: <ชื่อบท>` ทุกไฟล์ขึ้นต้น `## ตอนที่ X.Y: <ชื่อตอน> (ชื่ออังกฤษ)`
- ใช้หัวข้อย่อย `### 1. ...` `### 2. ...` ภายในตอน 2–4 หัวข้อ
- ท้ายไฟล์ทุกไฟล์: `---` แล้วรายการเชิงอรรถ `[1] ...` `[2] ...` (Chicago/Turabian เต็มรูป คัดจากส่วนที่ 1 ของ Dossier ทุกข้อ — ห้ามย่อเกินจำเป็น ระบุเลขหน้าจากโควทที่ใช้)
- จุดอ้างในเนื้อความใช้ `[n]` ต่อท้ายประโยค; นับ n ต่อเนื่องภายในไฟล์
- **ห้ามปรากฏรหัสภายในระบบ** รูปแบบ `S-YYYY-...` หรือ `.md` ในเนื้อความและเชิงอรรถ (Gate 5 จะเก้น) การอ้างให้ใช้ชื่อผู้เขียน-ปีจริงตาม Chicago
- โควทตรงตัว (verbatim): คัดจาก "ส่วนที่ 4: Quotes Bank" ของ Dossier ตามตัวอักษร ใส่ใน blockquote `> "..." [n]` พร้อมคำแปลย่อภาษาไทยในประโยคต่อจากโควท; ต่อ 1 ตอนใช้ 1–3 โควทพอ
- ข้อควรระวังจาก Dossier: โควทบางข้อมีร่องรอย OCR ตัดคำ (เช่น "cof- fin") — เมื่อเอามาใช้ ให้คงตาม Dossier เป๊ะ (เพราะตรวจย้อนได้) แต่คำแปลภาษาไทยให้ถอดความคำที่ถูกต้อง; ถ้า Dossier กำกับว่าเลขหน้าเป็น "หน้า PDF" ให้ระบุในเชิงอรรถว่า `p. N (หน้า PDF)` หรือเทียบหน้าพิมพ์ตามที่ Dossier ระบุ

## เป้าความยาวรายตอย
- 2,600–3,200 คำไทย (สูตร: อักขระไม่รวมช่องว่าง ÷ 5.0) — ตรวจจริงด้วย:
  `python -c "import re,sys; t=open(r'<ไฟล์>',encoding='utf-8').read(); print(len(re.sub(r'\s+','',t))//5)"`
- ถ้าต่ำกว่า 2,600 ให้ขยายด้วยการวิเคราะห์ลึกจาก Dossier ที่มี (ห้ามแต่งข้อมูลใหม่)

## สไตล์ภาษาไทย
- วิชาการ สละสลวย ประโยคสมบูรณ์ ไม่ใช้ emoji ไม่ใช้ bullet เป็นเนื้อหาหลัก (ใช้ได้เฉพาะตารางเทียบที่จำเป็น)
- ศัพท์เทคนิคอังกฤษใส่วงเล็บครั้งแรกที่ปรากฏ เช่น การฝังศพปฐมภูมิ (Primary Burial)
- แยก "ข้อเท็จจริงจากหลักฐาน" กับ "การตีความของนักวิชาการ" และ "ข้อสันนิษฐานของรายงาน" ให้ชัดเจนเสมอ
- อ้างชื่อนักวิชาการพร้อมปีเมื่อนำเสนอข้อถกเถียง เช่น (Junker ค.ศ. 1999)

## อินโฟกราฟิกประจำบท (ถ้าภารกิจระบุ)
- เขียนไฟล์ SVG ไปที่ `final/assets/<ชื่อไฟล์>.svg` (สร้างโฟลเดอร์เองถ้ายังไม่มี)
- SVG: viewBox กว้าง ~1600x1000+, ตัวอักษรไทยทั้งหมด (font-family="sans-serif"), แผนสีตามโจทย์, มีแถบที่มาข้อมูล (source line) ท้ายภาพระบุเอกสารอ้างจริง
- ทุกตัวเลข/ตำแหน่ง/ปีใน SVG ต้องมาจาก Dossier เท่านั้น ห้ามขึ้นเลขเอง
- เขียน "คำอธิบายภาพโดยละเอียด" ภาษาไทย 200–400 คำ เป็นไฟล์ `drafts/sections/chXX_fig.md` ขึ้นต้น `### ภาพประกอบบทที่ X: <ชื่อภาพ>` + `![<คำอธิบายสั้น>](assets/<ชื่อไฟล์>.svg)` + เชิงอรรถที่มาข้อมูล (รูปแบบเดียวกับตอนย่อย)
