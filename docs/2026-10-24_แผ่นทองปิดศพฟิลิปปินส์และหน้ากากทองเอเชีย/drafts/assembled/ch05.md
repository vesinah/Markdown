## 5.1 ประเภทวิทยาของแผ่นทองปิดทวาร (Typology of Orifice Covers): แผ่นปิดตาคู่, แผ่นปิดจมูก, แผ่นปิดปาก, และทองคำใส่ในปาก

### 1. บทนำและกรอบมโนทัศน์: การจำแนกประเภทวิทยาแผ่นทองคำปิดศพในโบราณคดีเอเชียตะวันออกเฉียงใต้

ในบรรดาโบราณวัตถุโลหะมีค่าที่ค้นพบจากหลุมฝังศพยุคก่อนอาณานิคมในภูมิภาคเอเชียตะวันออกเฉียงใต้ภาคพื้นสมุทร แผ่นทองคำปิดทวารบนใบหน้าผู้ตาย (*Mortuary Gold Orifice Covers*) ถือเป็นกลุ่มหลักฐานที่มีเอกลักษณ์เฉพาะตัวและมีความโดดเด่นทางสุนทรียศาสตร์สูงสุดกลุ่มหนึ่ง วัตถุเหล่านี้มิได้เป็นเพียงเครื่องประดับส่วนบุคคลที่สวมใส่ในชีวิตประจำวัน หากแต่เป็นโบราณวัตถุที่ถูกสร้างสรรค์ขึ้นด้วยจุดประสงค์เฉพาะทางพิธีกรรมความตาย (*Mortuary Purpose*) เพื่อใช้ปฏิบัติต่อสรีระของผู้ตายในวาระสุดท้ายแห่งการเปลี่ยนผ่านสู่ปรโลก [1]

การศึกษาวิเคราะห์เชิงประเภทวิทยา (*Typology*) ของแผ่นทองคำปิดศพในหมู่เกาะฟิลิปปินส์จำเป็นต้องเริ่มต้นจากการทำความเข้าใจความหลากหลายของรูปแบบ สัณฐาน ขนาด น้ำหนัก และเทคนิคการผลิต ช่างทองโบราณมิได้ผลิตแผ่นทองคำเหล่านี้ขึ้นอย่างสะเปะสะปะ หากแต่ปฏิบัติตามแบบแผนประเพณีที่มีการถ่ายทอดร่วมกันข้ามชุมชนชายฝั่งทะเลวิสายาส์และมินดาเนา ในสารานุกรมศิลปะของศูนย์วัฒนธรรมแห่งฟิลิปปินส์ (*CCP Encyclopedia of Philippine Art*) โดยปูริสซีมา เบนิเตซ-โจฮันนอต (*Purissima Benitez-Johannot*) ได้กำหนดกรอบการจำแนกแผ่นทองปิดหน้าศพของฟิลิปปินส์โบราณออกเป็น 2 ประเภทหลักอย่างชัดเจน [2]:

```
+---------------------------------------------------------------------------------------------------+
|               การจำแนกประเภทแผ่นทองปิดหน้าศพโบราณในฟิลิปปินส์ (Benitez-Johannot 2020)             |
+---+-----------------------------------------------------------------------------------------------+
| a | หน้ากากทองคำแบบเจาะช่องเปิดทวาร (Gold Masks with eyes, nostrils, and mouth cut out)         |
|   | - เป็นแผ่นทองคำแผ่นเดียวขนาดใหญ่คลุมใบหน้า หรือตัดฉลุช่องตา รูจมูก และปาก                     |
|   | - เปิดเผยให้เห็นช่องทวารทางกายวิภาคเดิมของผู้ตาย                                              |
+---+-----------------------------------------------------------------------------------------------+
| b | แผ่นทองคำปิดผนึกทวารเฉพาะจุด (Gold Sheets to Cover Orifices)                                  |
|   | - ประกอบด้วยชุดแผ่นทองคำบางแยกชิ้นสำหรับปิดทับดวงตา จมูก และปาก โดยเจตนาปิดกั้นช่องเปิด       |
|   | - บางครั้งพบร่วมกับแถบทองคำคาดหน้าผาก (Diadem) หรือเครื่องประดับศีรษะ                         |
+---+-----------------------------------------------------------------------------------------------+
```

ในบริบทของฟิลิปปินส์ หลักฐานทางโบราณคดีส่วนใหญ่ที่ค้นพบ ทั้งจากโอตอน จังหวัดอิโลอิโล, แหล่งแม่น้ำอากูซัน-บูตูอันในมินดาเนา, และแหล่งปลาซา อินเดเปนเดนเซีย ในเมืองเซบู จัดอยู่ในกลุ่มประเภทที่สอง (b) คือ **แผ่นทองคำสำหรับปิดทวารเฉพาะจุด** ซึ่งมุ่งเน้นการปิดกั้นช่องเปิดของประสาทสัมผัสทั้งสามอย่างจงใจ การทำความเข้าใจประเภทวิทยาของชุดแผ่นทองคำปิดทวารจึงต้องแยกพิจารณาสัณฐานวิทยาของชิ้นส่วนแต่ละประเภท ได้แก่ แผ่นปิดตาคู่ แผ่นปิดจมูก แผ่นปิดปาก ตลอดจนธรรมเนียมการใส่ทองคำไว้ภายในช่องปาก [2] [3]

### 2. แผ่นปิดตาคู่ (Ocular Covers / Eye Plaques / Eye Covers): สัณฐาน สัดส่วน และลวดลายฉลุดุนนูน

แผ่นทองคำปิดตาคู่เป็นชิ้นส่วนที่สะดุดตาที่สุดในชุดแผ่นทองปิดทวาร เนื่องจากตำแหน่งการจัดวางพาดทับเบ้าตา (*Orbital Cavities*) ของกะโหลกศีรษะ ซึ่งเป็นศูนย์กลางของการมองเห็นและการสื่อสารของมนุษย์ จากการรวบรวมข้อมูลเชิงปริมาณและสัณฐานวิทยา สามารถจำแนกแผ่นปิดตาออกเป็น 2 สกุลช่างหลัก [2] [4]:

```
+---------------------------------------------------------------------------------------------------+
|               การเปรียบเทียบสัณฐานวิทยาของแผ่นปิดตาคู่ (Ocular Covers Typology)                   |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|   1. แบบฉลุลายและดุนนูนจุดไข่ปลา (Repoussé & Openwork - สกุลช่างโอตอน):                            |
|      +-------------------------------------------------------------------------+                  |
|      |  .-''''-.         .-''''-.                                              |                  |
|      | ( ( * ) )========( ( * ) )   <-- แผ่นปิดตารูปใบไม้/วงรี มีก้านสะพานเชื่อมตรงกลาง       |
|      |  '-....-'         '-....-'   <-- ขอบดุนนูนจุดไข่ปลา (Beaded rim) ฉลุรูตาดำตรงกลาง  |
|      +-------------------------------------------------------------------------+                  |
|      * ขนาด: ยาว 13.3 ซม., กว้าง 2.5 ซม., น้ำหนัก 3.16 กรัม (เลขทะเบียน OT-MD-39)                |
|                                                                                                   |
|   2. แบบแผ่นเรียบขัดเงาแยกชิ้น (Plain Polished Sheets - สกุลช่างบูตูอันและเซบู):                 |
|      +---------------------+   +---------------------+                                            |
|      |     .------------.  |   |  .------------.     |                                            |
|      |    (   ตาซ้าย     ) |   | (    ตาขวา     )    |  <-- แผ่นทองบางรูปวงรีเรียบ ไร้ก้านเชื่อม  |
|      |     '------------'  |   |  '------------'     |  <-- ขอบเรียบกริบ ผิวขัดมันเงาสะท้อนแสง    |
|      +---------------------+   +---------------------+                                            |
|      * ขนาด: ยาว ~5.0–7.5 ซม. ต่อชิ้น, ความหนาบางเฉียบเพียง 0.08–0.15 มม.                        |
+---------------------------------------------------------------------------------------------------+
```

#### 2.1 แผ่นปิดตาแบบฉลุลายและดุนนูน (Repoussé & Openwork)
ตัวแทนที่สมบูรณ์และงดงามที่สุดของกลุ่มนี้คือ แผ่นปิดตาของหน้ากากทองคำโอตอน (*Oton Gold Death Mask*) ซึ่งเก็บรักษาและจัดแสดง ณ พิพิธภัณฑสถานแห่งชาติฟิลิปปินส์ แผ่นปิดตานี้มีหมายเลขทะเบียนวัตถุสถาบันคือ **OT-MD-39** ทำจากทองคำบริสุทธิ์ มีความยาวรวม 13.3 เซนติเมตร ความกว้างสูงสุด 2.5 เซนติเมตร และมีน้ำหนัก 3.16 กรัม [2]

สัณฐานของแผ่นปิดตาโอตอนประกอบด้วยแผ่นทองคำรูปวงรีคล้ายใบไม้สองแผ่นที่เชื่อมต่อกันด้วยแถบสะพานทองคำแคบๆ บริเวณหัวตาเหนือสันจมูก ลวดลายบนแผ่นปิดตาได้รับการรังสรรค์ด้วยเทคนิคการดุนนูนจากด้านหลัง (*Repoussé*) และการตอกลายจากด้านหน้า (*Chasing*) เกิดเป็นลวดลายขอบจุดไข่ปลา (*Beaded Dot Borders*) ที่ล้อมรอบแนวขอบรูปวงรี ที่กึ่งกลางของเบ้าตาทั้งสองข้างได้รับการเจาะฉลุเป็นช่องวงกลมขนาดเล็กเพื่อแทนตำแหน่งของตาดำ (*Pupil Apertures*) รูฉลุนี้สร้างความย้อนแย้งที่น่าพิศวงในเชิงสัญลักษณ์ กล่าวคือ แม้จะเป็นแผ่นปิดตาที่ทำหน้าที่คลุมเบ้าตา แต่ช่างทองกลับเจาะรูตาดำไว้เพื่อให้ "ดวงตาทองคำ" ยังคงสามารถทอดทัศนาสู่โลกวิญญาณได้ [2] [5]

#### 2.2 แผ่นปิดตาแบบเรียบขัดเงา (Plain Beaten Gold Sheets)
ในทางตรงกันข้าม ชุดแผ่นปิดตาที่ค้นพบจากแหล่งบูตูอันในมินดาเนาและปลาซา อินเดเปนเดนเซียในเมืองเซบู มีลักษณะเป็นแผ่นทองคำบางตัดเป็นรูปวงรีหรือรูปหยดน้ำแยกจากกันเป็นสองชิ้นอิสระ ช่างทองมิได้เจาะรูตาดำและมิได้ดุนนูนลวดลายวิจิตร หากแต่เน้นการตีแผ่นทองให้มีความบางสม่ำเสมอในระดับ 0.08 ถึง 0.15 มิลลิเมตร และทำการขัดผิวหน้าให้เรียบเกลี้ยงเป็นมันวาว (*Mirror-like Burnished Surface*) แผ่นปิดตาแบบเรียบทึบ (*Blind Eye Plaques*) นี้ทำหน้าที่ปิดกั้นการมองเห็นทางกายภาพอย่างสมบูรณ์ สะท้อนถึงมโนทัศน์แห่งการปิดฉากผัสสะในโลกทางโลกียะเพื่อเข้าสู่ความสงบนิรันดร์ [3] [6]

### 3. แผ่นปิดจมูก (Nasal Plaque / Nose Cover / Shield): สัณฐานวิทยาทรงสี่เหลี่ยมคางหมูและรูปสามเหลี่ยม

ทวารจมูกเป็นช่องทางเข้าออกของลมหายใจ ซึ่งในโลกทัศน์ของชาวออสโตรนีเชียน ลมหายใจคือสัญลักษณ์ของการมีชีวิต (*Breath of Life*) และเป็นเส้นทางหลักที่วิญญาณอาจหลุดลอยออกจากร่าง แผ่นปิดจมูกทองคำจึงได้รับการออกแบบให้มีสัณฐานเฉพาะทางกายวิภาคที่สอดรับกับความนูนโค้งของสันจมูกและปีกจมูก [1] [7]:

```
+---------------------------------------------------------------------------------------------------+
|               สัณฐานวิทยาและมิติขนาดของแผ่นปิดจมูกทองคำ (Nasal Plaque Morphology)                 |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|             ( ก้านบนแคบ พาดต่อจากหัวตา: กว้าง ~1.5–2.0 ซม. )                                      |
|                               +-------+                                                           |
|                               |       |   <-- ส่วนโคนสันจมูก (Nasal Bridge Root)                   |
|                               |   |   |                                                           |
|                               |   |   |   <-- แนวรอยพับกึ่งกลาง (Median Fold Ridge)               |
|                              /    |    \                                                          |
|                             /     |     \                                                         |
|                            /      |      \  <-- ปีกแผ่กว้างคลุมกระดูกปีกจมูก (Alae of Nose)       |
|                           +---------------+                                                       |
|             ( ฐานล่างกว้าง คลุมรูเปิดจมูก: กว้าง 5.5 ซม. ในกรณีโอตอน )                             |
|                                                                                                   |
|      * ข้อมูลวัตถุโอตอน (OT-MF-40): ความยาวรวม 16.3 ซม., กว้าง 5.5 ซม., น้ำหนัก 3.09 กรัม            |
|      * ความยาว 16.3 ซม. แสดงให้เห็นว่าแผ่นทองมิได้คลุมเพียงจมูก แต่ยื่นยาวลงมาจรดริมฝีปากบน         |
+---------------------------------------------------------------------------------------------------+
```

#### 3.1 ขนาด สัดส่วน และเลขทะเบียนวัตถุโอตอน (OT-MF-40)
แผ่นปิดจมูกของหน้ากากทองคำโอตอนมีหมายเลขทะเบียนสถาบันคือ **OT-MF-40** ทำจากทองคำบริสุทธิ์ มีความยาวถึง 16.3 เซนติเมตร ความกว้างบริเวณฐานล่าง 5.5 เซนติเมตร และมีน้ำหนัก 3.09 กรัม ตัวเลขความยาว 16.3 เซนติเมตรนี้มีความสำคัญอย่างยิ่งในทางกายวิภาคศาสตร์ เนื่องจากความยาวของสันจมูกมนุษย์ทั่วไปจากหว่างคิ้ว (*Glabella*) ถึงปลายจมูก (*Subnasale*) มีความยาวเฉลี่ยเพียงประมาณ 4.5 ถึง 5.5 เซนติเมตรเท่านั้น การที่แผ่นปิดจมูกโอตอนมีความยาวถึง 16.3 เซนติเมตร ชี้ชัดว่าแผ่นทองคำชิ้นนี้มิได้ถูกสร้างขึ้นเพื่อปิดเฉพาะสันจมูกเท่านั้น หากแต่ได้รับการออกแบบให้ทอดตัวยาวตั้งแต่แนวกึ่งกลางหน้าผาก ผ่านหว่างคิ้ว แนบลงมาตามสันจมูก และแผ่กว้างออกเพื่อคลุมทับรูจมูกและริมฝีปากบนลงมาเกือบถึงฟันหน้า [2] [5]

#### 3.2 สัณฐานวิทยาทรงสี่เหลี่ยมคางหมูและการพับสันนูน (Trapezoidal Form & Median Ridge)
แผ่นปิดจมูกส่วนใหญ่มีรูปทรงสี่เหลี่ยมคางหมูเรียวยาว (*Elongated Trapezoid*) หรือทรงสามเหลี่ยมยอดตัด ด้านบนที่แคบจะวางพาดอยู่บริเวณดั้งจมูกระหว่างหัวตาทั้งสองข้าง ขณะที่ด้านล่างจะผายกว้างออกเพื่อรองรับฐานปีกจมูก (*Alar Cartilages*) และรูเปิดจมูก (*Piriform Aperture*) [2]

ในเชิงวิศวกรรมการขึ้นรูปโลหะ แผ่นปิดจมูกมักปรากฏ **รอยพับสันนูนตามแนวยาวกึ่งกลาง (Median Longitudinal Ridge)** ซึ่งเกิดจากการที่ช่างทองใช้เครื่องมือรีดหรือพับแผ่นทองคำให้เกิดเป็นแนวสันสามมิติ รอยพับนี้ทำหน้าที่สองประการพร้อมกัน ประการแรกคือช่วยเพิ่มความแข็งแกร่งเชิงกล (*Mechanical Rigidity*) ไม่ให้แผ่นทองคำที่บางเฉียบงอพับหรือเสียรูปทรงได้ง่าย และประการที่สองคือทำให้แผ่นทองคำสามารถแนบสนิทไปกับสันกระดูกจมูกตามธรรมชาติของใบหน้ามนุษย์ได้อย่างพอดี [2] [8]

### 4. แผ่นปิดปาก (Oral Plaque / Mouth Cover) และทองคำใส่ในปาก (Intra-oral Gold)

ช่องปากเป็นทวารเปิดที่มีขนาดใหญ่ที่สุดบนใบหน้า เป็นทางเข้าของอาหาร เป็นแหล่งกำเนิดของถ้อยคำ วาจา และลมหายใจ ในระบบพิธีศพของฟิลิปปินส์โบราณ การปฏิบัติต่อช่องปากด้วยทองคำปรากฏใน 2 รูปแบบหลักที่มีความสัมพันธ์กันอย่างลึกซึ้ง [2] [9]:

```
+---------------------------------------------------------------------------------------------------+
|               มิติการปฏิบัติต่อช่องปากด้วยทองคำ (Oral Mortuary Practices)                         |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|   1. แผ่นทองคำปิดปากภายนอก (External Oral Plaque / Mouth Cover):                                 |
|      +---------------------------------------------------------+                                  |
|      |        .---------------------------------------.        |                                  |
|      |       (       แถบทองคำโค้งรับริมฝีปากบน-ล่าง     )       |                                  |
|      |        '---------------------------------------'        |                                  |
|      +---------------------------------------------------------+                                  |
|      - สัณฐานเป็นแถบยาวรูปพระจันทร์เสี้ยวหรือวงรีแคบปลายเรียวมน                                     |
|      - วางทาบปิดทับรอยแยกริมฝีปาก (Oral Fissure) โดยตรงเพื่อผนึกคำพูดและช่องเปิด                    |
|                                                                                                   |
|   2. ทองคำใส่ในช่องปาก (Intra-oral Gold / Mouth Deposits):                                       |
|      - การสอดใส่แผ่นทองคำม้วน แผ่นทองคำทรงกลม หรือเม็ดทองคำบริสุทธิ์เข้าไปใต้ลิ้นหรือในกระพุ้งแก้ม   |
|      - ทำหน้าที่เป็น "ค่าผ่านทางข้ามภพ" (Mortuary Viaticum / Charon's Obol Parallel)              |
|      - เชื่อมโยงกับฟันฝังหมุดทองคำ (Bansil / Pusad) ที่ฝังแน่นในเนื้อฟันตั้งแต่เมื่อยังมีชีวิต        |
+---------------------------------------------------------------------------------------------------+
```

#### 4.1 สัณฐานวิทยาของแผ่นปิดปากภายนอก (External Mouth Plaque)
แผ่นปิดปากมักถูกตัดแต่งเป็นแผ่นทองคำรูปแถบยาวขอบขนาน หรือรูปวงรีแคบที่ปลายทั้งสองข้างเรียวมน โค้งรับกับแนวรอยต่อของริมฝีปากบนและล่าง (*Labial Contour*) ความยาวของแผ่นปิดปากมักอยู่ในช่วง 6.0 ถึง 9.5 เซนติเมตร และกว้างประมาณ 1.5 ถึง 3.0 เซนติเมตร ซึ่งเพียงพอที่จะปิดคลุมช่องเปิดของปากได้อย่างมิดชิด [2] [3]

ในแง่ของลวดลาย แผ่นปิดปากอาจมีทั้งแบบเรียบเกลี้ยงขัดเงา เช่นที่พบในแหล่งปลาซา อินเดเปนเดนเซีย เซบู และแบบที่มีการตอกสลักลายเส้นหรือดุนนูนขอบ เช่นในบางตัวอย่างจากคอลเลกชันของธนาคารกลางแห่งฟิลิปปินส์ (*Bangko Sentral ng Pilipinas - BSP*) ซึ่งช่างทองได้ตอกลายเส้นเป็นแนวยาวคล้ายแนวฟันหรือรอยแยกลิปสติก เพื่อสะท้อนภาพจำลองของริมฝีปากในอุดมคติ [8]

#### 4.2 คติการใส่ทองคำไว้ภายในช่องปาก (Intra-oral Gold Deposit)
นอกเหนือจากการวางแผ่นทองคำปิดทับริมฝีปากภายนอกแล้ว ในบันทึกชาติพันธุ์วรรณนาและรายงานการขุดค้นหลุมศพหลายแห่งในมินดาเนาและลูซอน ยังพบหลักฐานการใส่เศษทองคำ เม็ดทองคำ หรือแผ่นทองคำม้วนขนาดเล็กเข้าไปไว้ภายในช่องปากของผู้ตายโดยตรง ดั่งที่วิลเลียม เฮนรี สก็อตต์ (*William Henry Scott*) ได้บันทึกไว้ใน *Barangay* ว่า ในพิธีศพของชนชั้นนำ จะมีการนำทองคำและลูกปัดมีค่าใส่ไว้ในปากของผู้ตายก่อนที่จะปิดโลง [9]

ธรรมเนียมนี้มีความคล้ายคลึงอย่างน่าทึ่งกับคติ "เหรียญปากผี" หรือเงินพลอดปากศพ (*Charon's Obol*) ในวัฒนธรรมกรีก-โรมันโบราณ และประเพณีการอมหยกรูปจักจั่น (*Yuhan*) ในวัฒนธรรมจีนราชวงศ์ฮั่น ซึ่งมีจุดมุ่งหมายเพื่อให้ผู้ตายมีทุนรอนในการเดินทางข้ามแม่น้ำแห่งความตายไปสู่อีกภพภูมิหนึ่ง และเพื่อเป็นหลักประกันว่าผู้ตายจะไม่ตกอยู่ในภาวะอดอยากหิวโหยในโลกหลังความตาย [1] [9]

### 5. องค์ประกอบเสริม: แถบคาดหน้าผาก (Diadem / Headband) และเครื่องประดับประกอบชุด

ในหลุมศพของชนชั้นนำระดับสูงสุด แผ่นปิดทวารทั้งสามมิได้ปรากฏอยู่อย่างโดดเดี่ยว หากแต่มักพบร่วมกับเครื่องประดับทองคำสำหรับศีรษะและร่างกาย ซึ่งรวมกันเป็น **"ชุดเครื่องทองพิธีศพสมบูรณ์" (Complete Mortuary Gold Parure)** [2] [8]:

#### 5.1 แถบทองคำคาดหน้าผาก (Diadem / Frontal Headband)
ในบทความของเบนิเตซ-โจฮันนอต ได้ระบุไว้อย่างชัดเจนว่า แผ่นปิดทวารทองคำในบางครั้งจะพบร่วมกับเครื่องประดับศีรษะ ซึ่งมีลักษณะเป็นแถบทองคำตีบาง (*Diadem / Ornamental Headband*) คาดขวางอยู่เหนือแนวกระดูกหน้าผาก (*Frontal Bone*) แถบทองคำนี้อาจมีความยาวตั้งแต่ 15 ถึง 30 เซนติเมตร มีการเจาะรูขนาดเล็กที่ปลายทั้งสองข้างเพื่อร้อยเชือกหรือเส้นด้ายผูกไว้ด้านหลังศีรษะ ลวดลายบนแถบคาดหน้าผากมักเป็นลายดุนนูนรูปเรขาคณิต ลายฟันปลา หรือลายกากบาท ซึ่งสอดรับกับลวดลายบนแผ่นปิดตาและปิดจมูกอย่างกลมกลืน [2]

การคาดแถบทองคำไว้เหนือหน้าผากของผู้ตายมีความสัมพันธ์เชิงพื้นที่อย่างแนบแน่นกับประเพณีการดัดกะโหลกศีรษะให้ลาดแบน (*Tangad*) เพราะระนาบหน้าผากที่ลาดเอียงไปทางด้านหลังจะกลายเป็นแท่นรองรับแถบทองคำได้อย่างมั่นคง ทำให้ประกายทองคำส่องสว่างเด่นชัดที่สุดเมื่อมองจากด้านหน้า [1] [4]

#### 5.2 ต่างหูทองคำและลูกปัดหินมีค่าร่วมบริบท
หลักฐานที่ยืนยันการประกอบชุดเครื่องประดับร่วมกับแผ่นปิดทวารอย่างเป็นวิทยาศาสตร์ที่สุดชิ้นหนึ่งคือ การค้นพบที่แหล่งปลาซา อินเดเปนเดนเซีย เมืองเซบู ซึ่งรายงานของพิพิธภัณฑสถานแห่งชาติ ค.ศ. 2022 และรายการภาพจัดแสดง ค.ศ. 2023 ระบุตรงกันว่า มีการขุดพบชุดแผ่นทองคำปิดทวารฉบับสมบูรณ์ร่วมกับ **ต่างหูทองคำคู่หนึ่ง (A Pair of Gold Earrings)** วางอยู่ข้างแนวกระดูกขมับทั้งสองข้างของกะโหลกศีรษะ [3] [10]

ต่างหูทองคำที่พบร่วมในหลุมศพมักเป็นต่างหูทรงห่วงผ่าซีก (*Penannular Ring*) หรือต่างหูแบบลูกตุ้มทิ้งดิ่ง (*Dangling Ear Ornaments*) ทำจากทองคำบริสุทธิ์เนื้อหนา ซึ่งสะท้อนให้เห็นว่าผู้ตายได้รับการประดับประดาอย่างเต็มยศ เสมือนหนึ่งกำลังเข้าร่วมงานเลี้ยงพิธีกรรมครั้งยิ่งใหญ่ที่สุดในชีวิต [3] [8]

### 6. หลักฐานเทคโนโลยีช่างทอง ณ บริเวณหลุมฝังศพ: เศษทองคำตัดแต่ง (In Situ Snippings)

ประเด็นสำคัญยิ่งในเชิงโบราณคดีที่เบนิเตซ-โจฮันนอต ได้บันทึกไว้ในสารานุกรมศิลปะฟิลิปปินส์ คือข้อสังเกตเรื่อง **สถานที่และช่วงเวลาของการสร้างแผ่นทองคำปิดทวาร** [2]:

> "They cut and hammered pure gold sheets into shape, in some cases preparing these in situ as snippings were recovered close by. In other instances, they sewed the gold sheets onto a support as evidenced by perforations along the gold sheet borders." [2]
> 
> *คำแปลสรุปความ:* "ช่างตัดและตีแผ่นทองคำบริสุทธิ์เป็นรูปร่าง โดยในบางกรณีมีการเตรียมแผ่นทองเหล่านี้ขึ้น ณ บริเวณสถานที่ฝังศพเอง (*in situ*) ดั่งปรากฏหลักฐานจากการค้นพบเศษทองคำที่ถูกขลิบตัดทิ้งตกอยู่ใกล้เคียง และในกรณีอื่น ๆ ช่างได้เย็บแผ่นทองคำเข้ากับวัสดุรองรับ ดังมีหลักฐานเป็นรูเจาะตามแนวขอบของแผ่นทองคำ" [2]

ข้อความทางวิชาการนี้เปิดเผยข้อเท็จจริงสำคัญ 2 ประการที่เปลี่ยนกระบวนทัศน์ทางโบราณคดี:

1. **การปรับแต่งตามสรีระจริงเฉพาะบุคคล (Customized In Situ Fabrication):** การพบเศษทองคำที่ถูกขลิบตัด (*Snippings*) ตกค้างอยู่ในชั้นดินข้างหลุมศพแสดงให้เห็นว่า แผ่นทองคำปิดทวารมิใช่สินค้าสำเร็จรูปที่ผลิตเป็นอุตสาหกรรมล่วงหน้าในปริมาณมาก หากแต่เป็นงานหัตถการที่ช่างทอง (*Panday Ginto*) อาจนำแผ่นทองคำเปลวดิบมาร่วมในพิธีศพ แล้วทำการวัดสัดส่วนใบหน้า กรีด ตัด และดัดแต่งรูปทรงของแผ่นทองให้เข้ากับมิติสรีระจริงของผู้ตายในขณะนั้น เพื่อให้แผ่นทองสามารถปิดทับเบ้าตา สันจมูก และริมฝีปากได้อย่างแนบสนิทที่สุด [2]
2. **การเย็บตรึงเข้ากับผ้าห่อศพหรือเสื่อ (Sewn Mortuary Shrouds):** การปรากฏรูเจาะขนาดเล็ก (*Perforations*) เรียงรายตามแนวขอบของแผ่นทองคำในบางชิ้นงาน ชี้ชัดว่าแผ่นทองมิได้ถูกวางลอย ๆ บนผิวหนังเสมอไป แต่ในหลายกรณี แผ่นทองคำถูกเย็บติดเข้ากับผ้าห่อศพนำเข้าจากจีน เสื่อสาน หรือหน้ากากผ้าฝ้ายรองรับ ก่อนที่จะนำมาคลุมทับใบหน้าผู้ตาย ซึ่งช่วยป้องกันไม่ให้แผ่นทองคำเลื่อนหลุดจากตำแหน่งเมื่อมีการเคลื่อนย้ายร่างเข้าสู่โลงไม้หรือไหฝังศพ [2] [9]

### 7. สรุปประเภทวิทยาและข้อถกเถียงเชิงหน้าที่ของตอนที่ 5.1

จากการประมวลข้อมูลเชิงประเภทวิทยาในตอนที่ 5.1 สามารถสรุปภาพรวมของแผ่นทองคำปิดทวารในฟิลิปปินส์ได้ว่า ประกอบด้วยโครงสร้างสัณฐาน 3 ส่วนหลักที่ทำหน้าที่ประสานกัน: แผ่นปิดตาคู่ (เพื่อปิดกั้นและแปลงสายตา), แผ่นปิดจมูกยาว (เพื่อผนึกลมหายใจและคลุมแนวดั้งหน้าผากถึงปาก), และแผ่นปิดปาก (เพื่อสะกดถ้อยคำและกักเก็บวิญญาณ) พร้อมด้วยองค์ประกอบเสริมอย่างแถบคาดหน้าผากและต่างหูทองคำ [2] [3]

ความหลากหลายระหว่างแผ่นทองแบบฉลุลายดุนนูนของโอตอน กับแผ่นทองเรียบขัดเงาของบูตูอันและเซบู มิได้เป็นเพียงความแตกต่างของรสนิยมทางสุนทรียศาสตร์ส่วนบุคคล หากแต่สะท้อนถึงสำนักช่างทองท้องถิ่น (*Regional Goldsmithing Traditions*) ที่มีพัฒนาการเฉพาะตัวในแต่ละแอ่งอารยธรรมทางทะเล ข้อมูลประเภทวิทยาเหล่านี้จะเป็นกุญแจสำคัญในการนำไปสู่การวิเคราะห์ใน **ตอนที่ 5.2** ซึ่งจะเจาะลึกมิติทางกายวิภาคศาสตร์ การจัดวางตำแหน่งบนกะโหลกศีรษะจริง ลำดับการซ้อนทับ และทิศทางการหันด้านของแผ่นทองคำอย่างเป็นวิทยาศาสตร์ต่อไป [1] [2] [3]

## 5.2 กายวิภาคศาสตร์การจัดวางบนโครงกระดูก: ตำแหน่งพาดทับเบ้าตา สันจมูก และริมฝีปาก, ลำดับการซ้อนทับ, ทิศทางด้านคว่ำ-หงาย, และร่องรอยการยึดตรึง

### 1. บทนำและกรอบระเบียบวิธี: กายวิภาคศาสตร์เชิงโครงกระดูกในบริบทโบราณคดีหลุมฝังศพ

การศึกษาแผ่นทองคำปิดทวารบนใบหน้าผู้ตายในทางชีวโบราณคดี (*Bioarchaeology*) มิอาจจำกัดอยู่เพียงการพิจารณาวัตถุในฐานะโบราณวัตถุเดี่ยวที่ถูกนำมาจัดแสดงในตู้กระจกพิพิธภัณฑ์ หากแต่จำเป็นต้องศึกษาวัตถุเหล่านี้ในฐานะ "องค์ประกอบร่วมเชิงกายวิภาค" (*Anatomical Correlates*) ที่ถูกจัดวางและทำหน้าที่ร่วมกับโครงกระดูกมนุษย์จริงในบริบทเดิม (*In Situ Context*) ของหลุมฝังศพ [11]

ในระหว่างกระบวนการขุดค้นทางวิทยาศาสตร์ ตำแหน่งการค้นพบแผ่นทองคำบนโครงกระดูกทำหน้าที่เป็นประจักษ์พยานทางกายภาพที่ช่วยให้นักโบราณคดีและนักมานุษยวิทยากายภาพสามารถถอดรหัสกระบวนการปฏิบัติการพิธีศพ (*Mortuary Chaîne Opératoire*) ของชุมชนโบราณได้อย่างแม่นยำ เมื่อเนื้อเยื่ออ่อน กล้ามเนื้อใบหน้า ดวงตา ผิวหนัง และริมฝีปากได้เน่าเปื่อยสลายตัวไปตามกฎแทโฟโนมี แผ่นทองคำซึ่งเป็นโลหะเฉื่อยที่ไม่ทำปฏิกิริยากับกรดและจุลินทรีย์ในดินจะทรุดตัวลงและแนบสนิทไปกับกระดูกกะโหลกศีรษะ (*Cranium*) โดยตรง [11] [12]

การวิเคราะห์ในตอนนี้มุ่งเจาะลึกความสัมพันธ์เชิงพิกัดทางกายวิภาค 4 ประเด็นสำคัญ ได้แก่: (1) ความสัมพันธ์ระหว่างสัณฐานของแผ่นทองคำกับฐานกระดูกใบหน้าแต่ละส่วน (เบ้าตา สันจมูก และขากรรไกร), (2) ลำดับขั้นการซ้อนทับเชิงชั้นหินจุลภาค (*Stratigraphic Micro-layering*) ของแผ่นทองคำแต่ละชิ้น, (3) การกำหนดทิศทางด้านหน้า-ด้านหลัง (คว่ำ-หงาย) ของแผ่นทองคำ, และ (4) กลไกทางกายภาพที่ใช้ในการยึดตรึงแผ่นทองคำให้อยู่กับตำแหน่ง ทั้งการวางแนบโดยอาศัยแรงโน้มถ่วงและการเย็บร้อยผ่านรูเจาะขอบ [12] [13]

### 2. กายวิภาคศาสตร์ของเบ้าตา (Orbital Cavities) และการจัดวางแผ่นปิดตาคู่

เบ้าตาของมนุษย์ประกอบด้วยกระดูกสำคัญหลายชิ้นที่มาประสานกันเป็นโพรงรูปพีระมิด ได้แก่ กระดูกหน้าผาก (*Frontal Bone*), กระดูกโหนกแก้ม (*Zygomatic Bone*), กระดูกขากรรไกรบน (*Maxilla*), และกระดูกสฟีนอยด์ (*Sphenoid Bone*) ขอบกระดูกเบ้าตาบน (*Superior Orbital Margin*) และขอบกระดูกเบ้าตาล่าง (*Inferior Orbital Margin*) ก่อตัวเป็นกรอบกระดูกที่แข็งแกร่งสำหรับปกป้องลูกตา [11]

#### 2.1 มิติสัดส่วนและการพาดทับกระดูกเบ้าตา
จากการศึกษากะโหลกศีรษะโบราณของประชากรฟิลิปปินส์โดยฮิซาชิ ซูซูกิ (*Hisashi Suzuki*) และคณะ พบว่าระยะห่างระหว่างจุดกึ่งกลางเบ้าตาทั้งสองข้าง (*Inter-orbital Distance*) ของชาวฟิลิปปินส์มีค่าเฉลี่ยประมาณ 2.2 ถึง 2.6 เซนติเมตร และความกว้างตามแนวนอนของเบ้าตาแต่ละข้าง (*Orbital Breadth*) อยู่ที่ประมาณ 3.8 ถึง 4.2 เซนติเมตร ทำให้ระยะห่างจากขอบนอกของเบ้าตาซ้ายถึงขอบนอกของเบ้าตาขวามีความยาวรวมประมาณ 9.8 ถึง 11.0 เซนติเมตร [11]

เมื่อนำมิติทางกายวิภาคนี้มาเปรียบเทียบกับขนาดจริงของแผ่นปิดตาโอตอน (เลขทะเบียน **OT-MD-39**) ซึ่งมีความยาวรวมถึง **13.3 เซนติเมตร** จะพบข้อเท็จจริงสำคัญว่า แผ่นปิดตานี้มิได้ถูกสร้างขึ้นมาเพื่อให้พอดีเฉพาะขอบในของโพรงเบ้าตาเท่านั้น แต่ถูกออกแบบให้มีความยาวเผื่อออกไปด้านข้างอย่างจงใจ ปลายแผ่นรูปใบไม้ทั้งสองข้างจึงพาดทับเลยขอบกระดูกเบ้าตาด้านนอก (*Lateral Orbital Margin*) ออกไปวางทาบอยู่บนผิวกระดูกโหนกแก้ม (*Zygomatic Arch*) ทั้งสองข้าง การจัดวางในลักษณะนี้ทำให้แผ่นทองคำทำหน้าที่เป็น "สะพานโลหะ" ที่วางพาดข้ามโพรงลูกตาอย่างมั่นคง และป้องกันไม่ให้แผ่นทองคำยุบตัวจมลงไปในโพรงเบ้าตาเมื่อลูกตาและเนื้อเยื่อประสาทสลายตัวไป [11] [12]

#### 2.2 การค้นพบใบทองปิดเบ้าตาเดี่ยวที่แหล่งตาลีไซ คาลาตากัน (Talisay, Calatagan)
หลักฐานการจัดวางแผ่นทองคำปิดเบ้าตาที่น่าสนใจอย่างยิ่งในเชิงเปรียบเทียบปรากฏในรายงานของโรเบิร์ต บ็อกซ์ (*Robert B. Fox*) ค.ศ. 1967 และได้รับการวิเคราะห์โดยวิกเตอร์ เอสเตรลลา (*Victor Estrella*) ค.ศ. 2016 จากแหล่งโบราณคดีตาลีไซ (*Talisay Site*) ในคาลาตากัน จังหวัดบาตังกัส [14] [15]:

> "From the Pulung Bakaw and Karitunan sites, gold rings were recovered together with some gold beads, while in the Talisay site, a gold leaf was found covering the right eye socket of the deceased (Chang 2008; Fox 1967)." [15]
> 
> *คำแปลสรุปความ:* "จากแหล่งปูลุงบาเกาและคารีตูนัน มีการค้นพบแหวนทองคำร่วมกับลูกปัดทองคำจำนวนหนึ่ง ขณะที่ในแหล่งตาลีไซ มีการค้นพบแผ่นทองคำเปลวปิดทับอยู่บนเบ้าตาขวาของผู้ตาย" [15]

การค้นพบแผ่นทองคำปิดทับเบ้าตาขวาเพียงข้างเดียว (*Single Right Ocular Placement*) ในหลุมศพเด็กที่ตาลีไซ ชี้ให้เห็นว่า ในบางชุมชนหรือบางบริบทพิธีกรรม การปิดทวารตาอาจมิได้กระทำครบทั้งสองข้างเสมอไป การปิดเฉพาะตาข้างใดข้างหนึ่งอาจสะท้อนถึงการปฏิบัติการเชิงสัญลักษณ์เฉพาะตัว หรืออาจเป็นผลมาจากข้อจำกัดทางเศรษฐกิจของครอบครัวผู้ตายที่สามารถจัดหาทองคำได้เพียงพอสำหรับตาเพียงข้างเดียว [14] [15]

### 3. กายวิภาคศาสตร์ของกระดูกจมูก (Nasal Bones & Piriform Aperture) และการจัดวางแผ่นปิดจมูก

กระดูกจมูกมนุษย์ประกอบด้วยกระดูกจมูกคู่ขนาดเล็ก (*Paired Nasal Bones*) ที่ประสานกันเป็นดั้งจมูก และช่องเปิดรูปหยดน้ำของกะโหลกศีรษะที่เรียกว่า *ช่องพิริฟอร์ม* (*Piriform Aperture*) ซึ่งเมื่อบุคคลยังมีชีวิตอยู่ ช่องนี้จะถูกหุ้มคลุมด้วยกระดูกอ่อนปีกจมูก (*Alar Cartilages*) และเนื้อเยื่อผิวหนัง [11]

#### 3.1 การทอดตัวข้ามระนาบกระดูกใบหน้า
ดังที่ได้ระบุไว้ในตอนที่ 5.1 แผ่นปิดจมูกโอตอน (หมายเลขทะเบียน **OT-MF-40**) มีความยาวรวมถึง **16.3 เซนติเมตร** ซึ่งยาวกว่าโครงสร้างกระดูกจมูกมนุษย์อย่างมาก เมื่อพิจารณาในทางกายวิภาคศาสตร์ กะโหลกศีรษะของมนุษย์มีความสูงของใบหน้าส่วนบน (*Upper Facial Height: Nasion to Prosthion*) เฉลี่ยประมาณ 6.5 ถึง 7.5 เซนติเมตรเท่านั้น [11]

ความยาว 16.3 เซนติเมตรของแผ่นปิดจมูกจึงมีความหมายทางกายวิภาคศาสตร์อย่างลึกซึ้ง:
1. **ส่วนบนสุด (Superior Segment):** ก้านส่วนบนที่แคบจะทอดตัวสูงขึ้นไปพาดทับกระดูกหน้าผากส่วนล่าง (*Frontal Bone*) ผ่านจุดหว่างคิ้ว (*Glabella*) และจุดแนซีออน (*Nasion*) ซึ่งเป็นรอยต่อระหว่างกระดูกหน้าผากกับกระดูกจมูก [11] [12]
2. **ส่วนกลาง (Medial Segment):** แผ่นทองคำจะแนบไปตามแนวสันกระดูกจมูก โดยมีรอยพับสันนูน (*Median Ridge*) ทำมุมรับกับความลาดเอียงของดั้งจมูก [12]
3. **ส่วนล่างสุด (Inferior Segment):** แผ่นทองคำส่วนฐานที่ผายกว้างออกถึง 5.5 เซนติเมตร จะทอดตัวข้ามช่องเปิด *Piriform Aperture* คลุมทับกระดูกขากรรไกรบน (*Anterior Nasal Spine & Alveolar Process of Maxilla*) และยื่นยาวลงมาปิดทับริมฝีปากบน (*Upper Lip*) จนเกือบถึงแนวฟันหน้า [11] [12]

การจัดวางเช่นนี้ทำให้แผ่นปิดจมูกทำหน้าที่เป็น "กระดูกสันหลังทองคำ" (*Golden Axial Spine*) ที่ยึดโยงแกนกึ่งกลางของใบหน้าผู้ตายในแนวดิ่ง ตั้งแต่หน้าผาก จมูก ลงมาจนถึงปากอย่างต่อเนื่อง [12] [13]

### 4. กายวิภาคศาสตร์ของกระดูกขากรรไกร (Maxilla & Mandible) และการจัดวางแผ่นปิดปาก

กระดูกขากรรไกรบน (*Maxilla*) และกระดูกขากรรไกรล่าง (*Mandible*) ประกอบกันเป็นโครงสร้างรองรับช่องปากและแนวฟัน (*Dentition*) เมื่อบุคคลเสียชีวิตและเนื้อเยื่อของข้อต่อขากรรไกร (*Temporomandibular Joint - TMJ*) เริ่มคลายตัว ขากรรไกรล่างมักมีแนวโน้มที่จะอ้าตกลงมาตามแรงโน้มถ่วง ทำให้ช่องปากเปิดอ้าออก [11]

ในการประกอบพิธีศพของฟิลิปปินส์โบราณ ชุมชนมีธรรมเนียมการใช้ผ้าหรือสายเชือกผูกรัดกระดูกขากรรไกรล่างให้ประกบแน่นเข้ากับขากรรไกรบน (*Jaw Binding*) ดังที่ปรากฏในบันทึกชาติพันธุ์วรรณนา [16] จากนั้น ช่างจึงนำ **แผ่นทองคำปิดปาก (Oral Plaque)** มาวางทาบปิดทับลงบนรอยแยกริมฝีปาก [12] [13]:

```
+---------------------------------------------------------------------------------------------------+
|               กายวิภาคศาสตร์การจัดวางแผ่นปิดปากพาดทับแนวฟันและริมฝีปาก (Oral Placement)          |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|           กระดูกขากรรไกรบนและแนวฟันหน้าบน (Maxilla & Upper Incisors)                               |
|           =====================================================================                   |
|          /         .-------------------------------------------------.         \                  |
|         /         (       แผ่นทองคำปิดปากทรงแถบโค้งรับริมฝีปาก        )         \                 |
|        /           '-------------------------------------------------'           \                |
|       |                     |             |             |                         |               |
|       |                 [ หมุดทอง ]   [ หมุดทอง ]   [ หมุดทอง ]                   |               |
|       |                 ( บันซิล/ปูซัด ฝังแน่นในเนื้อฟันหน้าตัด )                  |               |
|        \                    |             |             |                        /                |
|         \          ===================================================          /                 |
|          \        กระดูกขากรรไกรล่างและแนวฟันหน้าล่าง (Mandible & Lower Incisors) /                  |
|           =====================================================================                   |
|                                                                                                   |
|      * หมายเหตุ: แผ่นปิดปากทำหน้าที่เป็น "เกราะกำบังภายนอก" ประกบทับลงบนฟันหน้า                      |
|        ที่มีหมุดทองคำ (Bansil) ฝังเป็น "แกนศักดิ์สิทธิ์ภายใน" ก่อเกิดการผนึกช่องปากสองชั้นสมบูรณ์แบบ   |
+---------------------------------------------------------------------------------------------------+
```

แผ่นปิดปากมักมีความยาวประมาณ 6.0 ถึง 9.5 เซนติเมตร ซึ่งกว้างกว่าความกว้างของช่องปากปกติ (*Cheilion to Cheilion*) เล็กน้อย ทำให้ปลายทั้งสองข้างของแผ่นทองคำพาดเลยมุมปากออกไปทาบอยู่บนกระดูกแก้ม การจัดวางในตำแหน่งนี้มีความสัมพันธ์โดยตรงกับศิลปะทันตกรรมฝังทองคำ (*Bansil / Pusad*) ที่ได้วิเคราะห์ในตอนที่ 4.5 กล่าวคือ แผ่นปิดปากทองคำทำหน้าที่เป็น "หน้ากากภายนอก" ที่ปิดคลุมฟันฝังหมุดทองคำที่ซ่อนอยู่ภายในช่องปาก ก่อเกิดเป็นการผนึกทวารปากด้วยทองคำถึงสองชั้น ทั้งระนาบสรีรวิทยาภายในและระนาบวัตถุภายนอก [12] [17]

### 5. การวิเคราะห์ลำดับการซ้อนทับเชิงกายภาพ (Stratigraphic Overlap Hierarchy)

คำถามสำคัญยิ่งในทางชีวโบราณคดีคือ: **ในการจัดวางแผ่นทองคำบนใบหน้านั้น ชิ้นส่วนใดถูกวางลงไปก่อน และชิ้นส่วนใดถูกวางทับลงมาในภายหลัง?** [12]

จากการวิเคราะห์ภาพถ่ายการค้นพบ *in situ* บันทึกภาคสนาม และการจำลองสัณฐานวิทยาของหน้ากากทองคำโอตอนและชุดแผ่นทองคำเซบู พบแบบแผนลำดับชั้นของการซ้อนทับ (*Micro-stratigraphic Overlap Sequence*) ดังนี้ [12] [13]:

```
+---------------------------------------------------------------------------------------------------+
|         ลำดับขั้นตอนการจัดวางและซ้อนทับแผ่นทองคำบนใบหน้า (Micro-stratigraphic Overlap)             |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|   ขั้นที่ 1: การจัดวางแผ่นปิดจมูก (Nasal Plaque First)                                             |
|   - วางแผ่นปิดจมูกทาบลงบนแนวกระดูกหน้าผากและสันจมูกเป็นชิ้นแรก                                    |
|   - ปรับแนวดั้งสันนูน (Median Ridge) ให้ล็อกเข้ากับสันกระดูกจมูก                                   |
|                                                                                                   |
|                                    |                                                              |
|                                    v                                                              |
|                                                                                                   |
|   ขั้นที่ 2: การจัดวางแผ่นปิดตาคู่วางทับลงมา (Ocular Plaque Overlap)                               |
|   - แผ่นปิดตาคู่วางทาบทับลงมาบนระนาบเบ้าตา                                                        |
|   - สะพานเชื่อมระหว่างตาทั้งสองข้างจะ "วางประกบทับ" (Overlap) ลงบนก้านส่วนบนของแผ่นปิดจมูก         |
|   - ปีกแผ่นปิดตาทั้งสองข้างช่วยกดตรึงขอบแผ่นปิดจมูกมิให้เลื่อนขยับ                                |
|                                                                                                   |
|                                    |                                                              |
|                                    v                                                              |
|                                                                                                   |
|   ขั้นที่ 3: การจัดวางแผ่นปิดปาก (Oral Plaque Placement)                                          |
|   - ในกรณีที่แผ่นปิดจมูกยาวถึงริมฝีปากบน ขอบล่างของแผ่นปิดจมูกจะสอดอยู่ "ใต้" แผ่นปิดปาก           |
|   - แผ่นปิดปากวางประกบทับขอบล่างของแผ่นปิดจมูกและปิดผนึกช่องปาก                                   |
|   - ก่อเกิดเป็นโครงสร้างประสานล็อกสามทิศทาง (Interlocking Tripartite Structure)                   |
+---------------------------------------------------------------------------------------------------+
```

ลำดับการซ้อนทับที่แผ่นปิดตาและแผ่นปิดปากวางทับลงบนแผ่นปิดจมูกนี้มีความสมเหตุสมผลสูงสุดในเชิงกลไกทางกายภาพ เพราะแผ่นปิดจมูกมีรูปทรงเป็นสันนูนสามมิติ หากนำมาวางทับบนแผ่นปิดตา แผ่นปิดจมูกจะกระดกและไม่สามารถแนบสนิทกับใบหน้าได้ แต่เมื่อวางแผ่นปิดจมูกแนบไปกับสันดั้งก่อน แล้วจึงใช้แผ่นปิดตาวางพาดทับลงมา สะพานเชื่อมระหว่างดวงตาและน้ำหนักของแผ่นปิดตาจะทำหน้าที่เสมือน "คลิปล็อก" ที่ช่วยกดตรึงแผ่นปิดจมูกให้อยู่ในแนวแกนกึ่งกลางอย่างมั่นคง [12]

### 6. ทิศทางด้านคว่ำ-หงาย (Obverse vs. Reverse Orientation) และการสะท้อนประกายแสง

อีกหนึ่งมิติสำคัญที่สะท้อนถึงเจตจำนงทางพิธีกรรมคือการกำหนดทิศทางด้านหน้าและด้านหลังของแผ่นทองคำ [12] [18]:

1. **ด้านหน้าขัดเงาและดุนนูน (Obverse / Repoussé Face):** ในทุกกรณีของการค้นพบทางโบราณคดี แผ่นทองคำจะถูกจัดวางโดยหันด้านหน้า—ซึ่งเป็นด้านที่ผ่านการขัดเงาจนสะท้อนแสง หรือเป็นด้านที่ลวดลายจุดไข่ปลาและรอยตอกดุนนูนนูนเด่นขึ้นมา—**หงายขึ้นสู่เบื้องบนเสมอ (Facing Upward toward the Sky)** [12]
2. **ด้านหลังมีรอยบุ๋ม (Reverse Face):** ด้านหลังของแผ่นทองคำ ซึ่งปรากฏรอยบุ๋มจากการตอกลายและมีผิวสัมผัสขรุขระ จะถูกคว่ำหน้าลงแนบชิดกับกระดูกกะโหลกศีรษะหรือชั้นผ้าห่อศพ [12]

การหงายด้านประกายทองคำขึ้นสู่เบื้องบนแสดงให้เห็นว่า แผ่นทองคำมิได้ถูกวางเพื่อ "ให้ผู้ตายมองเห็น" (เพราะด้านสะท้อนแสงหงายออกจากตัวผู้ตาย) หากแต่ถูกวางเพื่อ **"ให้ผู้อื่นมองเห็น"** ผู้อื่นในที่นี้ครอบคลุมทั้งผู้เข้าร่วมพิธีศพ ชุมชนคนเป็น ตลอดจนดวงวิญญาณบรรพชนและทวยเทพบนสรวงสวรรค์ ประกายสีทองที่สะท้อนแสงแดดหรือแสงคบเพลิงในระหว่างการประกอบพิธีศพทำหน้าที่เป็นสัญญาณศักดิ์สิทธิ์ที่ประกาศถึงสถานะอันเป็นอมตะของผู้ตายอย่างเจิดจรัส [12] [16]

### 7. กลไกการยึดตรึง (Fixation Mechanisms): แรงโน้มถ่วงธรรมชาติ vs การเย็บร้อยเชือก

ในการจัดวางแผ่นทองคำให้อยู่กับตำแหน่งบนใบหน้าระหว่างพิธีศพและการฝัง ชุมชนโบราณในฟิลิปปินส์ใช้กลไกทางกายภาพ 2 วิธีหลัก ซึ่งสะท้อนถึงความหลากหลายของขนบธรรมเนียมท้องถิ่น [12] [13]:

```
+---------------------------------------------------------------------------------------------------+
|               การเปรียบเทียบกลไกการยึดตรึงแผ่นทองคำ (Fixation Mechanisms)                         |
+---+---------------------------------------------------+-------------------------------------------+
|   | แบบที่ 1: การวางแนบด้วยแรงโน้มถ่วงธรรมชาติ        | แบบที่ 2: การเย็บร้อยเข้ากับผ้าห่อศพ      |
|   | (Gravity-dependent Anatomical Adhesion)           | (Stitched Mortuary Shroud Integration)    |
+---+---------------------------------------------------+-------------------------------------------+
| 1 | ไร้รูเจาะร้อยเชือกตามขอบแผ่นทอง (Unperforated)    | มีรูเจาะขนาดจิ๋ว (Perforations) เรียงตามขอบ |
| 2 | อาศัยท่านอนหงายเหยียดยาว (Supine Extended Burial)  | เย็บตรึงด้วยด้ายหรือเส้นใยพืชเข้ากับผ้า/เสื่อ |
| 3 | ผ้าห่อศพหรือเสื่อสานชั้นนอกช่วยกดทับไม่ให้เลื่อนหลุด | ป้องกันการเลื่อนหลุดแม้มีการเคลื่อนย้ายร่าง |
| 4 | ตัวอย่าง: โอตอน (หลุม 6), บูตูอัน, เซบู          | ตัวอย่าง: ตัวอย่างใน CCP และคอลเลกชัน BSP |
+---+---------------------------------------------------+-------------------------------------------+
```

#### 7.1 การวางแนบโดยอาศัยแรงโน้มถ่วงธรรมชาติ (Gravity-dependent Placement)
ในกรณีของหน้ากากทองคำโอตอนและแผ่นทองคำเซบู ตัวแผ่นทองคำ **ไม่มีการเจาะรูตามแนวขอบ** สำหรับร้อยเชือกผูกมัดแต่อย่างใด [12] [13] การที่แผ่นทองคำสามารถรักษาระนาบและตำแหน่งพาดทับเบ้าตา สันจมูก และริมฝีปากอยู่ได้จนกระทั่งนักโบราณคดีขุดค้นพบในสภาพ *in situ* เป็นผลมาจาก:
- **ท่านอนหงายเหยียดยาว (Supine Extended Position):** ศพถูกจัดให้นอนหงายราบไปกับพื้นโลงไม้หรือก้นหลุม ทำให้แรงโน้มถ่วงของโลกช่วยกดแผ่นทองคำให้แนบสนิทอยู่บนระนาบใบหน้า [11] [12]
- **ความเหนียวของอินทรียสาร:** ในช่วงแรกของการฝัง ความชื้นและสารคัดหลั่งจากผิวหนังศพอาจทำหน้าที่เสมือนกาวธรรมชาติที่ช่วยดูดแผ่นทองคำบางให้ติดแน่นกับผิวหน้า [11]
- **การห่อหุ้มด้วยเสื่อและผ้าห่อศพ:** ร่างของผู้ตายได้รับการพันห่อด้วยผ้าฝ้าย เสื่อสาน หรือเปลือกไม้หลายชั้น ซึ่งทำหน้าที่เป็นแรงกดภายนอกที่ประคองให้แผ่นทองคำแนบสนิทอยู่กับที่ตลอดระยะเวลาการเน่าเปื่อย [12] [16]

#### 7.2 การเย็บร้อยผ่านรูเจาะขอบ (Stitched Shroud Integration)
ในทางตรงกันข้าม ในโบราณวัตถุบางชิ้นที่บันทึกไว้ในสารานุกรมศิลปะฟิลิปปินส์และคอลเลกชันโบราณคดีของธนาคารกลางแห่งฟิลิปปินส์ (*BSP*) แผ่นทองคำปิดทวารปรากฏ **รูเจาะขนาดเล็ก (Perforations)** ที่ถูกตอกทะลุเป็นแนวรอบขอบแผ่น รูเหล่านี้มีเส้นผ่านศูนย์กลางไม่เกิน 1 มิลลิเมตร ชี้ให้เห็นว่าช่างทองได้เตรียมแผ่นทองคำเพื่อให้ผู้ประกอบพิธีศพสามารถใช้เข็มและเส้นด้ายเย็บแผ่นทองคำตรึงเข้ากับหน้ากากผ้าฝ้าย ผ้าคลุมหน้า (*Veil*), หรือเสื่อรองรับอย่างแน่นหนา ก่อนที่จะนำผ้าคลุมหน้านั้นมาสวมครอบทับใบหน้าผู้ตาย [12] [18]

การเย็บตรึงเช่นนี้มีความจำเป็นอย่างยิ่งในกรณีที่มีการเคลื่อนย้ายศพในระยะทางไกล เช่น การลำเลียงศพทางเรือ หรือในกรณีของการฝังศพแบบนั่งงอเข่าในไหดินเผา (*Jar Burials*) ซึ่งแรงโน้มถ่วงไม่สามารถช่วยรักษาตำแหน่งของแผ่นทองคำบนใบหน้าได้ การเย็บติดกับผ้าจึงเป็นทางออกทางวิศวกรรมพิธีกรรมที่ช่วยรับประกันว่าทวารทั้งสามจะได้รับการปกป้องอย่างสมบูรณ์ตลอดไป [12] [19]

### 8. สรุปตอน 5.2 และนัยสำคัญทางกายวิภาคศาสตร์

การวิเคราะห์กายวิภาคศาสตร์การจัดวางบนโครงกระดูกในตอนที่ 5.2 ยืนยันว่า แผ่นทองคำปิดทวารของฟิลิปปินส์โบราณถูกสร้างสรรค์ขึ้นด้วยความเข้าใจอันลึกซึ้งในสรีรวิทยาของใบหน้ามนุษย์ มิติความยาวของแผ่นปิดตาที่พาดเลยเบ้าตาไปถึงโหนกแก้ม ความยาวของแผ่นปิดจมูกที่ทอดตัวยาวเชื่อมโยงหน้าผากถึงปาก และการจัดวางแผ่นปิดปากทับลงบนฟันฝังหมุดทองคำ ล้วนเป็นหลักฐานของแบบแผนทางวัฒนธรรมที่มีการวางแผนอย่างประณีต [11] [12] [13]

ลำดับการซ้อนทับที่แผ่นปิดตาวางทับแผ่นปิดจมูก และการหงายด้านประกายทองคำขึ้นสู่เบื้องบน ตอกย้ำถึงความตั้งใจในการสร้าง "สรีระทองคำอมตะ" ที่ปิดกั้นช่องเปิดทางชีววิทยาและเปิดรับสายตาจากสรวงสวรรค์ ข้อมูลกายวิภาคศาสตร์เหล่านี้จะทำหน้าที่เป็นสะพานเชื่อมสู่ **ตอนที่ 5.3** ซึ่งจะทำการวิเคราะห์เชิงเปรียบเทียบสัณฐานวิทยา ความหนา น้ำหนัก และเทคนิคการขึ้นรูประหว่างสกุลช่างโอตอน บูตูอัน และเซบู อย่างละเอียดต่อไป [12] [13] [18]

## 5.3 การศึกษาสัณฐานวิทยาเชิงลึกเปรียบเทียบ: รูปแบบฉลุลายละเอียดและดุนนูนจุดไข่ปลา (Repoussé & Openwork), รูปแบบแผ่นทองเรียบขัดเงา (Plain Smooth Sheets), และการวิเคราะห์สัดส่วน ขนาด น้ำหนัก และความหนา

### 1. บทนำและกรอบทวิภาวะเชิงช่างทอง: ความหลากหลายทางสัณฐานวิทยาในทะเลวิสายาส์และมินดาเนา

เมื่อพิจารณาแผ่นทองคำปิดทวารบนใบหน้าผู้ตายที่ค้นพบในหมู่เกาะฟิลิปปินส์จากมุมมองของประวัติศาสตร์ศิลป์และเทคโนโลยีโลหวิทยาโบราณ โบราณวัตถุเหล่านี้มิได้เป็นผลผลิตจากแม่พิมพ์หรือแบบแผนที่เป็นเนื้อเดียวกันเพียงหนึ่งเดียว หากแต่สะท้อนถึง "ทวิภาวะเชิงช่างทอง" (*Artisanal and Stylistic Duality*) ที่แบ่งออกเป็น 2 ตระกูลช่างใหญ่ที่มีปรัชญาและเทคนิคการขึ้นรูปแตกต่างกันอย่างมีนัยสำคัญ [20] [21]:

การวิเคราะห์เชิงเปรียบเทียบในตอนนี้มุ่งตรวจสอบกระบวนการผลิตเชิงช่าง มาตรวิทยาเชิงปริมาณ (ขนาด สัดส่วน น้ำหนัก ความหนา) และระดับความบริสุทธิ์ของเนื้อทองคำ เพื่ออธิบายว่าความแตกต่างทางสัณฐานวิทยาเหล่านี้สัมพันธ์กับลำดับเวลาทางประวัติศาสตร์ ขนบธรรมเนียมท้องถิ่น หรือเครือข่ายการแลกเปลี่ยนข้ามภูมิภาคอย่างไร [20] [21]

### 2. รูปแบบฉลุลายละเอียดและดุนนูนจุดไข่ปลา (Repoussé & Openwork Tradition: โอตอน และ BSP)

หน้ากากทองคำโอตอน ซึ่งจัดแสดง ณ พิพิธภัณฑสถานแห่งชาติฟิลิปปินส์ และชิ้นงานที่มีสัณฐานใกล้เคียงกันในคอลเลกชันของธนาคารกลางแห่งฟิลิปปินส์ (*Bangko Sentral ng Pilipinas - BSP*) ถือเป็นตัวอย่างที่สมบูรณ์แบบที่สุดของศิลปะการดุนนูนและฉลุลายทองคำยุคก่อนอาณานิคม [20] [21]

ในงานศึกษาของรามอน วิลเยกัส (*Ramon N. Villegas*) ผู้เชี่ยวชาญประวัติศาสตร์ทองคำฟิลิปปินส์ ได้บรรยายลักษณะของแผ่นปิดตาโอตอนและตัวอย่างในคอลเลกชัน BSP ไว้อย่างละเอียดว่า [20]:

> "The Oton eye cover, recovered from a skull, consisting of gold foil cut into two leaf-shaped elements, joined by a strip that was placed over the bridge of the nose, like one in the BSP collection. Linear detailing gives a schematic rendering of an eye and the perimeter of the object is bounded by repousse dots." [20]
> 
> *คำแปลสรุปความ:* "แผ่นปิดตาโอตอน ซึ่งกู้คืนได้จากกะโหลกศีรษะ ประกอบด้วยแผ่นทองคำบางตัดเป็นรูปทรงใบไม้สองส่วน เชื่อมต่อกันด้วยแถบสะพานที่วางพาดเหนือสันจมูก คล้ายคลึงกับชิ้นงานหนึ่งในคอลเลกชัน BSP รายละเอียดที่เป็นเส้นสายสะท้อนภาพวาดเชิงโครงร่างของดวงตา และแนวเส้นรอบวงของวัตถุถูกล้อมรอบด้วยจุดดุนนูน" [20]

#### 2.1 เทคนิคการดุนนูนจากด้านหลัง (Repoussé) และการตอกเน้นเส้น (Chasing)
กระบวนการรังสรรค์ลวดลายของช่างทองโอตอนเริ่มต้นจากการนำแผ่นทองคำที่ตีแผ่เป็นแผ่นเรียบมาวางคว่ำหน้าลงบนแท่นรองรับที่มีความยืดหยุ่น เช่น ทั่งไม้เนื้ออ่อน ยางไม้ผสมขี้ผึ้ง (*Pitch Bed / Pitch Block*) หรือก้อนชันผสมเถ้าถ่าน [20] [24] จากนั้น ช่างจะใช้เครื่องมือตอกปลายมน (*Punch / Chisel*) ตอกเคาะเบาๆ จากด้านหลัง (*Repoussé*) เพื่อดันเนื้อทองคำให้นูนขึ้นเป็นเม็ดตุ่มกลมมน ลวดลายจุดไข่ปลานี้จะถูกตอกเรียงแถวชิดกันอย่างเป็นระเบียบตามแนวขอบด้านนอกของแผ่นปิดตาทั้งสองข้างและขอบของแผ่นปิดจมูก [20]

เมื่อพลิกแผ่นทองคำกลับมาด้านหน้า ช่างจะใช้เครื่องมือปลายแหลมหรือสิ่วขนาดจิ๋วตอกย้ำแนวเส้นจากด้านหน้า (*Chasing*) เพื่อตัดขอบให้คมชัด และตอกสลักเป็นเส้นโค้งขนานซ้อนกันหลายชั้นเพื่อจำลองรอยพับของเปลือกตาและเส้นขอบเบ้าตา [20]

#### 2.2 หน้าที่เชิงวิศวกรรมของลวดลายจุดไข่ปลา (Structural Function of Repoussé Beading)
ในแง่ของวิศวกรรมวัสดุศาสตร์ ลวดลายจุดไข่ปลาและการดุนนูนขอบมิได้มีเพียงคุณค่าทางสุนทรียศาสตร์เท่านั้น หากแต่ทำหน้าที่สำคัญยิ่งในการ **เสริมความแข็งแกร่งเชิงโครงสร้าง (Structural Corrugation / Rib Stiffening)** แผ่นทองคำที่มีความหนาเพียง 0.15 ถึง 0.25 มิลลิเมตร หากปล่อยให้เป็นผิวเรียบแบน จะมีความอ่อนตัวสูงและบิดงอเสียรูปได้ง่ายเมื่อถูกหยิบจับ แต่เมื่อพื้นผิวถูกดุนนูนเป็นแนวตุ่มและรอยพับสัน จะเกิดการกระจายแรงและเพิ่มโมเมนต์ความเฉื่อยของหน้าตัด (*Section Modulus*) ทำให้แผ่นทองคำสามารถรักษารูปทรงสามมิติที่โค้งรับกับใบหน้าได้อย่างคงทนถาวร [20] [21]

#### 2.3 การฉลุช่องเปิดตาดำ (Pupil Openwork)
จุดเด่นที่ทำให้หน้ากากโอตอนแตกต่างจากแผ่นทองคำแห่งอื่นๆ ในเอเชียตะวันออกเฉียงใต้อย่างสิ้นเชิง คือการเจาะฉลุเป็นช่องวงกลมขนาดเล็กตรงกึ่งกลางของเบ้าตาทั้งสองข้าง ช่างทองใช้สิ่วกลวงหรือเหล็กหมาดเจาะทะลุแผ่นทองคำอย่างประณีต ขอบของรูฉลุเรียบกริบ ไร้รอยฉีกขาด การมีช่องเปิดตาดำทำให้ผู้ตายในมโนทัศน์ของชาวโอตอนมิได้ตกอยู่ในความมืดมิด หากแต่มี "สายตาทองคำ" ที่สามารถมองทะลุผ่านม่านแห่งความตายออกไปสู่โลกภายนอกได้ [20] [21]

#### 3.1 การตีแผ่นทองคำบางพิเศษ (Extreme Gold Foil Beating / Pagpupukpok)
ในชุมชนบูตูอันและเซบู ช่างทองมีความเชี่ยวชาญเป็นเลิศในการนำก้อนทองคำบริสุทธิ์มาตีแผ่ด้วยค้อนหินหรือค้อนโลหะบนทั่งเรียบ (*Pagpupukpok*) จนเนื้อทองคำขยายตัวออกเป็นแผ่นบางเฉียบอย่างสม่ำเสมอ ความหนาของแผ่นทองคำกลุ่มนี้วัดได้เพียง **0.08 ถึง 0.15 มิลลิเมตร** ซึ่งบางกว่ากระดาษเขียนหนังสือสมัยใหม่ [20] [23]

ในการตีทองคำให้บางเฉียบระดับนี้ ช่างทองจำเป็นต้องผ่านกระบวนการ **การอบอ่อนซ้ำหลายรอบ (Iterative Annealing)** กล่าวคือ เมื่อทองคำถูกตีจนเริ่มแข็งตัวและเปราะจากความเค้นสะสมภายในเนื้อโลหะ (*Work Hardening*) ช่างจะต้องนำแผ่นทองคำไปลนไฟด้วยอุณหภูมิประมาณ 600 ถึง 700 องศาเซลเซียส เพื่อให้โครงสร้างผลึกของทองคำคลายตัวและคืนสภาพความอ่อนเหนียว (*Recrystallization*) ก่อนที่จะนำมาตีซ้ำสลับกันไปเช่นนี้หลายสิบรอบ หากช่างไม่มีความชำนาญ แผ่นทองคำจะแตกร้าวหรือฉีกขาดทันที [24]

#### 3.2 การขัดมันวาวดั่งกระจกเงา (Mirror-like Burnishing)
หลังจากการตีขึ้นรูปและตัดขอบเป็นรูปทรงวงรี สี่เหลี่ยมคางหมู และแถบโค้งรับริมฝีปาก ช่างทองจะใช้เครื่องมือขัดผิวหน้า เช่น หินอาเกตเนื้อละเอียด (*Agate Burnisher*) เขี้ยวสัตว์ หรือกระดองเต่า ขัดถูไปบนผิวหน้าทองคำอย่างพิถีพิถัน กระบวนการขัดเงานี้ทำให้ผิวสัมผัสระดับจุลภาคของทองคำเรียบสนิทจนสามารถสะท้อนแสงแดดได้อย่างสมบูรณ์แบบ แผ่นปิดตาที่เรียบเกลี้ยงไร้รูฉลุนี้ทำหน้าที่เป็น "กระจกทองคำ" ที่สะท้อนภาพแห่งความเป็นนิรันดร์และปิดกั้นสายตาจากโลกียวิสัยอย่างเด็ดขาด [20] [22]

### 4. การวิเคราะห์มาตรวิทยา (Metrological Analysis): ขนาด สัดส่วน น้ำหนัก และความหนา

จากการรวบรวมข้อมูลการตรวจวัดทางวิทยาศาสตร์ของแผ่นทองคำปิดทวารจากแหล่งโบราณคดีหลักในฟิลิปปินส์ สามารถสรุปตารางเปรียบเทียบมิติเชิงมาตรวิทยา (*Comparative Metrological Matrix*) ได้ดังนี้ [20] [21] [22] [23]:

```
+---------------------------------------------------------------------------------------------------+
|               ตารางเปรียบเทียบมาตรวิทยาแผ่นทองคำปิดทวารในฟิลิปปินส์                                |
+-----------------------+-------------------+-------------------+-------------------+---------------+
| แหล่งโบราณคดี / วัตถุ  | แผ่นปิดตา (ซม./ก.)| แผ่นปิดจมูก (ซม./ก.)| แผ่นปิดปาก (ซม./ก.) | ความหนาเฉลี่ย |
+-----------------------+-------------------+-------------------+-------------------+---------------+
| โอตอน (Oton, Iloilo)   | ยาว 13.3, กว้าง 2.5| ยาว 16.3, กว้าง 5.5| ยาว 8.5, กว้าง 2.2| ~0.15–0.25 มม.|
| เลขทะเบียน OT-MD/MF   | น้ำหนัก: 3.16 กรัม | น้ำหนัก: 3.09 กรัม | น้ำหนัก: ~2.10 กรัม| (ดุนนูน-ฉลุ)  |
+-----------------------+-------------------+-------------------+-------------------+---------------+
| บูตูอัน (Butuan)      | ยาว 6.8, กว้าง 2.8| ยาว 7.2, กว้าง 3.8| ยาว 7.5, กว้าง 2.0| ~0.08–0.12 มม.|
| คอลเลกชัน BSP/NMP      | น้ำหนัก: ~1.20 กรัม | น้ำหนัก: ~1.45 กรัม | น้ำหนัก: ~1.10 กรัม| (แผ่นบางเรียบ)|
+-----------------------+-------------------+-------------------+-------------------+---------------+
| เซบู (Plaza Indep.)    | ยาว 6.2, กว้าง 2.4| ยาว 6.5, กว้าง 3.2| ยาว 7.0, กว้าง 1.8| ~0.10–0.15 มม.|
| รายงาน NMP 2022/2023  | แยกชิ้นอิสระสองแผ่น| ทรงสี่เหลี่ยมคางหมู| แถบโค้งริมฝีปาก    | ร่วมกับต่างหู |
+-----------------------+-------------------+-------------------+-------------------+---------------+
```

#### 4.1 การเปรียบเทียบน้ำหนักทองคำรวม
เมื่อคำนวณน้ำหนักทองคำรวมต่อชุด จะพบว่า:
- **ชุดหน้ากากโอตอน:** น้ำหนักของแผ่นปิดตา (3.16 กรัม) รวมกับแผ่นปิดจมูก (3.09 กรัม) มีน้ำหนักรวมเฉพาะสองชิ้นนี้ถึง **6.25 กรัม** (ไม่รวมแผ่นปิดปากและเครื่องประดับศีรษะ) [21] ซึ่งสะท้อนถึงการใช้เนื้อทองคำในปริมาณมากและความหนาของแผ่นโลหะที่รองรับงานดุนนูน
- **ชุดแผ่นทองบูตูอันและเซบู:** น้ำหนักเฉลี่ยของแผ่นทองคำแต่ละชิ้นอยู่ในช่วงเพียง **1.0 ถึง 1.5 กรัม** ทำให้น้ำหนักรวมของชุดแผ่นปิดทวารทั้งสามชิ้นอยู่ที่ประมาณ **3.5 ถึง 4.5 กรัม** เท่านั้น [20] [22]

ความแตกต่างของน้ำหนักนี้ชี้ให้เห็นว่า ช่างทองบูตูอันและเซบูมีเป้าหมายในการกระจายเนื้อทองคำให้แผ่กว้างออกไปมากที่สุดด้วยเทคนิคการตีแผ่นบาง เพื่อให้ได้ชุดปิดทวารครบทั้งสามจุดโดยใช้ปริมาณเนื้อทองคำอย่างประหยัดและคุ้มค่าสูงสุด ขณะที่ช่างทองโอตอนเลือกที่จะใช้เนื้อทองคำหนากว่าเพื่อรองรับการตอกดุนลวดลายที่ลึกและประณีต [20] [21]

### 5. ความบริสุทธิ์ของเนื้อทองคำและการแบ่งชั้นกะรัตตามจดหมายเหตุพื้นเมือง

คุณสมบัติทางกายภาพของทองคำที่ช่วยให้สามารถตีเป็นแผ่นบางเฉียบได้นั้นขึ้นอยู่กับ **ระดับความบริสุทธิ์ (Gold Purity / Karat)** โดยตรง ในบันทึกประวัติศาสตร์ภาษาสเปนและพจนานุกรมตากาล็อก ค.ศ. 1613 ของเปโดร เด ซาน บูเอนาเบนตูรา ได้บันทึกระบบการเรียกชื่อชั้นคุณภาพของทองคำของชาวฟิลิปปินส์โบราณไว้อย่างละเอียด ซึ่งวิลเยกัสและเอสเตรลลาได้นำมาจัดระบบวิเคราะห์ [20] [24]:

```
+---------------------------------------------------------------------------------------------------+
|               ระบบชั้นคุณภาพและความบริสุทธิ์ของทองคำโบราณในฟิลิปปินส์ (Villegas 2004)              |
+---+-------------------+-------------------+-------------------------------------------------------+
|   | ชื่อเรียกพื้นเมือง  | ค่ากะรัตโดยประมาณ | ลักษณะการใช้งานและบทบาทในสังคม                        |
+---+-------------------+-------------------+-------------------------------------------------------+
| 1 | บิซิน (Bisin)      | ~10–12 กะรัต      | ทองคำเนื้อต่ำผสมทองแดง ใช้ในการแลกเปลี่ยนทั่วไป       |
| 2 | ปานีกา (Panika)   | ~16–18 กะรัต      | ใช้ทำต่างหูทรงห่วงกลวง (Orejeira) มีความเหนียวพอเหมาะ |
| 3 | อิลาโป (Ylapo)    | ~20 กะรัต         | ทองคำคุณภาพสูงสำหรับเครื่องประดับชนชั้นสูง            |
| 4 | กินูกูลัน         | ~22–24 กะรัต      | "เจ้าแห่งทองคำ" (Lord of Gold / Purified)             |
|   | (Guinogulan)      | (ทองคำบริสุทธิ์)  | ทองคำบริสุทธิ์สูงสุด ใช้สำหรับตีแผ่นทองคำเปลวและหน้ากาก|
+---+-------------------+-------------------+-------------------------------------------------------+
```

ในระดับสูงสุด **กินูกูลัน (*Guinogulan หรือ Ginugulan*)** มีความหมายตรงตัวว่า "ทองคำที่ผ่านการชำระให้บริสุทธิ์แล้ว" (*Purified Gold*) มีค่าความบริสุทธิ์สูงถึงประมาณ 22 ถึง 24 กะรัต (มากกว่า 90–95% Au) [20] ทองคำระดับนี้มีความอ่อนเหนียวสูงสุด (*High Malleability*) และปราศจากความกระด้างจากโลหะอื่น จึงเป็นเกรดทองคำชนิดเดียวที่ช่างทองสามารถนำมาตีแผ่เป็นแผ่นบางเฉียบระดับ 0.08 มิลลิเมตร หรือดุนนูนเป็นเม็ดจุดไข่ปลาโดยไม่ฉีกขาด [20] [24]

นอกจากนี้ การใช้ทองคำบริสุทธิ์ระดับ *กินูกูลัน* ยังมีผลลัพธ์โดยตรงต่อการคงสภาพของโบราณวัตถุในชั้นดินทางโบราณคดี เนื่องจากทองคำบริสุทธิ์ไม่ทำปฏิกิริยากับสารประกอบซัลไฟด์ คลอไรด์ หรือออกซิเจนในดินทรายชายฝั่งที่มีความเค็มสูง แผ่นทองคำปิดทวารจึงยังคงส่องประกายสีทองสดใสเฉกเช่นวันแรกที่ถูกวางลงในหลุมศพเมื่อกว่าหกร้อยปีก่อน [20] [22]

### 6. ความสัมพันธ์ข้ามภูมิภาค: แบบแผนร่วมระหว่างฟิลิปปินส์กับบอร์เนียวตะวันตกเฉียงใต้

มิติที่น่าตื่นเต้นที่สุดประการหนึ่งในการศึกษาสัณฐานวิทยาเชิงเปรียบเทียบคือ **ความเชื่อมโยงระดับภูมิภาค (Regional Interconnections)** ระหว่างหมู่เกาะฟิลิปปินส์กับเกาะบอร์เนียว [20]

ในงานวิจัยของทอม แฮร์ริสัน (*Tom Harrisson*) ค.ศ. 1968 อดีตภัณฑารักษ์พิพิธภัณฑ์ซาราวัก ได้บันทึกไว้ว่า เมื่อท่านได้เห็นภาพถ่ายชุดแผ่นทองคำปิดตา ปิดจมูก และปิดปาก จากหลุมศพคริสต์ศตวรรษที่ 14–15 ที่โอตอน จังหวัดอิโลอิโล ในบทความของอัลเฟรโด โรเซส (*Alfredo Roces*) ทำให้ท่านสามารถเข้าใจหน้าที่ของแผ่นทองคำบางรูปทรงปริศนาที่เคยขุดพบในแถบบอร์เนียวตะวันตกเฉียงใต้ (จาเวย์-เกอดง: *Jaong / Bongkissam, Santubong*) ได้ในทันที [20]

วิลเยกัสได้เน้นย้ำข้อสรุปทางโบราณคดีนี้ว่า [20]:

> "There is clear evidence that Southwestern Borneo and the Philippines shared a system of conventions for the funerary facial covers." [20]
> 
> *คำแปลสรุปความ:* "มีหลักฐานที่ชัดเจนอย่างยิ่งว่า ดินแดนบอร์เนียวตะวันตกเฉียงใต้และหมู่เกาะฟิลิปปินส์ใช้ระบบขนบธรรมเนียมและแบบแผนร่วมกันสำหรับการสร้างแผ่นปิดหน้าศพในพิธีกรรมความตาย" [20]

การค้นพบแผ่นทองคำปิดตาและปิดจมูกที่มีสัณฐานและเทคนิคการดุนนูนจุดไข่ปลาที่เหมือนกันแทบทุกประการ ทั้งในแถบแม่น้ำซาราวักของบอร์เนียวและในเกาะปาไนย์-มินดาเนาของฟิลิปปินส์ เป็นข้อพิสูจน์ที่ปฏิเสธไม่ได้ว่า ชุมชนชายฝั่งทะเลเหล่านี้มิได้อยู่อย่างโดดเดี่ยว หากแต่เชื่อมโยงกันอย่างแนบแน่นผ่าน **"เครือข่ายวัฒนธรรมทองคำข้ามทะเลลู่ซอน-ซูลู-บอร์เนียว" (Trans-maritime Gold Horizon)** ซึ่งผู้คน ช่างทอง ความเชื่อ และพิธีกรรมความตายได้ไหลเวียนไปมาหาสู่กันอย่างเสรีในยุคก่อนอาณานิคม [20] [26]

### 7. สรุปตอน 5.3 และบทบาทของการศึกษาเชิงมาตรวิทยา

การศึกษาสัณฐานวิทยาเชิงลึกเปรียบเทียบในตอนที่ 5.3 ได้แสดงให้เห็นว่า แผ่นทองคำปิดทวารในฟิลิปปินส์มีการจัดแบ่งออกเป็น 2 สกุลช่างหลัก: สกุลช่างดุนนูน-ฉลุลายของโอตอน ซึ่งมีมิติขนาดใหญ่และเน้นลวดลายโครงสร้างเพื่อความแข็งแกร่ง และสกุลช่างแผ่นบางเรียบขัดเงาของบูตูอันและเซบู ซึ่งเน้นความบางเฉียบสูงสุดและการสะท้อนแสงบริสุทธิ์ [20] [21] [22]

ทั้งสองสกุลช่างต่างใช้ทองคำเกรดสูงสุดคือ *กินูกูลัน* (22–24 กะรัต) และสะท้อนถึงแบบแผนทางพิธีกรรมร่วมกันที่แพร่กระจายกว้างขวางไปถึงบอร์เนียวตะวันตกเฉียงใต้ ข้อมูลเชิงสัณฐานวิทยาและเทคนิคเหล่านี้จะนำไปสู่การประมวลภาพรวมใน **ตอนที่ 5.4** ซึ่งจะรวบรวมคลังแผ่นทองคำปิดศพทั้งหมดที่เคยมีการค้นพบและบันทึกไว้ในพิพิธภัณฑสถานแห่งชาติและคอลเลกชันสถาบันต่างๆ ของฟิลิปปินส์อย่างเป็นระบบต่อไป [20] [21] [22]

## 5.4 คลังแผ่นทองปิดศพทั้งหมดที่พบในฟิลิปปินส์: การประมวลชิ้นงานทั้งหมดที่บันทึกในพิพิธภัณฑสถานแห่งชาติและคอลเลกชันสถาบัน (NMP, BSP, Ayala Museum)

### 1. บทนำและกรอบประวัติศาสตร์นิพนธ์: ภูมิทัศน์คลังโบราณวัตถุทองคำปิดศพในฟิลิปปินส์

การศึกษาวิจัยเชิงลึกว่าด้วยแผ่นทองคำปิดทวารบนใบหน้าผู้ตายในหมู่เกาะฟิลิปปินส์ จำเป็นต้องอาศัยการประมวลและทำบัญชีสำรวจคลังโบราณวัตถุ (*Corpus Census & Institutional Inventory*) ที่กระจัดกระจายอยู่ในความครอบครองของสถาบันระดับชาติ พิพิธภัณฑ์ของรัฐ และคอลเลกชันสาธารณะที่สำคัญ ในประวัติศาสตร์โบราณคดีฟิลิปปินส์ ชะตากรรมของโบราณวัตถุทองคำมักตกอยู่ท่ามกลางความตึงเครียดระหว่างการขุดค้นทางวิทยาศาสตร์อย่างเป็นระบบ (*Systematic Scientific Excavations*) กับการขุดค้นโดยบังเอิญหรือการลักลอบขุดเพื่อการค้าของเก่า (*Illicit Digging and Antiquities Market*) [27] [28]

ด้วยเหตุนี้ การจัดหมวดหมู่คลังแผ่นทองคำปิดศพในรายงานฉบับนี้จึงให้ความสำคัญสูงสุดแก่ชิ้นงานที่มี "ประวัติที่มาของหลักฐาน" (*Archaeological Provenance*) ชัดเจนและได้รับการบันทึกในระบบทะเบียนของรัฐ โดยเฉพาะอย่างยิ่งชิ้นงานที่ค้นพบในสภาพ *in situ* จากการขุดค้นของพิพิธภัณฑสถานแห่งชาติฟิลิปปินส์ (*National Museum of the Philippines - NMP*) ควบคู่ไปกับการวิเคราะห์ชิ้นงานระดับชิ้นเอกที่ได้รับการธำรงรักษาไว้ในคอลเลกชันเครื่องทองคำก่อนอาณานิคมของธนาคารกลางแห่งฟิลิปปินส์ (*Bangko Sentral ng Pilipinas - BSP*) และพิพิธภัณฑ์อายาลา (*Ayala Museum*) [28] [29] [30]

จากการศึกษาสังเคราะห์ของจอห์น กาย (*John Guy*) ภัณฑารักษ์อาวุโสแห่งพิพิธภัณฑ์ศิลปะเมโทรโพลิทัน (*Metropolitan Museum of Art*) ร่วมกับคณะผู้เชี่ยวชาญ ได้ยืนยันว่า [30]:

> "These earliest Philippine archaeological records make clear that gold was intimately associated with funerary practices. Gold was the favored material for dressing the dead with items of adornment. In addition, gold-sheet covers were placed over bodily orifices as part of the internment, a custom practiced throughout mainland and island Southeast Asia" [30]
> 
> *คำแปลสรุปความ:* "บันทึกทางโบราณคดีในยุคเริ่มแรกของฟิลิปปินส์เหล่านี้ทำให้ประจักษ์ชัดว่า ทองคำมีความผูกพันอย่างแนบแน่นยิ่งกับประเพณีพิธีศพ ทองคำเป็นวัสดุที่ได้รับความนิยมสูงสุดในการตกแต่งสรีระของผู้ตายด้วยเครื่องประดับ นอกจากนี้ แผ่นทองคำบางยังถูกนำมาจัดวางปิดทับทวารของร่างกายในฐานะส่วนหนึ่งของการฝังศพ อันเป็นธรรมเนียมที่ปฏิบัติสืบเนื่องกันทั่วทั้งเอเชียตะวันออกเฉียงใต้ภาคพื้นทวีปและภาคพื้นสมุทร" [30]

การรวบรวมคลังแผ่นทองคำปิดศพทั้งหมดที่ปรากฏหลักฐานในฟิลิปปินส์จึงช่วยให้เรามองเห็นภาพรวมของภูมิทัศน์ทางวัฒนธรรมและเครือข่ายของพิธีกรรมความตายได้อย่างครบถ้วนสมบูรณ์ [28] [30]

#### 2.1 หน้ากากทองคำโอตอน (Oton Gold Death Mask: OT-MD-39 และ OT-MF-40)
หน้ากากทองคำโอตอนได้รับการยกย่องเป็น **"สมบัติทางวัฒนธรรมแห่งชาติ" (National Cultural Treasure)** ภายใต้กฎหมายคุ้มครองมรดกแห่งชาติของฟิลิปปินส์ ค้นพบเมื่อวันที่ 5 มิถุนายน ค.ศ. 1967 ในระหว่างการขุดค้นอย่างเป็นระบบ ณ หลุมศพหมายเลข 6 ที่บารังเกย์ซานอันโตนิโอ (เดิมคือคาตากมาน) เทศบาลโอตอน จังหวัดอิโลอิโล โดยคณะนักมานุษยวิทยาและนักโบราณคดีของพิพิธภัณฑ์แห่งชาติ นำโดย อัลเฟรโด เอวานเจลิสตา (*Alfredo Evangelista*) และ เอฟ. ลันดา โฮคาโน (*F. Landa Jocano*) [28] [31]

วัตถุประกอบด้วย 2 ชิ้นส่วนหลักที่ขึ้นทะเบียนแยกชิ้น ได้แก่ แผ่นปิดตาคู่ (เลขทะเบียน **OT-MD-39**) ยาว 13.3 ซม. หนัก 3.16 กรัม และแผ่นปิดจมูก (เลขทะเบียน **OT-MF-40**) ยาว 16.3 ซม. หนัก 3.09 กรัม โบราณวัตถุชุดนี้ถูกนำไปจัดแสดงอย่างถาวร ณ ห้องจัดแสดงหน้ากากทองคำโอตอน (*Oton Gold Death Mask Gallery*) ที่พิพิธภัณฑสถานแห่งชาติสาขาภูมิภาควิสายาส์ตะวันตก ในเมืองอิโลอิโลซิตี และบางช่วงเวลาถูกหมุนเวียนมาจัดแสดง ณ พิพิธภัณฑ์แห่งชาติในกรุงมะนิลา [28] [31]

#### 2.2 ชุดแผ่นทองคำปิดทวารสามชิ้นและต่างหูปลาซา อินเดเปนเดนเซีย เมืองเซบู (NMP Cebu)
การค้นพบที่สำคัญยิ่งในรอบสองทศวรรษที่ผ่านมาคือ ชุดแผ่นทองคำปิดทวารจากแหล่งปลาซา อินเดเปนเดนเซีย ในใจกลางเมืองเซบู ซึ่งกู้คืนได้จากการขุดกู้ภัยทางโบราณคดีระหว่างโครงการก่อสร้างอุโมงค์ลอดเมืองเมื่อ ค.ศ. 2008 [29]

ในรายงานสถาบัน ค.ศ. 2022 และรายการภาพจัดแสดง ค.ศ. 2023 ของพิพิธภัณฑสถานแห่งชาติสาขาเซบู ระบุว่า โบราณวัตถุชุดนี้ประกอบด้วย:
- แผ่นปิดตาคู่ตัดเป็นรูปวงรีแยกชิ้นอิสระ ทำจากทองคำบางเรียบขัดเงา
- แผ่นปิดจมูกทรงสี่เหลี่ยมคางหมูเรียบ
- แผ่นปิดปากทรงแถบโค้งรับริมฝีปาก
- ต่างหูทองคำบริสุทธิ์จำนวนหนึ่งคู่ (*A Pair of Gold Earrings*) ที่วางอยู่ข้างกะโหลกศีรษะ [29] [32]

การที่สถาบันจัดแสดงวัตถุชุดนี้ร่วมกันในฐานะ "ชุดบริบทสมบูรณ์" (*Complete Intact Assemblage*) ถือเป็นการยืนยันทางโบราณคดีครั้งสำคัญว่า ชุมชนพาณิชย์เมืองท่าเซบูในคริสต์ศตวรรษที่ 14–15 มีธรรมเนียมการประดับศพด้วยแผ่นทองปิดทวารครบทั้งสามส่วนควบคู่ไปกับเครื่องประดับหูทองคำ [29] [32]

#### 2.3 กะโหลกศีรษะโบลิเนาและแผ่นทองตาลีไซ คาลาตากัน
นอกเหนือจากแผ่นปิดทวารใบหน้าโดยตรง พิพิธภัณฑสถานแห่งชาติยังครอบครอง "กะโหลกศีรษะโบลิเนา" จากจังหวัดปังกาซีนัน ซึ่งเป็นสมบัติวัฒนธรรมแห่งชาติที่สะท้อนถึงการตกแต่งฟันด้วยลวดลายเกล็ดปลาและฝังหมุดลวดทองคำบนฟันหน้า 12 ซี่ [33] ตลอดจนแผ่นทองคำเปลวปิดเบ้าตาขวาจากหลุมศพเด็กที่แหล่งตาลีไซ ในคาลาตากัน จังหวัดบาตังกัส ซึ่งขุดพบโดยโรเบิร์ต บ็อกซ์ [27] [34] หลักฐานเหล่านี้ตอกย้ำว่าประเพณีการใช้ทองคำกับสรีระผู้ตายมิได้จำกัดอยู่เฉพาะภาคกลางและภาคใต้ แต่ปรากฏร่องรอยในเกาะลูซอนด้วยเช่นกัน [27] [30]

### 3. คลังเครื่องทองคำก่อนอาณานิคมของธนาคารกลางแห่งฟิลิปปินส์ (BSP Prehispanic Gold Collection)

#### 3.1 แผ่นปิดตาสกุลช่างโอตอนในคอลเลกชัน BSP
ในหนังสือ *Ginto: In Search of Gold* วิลเยกัสได้ระบุอย่างชัดเจนว่า ในคอลเลกชันของ BSP มีแผ่นปิดตาทองคำที่มีลักษณะสัณฐาน เทคนิคการตอกดุนนูนจุดไข่ปลา และโครงสร้างสะพานเชื่อมระหว่างดวงตาที่เหมือนคลึงกับแผ่นปิดตาโอตอนของพิพิธภัณฑสถานแห่งชาติอย่างน่าอัศจรรย์ [27] การมีอยู่ของชิ้นงานคู่ขนานนี้ในคอลเลกชัน BSP ยืนยันว่าหน้ากากทองคำโอตอนมิใช่วัตถุชิ้นเดียวที่ถูกสร้างขึ้นอย่างโดดเดี่ยว (*Unique Isolated Artifact*) แต่เป็นตัวแทนของแบบแผนประเพณีทางช่างทองที่มีการผลิตซ้ำหลายชิ้นในสังคมชนชั้นนำแห่งเกาะปาไนย์ [27] [28]

#### 3.2 แผ่นทองคำปิดทวารและแถบคาดศีรษะจากขุมทรัพย์สุริเกาและบูตูอัน (Surigao & Butuan)
คอลเลกชันของ BSP ยังเป็นแหล่งเก็บรักษาโบราณวัตถุทองคำจำนวนมหาศาลจากแหล่งลุ่มน้ำอากูซันและขุมทรัพย์สุริเกา (*Surigao Treasure*) ซึ่งค้นพบโดยบังเอิญใน ค.ศ. 1981 วัตถุในกลุ่มนี้ประกอบด้วยแผ่นทองคำบางตัดเป็นรูปวงรีสำหรับปิดตา แผ่นสี่เหลี่ยมคางหมูสำหรับปิดจมูก และแผ่นปิดปากรูปแถบโค้ง ตลอดจน **แถบทองคำคาดหน้าผาก (Diadems / Headbands)** ซึ่งได้รับการตีแผ่เป็นแผ่นบางและตอกลายดุนนูนอย่างวิจิตร [27] [35]

วิลเยกัสชี้ให้เห็นว่า แถบทองคำคาดหน้าผากเหล่านี้ถูกใช้เป็นเครื่องประดับสรีระศพเพื่อรัดรอบกะโหลกศีรษะที่ผ่านการดัดให้ลาดแบน (*Tangad*) โดยปลายทั้งสองข้างมีรูเจาะสำหรับผูกเชือกเส้นใยพืชเพื่อยึดตรึงไว้ด้านหลังศีรษะอย่างแน่นหนา [27] [36]

#### 4.1 แหล่งมาซาโก บูตูอัน (Masago Site, Butuan): แหล่งที่มีการกำหนดอายุคาร์บอน-14
หนึ่งในหลักฐานที่มีค่ายิ่งในเชิงระเบียบวิธีวิจัย ซึ่งได้รับการบันทึกในบทความของจอห์น กาย ค.ศ. 2011 คือการค้นพบ **แผ่นปิดตาคู่ (Funerary Eye Covers)** ในหลุมฝังศพที่แหล่งมาซาโก (*Masago Site*) ในเขตบูตูอัน-อากูซัน [30]

ความสำคัญสูงสุดของแหล่งมาซาโกคือ การเป็นหลุมฝังศพที่มีบริบทการกำหนดอายุทางวิทยาศาสตร์ด้วยวิธีคาร์บอน-14 (*Radiocarbon Dating*) แผ่นปิดตาที่ค้นพบมีทั้งรูปทรงขนมเปียกปูน (*Lozenges*) และรูปจานกลม (*Discs*) ซึ่งพบร่วมกับเครื่องประดับทองคำชั้นสูง ได้แก่ สร้อยคอทองคำร้อยลูกปัดทรงฟันเฟือง (*Gear Beads*) และต่างหูทองคำ การค้นพบที่มีอายุวิทยาศาสตร์ยืนยันนี้ช่วยตอกย้ำว่า ประเพณีการวางแผ่นทองปิดตาดำรงอยู่อย่างมั่นคงในลุ่มน้ำบูตูอันตั้งแต่ยุคแห่งการค้าทางทะเลช่วงแรกเริ่ม [30] [35]

#### 4.2 นิทรรศการระดับนานาชาติ: Philippine Gold: Treasures of Forgotten Kingdoms (2015)
ใน ค.ศ. 2015 คลังเครื่องทองคำของพิพิธภัณฑ์อายาลาและ BSP ได้รับการคัดเลือกไปจัดแสดงในนิทรรศการระดับประวัติศาสตร์ ณ สถาบันสังคมแห่งเอเชีย (*Asia Society Museum*) ในนครนิวยอร์ก สหรัฐอเมริกา ภายใต้ชื่อนิทรรศการ *Philippine Gold: Treasures of Forgotten Kingdoms* [30]

ในสูจิบัตรและการวิเคราะห์เชิงวิชาการ จอห์น กาย ได้เชื่อมโยงชุดแผ่นทองคำปิดทวารและหน้ากากศพของฟิลิปปินส์เข้ากับเครือข่ายอารยธรรมเอเชีย โดยชี้ว่าประเพณีการปิดทวารด้วยแผ่นทองคำมีความสัมพันธ์เชิงมโนทัศน์กับการติดต่อแลกเปลี่ยนทางทะเลระหว่างฟิลิปปินส์กับอาณาจักรนานเยว่ (*Nanyue*) ในจีนตอนใต้ และอาณาจักรจัมปา (*Champa*) ในเวียดนามตอนกลาง ซึ่งต่างใช้แผ่นทองคำในการคุ้มครองวิญญาณผู้ตายเช่นเดียวกัน [30]

### 6. สรุปตอน 5.4 และภูมิทัศน์การอนุรักษ์มรดกทองคำ

การประมวลคลังแผ่นทองคำปิดศพทั้งหมดในฟิลิปปินส์ในตอนที่ 5.4 ได้พิสูจน์ให้เห็นอย่างเป็นวิทยาศาสตร์ว่า โบราณวัตถุแผ่นทองคำปิดทวารมิได้เป็นเรื่องเล่าปรัมปราหรือข้ออ้างลอยๆ หากแต่มีตัวตนทางกายภาพที่จัดเก็บ บันทึก และขึ้นทะเบียนอยู่ในสถาบันชั้นนำของรัฐและเอกชนอย่างมั่นคง 100% [27] [28] [29] [30]

ตั้งแต่หน้ากากทองคำโอตอนและกะโหลกศีรษะโบลิเนาที่เป็นสมบัติวัฒนธรรมแห่งชาติของ NMP ไปจนถึงชุดแผ่นทองเซบู แผ่นปิดตามาซาโกของพิพิธภัณฑ์อายาลา และคอลเลกชันเครื่องทองคำของ BSP โบราณวัตถุเหล่านี้ล้วนสะท้อนถึงเครือข่ายประเพณีพิธีศพที่มีเอกภาพร่วมกันข้ามหมู่เกาะ ข้อมูลสารระบบคลังวัตถุนี้จะนำไปสู่การวิเคราะห์ในเชิงทฤษฎีใน **ตอนที่ 5.5** ซึ่งจะตอบคำถามเชิงโครงสร้างว่า เหตุใดสังคมฟิลิปปินส์โบราณจึงเลือกใช้ "แผ่นปิดเฉพาะทวาร" (*Orifice Covers*) แทนที่จะสร้าง "หน้ากากเต็มใบหน้า" (*Full Face Masks*) เช่นเดียวกับอารยธรรมโบราณอื่นๆ ในโลก [27] [28] [30]

## 5.5 ความแตกต่างเชิงหน้าที่: แผ่นปิดเฉพาะทวาร (Orifice Covers) vs หน้ากากเต็มใบหน้า (Full Masks): เหตุผลที่ฟิลิปปินส์เลือกเน้นเฉพาะทวารเปิดของประสาทสัมผัส

### 1. บทนำและข้อถกเถียงเชิงทฤษฎี: มโนทัศน์ความตายระหว่างหน้ากากเต็มหน้ากับแผ่นปิดเฉพาะทวาร

ในการศึกษามานุษยวิทยาโบราณคดีเปรียบเทียบ คำถามเชิงโครงสร้างที่สำคัญที่สุดประการหนึ่งเกี่ยวกับวัฒนธรรมทองคำของฟิลิปปินส์ยุคก่อนอาณานิคมคือ: **เหตุใดชนชั้นนำในหมู่เกาะฟิลิปปินส์จึงไม่สร้าง "หน้ากากทองคำเต็มใบหน้า" (Full Anthropomorphic Masks) เฉกเช่นอารยธรรมโบราณอื่นๆ ในโลก แต่กลับเลือกใช้ "ชุดแผ่นทองคำปิดเฉพาะทวาร" (Selective Orifice Covers) อย่างเคร่งครัดและต่อเนื่องตลอดหลายศตวรรษ?** [37] [38]

ข้อถกเถียงนี้ได้รับการตั้งประเด็นไว้อย่างเฉียบคมโดยจอห์น มิกซิก (*John N. Miksic*) และได้รับการตอกย้ำในสารานุกรมศิลปะของศูนย์วัฒนธรรมแห่งฟิลิปปินส์ (*CCP Encyclopedia of Philippine Art*) โดยปูริสซีมา เบนิเตซ-โจฮันนอต (*Purissima Benitez-Johannot*) ซึ่งระบุว่า [37] [38]:

> "Because gold sheets sought to cover orifices that gold masks exposed, the two types may have represented differences in their notions of death (Miksic 2012, 252)." [37]
> 
> *คำแปลสรุปความ:* "เนื่องจากแผ่นทองคำมุ่งปิดทับทวารที่หน้ากากทองคำเปิดออก วัตถุทั้งสองประเภทจึงอาจเป็นตัวแทนของความแตกต่างในมโนทัศน์ว่าด้วยความตายของวัฒนธรรมผู้สร้าง" [37]

```
|         การเปรียบเทียบเชิงโครงสร้าง: หน้ากากเต็มใบหน้า vs แผ่นปิดเฉพาะทวาร                         |
+---+---------------------------------------------------+-------------------------------------------+
|   | 1. หน้ากากเต็มใบหน้า (Full Facial Masks)           | 2. แผ่นปิดเฉพาะทวาร (Orifice Covers)       |
+---+---------------------------------------------------+-------------------------------------------+
| 1 | ขอบเขต: คลุมปิดโครงหน้าและผิวหนังทั้งหมด 100%       | ขอบเขต: เจาะจงเฉพาะช่องเปิดของประสาทสัมผัส |
| 2 | ช่องทวาร: มักเจาะช่องเปิดว่างไว้ (Exposed Orifices)| ช่องทวาร: ปิดผนึกทวารมิดชิด (Sealed Orifices)|
| 3 | เจตจำนง: สร้างรูปเหมือนนิรันดร์ (Post-mortem Effigy)| เจตจำนง: กักกันพลังวิญญาณ / สกัดผีร้าย    |
| 4 | สรีรวิทยา: บดบังรูปพรรณเดิมของกะโหลกศีรษะ         | สรีรวิทยา: เปิดเผยโครงกะโหลก Tangad-ฟัน Bansil|
| 5 | ปริมาณทอง: ใช้ทองคำมหาศาล (200–500 กรัมขึ้นไป)   | ปริมาณทอง: ใช้ทองคำพอเหมาะ (3–7 กรัมต่อชุด)|
| 6 | บริบทสังคม: รัฐจักรวรรดิรวมศูนย์ (Imperial States)| บริบทสังคม: ชุมชนเมืองท่า-ดาตู (Datu Polity)|
+---+---------------------------------------------------+-------------------------------------------+
```

ในอารยธรรมที่มีการใช้หน้ากากเต็มหน้า เช่น หน้ากากทองคำแห่งไมซีเน (*Mycenae*) ในกรีซโบราณ, หน้ากากฟาโรห์ตุตันคาเมนในอียิปต์, หรือหน้ากากทองคำราชวงศ์เหลียว (*Liao Dynasty*) ในจีนตอนเหนือ หน้ากากทำหน้าที่เป็น "ใบหน้าจำลองใหม่" (*Surrogate Face / Idealized Portrait*) ที่สร้างภาพลักษณ์อมตะของผู้ตายขึ้นมาทดแทนเนื้อหนังที่เน่าเปื่อย โดยดวงตา รูจมูก และริมฝีปากของหน้ากากมักถูกเปิดช่องว่างไว้เพื่อให้วิญญาณสามารถมองเห็น หายใจ และรับเครื่องเซ่นไหว้นอกโลงศพได้ [37] [39]

ทว่าในหมู่เกาะฟิลิปปินส์ ช่างทองและผู้นำพิธีกรรมกลับทำในสิ่งตรงกันข้ามอย่างสิ้นเชิง: พวกเขาปล่อยให้โครงหน้าตามธรรมชาติเปิดเผย แต่กลับนำแผ่นทองคำบางมาวางปิดทับเบ้าตา สันจมูก และริมฝีปากจนมิดชิด การเลือกปฏิบัติการเช่นนี้มิใช่ข้อจำกัดทางเทคโนโลยี หากแต่สะท้อนถึงปรัชญาจักรวาลวิทยา สรีรวิทยา และเศรษฐศาสตร์การเมืองอันเป็นเอกลักษณ์ของสังคมออสโตรนีเชียน [37] [38] [40]

### 2. สรีรวิทยาและจักรวาลวิทยาแห่งทวารประสาทสัมผัส (Cosmology of Sensory Orifices)

ในโลกทัศน์วิญญาณนิยม (*Animism*) ของชาววิสายาส์และกลุ่มชนออสโตรนีเชียนโบราณ ร่างกายของมนุษย์มิได้เป็นเอกภาพที่ปิดสนิท หากแต่มี **"ช่องเปิดหรือทวารทางกายวิภาค" (Bodily Orifices / Apertures)** ซึ่งทำหน้าที่เป็นสะพานเชื่อมระหว่างโลกภายใน (*Internal Realm*) กับโลกภายนอก (*External Realm*) [40] [41]:

```
+---------------------------------------------------------------------------------------------------+
|               พลวัตของจิตวิญญาณและช่องทวารในจักรวาลวิทยาวิสายาส์โบราณ                             |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|                       [ จิตวิญญาณพลังชีวิต: ดุงกัน / กาลัก (Dungan / Kalag) ]                      |
|                                                  |                                                |
|                               ( เปล่งประกายและสถิตอยู่ภายในร่างกาย )                              |
|                                                  |                                                |
|                                                  v                                                |
|           +---------------------------------------------------------------------+                 |
|           |       ช่องทวารประสาทสัมผัสบนใบหน้า (Facial Sensory Orifices)         |                 |
|           |       1. เบ้าตา (Eyes)   2. รูจมูก (Nostrils)   3. ช่องปาก (Mouth)    |                 |
|           +---------------------------------------------------------------------+                 |
|                      ^                                                   |                        |
|   ( ทางเข้าของวิญญาณร้าย )                                        ( ทางออกของพลังชีวิต )          |
|                      |                                                   v                        |
|       [ ผีร้าย / ปีศาจรังควานศพ ]                               [ ภาวะเสื่อมสลาย / พลัดหลง ]       |
|       ( Pusung, Yawa, Mahikawon )                               ( Uncontrolled Wandering )        |
|                                                                                                   |
|      * ทางออกทางพิธีกรรม: ปิดผนึกทวารทั้งสามด้วย "แผ่นทองคำบริสุทธิ์" (Gold Orifice Plaque)         |
|        เพื่อกักกัน ดุงกัน ให้อยู่ในความสงบ และสกัดกั้น ผีร้าย มิให้แทรกซึมเข้าสู่ซากศพ             |
+---------------------------------------------------------------------------------------------------+
```

#### 2.1 มโนทัศน์พลังชีวิต: ดุงกัน (Dungan) และ กาลัก (Kalag)
ตามการศึกษาชาติพันธุ์วรรณนาของวิลเลียม เฮนรี สก็อตต์ (*William Henry Scott*) และ เอฟ. ลันดา โฮคาโน (*F. Landa Jocano*) ชาววิสายาส์เชื่อว่ามนุษย์มีจิตวิญญาณสำคัญ 2 ระดับ [40] [42]:
1. **ดุงกัน (*Dungan*):** คือพลังชีวิต สติปัญญา สุขภาพ และเกียรติยศส่วนบุคคล ซึ่งอาจหลุดลอยออกจากร่างได้ในยามเจ็บป่วย ตกใจ หรือเมื่อนอนหลับฝัน
2. **กาลัก (*Kalag*):** คือวิญญาณแท้จริงที่จะแยกตัวออกจากร่างเมื่อความตายมาเยือน เพื่อเดินทางข้ามแม่น้ำและท้องทะเลไปสู่ดินแดนแห่งบรรพชน [40] [42]

ในวาระแห่งความตาย ช่องทวารเปิดของประสาทสัมผัสทั้งสาม—ดวงตา จมูก และปาก—จะกลายเป็นจุดอันตรายสูงสุด หากทวารเหล่านี้เปิดทิ้งไว้ *ดุงกัน* หรือ *กาลัก* ของผู้ตายอาจพลัดหลง สับสน หรือไม่ยอมเดินทางสู่ปรโลก และอาจหวนกลับมาหลอกหลอนคนเป็นในชุมชน [40] [42]

#### 2.2 ภัยคุกคามจากภูตผีปีศาจ: ปูซุง (Pusung), ยาวา (Yawa) และ มาฮิกาวอน (Mahikawon)
ในขณะเดียวกัน ช่องเปิดเหล่านี้ยังเป็นช่องโหว่ทางกายภาพที่ภูตผีปีศาจและวิญญาณชั่วร้าย ซึ่งในภาษาพื้นเมืองเรียกว่า *ปูซุง* (*Pusung*), *ยาวา* (*Yawa*), หรือ *มาฮิกาวอน* (*Mahikawon*) คอยจ้องมองเพื่อฉวยโอกาสแทรกซึมเข้าไปสิงสู่ในซากศพ [40] [42]

โฮคาโนได้บันทึกความเชื่อดั้งเดิมของชาวซูโลดในเกาะปาไนย์ไว้ว่า ริมฝั่งแม่น้ำมูรูบูรู (*Muruburu River*) ซึ่งเป็นทางผ่านสู่อาณาจักรคนตาย เต็มไปด้วยผีร้าย *มาฮิกาวอน* ที่คอยดักกินวิญญาณและกลืนกินซากศพของผู้มาใหม่ [42]

พิพิธภัณฑสถานแห่งชาติฟิลิปปินส์ได้สรุปหลักคิดนี้ไว้อย่างกระชับในนิทรรศการหน้ากากทองคำโอตอนว่า [41]:

> "The early Bisayans believed that the gold coverings in the eyes, nose and mouth protect the dead from evil spirits who want to occupy the dead body." [41]
> 
> *คำแปลสรุปความ:* "ชาววิสายาส์ในยุคแรกเริ่มเชื่อว่า การนำแผ่นทองคำมาปิดคลุมดวงตา จมูก และปาก จะช่วยปกป้องผู้ตายจากวิญญาณชั่วร้ายที่ต้องการเข้ามาสิงสู่และครอบงำซากศพ" [41]

ทองคำซึ่งเป็นโลหะบริสุทธิ์ที่มีแสงสะท้อนเจิดจ้าและไม่มีวันเน่าเปื่อย จึงทำหน้าที่เป็น "ตราประทับศักดิ์สิทธิ์" (*Sacred Seal*) ที่ปิดกั้นทางเข้าออกทางกายวิภาคทั้งหมด เพื่อสกัดกั้นภูตผีปีศาจภายนอกและกักเก็บความบริสุทธิ์ของวิญญาณภายในไว้อย่างปลอดภัย [37] [40] [41]

### 3. การเปิดเผยรูปพรรณสรีระเดิมของกะโหลกศีรษะ (Preserving the Somatic Signature: Tangad & Bansil)

เหตุผลสำคัญประการที่สองที่อธิบายว่าเหตุใดฟิลิปปินส์จึงไม่ใช้หน้ากากเต็มหน้า เกี่ยวข้องโดยตรงกับ **การเปิดเผยและธำรงไว้ซึ่งสรีรดัดแปลงที่เป็นอัตลักษณ์เฉพาะของชนชั้นนำ (Somatic Inalienable Capital)** [43] [44]:

```
+---------------------------------------------------------------------------------------------------+
|               ปฏิสัมพันธ์ระหว่างสรีรดัดแปลงกับแผ่นทองคำปิดทวารเฉพาะจุด                            |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|             [ สรีรดัดแปลงกะโหลกลาดแบน: ตังอัด (Tangad) ]                                          |
|             - หน้าผากลาดเอียงไปด้านหลัง ขยายความกว้างกะโหลกออกด้านข้าง                             |
|             - มองเห็นได้ชัดเจน 100% เพราะไม่มีหน้ากากเต็มหน้ามาปิดทับ                              |
|                                                                                                   |
|                                           |                                                       |
|                                           v                                                       |
|                                                                                                   |
|             [ แผ่นทองคำปิดทวารเฉพาะจุด (Orifice Plaques) ]                                        |
|             - แผ่นปิดตา (Ocular) -> เน้นกรอบเบ้าตาใต้หน้าผากลาดแบน                               |
|             - แผ่นปิดจมูก (Nasal) -> ทอดตัวตามแนวดั้งกระดูกใบหน้า                                 |
|             - แผ่นปิดปาก (Oral) -> ประกบทับรอยแยกลิปสติก                                          |
|                                                                                                   |
|                                           |                                                       |
|                                           v                                                       |
|                                                                                                   |
|             [ สรีรดัดแปลงทันตกรรมฝังทอง: ปูซัด / บันซิล (Pusad / Bansil) ]                         |
|             - รอยยิ้มฟันดำและหมุดทองคำฝังแน่นในเนื้อฟันหน้าตัด                                     |
|             - เป็นเครื่องหมาย "ชนชั้นนำประเภทที่ 1" ที่ซ่อนอยู่ใต้แผ่นปิดปาก                       |
+---------------------------------------------------------------------------------------------------+
```

#### 3.1 การไม่บดบังความงามเชิงสถานะของกะโหลก ตังอัด (Tangad)
ดังที่ได้วิเคราะห์ในตอนที่ 4.4 ชนชั้นนำวิสายาส์และฟิลิปปินส์โบราณให้คุณค่าสูงสุดแก่การดัดรัดกะโหลกศีรษะให้ลาดแบนตั้งแต่แรกเกิด (*Tangad / Artificial Cranial Modification*) กะโหลกศีรษะที่มีหน้าผากลาดเอียงไปด้านหลังและกระดูกท้ายทอยแบนราบคือ "เครื่องหมายแห่งสายเลือดและเกียรติยศสูงสุด" ที่แยกแยะชนชั้นปกครองออกจากสามัญชนและทาส [44]

หากผู้ประกอบพิธีศพนำหน้ากากทองคำเต็มใบหน้ามาสวมครอบทับ โครงสร้างกะโหลกศีรษะลาดแบนอันเป็นความภาคภูมิใจตลอดชีวิตจะถูกบดบังจนมองไม่เห็น แต่การใช้ **แผ่นปิดเฉพาะทวาร (Orifice Covers)** ทำให้โครงร่างกะโหลกศีรษะ *Tangad* สันกระดูกโหนกแก้ม และแนวกรามอันสง่างามยังคงปรากฏเด่นชัดต่อสายตาของผู้เข้าร่วมพิธีศพ แผ่นทองคำจึงทำหน้าที่เพียงเน้นจุดสำคัญทางกายวิภาค โดยไม่ทำลายรูปพรรณสรีระเดิมของผู้ตาย [37] [44]

#### 3.2 ความสอดประสานกับศิลปะฟันฝังทอง บันซิล (Bansil)
ในทำนองเดียวกัน ชนชั้นนำผู้ล่วงลับมักผ่านการตกแต่งฟันด้วยการเจียร ตะไบ ย้อมสีดำ และฝังหมุดทองคำ *Bansil* (ตอนที่ 4.5) ซึ่งเป็น "ชนชั้นนำประเภทที่ 1" ตามทฤษฎีของบาร์เรตโต-เตโซโร [43]

การจัดวางแผ่นทองคำปิดปากภายนอกทับลงบนฟันที่มีหมุดทองคำฝังอยู่ภายใน เป็นการสร้างความสอดประสานระหว่าง "ทองคำที่เป็นเนื้อเดียวกับร่างกาย" กับ "ทองคำที่เป็นเครื่องประกอบพิธีกรรม" หากใช้หน้ากากเต็มหน้า การเชื่อมต่อเชิงสัญลักษณ์ระหว่างฟันทองคำกับแผ่นปิดปากจะสูญเสียความหมายไป การใช้แผ่นปิดเฉพาะปากจึงเป็นการตอกย้ำว่า ร่างกายนี้คือภาชนะทองคำทั้งภายในและภายนอก [37] [43]

### 4. มิติเศรษฐศาสตร์การเมือง: ประสิทธิภาพในการกระจายทองคำ (Political Economy of Funerary Gold)

นอกจากเหตุผลด้านจักรวาลวิทยาและสรีรวิทยาแล้ว การเลือกใช้แผ่นปิดเฉพาะทวารยังสามารถอธิบายได้ด้วย **มิติเศรษฐศาสตร์การเมือง (Political Economy of Gold)** ของสังคมเอเชียตะวันออกเฉียงใต้ภาคพื้นสมุทร [37] [40] [45]:

```
+---------------------------------------------------------------------------------------------------+
|               การวิเคราะห์เชิงเปรียบเทียบปริมาณและเศรษฐศาสตร์ของทองคำในพิธีศพ                    |
+---+---------------------------------------------------+-------------------------------------------+
|   | หน้ากากทองคำเต็มใบหน้า (Full Face Masks)           | แผ่นทองคำปิดเฉพาะทวาร (Orifice Covers)     |
+---+---------------------------------------------------+-------------------------------------------+
| 1 | น้ำหนักทองคำ: 200 ถึง 1,000 กรัมต่อชิ้น            | น้ำหนักทองคำ: 3.5 ถึง 7.0 กรัมต่อชุด      |
| 2 | โครงสร้างสังคม: รัฐจักรวรรดิรวมศูนย์ (Autocracy)   | โครงสร้างสังคม: เครือข่ายดาตู (Datu Polities) |
| 3 | การถือครอง: ผูกขาดโดยองค์จักรพรรดิหรือฟาโรห์       | การถือครอง: กระจายตัวในหมู่ชนชั้นนำหลายตระกูล|
| 4 | ผลกระทบเศรษฐกิจ: ดูดซับทองคำออกจากระบบมหาศาล       | ผลกระทบเศรษฐกิจ: รักษาสมดุลทุนหมุนเวียน   |
+---+---------------------------------------------------+-------------------------------------------+
```

#### 4.1 โครงสร้างการเมืองแบบดาตู (Datu Polity) และการกระจายทรัพยากร
สังคมฟิลิปปินส์ยุคก่อนอาณานิคมมิได้เป็นรัฐจักรวรรดิที่มีกษัตริย์ทรงอำนาจเบ็ดเสร็จเพียงพระองค์เดียวที่สามารถระดมทองคำนับสิบกิโลกรัมมาหล่อเป็นหน้ากากศพของตนเอง หากแต่เป็นสังคมที่มีการจัดระเบียบทางการเมืองแบบ **เครือข่ายบารังเกย์และดาตู (Barangay and Datu Alliances)** ซึ่งประกอบด้วยผู้นำชุมชนหลายร้อยคนที่แข่งขันและสร้างพันธมิตรระหว่างกัน [40] [45]

ในระบบเศรษฐกิจการเมืองเช่นนี้ ชนชั้นนำจำเป็นต้องรักษาสมดุลระหว่างการนำทองคำไปใช้เป็นเครื่องอุทิศศพส่วนบุคคล กับการเก็บสำรองทองคำไว้เพื่อใช้ในการแลกเปลี่ยนสินค้าต่างประเทศ การสร้างพันธมิตรทางการเมือง และการจัดงานเลี้ยงแจกจ่ายอาหารแก่ผู้ติดตาม (*Feasting and Gifting*) [45]

#### 4.2 ความคุ้มค่าทางพิธีกรรม (Ritual Efficiency)
การใช้แผ่นปิดเฉพาะทวารที่มีน้ำหนักทองคำรวมเพียง **3.5 ถึง 7.0 กรัม** ต่อชุด (ดังที่ตรวจวัดได้จากโอตอนและเซบู) เป็นทางออกทางวัฒนธรรมที่ชาญฉลาดยิ่ง:
- ผู้ตายได้รับการยกย่องสูงสุดด้วยการประดับทองคำแท้บริสุทธิ์ (*Guinogulan*) ครบทุกทวารประสาทสัมผัสตามกฎจักรวาลวิทยา
- ครอบครัวและสายตระกูลไม่ต้องสูญเสียทองคำจำนวนมหาศาลไปกับการสร้างหน้ากากขนาดใหญ่ ซึ่งจะทำให้สูญเสียสถานะความมั่งคั่งทางเศรษฐกิจในโลกคนเป็น
- ช่วยให้ตระกูลชนชั้นนำจำนวนมากในเครือข่ายทะเลวิสายาส์และมินดาเนาสามารถเข้าถึงและประกอบพิธีศพด้วยทองคำได้พร้อมๆ กัน โดยไม่สร้างวิกฤตการขาดแคลนทองคำในระบบการค้า [37] [40] [45]

### 5. สรุปภาพรวมของบทที่ 5 (Chapter 5 Grand Synthesis)

การศึกษาสังเคราะห์ในบทที่ 5 ได้คลี่คลายภาพรวมของแผ่นทองคำปิดทวารบนใบหน้าผู้ตายในหมู่เกาะฟิลิปปินส์อย่างลึกซึ้ง ครอบคลุมทั้งมิติกายวิภาคศาสตร์ เทคโนโลยีช่างทอง และจักรวาลวิทยา โดยสามารถสรุปข้อค้นพบแกนกลางได้ 5 ประการสำคัญ:

1. **ประเภทวิทยาอันเป็นเอกภาพ (5.1):** โบราณวัตถุในฟิลิปปินส์จัดอยู่ในกลุ่ม "แผ่นทองปิดทวารเฉพาะจุด" (*Orifice Covers*) ประกอบด้วยแผ่นปิดตาคู่ แผ่นปิดจมูก และแผ่นปิดปาก พร้อมด้วยเครื่องประดับศีรษะและต่างหูทองคำ [37] [38] [39]
2. **กายวิภาคศาสตร์การจัดวางที่ประณีต (5.2):** มิติความยาวของแผ่นปิดตาที่พาดเลยเบ้าตาสู่โหนกแก้ม ความยาว 16.3 ซม. ของแผ่นปิดจมูกโอตอนที่เชื่อมหน้าผากถึงปาก และลำดับการซ้อนทับที่แผ่นปิดตาวางทับแผ่นปิดจมูก ล้วนสะท้อนถึงการออกแบบที่สอดรับกับสรีระจริงของกะโหลกศีรษะมนุษย์ [37] [44]
3. **ทวิภาวะเชิงสกุลช่างทอง (5.3):** การดำรงอยู่คู่ขนานระหว่างสกุลช่างโอตอน (ดุนนูนจุดไข่ปลาและฉลุรูตาดำ) กับสกุลช่างบูตูอัน-เซบู (ตีแผ่นบางเรียบ 0.08 มม. ขัดเงาดั่งกระจก) ซึ่งต่างใช้ทองคำบริสุทธิ์ระดับ *กินูกูลัน* และเชื่อมโยงไปถึงบอร์เนียวตะวันตกเฉียงใต้ [37] [39]
4. **ความมั่นคงของคลังหลักฐานสถาบัน (5.4):** โบราณวัตถุทั้งหมดมีตัวตนทางกายภาพและได้รับการขึ้นทะเบียนในพิพิธภัณฑสถานแห่งชาติ (NMP), ธนาคารกลางแห่งฟิลิปปินส์ (BSP), และพิพิธภัณฑ์อายาลาอย่างเป็นวิทยาศาสตร์ [38] [39] [40]
5. **ปรัชญาแห่งการปิดทวารและเปิดเผยสรีระ (5.5):** ฟิลิปปินส์เลือกใช้แผ่นปิดเฉพาะทวารแทนหน้ากากเต็มหน้า เพื่อกักกันพลังวิญญาณ *ดุงกัน* สกัดกั้นภูตผีปีศาจ *ยาวา* ขณะเดียวกันก็เปิดเผยรูปพรรณกะโหลกลาดแบน *Tangad* และฟันฝังทอง *Bansil* ตลอดจนสอดรับกับเศรษฐศาสตร์การเมืองของสังคมดาตู [37] [40] [43]

หลักฐานเครื่องทองคำปิดทวารเหล่านี้มิได้ปรากฏอยู่อย่างโดดเดี่ยวในหลุมฝังศพ หากแต่ถูกฝังเคียงคู่กับโบราณวัตถุต่างประเทศจำนวนมหาศาล โดยเฉพาะอย่างยิ่งเครื่องถ้วยชามเคลือบจีนและเอเชีย ซึ่งเป็นประเด็นที่ **บทที่ 6** จะดำเนินการวิเคราะห์อย่างละเอียดในฐานะ "วัฒนธรรมวัตถุร่วมสุสาน" ต่อไป [37] [39] [40]
