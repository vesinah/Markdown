# บทที่ 5: กายวิภาคและการจัดวางแผ่นทองปิดทวารบนใบหน้าผู้ตาย

## 5.5 ความแตกต่างเชิงหน้าที่: แผ่นปิดเฉพาะทวาร (Orifice Covers) vs หน้ากากเต็มใบหน้า (Full Masks): เหตุผลที่ฟิลิปปินส์เลือกเน้นเฉพาะทวารเปิดของประสาทสัมผัส

### 1. บทนำและข้อถกเถียงเชิงทฤษฎี: มโนทัศน์ความตายระหว่างหน้ากากเต็มหน้ากับแผ่นปิดเฉพาะทวาร

ในการศึกษามานุษยวิทยาโบราณคดีเปรียบเทียบ คำถามเชิงโครงสร้างที่สำคัญที่สุดประการหนึ่งเกี่ยวกับวัฒนธรรมทองคำของฟิลิปปินส์ยุคก่อนอาณานิคมคือ: **เหตุใดชนชั้นนำในหมู่เกาะฟิลิปปินส์จึงไม่สร้าง "หน้ากากทองคำเต็มใบหน้า" (Full Anthropomorphic Masks) เฉกเช่นอารยธรรมโบราณอื่นๆ ในโลก แต่กลับเลือกใช้ "ชุดแผ่นทองคำปิดเฉพาะทวาร" (Selective Orifice Covers) อย่างเคร่งครัดและต่อเนื่องตลอดหลายศตวรรษ?** [1] [2]

ข้อถกเถียงนี้ได้รับการตั้งประเด็นไว้อย่างเฉียบคมโดยจอห์น มิกซิก (*John N. Miksic*) และได้รับการตอกย้ำในสารานุกรมศิลปะของศูนย์วัฒนธรรมแห่งฟิลิปปินส์ (*CCP Encyclopedia of Philippine Art*) โดยปูริสซีมา เบนิเตซ-โจฮันนอต (*Purissima Benitez-Johannot*) ซึ่งระบุว่า [1] [2]:

> "Because gold sheets sought to cover orifices that gold masks exposed, the two types may have represented differences in their notions of death (Miksic 2012, 252)." [1]
> 
> *คำแปลสรุปความ:* "เนื่องจากแผ่นทองคำมุ่งปิดทับทวารที่หน้ากากทองคำเปิดออก วัตถุทั้งสองประเภทจึงอาจเป็นตัวแทนของความแตกต่างในมโนทัศน์ว่าด้วยความตายของวัฒนธรรมผู้สร้าง" [1]

```
+---------------------------------------------------------------------------------------------------+
|         การเปรียบเทียบเชิงโครงสร้าง: หน้ากากเต็มใบหน้า vs แผ่นปิดเฉพาะทวาร                         |
+---+---------------------------------------------------+-------------------------------------------+
|   | 1. หน้ากากเต็มใบหน้า (Full Facial Masks)           | 2. แผ่นปิดเฉพาะทวาร (Orifice Covers)       |
+---+---------------------------------------------------+-------------------------------------------+
| 1 | ขอบเขต: คลุมปิดโครงหน้าและผิวหนังทั้งหมด 100%       | ขอบเขต: เจาะจงเฉพาะช่องเปิดของประสาทสัมผัส |
| 2 | ช่องทวาร: มักเจาะช่องเปิดว่างไว้ (Exposed Orifices)| ช่องทวาร: ปิดผนึกทวารมิดชิด (Sealed Orifices)|
| 3 | เจตจำนง: สร้างรูปเหมือนนิรันดร์ (Post-mortem Effigy)| เจตจำนง: กักกันพลังวิญญาณ / สกัดผีร้าย    |
| 4 | สรีรวิทยา: บดบังรูปพรรณเดิมของกะโหลกศีรษะ         | สรีรวิทยา: เปิดเผยโครงกะโหลก Tangad-ฟัน Bansil|
| 5 | ปริมาณทอง: ใช้ทองคำมหาศาล (200–500 กรัมขึ้นไป)   | ปริมาณทอง: ใช้ทองคำพอเหมาะ (3–7 กรัมต่อชุด)|
| 6 | บริบทสังคม: รัฐจักรวรรดิรวมศูนย์ (Imperial States)| บริบทสังคม: ชุมชนเมืองท่า-ดาตู (Datu Polity)|
+---+---------------------------------------------------+-------------------------------------------+
```

ในอารยธรรมที่มีการใช้หน้ากากเต็มหน้า เช่น หน้ากากทองคำแห่งไมซีเน (*Mycenae*) ในกรีซโบราณ, หน้ากากฟาโรห์ตุตันคาเมนในอียิปต์, หรือหน้ากากทองคำราชวงศ์เหลียว (*Liao Dynasty*) ในจีนตอนเหนือ หน้ากากทำหน้าที่เป็น "ใบหน้าจำลองใหม่" (*Surrogate Face / Idealized Portrait*) ที่สร้างภาพลักษณ์อมตะของผู้ตายขึ้นมาทดแทนเนื้อหนังที่เน่าเปื่อย โดยดวงตา รูจมูก และริมฝีปากของหน้ากากมักถูกเปิดช่องว่างไว้เพื่อให้วิญญาณสามารถมองเห็น หายใจ และรับเครื่องเซ่นไหว้นอกโลงศพได้ [1] [3]

ทว่าในหมู่เกาะฟิลิปปินส์ ช่างทองและผู้นำพิธีกรรมกลับทำในสิ่งตรงกันข้ามอย่างสิ้นเชิง: พวกเขาปล่อยให้โครงหน้าตามธรรมชาติเปิดเผย แต่กลับนำแผ่นทองคำบางมาวางปิดทับเบ้าตา สันจมูก และริมฝีปากจนมิดชิด การเลือกปฏิบัติการเช่นนี้มิใช่ข้อจำกัดทางเทคโนโลยี หากแต่สะท้อนถึงปรัชญาจักรวาลวิทยา สรีรวิทยา และเศรษฐศาสตร์การเมืองอันเป็นเอกลักษณ์ของสังคมออสโตรนีเชียน [1] [2] [4]

### 2. สรีรวิทยาและจักรวาลวิทยาแห่งทวารประสาทสัมผัส (Cosmology of Sensory Orifices)

ในโลกทัศน์วิญญาณนิยม (*Animism*) ของชาววิสายาส์และกลุ่มชนออสโตรนีเชียนโบราณ ร่างกายของมนุษย์มิได้เป็นเอกภาพที่ปิดสนิท หากแต่มี **"ช่องเปิดหรือทวารทางกายวิภาค" (Bodily Orifices / Apertures)** ซึ่งทำหน้าที่เป็นสะพานเชื่อมระหว่างโลกภายใน (*Internal Realm*) กับโลกภายนอก (*External Realm*) [4] [5]:

```
+---------------------------------------------------------------------------------------------------+
|               พลวัตของจิตวิญญาณและช่องทวารในจักรวาลวิทยาวิสายาส์โบราณ                             |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|                       [ จิตวิญญาณพลังชีวิต: ดุงกัน / กาลัก (Dungan / Kalag) ]                      |
|                                                  |                                                |
|                               ( เปล่งประกายและสถิตอยู่ภายในร่างกาย )                              |
|                                                  |                                                |
|                                                  v                                                |
|           +---------------------------------------------------------------------+                 |
|           |       ช่องทวารประสาทสัมผัสบนใบหน้า (Facial Sensory Orifices)         |                 |
|           |       1. เบ้าตา (Eyes)   2. รูจมูก (Nostrils)   3. ช่องปาก (Mouth)    |                 |
|           +---------------------------------------------------------------------+                 |
|                      ^                                                   |                        |
|   ( ทางเข้าของวิญญาณร้าย )                                        ( ทางออกของพลังชีวิต )          |
|                      |                                                   v                        |
|       [ ผีร้าย / ปีศาจรังควานศพ ]                               [ ภาวะเสื่อมสลาย / พลัดหลง ]       |
|       ( Pusung, Yawa, Mahikawon )                               ( Uncontrolled Wandering )        |
|                                                                                                   |
|      * ทางออกทางพิธีกรรม: ปิดผนึกทวารทั้งสามด้วย "แผ่นทองคำบริสุทธิ์" (Gold Orifice Plaque)         |
|        เพื่อกักกัน ดุงกัน ให้อยู่ในความสงบ และสกัดกั้น ผีร้าย มิให้แทรกซึมเข้าสู่ซากศพ             |
+---------------------------------------------------------------------------------------------------+
```

#### 2.1 มโนทัศน์พลังชีวิต: ดุงกัน (Dungan) และ กาลัก (Kalag)
ตามการศึกษาชาติพันธุ์วรรณนาของวิลเลียม เฮนรี สก็อตต์ (*William Henry Scott*) และ เอฟ. ลันดา โฮคาโน (*F. Landa Jocano*) ชาววิสายาส์เชื่อว่ามนุษย์มีจิตวิญญาณสำคัญ 2 ระดับ [4] [6]:
1. **ดุงกัน (*Dungan*):** คือพลังชีวิต สติปัญญา สุขภาพ และเกียรติยศส่วนบุคคล ซึ่งอาจหลุดลอยออกจากร่างได้ในยามเจ็บป่วย ตกใจ หรือเมื่อนอนหลับฝัน
2. **กาลัก (*Kalag*):** คือวิญญาณแท้จริงที่จะแยกตัวออกจากร่างเมื่อความตายมาเยือน เพื่อเดินทางข้ามแม่น้ำและท้องทะเลไปสู่ดินแดนแห่งบรรพชน [4] [6]

ในวาระแห่งความตาย ช่องทวารเปิดของประสาทสัมผัสทั้งสาม—ดวงตา จมูก และปาก—จะกลายเป็นจุดอันตรายสูงสุด หากทวารเหล่านี้เปิดทิ้งไว้ *ดุงกัน* หรือ *กาลัก* ของผู้ตายอาจพลัดหลง สับสน หรือไม่ยอมเดินทางสู่ปรโลก และอาจหวนกลับมาหลอกหลอนคนเป็นในชุมชน [4] [6]

#### 2.2 ภัยคุกคามจากภูตผีปีศาจ: ปูซุง (Pusung), ยาวา (Yawa) และ มาฮิกาวอน (Mahikawon)
ในขณะเดียวกัน ช่องเปิดเหล่านี้ยังเป็นช่องโหว่ทางกายภาพที่ภูตผีปีศาจและวิญญาณชั่วร้าย ซึ่งในภาษาพื้นเมืองเรียกว่า *ปูซุง* (*Pusung*), *ยาวา* (*Yawa*), หรือ *มาฮิกาวอน* (*Mahikawon*) คอยจ้องมองเพื่อฉวยโอกาสแทรกซึมเข้าไปสิงสู่ในซากศพ [4] [6]

โฮคาโนได้บันทึกความเชื่อดั้งเดิมของชาวซูโลดในเกาะปาไนย์ไว้ว่า ริมฝั่งแม่น้ำมูรูบูรู (*Muruburu River*) ซึ่งเป็นทางผ่านสู่อาณาจักรคนตาย เต็มไปด้วยผีร้าย *มาฮิกาวอน* ที่คอยดักกินวิญญาณและกลืนกินซากศพของผู้มาใหม่ [6]

พิพิธภัณฑสถานแห่งชาติฟิลิปปินส์ได้สรุปหลักคิดนี้ไว้อย่างกระชับในนิทรรศการหน้ากากทองคำโอตอนว่า [5]:

> "The early Bisayans believed that the gold coverings in the eyes, nose and mouth protect the dead from evil spirits who want to occupy the dead body." [5]
> 
> *คำแปลสรุปความ:* "ชาววิสายาส์ในยุคแรกเริ่มเชื่อว่า การนำแผ่นทองคำมาปิดคลุมดวงตา จมูก และปาก จะช่วยปกป้องผู้ตายจากวิญญาณชั่วร้ายที่ต้องการเข้ามาสิงสู่และครอบงำซากศพ" [5]

ทองคำซึ่งเป็นโลหะบริสุทธิ์ที่มีแสงสะท้อนเจิดจ้าและไม่มีวันเน่าเปื่อย จึงทำหน้าที่เป็น "ตราประทับศักดิ์สิทธิ์" (*Sacred Seal*) ที่ปิดกั้นทางเข้าออกทางกายวิภาคทั้งหมด เพื่อสกัดกั้นภูตผีปีศาจภายนอกและกักเก็บความบริสุทธิ์ของวิญญาณภายในไว้อย่างปลอดภัย [1] [4] [5]

### 3. การเปิดเผยรูปพรรณสรีระเดิมของกะโหลกศีรษะ (Preserving the Somatic Signature: Tangad & Bansil)

เหตุผลสำคัญประการที่สองที่อธิบายว่าเหตุใดฟิลิปปินส์จึงไม่ใช้หน้ากากเต็มหน้า เกี่ยวข้องโดยตรงกับ **การเปิดเผยและธำรงไว้ซึ่งสรีรดัดแปลงที่เป็นอัตลักษณ์เฉพาะของชนชั้นนำ (Somatic Inalienable Capital)** [7] [8]:

```
+---------------------------------------------------------------------------------------------------+
|               ปฏิสัมพันธ์ระหว่างสรีรดัดแปลงกับแผ่นทองคำปิดทวารเฉพาะจุด                            |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|             [ สรีรดัดแปลงกะโหลกลาดแบน: ตังอัด (Tangad) ]                                          |
|             - หน้าผากลาดเอียงไปด้านหลัง ขยายความกว้างกะโหลกออกด้านข้าง                             |
|             - มองเห็นได้ชัดเจน 100% เพราะไม่มีหน้ากากเต็มหน้ามาปิดทับ                              |
|                                                                                                   |
|                                           |                                                       |
|                                           v                                                       |
|                                                                                                   |
|             [ แผ่นทองคำปิดทวารเฉพาะจุด (Orifice Plaques) ]                                        |
|             - แผ่นปิดตา (Ocular) -> เน้นกรอบเบ้าตาใต้หน้าผากลาดแบน                               |
|             - แผ่นปิดจมูก (Nasal) -> ทอดตัวตามแนวดั้งกระดูกใบหน้า                                 |
|             - แผ่นปิดปาก (Oral) -> ประกบทับรอยแยกลิปสติก                                          |
|                                                                                                   |
|                                           |                                                       |
|                                           v                                                       |
|                                                                                                   |
|             [ สรีรดัดแปลงทันตกรรมฝังทอง: ปูซัด / บันซิล (Pusad / Bansil) ]                         |
|             - รอยยิ้มฟันดำและหมุดทองคำฝังแน่นในเนื้อฟันหน้าตัด                                     |
|             - เป็นเครื่องหมาย "ชนชั้นนำประเภทที่ 1" ที่ซ่อนอยู่ใต้แผ่นปิดปาก                       |
+---------------------------------------------------------------------------------------------------+
```

#### 3.1 การไม่บดบังความงามเชิงสถานะของกะโหลก ตังอัด (Tangad)
ดังที่ได้วิเคราะห์ในตอนที่ 4.4 ชนชั้นนำวิสายาส์และฟิลิปปินส์โบราณให้คุณค่าสูงสุดแก่การดัดรัดกะโหลกศีรษะให้ลาดแบนตั้งแต่แรกเกิด (*Tangad / Artificial Cranial Modification*) กะโหลกศีรษะที่มีหน้าผากลาดเอียงไปด้านหลังและกระดูกท้ายทอยแบนราบคือ "เครื่องหมายแห่งสายเลือดและเกียรติยศสูงสุด" ที่แยกแยะชนชั้นปกครองออกจากสามัญชนและทาส [8]

หากผู้ประกอบพิธีศพนำหน้ากากทองคำเต็มใบหน้ามาสวมครอบทับ โครงสร้างกะโหลกศีรษะลาดแบนอันเป็นความภาคภูมิใจตลอดชีวิตจะถูกบดบังจนมองไม่เห็น แต่การใช้ **แผ่นปิดเฉพาะทวาร (Orifice Covers)** ทำให้โครงร่างกะโหลกศีรษะ *Tangad* สันกระดูกโหนกแก้ม และแนวกรามอันสง่างามยังคงปรากฏเด่นชัดต่อสายตาของผู้เข้าร่วมพิธีศพ แผ่นทองคำจึงทำหน้าที่เพียงเน้นจุดสำคัญทางกายวิภาค โดยไม่ทำลายรูปพรรณสรีระเดิมของผู้ตาย [1] [8]

#### 3.2 ความสอดประสานกับศิลปะฟันฝังทอง บันซิล (Bansil)
ในทำนองเดียวกัน ชนชั้นนำผู้ล่วงลับมักผ่านการตกแต่งฟันด้วยการเจียร ตะไบ ย้อมสีดำ และฝังหมุดทองคำ *Bansil* (ตอนที่ 4.5) ซึ่งเป็น "ชนชั้นนำประเภทที่ 1" ตามทฤษฎีของบาร์เรตโต-เตโซโร [7]

การจัดวางแผ่นทองคำปิดปากภายนอกทับลงบนฟันที่มีหมุดทองคำฝังอยู่ภายใน เป็นการสร้างความสอดประสานระหว่าง "ทองคำที่เป็นเนื้อเดียวกับร่างกาย" กับ "ทองคำที่เป็นเครื่องประกอบพิธีกรรม" หากใช้หน้ากากเต็มหน้า การเชื่อมต่อเชิงสัญลักษณ์ระหว่างฟันทองคำกับแผ่นปิดปากจะสูญเสียความหมายไป การใช้แผ่นปิดเฉพาะปากจึงเป็นการตอกย้ำว่า ร่างกายนี้คือภาชนะทองคำทั้งภายในและภายนอก [1] [7]

### 4. มิติเศรษฐศาสตร์การเมือง: ประสิทธิภาพในการกระจายทองคำ (Political Economy of Funerary Gold)

นอกจากเหตุผลด้านจักรวาลวิทยาและสรีรวิทยาแล้ว การเลือกใช้แผ่นปิดเฉพาะทวารยังสามารถอธิบายได้ด้วย **มิติเศรษฐศาสตร์การเมือง (Political Economy of Gold)** ของสังคมเอเชียตะวันออกเฉียงใต้ภาคพื้นสมุทร [1] [4] [9]:

```
+---------------------------------------------------------------------------------------------------+
|               การวิเคราะห์เชิงเปรียบเทียบปริมาณและเศรษฐศาสตร์ของทองคำในพิธีศพ                    |
+---+---------------------------------------------------+-------------------------------------------+
|   | หน้ากากทองคำเต็มใบหน้า (Full Face Masks)           | แผ่นทองคำปิดเฉพาะทวาร (Orifice Covers)     |
+---+---------------------------------------------------+-------------------------------------------+
| 1 | น้ำหนักทองคำ: 200 ถึง 1,000 กรัมต่อชิ้น            | น้ำหนักทองคำ: 3.5 ถึง 7.0 กรัมต่อชุด      |
| 2 | โครงสร้างสังคม: รัฐจักรวรรดิรวมศูนย์ (Autocracy)   | โครงสร้างสังคม: เครือข่ายดาตู (Datu Polities) |
| 3 | การถือครอง: ผูกขาดโดยองค์จักรพรรดิหรือฟาโรห์       | การถือครอง: กระจายตัวในหมู่ชนชั้นนำหลายตระกูล|
| 4 | ผลกระทบเศรษฐกิจ: ดูดซับทองคำออกจากระบบมหาศาล       | ผลกระทบเศรษฐกิจ: รักษาสมดุลทุนหมุนเวียน   |
+---+---------------------------------------------------+-------------------------------------------+
```

#### 4.1 โครงสร้างการเมืองแบบดาตู (Datu Polity) และการกระจายทรัพยากร
สังคมฟิลิปปินส์ยุคก่อนอาณานิคมมิได้เป็นรัฐจักรวรรดิที่มีกษัตริย์ทรงอำนาจเบ็ดเสร็จเพียงพระองค์เดียวที่สามารถระดมทองคำนับสิบกิโลกรัมมาหล่อเป็นหน้ากากศพของตนเอง หากแต่เป็นสังคมที่มีการจัดระเบียบทางการเมืองแบบ **เครือข่ายบารังเกย์และดาตู (Barangay and Datu Alliances)** ซึ่งประกอบด้วยผู้นำชุมชนหลายร้อยคนที่แข่งขันและสร้างพันธมิตรระหว่างกัน [4] [9]

ในระบบเศรษฐกิจการเมืองเช่นนี้ ชนชั้นนำจำเป็นต้องรักษาสมดุลระหว่างการนำทองคำไปใช้เป็นเครื่องอุทิศศพส่วนบุคคล กับการเก็บสำรองทองคำไว้เพื่อใช้ในการแลกเปลี่ยนสินค้าต่างประเทศ การสร้างพันธมิตรทางการเมือง และการจัดงานเลี้ยงแจกจ่ายอาหารแก่ผู้ติดตาม (*Feasting and Gifting*) [9]

#### 4.2 ความคุ้มค่าทางพิธีกรรม (Ritual Efficiency)
การใช้แผ่นปิดเฉพาะทวารที่มีน้ำหนักทองคำรวมเพียง **3.5 ถึง 7.0 กรัม** ต่อชุด (ดังที่ตรวจวัดได้จากโอตอนและเซบู) เป็นทางออกทางวัฒนธรรมที่ชาญฉลาดยิ่ง:
- ผู้ตายได้รับการยกย่องสูงสุดด้วยการประดับทองคำแท้บริสุทธิ์ (*Guinogulan*) ครบทุกทวารประสาทสัมผัสตามกฎจักรวาลวิทยา
- ครอบครัวและสายตระกูลไม่ต้องสูญเสียทองคำจำนวนมหาศาลไปกับการสร้างหน้ากากขนาดใหญ่ ซึ่งจะทำให้สูญเสียสถานะความมั่งคั่งทางเศรษฐกิจในโลกคนเป็น
- ช่วยให้ตระกูลชนชั้นนำจำนวนมากในเครือข่ายทะเลวิสายาส์และมินดาเนาสามารถเข้าถึงและประกอบพิธีศพด้วยทองคำได้พร้อมๆ กัน โดยไม่สร้างวิกฤตการขาดแคลนทองคำในระบบการค้า [1] [4] [9]

### 5. สรุปภาพรวมของบทที่ 5 (Chapter 5 Grand Synthesis)

การศึกษาสังเคราะห์ในบทที่ 5 ได้คลี่คลายภาพรวมของแผ่นทองคำปิดทวารบนใบหน้าผู้ตายในหมู่เกาะฟิลิปปินส์อย่างลึกซึ้ง ครอบคลุมทั้งมิติกายวิภาคศาสตร์ เทคโนโลยีช่างทอง และจักรวาลวิทยา โดยสามารถสรุปข้อค้นพบแกนกลางได้ 5 ประการสำคัญ:

1. **ประเภทวิทยาอันเป็นเอกภาพ (5.1):** โบราณวัตถุในฟิลิปปินส์จัดอยู่ในกลุ่ม "แผ่นทองปิดทวารเฉพาะจุด" (*Orifice Covers*) ประกอบด้วยแผ่นปิดตาคู่ แผ่นปิดจมูก และแผ่นปิดปาก พร้อมด้วยเครื่องประดับศีรษะและต่างหูทองคำ [1] [2] [3]
2. **กายวิภาคศาสตร์การจัดวางที่ประณีต (5.2):** มิติความยาวของแผ่นปิดตาที่พาดเลยเบ้าตาสู่โหนกแก้ม ความยาว 16.3 ซม. ของแผ่นปิดจมูกโอตอนที่เชื่อมหน้าผากถึงปาก และลำดับการซ้อนทับที่แผ่นปิดตาวางทับแผ่นปิดจมูก ล้วนสะท้อนถึงการออกแบบที่สอดรับกับสรีระจริงของกะโหลกศีรษะมนุษย์ [1] [8]
3. **ทวิภาวะเชิงสกุลช่างทอง (5.3):** การดำรงอยู่คู่ขนานระหว่างสกุลช่างโอตอน (ดุนนูนจุดไข่ปลาและฉลุรูตาดำ) กับสกุลช่างบูตูอัน-เซบู (ตีแผ่นบางเรียบ 0.08 มม. ขัดเงาดั่งกระจก) ซึ่งต่างใช้ทองคำบริสุทธิ์ระดับ *กินูกูลัน* และเชื่อมโยงไปถึงบอร์เนียวตะวันตกเฉียงใต้ [1] [3]
4. **ความมั่นคงของคลังหลักฐานสถาบัน (5.4):** โบราณวัตถุทั้งหมดมีตัวตนทางกายภาพและได้รับการขึ้นทะเบียนในพิพิธภัณฑสถานแห่งชาติ (NMP), ธนาคารกลางแห่งฟิลิปปินส์ (BSP), และพิพิธภัณฑ์อายาลาอย่างเป็นวิทยาศาสตร์ [2] [3] [4]
5. **ปรัชญาแห่งการปิดทวารและเปิดเผยสรีระ (5.5):** ฟิลิปปินส์เลือกใช้แผ่นปิดเฉพาะทวารแทนหน้ากากเต็มหน้า เพื่อกักกันพลังวิญญาณ *ดุงกัน* สกัดกั้นภูตผีปีศาจ *ยาวา* ขณะเดียวกันก็เปิดเผยรูปพรรณกะโหลกลาดแบน *Tangad* และฟันฝังทอง *Bansil* ตลอดจนสอดรับกับเศรษฐศาสตร์การเมืองของสังคมดาตู [1] [4] [7]

หลักฐานเครื่องทองคำปิดทวารเหล่านี้มิได้ปรากฏอยู่อย่างโดดเดี่ยวในหลุมฝังศพ หากแต่ถูกฝังเคียงคู่กับโบราณวัตถุต่างประเทศจำนวนมหาศาล โดยเฉพาะอย่างยิ่งเครื่องถ้วยชามเคลือบจีนและเอเชีย ซึ่งเป็นประเด็นที่ **บทที่ 6** จะดำเนินการวิเคราะห์อย่างละเอียดในฐานะ "วัฒนธรรมวัตถุร่วมสุสาน" ต่อไป [1] [3] [4]
