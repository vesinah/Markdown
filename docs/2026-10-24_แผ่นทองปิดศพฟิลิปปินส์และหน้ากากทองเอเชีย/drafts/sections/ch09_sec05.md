# บทที่ 9: โลกหน้ากากทองคำและแผ่นทองปิดศพเปรียบเทียบในเอเชียตะวันออกเฉียงใต้และเอเชียตะวันออก

## 9.5 บทสังเคราะห์เปรียบเทียบขอบฟ้าวัฒนธรรมทองคำข้ามเอเชีย: ความเหมือน-ความต่างเชิงหน้าที่ สัณฐานวิทยา และการแพร่กระจายทางวัฒนธรรม

### 1. การสังเคราะห์องค์รวมของขอบฟ้าวัฒนธรรมหน้ากากทองคำและแผ่นปิดทวารทั่วเอเชีย

การศึกษาเปรียบเทียบเชิงลึกตลอดทั้งบทที่ 9 นี้ ได้นำพาผู้วิจัยเดินทางข้ามพรมแดนทางภูมิศาสตร์และเส้นเวลาทางประวัติศาสตร์ของทวีปเอเชีย จากดินแดนสามเหลี่ยมปากแม่น้ำโขงของอาณาจักรฟูนัน (อ๊อกแอว) ชายฝั่งเวียดนามตอนกลาง (จัมปาและกิองลน) ที่ราบลุ่มทะเลสาบเขมร (โพร์เฮียร์และพุมสเนย์) หมู่เกาะอินโดนีเซีย (สุลาเวสีใต้ บาหลี และชวา) แอ่งกระทะเสฉวนยุคสำริด (ซานซิงตุยและจินซา) ที่ราบภาคกลางของจักรวรรดิฮั่น ไปจนถึงทุ่งหญ้าสเตปป์แห่งมองโกเลียในของจักรวรรดิเหลียว [1] [2] [3] [4]

การนำข้อมูลเชิงประจักษ์จาก 5 ภูมิวัฒนธรรมหลักเหล่านี้มาวางเคียงคู่กับปรากฏการณ์ **หน้ากากทองคำและแผ่นทองคำปิดทวารสรีระแห่งหมู่เกาะฟิลิปปินส์ (โอตอน, บูตูอัน, เซบู)** ได้สลายมายาคติทางโบราณคดีเดิมที่เคยมองว่า หน้ากากทองคำแห่งโอตอนเป็นโบราณวัตถุเดี่ยวที่เกิดขึ้นอย่างโดดเดี่ยวหรือบังเอิญในประวัติศาสตร์ฟิลิปปินส์ [5] [6] ในทางตรงกันข้าม การสังเคราะห์องค์รวมเผยให้เห็นอย่างชัดเจนว่า สังคมฟิลิปปินส์ยุคก่อนอาณานิคมเป็นส่วนหนึ่งของ **"ขอบฟ้าวัฒนธรรมทองคำข้ามเอเชีย" (Pan-Asian Gold Horizon)** ที่มีความเชื่อมโยงกันอย่างสลับซับซ้อน ทั้งผ่านเครือข่ายพาณิชย์นาวีข้ามสมุทร (*Maritime Silk Road*) และผ่านการสืบทอดชั้นฐานความเชื่อดั้งเดิมของมนุษยชาติร่วมกัน [2] [5] [7]

```
+---------------------------------------------------------------------------------------------------+
|               แผนภาพสังเคราะห์ขอบฟ้าวัฒนธรรมหน้ากากทองคำข้ามเอเชีย (Pan-Asian Gold Matrix)          |
+---------------------------------------------------------------------------------------------------+
| 1. ขอบฟ้าออสโตรนีเชียนแห่งหมู่เกาะ (Insular Austronesian Horizon):                               |
|    - ฟิลิปปินส์ (โอตอน, บูตูอัน, เซบู) & สุลาเวสีใต้ (มากัสซาร์, เซียง, บันตาเอง) & บาหลี (กิลิมานุก) |
|    - สัณฐาน: แผ่นทองตีบางปิดเฉพาะทวาร (ตา จมูก ปาก อวัยวะเพศ) เจาะรูร้อยด้ายผูกรัด               |
|    - จักรวาลวิทยา: วิญญาณนิยม ลัทธิบรรพชน กักเก็บพลังชีวิต (Dungan/Sumange) สกัดอสูร (Asuang)     |
|                                       ↓                                                           |
| 2. ขอบฟ้าชายฝั่งและแผ่นดินใหญ่อินโดจีน (Mainland Indochinese Horizon):                             |
|    - เวียดนามใต้ (กิองลน, อ๊อกแอว/ฟูนัน), กัมพูชา (โพร์เฮียร์), เวียดนามกลาง (จัมปา)                |
|    - สัณฐาน: แผ่นปิดตา-จมูก (กิองลน), หน้ากากเทวรูป (Kosa Champa), แผ่นทองดุนลายรูปตา (Oc Eo)     |
|    - จักรวาลวิทยา: ยุคเหล็กปิดหน้าศพด้วยสำริด/ทอง สู่ยุคประวัติศาสตร์รับเทววิทยาฮินดู-พุทธ       |
|                                       ↓                                                           |
| 3. ขอบฟ้าที่ราบภาคกลางและเสฉวน (Central Plains & Sichuan Horizon):                                |
|    - ซานซิงตุย/จินชา: หน้ากากทองสวมเทวรูปสัมฤทธิ์ในหลุมบวงสรวง                                   |
|    - ราชวงศ์ฮั่น: ปิด 9 ทวารสรีระ (Jiuqiao Sai) สกัดการรั่วไหลของชี่ (Qi) สู่ความเป็นเซียนเต๋า    |
|                                       ↓                                                           |
| 4. ขอบฟ้าทุ่งหญ้าสเตปป์ยูเรเซียเหนือ (Northern Eurasian Steppe Horizon):                          |
|    - จักรวรรดิเหลียว (ชิตัน): หน้ากากทองคำเต็มใบหน้า + ชุดตาข่ายลวดโลหะคลุมร่างทั้งร่าง             |
|    - จักรวาลวิทยา: ชาแมนทุ่งหญ้าไซธิเอีย การถนอมสรีระจักรพรรดิ (ตีปา) สตาฟดวงหน้านิรันดร์         |
+---------------------------------------------------------------------------------------------------+
```

### 2. อนุกรมวิธานเชิงสัณฐานวิทยาและเทคโนโลยีโลหวิทยา (Morphological & Metallurgical Taxonomy)

จากการวิเคราะห์เชิงเปรียบเทียบในรายละเอียดทางกายภาพ โบราณวัตถุหน้ากากและแผ่นทองคำทั่วเอเชียสามารถจัดจำแนกออกเป็น **3 หมวดหมู่สัณฐานวิทยาหลัก (Three Major Morphological Categories)** ซึ่งสะท้อนถึงเจตจำนงทางเทคโนโลยีและการใช้งานที่แตกต่างกัน [1] [2] [3] [6]:

```
+---------------------------------------------------------------------------------------------------+
|               อนุกรมวิธานสัณฐานวิทยาหน้ากากและแผ่นทองคำทั่วเอเชีย (Taxonomy of Forms)              |
+-------------------+-----------------------------------+-------------------------------------------+
| หมวดหมู่สัณฐาน     |         ตัวแทนวัฒนธรรมและแหล่ง        |           ลักษณะเชิงเทคนิคและกายวิภาค      |
+-------------------+-----------------------------------+-------------------------------------------+
| 1. หน้ากากเต็มหน้า | - ราชวงศ์เหลียว (Princess of Chen)| แผ่นทองคำหนาปานกลาง ตีขึ้นรูปคลุมทั้งใบหน้า|
|    (Full-face     | - จัมปา (Mukha-linga / Kosa)      | (Full facial sheet) ตั้งแต่หน้าผากถึงคาง   |
|     Sheet Masks)  | - ซานซิงตุย (Sanxingdui, Sichuan) | สลักพระพักตร์สงบ เจาะรูร้อยลวดหรือโครงหนุน |
|                   | - มากัสซาร์บางชิ้น (South Sulawesi)| หลอมรวมสรีระเป็นอัตลักษณ์เทวะหรือข่านอมตะ |
+-------------------+-----------------------------------+-------------------------------------------+
| 2. แผ่นปิดทวาร    | - ฟิลิปปินส์ (Oton, Butuan, Cebu) | แผ่นทองคำตีบางยิ่งยวด (0.026–0.15 มม.)     |
|    เฉพาะจุด       | - เวียดนามใต้ (Giong Lon, 410 BCE)| ตัดแยกชิ้นตามอวัยวะ: ตา (Ocular), จมูก,    |
|    (Discrete      | - ราชวงศ์ฮั่น (Han Nine Orifices) | ปาก (Labial), อวัยวะเพศ (Genital)         |
|     Orifice Foils)| - บาหลี (Gilimanuk) & มากัสซาร์   | เจาะรูมุมผูกรัด มุ่งปิดกั้นประตูวิญญาณ    |
+-------------------+-----------------------------------+-------------------------------------------+
| 3. เครื่องบูชากรุ   | - อ๊อกแอว/ฟูนัน (Go Thap, Nen Chua)| แผ่นทองคำสี่เหลี่ยม/วงรี ดุนลายนูนต่ำ     |
|    และแผ่นบูชา     | - ชวาโบราณ (Central/East Java)    | รูปดวงตา, เทพเจ้า, สัตว์มงคล, ตรีศูล      |
|    (Relic Plaques)| - จินชา (Sun Bird Gold Foil)      | บรรจุใต้ฐานศาสนสถาน มิได้สวมติดร่างมนุษย์ |
+-------------------+-----------------------------------+-------------------------------------------+
```

ในมิติของ **เทคโนโลยีโลหวิทยา (Metallurgical Technology)** การเปรียบเทียบเผยให้เห็นถึงวิวัฒนาการอันน่าทึ่ง:
1. **ความบางของแผ่นทองคำ (Foil Thickness):** แผ่นทองคำของราชวงศ์ฮั่นที่สุสานจินหยางแสดงความบางสูงสุดถึง **26 ไมโครเมตร (μm)** ซึ่งเป็นผลจากการตีรีดด้วยค้อนเหล็กและเทคนิคการอบอ่อน (*annealing*) ซ้ำหลายรอบ [3] ขณะที่แผ่นทองคำปิดทวารของฟิลิปปินส์ (โอตอนและบูตูอัน) มีความหนาเฉลี่ยอยู่ที่ **0.08–0.15 มิลลิเมตร (80–150 μm)** ซึ่งเป็นความหนาที่เหมาะสมที่สุดต่อการคงรูปทรงสามมิติบนใบหน้าศพจริง โดยไม่ฉีกขาดง่ายเมื่อถูกดุนลายนูนต่ำบนแท่นชันไม้ [5] [8]
2. **องค์ประกอบธาตุและโลหะผสม (Alloy Chemistry):** 
   - แหล่งแผ่นดินใหญ่ เช่น ฮั่นและจินชา ใช้ทองคำที่มีความบริสุทธิ์สูงยิ่ง (Au 96–98% ในฮั่น, Au 83–94% ในจินชา) [3]
   - สุสานโพร์เฮียร์ในกัมพูชาใช้อิเล็กตรัมธรรมชาติที่มีเงินสูง (Au 60%, Ag สูง) และมีร่องรอยดีบุกจากแหล่งแร่ปั่น [9]
   - จักรวรรดิเหลียว (สุสานเขาถูจี๋) ใช้โลหะผสมทอง-เงิน (Au 84–88%, Ag 10–13%) [4]
   - หมู่เกาะฟิลิปปินส์ (โอตอนและบูตูอัน) ใช้ทองคำธรรมชาติระบบสามส่วน **Au-Ag-Cu (Dalisay / Guinogulan, 20–22k)** ที่มีเนื้อทองคำ 87–91% เงิน 7–10% และทองแดง 1.5–2.2% ซึ่งเป็นเอกลักษณ์ทางธรณีเคมีของสายแร่พลาเซอร์ในเขตซูริเกา-อากูซันและปานาย [5] [10]
3. **เทคนิคการขึ้นรูปและลวดลาย (Forming & Ornamentation):** เทคนิค **ดุนลายนูนต่ำ (Repoussé)** จากด้านหลังร่วมกับ **การสลักลายเส้น (Chasing / Incising)** จากด้านหน้า ถือเป็นภาษาร่วมทางช่างทองที่ปรากฏในทุกวัฒนธรรม ทว่าช่างทองฟิลิปปินส์มีความโดดเด่นเป็นพิเศษในการเจาะรูขนาดเล็ก (0.5–1.0 มม.) ที่มุมของแผ่นทองอย่างประณีต เพื่อใช้ร้อยเส้นด้ายอินทรีย์ยึดโยงแผ่นปิดตากับแผ่นปิดจมูกและผูกรัดเข้ากับกะโหลกศีรษะ ซึ่งเป็นนวัตกรรมการติดตั้งที่ไม่พบในแผ่นทองบูชาของอ๊อกแอว [5] [6]

### 3. เมทริกซ์การเปรียบเทียบหน้าที่เชิงจักรวาลวิทยาและพิธีกรรม (Cosmological & Functional Matrix)

ความแตกต่างที่ลึกซึ้งที่สุดระหว่างวัฒนธรรมหน้ากากทองคำทั่วเอเชีย มิได้อยู่ที่รูปแบบทางกายภาพ แต่อยู่ที่ **"กรอบจักรวาลวิทยาและอุดมการณ์ความตาย" (Cosmological and Mortuary Ideologies)** ซึ่งสามารถสังเคราะห์ออกเป็น 4 เสาหลักทางปรัชญา [1] [2] [3] [7]:

```
+---------------------------------------------------------------------------------------------------+
|               สี่เสาหลักจักรวาลวิทยาความตายของหน้ากากทองคำทั่วเอเชีย (The Four Ideological Pillars)  |
+-------------------+-----------------------------------+-------------------------------------------+
|    เสาหลักอุดมการณ์ |         วัฒนธรรมที่เป็นตัวแทน         |           มโนทัศน์และหน้าที่ทางจิตวิญญาณ  |
+-------------------+-----------------------------------+-------------------------------------------+
| 1. วิญญาณนิยมและ   | - หมู่เกาะฟิลิปปินส์ (โอตอน/บูตูอัน)| - ร่างกายมี 9 ทวารเปราะบางต่ออสูร (Asuang) |
|    ลัทธิบรรพชน     | - สุลาเวสีใต้ (มากัสซาร์/โกอา)     | - กักเก็บพลังชีวิต (Dungan / Sumange)      |
|    ออสโตรนีเชียน  | - เวียดนามใต้ (กิองลน)            | - สกัดวิญญาณกลับบ้านมารบกวนคนเป็น (Anja)  |
|    (Austronesian) | - เกาะบาหลี (กิลิมานุก)           | - ค่าผ่านทางแม่น้ำสุลัด (Viaticum / Baon)  |
|                   |                                   | - ป้องกันความอับอายต่อหน้าปวงผีบรรพชน     |
+-------------------+-----------------------------------+-------------------------------------------+
| 2. เทววิทยาฮินดู- | - อาณาจักรจัมปา (หมี่เซิน, โปนคร) | - พระพักตร์ทิพย์แห่งพระศิวะ (Trinetra)    |
|    พุทธมหายาน     | - วัฒนธรรมอ๊อกแอว (ฟูนัน)         | - การรวมวิญญาณกษัตริย์เข้ากับเทวะ (เทวราชา)|
|    (Indic Faiths) | - สุสานโพร์เฮียร์ (กัมพูชา)       | - การสถาปนามณฑลจักรวาลใต้ฐานเทวาลัย      |
|                   |                                   | - เครื่องบูชาอันบริสุทธิ์จากการสวดอธิษฐาน |
+-------------------+-----------------------------------+-------------------------------------------+
| 3. ลัทธิเต๋าและ    | - ราชวงศ์ฮั่นแห่งที่ราบภาคกลาง     | - มโนทัศน์ทวิวิญญาณ หุน (Hun) และ พัว (Po)|
|    การเล่นแร่แปรธาตุ|   (สุสานหม่าหวังตุย, หลิวเซิ่ง)   | - สกัดกั้นการรั่วไหลของ "ชี่" (Qi) 9 ทวาร  |
|    (Daoist Immortality)                               | - รักษาเรือนร่างไม่ให้เน่าเปื่อยสู่เซียน   |
|                   |                                   | - ทองคำและหยกเป็นธาตุหยางค้ำจุนชีวิตนิรันดร์|
+-------------------+-----------------------------------+-------------------------------------------+
| 4. ลัทธิชาแมนและ   | - จักรวรรดิเหลียวของชาวชิตัน      | - มรดกชนเร่ร่อนทุ่งหญ้าสเตปป์ (ไซธิเอีย)  |
|    การถนอมรูปโฉมข่าน|   (สุสานเจ้าหญิงเฉิน, เขาถูจี๋)   | - การผ่าตัดสมอง/เครื่องใน ถนอมสรีระ (ตีปา)|
|    (Steppe Shamanism)                                 | - สตาฟดวงหน้าและเรือนร่างขุนนางให้สง่างาม |
|                   |                                   | - แสดงเกียรติภูมิสูงสุดในสังคมปรโลก       |
+-------------------+-----------------------------------+-------------------------------------------+
```

ในเสาหลักที่ 1 ซึ่งเป็นแกนกลางของ **วัฒนธรรมออสโตรนีเชียนแห่งหมู่เกาะ (ฟิลิปปินส์และสุลาเวสีใต้)** พิธีกรรมศพมิได้ผูกติดกับสถาบันศาสนาจักรวาลนิยมแบบอินเดียหรือจีน หากแต่ขับเคลื่อนด้วย **"ความกลัวต่อความเสื่อมสลายทางสรีระและภัยคุกคามจากอมนุษย์"** [1] [5] [7] การที่ช่องเปิดตามธรรมชาติของร่างกาย (ตา จมูก ปาก) ถูกปิดทับด้วยทองคำ มิใช่เพียงเพื่อความสวยงาม แต่เพื่อสร้างปราการเวทมนตร์สกัดกั้นอสูรปอบกินศพ (*asuang / mahikawon*) มิให้เข้ามาชำแรกกลืนกินตับไตไส้พุง และป้องกันมิให้วิญญาณของผู้ตาย (*kalag / anja*) หวนกลับมารังควานคนเป็น ขณะเดียวกัน แผ่นทองคำยังทำหน้าที่เป็นเสบียงทางศักดิ์สิทธิ์ (*pabaon / viaticum*) ในการจ่ายค่าข้ามฟากแม่น้ำมรณะแก่คนพายเรือวิญญาณ (ซิมูรันและซิกินารูกัน) เพื่อนำพาดวงวิญญาณไปรวมตัวกับปวงผีบรรพชน ณ ดินแดนสุลัดหรือยอดเขามัดยาอาสอย่างสมศักดิ์ศรี [5] [7] [11]

### 4. แบบจำลองทิศทางการแพร่กระจายและพลวัตการปรับประยุกต์สู่ท้องถิ่น (Diffusion Dynamics vs Indigenization)

การทำความเข้าใจความสัมพันธ์เชิงประวัติศาสตร์ระหว่างวัฒนธรรมทองคำเหล่านี้ นำไปสู่ข้อถกเถียงสำคัญ 2 แนวทางในวงวิชาการโบราณคดีสากล:

#### 1) ข้อถกเถียงเรื่องการแพร่กระจายข้ามสมุทร (Maritime Diffusion via Maritime Interaction Spheres)
นักโบราณคดีอย่าง อันเดรียส ไรเน็คเคอ (2009) และ เวย์น บูกาส (2007) ได้ชี้ให้เห็นหลักฐานการเชื่อมโยงทางกายภาพที่ชัดเจนระหว่างแหล่งโบราณคดีชายฝั่ง [1] [2]:
- การค้นพบหน้ากากทองคำปิดเฉพาะ "ตาและจมูก" ที่แหล่งกิองลน ชายฝั่งเวียดนามใต้ (410–90 ปีก่อน ค.ศ.) ซึ่งมีลักษณะทางสัณฐานและรูเจาะมุมผูกรัดแบบเดียวกับหน้ากากโอตอนในฟิลิปปินส์ ชี้ว่ามโนทัศน์เรื่องการปิดเฉพาะทวารส่วนบนได้เดินทางข้ามทะเลจีนใต้ผ่านเครือข่ายการค้าทางทะเลยุคก่อนประวัติศาสตร์ [2]
- ในทำนองเดียวกัน บูกาส (2007) ได้เสนอว่า จากหลักฐานลำดับอายุทางวิทยาศาสตร์ที่หน้ากากทองคำและแผ่นปิดทวารในฟิลิปปินส์ (บูตูอัน ศตวรรษที่ 9–13, โอตอน ศตวรรษที่ 14–15) มีอายุเก่าแก่กว่าหลุมศพมากัสซาร์ในสุลาเวสีใต้ (ศตวรรษที่ 14–16) เล็กน้อย จึงมีความเป็นไปได้สูงยิ่งที่ **ประเพณีการใช้ทองคำปิดศพและโลงไม้ขุดจะแพร่กระจายจากฟิลิปปินส์ลงสู่สุลาเวสีใต้** ผ่านเส้นทางการค้าเลียบทะเลซูลูและช่องแคบมากัสซาร์ [1]

#### 2) พลวัตการปรับประยุกต์สู่ท้องถิ่นและการคงอยู่ของชั้นฐานวัฒนธรรมดั้งเดิม (Indigenization & Cultural Resilience)
อย่างไรก็ดี เมื่อพิจารณาในเชิงมานุษยวิทยาวัฒนธรรม ปรากฏการณ์แผ่นทองปิดทวารแห่งฟิลิปปินส์มิใช่งานลอกเลียนแบบจากภายนอก หากแต่เป็นผลลัพธ์ของ **"กระบวนการกลืนกลายและปรับประยุกต์สู่ท้องถิ่นอย่างทรงพลัง" (Creative Indigenization)** [5] [7]:
- แม้ว่าฟิลิปปินส์จะติดต่อค้าขายอย่างเข้มข้นกับจักรวรรดิจีน (นำเข้าเครื่องถ้วยชามซ่ง-หยวน-หมิงนับแสนชิ้น) ทว่าสังคมดาตูของฟิลิปปินส์กลับ **ไม่เคยรับเอาคติชุดหยกเย็บด้ายทองคำหรือหน้ากากเต็มหน้าแบบจีน** เข้ามาใช้ในพิธีศพของตนเลย [5] [10]
- ในทำนองเดียวกัน แม้จะมีการแลกเปลี่ยนกับอาณาจักรฮินดู-พุทธในอินโดจีนและชวา แต่ฟิลิปปินส์ก็ **ไม่เคยสร้างโกศะครอบศิวลึงค์หรือหันไปใช้การเผาศพแบบอินเดีย** [5] [12]

ชนชั้นนำดาตูแห่งฟิลิปปินส์เลือกที่จะรักษา **"ประเพณีการฝังศพปฐมภูมิในโลงไม้ขุดรูปเรือลองกอน (Longon)"** และเลือกใช้ **"แผ่นทองคำตีบางตัดแยกชิ้นเพื่อปิดเฉพาะช่องทวารสรีระ"** ไว้อย่างเหนียวแน่น การเลือกสรรทางวัฒนธรรมเช่นนี้ยืนยันว่า สำหรับชาวออสโตรนีเชียนในฟิลิปปินส์ โบราณวัตถุทองคำมิได้ทำหน้าที่เป็นสัญลักษณ์ของอำนาจจักรวรรดิรวมศูนย์หรือเทววิทยาจากต่างแดน หากแต่ทำหน้าที่เป็น **"เกราะกำบังทางจิตวิญญาณและตราประทับเกียรติยศแห่งบรรพชนดั้งเดิม"** ที่ตอบสนองต่อจักรวาลวิทยาความตายของตนเองอย่างแท้จริง [5] [7] [10]

### 5. บทสรุปของบทที่ 9: หน้ากากทองคำแห่งฟิลิปปินส์ในฐานะยอดมงกุฎแห่งโลกทัศน์ออสโตรนีเชียนในบริบทเอเชีย

จากการเปรียบเทียบข้ามอารยธรรมอย่างรอบด้านในบทที่ 9 นี้ สามารถสรุปได้อย่างหนักแน่นว่า **หน้ากากทองคำโอตอนและแผ่นทองคำปิดทวารสรีระแห่งหมู่เกาะฟิลิปปินส์ ครอบครองสถานะเป็น "ยอดมงกุฎแห่งประณีตศิลป์และจักรวาลวิทยาของโลกออสโตรนีเชียน" (The Crown Jewel of Austronesian Funerary Metallurgy)** [1] [2] [5]:

ประการแรก ในเชิง **ประวัติศาสตร์ศิลปะและโบราณโลหวิทยา** แผ่นทองคำปิดทวารของฟิลิปปินส์สะท้อนความเชี่ยวชาญขั้นสูงสุดของช่างทองพื้นเมืองปันดาย-กินโต (*panday ginto*) ในการรีดทองคำธรรมชาติความบริสุทธิ์สูง (20–22k) ให้บางเฉียบถึง 0.08–0.15 มม. และดุนลายนูนต่ำรูปดวงตาที่มีม่านตาคมชัดและริมฝีปากที่แย้มสรวลอย่างเปี่ยมชีวิตชีวา ซึ่งมีความประณีตและมีอัตลักษณ์ทางกายวิภาคที่โดดเด่นไม่แพ้งานช่างทองของราชวงศ์ฮั่นหรืออาณาจักรจัมปา [3] [5] [8]

ประการที่สอง ในเชิง **มานุษยวิทยาศาสนาและจักรวาลวิทยา** ปรากฏการณ์แผ่นทองปิดทวารของฟิลิปปินส์เป็นตัวแทนที่สมบูรณ์แบบที่สุดของระบบความเชื่อแบบวิญญาณนิยมออสโตรนีเชียนดั้งเดิม ที่สามารถรักษาความบริสุทธิ์ของแก่นความเชื่อไว้ได้โดยไม่ถูกกลืนกลายด้วยศาสนาแห่งคัมภีร์จากภายนอก ในขณะที่วัฒนธรรมอื่น (เช่น ชวา หรือ จัมปา) ได้แปรเปลี่ยนคติการฝังศพไปสู่การเผาศพตามคติอินเดีย หรือถูกแทนที่ด้วยอิสลาม ชุมชนโบราณในฟิลิปปินส์ยังคงสืบทอดการปิดทวารสรีระเพื่อคุ้มครองพลังชีวิตดวงันและสถาปนาเกียรติภูมิผีบรรพชนอูมาลากัดต่อเนื่องมาจนถึงศตวรรษที่ 16 ก่อนการเข้ามาของระเบียบอาณานิคมสเปน [5] [7] [11]

ด้วยเหตุนี้ หน้ากากทองคำแห่งฟิลิปปินส์จึงมิได้เป็นเพียงมรดกทางวัฒนธรรมของชาติฟิลิปปินส์เท่านั้น หากแต่เป็นมรดกทางโบราณคดีชิ้นเอกของภูมิภาคเอเชีย ที่สะท้อนถึงการบรรจบกันอย่างลงตัวระหว่างความอุดมสมบูรณ์ของสายแร่ทองคำธรรมชาติ เทคโนโลยีช่างทองชั้นครู และพลังอำนาจแห่งศรัทธาของมนุษยชาติในการแสวงหาชัยชนะเหนือความตายและความเน่าเปื่อยสู่ความเป็นนิรันดร์ [1] [5] [10]
