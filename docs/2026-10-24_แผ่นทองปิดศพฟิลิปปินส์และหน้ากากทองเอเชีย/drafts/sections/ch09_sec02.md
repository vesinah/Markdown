# บทที่ 9: โลกหน้ากากทองคำและแผ่นทองปิดศพเปรียบเทียบในเอเชียตะวันออกเฉียงใต้และเอเชียตะวันออก

## 9.2 หน้ากากทองคำและแผ่นทองปิดศพในวัฒนธรรมจัมปา (เวียดนามกลาง) และกัมพูชา

### 1. บริบททางประวัติศาสตร์และภาษาศาสตร์: วัฒนธรรมจัมปาในฐานะสังคมออสโตรนีเชียนบนแผ่นดินใหญ่

ในการพิจารณาขอบฟ้าวัฒนธรรมหน้ากากทองคำและแผ่นทองคำปิดทวารสรีระของเอเชียตะวันออกเฉียงใต้ ดินแดนชายฝั่งเวียดนามตอนกลางอันเป็นถิ่นกำเนิดของอารยธรรม **จัมปา (Champa)** ครอบครองตำแหน่งทางประวัติศาสตร์และชาติพันธุ์วรรณนาที่มีความพิเศษเป็นเอกลักษณ์อย่างยิ่ง [1] [2] ประชากรชาวจาม (*Chams*) มิได้พูดภาษาในตระกูลออสโตรเอเชียติก (*Austroasiatic*) ดั่งเช่นกลุ่มชนส่วนใหญ่บนคาบสมุทรอินโดจีน หากแต่พูดภาษาในกลุ่มจามิก (*Chamic languages*) ซึ่งจัดเป็นสาขาหนึ่งของตระกูลภาษา **ออสโตรนีเชียน (Austronesian)** สายมลายู-โพลินีเชียน (*Malayo-Polynesian*) [2] [3]

ความสัมพันธ์ทางภาษาศาสตร์นี้สะท้อนว่า ชาวจามมีรากเหง้าทางบรรพชนและประวัติศาสตร์ร่วมกับประชากรดั้งเดิมของหมู่เกาะฟิลิปปินส์ อินโดนีเซีย และคาบสมุทรมลายู โดยได้เคลื่อนย้ายข้ามทะเลจีนใต้เข้ามาตั้งถิ่นฐานตามแนวชายฝั่งเวียดนามตอนกลางตั้งแต่ยุคก่อนประวัติศาสตร์ตอนปลาย (วัฒนธรรมซาหึ่ง, *Sa Huynh Culture*, ราว 500 ปีก่อนคริสตศักราช ถึง ค.ศ. 100) [1] [4] สภาพแวดล้อมทางภูมิศาสตร์ของจัมปาซึ่งถูกขนาบด้วยเทือกเขาอันนัม (*Annamite Range*) ทางทิศตะวันตก และทะเลจีนใต้ทางทิศตะวันออก บีบบังคับให้ชาวจามพัฒนาวิถีชีวิตแบบ **"รัฐพาณิชย์นาวีและการสงครามทางทะเล" (Maritime Trading and Raiding Polities)** เช่นเดียวกับสังคมดาตูของฟิลิปปินส์โบราณ [2] [5]

```

|    - แหล่งกิองลน (Giong Lon, 410–90 BCE): หน้ากากทองปิดตา-จมูกยุคแรกเริ่มของเอเชียตะวันออกเฉียงใต้  |

|    - ประเพณีการถวายมงกุฎ-หน้ากากทองคำ (Kosa) ครอบศิวลึงค์ และหน้ากากทองคำปิดพระพักตร์ในพิธีศพ     |
```

ความมั่งคั่งทางเศรษฐกิจของจัมปาเกิดจากการควบคุมเส้นทางเดินเรือเลียบชายฝั่งและการสกัดสายแร่ทองคำปฐมภูมิและพลาเซอร์ตามแนวเทือกเขาตอนกลาง ส่งผลให้ราชสำนักจัมปาพัฒนางานประณีตศิลป์ช่างทอง (*Champa Goldsmithing*) จนเจริญถึงขีดสุด [1] [6] โบราณวัตถุทองคำของจัมปามิได้จำกัดอยู่เพียงเครื่องประดับกายเท่านั้น แต่ได้ผสานเข้ากับอุดมการณ์ทางศาสนาพราหมณ์-ฮินดูและการยกย่องบรรพชน นำไปสู่การรังสรรค์ **"หน้ากากทองคำ" (Gold Masks)** และ **"เครื่องคลุมพระพักตร์ทองคำ" (Kosa)** ซึ่งเป็นหมุดหมายสำคัญในการศึกษาเปรียบเทียบกับประเพณีหน้ากากทองคำของฟิลิปปินส์ [1] [7]

### 2. หน้ากากทองคำและแผ่นปิดพระพักตร์ในศิลปกรรมจัมปา (Champa Gold Masks & Kosa Tradition)

ในบริบทของศิลปกรรมและศาสนาของอาณาจักรจัมปา โบราณวัตถุประเภทหน้ากากทองคำปรากฏขึ้นใน 2 รูปแบบหลักที่มีความเชื่อมโยงกันอย่างลึกซึ้ง ได้แก่ **เครื่องครอบศิวลึงค์ทองคำ (Kosa / Mukha-linga)** และ **หน้ากากทองคำสำหรับพิธีกรรมศพของชนชั้นนำ (Mortuary Gold Masks)** [1] [6]

ตามคติเทววิทยาไศวนิกายที่เจริญรุ่งเรืองในจัมปาตั้งแต่คริสต์ศตวรรษที่ 4 เป็นต้นมา พระมหากษัตริย์ทรงเปรียบเสมือนองค์อวตารของพระศิวะบนโลกมนุษย์ การถวายเครื่องอุทิศแด่เทวาลัยหลัก เช่น หมี่เซิน (*Mỹ Sơn*) หรือ โปนคร (*Po Nagar*) มักกระทำผ่านการสร้าง **โกศะ (Kosa)** ซึ่งเป็นปลอกหุ้มหรือหมวกครอบศิวลึงค์ที่ทำจากทองคำและเงินดุนลาย [6] [7] บริเวณส่วนบนของโกศะมักได้รับการรังสรรค์เป็น "พระพักตร์ของพระศิวะ" (*Mukha-linga*) ที่ประกอบด้วย:
- พระเนตรสองข้างที่เบิกกว้าง ดุนลายนูนต่ำแสดงเปลือกตาและม่านตา
- พระเนตรที่สาม (*Trinetra*) ประดิษฐานอยู่กึ่งกลางพระนลาฏ (หน้าผาก) ในแนวตั้ง
- นาสิกโด่งเป็นสันคม และโอษฐ์ที่แย้มสรวลเล็กน้อย
- พระกรรณยาวย้อยประดับกุณฑลทองคำ
- มงกุฎทรงกรวยหรือกระบังหน้า (*Jatamukuta / Tiara*) ที่ประดับลวดลายกระหนกเปลวเพลิงและพวงมาลัยดอกไม้ [6] [7]

```
+---------------------------------------------------------------------------------------------------+
|               สัณฐานวิทยาของหน้ากากทองคำจัมปา (Morphology of Champa Gold Masks)                   |
+---------------------------------------------------------------------------------------------------+

|    - ดวงตาทั้งสองข้างดุนลายนูนทรงวงรี เปลือกตาคมชัด พร้อมดวงตาที่สาม (Trinetra) กึ่งกลางหน้าผาก   |
|    - สันจมูกแคบตรง ปลายจมูกตัดเหลี่ยม ริมฝีปากอวบอิ่มดุนลายประกบสนิท                             |
|                                       ↓                                                           |
| 2. เทคนิคโลหวิทยา:                                                                                |
|    - การตีแผ่ทองคำแผ่นหนาปานกลาง (Medium-gauge beaten gold sheet)                                 |
|    - การดุนลายนูนสูงและนูนต่ำ (Repoussé) จากด้านหลังบนแท่นยางไม้หรือชัน                            |
|    - การกรีดสลักลายเส้นเก็บรายละเอียดหนวด พระเกศา และมงกุฎ (Chasing / Incising)                   |
|                                       ↓                                                           |
| 3. มิติเชิงหน้าที่และการติดตั้ง:                                                                   |
|    - เจาะรูขนาดเล็กตามขอบด้านหลังและขมับสำหรับร้อยยึดกับโครงไม้ ปูนปั้น หรือศิวลึงค์หิน            |
|    - สวมครอบพระพักตร์รูปเคารพเทวรูป หรือปิดทับใบหน้าของกษัตริย์ในพิธีฌาปนกิจหลวง                 |
+---------------------------------------------------------------------------------------------------+
```

นอกเหนือจากการครอบศิวลึงค์แล้ว หลักฐานทางประวัติศาสตร์และจารึกโบราณยังชี้ให้เห็นว่า ในพิธีพระบรมศพของพระมหากษัตริย์จัมปา สรีระขององค์ประมุขจะได้รับการถวายเกียรติยศสูงสุดด้วยการประดับ **หน้ากากทองคำปิดพระพักตร์** ก่อนการนำร่างเข้าสู่กระบวนการฌาปนกิจด้วยกองฟืนไม้จันทน์หอม [1] [7] หน้ากากทองคำนี้ทำหน้าที่เป็น "พระพักตร์ทิพย์" (*Divine Face*) ที่แปลงสภาพกษัตริย์ผู้ล่วงลับให้รวมเป็นเนื้อเดียวกับพระผู้เป็นเจ้า เพื่อให้พระองค์ทรงเสด็จกลับคืนสู่สรวงสวรรค์ไกลาสในฐานะองค์เทพ [6] [7] 

ความเชื่อมโยงระหว่างพระพักตร์ทองคำของเทวรูปและหน้ากากศพของกษัตริย์ในวัฒนธรรมจัมปา แสดงให้เห็นถึงการหลอมรวมระหว่างลัทธิเทวราชากับการนับถือผีบรรพชนดั้งเดิมของชาวออสโตรนีเชียน ซึ่งทองคำได้กลายเป็นสสารเชื่อมภพภูมิที่คงความบริสุทธิ์และศักดิ์สิทธิ์เหนือกาลเวลา [1] [2]

### 3. การค้นพบหน้ากากทองคำปิดตา-จมูกแห่งกิองลน (Giồng Lớn, เวียดนามใต้)

หากหน้ากากทองคำแห่งจัมปาสะท้อนบริบทของยุคประวัติศาสตร์ฮินดู การค้นพบทางโบราณคดีที่ **กิองลน (Giồng Lớn)** ในเขตจังหวัดบ่าเรียะ-หวุงเต่า (*Bà Rịa-Vũng Tàu Province*) ทางตอนใต้ของเวียดนาม กลับเปิดเผยขอบฟ้าวัฒนธรรมหน้ากากทองคำที่เก่าแก่กว่านั้นอย่างมหาศาล และมีความละม้ายคล้ายคลึงกับหน้ากากทองคำของฟิลิปปินส์อย่างน่าตื่นตะลึงที่สุด [1]

การขุดค้นที่กิองลนดำเนินการโดย อันเดรียส ไรเน็คเคอ (*Andreas Reinecke*) นักโบราณคดีแห่งสถาบันโบราณคดีเยอรมัน (*Deutsches Archäologisches Institut - DAI*) ร่วมกับ เหงียน ถิ ทัญ ลูเยน (*Nguyen Thi Thanh Luyen*) ในปี ค.ศ. 2003 และ 2005 [1] สุสานเนินทรายกิองลนตั้งอยู่ห่างจากปลายแหลมหวุงเต่า (*Cap Saint-Jacques*) เพียง 10 กิโลเมตร ซึ่งเป็นจุดแวะพักและจอดเรือที่สำคัญยิ่งบนเส้นทางการค้าทางทะเลโบราณข้ามอ่าวไทย [1]:

> "Quite obviously, the masks arrived in the Vung Tau area as a result of long-distance trade." [1]

การขุดค้นกู้ภัยบนพื้นที่รวม 536 ตารางเมตร ได้ค้นพบหลุมฝังศพมนุษย์ที่สมบูรณ์ถึง 72 หลุม และหลุมศพแบบฝังในไห (*jar burials*) อีก 7 หลุม [1]:

> "From March to May 2003, an excavation of five units with a total area of 344 sq. m was carried out, followed by a second campaign in June 2005 of two units consisting of 192 sq. m. Alto- gether, seventy-two inhumations and seven jar burials were discovered in the sandy soil" [1]

สิ่งที่สร้างความตื่นตะลึงให้แก่วงการโบราณคดีสากล คือการค้นพบ **หน้ากากทองคำแผ่นบาง 3 ชิ้น** ซึ่งถือเป็นหน้ากากทองคำยุคก่อนประวัติศาสตร์ชุดแรกที่เคยพบในดินแดนเวียดนาม [1] ไรเน็คเคอและลูเยนได้บันทึกรายละเอียดทางสัณฐานวิทยาและขนาดของหน้ากากทั้งสามไว้อย่างแม่นยำว่า:

> "They measure only 10.9 x 4.5 cm, 9.7 x 6.0 cm (both masks from 2003, following No. 1 and 2) and 9.1 x 7.5 cm (2005, No. 3) and are made from thin gold metal sheet. The first two specimens (No. | and 2) are not masks which covered the whole face of the dead person, but only of the eyes and nose." [1]


ข้อค้นพบที่สำคัญที่สุดคือ หน้ากากชิ้นที่ 1 และ 2 **"มิใช่หน้ากากที่ปิดคลุมทั้งใบหน้า แต่เป็นแผ่นทองคำที่ออกแบบมาเพื่อปิดเฉพาะช่องตาและจมูกเท่านั้น"** [1] ลักษณะการปิดเฉพาะอวัยวะรับสัมผัสนี้มีรูปร่างคล้ายแว่นตา (*eyeglass-shaped*) และที่ขอบของแผ่นทองคำมีการเจาะรูขนาดเล็กอย่างจงใจเพื่อใช้ในการยึดติด [1]:

> "All four corners of the mask No. | (1) have a small punched hole. The same seems to be so with the face mask No. 3 (3), although two corners have not survived. Mask No. 2 (2) has three holes along the edge at both sides. These holes point to the possibility that the masks were attached to a wood or cloth base, similar to the gold plaques of the Scythians." [1]

ในการกำหนดอายุทางวิทยาศาสตร์ การวัดอายุด้วยวิธีคาร์บอน-14 จากตัวอย่างถ่านในหลุมศพให้ค่าอายุสัมบูรณ์อยู่ในช่วง **410–90 ปีก่อนคริสตศักราช** ซึ่งสอดรับอย่างลงตัวกับการค้นพบเหรียญสำริดจีนโบราณสมัยราชวงศ์ฮั่นตะวันตก (เหรียญอู่จู, *Wu Shu*, 五銖) ในชั้นดินเดียวกัน [1]:

> "A radiocarbon date of charcoal from a grave provided a time span of 410—90 BC, which fits the terminus post quem of the coin for the inhumation with the gold mask and the main utilisation of the cemetery in the last century BC. Actually, two masks are rather eyes than face masks, and remind of the famous eyeglass-shaped mask offerings in burials of the Greco-Bactrian Kingdom of the 3rd and 2nd century BC (in present Afghanistan and neighbouring countries)." [1]

ไรเน็คเคอได้สร้างข้อสังเกตเชิงเปรียบเทียบที่ทรงคุณค่าอย่างยิ่ง โดยชี้ว่าหน้ากากปิดตาและจมูกแห่งกิองลนนี้ มีความสัมพันธ์เชิงขนบกับหลักฐานโบราณคดีชิ้นสำคัญในฟิลิปปินส์โดยตรง:

> "Another “fanciful eyes-nose gold mask found on a skull from the central Bisayas” in the Philippines has been mentioned. This mask is said to have been excavated by the Philippine National Museum at Oton Iloilo and has been dated in the 14th to 15th century." [1]

การที่นักโบราณคดีระดับสากลอย่างไรเน็คเคอเชื่อมโยงหน้ากากกิองลน (ศตวรรษที่ 1 ก่อน ค.ศ.) เข้ากับหน้ากากโอตอนแห่งฟิลิปปินส์ (ศตวรรษที่ 14–15) ตอกย้ำให้เห็นว่า มโนทัศน์เรื่องการใช้แผ่นทองคำปิดเฉพาะ "ตาและจมูก" มิใช่ปรากฏการณ์ที่เกิดขึ้นอย่างโดดเดี่ยวหรือบังเอิญในฟิลิปปินส์ หากแต่เป็นส่วนหนึ่งของสายธารประเพณีทางจิตวิญญาณที่มีความลึกซึ้งทางประวัติศาสตร์ข้ามทะเลจีนใต้ยาวนานกว่าหนึ่งพันห้าร้อยปี [1] [4] [8]

### 4. วัฒนธรรมยุคเหล็กโพร์เฮียร์และพุมสเนย์ในกัมพูชา (Prohear & Phum Snay, Cambodia)

ลึกลงไปในแผ่นดินใหญ่ตามแนวลุ่มน้ำโขง-สาบโบราณ ในเขตจังหวัดเปรยแวง (*Prey Veng Province*) ทางตะวันออกเฉียงใต้ของประเทศกัมพูชา การค้นพบสุสานยุคเหล็กตอนต้นที่หมู่บ้าน **โพร์เฮียร์ (Prohear)** ในปี ค.ศ. 2007 ได้สร้างปรากฏการณ์ใหม่ให้แก่วงการโบราณคดีโลหกรรมของเอเชียตะวันออกเฉียงใต้ [1] [9]

โพร์เฮียร์ได้รับการประเมินว่าเป็นหนึ่งในแหล่งฝังศพก่อนประวัติศาสตร์ที่ร่ำรวยด้วยเครื่องทองคำและเครื่องเงินมากที่สุดเท่าที่เคยขุดค้นพบในแผ่นดินใหญ่เอเชียตะวันออกเฉียงใต้ [9] [10] แม้ว่าแหล่งโบราณคดีแห่งนี้จะถูกชาวบ้านลักลอบขุดทำลายไปมากกว่า 1,000 หลุมศพ แต่การขุดค้นกู้ภัยทางวิชาการโดยสถาบันโบราณคดีเยอรมัน (DAI) ร่วมกับศูนย์เมมอต (*Memot Centre for Archaeology*) ได้ค้นพบข้อมูลเชิงประจักษ์ที่ทรงคุณค่ามหาศาล [1] [9]:

> "About 7 km to the north of Bit Meas, in spring 2007, one of the richest prehistoric burial sites of Southeast Asia was found in Prohear village... In Southeast Asia, never before was such a rich burial site of the Pre-Funan period discovered" [1]

> "no other prehistoric site in mainland Southeast Asia has yielded so many gold and silver objects... In fact, of all the archaeological sites that have been discovered along the neighboring Vietnamese coastline, only Oc Eo is ‘richer’ in this way than Prohear." [9]

```
+---------------------------------------------------------------------------------------------------+
|               ประเพณีพิธีศพและการใช้โลหะปิดใบหน้า ณ สุสานโพร์เฮียร์ (Prohear Mortuary Suite)       |
+---------------------------------------------------------------------------------------------------+
| 1. ลำดับระยะพิธีศพ (Mortuary Phases):                                                             |
|    - ระยะที่ 1 (Period I: 500–150 BCE): หลุมฝังศพยากจน ปราศจากเครื่องอุทิศทองคำและเงิน             |
|    - ระยะที่ 2 (Period II: 150 BCE – 100 CE): ยุคทองคำเฟื่องฟู ชนชั้นนำฝังร่วมกับทองคำ เงิน สำริด  |
|                                       ↓                                                           |
| 2. ประเพณีการใช้โลหะปิดและครอบใบหน้าศพ (Facial & Cranial Coverings):                              |
|    - การวางศีรษะศพไว้ภายในกลองมโหระทึกสำริด (Bronze Heger-I Drum Burial, หลุมที่ 4)               |
|    - การใช้ "ชามสำริด" (Bronze Bowl) ครอบปิดกะโหลกศีรษะของสตรีชนชั้นสูง                           |
|    - การใช้ "แผ่นจานหรือวงล้อสำริด" (Bronze Disc) ปิดทับใบหน้าของศพเด็กวัย 9 ขวบ                  |
|                                       ↓                                                           |
| 3. ผลการวิเคราะห์ทางโบราณโลหวิทยา (Archaeometry by Schlosser et al. 2012):                        |
|    - องค์ประกอบทอง-เงิน (Electrum): ช่วงความบริสุทธิ์ทองคำ 60%–95%, เงิน 99%                     |
|    - แหล่งแร่ปั่นทองคำมีดีบุก (Tin-bearing placer deposit) นำเข้าจากภายนอก                        |
|    - เทคนิคปิดทองสองแบบแรกในเอเชียตะวันออกเฉียงใต้: Foil-fusion gilding และ Depletion gilding     |
+---------------------------------------------------------------------------------------------------+
```

ไรเน็คเคอและคณะ (2010) ได้แบ่งระยะการใช้สุสานโพร์เฮียร์ออกเป็น 2 ระยะสำคัญ โดยพบว่าเครื่องทองและเงินปรากฏขึ้นเฉพาะใน **ระยะที่ 2 (Period II: ราว 150 ปีก่อน ค.ศ. ถึง ค.ศ. 100)** เท่านั้น [9]:

> "Furthermore, none of the inhumations or jar burials of period I contained gold or silver offerings, and on the whole they were not richly equipped." [9]

ในมิติของประเพณีการปฏิบัติต่อสรีระผู้ตาย สุสานโพร์เฮียร์แสดงให้เห็นถึงขนบพิธีกรรมที่น่าสนใจยิ่งในการ **"ปิดและปกคลุมใบหน้าศพด้วยโลหะ"** ซึ่งทำหน้าที่คู่ขนานกับคติหน้ากากทองคำ [1] [9]:
1. **การบรรจุศีรษะในกลองสำริด:** ในหลุมศพหมายเลข 4 ซึ่งเป็นหลุมศพของสตรีสูงศักดิ์ ("สุภาพสตรีชราผู้งดงาม", *burial of the fine old lady*) ศีรษะของผู้ตายถูกนำไปวางไว้ภายในกลองมโหระทึกสำริดแบบเฮเกอร์หนึ่ง (*Heger-I drum*) และมีเครื่องประดับทองคำและเงินบรรจุร่วมถึง 13 ชิ้น [9] [10]:
   > "A very specific burial custom of rich individuals at Prohear was to be buried with their head in a bronze drum, as we discovered in burial 4." [9]
2. **การใช้ชามสำริดครอบกะโหลกศีรษะ:** ในหลุมศพของสตรีชั้นสูงอีกรายหนึ่ง กะโหลกศีรษะถูกครอบปิดทับด้วยชามสำริด (*bronze bowl*) ซึ่งลักษณะเช่นนี้ยังพบที่แหล่งพุมสเนย์ (*Phum Snay*) ทางตะวันตกเฉียงเหนือของกัมพูชาเช่นกัน [9]:
   > "In the burial of another richly equipped woman, the skull was covered by a bronze bowl (Fig. 20). A similar feature is documented at Phum Snay in northwestern Cambodia." [9]
3. **การใช้แผ่นจานสำริดปิดใบหน้าเด็ก:** ในหลุมศพของเด็กอายุ 9 ขวบ มีการนำแผ่นวงล้อหรือจานสำริด (*bronze disc*) ทรงกลมมาวางปิดทับลงบนใบหน้าของศพโดยตรง [9]:
   > "Also exceptional is the grave of a 9-years-old child, whose face was covered by a bronze disc." [9]

นอกจากนี้ ไรเน็คเคอยังระบุในบทความ ค.ศ. 2009 ถึงการค้นพบในหลุมศพอื่นว่า:

> "in two other burials a mirror and a bowl, both of bronze, were used to cover the face in a similar way as the gold masks in Giong Lon." [1]

การใช้กระจกสัมฤทธิ์ ชามสัมฤทธิ์ และจานสำริดปิดทับใบหน้าของศพในโพร์เฮียร์และพุมสเนย์ สะท้อนถึง **"มโนทัศน์ร่วมแห่งการปิดกั้นใบหน้าและช่องทวาร" (Facial & Orifice Occlusion Concept)** ซึ่งหากชุมชนมีทรัพยากรทองคำเพียงพอก็จะใช้หน้ากากทองคำแผ่นบาง (เช่นที่กิองลนและฟิลิปปินส์) แต่หากใช้โลหะสำริดก็จะเลือกใช้วัตถุผิวเรียบสะท้อนแสง เช่น กระจกหรือก้นชาม เพื่อทำหน้าที่เชิงสัญลักษณ์ในการสะท้อนพลังชั่วร้ายและปกป้องดวงวิญญาณ [1] [9]

ในเชิงโบราณโลหวิทยา ซานดรา ชลอสเซอร์ (*Sandra Schlosser*) และคณะ (2012) ได้ทำการวิเคราะห์วัตถุทองคำและเงินจากโพร์เฮียร์ด้วยเทคนิคขั้นสูง LA-ICP-MS และ SEM-EDX เผยให้เห็นผลลัพธ์ที่สำคัญอย่างยิ่ง [10]:
- โลหะมีค่าครอบคลุมตั้งแต่เงินเกือบบริสุทธิ์ (99% Ag) ไปจนถึงทองคำเกรดสูง (95% Au) โดยโลหะผสมธรรมชาติแบบ **อิเล็กตรัม (Electrum)** ที่มีทองคำราว 60% เป็นโลหะที่พบมากที่สุด [10]:
  > "The artefacts show a wide range of composition from practically pure silver (99%) to high-grade gold (95%), electrum with about 60% gold as the most frequent alloy" [10]
- ธาตุร่องรอยชี้ว่าทองคำถูกสกัดมาจากแหล่งลานแร่ปั่นที่มีแร่ดีบุกปนอยู่ (*tin-bearing placer deposit*) [10]:
  > "that indicates that the gold was extracted from a tin-bearing placer deposit" [10]
- การค้นพบเทคนิคการปิดทอง 2 รูปแบบที่ก้าวหน้าอย่างยิ่ง ซึ่งพบเป็นครั้งแรกในเอเชียตะวันออกเฉียงใต้ ได้แก่ **Foil-fusion gilding** (การห่อฟอยล์ทองคำรอบแกนโลหะแล้วหลอมรวมด้วยความร้อน) และ **Depletion gilding** (การกัดกร่อนสลายโลหะไม่สูงศักดิ์ออกจากผิวหน้าเพื่อให้ผิวหน้ามีทองคำเข้มข้น) [10]:
  > "SEM-EDX analyses revealed two different gilding techniques so far unknown from Southeast Asia, foil-fusion gilding of silver objects and depletion gilding." [10]

หลักฐานทางวิทยาศาสตร์นี้ยืนยันว่า ช่างทองในภูมิภาคอินโดจีนและเอเชียตะวันออกเฉียงใต้โบราณมีองค์ความรู้ด้านโลหวิทยาขั้นสูงในการควบคุมความบางของแผ่นทองคำและการจัดการพื้นผิวโลหะ ซึ่งเป็นฐานรากทางเทคโนโลยีเดียวกับที่ปรากฏในงานช่างทองพิธีศพของฟิลิปปินส์ [8] [10]

### 5. บทวิเคราะห์สังเคราะห์เปรียบเทียบเชิงขอบฟ้าวัฒนธรรมกับฟิลิปปินส์

การนำข้อมูลโบราณคดีจากจัมปา กิองลน และโพร์เฮียร์ มาเปรียบเทียบกับกลุ่มแผ่นทองคำปิดทวารของฟิลิปปินส์ (โอตอน, บูตูอัน, เซบู) ช่วยให้นักวิจัยสามารถสร้างแบบจำลองวิวัฒนาการของประเพณีหน้ากากทองคำในเอเชียตะวันออกเฉียงใต้ได้อย่างเป็นรูปธรรม [1] [8] [11]:

```
|    (Ritual Function)| - จัมปา: เทวราชา พระพักตร์ทิพย์ศิวะ   |   กักเก็บดูงัน ค่าผ่านทางแม่น้ำสุลัด |

```

การเปรียบเทียบเผยให้เห็นข้อสรุปสำคัญ 3 ประการ:

ประการแรก **ความสืบเนื่องของสัณฐาน "ปิดเฉพาะตาและจมูก":** การที่หน้ากากทองคำชิ้นที่ 1 และ 2 แห่งกิองลน (410–90 ปีก่อน ค.ศ.) ทำหน้าที่ปิดเฉพาะช่องตาและจมูก และมีรูเจาะที่มุมเพื่อยึดติดกับโครงหน้า ถือเป็น **"ต้นแบบทางสัณฐานวิทยาข้ามสมุทร" (Trans-oceanic Morphological Archetype)** ที่ตรงกันอย่างน่าประหลาดใจกับชุดแผ่นทองปิดตาและปิดจมูกแห่งโอตอนและบูตูอันในฟิลิปปินส์ (ศตวรรษที่ 14–15) [1] [8] แม้จะมีระยะห่างทางเวลานับพันปี แต่มโนทัศน์ในการเลือกปกป้องเฉพาะ "ทวารรับรู้ส่วนบนของใบหน้า" (การมองเห็นและการหายใจ) ยังคงได้รับการสืบทอดอย่างเหนียวแน่น [1] [11]

ประการที่สอง **ความสัมพันธ์ทางเครือข่ายออสโตรนีเชียนระหว่างชาวจามกับชาววิซายัส:** ทั้งจัมปาและชุมชนชายฝั่งฟิลิปปินส์ต่างเป็นสังคมผู้พูดภาษาตระกูลออสโตรนีเชียนที่ผูกพันกับทะเลอย่างลึกซึ้ง ความเชื่อเรื่องพลังชีวิตที่สถิตอยู่ในร่างกายและการกลายสภาพเป็นผีบรรพชนศักดิ์สิทธิ์ (*Ancestral Cult*) เป็นมรดกทางวัฒนธรรมร่วม (*Shared Cultural Heritage*) ที่ทำให้ทั้งสองสังคมเลือกใช้ "ทองคำ" ซึ่งเป็นโลหะธาตุอมตะ ไม่หมอง และเป็นตัวแทนของแสงอาทิตย์ มาเป็นเกราะกำบังดวงวิญญาณและตราประทับแห่งเกียรติภูมิข้ามภพภูมิ [2] [3] [8]

ประการที่สาม **การแปรเปลี่ยนจากแผ่นโลหะสำริดสู่แผ่นทองคำบริสุทธิ์:** หลักฐานจากโพร์เฮียร์และพุมสเนย์ในกัมพูชา ซึ่งใช้ชามสัมฤทธิ์ กระจกสัมฤทธิ์ และจานสำริดปิดทับใบหน้าและศีรษะศพ แสดงให้เห็นว่าในยุคแรกเริ่ม (ยุคเหล็ก) ชุมชนโบราณในเอเชียตะวันออกเฉียงใต้พยายามแสวงหา "วัตถุโลหะสะท้อนแสง" มาทำหน้าที่ปกป้องใบหน้าของผู้ตาย [1] [9] เมื่อเครือข่ายการค้าทางทะเลเปิดกว้างขึ้นและการถลุงแร่ทองคำในท้องถิ่น (โดยเฉพาะในฟิลิปปินส์และดินดอนสามเหลี่ยมปากแม่น้ำโขง) พัฒนาสู่ระดับอุตสาหกรรม โลหะสำริดจึงถูกแทนที่ด้วย **"ทองคำบริสุทธิ์ตีบาง"** ซึ่งไม่เพียงแต่สะท้อนแสงได้เจิดจรัสกว่า แต่ยังไม่ผุกร่อนเป็นสนิมเขียวเหมือนสำริด ทำให้กลายเป็นสสารในอุดมคติที่สมบูรณ์แบบที่สุดในการพิทักษ์ทวารสรีระของมนุษย์สู่ความเป็นนิรันดร์ [8] [10] [12]
