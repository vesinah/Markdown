# บทที่ 5: กายวิภาคและการจัดวางแผ่นทองปิดทวารบนใบหน้าผู้ตาย

## 5.1 ประเภทวิทยาของแผ่นทองปิดทวาร (Typology of Orifice Covers): แผ่นปิดตาคู่, แผ่นปิดจมูก, แผ่นปิดปาก, และทองคำใส่ในปาก

### 1. บทนำและกรอบมโนทัศน์: การจำแนกประเภทวิทยาแผ่นทองคำปิดศพในโบราณคดีเอเชียตะวันออกเฉียงใต้

ในบรรดาโบราณวัตถุโลหะมีค่าที่ค้นพบจากหลุมฝังศพยุคก่อนอาณานิคมในภูมิภาคเอเชียตะวันออกเฉียงใต้ภาคพื้นสมุทร แผ่นทองคำปิดทวารบนใบหน้าผู้ตาย (*Mortuary Gold Orifice Covers*) ถือเป็นกลุ่มหลักฐานที่มีเอกลักษณ์เฉพาะตัวและมีความโดดเด่นทางสุนทรียศาสตร์สูงสุดกลุ่มหนึ่ง วัตถุเหล่านี้มิได้เป็นเพียงเครื่องประดับส่วนบุคคลที่สวมใส่ในชีวิตประจำวัน หากแต่เป็นโบราณวัตถุที่ถูกสร้างสรรค์ขึ้นด้วยจุดประสงค์เฉพาะทางพิธีกรรมความตาย (*Mortuary Purpose*) เพื่อใช้ปฏิบัติต่อสรีระของผู้ตายในวาระสุดท้ายแห่งการเปลี่ยนผ่านสู่ปรโลก [1]

การศึกษาวิเคราะห์เชิงประเภทวิทยา (*Typology*) ของแผ่นทองคำปิดศพในหมู่เกาะฟิลิปปินส์จำเป็นต้องเริ่มต้นจากการทำความเข้าใจความหลากหลายของรูปแบบ สัณฐาน ขนาด น้ำหนัก และเทคนิคการผลิต ช่างทองโบราณมิได้ผลิตแผ่นทองคำเหล่านี้ขึ้นอย่างสะเปะสะปะ หากแต่ปฏิบัติตามแบบแผนประเพณีที่มีการถ่ายทอดร่วมกันข้ามชุมชนชายฝั่งทะเลวิสายาส์และมินดาเนา ในสารานุกรมศิลปะของศูนย์วัฒนธรรมแห่งฟิลิปปินส์ (*CCP Encyclopedia of Philippine Art*) โดยปูริสซีมา เบนิเตซ-โจฮันนอต (*Purissima Benitez-Johannot*) ได้กำหนดกรอบการจำแนกแผ่นทองปิดหน้าศพของฟิลิปปินส์โบราณออกเป็น 2 ประเภทหลักอย่างชัดเจน [2]:

```
+---------------------------------------------------------------------------------------------------+
|               การจำแนกประเภทแผ่นทองปิดหน้าศพโบราณในฟิลิปปินส์ (Benitez-Johannot 2020)             |
+---+-----------------------------------------------------------------------------------------------+
| a | หน้ากากทองคำแบบเจาะช่องเปิดทวาร (Gold Masks with eyes, nostrils, and mouth cut out)         |
|   | - เป็นแผ่นทองคำแผ่นเดียวขนาดใหญ่คลุมใบหน้า หรือตัดฉลุช่องตา รูจมูก และปาก                     |
|   | - เปิดเผยให้เห็นช่องทวารทางกายวิภาคเดิมของผู้ตาย                                              |
+---+-----------------------------------------------------------------------------------------------+
| b | แผ่นทองคำปิดผนึกทวารเฉพาะจุด (Gold Sheets to Cover Orifices)                                  |
|   | - ประกอบด้วยชุดแผ่นทองคำบางแยกชิ้นสำหรับปิดทับดวงตา จมูก และปาก โดยเจตนาปิดกั้นช่องเปิด       |
|   | - บางครั้งพบร่วมกับแถบทองคำคาดหน้าผาก (Diadem) หรือเครื่องประดับศีรษะ                         |
+---+-----------------------------------------------------------------------------------------------+
```

ในบริบทของฟิลิปปินส์ หลักฐานทางโบราณคดีส่วนใหญ่ที่ค้นพบ ทั้งจากโอตอน จังหวัดอิโลอิโล, แหล่งแม่น้ำอากูซัน-บูตูอันในมินดาเนา, และแหล่งปลาซา อินเดเปนเดนเซีย ในเมืองเซบู จัดอยู่ในกลุ่มประเภทที่สอง (b) คือ **แผ่นทองคำสำหรับปิดทวารเฉพาะจุด** ซึ่งมุ่งเน้นการปิดกั้นช่องเปิดของประสาทสัมผัสทั้งสามอย่างจงใจ การทำความเข้าใจประเภทวิทยาของชุดแผ่นทองคำปิดทวารจึงต้องแยกพิจารณาสัณฐานวิทยาของชิ้นส่วนแต่ละประเภท ได้แก่ แผ่นปิดตาคู่ แผ่นปิดจมูก แผ่นปิดปาก ตลอดจนธรรมเนียมการใส่ทองคำไว้ภายในช่องปาก [2] [3]

### 2. แผ่นปิดตาคู่ (Ocular Covers / Eye Plaques / Eye Covers): สัณฐาน สัดส่วน และลวดลายฉลุดุนนูน

แผ่นทองคำปิดตาคู่เป็นชิ้นส่วนที่สะดุดตาที่สุดในชุดแผ่นทองปิดทวาร เนื่องจากตำแหน่งการจัดวางพาดทับเบ้าตา (*Orbital Cavities*) ของกะโหลกศีรษะ ซึ่งเป็นศูนย์กลางของการมองเห็นและการสื่อสารของมนุษย์ จากการรวบรวมข้อมูลเชิงปริมาณและสัณฐานวิทยา สามารถจำแนกแผ่นปิดตาออกเป็น 2 สกุลช่างหลัก [2] [4]:

```
+---------------------------------------------------------------------------------------------------+
|               การเปรียบเทียบสัณฐานวิทยาของแผ่นปิดตาคู่ (Ocular Covers Typology)                   |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|   1. แบบฉลุลายและดุนนูนจุดไข่ปลา (Repoussé & Openwork - สกุลช่างโอตอน):                            |
|      +-------------------------------------------------------------------------+                  |
|      |  .-''''-.         .-''''-.                                              |                  |
|      | ( ( * ) )========( ( * ) )   <-- แผ่นปิดตารูปใบไม้/วงรี มีก้านสะพานเชื่อมตรงกลาง       |
|      |  '-....-'         '-....-'   <-- ขอบดุนนูนจุดไข่ปลา (Beaded rim) ฉลุรูตาดำตรงกลาง  |
|      +-------------------------------------------------------------------------+                  |
|      * ขนาด: ยาว 13.3 ซม., กว้าง 2.5 ซม., น้ำหนัก 3.16 กรัม (เลขทะเบียน OT-MD-39)                |
|                                                                                                   |
|   2. แบบแผ่นเรียบขัดเงาแยกชิ้น (Plain Polished Sheets - สกุลช่างบูตูอันและเซบู):                 |
|      +---------------------+   +---------------------+                                            |
|      |     .------------.  |   |  .------------.     |                                            |
|      |    (   ตาซ้าย     ) |   | (    ตาขวา     )    |  <-- แผ่นทองบางรูปวงรีเรียบ ไร้ก้านเชื่อม  |
|      |     '------------'  |   |  '------------'     |  <-- ขอบเรียบกริบ ผิวขัดมันเงาสะท้อนแสง    |
|      +---------------------+   +---------------------+                                            |
|      * ขนาด: ยาว ~5.0–7.5 ซม. ต่อชิ้น, ความหนาบางเฉียบเพียง 0.08–0.15 มม.                        |
+---------------------------------------------------------------------------------------------------+
```

#### 2.1 แผ่นปิดตาแบบฉลุลายและดุนนูน (Repoussé & Openwork)
ตัวแทนที่สมบูรณ์และงดงามที่สุดของกลุ่มนี้คือ แผ่นปิดตาของหน้ากากทองคำโอตอน (*Oton Gold Death Mask*) ซึ่งเก็บรักษาและจัดแสดง ณ พิพิธภัณฑสถานแห่งชาติฟิลิปปินส์ แผ่นปิดตานี้มีหมายเลขทะเบียนวัตถุสถาบันคือ **OT-MD-39** ทำจากทองคำบริสุทธิ์ มีความยาวรวม 13.3 เซนติเมตร ความกว้างสูงสุด 2.5 เซนติเมตร และมีน้ำหนัก 3.16 กรัม [2]

สัณฐานของแผ่นปิดตาโอตอนประกอบด้วยแผ่นทองคำรูปวงรีคล้ายใบไม้สองแผ่นที่เชื่อมต่อกันด้วยแถบสะพานทองคำแคบๆ บริเวณหัวตาเหนือสันจมูก ลวดลายบนแผ่นปิดตาได้รับการรังสรรค์ด้วยเทคนิคการดุนนูนจากด้านหลัง (*Repoussé*) และการตอกลายจากด้านหน้า (*Chasing*) เกิดเป็นลวดลายขอบจุดไข่ปลา (*Beaded Dot Borders*) ที่ล้อมรอบแนวขอบรูปวงรี ที่กึ่งกลางของเบ้าตาทั้งสองข้างได้รับการเจาะฉลุเป็นช่องวงกลมขนาดเล็กเพื่อแทนตำแหน่งของตาดำ (*Pupil Apertures*) รูฉลุนี้สร้างความย้อนแย้งที่น่าพิศวงในเชิงสัญลักษณ์ กล่าวคือ แม้จะเป็นแผ่นปิดตาที่ทำหน้าที่คลุมเบ้าตา แต่ช่างทองกลับเจาะรูตาดำไว้เพื่อให้ "ดวงตาทองคำ" ยังคงสามารถทอดทัศนาสู่โลกวิญญาณได้ [2] [5]

#### 2.2 แผ่นปิดตาแบบเรียบขัดเงา (Plain Beaten Gold Sheets)
ในทางตรงกันข้าม ชุดแผ่นปิดตาที่ค้นพบจากแหล่งบูตูอันในมินดาเนาและปลาซา อินเดเปนเดนเซียในเมืองเซบู มีลักษณะเป็นแผ่นทองคำบางตัดเป็นรูปวงรีหรือรูปหยดน้ำแยกจากกันเป็นสองชิ้นอิสระ ช่างทองมิได้เจาะรูตาดำและมิได้ดุนนูนลวดลายวิจิตร หากแต่เน้นการตีแผ่นทองให้มีความบางสม่ำเสมอในระดับ 0.08 ถึง 0.15 มิลลิเมตร และทำการขัดผิวหน้าให้เรียบเกลี้ยงเป็นมันวาว (*Mirror-like Burnished Surface*) แผ่นปิดตาแบบเรียบทึบ (*Blind Eye Plaques*) นี้ทำหน้าที่ปิดกั้นการมองเห็นทางกายภาพอย่างสมบูรณ์ สะท้อนถึงมโนทัศน์แห่งการปิดฉากผัสสะในโลกทางโลกียะเพื่อเข้าสู่ความสงบนิรันดร์ [3] [6]

### 3. แผ่นปิดจมูก (Nasal Plaque / Nose Cover / Shield): สัณฐานวิทยาทรงสี่เหลี่ยมคางหมูและรูปสามเหลี่ยม

ทวารจมูกเป็นช่องทางเข้าออกของลมหายใจ ซึ่งในโลกทัศน์ของชาวออสโตรนีเชียน ลมหายใจคือสัญลักษณ์ของการมีชีวิต (*Breath of Life*) และเป็นเส้นทางหลักที่วิญญาณอาจหลุดลอยออกจากร่าง แผ่นปิดจมูกทองคำจึงได้รับการออกแบบให้มีสัณฐานเฉพาะทางกายวิภาคที่สอดรับกับความนูนโค้งของสันจมูกและปีกจมูก [1] [7]:

```
+---------------------------------------------------------------------------------------------------+
|               สัณฐานวิทยาและมิติขนาดของแผ่นปิดจมูกทองคำ (Nasal Plaque Morphology)                 |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|             ( ก้านบนแคบ พาดต่อจากหัวตา: กว้าง ~1.5–2.0 ซม. )                                      |
|                               +-------+                                                           |
|                               |       |   <-- ส่วนโคนสันจมูก (Nasal Bridge Root)                   |
|                               |   |   |                                                           |
|                               |   |   |   <-- แนวรอยพับกึ่งกลาง (Median Fold Ridge)               |
|                              /    |    \                                                          |
|                             /     |     \                                                         |
|                            /      |      \  <-- ปีกแผ่กว้างคลุมกระดูกปีกจมูก (Alae of Nose)       |
|                           +---------------+                                                       |
|             ( ฐานล่างกว้าง คลุมรูเปิดจมูก: กว้าง 5.5 ซม. ในกรณีโอตอน )                             |
|                                                                                                   |
|      * ข้อมูลวัตถุโอตอน (OT-MF-40): ความยาวรวม 16.3 ซม., กว้าง 5.5 ซม., น้ำหนัก 3.09 กรัม            |
|      * ความยาว 16.3 ซม. แสดงให้เห็นว่าแผ่นทองมิได้คลุมเพียงจมูก แต่ยื่นยาวลงมาจรดริมฝีปากบน         |
+---------------------------------------------------------------------------------------------------+
```

#### 3.1 ขนาด สัดส่วน และเลขทะเบียนวัตถุโอตอน (OT-MF-40)
แผ่นปิดจมูกของหน้ากากทองคำโอตอนมีหมายเลขทะเบียนสถาบันคือ **OT-MF-40** ทำจากทองคำบริสุทธิ์ มีความยาวถึง 16.3 เซนติเมตร ความกว้างบริเวณฐานล่าง 5.5 เซนติเมตร และมีน้ำหนัก 3.09 กรัม ตัวเลขความยาว 16.3 เซนติเมตรนี้มีความสำคัญอย่างยิ่งในทางกายวิภาคศาสตร์ เนื่องจากความยาวของสันจมูกมนุษย์ทั่วไปจากหว่างคิ้ว (*Glabella*) ถึงปลายจมูก (*Subnasale*) มีความยาวเฉลี่ยเพียงประมาณ 4.5 ถึง 5.5 เซนติเมตรเท่านั้น การที่แผ่นปิดจมูกโอตอนมีความยาวถึง 16.3 เซนติเมตร ชี้ชัดว่าแผ่นทองคำชิ้นนี้มิได้ถูกสร้างขึ้นเพื่อปิดเฉพาะสันจมูกเท่านั้น หากแต่ได้รับการออกแบบให้ทอดตัวยาวตั้งแต่แนวกึ่งกลางหน้าผาก ผ่านหว่างคิ้ว แนบลงมาตามสันจมูก และแผ่กว้างออกเพื่อคลุมทับรูจมูกและริมฝีปากบนลงมาเกือบถึงฟันหน้า [2] [5]

#### 3.2 สัณฐานวิทยาทรงสี่เหลี่ยมคางหมูและการพับสันนูน (Trapezoidal Form & Median Ridge)
แผ่นปิดจมูกส่วนใหญ่มีรูปทรงสี่เหลี่ยมคางหมูเรียวยาว (*Elongated Trapezoid*) หรือทรงสามเหลี่ยมยอดตัด ด้านบนที่แคบจะวางพาดอยู่บริเวณดั้งจมูกระหว่างหัวตาทั้งสองข้าง ขณะที่ด้านล่างจะผายกว้างออกเพื่อรองรับฐานปีกจมูก (*Alar Cartilages*) และรูเปิดจมูก (*Piriform Aperture*) [2]

ในเชิงวิศวกรรมการขึ้นรูปโลหะ แผ่นปิดจมูกมักปรากฏ **รอยพับสันนูนตามแนวยาวกึ่งกลาง (Median Longitudinal Ridge)** ซึ่งเกิดจากการที่ช่างทองใช้เครื่องมือรีดหรือพับแผ่นทองคำให้เกิดเป็นแนวสันสามมิติ รอยพับนี้ทำหน้าที่สองประการพร้อมกัน ประการแรกคือช่วยเพิ่มความแข็งแกร่งเชิงกล (*Mechanical Rigidity*) ไม่ให้แผ่นทองคำที่บางเฉียบงอพับหรือเสียรูปทรงได้ง่าย และประการที่สองคือทำให้แผ่นทองคำสามารถแนบสนิทไปกับสันกระดูกจมูกตามธรรมชาติของใบหน้ามนุษย์ได้อย่างพอดี [2] [8]

### 4. แผ่นปิดปาก (Oral Plaque / Mouth Cover) และทองคำใส่ในปาก (Intra-oral Gold)

ช่องปากเป็นทวารเปิดที่มีขนาดใหญ่ที่สุดบนใบหน้า เป็นทางเข้าของอาหาร เป็นแหล่งกำเนิดของถ้อยคำ วาจา และลมหายใจ ในระบบพิธีศพของฟิลิปปินส์โบราณ การปฏิบัติต่อช่องปากด้วยทองคำปรากฏใน 2 รูปแบบหลักที่มีความสัมพันธ์กันอย่างลึกซึ้ง [2] [9]:

```
+---------------------------------------------------------------------------------------------------+
|               มิติการปฏิบัติต่อช่องปากด้วยทองคำ (Oral Mortuary Practices)                         |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|   1. แผ่นทองคำปิดปากภายนอก (External Oral Plaque / Mouth Cover):                                 |
|      +---------------------------------------------------------+                                  |
|      |        .---------------------------------------.        |                                  |
|      |       (       แถบทองคำโค้งรับริมฝีปากบน-ล่าง     )       |                                  |
|      |        '---------------------------------------'        |                                  |
|      +---------------------------------------------------------+                                  |
|      - สัณฐานเป็นแถบยาวรูปพระจันทร์เสี้ยวหรือวงรีแคบปลายเรียวมน                                     |
|      - วางทาบปิดทับรอยแยกริมฝีปาก (Oral Fissure) โดยตรงเพื่อผนึกคำพูดและช่องเปิด                    |
|                                                                                                   |
|   2. ทองคำใส่ในช่องปาก (Intra-oral Gold / Mouth Deposits):                                       |
|      - การสอดใส่แผ่นทองคำม้วน แผ่นทองคำทรงกลม หรือเม็ดทองคำบริสุทธิ์เข้าไปใต้ลิ้นหรือในกระพุ้งแก้ม   |
|      - ทำหน้าที่เป็น "ค่าผ่านทางข้ามภพ" (Mortuary Viaticum / Charon's Obol Parallel)              |
|      - เชื่อมโยงกับฟันฝังหมุดทองคำ (Bansil / Pusad) ที่ฝังแน่นในเนื้อฟันตั้งแต่เมื่อยังมีชีวิต        |
+---------------------------------------------------------------------------------------------------+
```

#### 4.1 สัณฐานวิทยาของแผ่นปิดปากภายนอก (External Mouth Plaque)
แผ่นปิดปากมักถูกตัดแต่งเป็นแผ่นทองคำรูปแถบยาวขอบขนาน หรือรูปวงรีแคบที่ปลายทั้งสองข้างเรียวมน โค้งรับกับแนวรอยต่อของริมฝีปากบนและล่าง (*Labial Contour*) ความยาวของแผ่นปิดปากมักอยู่ในช่วง 6.0 ถึง 9.5 เซนติเมตร และกว้างประมาณ 1.5 ถึง 3.0 เซนติเมตร ซึ่งเพียงพอที่จะปิดคลุมช่องเปิดของปากได้อย่างมิดชิด [2] [3]

ในแง่ของลวดลาย แผ่นปิดปากอาจมีทั้งแบบเรียบเกลี้ยงขัดเงา เช่นที่พบในแหล่งปลาซา อินเดเปนเดนเซีย เซบู และแบบที่มีการตอกสลักลายเส้นหรือดุนนูนขอบ เช่นในบางตัวอย่างจากคอลเลกชันของธนาคารกลางแห่งฟิลิปปินส์ (*Bangko Sentral ng Pilipinas - BSP*) ซึ่งช่างทองได้ตอกลายเส้นเป็นแนวยาวคล้ายแนวฟันหรือรอยแยกลิปสติก เพื่อสะท้อนภาพจำลองของริมฝีปากในอุดมคติ [8]

#### 4.2 คติการใส่ทองคำไว้ภายในช่องปาก (Intra-oral Gold Deposit)
นอกเหนือจากการวางแผ่นทองคำปิดทับริมฝีปากภายนอกแล้ว ในบันทึกชาติพันธุ์วรรณนาและรายงานการขุดค้นหลุมศพหลายแห่งในมินดาเนาและลูซอน ยังพบหลักฐานการใส่เศษทองคำ เม็ดทองคำ หรือแผ่นทองคำม้วนขนาดเล็กเข้าไปไว้ภายในช่องปากของผู้ตายโดยตรง ดั่งที่วิลเลียม เฮนรี สก็อตต์ (*William Henry Scott*) ได้บันทึกไว้ใน *Barangay* ว่า ในพิธีศพของชนชั้นนำ จะมีการนำทองคำและลูกปัดมีค่าใส่ไว้ในปากของผู้ตายก่อนที่จะปิดโลง [9]

ธรรมเนียมนี้มีความคล้ายคลึงอย่างน่าทึ่งกับคติ "เหรียญปากผี" หรือเงินพลอดปากศพ (*Charon's Obol*) ในวัฒนธรรมกรีก-โรมันโบราณ และประเพณีการอมหยกรูปจักจั่น (*Yuhan*) ในวัฒนธรรมจีนราชวงศ์ฮั่น ซึ่งมีจุดมุ่งหมายเพื่อให้ผู้ตายมีทุนรอนในการเดินทางข้ามแม่น้ำแห่งความตายไปสู่อีกภพภูมิหนึ่ง และเพื่อเป็นหลักประกันว่าผู้ตายจะไม่ตกอยู่ในภาวะอดอยากหิวโหยในโลกหลังความตาย [1] [9]

### 5. องค์ประกอบเสริม: แถบคาดหน้าผาก (Diadem / Headband) และเครื่องประดับประกอบชุด

ในหลุมศพของชนชั้นนำระดับสูงสุด แผ่นปิดทวารทั้งสามมิได้ปรากฏอยู่อย่างโดดเดี่ยว หากแต่มักพบร่วมกับเครื่องประดับทองคำสำหรับศีรษะและร่างกาย ซึ่งรวมกันเป็น **"ชุดเครื่องทองพิธีศพสมบูรณ์" (Complete Mortuary Gold Parure)** [2] [8]:

#### 5.1 แถบทองคำคาดหน้าผาก (Diadem / Frontal Headband)
ในบทความของเบนิเตซ-โจฮันนอต ได้ระบุไว้อย่างชัดเจนว่า แผ่นปิดทวารทองคำในบางครั้งจะพบร่วมกับเครื่องประดับศีรษะ ซึ่งมีลักษณะเป็นแถบทองคำตีบาง (*Diadem / Ornamental Headband*) คาดขวางอยู่เหนือแนวกระดูกหน้าผาก (*Frontal Bone*) แถบทองคำนี้อาจมีความยาวตั้งแต่ 15 ถึง 30 เซนติเมตร มีการเจาะรูขนาดเล็กที่ปลายทั้งสองข้างเพื่อร้อยเชือกหรือเส้นด้ายผูกไว้ด้านหลังศีรษะ ลวดลายบนแถบคาดหน้าผากมักเป็นลายดุนนูนรูปเรขาคณิต ลายฟันปลา หรือลายกากบาท ซึ่งสอดรับกับลวดลายบนแผ่นปิดตาและปิดจมูกอย่างกลมกลืน [2]

การคาดแถบทองคำไว้เหนือหน้าผากของผู้ตายมีความสัมพันธ์เชิงพื้นที่อย่างแนบแน่นกับประเพณีการดัดกะโหลกศีรษะให้ลาดแบน (*Tangad*) เพราะระนาบหน้าผากที่ลาดเอียงไปทางด้านหลังจะกลายเป็นแท่นรองรับแถบทองคำได้อย่างมั่นคง ทำให้ประกายทองคำส่องสว่างเด่นชัดที่สุดเมื่อมองจากด้านหน้า [1] [4]

#### 5.2 ต่างหูทองคำและลูกปัดหินมีค่าร่วมบริบท
หลักฐานที่ยืนยันการประกอบชุดเครื่องประดับร่วมกับแผ่นปิดทวารอย่างเป็นวิทยาศาสตร์ที่สุดชิ้นหนึ่งคือ การค้นพบที่แหล่งปลาซา อินเดเปนเดนเซีย เมืองเซบู ซึ่งรายงานของพิพิธภัณฑสถานแห่งชาติ ค.ศ. 2022 และรายการภาพจัดแสดง ค.ศ. 2023 ระบุตรงกันว่า มีการขุดพบชุดแผ่นทองคำปิดทวารฉบับสมบูรณ์ร่วมกับ **ต่างหูทองคำคู่หนึ่ง (A Pair of Gold Earrings)** วางอยู่ข้างแนวกระดูกขมับทั้งสองข้างของกะโหลกศีรษะ [3] [10]

ต่างหูทองคำที่พบร่วมในหลุมศพมักเป็นต่างหูทรงห่วงผ่าซีก (*Penannular Ring*) หรือต่างหูแบบลูกตุ้มทิ้งดิ่ง (*Dangling Ear Ornaments*) ทำจากทองคำบริสุทธิ์เนื้อหนา ซึ่งสะท้อนให้เห็นว่าผู้ตายได้รับการประดับประดาอย่างเต็มยศ เสมือนหนึ่งกำลังเข้าร่วมงานเลี้ยงพิธีกรรมครั้งยิ่งใหญ่ที่สุดในชีวิต [3] [8]

### 6. หลักฐานเทคโนโลยีช่างทอง ณ บริเวณหลุมฝังศพ: เศษทองคำตัดแต่ง (In Situ Snippings)

ประเด็นสำคัญยิ่งในเชิงโบราณคดีที่เบนิเตซ-โจฮันนอต ได้บันทึกไว้ในสารานุกรมศิลปะฟิลิปปินส์ คือข้อสังเกตเรื่อง **สถานที่และช่วงเวลาของการสร้างแผ่นทองคำปิดทวาร** [2]:

> "They cut and hammered pure gold sheets into shape, in some cases preparing these in situ as snippings were recovered close by. In other instances, they sewed the gold sheets onto a support as evidenced by perforations along the gold sheet borders." [2]
> 
> *คำแปลสรุปความ:* "ช่างตัดและตีแผ่นทองคำบริสุทธิ์เป็นรูปร่าง โดยในบางกรณีมีการเตรียมแผ่นทองเหล่านี้ขึ้น ณ บริเวณสถานที่ฝังศพเอง (*in situ*) ดั่งปรากฏหลักฐานจากการค้นพบเศษทองคำที่ถูกขลิบตัดทิ้งตกอยู่ใกล้เคียง และในกรณีอื่น ๆ ช่างได้เย็บแผ่นทองคำเข้ากับวัสดุรองรับ ดังมีหลักฐานเป็นรูเจาะตามแนวขอบของแผ่นทองคำ" [2]

ข้อความทางวิชาการนี้เปิดเผยข้อเท็จจริงสำคัญ 2 ประการที่เปลี่ยนกระบวนทัศน์ทางโบราณคดี:

1. **การปรับแต่งตามสรีระจริงเฉพาะบุคคล (Customized In Situ Fabrication):** การพบเศษทองคำที่ถูกขลิบตัด (*Snippings*) ตกค้างอยู่ในชั้นดินข้างหลุมศพแสดงให้เห็นว่า แผ่นทองคำปิดทวารมิใช่สินค้าสำเร็จรูปที่ผลิตเป็นอุตสาหกรรมล่วงหน้าในปริมาณมาก หากแต่เป็นงานหัตถการที่ช่างทอง (*Panday Ginto*) อาจนำแผ่นทองคำเปลวดิบมาร่วมในพิธีศพ แล้วทำการวัดสัดส่วนใบหน้า กรีด ตัด และดัดแต่งรูปทรงของแผ่นทองให้เข้ากับมิติสรีระจริงของผู้ตายในขณะนั้น เพื่อให้แผ่นทองสามารถปิดทับเบ้าตา สันจมูก และริมฝีปากได้อย่างแนบสนิทที่สุด [2]
2. **การเย็บตรึงเข้ากับผ้าห่อศพหรือเสื่อ (Sewn Mortuary Shrouds):** การปรากฏรูเจาะขนาดเล็ก (*Perforations*) เรียงรายตามแนวขอบของแผ่นทองคำในบางชิ้นงาน ชี้ชัดว่าแผ่นทองมิได้ถูกวางลอย ๆ บนผิวหนังเสมอไป แต่ในหลายกรณี แผ่นทองคำถูกเย็บติดเข้ากับผ้าห่อศพนำเข้าจากจีน เสื่อสาน หรือหน้ากากผ้าฝ้ายรองรับ ก่อนที่จะนำมาคลุมทับใบหน้าผู้ตาย ซึ่งช่วยป้องกันไม่ให้แผ่นทองคำเลื่อนหลุดจากตำแหน่งเมื่อมีการเคลื่อนย้ายร่างเข้าสู่โลงไม้หรือไหฝังศพ [2] [9]

### 7. สรุปประเภทวิทยาและข้อถกเถียงเชิงหน้าที่ของตอนที่ 5.1

จากการประมวลข้อมูลเชิงประเภทวิทยาในตอนที่ 5.1 สามารถสรุปภาพรวมของแผ่นทองคำปิดทวารในฟิลิปปินส์ได้ว่า ประกอบด้วยโครงสร้างสัณฐาน 3 ส่วนหลักที่ทำหน้าที่ประสานกัน: แผ่นปิดตาคู่ (เพื่อปิดกั้นและแปลงสายตา), แผ่นปิดจมูกยาว (เพื่อผนึกลมหายใจและคลุมแนวดั้งหน้าผากถึงปาก), และแผ่นปิดปาก (เพื่อสะกดถ้อยคำและกักเก็บวิญญาณ) พร้อมด้วยองค์ประกอบเสริมอย่างแถบคาดหน้าผากและต่างหูทองคำ [2] [3]

ความหลากหลายระหว่างแผ่นทองแบบฉลุลายดุนนูนของโอตอน กับแผ่นทองเรียบขัดเงาของบูตูอันและเซบู มิได้เป็นเพียงความแตกต่างของรสนิยมทางสุนทรียศาสตร์ส่วนบุคคล หากแต่สะท้อนถึงสำนักช่างทองท้องถิ่น (*Regional Goldsmithing Traditions*) ที่มีพัฒนาการเฉพาะตัวในแต่ละแอ่งอารยธรรมทางทะเล ข้อมูลประเภทวิทยาเหล่านี้จะเป็นกุญแจสำคัญในการนำไปสู่การวิเคราะห์ใน **ตอนที่ 5.2** ซึ่งจะเจาะลึกมิติทางกายวิภาคศาสตร์ การจัดวางตำแหน่งบนกะโหลกศีรษะจริง ลำดับการซ้อนทับ และทิศทางการหันด้านของแผ่นทองคำอย่างเป็นวิทยาศาสตร์ต่อไป [1] [2] [3]
