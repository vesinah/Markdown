# บทที่ 8: จักรวาลวิทยาความตาย โลกทัศน์วิญญาณนิยม และคติการคุ้มครองทวารสรีระ

## 8.1 ภูมิทัศน์วิญญาณนิยมและจักรวาลวิทยาความตายของกลุ่มชนออสโตรนีเชียน: โลกหน้า, สุลัด, และพิธีกรรมเปลี่ยนผ่านสภาวะ

### 1. บทนำและกรอบมโนทัศน์: จักรวาลวิทยาความตายของกลุ่มชนผู้ใช้ภาษาตระกูลออสโตรนีเชียน

ในทางมานุษยวิทยาสัญลักษณ์และโบราณคดีศาสนา ความตายมิได้เป็นเพียงปรากฏการณ์ทางชีววิทยาที่การทำงานของอวัยวะและเซลล์ในร่างกายมนุษย์ยุติลงเท่านั้น หากแต่เป็น "ปรากฏการณ์ทางสังคมและจักรวาลวิทยา" (*Cosmological and Social Phenomenon*) ที่กระตุ้นให้เกิดระบบความเชื่อ พิธีกรรม และวัฒนธรรมวัตถุที่ซับซ้อนที่สุดของมนุษยชาติ [1] [2] สำหรับกลุ่มชนผู้ใช้ภาษาตระกูลออสโตรนีเชียน (*Austronesian-speaking Peoples*) ซึ่งตั้งถิ่นฐานและแผ่ขยายอารยธรรมครอบคลุมทั่วหมู่เกาะเอเชียตะวันออกเฉียงใต้และมหาสมุทรแปซิฟิก มโนทัศน์เกี่ยวกับความตายมีลักษณะร่วมทางวัฒนธรรมที่ลึกซึ้งและหยั่งรากลึกมายาวนานนับพันปี [2] [3]

โลกทัศน์วิญญาณนิยมดั้งเดิมของชาวออสโตรนีเชียน (*Indigenous Austronesian Animism*) มองจักรวาลเป็นองค์รวมที่สิ่งมีชีวิต มนุษย์ ธรรมชาติ สิ่งแวดล้อม และดวงวิญญาณ เชื่อมโยงสัมพันธ์กันอย่างไร้รอยต่อ [3] [4] โลกมิได้ถูกแบ่งแยกอย่างเด็ดขาดระหว่าง "กายภาพ" กับ "จิตวิญญาณ" หากแต่มีมิติซ้อนทับกันอยู่ตลอดเวลา ในกรอบทัศน์นี้ มนุษย์มิได้เป็นเจ้าเหนือธรรมชาติ หากแต่เป็นส่วนหนึ่งของสายใยแห่งพลังงานชีวิต จักรวาลเต็มไปด้วยอำนาจลึกลับ ดวงวิญญาณของบรรพบุรุษ (*Ancestral Spirits*) และอำนาจเหนือธรรมชาติประจำถิ่น (*Spirits of Nature*) [4] [5]

เมื่อความตายมาเยือน สังคมออสโตรนีเชียนมิได้ตีความว่าการดับสูญของร่างกายคือจุดสิ้นสุดของอัตลักษณ์บุคคล (*Annihilation of Being*) หากแต่ทำความเข้าใจความตายในฐานะ **"พิธีกรรมเปลี่ยนผ่านสภาวะ" (Rite of Passage)** ตามกรอบทฤษฎีคลาสสิกของอาร์โนลด์ ฟาน เจนเนป (*Arnold van Gennep*) [1] ฟาน เจนเนป ชี้ให้เห็นว่า พิธีกรรมเปลี่ยนผ่านทุกประเภทประกอบด้วย 3 ระยะสำคัญ ได้แก่:
1. **ระยะการแยกตัว (Separation / Preliminal Phase):** การตัดขาดผู้ตายออกจากโลกของคนเป็น
2. **ระยะช่วงต่อหรือระยะก้ำกึ่ง (Liminal / Transitional Phase):** สภาวะที่วิญญาณของผู้ตายยังมิได้เข้าสู่ดินแดนใหม่โดยสมบูรณ์ และร่างศพยังอยู่ในระหว่างการสลายตัว ซึ่งเป็นช่วงเวลาที่อันตรายและเปราะบางที่สุด
3. **ระยะการรวมตัวใหม่ (Incorporation / Postliminal Phase):** การที่ดวงวิญญาณของผู้ตายได้เข้าสถิตในดินแดนบรรพชนอย่างถาวร และได้รับการยกระดับสถานะขึ้นเป็นผีบรรพบุรุษผู้ทรงฤทธิ์ [1] [2]

ในบริบทของหมู่เกาะฟิลิปปินส์ยุคก่อนอาณานิคม โบราณวัตถุทองคำโดยเฉพาะแผ่นทองคำปิดทวารบนใบหน้าผู้ตาย (*Mortuary Gold Orifice Covers*) ทำหน้าที่เป็น "กลไกวัตถุเชิงพิธีกรรม" (*Ritual Material Technology*) ที่ถูกสร้างขึ้นมาเพื่อควบคุมและคุ้มครองความปลอดภัยของบุคคลในช่วงระยะก้ำกึ่ง (*Liminal Phase*) ของการเปลี่ยนผ่านสภาวะนี้โดยตรง [2] [3] [6]

```
+---------------------------------------------------------------------------------------------------+
|               วงจรพิธีกรรมเปลี่ยนผ่านสภาวะแห่งความตายในจักรวาลวิทยาออสโตรนีเชียน                     |
+---------------------------------------------------------------------------------------------------+
| 1. ระยะแยกตัว (Separation):                                                                       |
|    - สรีระสิ้นลมหายใจ → พันธะระหว่างพลังชีวิต (Dungan) กับวิญญาณอมตะ (Kalag) เริ่มคลายตัว           |
|    - การชำระล้างร่างด้วยน้ำหอมการบูรและสมุนไพร เพื่อตัดขาดจากมลทินของโลกคนเป็น                     |
|                                       ↓                                                           |
| 2. ระยะก้ำกึ่ง (Liminal Phase) - **ช่วงอันตรายสูงสุด**:                                           |
|    - ร่างกายกำลังเน่าเปื่อย ช่องทวารเปิดกว้าง กลายเป็นประตูเชื่อมต่อระหว่างสองโลก                  |
|    - ภัยคุกคามจากภูตผีปีศาจกินซากศพ (Asuang / Balbal / Mahikawon) ที่จะมาชิงวิญญาณ                 |
|    - **การแทรกแซงด้วยแผ่นทองคำปิดทวาร (ตา จมูก ปาก)**: สถาปนาเกราะพิทักษ์อภิปรัชญา                 |
|    - การบังคับใช้ข้อห้ามไว้ทุกข์ลาราโอ (Larao Strict Taboos) สร้างความสงบศักดิ์สิทธิ์            |
|                                       ↓                                                           |
| 3. ระยะรวมตัวใหม่ (Incorporation):                                                                |
|    - การนำพาดวงวิญญาณข้ามห้วงน้ำใหญ่ด้วยเรือแห่งดวงวิญญาณ (Boat of the Dead)                       |
|    - การเดินทางถึงดินแดนบรรพบุรุษ (Sulad / Saad / Kasakian)                                       |
|    - การเปลี่ยนผ่านสถานะของ Kalag ขึ้นเป็น **อานิโต (Anito)** หรือ **อูมาลากัด (Umalagad)**         |
|      เพื่อทำหน้าที่พิทักษ์คุ้มครองวงศ์ตระกูลที่ยังมีชีวิตสืบไป                                    |
+---------------------------------------------------------------------------------------------------+
```

### 2. แนวคิดเรื่องโลกหน้า: สุลัด (Sulad), ซาอัด (Saad), และกาสะเคียน (Kasakian)

จักรวาลวิทยาของสังคมฟิลิปปินส์โบราณ โดยเฉพาะในกลุ่มชาติพันธุ์วิซายาส์ (*Visayan Ethnolinguistic Groups*) ซึ่งได้รับการบันทึกไว้อย่างละเอียดในจดหมายเหตุสเปนศตวรรษที่ 16 และงานวิจัยชาติพันธุ์วรรณนา มีโครงสร้างภูมิศาสตร์แห่งปรโลก (*Mythological Geography of the Underworld*) ที่มีความหลากหลายและสะท้อนสภาพแวดล้อมทางทะเลของหมู่เกาะอย่างแจ่มชัด [4] [7]

มิเกล เด โลอาร์กา (*Miguel de Loarca*) ในบันทึกประวัติศาสตร์ *Relación de las Yslas Filipinas* (ค.ศ. 1582) ได้บันทึกถึงความเชื่อเรื่องดินแดนแห่งความตายของชาววิซายาส์ไว้ว่า โลกหน้าถูกแบ่งออกเป็นมิติต่าง ๆ ตามสถานะและลักษณะการตายของบุคคล [7] ดินแดนหลังความตายที่เป็นที่รู้จักมากที่สุดมี 3 ภพภูมิหลัก [4] [7]:

```
+---------------------------------------------------------------------------------------------------+
|               โครงสร้างภูมิศาสตร์ปรโลกในจักรวาลวิทยาความตายของชาววิซายาส์โบราณ                     |
+-------------------+----------------------------+-----------------------+--------------------------+
|  ชื่อดินแดนปรโลก  |       ที่ตั้งทางจักรวาล    |        สภาพแวดล้อม    |   กลุ่มบุคคลผู้เข้าพำนัก  |
|   (Afterlife Realm|     (Cosmic Location)      |      (Environment)    |      (Destined Souls)    |
+-------------------+----------------------------+-----------------------+--------------------------+
| 1. สุลัด          | ตั้งอยู่ใต้พิภพหรือข้ามทะเล | ดินแดนที่อุดมสมบูรณ์   | วิญญาณของบุคคลทั่วไป     |
|    (Sulad)        | ลึกในแนวเทือกเขาศักดิ์สิทธิ์| มีหมู่บ้าน ลำน้ำ และ  | และชนชั้นนำที่ประกอบ     |
|                   | (เช่น Mount Madya-as)      | สวนเกษตรกรรมคล้ายโลก  | พิธีกรรมศพอย่างครบถ้วน   |
+-------------------+----------------------------+-----------------------+--------------------------+
| 2. ซาอัด          | ภพภูมิสัญญาสวรรค์          | ดินแดนแห่งความรื่นรมย์ | ชนชั้นนำดาตูและนักรบ     |
|    (Saad)         | บนยอดเขาสูงหรือเกาะสวรรค์  | มีงานเลี้ยงฉลอง อาหาร | ผู้ประกอบวีรกรรมและมี     |
|                   | ในทิศที่ดวงอาทิตย์ตก       | และสุราพังกาซีไม่รู้จบ| เครื่องอุทิศทองคำพรั่งพร้อม|
+-------------------+----------------------------+-----------------------+--------------------------+
| 3. กาสะเคียน      | ภพภูมิแห่งความมืดมิด       | ดินแดนแห้งแล้ง หนาวเย็น| วิญญาณของผู้ตายผิดธรรมชาติ|
|    (Kasakian)     | ใต้ก้นบึ้งของมหาสมุทร      | เต็มไปด้วยความทุกข์ทรมาน| คนยากจนที่ไร้เครื่องอุทิศ|
|                   | หรือหุบเหวลึก              | และการถูกลงโทษ        | หรือผู้ละเมิดจารีตชุมชน  |
+-------------------+----------------------------+-----------------------+--------------------------+
```

โลอาร์การะบุว่า เมื่อบุคคลเสียชีวิต ดวงวิญญาณจะต้องเดินทางไปยังดินแดนที่เรียกว่า **สุลัด (Sulad)** ซึ่งมักตั้งอยู่ ณ ปลายสุดของขอบฟ้าทางทะเลหรือบนยอดเขาสูงศักดิ์สิทธิ์ เช่น เทือกเขามาดียัส (*Mount Madya-as*) ในเกาะปานาย [4] [7] สุลัดมิได้มีสภาพเป็นนรกแห่งการลงทัณฑ์ตามแนวคิดคริสต์ศาสนา หากแต่เป็นภาพสะท้อนของโลกมนุษย์ที่มีหมู่บ้าน ทุ่งนา ลำธาร และป่าไม้ ที่ซึ่งดวงวิญญาณของบรรพชนจะกลับมารวมตัวกันและใช้ชีวิตสืบเนื่องต่อไป [4] [7]

ในงานศึกษาชาติพันธุ์วรรณนาของเอฟ. ลันดา โฮกาโน (*F. Landa Jocano*) เกี่ยวกับชาวซูลอด (*Sulod*) ในเทือกเขากลางเกาะปานาย ซึ่งเป็นกลุ่มชนดั้งเดิมที่สืบทอดความเชื่อก่อนอาณานิคม ได้ให้รายละเอียดเกี่ยวกับมหากาพย์การเดินทางของวิญญาณสู่สุลัดว่า วิญญาณจะต้องเผชิญหน้ากับด่านตรวจสอบหลายด่าน และต้องข้ามลำน้ำแห่งความตายขนาดใหญ่ [8] [9] ผู้ตายที่จะสามารถข้ามผ่านเข้าสู่สุลัดหรือภพภูมิสวรรค์ **ซาอัด (Saad)** ได้อย่างราบรื่น จะต้องเป็นบุคคลที่ได้รับการประกอบพิธีกรรมอย่างถูกต้องจากญาติมิตร มีการแต่งกายด้วยอาภรณ์ที่ดีที่สุด และมี "เครื่องเบิกทาง" ที่ทำจากทองคำบริสุทธิ์ [4] [8]

ในทางตรงกันข้าม หากบุคคลใดเสียชีวิตโดยไม่มีผู้ประกอบพิธีกรรมให้ ไร้ญาติมิตร หรือเป็นทาสที่ไร้เครื่องอุทิศ ดวงวิญญาณจะถูกผลักไสให้ตกลงสู่ **กาสะเคียน (Kasakian)** ซึ่งเป็นดินแดนแห่งความทุกข์ยาก โดดเดี่ยว และมืดมนใต้ก้นบึ้งของมหาสมุทร [4] [7] จักรวาลวิทยาความตายของออสโตรนีเชียนจึงเป็นโครงสร้างที่ตอกย้ำและสืบทอด "สถานภาพทางสังคมและชนชั้น" (*Social Hierarchy*) จากโลกมนุษย์ไปสู่โลกหน้าอย่างไม่มีวันสิ้นสุด [2] [4]

### 3. ความตายในฐานะการเปลี่ยนผ่านสถานะ (Rite of Passage) มิใช่จุดสิ้นสุด

มโนทัศน์ที่ว่าความตายคือการเปลี่ยนผ่านสภาวะ มิใช่การดับสูญ ก่อให้เกิดทัศนคติและการปฏิบัติต่อสรีระของผู้ตายที่แตกต่างอย่างลึกซึ้งจากสังคมสมัยใหม่ [1] [2] สรีระของบุคคลหลังความตายมิได้ถูกมองว่าเป็นเพียง "ซากศพ" (*Corpse*) ที่ไร้ประโยชน์และต้องรีบนำไปกำจัดทิ้ง หากแต่เป็น "ภาชนะศักดิ์สิทธิ์" (*Sacred Vessel*) ที่ยังคงมีความผูกพันกับอัตลักษณ์และสถานะของดวงวิญญาณตลอดระยะเวลาของการเปลี่ยนผ่าน [2] [3]

วิลเลียม เฮนรี สก็อตต์ (*William Henry Scott*) นักประวัติศาสตร์ชั้นครู ได้ชี้ให้เห็นว่า ในสังคมฟิลิปปินส์ศตวรรษที่ 16 กระบวนการจัดการศพของชนชั้นนำดาตูเป็นกระบวนการที่ยาวนาน กินเวลาหลายวันจนถึงหลายสัปดาห์ [4]:

> "All datus or prominent persons wanted to be buried in a traditional longon, decorated with fanciful carvings often executed by the future occupant himself during his lifetime. Some wore ac tual masks and mouthpieces of beaten gold... The dead were buried in coffins placed in caves with thin plates of gold over their mouth and eyes" [4]

ความปรารถนาของชนชั้นนำที่จะได้รับการบรรจุในโลงไม้ขุดเนื้อแข็ง (*Longon*) ที่ตนเองเป็นผู้แกะสลักลวดลายขึ้นในขณะที่ยังมีชีวิต และการสวมใส่หน้ากากทองคำหรือแผ่นปิดตาปิดปากทองคำ สะท้อนถึง **"การเตรียมการล่วงหน้าเพื่อการเปลี่ยนผ่านสภาวะ"** อย่างมีสติ [2] [4] ความตายสำหรับดาตูมิใช่อุบัติเหตุที่น่าหวาดกลัว แต่เป็นขั้นตอนสำคัญที่สุดของการบรรลุสถานภาพสูงสุดแห่งชีวิต คือการเปลี่ยนผ่านจาก "ผู้นำทางการเมืองในโลกมนุษย์" ไปสู่ "เทพบรรพชนผู้อารักษ์ชุมชนในปรโลก" (*Apotheosis into Ancestral Deity*) [2] [4]

ในระหว่างที่สรีระนอนสงบนิ่งอยู่ในโลงไม้ลองกอน ชุมชนจะร่วมกันประกอบพิธีกรรมเพื่อประคับประคองการเปลี่ยนผ่านนี้ การที่ร่างกายยังคงรักษารูปลักษณ์ มีการประดับเครื่องทองคำ และมีการอุดชโลมช่องทวารด้วยน้ำยางพลู (*Buyo Sap*) เป็นการส่งสัญญาณทางสัญลักษณ์แก่ปวงผีบรรพชนว่า ผู้ตายพร้อมแล้วที่จะละทิ้งพันธะแห่งโลกียะและก้าวเข้าสู่ความเป็นอมตะ [4] [6]

### 4. ความสัมพันธ์ระหว่างสรีระวัตถุกับจักรวาลวิทยา: สุสานในฐานะพื้นที่ศักดิ์สิทธิ์รอยต่อระหว่างภพ

ในภูมิทัศน์เชิงพื้นที่ (*Spatial Landscape*) ของสังคมออสโตรนีเชียน สุสานมิได้เป็นเพียงพื้นที่ทิ้งซากศพทางกายภาพ หากแต่เป็น **"พื้นที่ศักดิ์สิทธิ์แห่งรอยต่อระหว่างภพ" (Liminal Heterotopia)** [2] [10] การเลือกทำเลที่ตั้งของสุสานในแหล่งโบราณคดีสำคัญของฟิลิปปินส์ เช่น แหล่งซานอันโตนิโอ โอตอน ริมแนวสันทรายชายฝั่งช่องแคบอิโลอิโล, สุสานอัมบังกันและซูอาตันริมแม่น้ำอากูซันในบูตูอัน, และสุสานปลาซาอินเดเปนเดนเซียริมอ่าวเซบู ล้วนมีความสัมพันธ์อย่างแนบแน่นกับ "น้ำ" (*Water*) และ "การเชื่อมต่อทางภูมิศาสตร์" [2] [10] [11]

น้ำในจักรวาลวิทยาออสโตรนีเชียนมีนัยทางสัญลักษณ์ 2 ประการที่ขัดแย้งและประสานกัน:
ในด้านหนึ่ง น้ำคือสื่อกลางแห่งการค้า ความมั่งคั่ง และการเชื่อมต่อระหว่างชุมชนชายฝั่ง
ในอีกด้านหนึ่ง น้ำคือ "พรมแดนธรรมชาติที่แบ่งแยกโลกคนเป็นออกจากโลกคนตาย" [3] [10]
การตั้งสุสานไว้ริมแม่น้ำหรือชายฝั่งทะเล สะท้อนถึงการเตรียมความพร้อมให้ดวงวิญญาณสามารถก้าวลงสู่เรือเพื่อแล่นออกสู่อ่าวและข้ามทะเลหลวงไปสู่ดินแดนสุลัดได้อย่างสะดวก [8] [10]

ภายในหลุมศพ การจัดวางสรีระและวัฒนธรรมวัตถุถูกควบคุมด้วยแบบแผนจักรวาลวิทยาอย่างเข้มงวด การวางทิศทางของศีรษะส่วนใหญ่จะหันไปทางทิศตะวันออกหรือทิศเหนือ ซึ่งเป็นทิศแห่งการกำเนิด แสงสว่าง และภูเขาศักดิ์สิทธิ์ต้นน้ำ [10] [12] การวางแผ่นทองคำปิดตา ปิดจมูก และปิดปากลงบนใบหน้าของผู้ตายในหลุมศพ เป็นการสถาปนา "พื้นที่ศักดิ์สิทธิ์ขนาดจิ๋ว" (*Micro-sacred Space*) ขึ้นบนร่างกายของมนุษย์ [3] [6] ร่างกายที่ถูกปิดทวารด้วยทองคำจะไม่สามารถถูกแทรกซึมโดยพลังงานด้านลบของดินหรือสิ่งอัปมงคล และกลายเป็นสะพานเชื่อมทางจิตวิญญาณระหว่างพื้นที่หลุมฝังศพใต้ดินกับภพภูมิบรรพบุรุษเบื้องบน [2] [6]

### 5. บทสังเคราะห์: อุดมการณ์ทางวัฒนธรรมที่ผลักดันการใช้ทองคำในพิธีกรรมศพ

เหตุใดสังคมฟิลิปปินส์โบราณจึงเลือกใช้ "ทองคำ" เป็นวัสดุหลักในการปิดกั้นช่องทวารบนใบหน้าผู้ตาย? คำตอบสำหรับคำถามเชิงโครงสร้างนี้มิได้จำกัดอยู่เพียงเรื่องของความมั่งคั่งทางเศรษฐกิจเท่านั้น หากแต่อยู่ที่ **"อภิปรัชญาแห่งคุณสมบัติของทองคำ" (The Metaphysics of Gold)** ในระบบสัญลักษณ์นิยมออสโตรนีเชียน [2] [3]

จอห์น กาย (*John Guy*) และแมรี เจน หลุยส์ โบลูเนีย (*Mary Jane Louise Bolunia*) ได้วิเคราะห์อย่างลึกซึ้งว่า ทองคำเป็นสสารชนิดเดียวในธรรมชาติที่รวบรวมคุณสมบัติอุดมคติ 3 ประการไว้พร้อมกัน [3] [6]:
1. **ความบริสุทธิ์ไม่เสื่อมสลาย (Incorruptibility):** ในโลกที่ทุกสิ่งทุกอย่าง ตั้งแต่ร่างกายมนุษย์ พืชพันธุ์ ไปจนถึงไม้และผ้า ต้องเน่าเปื่อยผุพังสลายตัวไปตามกาลเวลา ทองคำเป็นสสารเดียวที่ไม่เกิดสนิม ไม่ดำคล้ำ และไม่ผุกร่อน ทองคำจึงกลายเป็น "อุปมานิทรรศน์แห่งความเป็นอมตะ" (*Metaphor of Immortality*) ที่สมบูรณ์แบบที่สุด การนำทองคำมาทาบทับสรีระที่กำลังจะเน่าเปื่อย เป็นความพยายามเชิงพิธีกรรมในการถ่ายโอนคุณสมบัติความไม่เน่าเปื่อยของทองคำให้แก่ร่างของผู้ตาย [3] [6]
2. **แสงสว่างและการสะท้อนรังสีสุริยะ (Solar Radiance):** สีเหลืองทองอร่ามที่เปล่งประกายเงางามถูกเชื่อมโยงเข้ากับพลังแห่งดวงอาทิตย์ ไฟ และแสงสว่าง ในจักรวาลวิทยาโบราณ แสงสว่างคืออาวุธที่มีอานุภาพสูงสุดในการขับไล่ความมืดมิดและภูตผีปีศาจ การปิดทวารด้วยแผ่นทองคำจึงเปรียบเสมือนการติดตั้งดวงประทีปแห่งแสงสว่างไว้เหนือดวงตา จมูก และปาก เพื่อส่องทางให้แก่วิญญาณในความมืดแห่งปรโลก [2] [3]
3. **การแปลงสภาพทุนทางเศรษฐกิจสู่ทุนสัญลักษณ์ (Conversion of Capital):** ดังที่โบลูเนียเสนอใน *"The Death of Gold in Early Visayan Society"* การที่ชนชั้นนำยอม "ฝังทองคำทิ้งไว้ใต้ดิน" มิใช่ความไร้เหตุผลทางเศรษฐศาสตร์ แต่เป็นกลยุทธ์สูงสุดในการสถาปนาเกียรติภูมิอันเป็นนิรันดร์ของวงศ์ตระกูล [6] ทองคำที่ถูกเปลี่ยนเป็นแผ่นปิดทวารศพได้ก้าวพ้นจากการเป็นสินค้าโภคภัณฑ์ในระบบตลาด ไปสู่การเป็น "วัตถุศักดิ์สิทธิ์ประจำบรรพชน" (*Sacred Ancestral Regalia*) ที่ยืนยันความชอบธรรมในการสืบทอดอำนาจของทายาทรุ่นต่อไป [2] [6]

จักรวาลวิทยาความตายและภูมิทัศน์วิญญาณนิยมของชาวออสโตรนีเชียนจึงเป็นพลังขับเคลื่อนพื้นฐานที่ให้กำเนิด ให้ความหมาย และค้ำจุนประเพณีแผ่นทองคำปิดทวารศพในหมู่เกาะฟิลิปปินส์ให้ดำรงอยู่อย่างมั่นคงยาวนานหลายร้อยปี ก่อนที่จะเกิดการปะทะและเปลี่ยนผ่านครั้งใหญ่ในยุคอาณานิคม
