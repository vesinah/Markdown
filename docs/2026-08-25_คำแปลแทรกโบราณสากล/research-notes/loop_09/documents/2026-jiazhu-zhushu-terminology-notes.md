# Source notes: jiazhu (interlinear annotation) terminology and zhu/shu relationship

- Date compiled: 2026-08-25
- Sources (all retrieved via webfetch on 2026-08-25):

## 1. Chinese Text Project dictionary entry for jiazhu

- URL: https://ctext.org/dictionary.pl?if=gb&char=%E5%A4%B9%E6%B3%A8
- Content fetched: entry splits the compound: 夹/夾 (jia) glossed 'be wedged or inserted between' and 注/註 (zhu) glossed 'concentrate, focus, direct'; confirms literal sense of jiazhu = annotations inserted between/beneath the main text.

## 2. Baidu Baike entry for jiazhu (used only as keyword source, not cited as scholarly authority)

- URL: https://baike.baidu.com/item/%E5%A4%B9%E6%B3%A8/3188593
- Snippet retrieved via DuckDuckGo search result page (https://html.duckduckgo.com/html/?q=jiazhu+%E5%A4%B9%E6%B3%A8+interlinear+annotation+Chinese+commentary): 'jiazhu... refers to annotations inserted beneath the main text in books, with characters smaller than the main text. English: interlinear notes... Chinese old books mostly used jiazhu; ancients set type vertically, and interlinear notes usually occupied two small lines inserted within the main text column, called shuanghang jiazhu (double-line interlinear notes).'
- Also retrieved same search page: jiapipi entry (https://baike.baidu.com/item/%E5%A4%B9%E6%89%B9/5643272) — jiapi = comments written between the lines of a book or manuscript; one form of the pingdian (annotation/criticism) system together with meipi (top-margin comments), pangpi (side comments), zongpi (overall comments).

## 4. Typographic codification of double-line interlinear notes (luatex-cn / open-guji project)

- GitHub README: https://github.com/open-guji/luatex-cn/blob/main/README-EN.md
- DeepWiki glossary (dated 2026-08-02): https://deepwiki.com/open-guji/luatex-cn/10-glossary
- CTAN mirror README: https://ctan.math.washington.edu/tex-archive/languages/chinese/luatex-cn/README-EN.md
- Retrieved snippets: 'Interlinear Notes (jiazhu): Automatic balancing and breaking for dual-column small notes'; glossary defines Jiazhu as 'interlinear annotations where notes are typeset in two columns of smaller text within the space of a single standard column'; Japanese typographic equivalent term warichu (割注). Confirms that the classical Chinese woodblock/print layout convention renders jiazhu as two half-width columns of smaller characters inside the parent text line.

## Relevance to interlinear gloss research

- jiazhu names both a physical placement (inserted within/beneath the running text) and a typographic format (smaller double-line columns); it is the Chinese counterpart of the interlinear gloss.
- The zhu -> shu sequence shows evolution from compact annotation (often interlinear in early manuscripts) toward expository sub-commentary transmitted separately, with zhushu later fused into composite editions (Shisan jing zhushu).
