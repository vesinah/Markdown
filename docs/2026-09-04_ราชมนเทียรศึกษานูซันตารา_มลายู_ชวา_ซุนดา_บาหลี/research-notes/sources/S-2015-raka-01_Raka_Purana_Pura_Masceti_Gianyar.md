### ส่วนที่ 2: แผนผังการจัดสรรเข้าสู่บทและหัวข้อย่อยของหนังสือ (Chapter & Section Mapping Matrix)

*การจัดสรรสาระสำคัญ ข้อค้นพบ และตัวบทจารึกจากเอกสาร S-2015-raka-01 เข้าสู่โครงสร้างหนังสือโครงการวิจัย "ราชมนเทียรศึกษานูซันตารา: ระบบวัง แผนผัง สถาปัตยกรรม ธรรมเนียมราชสำนัก และพิธีบรมราชาภิเษกใน 4 วัฒนธรรม (มลายู ชวา ซุนดา บาหลี)":*

#### 1. การจัดสรรเข้าสู่ บทที่ 1: บทประมวลสังเคราะห์ภาพรวมระดับมหภาคและทฤษฎีอำนาจเชิงพื้นที่ (Macro-Synthesis & Spatial Power Theory)
- **หัวข้อย่อย 1.1 (ภูมิทัศน์แห่งอำนาจและราชมนเทียรศึกษาในโลกนูซันตารา):**  
  ใช้กรณีศึกษาปูรามาสเจตี (Pura Masceti) วิเคราะห์ทฤษฎี "รัฐเกษตรกรรมศักดิ์สิทธิ์" (Sacred Agrarian State) และ "ระบบนิเวศการเมืองเชิงพิธีกรรม" (Agro-Ritual Political Ecology) ชี้ให้เห็นว่าอำนาจของราชสำนักบาหลี (Puri) มิได้ตั้งอยู่บนการผูกขาดกำลังทหารหรือการรีดภาษีทางกายภาพเพียงลำพัง หากแต่ผูกพันอย่างแยกไม่ออกกับการทำหน้าที่เป็น "ผู้อุปถัมภ์สูงสุด" (Panganceng / Pangrajeg Karya) ของเครือข่ายเทวสถานชลประทานน้ำ (Water Temple Network) เพื่อรักษาสมดุลของระบบนิเวศนาข้าวและการควบคุมศัตรูพืช (DOC PAGE: 20–24, 31–33 / Book pp. 3–7, 14–16)
- **หัวข้อย่อย 1.3 (กรอบทฤษฎีว่าด้วยอำนาจและพื้นที่ศักดิ์สิทธิ์):**  
  ประยุกต์ทฤษฎีของ J. Stephen Lansing ว่าด้วยระบบซูบักและเทวสถานจัดการน้ำ ร่วมกับแนวคิดเรื่อง "เนอการา: รัฐนาฏกรรม" (Negara: The Theatre State) ของ Clifford Geertz เพื่ออธิบายความสัมพันธ์เชิงโครงสร้างระหว่างสถาบันกษัตริย์ (Puri Agung Keramas / Puri Gianyar) กับสหพันธ์ซูบัก 20 ชุมชนลุ่มน้ำปาเกอริซัน (Subak Pakerisan Teben & Subak Gunung Sari) ผ่านเวทีพิธีกรรมขับไล่ภัยพิบัติและศัตรูพืช "นังลุกเมอรานา" (Nangluk Merana) (DOC PAGE: 22–24, 31–33 / Book pp. 5–7, 14–16)
- **หัวข้อย่อย 1.4 (สังเคราะห์ข้อค้นพบหลักจาก 4 ภูมิวัฒนธรรม):**  
  เปรียบเทียบบทบาทของราชสำนักในการจัดการน้ำและการผลิตทางการเกษตร: ในบาหลี ราชสำนักทำหน้าที่เป็นหุ้นส่วนทางพิธีกรรมร่วมกับองค์กรชุมชนซูบักที่เป็นอิสระ ต่างจากราชสำนักชวาที่ระบบเกอราตอน (Keraton) รวมศูนย์การจัดเก็บส่วยภาษีผลผลิตข้าว (Pajak Hasil Bumi) ผ่านขุนนางเบอตูลิน/เบปาเตฮ์ และต่างจากราชสำนักมลายูที่อำนาจกษัตริย์ผูกขาดอยู่กับเส้นทางการค้าทางน้ำและภาษีปากเรือ (DOC PAGE: 21–22, 32–33 / Book pp. 4–5, 15–16)

#### 2. การจัดสรรเข้าสู่ บทที่ 5: รวมทุกมิติของระบบวังเจ้าบาหลี (Puri Bali: Gianyar / Ubud / Keramas / Klungkung)
- **หัวข้อย่อย 5.1 (รากฐานทางประวัติศาสตร์และกำเนิดปูรีบาหลี):**  
  สกัดประวัติศาสตร์การเมืองบาหลียุคหลังการล่มสลายของราชธานีเจลเจล (Gelgel Interregnum ค.ศ. 1651–1686): การลี้ภัยของ อี กุสตี อากุง มารูตี (I Gusti Agung Maruti) อัครมหาเสนาบดีผู้ยึดอำนาจในเจลเจล แล้วอพยพไพร่พลและขุนนางบริวาร (wadwa lan pepatih) มาสร้างพระราชวังใหม่ ณ ปูรีอากุงเกอรามัส (Puri Agung Keramas) พร้อมกับการเข้าปฏิสังขรณ์ปูรามาสเจตีเพื่อสถาปนาความชอบธรรมทางการเมืองและอำนาจบารมี (kawiryyan lan kawibhawan) (DOC PAGE: 25, 41–42 / Book pp. 8, 24–25)
- **หัวข้อย่อย 5.2 (คติ ปรัชญา และจักรวาลวิทยาของปูรีบาหลี):**  
  วิเคราะห์ระบบเทววิทยาคู่ตรงข้ามอันเป็นเอกภาพ "รวาภิเนดา" (Rwa Bhineda) ผ่านแกนจักรวาลภูเขา-ทะเล (Kaja-Kelod): การผสานพลังระหว่างพระแม่แห่งทะเลสาบยอดเขาพญาบาตูร์ ทัมปุรฮยัง คือ "ภะฏารี ดานุฮ์" (Bhatari Danuh) สัญลักษณ์แห่งน้ำจืด ความอุดมสมบูรณ์ และสตรีเพศ เข้ากับพระผู้เป็นเจ้าแห่งมหาสมุทรใต้ คือ "ภะฏาระ บารุณา" (Bhatara Baruna / Bhatara Tengahing Sagara) สัญลักษณ์แห่งน้ำเค็ม พลังการชำระล้าง และบุรุษเพศ โดยมีพญานาควาสุกี (Sang Hyang Naga Basuki) เป็นผู้ค้ำจุนแผ่นดิน และสังฮยังราเรอังงน (Sang Hyang Rare Angon) เป็นเทพผู้อภิบาลกสิกรรม (DOC PAGE: 20, 22–24, 27 / Book pp. 3, 5–7, 10)
- **หัวข้อย่อย 5.3 (แผนผังและการจัดวางเชิงพื้นที่แบบสังคามณฑล):**  
  วิเคราะห์การจัดระเบียบพื้นที่ศักดิ์สิทธิ์ตามระบบตรีมณฑล (Tri Mandala: Utama Mandala, Madhya Mandala, Kanistha Mandala) ร่วมกับระบบปูราบริวาร ได้แก่ ปูราตามัน (Pura Taman) บ่อน้ำบัวศักดิ์สิทธิ์ทางทิศตะวันออก, ปูราเกอโลดัน (Pura Kelodan) ทางทิศตะวันออกเฉียงใต้, ปูราซาลูกัต (Pura Salukat) สำหรับการชำระมลทิน และปูราจันดีบัง (Pura Candi Bang) เพื่อขจัดโรคาพยาธิ (DOC PAGE: 25–29, 42–47 / Book pp. 8–12, 25–30)
- **หัวข้อย่อย 5.6 (โครงสร้างสังคม การระดมแรงงาน และสหพันธ์ซูบัก 20 แห่ง):**  
  แจกแจงโครงสร้างความสัมพันธ์เชิงอำนาจและพันธะทางจารีต: สถานะของปูรีอากุงเกอรามัสในฐานะ "ปางันเจ็ง / ปางราเจกการ์ยา" (Panganceng / Pangrajeg Karyya - องค์อุปถัมภ์และประธานพิธีหลวง) ประสานเข้ากับ "ปาเงิมปอน / ปาเงามอง" (Pangempon / Pangamong) คือ สหพันธ์องค์กรชลประทานซูบัก 20 แห่งในเขตปาเกอริซันตอนล่าง (Subak Pakerisan Teben) และกูนุงซารี (Subak Gunung Sari) แต่ละซูบักนำโดยหัวหน้าชลประทาน "ปากาเสะฮ์" (Pakaseh / Paka Ser) โดยมี "เบินเดซาปูรา" (Bandesa Pura) ปัญญาธิการ (Panyarikan) และสมุหบัญชี (Juru Raksa) เป็นคณะกรรมการบริหาร (DOC PAGE: 31–33, 49–51 / Book pp. 14–16, 32–34)
- **หัวข้อย่อย 5.7 (สถาปัตยกรรมศาสนสถาน แท่นปัทมาสน์ เมรุ และศาลาพิธี):**  
  ถอดรหัสสถาปัตยกรรมศักดิ์สิทธิ์: เมรุ 5 ชั้น (Meru Tumpang Lima) แท่นประทับของภะฏาระมาสเจตี/บารุณา, เมรุ 3 ชั้น (Meru Tumpang Tiga) แท่นประทับของราตูอูลุนซูวี/ภะฏารีดานุฮ์, แท่นหินโบราณวาตูโรโร (Watu Roro), แท่นปูนปั้นขั้นบันไดเตปาซานา/สัปตปาตาละ (Tepasana / Saptapatala) บูชาพระแม่ธรณี (Dewi Bhumi / Dewi Ibu), แท่นปัทมาสน์ (Padmasana) สถาปนาโดยดังฮยังนิราร์ถา, ประตูโกรีอากุง (Kori Agung) ขนาบด้วยปีกบินตังอาริง (Bintang Aring), และศาลาวานตีลัน (Wantilan) สำหรับพิธีชนไก่บวงสรวงตาบุฮ์ระฮ์ (Tabuh Rah) (DOC PAGE: 26–28, 42–46 / Book pp. 9–11, 25–29)
- **หัวข้อย่อย 5.8 (พระราชพิธีบรมราชาภิเษกและวัฏจักรพิธีกรรมหลวงประจำปี):**  
  สกัดรายละเอียดวัฏจักรพิธีกรรมเกษตรกรรมหลวง: พิธีเนอดุฮ์ (Neduh), พิธีงูซาบาเกอตูปัต (Ngusaba Ketipat), พิธีปางาจี กาเลจัน (Pangaci Kalecan / Tabuh Rah 1,000 เกเป็ง), พิธีอาจี มาเตตาบูฮัน เบอเร็ม (Aci Matetabuhan Berem - สาดเหล้าข้าวหมัก 1 ไหต่อซูบัก), พิธีงาตูรัง ลิงกิฮ์ (Ngaturang Linggih ในเดือนห้า / Sasih Kalima), พิธีปีโอดาลัน (Piodalan ทุกรอบ 210 วันตรงกับ Anggara Kasih Medangsia), และมหาพิธีปาดูดูซัน (Padudusan ทุก 30 ปี / 3 ปี) (DOC PAGE: 29–31, 47–49 / Book pp. 12–14, 30–32)

#### 3. การจัดสรรเข้าสู่ บทที่ 6: บทวิเคราะห์เปรียบเทียบ 4 ภูมิวัฒนธรรม (Comparative Monograph)
- นำมิติความสัมพันธ์ระหว่าง "ราชสำนัก-เทวสถานจัดการน้ำ-สหพันธ์ชาวนา" ของบาหลี ไปเปรียบเทียบกับมิติอำนาจชลประทานในชวา (ระบบคลองส่งน้ำรอบเกอราตอนและอ่างเก็บน้ำโบราณเช่น Candi Tikus ในมัชปาหิต), ในซุนดา (คติบูชาพระศรีโพสพ Dewi Sri / Nyi Pohaci Sanghyang Asri ในระบบเกษตรนาดอน/ฮูมา), และในมลายู (ระบบนาข้าวแคว้นเกอดะฮ์และกลันตันภายใต้การขุดคลองของสุลต่าน Terusan Wan Mat Saman) ชี้ให้เห็นเอกลักษณ์เฉพาะของบาหลีที่กระจายอำนาจการบริหารน้ำผ่านโครงข่ายสถาบันศักดิ์สิทธิ์แบบองค์รวม (DOC PAGE: 21–24, 31–33 / Book pp. 4–7, 14–16)

#### 4. การจัดสรรเข้าสู่ บทที่ 7: บทวิเคราะห์เฉพาะสถาปัตยกรรม วิศวกรรมพื้นถิ่น และระบบแผนผัง (Architectural & Spatial Analysis)
- นำข้อมูลโครงสร้างสถาปัตยกรรมหินยุคก่อนประวัติศาสตร์ (Austronesian Megalithic Substratum) ที่แฝงอยู่ในปูรามาสเจตี: แท่นบูชาหินตั้ง (Menhir / Sila Angadeg), แท่นหินโต๊ะ (Dolmen / Lempeng Magong Direbahkan), และโครงสร้างฐานหินขั้นบันได (Punden Berundak / Gagumuk Maundak) ซึ่งถูกวิวัฒนาการและปรับเปลี่ยนความหมายเชิงเทววิทยาในยุคต่อมาให้กลายเป็นแท่นวาตูโรโร (Watu Roro), แท่นเตปาซานา (Tepasana), และแท่นสัปตปาตาละ (Saptapatala) ภายใต้การจัดผังแบบตรีมณฑลอันเคร่งครัด (DOC PAGE: 21–22, 26, 37–38, 43 / Book pp. 4–5, 9, 20–21, 26)

### ส่วนที่ 3: สรุปสาระสำคัญเชิงวิเคราะห์และจุดยืนทางวิชาการ (Executive Academic Analysis)

#### 1. วิทยานิพนธ์และข้อถกเถียงหลักของผู้เขียน (Core Argument / Thesis)
เอกสาร *Purana Pura Masceti: Kahyangan Jagat di Gianyar* ซึ่งจัดทำและเรียบเรียงโดยคณะนักโบราณคดีและผู้เชี่ยวชาญภาษาโบราณ นำโดย Anak Agung Gde Raka (2015) ภายใต้การสนับสนุนของสำนักงานวัฒนธรรมอำเภอกียันยาร์ มีเป้าหมายทางวิชาการและการเมืองวัฒนธรรมที่ลึกซึ้งอย่างยิ่ง วิทยานิพนธ์หลัก (Central Thesis) ของเอกสารชิ้นนี้สามารถสรุปได้เป็น 4 มิติต่อเนื่องกัน:

1. **การผสานรากฐานความเชื่อหินโบราณเข้ากับเทววิทยาฮินดู-ชวา (Megalithic-Hindu Syncretism):**  
   ตัวบทปุราณะยืนยันว่า ปูรามาสเจตีมิได้เริ่มต้นขึ้นจากการสร้างวัดฮินดูตามตำราอินเดีย หากแต่หยั่งรากลึกมาจากศาสนาดั้งเดิมของชาวบาหลีโบราณ (Dresta Gama Bali Kina) ในยุคก่อนประวัติศาสตร์ ที่มีการสร้างแท่นบูชาบรรพชนด้วยหินกองขั้นบันได (Gagumuk Maundak / Punden Berundak), หินตั้ง (Sila Angadeg / Menhir), และหินแผ่นนอน (Dolmen) ซึ่งต่อมาได้รับการประดิษฐ์สร้างทางความหมายใหม่ในคริสต์ศตวรรษที่ 11 โดยมหาโยคี มปู กุตูรัน (Mahayogi Mpu Kuturan) มหาปุโรหิตแห่งอาณาจักรมะตะรัมโบราณ (เกาะชวา) ผู้เดินทางมาจัดระเบียบสังคมและการสร้างวัดในบาหลี โดยได้สร้างหอเมรุ 5 ชั้น (บูชาปัญจเทวตา) และเมรุ 3 ชั้น (บูชาตรีมูรติ) ทับซ้อนลงบนฐานรากเดิม และต่อมาในคริสต์ศตวรรษที่ 16 ดังฮยัง นิราร์ถา (Dang Hyang Nirartha) ได้สถาปนาแท่นปัทมาสน์ (Padmasana) ขึ้นเพื่อบูชาพระปรมวิเศษ (Sang Hyang Parama Wisesa / Acintya) (DOC PAGE: 21–25 / Book pp. 4–8)

2. **การบูรณาการทางนิเวศวิทยาการเกษตรผ่านทวิภาวะจักรวาล (Agro-Ecological Integration via Cosmic Duality):**  
   ปุราณะเล่าถึงวิกฤตภัยแล้งครั้งใหญ่และโรคระบาดศัตรูพืชกัดกินนาข้าว (Kemarau berkepanjangan dan hama penyakit / Marana tan papagetan) ซึ่งทำให้พระผู้เป็นเจ้าบรมครู ปศุบดี (Sang Hyang Guru Pasupati) บัญชาให้พระธิดาคือ ภะฏารี ดานุฮ์ (Bhatari Danuh) เสด็จลงมาจากยอดเขาบาตูร์ (Giri Tampurhyang) มุ่งลงใต้มาพบกับ ภะฏาระ บารุณา (Bhatara Baruna / Bhatara Sagara) ณ ปากแม่น้ำปาเกอริซันริมทะเลใต้ การพบกันระหว่าง "เทพีแห่งน้ำจืดบนยอดเขา" กับ "เทพแห่งน้ำเค็มในมหาสมุทร" ได้กลายเป็นจุดกำเนิดของปูรามาสเจตีในฐานะสถาบันควบคุมสมดุลน้ำและขับไล่ศัตรูพืช (Nangluk Merana) โดยกำหนดให้เกษตรกรชาวนาและชนทุกวรรณะต้องเคารพบูชามิให้ขาด เพื่อมิให้เกาะบาหลีต้องเผชิญกับทุพภิกขภัย (DOC PAGE: 22–23 / Book pp. 5–6)

3. **ความชอบธรรมทางการเมืองของราชสำนักผ่านการเป็นผู้อุปถัมภ์เทวสถานน้ำ (Royal Legitimacy through Agrarian Patronage):**  
   เอกสารบันทึกเหตุการณ์ประวัติศาสตร์ช่วงปลายคริสต์ศตวรรษที่ 17 ภายหลังการล่มสลายของราชธานีเจลเจล เมื่อ อี กุสตี อากุง มารูตี (I Gusti Agung Maruti) ต้องล่าถอยมาตั้งพระราชวังปูรีเกอรามัส (Puri Agung Keramas) สิ่งแรกที่พระองค์ทรงกระทำเพื่อสถาปนาอำนาจบารมี (kawiryyan lan kawibhawan) และรวบรวมไพร่พล คือการประกาศยกให้ภะฏาระมาสเจตีเป็น "เทพารักษ์ประจำราชสำนัก" (Sungsungan Sang Natha) และนำกำลังไพร่พลร่วมมือกับราษฎรทำการบูรณปฏิสังขรณ์เทวสถานครั้งใหญ่ พร้อมทั้งแต่งตั้ง กี เบินเดซา เกอเดะฮ์ (Ki Bandesa Kedeh) เป็นผู้พิทักษ์วัด รูปแบบนี้สถาปนาให้ราชสกุลปูรีเกอรามัสกลายเป็น "ปางันเจ็ง / ปางราเจกการ์ยา" (Panganceng - องค์อุปถัมภ์หลักผู้เป็นพยานในทุกพิธีกรรมหลวง) ซึ่งทำให้ราชสำนักมีอำนาจเชิงสัญลักษณ์เหนือกองกำลังแรงงานและผลผลิตข้าวของชุมชน (DOC PAGE: 25, 31–33 / Book pp. 8, 14–16)

4. **ความเป็นอิสระและโครงสร้างสหพันธ์ซูบัก 20 แห่ง (Subak Federation & Autonomous Management):**  
   แม้ราชสำนักปูรีจะเป็นผู้อุปถัมภ์สูงสุด แต่เอกสารระบุชัดเจนว่า ผู้ถือครองหน้าที่ "ปาเงิมปอน / ปาเงามอง" (ผู้ดูแล บำรุงรักษา และออกแรงงานปรนนิบัติวัด) ที่แท้จริงคือ เครือข่ายสหพันธ์ซูบัก 20 แห่งในเขตลุ่มน้ำปาเกอริซันตอนล่างและกูนุงซารี โดยมีคณะกรรมการวัดที่เรียกว่า "เบินเดซาปูรา" (Bandesa Pura) ซึ่งคัดเลือกมาจากผู้อาวุโสของชาวนาซูบัก ทำงานร่วมกับหัวหน้าชลประทาน (Pakaseh) ทั้ง 20 คน และสมุหพระราชพิธี (Pamangku Gede) โดยงบประมาณการดูแลวัดมาจากค่าธรรมเนียมของสมาชิกซูบัก (Papeson) ดอกผลจากที่ดินธรณีสงฆ์ (Laba Pura) และเงินบริจาคของราชสำนักและรัฐบาล (Punya Sang Maweng Rat) โมเดลนี้สะท้อนภาวะ "สมดุลเชิงสถาบัน" ระหว่างอำนาจรัฐของปูรีกับอำนาจประชาสังคมของชาวนาซูบักอย่างสมบูรณ์แบบ (DOC PAGE: 31–33 / Book pp. 14–16)

#### 2. บริบทประวัติศาสตร์นิพนธ์และการประเมินความน่าเชื่อถือ (Historiography & Source Criticism)
- **ตำแหน่งในประวัติศาสตร์นิพนธ์บาหลีศึกษา (Position in Balinese Historiography):**  
  งานศึกษาปูราณะปูรามาสเจตีชิ้นนี้ เป็นเอกสารหลักฐานชั้นต้น (Primary Source) ที่มีค่ายิ่งในการทำความเข้าใจสถาบัน "กาฮยางัน จากัต" (Kahyangan Jagat - มหาเทวสถานแห่งจักรวาล) ควบคู่กับสถานะ "กาฮยางัน สวากีนา" (Kahyangan Swagina - เทวสถานตามสายอาชีพเกษตรกรรม) ในประวัติศาสตร์นิพนธ์บาหลี งานชิ้นนี้ช่วยเติมเต็มช่องว่างของทฤษฎีระบบชลประทานเทวสถานน้ำของ **J. Stephen Lansing (1991, 2006)** ในหนังสือคลาสสิก *Priests and Programmers: Technologies of Power in the Engineered Landscape of Bali* ซึ่งเคยวิเคราะห์ลุ่มน้ำปาเกอริซันไว้ในฐานะภูมิทัศน์มรดกโลก โดย Lansing มักเน้นบทบาทของปูราอูลุนดานูบาตูร์ (Pura Ulun Danu Batur) บนยอดเขา แต่เอกสารปูราณะปูรามาสเจตีฉบับนี้ชี้ให้เห็นอย่างกระจ่างชัดว่า ที่ปลายสุดของลุ่มน้ำปาเกอริซันก่อนออกสู่มหาสมุทร มี "ปูรามาสเจตี" ทำหน้าที่เป็นสถานีชลประทานศักดิ์สิทธิ์ส่วนปลาย (Downstream Hydrological Node) ที่ควบคุมการระบายน้ำและการขจัดโรคระบาดของระบบซูบักถึง 20 แห่ง
- **การประเมินความน่าเชื่อถือและระเบียบวิธีวิจัย (Methodological Evaluation):**  
  - **จุดแข็งด้านภาษาศาสตร์และจารึกวิทยา:** คณะผู้จัดทำประกอบด้วยนักโบราณคดีและผู้เชี่ยวชาญภาษาชวาโบราณจากมหาวิทยาลัยอูดายานา ทำให้การถ่ายทอดอักษร (Alih Aksara) จากใบลานอักษรบาหลีดั้งเดิมมีความแม่นยำทางอักขรวิธี มีการคงรูปศัพท์โบราณ เช่น *mêdahan, añakradala, parimaóðala, pangjahit, paka ser, tpas, batu roro* ไว้อย่างครบถ้วน พร้อมเทียบเคียงกับภาษาบาหลีร่วมสมัยและภาษาอินโดนีเซีย
  - **การระบุศักราชและจารึกท้ายคัมภีร์ (Colophon / Candrasangkala):** ท้ายตัวบทใบลานมีการระบุวันเวลาที่คัดลอก/ชำระไว้อย่างแม่นยำตามระบบปฏิทินบาหลี: *rahina Soma Pahing, wuku Wukir, tithi Pañcadaúi, Kåûóapakûa, Desta màsa, I Úaka Warûaninglokha, pandhita guna gapura caóðra* (วันจันทร์ ปาฮิง สัปดาห์วูกีร์ วันแรม 15 ค่ำ เดือนเดสตา มหาศักราช 1937 หรือเทียบเท่า 15 พฤษภาคม ค.ศ. 2015 ในคำแปล) คำว่า *pandhita (7), guna (3), gapura (9), candra (1)* เป็นรหัสคำแทนตัวเลขศักราชแบบย้อนกลับ (Candrasangkala) คือ 1937 ศักราช (Saka) แสดงถึงการสืบทอดจารีตการชำระคัมภีร์ใบลานอย่างต่อเนื่อง
  - **ข้อสังเกตเชิงวิพากษ์ (Critical Observation):** ในคำแปลภาษาอินโดนีเซีย (หน้า 32 / Doc: 49) แปลรอบเวลาการจัดมหาพิธีปาดูดูซัน (Padudusan) ว่า "diselenggarakan setiap tiga tahun sekali" (ทุก 3 ปีครั้ง) แต่ในตัวบทภาษาชวาโบราณดั้งเดิม (หน้า 14 / Doc: 31) ระบุชัดเจนว่า *"linaksanakên ngangkên tigang daúa warûa"* ซึ่งคำว่า *tigang daúa warûa* แปลตรงตัวว่า "สามสิบปี" (30 ปี) ความคลาดเคลื่อนในภาคแปลนี้เป็นประเด็นสำคัญที่นักประวัติศาสตร์ต้องตระหนักว่า พิธีปาดูดูซันหลวงระดับมหาพิธีของกาฮยางันจากัตนั้นตามจารีตโบราณจัดขึ้นทุกรอบ 30 ปี มิใช่ทุก 3 ปี (ซึ่งทุก 3 ปีอาจเป็นเพียงรอบพิธีปาดูดูซันขนาดเล็กในระดับท้องถิ่น)

### ส่วนที่ 4: สารบัญข้อค้นพบเชิงลึกแยกตาม 10 มิติราชมนเทียรศึกษา (Thematic Findings with Exact Pages)

#### 1. คติและปรัชญาความชอบธรรมแห่งอำนาจ (Cosmological Philosophy & Royal Legitimacy)
- **พันธะสัญญาแห่งผู้ปกครองต่อจักรวาล (The Sovereign's Duty to Sacred Order):** ตัวบทปุราณะเปิดฉากด้วยการประกาศบังคับให้ผู้ถือครองอำนาจรัฐทุกระดับ โดยเฉพาะผู้ปกครองแห่งกียันยาร์ (Sang Añakradala haneng Gianyar) กษัตริย์แห่งเกาะบาหลี (Sang Maweng Rat / Ratu Bali) ตลอดจนไพร่พลราษฎรทั้งปวง ต้องตระหนักรู้และปรนนิบัติบูชาปูรามาสเจตีอย่างเคร่งครัด เพราะเทวสถานแห่งนี้เป็นที่สถิตของพระเป็นเจ้าผู้ทรงอานุภาพสูงสุด (Sang Hyang Widhi Wasa / Sang Hyang Parama Wisesa) และภาคสำแดงพระองค์ในฐานะภะฏาระมาสเจตี, ภะฏาระบารุณา, ภะฏารีดานุฮ์, ภะฏาระฮูลุนซูวี, และพญานาควาสุกี ผู้ค้ำจุนโลก (DOC PAGE: 20, 36 / Book pp. 3, 19)
- **เทวบัญชาเพื่อขจัดภัยพิบัติและศัตรูพืช (Divine Decree against Pests / Nangluk Merana):** ความชอบธรรมของเทวสถานเกิดจากวิกฤตความอดอยากและโรคระบาดในอดีต (kemarau berkepanjangan dan hama penyakit / marana tan papagetan) พระมหากูรู ปศุบดี ได้ส่งพระธิดาคือภะฏารีดานุฮ์มาประสานพลังกับภะฏาระบารุณา ณ ชายทะเลปากแม่น้ำปาเกอริซัน เพื่อสถาปนาปูรามาสเจตีเป็น "สถานที่ดับสูญแห่งศัตรูพืชและโรคระบาดทั้งปวง" (amunahaken ikang sarwwa marana) และมีคำสั่งห้ามมิให้ผู้ใดละเลยหรือลดทอนเครื่องบวงสรวงในไร่นาเด็ดขาด มิฉะนั้นแผ่นดินบาหลีจะเผชิญความแห้งแล้งและทุกข์เข็ญไม่สิ้นสุด (DOC PAGE: 22–23, 38–40 / Book pp. 5–6, 21–23)
- **การฟื้นฟูอำนาจราชวงศ์ผ่านสิ่งศักดิ์สิทธิ์ (Regal Re-legitimation of Puri Keramas):** ปุราณะบันทึกว่า ภายหลังสูญเสียราชธานีเจลเจล อี กุสตี อากุง มารูตี ได้รับอำนาจบารมี ความเคารพยำเกรง และการยอมสวามิภักดิ์จากไพร่พลและขุนนาง (kawiryyan lan kawibhawan) จนสามารถสร้างพระราชวังปูรีเกอรามัสได้สำเร็จ ก็ด้วยเดชะพระบารมีของภะฏาระมาสเจตี การยกย่องวัดนี้เป็นเทพารักษ์ประจำองค์กษัตริย์จึงเป็นยุทธศาสตร์การสร้างความชอบธรรมทางการเมืองของราชสกุลใหม่ (DOC PAGE: 25, 41–42 / Book pp. 8, 24–25)

#### 2. แผนผังและการจัดวางเชิงพื้นที่ (Spatial Layout & Agro-Cosmological Topography)
- **ตำแหน่งที่ตั้งและแกนแม่น้ำศักดิ์สิทธิ์ (Hydrological-Cosmological Axis):** ปูรามาสเจติตั้งอยู่ ณ หมู่บ้านเมอดาฮัน-เกอรามัส (Desa Medahan – Keramas) อำเภอบละฮ์บาตูฮ์ (Kecamatan Blahbatuh) เขตกียันยาร์ บริเวณชายฝั่งทะเลใต้ ณ จุดบรรจบส่วนปลายของแม่น้ำปาเกอริซัน (Hilir Lwah Pakrisan) ซึ่งเชื่อมโยงโดยตรงกับยอดเขาบาตูร์ทางทิศเหนือ (Kaja) สู่ทะเลทางทิศใต้ (Kelod) ทำให้เทวสถานแห่งนี้เป็นชุมทางแห่งพลังชีวิตจักรวาล (Cosmic Conduit) ที่บรรจบระหว่างน้ำจืดบนภูเขากับน้ำเค็มในมหาสมุทร (DOC PAGE: 22, 39 / Book pp. 5, 22)
- **การแบ่งพื้นที่ตามคติระบบตรีมณฑล (Tri Mandala Zonation):** ผังวัดแบ่งออกเป็น 3 ลานล้อมรอบด้วยกำแพงหินศิลาแลงและอิฐโบราณ (Panyengker) อย่างชัดเจน:
  1. **อุตตมะมณฑล (Uttama Mandala / Jeroan):** ลานชั้นในสุดอันศักดิ์สิทธิ์สูงสุด เป็นที่ตั้งของหมู่อาคารเมรุ แท่นบูชาเทพเจ้าหลัก หอพระเวท และศาลาประกอบพิธีศักดิ์สิทธิ์
  2. **มัธยมมณฑล (Madhya Mandala / Jaba Tengah):** ลานชั้นกลาง เป็นพื้นที่เชื่อมต่อ มีศาลาขับลำนำศักดิ์สิทธิ์ (Bale Gegitan), ศาลาการแสดงนาฏศิลป์ศักดิ์สิทธิ์ (Bale Pagambuhan), และหอกลองสัญญาณ (Bale Kulkul)
  3. **กนิษฐมณฑล (Kanistha Mandala / Jabaan / Jaba Sisi):** ลานชั้นนอกสุด เป็นพื้นที่อเนกประสงค์ มีศาลาวานตีลัน (Wantilan) สำหรับพิธีชนไก่บวงสรวงและตลาดศักดิ์สิทธิ์ (Pasar Agung) (DOC PAGE: 25–28, 42–46 / Book pp. 8–11, 25–29)
- **หมู่วัดบริวารในระบบภูมิทัศน์ (Satellite Temple Network):** มีวัดที่ผูกพันโดยตรงในเชิงพื้นที่และพิธีกรรม ได้แก่ **ปูราตามัน (Pura Taman)** บ่อน้ำบัวศักดิ์สิทธิ์ติดกำแพงด้านตะวันออก, **ปูราเกอโลดัน (Pura Kelodan)** ทางทิศตะวันออกเฉียงใต้, **ปูราซาลูกัต (Pura Salukat / Selukat)** ทางทิศเหนือ สำหรับพิธีชำระล้างมลทิน (Panglukatan), และ **ปูราจันดีบัง (Pura Candi Bang)** สำหรับการขอพรคุ้มครองจากโรคาพยาธิ (DOC PAGE: 27, 28–29, 44, 46–47 / Book pp. 10, 11–12, 27, 29–30)

#### 3. การออกแบบและสถาปัตยกรรม (Architectural Design & Sacred Pavilions)
- **ชั้นฐานสถาปัตยกรรมหินดึกดำบรรพ์ (Megalithic Stone Substratum):** ก่อนการสร้างอาคารไม้ ตัววัดมีรากฐานมาจากโครงสร้างหินยุคก่อนประวัติศาสตร์ ได้แก่ ฐานหินขั้นบันได (Gegumuk Maundak / Punden Berundak) ซึ่งต่อมาวิวัฒนาการเป็น "ปาลึงกิฮ์ สัปตปาตาละ" (Palinggih Saptapatala) หรือแท่นเตปาซานา (Tepasana) เพื่อบูชาพระแม่ธรณี (Dewi Bhumi / Dewi Ibu) และแท่นหินแบนคู่ "วาตูโรโร" (Watu Roro) ซึ่งเป็นแท่นบูชาภะฏาระบารุณา (DOC PAGE: 23, 26, 40, 43 / Book pp. 6, 9, 23, 26)
- **หอเมรุยอดซ้อนชั้นแห่งมหาโยคี มปู กุตูรัน (Multi-tiered Meru Architecture):** มปู กุตูรัน ได้ออกแบบและควบคุมการสร้างหอเมรุ 2 องค์สำคัญในอุตตมะมณฑล:
  1. **เมรุ 5 ชั้น (Meru Tumpang Lima):** สร้างขึ้นเพื่อบูชาปัญจเทวตา (Hyang Panca Dewata) และต่อมาใช้เป็นแท่นประทับสถิตของภะฏาระมาสเจตี (Bhatara Masceti) ซึ่งเป็นภาคสำแดงของภะฏาระบารุณา
  2. **เมรุ 3 ชั้น (Meru Tumpang Tiga / Katrini):** สร้างขึ้นเพื่อบูชาพระตรีมูรติ (Hyang Tri Murti) และต่อมาใช้เป็นแท่นประทับของอีดา ราตู อูลุน ซูวี (Ida Ratu Ulun Suwi) ภาคสำแดงของภะฏารีดานุฮ์ (DOC PAGE: 24, 26, 40–41, 43 / Book pp. 7, 9, 23–24, 26)
- **แท่นปัทมาสน์แห่งดังฮยัง นิราร์ถา (Padmasana of Dang Hyang Nirartha):** สถาปัตยกรรมแท่นเสาหินเดี่ยวแกะสลักรูปดอกบัวยอดบัลลังก์ว่างเปล่า สถาปนาขึ้นตามคำสอนของมหาบรรพชิตดังฮยัง นิราร์ถา ในคริสต์ศตวรรษที่ 16 ก่อนที่ท่านจะเดินทางไปบรรลุโมกษะ ณ หน้าผาอูลูวาตู เพื่อเป็นศูนย์กลางการบูชาพระปรมวิเศษ (Sang Hyang Parama Wisesa) สูงสุดแห่งสากลจักรวาล (DOC PAGE: 24–25, 41 / Book pp. 7–8, 24)

#### 4. หมู่อาคารประกอบในเทวสถานและเขตวังอุปถัมภ์ (Ancillary Structures, Shrines & Water Gardens)
- **อาคารประกอบในอุตตมะมณฑล (Utama Mandala Structures):**
  - *เกอดง ตักซู เกิมบาร์ (Gedong Taksu Kembar):* อาคารเรือนคู่ประดิษฐานสังฮยังกาฬราชา (Sang Hyang Kala Raja)
  - *เกอดง ราตู งูรุระฮ์ อากุง (Gedong Ratu Ngrurah Agung):* เรือนประดิษฐานเทพผู้อภิบาลและรักษาความปลอดภัยเทวสถาน (Anggabaya)
  - *เกอดง ปาซิมปางัน บาตูร์ และ อากุง:* ศาลจำลองเพื่อเชื่อมโยงจิตวิญญาณสู่ภูเขาศักดิ์สิทธิ์ กูนุงบาตูร์ และ กูนุงอากุง แหล่งกำเนิดน้ำอมฤต
  - *เกอดง เกอเร็บบ์ วาตู โรโร (Gedong Kereb Watu Roro):* เรือนมีหลังคาและกำแพงบันได ประดิษฐานภะฏาระสาการา/บารุณา ขนาบด้วยศาลบริวารเซอดาฮันสาการา (Sedahan Sagara) ซ้ายขวา สำหรับชาวประมงบวงสรวง
  - *ปาตีร์ถาน (Patirthan):* บ่อน้ำศักดิ์สิทธิ์เปิดโล่งไร้หลังคา
  - *บาเล ปาเวดัน (Bale Pawedan):* ศาลาอาสน์สูงสำหรับพระเปอดันดา (Ida Pedanda) นั่งบริกรรมมนตร์และประกอบยัญพิธี
  - *บาเล ปางารูมัน (Bale Pangaruman):* ศาลาชุมนุมทวยเทพขณะเสด็จลงมาเป็นสักขีพยานในพิธี
  - *บาเล เปียซัน (Bale Pyasan):* ศาลาแต่งองค์ทรงเครื่องเทวรูปและเครื่องสูงก่อนยาตรา
  - *บาเล กง (Bale Gong):* ศาลาวงดนตรีมโหรีคามะลัน
  - *เกอดง ซิมเปิน (Gedong Simpen):* เรือนคลังเก็บรักษาหน้ากากเทวรูปและสิ่งศักดิ์สิทธิ์ (Tapakan) (DOC PAGE: 26–27, 42–44 / Book pp. 9–10, 25–27)
- **หมู่อาคารในปูราตามัน (Pura Taman Water Sanctuary):** ตั้งอยู่ติดกำแพงด้านทิศตะวันออก มีสระบัวศักดิ์สิทธิ์ขนาดใหญ่ (Talaga Kumuda) ล้อมรอบด้วยกำแพงที่มีประตูกระจกเปิดสี่ทิศ ตรงกลางมีแท่น *ปาลึงกิฮ์ อูลุน ตามัน (Palinggih Ulun Taman)* ทรงปัทมจาปะฮ์ บูชาเทพ-เทวี สัญลักษณ์แห่งพระวิคุยาชมานะ (Wiku Yajamana) และพระวิคุตาปินี (Wiku Tapini) เคียงคู่กับบ่อน้ำศักดิ์สิทธิ์ *ปาลึงกิฮ์ ตีร์ถา* (อุทยานทิพย์เร้นลับ / Taman Niskala), ศาลาตัดเย็บเครื่องพิธี *บาเล เรริงกีตัน (Bale Reringgitan)*, ศาลาครัวหลวง *บาเล เปอรันเตอนัน (Bale Perantenan)*, และศาลาชำแหละเนื้อสัตว์บูชา *บาเล ปาเออบาตัน (Bale Paebatan)* (DOC PAGE: 28–29, 46–47 / Book pp. 11–12, 29–30)

#### 5. กำแพง ป้อมค่าย และระบบแบ่งลำดับชั้นความศักดิ์สิทธิ์ (Perimeter Walls, Gates & Boundary Delimitation)
- **กำแพงปันเยิงเกอร์และแนวเขตปังจาฮิต (Panyengker & Pangjahit Boundaries):** ปุราณะอธิบายว่า ขอบเขตพื้นที่ศักดิ์สิทธิ์ในระดับชุมชนโบราณเรียกว่า "ปังจาฮิต" (Pangjahit) ซึ่งทำหน้าที่เย็บร้อยผืนดินและจัดระเบียบความสงบสุข ส่วนภายในเทวสถาน กำแพงหินศิลาแลง "ปันเยิงเกอร์" (Panyengker) ทำหน้าที่เป็นเส้นแบ่งภาวะมลทินภายนอกออกจากความบริสุทธิ์ภายใน (DOC PAGE: 22, 25, 38, 42 / Book pp. 5, 8, 21, 25)
- **ประตูโกรีอากุงและปีกบินตังอาริง (Kori Agung & Bintang Aring):** ทางผ่านระหว่างลานกลาง (Madhya Mandala) เข้าสู่ลานใน (Utama Mandala) ถูกควบคุมด้วยมหาทวาร "โกรีอากุง" (Kori Agung / Candi Kurung) ซึ่งปิดทึบและมียอดซ้อนชั้นสูงตระหง่าน ขนาบด้วยกำแพงปีกแยกลดหลั่นที่เรียกว่า "บินตังอาริง" (Bintang Aring) และมีศาลทวารบาล "อาปิตลาวัง" (Apit Lawang) ขนาบซ้ายขวา ประดิษฐานพระมหากาฬ (Sang Hyang Mahakala) และพระนนทิศวร (Sang Nandiswara) เพื่อตรวจตราและขจัดสิ่งอัปมงคลมิให้ล่วงล้ำเข้าสู่อุตตมะมณฑล (DOC PAGE: 27–28, 44–45 / Book pp. 10–11, 27–28)
- **จันดีเบินตาร์และอาลิง-อาลิง (Candi Bentar & Aling-aling):** ทางเข้าสู่ลานนอกและลานกลางใช้ประตูผ่าซีก "จันดีเบินตาร์" (Candi Bentar) ขนาบด้วยศาล "กลาบังอาปิต" (Klabang Apit) ด้านหลังประตูโกรีอากุงมีกำแพงบังตา "อาลิง-อาลิง" (Aling-aling) ตั้งขวางเพื่อเบี่ยงเบนและสกัดกั้นพลังงานด้านลบที่พุ่งตรงเข้ามา (DOC PAGE: 27, 28, 44, 45 / Book pp. 10, 11, 27, 28)

#### 6. ความมั่นคง การระดมแรงงาน และระบบการบริหารจัดการซูบัก (Subak Mobilization & Agrarian Administration)
- **การวิวัฒน์จากชุมชนบรรพชนสู่ระบบซูบัก (Evolution of Subak from Ancient Banjar):** ตัวบทปุราณะให้ข้อมูลประวัติศาสตร์สังคมที่ล้ำค่ายิ่ง บันทึกว่าชาวบาหลีโบราณเริ่มตั้งถิ่นฐานสร้างกระท่อมเรียงรายเป็นแถว เรียกว่า "มาบันจาร์-บันจาร์" (Mabanjar-banjar) จึงเกิดเป็น "บันจาร์" (Banjar) เมื่อชุมชนขยายใหญ่ขึ้นเรียกว่า "บันวา" (Banwa / Thani / Desa) ประชาชนเรียกว่า "การามัน" (Karaman) ผู้นำเรียกว่า "ตูฮาเดซา" (Tuha Desa) และกลุ่มชาวนาที่รวมตัวกันทำนาเรียกว่า "ซูวัก" (Suwak / Subak) มีหัวหน้าเรียกว่า "ปากาเซร์" (Paka Ser / Pakaseh) (DOC PAGE: 21–22, 38 / Book pp. 4–5, 21)
- **พันธมิตร 20 ซูบักแห่งลุ่มน้ำปาเกอริซัน (Federation of 20 Subaks):** สหพันธ์ซูบักที่ขึ้นตรงต่อปูรามาสเจตีครอบคลุมพื้นที่ชลประทานขนาดมหึมา 2 เขต คือ ซูบักปาเกอริซันตอนล่าง (Subak Pakerisan Teben) และซูบักกูนุงซารี (Subak Gunung Sari) ประกอบด้วย 20 ซูบักอย่างเป็นทางการ:
  1. Subak Gaga, 2. Subak Dayang, 3. Subak Diga, 4. Subak Dewa, 5. Subak Amping,
  6. Subak Poh Gading, 7. Subak Betuas, 8. Subak Slukat, 9. Subak Sengauk, 10. Subak Abang,
  11. Subak Dukuh, 12. Subak Tedung, 13. Subak Nengan, 14. Subak Abu, 15. Subak Celuk,
  16. Subak Ceti, 17. Subak Padang Legi, 18. Subak Panjan, 19. Subak Jurit, 20. Subak Peling
  แต่ละซูบักมีปากาเสะฮ์ (Pakaseh) เป็นผู้นำ และทั้งหมดมีพันธะหน้าที่ทางจารีตในการระดมแรงงาน (Ngayah) ปรนนิบัติบูรณะเทวสถาน (DOC PAGE: 32, 49–50 / Book pp. 15, 32–33)
- **ระบบการคลังและงบประมาณเทวสถาน (Temple Finance & Resource Allocation):** ค่าใช้จ่ายในการบูรณะและจัดพิธีกรรมหลวง มิได้พึ่งพาเงินจากกษัตริย์ฝ่ายเดียว หากเกิดจากการระดมทุน 4 สาย: ดอกผลจากที่ดินนาของวัด (Laba Pura), เงินเรี่ยไรรายแปลงจากชาวนาซูบัก (Papeson / Pasek-pasek), พระราชทรัพย์บริจาคจากราชสำนัก/รัฐบาล (Punya Sang Maweng Rat), และของถวายจากสาธุชนทั่วไป (Aturan Damuh) (DOC PAGE: 33, 51 / Book pp. 16, 34)

#### 7. มิติเพศสภาพ เทวีศักดิ์สิทธิ์ และการผลิตซ้ำทางพิธีกรรม (Gender, Sacred Goddesses & Feminine Agro-Cosmology)
- **เทวีดานุฮ์ในฐานะมารดาแห่งความอุดมสมบูรณ์ (Bhatari Danuh as Cosmic Mother):** สตรีเพศในจักรวาลวิทยาบาหลีถูกยกย่องเป็นแหล่งกำเนิดแห่งน้ำและชีวิต ภะฏารีดานุฮ์ได้รับการเชิดชูคู่กับ "เทวีภูมิมารดา" (Dewi Bhumi / Dewi Ibu) ซึ่งได้รับการบูชา ณ แท่นหินเตปาซานา/สัปตปาตาละ พระองค์เป็นผู้ตรวจสอบความทุกข์ยากของชาวนาและนำน้ำลงมาป้อนสู่ไร่นาผ่านระบบลำธาร (DOC PAGE: 22, 26, 39, 43 / Book pp. 5, 9, 22, 26)
- **ดุลยภาพปุรุษะ-ประกฤติผ่านหอกลองคู่ (Purusa-Pradhana Symbolism):** บนหอกลองกุลกุล (Bale Kulkul) ในลานกลาง มีการแขวนกลองไม้ผ่าซีกคู่ขนานกันสองใบ เรียกว่า "กุลกุลลานัง" (Kulkul Lanang - กลองเพศผู้/ปุรุษะ) และ "กุลกุลวาโดน" (Kulkul Wadon - กลองเพศเมีย/ประกฤติ) ซึ่งจะต้องถูกตีประสานเสียงพร้อมกันในยามประกอบพิธีกรรมเทวยัชญะ เพื่อสะท้อนการรวมเป็นหนึ่งของพลังเพศชายและเพศหญิงในการสร้างสรรค์และคุ้มครองจักรวาล (DOC PAGE: 28, 45 / Book pp. 11, 28)
- **วิคุตาปินีและกลุ่มสตรีผู้รังสรรค์เครื่องพลีกรรม (Wiku Tapini & Female Ritual Labor):** ณ ปูราตามัน มีแท่นบูชาพระวิคุตาปินี (Wiku Tapini) ผู้เป็นมหาเทวี/ปุโรหิตาสตรีผู้อุปถัมภ์การประดิษฐ์เครื่องบูชาดอกไม้และใบตอง (Banten / Majejahitan) ณ ศาลาบาเลเรริงกีตัน ซึ่งแรงงานสตรีชาวนามีบทบาทหลักในการจัดเตรียมเครื่องบวงสรวงอันสลับซับซ้อน (DOC PAGE: 28–29, 46 / Book pp. 11–12, 29)

#### 8. ธรรมเนียม จารีตประเพณี และภาษาศักดิ์สิทธิ์ (Court Rituals, Customary Law & Sacred Idioms)
- **จตุรภาคีแห่งกฎบัตรประเพณี (Fourfold Canonical Framework):** การประกอบพิธีและการบริหารจัดการปูรามาสเจตีต้องดำเนินไปตามกรอบ 4 ประการอย่างเคร่งครัด ได้แก่:
  1. *สีมา (Sima):* กฎระเบียบและเขตแดนศักดิ์สิทธิ์ที่สถาปนามาแต่โบราณ
  2. *ดฤษฏา (Drsta / Dresta):* จารีตประเพณีที่ปฏิบัติสืบทอดกันมาของบรรพชน
  3. *ศาสตรา (Sastra):* พระคัมภีร์และตำราพิธีกรรมทางศาสนา
  4. *ปาราเร็ม (Pararem) และ ปลูตุก (Plutuk):* ข้อตกลงร่วมกันของประชาคมซูบักและคู่มือระเบียบปฏิบัติพิธีกรรม (DOC PAGE: 31, 32, 48, 50 / Book pp. 14, 15, 31, 33)
- **ภาษาศักดิ์สิทธิ์แห่งการสวดขอขมา (Pangaksama Sacred Discourse):** ปุราณะเปิดด้วยบทร้อยกรองภาษาสันสกฤต-กาวี "มหาเทวะมนตรา" (*Ong Ksamam swamam Mahadewa, Hotyesti Ongkara mantram...*) เพื่อขอขมาต่อทวยเทพและดวงวิญญาณบรรพชน การเปล่งเสียงมนตร์อักษรโอมการะ (Ongkara) ถือเป็นหัวใจในการชำระจิตใจของผู้ประกอบพิธีให้บริสุทธิ์ปราศจากมลทิน (Suddha Sucinirmalam) เพื่อป้องกันมิให้ผู้คัดลอกหรือผู้อ่านต้องคำสาป (Tulah Pamidi) หรือเคราะห์กรรม (Upadrawa) (DOC PAGE: 20–21, 36–37 / Book pp. 3–4, 19–20)
- **สถานะกาฮยางันจากัตและกาฮยางันสวากีนา (Dual Sacred Status):** เทวสถานแห่งนี้ได้รับการประกาศให้เป็นทั้ง "กาฮยางันจากัต" (Kahyangan Jagat - เทวสถานแห่งสากลพิภพที่กษัตริย์และชาวบาหลีทุกคนต้องกราบไหว้) และ "กาฮยางันสวากีนา" (Kahyangan Swagina - เทวสถานเฉพาะสายอาชีพของชาวนาซูบัก) ซึ่งสะท้อนการเชื่อมต่อระหว่างมิติทางจิตวิญญาณระดับชาติกับมิติวิถีชีวิตทางเศรษฐกิจระดับรากหญ้า (DOC PAGE: 31, 49 / Book pp. 14, 32)

#### 9. เครื่องสูง เทวรูปสัญลักษณ์ และดนตรีศักดิ์สิทธิ์ (Regalia, Effigies, Tapakan & Sacred Gamelan)
- **ตาปากันและเทวรูปหน้ากากศักดิ์สิทธิ์ (Tapakan / Sacred Effigies):** ภายในลานในมีเรือนเก็บรักษาพิเศษ "เกอดง ซิมเปิน" (Gedong Simpen) ซึ่งเป็นที่ประดิษฐานของ "ตาปากัน" (Tapakan) หรือหน้ากากศักดิ์สิทธิ์รูปบารง (Barong) และรังดา (Rangda) หรือรูปเคารพจำลองของเทพเจ้า ซึ่งจะได้รับการอัญเชิญออกมาแต่งองค์ทรงเครื่อง ณ ศาลาบาเลเปียซันเฉพาะในวาระพิธีปีโอดาลันเท่านั้น (DOC PAGE: 27, 44 / Book pp. 10, 27)
- **มโหรีคามะลันและนาฏศิลป์ศักดิ์สิทธิ์ (Gamelan Gong & Sacred Performance):** ในมัธยมมณฑลมีศาลา "บาเล ปากัมบูฮัน" (Bale Pagambuhan) ซึ่งใช้เป็นเวทีแสดงนาฏศิลป์ละครรำโบราณ "กัมบูฮ์" (Gambuh) ถวายแด่ทวยเทพ ละครกัมบูฮ์เป็นนาฏศิลป์ราชสำนักชั้นสูงสุดที่สืบทอดมาจากชวา-มัชปาหิต ใช้ภาษาชวาโบราณ ขับขานคลอเคลียด้วยวงดนตรีคามะลันจากศาลาบาเลกง (DOC PAGE: 27, 28, 44, 45 / Book pp. 10, 11, 27, 28)
- **ศาลาขับลำนำพระเวทและบทกวีศักดิ์สิทธิ์ (Bale Gegitan / Bale Sake Nem):** ศาลาเสาหกต้นในลานกลาง มีไว้เฉพาะสำหรับกลุ่มนักสวดในการขับลำนำเพลงสวดศักดิ์สิทธิ์ (Gita / Kidung Wargasari) เพื่อสร้างคลื่นเสียงอันสงบระงับกล่อมเกลาจิตใจของสาธุชนก่อนย่างก้าวผ่านประตูโกรีอากุงเข้าสู่เขตชั้นใน (DOC PAGE: 28, 45 / Book pp. 11, 28)

#### 10. พระราชพิธีบรมราชาภิเษก การสถาปนา และพิธีกรรมประจำรอบปี (Royal Patronage, Pujawali & Ritual Cycles)
- **พระราชพิธีปีโอดาลันและขบวนแห่สรงน้ำทะเล (Piodalan & Masucian Procession):** พิธีฉลองวันคล้ายวันสถาปนาวัดจัดขึ้นทุกรอบ 210 วัน (6 เดือนบาหลี) ตรงกับวันอังคาร กลิวอน สัปดาห์เมอดังเซีย (Anggara Kasih Medangsia) ลำดับพิธีเริ่มจากการอัญเชิญเทวรูปจากวัดปันยิมเปอนัน (Banjar Anggar Kasih) เคลื่อนขบวนยาตราไปประกอบพิธีสรงน้ำชำระล้างความบริสุทธิ์ (Masucyan) ณ ท้องทะเลมาสเจตี (Sagara Masceti) และน้ำพุศักดิ์สิทธิ์ตีร์ถาสลูกัต (Tirtha Selukat) จากนั้นอัญเชิญขึ้นประทับในวัดเพื่อรับการบวงสรวงและสถิตอยู่เป็นเวลา 3 วัน (Nyejer tigang dinten) ก่อนทำพิธีปิดประตูส่งเสด็จ (Masineb) (DOC PAGE: 30–31, 48–49 / Book pp. 13–14, 31–32)
- **วัฏจักรพิธีกรรมเกษตรกรรมตลอดรอบปี (Agricultural Ritual Calendar):**
  1. *เนอดุฮ์ (Neduh):* จัดขึ้นทุกปีในวัน Anggara Kasih Dukut เพื่อบวงสรวงขอให้พืชผลในไร่นาเจริญงอกงาม ปราศจากโรคระบาด
  2. *งูซาบา เกอตูปัต (Ngusaba Ketipat):* จัดขึ้นทุกปีในวัน Anggara Kasih Kulantir เป็นพิธีขอบคุณพระแม่โพสพและเทพเจ้าด้วยข้าวต้มมัดใบมะพร้าว (Ketipat) ภายหลังการเก็บเกี่ยวข้าวได้ผลอุดมสมบูรณ์
  3. *ปางาจี กาเลจัน หรือ ตาบุฮ์ระฮ์ (Pangaci Kalecan / Tabuh Rah):* จัดติดต่อกันทุกวันตั้งแต่วันศุกร์ Pon Kulantir ถึงวันจันทร์ Umanis Tolu รวม 4 วัน มีการชนไก่บวงสรวงโดยวางเงินเดิมพันตามจารีต 1,000 เกเป็ง (เหรียญจีนโบราณ) เลือดไก่ที่หยดลงดินร่วมกับเหล้ากลั่น (Arak), สุราข้าวหมัก (Berem), น้ำตาลเมา (Tuak), และน้ำบริสุทธิ์ (Toya Anyar) เป็นเครื่องเซ่นเพื่อสงบระงับภูตผีปีศาจ (Nyomyang Bhuta Kala)
  4. *อาจี มาเตตาบูฮัน เบอเร็ม (Aci Matetabuhan Berem):* จัดขึ้นในวัน Anggara Kasih Julungwangi สมาชิกซูบักทั้ง 20 แห่งจะต้องนำเหล้าข้าวหมักสีแดง (Berem) มาซูบักละ 1 ไห เพื่อนำไปรินหลั่งบวงสรวงลงบนพื้นดินเบื้องหน้าแท่นบูชาทุกแท่นในวัด
  5. *งาตูรัง ลิงกิฮ์ (Ngaturang Linggih):* จัดขึ้นในเดือนห้าทางจันทรคติ (Sasih Kalima) ถวายเครื่องพลีกรรมข้าวรูปศาลา (Nasi Bale-an) (DOC PAGE: 29–30, 47–48 / Book pp. 12–13, 30–31)
- **มหาพิธีปาดูดูซันหลวงรอบ 30 ปี (Padudusan Great Cleansing Rite):** มหาพิธีชำระล้างมลทินจักรวาลและเฉลิมฉลองสถานะกาฮยางันจากัต กำหนดจัดขึ้นทุกรอบ 30 ปี (Tigang dasa warsa) ตรงกับวันปีโอดาลัน Anggara Kasih Medangsia ซึ่งเป็นการระดมความร่วมมือระดับสูงสุดระหว่างราชสกุลปูรีเกอรามัส/ปูรีเกียนยาร์ พระสังฆราชเปอดันดาจากทุกนิกาย และสหพันธ์ซูบักทั้งปวง (DOC PAGE: 31, 48–49 / Book pp. 14, 31–32)

### ส่วนที่ 6: คลังคำศัพท์เฉพาะทางจากเอกสาร (Native Terminology Glossary)

| คำศัพท์ดั้งเดิม (Kawi / Balinese / Sanskrit) | คำอ่านถ่ายทอดเสียงไทย | ความหมายเชิงวิชาการและบริบทการใช้งานในราชมนเทียรศึกษา |
| :--- | :--- | :--- |
| **Purana** | ปุราณะ | เอกสารคัมภีร์จารึกใบลานบันทึกประวัติศาสตร์ เทววิทยา กฎระเบียบ จารีต และผังเทวสถาน |
| **Pura Masceti** | ปูรามาสเจตี | มหาเทวสถานเกษตรกรรมและชลประทานชั้นสูงสุดริมหาดเมอดาฮัน-เกอรามัส กียันยาร์ |
| **Kahyangan Jagat** | กาฮยางัน จากัต | เทวสถานระดับสากลพิภพ เป็นศูนย์กลางจักรวาลที่กษัตริย์และชนทุกวรรณะต้องเคารพบูชา |
| **Kahyangan Swagina** | กาฮยางัน สวากีนา | เทวสถานตามสายอาชีพ ในที่นี้คือเทวสถานศูนย์กลางของเกษตรกรชาวนาและระบบชลประทาน |
| **Panganceng** | ปางันเจ็ง | ตำแหน่งองค์อุปถัมภ์สูงสุดของวัด สงวนแด่ราชวงศ์ปูรี (Puri Agung Keramas / Puri Gianyar) |
| **Pangrajeg Karyya** | ปางราเจกการ์ยา | องค์ประธานและผู้นำสูงสุดในการจัดงานพระราชพิธีหลวงของเทวสถาน |
| **Pangempon / Pangamong** | ปาเงิมปอน / ปาเงามอง | ประชาคมผู้มีพันธะหน้าที่ดูแล รักษา ออกแรงงาน และบำรุงเทวสถาน (สหพันธ์ซูบัก 20 แห่ง) |
| **Panyungsung** | ปันยุงซุง | พุทธศาสนิกชน/ฮินดูชนทั่วไปที่เดินทางมาร่วมสักการะบูชาแต่ไม่มีพันธะออกแรงงานประจำ |
| **Subak** | ซูบัก (เดิม: ซูวัก) | องค์กรชลประทานแบบจารีตประเพณีของชาวนาบาหลี มีเอกราชในการบริหารจัดการน้ำและพิธี |
| **Pakaseh / Paka Ser** | ปากาเสะฮ์ / ปากาเซร์ | หัวหน้าองค์กรชลประทานซูบัก ผู้ควบคุมการปันน้ำและการประสานงานพิธีกรรมร่วมกับปูรี |
| **Pakerisan Teben** | ปาเกอริซัน เตเบน | พื้นที่ลุ่มน้ำปาเกอริซันตอนล่างก่อนออกสู่ทะเล แหล่งรวม 20 ซูบักบริวารปูรามาสเจตี |
| **Bhatari Danuh** | ภะฏารี ดานุฮ์ | พระแม่แห่งทะเลสาบยอดเขาบาตูร์ เทพีแห่งน้ำจืด ความอุดมสมบูรณ์ และสัญลักษณ์สตรีเพศ |
| **Bhatara Baruna** | ภะฏาระ บารุณา | พระวรุณ เทพแห่งมหาสมุทรใต้และน้ำเค็ม (Bhatara Tengahing Sagara / Bhatara Segara) |
| **Nangluk Merana** | นังลุก เมอรานา | พิธีกรรมศักดิ์สิทธิ์เพื่อขับไล่ กำราบ และสงบระงับศัตรูพืช โรคระบาด และภัยธรรมชาติ |
| **Marana** | เมอรานา / มะระณะ | ภัยพิบัติ ศัตรูพืช โรคระบาดในไร่นา (เช่น ตั๊กแตนสิง หนู นก เพลี้ย) |
| **Sang Hyang Rare Angon** | สังฮยัง ราเรอังงน | พระภาคหนึ่งของพระศิวะในรูปลักษณ์เด็กเลี้ยงวัว เทพอภิบาลสัตว์เลี้ยงและเกษตรกร |
| **Sang Hyang Naga Basuki** | สังฮยัง นาวาสุกี | พญานาควาสุกี สัญลักษณ์แห่งความอุดมสมบูรณ์ของสายน้ำและผู้ค้ำจุนโลกธาตุ |
| **Mpu Kuturan** | มปู กุตูรัน | มหาโยคีราชปุโรหิตจากชวา (คริสต์ศตวรรษที่ 11) ผู้ปฏิรูปผังวัดบาหลีและสร้างหอเมรุ |
| **Dang Hyang Nirartha** | ดังฮยัง นิราร์ถา | มหาบรรพชิตจากชวา (คริสต์ศตวรรษที่ 16) ผู้สถาปนาแท่นปัทมาสน์และระบบไศวนิกาย |
| **I Gusti Agung Maruti** | อี กุสตี อากุง มารูตี | อัครมหาเสนาบดีผู้ครองเจลเจล แล้วลี้ภัยมาสร้างปูรีเกอรามัสและบูรณะปูรามาสเจตี |
| **Tri Mandala** | ตรีมณฑล | ระบบการจัดผังพื้นที่ 3 ลาน: อุตตมะมณฑล (ใน), มัธยมมณฑล (กลาง), กนิษฐมณฑล (นอก) |
| **Kori Agung / Candi Kurung** | โกรีอากุง / จันดีกูรุง | ประตูซุ้มยอดทึบขนาดใหญ่ ทางผ่านสู่ลานใน ขนาบด้วยปีกบินตังอาริง |
| **Bintang Aring** | บินตัง อาริง | กำแพงปีกแยกลดหลั่นขนาบสองข้างของประตูโกรีอากุงเพื่อเสริมความสง่างามและความมั่นคง |
| **Candi Bentar** | จันดี เบินตาร์ | ประตูผ่าซีก ทางผ่านระหว่างลานนอกสู่ลานกลาง สัญลักษณ์การผ่าแยกเขาพระสุเมรุ |
| **Padmasana** | ปัทมาสน์ | แท่นเสาหินเดี่ยวทรงดอกบัว ที่ประทับของพระปรมวิเศษ (Acintya) สถาปนาโดยนิราร์ถา |
| **Meru Tumpang Lima** | เมรุ ตุมปัง ลิมา | หอเมรุ 5 ชั้น แท่นประทับของภะฏาระมาสเจตี / ปัญจเทวตา |
| **Meru Tumpang Tiga** | เมรุ ตุมปัง ติกา | หอเมรุ 3 ชั้น แท่นประทับของราตูอูลุนซูวี (ภะฏารีดานุฮ์) / ตรีมูรติ |
| **Tepasana / Saptapatala** | เตปาซานา / สัปตปาตาละ | แท่นฐานหินขั้นบันได บูชาพระแม่ธรณี (Dewi Bhumi / Dewi Ibu) วิวัฒน์จากหินโบราณ |
| **Watu Roro** | วาตู โรโร | แท่นบูชาหินโบราณคู่ บูชาภะฏาระบารุณา เพื่อความปลอดภัยของชาวประมง |
| **Pangaci Kalecan (Tabuh Rah)** | ปางาจี กาเลจัน (ตาบุฮ์ระฮ์) | พิธีชนไก่บวงสรวงเพื่อสังเวยเลือดแด่ภูตกาฬ ใช้เดิมพันเหรียญเกเป็ง 1,000 เหรียญ |
| **Aci Matetabuhan Berem** | อาจี มาเตตาบูฮัน เบอเร็ม | พิธีที่ซูบักทั้ง 20 แห่งต้องนำเหล้าข้าวหมัก 1 ไห มารินบวงสรวงหน้าแท่นบูชาทุกแท่น |
| **Neduh** | เนอดุฮ์ | พิธีประจำปีในวัน Anggara Kasih Dukut บวงสรวงขอความอุดมสมบูรณ์แก่พืชผล |
| **Ngusaba Ketipat** | งูซาบา เกอตูปัต | พิธีประจำปีในวัน Anggara Kasih Kulantir ถวายข้าวต้มมัดขอบคุณผลผลิตข้าว |
| **Piodalan** | ปีโอดาลัน | พิธีฉลองวันคล้ายวันสถาปนาวัด จัดขึ้นทุก 210 วัน (Anggara Kasih Medangsia) |
| **Padudusan** | ปาดูดูซัน | มหาพิธีชำระล้างมลทินจักรวาล จัดขึ้นทุก 30 ปี (ตามใบลาน) หรือทุก 3 ปี (ตามคำแปล) |
| **Bandesa Pura** | เบินเดซา ปูรา | ประธานคณะกรรมการบริหารวัด คัดเลือกจากผู้อาวุโสของสมาชิกซูบัก 20 แห่ง |
| **Pamangku Gede** | เปอมังกู เกอเด | สมุหพระราชพิธีหรือหัวหน้านักบวชผู้ประกอบพิธีประจำวัด (Jan Bangul) |
| **Ngayah** | งายะฮ์ | การอุทิศแรงกายแรงใจทำงานบำรุงวัดและศาสนพิธีโดยไม่หวังผลตอบแทนทางวัตถุ |
| **Laba Pura** | ลาภา ปูรา | ผลประโยชน์และดอกผลจากที่ดินธรณีสงฆ์ของวัดเพื่อใช้เป็นงบประมาณดำเนินงาน |
| **Papeson / Pasek-pasek** | ปาเปโซน / ปาเสก-ปาเสก | ค่าบำรุงหรือเงินเรี่ยไรตามจารีตที่สมาชิกซูบักร่วมกันจ่ายเพื่อจัดพิธีกรรม |
| **Candrasangkala** | จันทรสังขยา | รหัสคำแทนตัวเลขศักราชในคัมภีร์โบราณ (pandhita guna gapura candra = 1937/1935) |
