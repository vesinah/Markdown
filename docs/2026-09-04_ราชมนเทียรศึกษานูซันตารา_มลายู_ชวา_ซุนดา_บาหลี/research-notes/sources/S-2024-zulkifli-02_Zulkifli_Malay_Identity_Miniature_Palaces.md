### ส่วนที่ 2: แผนผังการจัดสรรเข้าสู่บทและหัวข้อย่อย (Chapter & Section Mapping Matrix)

*การจัดสรรข้อมูล ข้อค้นพบ และหลักฐานเชิงประจักษ์จากเอกสารฉบับนี้เข้าสู่โครงสร้างหนังสือ:*

1. **บทที่ 1: บทประมวลสังเคราะห์ภาพรวมระดับมหภาคและทฤษฎีอำนาจเชิงพื้นที่**
   - **หัวข้อย่อย 1.1 (กรอบทฤษฎีอำนาจเชิงพื้นที่และสัญวิทยาแห่งราชมณเฑียร):**  
     การประยุกต์ทฤษฎีสัญวิทยา (Semiotics of Iconic Architecture) สถาปัตยกรรมพระราชวังและศาสนสถานหลวงในฐานะ "รูปสัญลักษณ์และสิ่งถูกแสดงแทน" (Signifier and Signified) ของอารยธรรมมลายู (หน้า 448–449 / PAGE 2–3)
   - **หัวข้อย่อย 1.3 (โครงสร้างสถาปัตยกรรมแบบไตรภาคแนวดิ่ง):**  
     การวิเคราะห์สัณฐานวิทยาตามแนวแกนตั้ง (Vertical Approach) 3 ระดับ: ส่วนบน (หลังคาปั้นหยา/โดม), ส่วนกลาง (ผนัง เสา ช่องเปิด), และส่วนล่าง (ใต้ถุนยกสูง) (หน้า 449–450 / PAGE 3–4, หน้า 452 / PAGE 6, หน้า 455–456 / PAGE 9–10)

2. **บทที่ 2: รวมทุกอย่างเกี่ยวกับระบบวังเจ้ามลายู (Istana Melayu) — สุมาตราตะวันออก (East Coast of North Sumatra)**
   - **หัวข้อย่อย 2.1 (บริบททางประวัติศาสตร์และกำเนิดราชสำนักมลายูชายฝั่งสุมาตรา):**  
     ประวัติศาสตร์และภูมิศาสตร์วัฒนธรรมของรัฐสุลต่านเดลี (Kesultanan Deli), รัฐสุลต่านลังกัต (Kesultanan Langkat), และแคว้นบาตูบารา (Kedatuan Batubara) (หน้า 447–448 / PAGE 1–2, หน้า 453 / PAGE 7)
   - **หัวข้อย่อย 2.3 (ลำดับชั้น 4 ระดับของเคหสถานและพระราชวังมลายู):**  
     - พระราชวังหลวง (Istana Sultan): พระราชวังไมมูน (Istana Maimun) แห่งเดลี และพระราชวังเนียตลีมาลารัซ (Istana Niat Lima Laras) แห่งบาตูบารา
     - เรือนเคหสถานดั้งเดิม (Rumah Panggung / Rumah Tradisional Melayu) ในฐานะรากฐานทางสถาปัตยกรรมที่พัฒนาสู่วังเจ้า (หน้า 454 / PAGE 8, หน้า 455 / PAGE 9)
   - **หัวข้อย่อย 2.4 (แผนผังและการจัดวางเชิงพื้นที่ของพระราชวังมลายู):**  
     - การวางผังสมมาตรแนวนอน (Horizontal Bilateral Symmetry) ของวังไมมูนที่แผ่ปีกออกซ้ายขวาอย่างสง่างาม (หน้า 453 / PAGE 7)
     - ผังอาคารแปดเหลี่ยมสมมาตร (Octagonal Pattern) และมุขระเบียง 4 ทิศของมัสยิดหลวงอัลมาซุน (หน้า 453 / PAGE 7)
     - ผังอาคารที่ตอบสนองทิศทางลมและอักษะ 4 ทิศของวังเนียตลีมาลารัซ (หน้า 449 / PAGE 3, หน้า 453 / PAGE 7)
   - **หัวข้อย่อย 2.5 (การออกแบบและสถาปัตยกรรมเชิงช่างมลายู — พหุลักษณ์ทางวัฒนธรรม):**  
     การสังเคราะห์รูปแบบสถาปัตยกรรมลูกผสม 3 วัฒนธรรมในวังไมมูน: โครงสร้างไม้และหลังคาปั้นหยามลายู + ซุ้มโค้งและเสาผนังแบบยุโรป + โดมหัวหอมแบบเปอร์เซีย-อิสลาม ผลงานสถาปนิกชาวดัตช์ Theodoore van Erp (หน้า 452–453 / PAGE 6–7)
   - **หัวข้อย่อย 2.6 (หมู่อาคารประกอบในวังและศูนย์กลางอำนาจ):**  
     ความสัมพันธ์เชิงพื้นที่ระหว่างพระราชวังไมมูนกับมัสยิดหลวงอัลมาซุนในฐานะกลุ่มคอมเพล็กซ์ราชธานีเดลี (หน้า 453 / PAGE 7), ศาลาว่าการจารีตประเพณี (Balai Adat / TCMBS Stabat) (หน้า 454 / PAGE 8)
   - **หัวข้อย่อย 2.10 (ธรรมเนียม กฎระเบียบ และปรัชญาสังคมราชสำนัก):**  
     ปรัชญา "ความเปิดกว้างและการต้อนรับขับสู้" (Openness and Hospitality) ที่สะท้อนผ่านการจัดวางเสาจำนวนมากและช่องโค้งเปิดโล่ง (Pillars and Niches) ในพระราชวังและมัสยิดหลวง (หน้า 452 / PAGE 6)
   - **หัวข้อย่อย 2.11 (เครื่องราชกกุธภัณฑ์ สัญลักษณ์สี และงานประณีตศิลป์):**  
     - สัญลักษณ์สีเชิงวัฒนธรรม: สีเหลืองราชสำนัก (Kuning Diraja) แห่งอำนาจกษัตริย์ ผสานกับสีเขียว (Hijau) แห่งจิตวิญญาณอิสลาม (หน้า 457 / PAGE 11)
     - งานไม้ฉลุโปร่งลายพันธุ์พฤกษา (Transparent Traditional Malay Ornaments) (หน้า 454 / PAGE 8)

3. **บทที่ 7: บทวิเคราะห์เฉพาะสถาปัตยกรรม วิศวกรรมพื้นถิ่น และระบบแผนผังอย่างละเอียด**
   - **หัวข้อย่อย 7.1 (วิศวกรรมโครงสร้างไตรภาคแนวดิ่ง):**  
     การถอดรหัสโครงสร้าง 3 ชั้น: ฐานรากยกใต้ถุนสูง (Staged foundation) เพื่อสร้างภาพลักษณ์น่าเกรงขามและระบายอากาศ, ตัวเรือนที่เต็มไปด้วยเสาและช่องลม, หลังคาทรงปั้นหยา (Pyramidal roof) และทรงโดม (Domed roof) (หน้า 452 / PAGE 6, หน้า 455–456 / PAGE 9–10)
   - **หัวข้อย่อย 7.2 (การศึกษาเปรียบเทียบสัณฐานวิทยาอาคารราชสำนัก):**  
     การเปรียบเทียบทางเรขาคณิตระหว่างวังไมมูน, วังเนียตลีมาลารัซ, มัสยิดอาซีซี, และเรือนสามัญชน (หน้า 453–455 / PAGE 7–9)

4. **บทที่ 8: มรดกวัฒนธรรมราชมนเทียรศึกษาในโลกร่วมสมัย (Contemporary Royal Heritage Studies)**
   - **หัวข้อย่อย 8.1 (การอนุรักษ์เชิงสัญนิยมและการจำลองสถาปัตยกรรมขนาดจิ๋ว):**  
     บทบาทของสถาปัตยกรรมจำลอง (Miniature Creation) ในฐานะเครื่องมือ "อนุรักษ์เชิงรูปแบบ" (Form Conservation) สำหรับโบราณสถานราชสำนักที่กำลังเสื่อมสภาพและขาดงบประมาณดูแล เช่น พระราชวังเนียตลีมาลารัซ (หน้า 451 / PAGE 5, หน้า 453 / PAGE 7, หน้า 459 / PAGE 13)
   - **หัวข้อย่อย 8.2 (ทฤษฎีศิลปะการท่องเที่ยวและการปรับแปลงมรดกราชสำนัก):**  
     การประยุกต์ทฤษฎีศิลปะการท่องเที่ยวของ R.M. Soedarsono: ย่อส่วน, กะทัดรัด, หลากหลาย, ปลดเปลื้องความศักดิ์สิทธิ์เชิงไสยศาสตร์, และราคาจับต้องได้ เพื่อเผยแพร่อัตลักษณ์มลายูสู่สากล (หน้า 450 / PAGE 4, หน้า 458 / PAGE 12)
   - **หัวข้อย่อย 8.3 (การสืบทอดภูมิปัญญาเชิงช่างผ่านอุตสาหกรรมสร้างสรรค์และดิจิทัล):**  
     การผสานงานช่างไม้ดั้งเดิมเข้ากับโปรแกรมคอมพิวเตอร์ดิจิทัล (CorelDRAW) และวัสดุประยุกต์ (ไม้, กระดาษแข็ง, แป้งดินประดิษฐ์) เพื่อการผลิตซ้ำอย่างมีคุณภาพและสร้างความตระหนักรู้ในหมู่คนรุ่นใหม่อย่างยั่งยืน (หน้า 457–458 / PAGE 11–12)

### ส่วนที่ 3: สรุปสาระสำคัญเชิงวิเคราะห์และจุดยืนทางวิชาการ (Executive Academic Analysis)

#### 1. วิทยานิพนธ์และข้อถกเถียงหลักของผู้เขียน (Core Argument / Thesis)

บทความวิจัยของ ซุลกิฟลี และคณะ (Zulkifli et al., 2024) ตีพิมพ์ในวารสารระดับนานาชาติ *Creativity Studies* (Vilnius Gediminas Technical University) นำเสนอข้อถกเถียงหลักว่าด้วยการพิทักษ์ ฟื้นฟู และสืบทอดอัตลักษณ์มลายูของสุมาตราเหนือผ่านการจำลองสถาปัตยกรรมพระราชวังและเคหสถานหลวงขนาดจิ๋ว (Miniature Creation) โดยมีสาระสำคัญเชิงวิชาการ 4 ประการ:

1. **สถาปัตยกรรมราชสำนักในฐานะรูปสัญลักษณ์สูงสุดแห่งอารยธรรมมลายู (Iconic Architecture as Cultural Signifier):**  
   ผู้เขียนใช้กรอบทฤษฎีสัญวิทยา (Semiotics) ชี้ว่า พระราชวัง (เช่น วังไมมูน และวังเนียตลีมาลารัซ) และมัสยิดหลวง (เช่น มัสยิดอัลมาซุน และมัสยิดอาซีซี) มิได้เป็นเพียงสิ่งปลูกสร้างทางกายภาพ แต่ทำหน้าที่เป็น "รูปสัญลักษณ์" (Iconic Form) ซึ่งเป็นตัวแทนเชิงสัญญะ (Signifier) ของความรุ่งเรืองในอดีต (Past Malay Glory) และความชอบธรรมทางจิตวิญญาณของชุมชนมลายูชายฝั่งสุมาตราเหนือ (หน้า 447, 448–449 / PAGE 1, 2–3)

2. **การถอดรหัสโครงสร้างไตรภาคแนวดิ่งและความหมายเชิงสังคมวิทยา (Vertical Tripartite Decoding & Sociological Meaning):**  
   บทวิเคราะห์ทางสถาปัตยกรรมชี้ว่า อาคารมลายูโบราณจำแนกออกเป็น 3 ส่วนหลักตามแนวดิ่ง ได้แก่:
   - **ส่วนบน (Top):** หลังคาปั้นหยา (Pyramidal roof) สำหรับที่ประทับและเคหสถาน, หลังคาทรงโดม (Domed roof) สำหรับศาสนสถาน, และการผสานสองรูปทรงเข้าด้วยกันในพระราชวังหลวง
   - **ส่วนกลาง (Middle):** โครงสร้างที่เต็มไปด้วยเสา ระเบียง ช่องเปิด และซุ้มโค้ง (Pillars and Niches) ซึ่งนอกจากจะทำหน้าที่ระบายอากาศและรับแสงธรรมชาติในเขตมรสุมเขตร้อนแล้ว ยังแฝงความหมายเชิงสังคมวิทยาอันลึกซึ้งถึง "ความเปิดกว้างและอัธยาศัยไมตรี" (Openness and Hospitality) ของชาวมลายู
   - **ส่วนล่าง (Bottom):** การยกใต้ถุนสูง (Staged / Elevated Base) ซึ่งตอบสนองทั้งการป้องกันน้ำท่วม-สัตว์ร้าย และการสร้าง "ความน่าเกรงขามสง่างาม" (Great Impression and Dignified Image) ให้แก่ผู้อยู่อาศัย (หน้า 449–450, 452 / PAGE 3–4, 6)

3. **การอนุรักษ์เชิงรูปแบบเพื่อกอบกู้วังโบราณที่กำลังสูญสลาย (Form Conservation for Endangered Heritage):**  
   ผู้เขียนชี้ให้เห็นภาวะวิกฤตของมรดกราชสำนักมลายู โดยเฉพาะอย่างยิ่ง "พระราชวังเนียตลีมาลารัซ" (Istana Niat Lima Laras) ในอำเภอบาตูบารา ซึ่งเป็นพระราชวังไม้ริมฝั่งทะเลที่ทรงคุณค่าแต่ทรุดโทรมลงอย่างหนักและขาดการบำรุงรักษา ในบริบทที่อาคารจริงสุ่มเสี่ยงต่อการพังทลาย การสร้างสถาปัตยกรรมจำลองขนาดจิ๋วที่แม่นยำทางสัดส่วนร่วมกับการจัดเก็บฐานข้อมูลดิจิทัล ถือเป็นยุทธศาสตร์ "การอนุรักษ์เชิงรูปแบบ" (Conservation Method) ที่ช่วยบันทึกโครงสร้าง สัดส่วน และลวดลายฉลุไม้ไว้ไม่ให้สูญหายไปตามกาลเวลา (หน้า 449, 453 / PAGE 3, 7)

4. **การถ่ายทอดภูมิปัญญาเชิงช่างไม้สู่งานประณีตศิลป์ร่วมสมัย (Craftsmanship Transfer via Creative Industry):**  
   การศึกษานี้ปฏิเสธการมองของที่ระลึกเป็นเพียงสินค้าเชิงพาณิชย์เกรดต่ำ แต่เสนอให้นำ "ทฤษฎีความคิดสร้างสรรค์ของ Graham Wallas" และ "ทฤษฎีศิลปะการท่องเที่ยวของ R.M. Soedarsono" มาใช้เป็นระเบียบวิธีในการแปลงรหัสสถาปัตยกรรมราชสำนักสู่งานประณีตศิลป์จำลอง 3 มิติ โดยทดลองใช้วัสดุ 3 ชนิด (ไม้, การ์ดบอร์ด, แป้งดินประดิษฐ์) ผสานการออกแบบลวดลายซ้ำผ่านโปรแกรมดิจิทัล (CorelDRAW) เพื่อให้เกิดการผลิตซ้ำที่มีมาตรฐาน สอดแทรกสัญลักษณ์สีราชสำนักมลายู (เหลือง-เขียว) และสร้างความตระหนักรู้ในหมู่คนรุ่นใหม่อย่างยั่งยืน (หน้า 450, 457–458 / PAGE 4, 11–12)

#### 2. บริบทประวัติศาสตร์นิพนธ์และการประเมินความน่าเชื่อถือ (Historiography & Source Criticism)

- **ตำแหน่งแห่งที่ในประวัติศาสตร์นิพนธ์:**  
  งานวิจัยของ Zulkifli et al. (2024) ถือเป็นงานบุกเบิกที่ผสาน "ประวัติศาสตร์สถาปัตยกรรมราชสำนักนูซันตารา" (Palace Architecture Studies) เข้ากับ "มานุษยวิทยาศิลปะการท่องเที่ยวและอุตสาหกรรมสร้างสรรค์" (Tourism Art & Creative Heritage) ในแวดวงวิชาการสุมาตราเหนือ งานศึกษาส่วนใหญ่มักมุ่งเน้นไปที่กลุ่มชาติพันธุ์บาตักโตบา (Batak Toba) บริเวณทะเลสาบโตบา หรือเน้นเฉพาะวังไมมูนในเมืองเมดัน แต่งานชิ้นนี้ได้ขยายขอบเขตครอบคลุมไปยังรัฐสุลต่านลังกัตและแคว้นบาตูบารา ทำให้เห็นเครือข่ายสถาปัตยกรรมราชสำนักมลายูชายฝั่งตะวันออกอย่างรอบด้าน
- **ระเบียบวิธีวิจัยและการตรวจสอบความถูกต้อง (Methodological Rigor):**  
  ระเบียบวิธีวิจัยมีความเข้มงวดตามหลักวิชาการสากล โดยใช้แนวทางสังคม-วัฒนธรรม (Socio-cultural Approach) ประกอบด้วย:
  1) วิธีการสำรวจและจัดเก็บข้อมูลกายภาพ (Survey & Collection Method) ของอาคารจริงทั้ง 6 แห่ง
  2) วิธีการทดลองสร้างสรรค์ (Creative Experiment) ตามกระบวนการ 7 ขั้นตอนของ Graham Wallas (Preparation, Incubation, Illumination, Execution, Confirmation, Validation, Development)
  3) วิธีการอนุรักษ์มรดกวัฒนธรรม (Conservation Method)
  4) การตรวจสอบความถูกต้องของข้อมูลด้วยวิธีสามเส้า (Data Triangulation) โดยใช้นักวิชาการและผู้เชี่ยวชาญด้านวัฒนธรรมมลายูและสถาปัตยกรรมในสุมาตราเหนือจำนวน 8 ท่าน เป็นผู้ประเมินและสะท้อนผลผ่านแบบสอบถามวิจักษ์ (หน้า 451–452 / PAGE 5–6)
- **จุดเด่นและข้อจำกัดของเอกสาร:**  
  - *จุดเด่น:* ให้การวิเคราะห์สัณฐานวิทยาเชิงสถาปัตยกรรม (Architectural Morphology) ที่ชัดเจนมาก โดยเฉพาะการถอดรหัสโครงสร้างไตรภาคแนวดิ่ง และการชี้เป้าความสำคัญของพระราชวังเนียตลีมาลารัซ ซึ่งเป็นโบราณสถานที่มักถูกละเลยในเอกสารวิชาการกระแสหลัก
  - *ข้อจำกัด:* บทความมุ่งเน้นที่ผลลัพธ์ของการผลิตโมเดลจำลองเพื่อการท่องเที่ยวเป็นหลัก ทำให้การลงลึกในมิติประวัติศาสตร์เชิงเอกสารจดหมายเหตุของราชสำนักแต่ละแห่งมีอยู่อย่างจำกัด แต่สามารถใช้เชื่อมโยงกับเอกสารราชสำนักชิ้นอื่นๆ ในโครงการวิจัยนี้ได้อย่างสมบูรณ์

### ส่วนที่ 4: สารบัญข้อค้นพบเชิงลึกแยกตาม 10 มิติราชมนเทียรศึกษา (Thematic Findings with Exact Pages)

#### 1. คติและปรัชญาความชอบธรรมแห่งอำนาจ
- **ความผูกพันแนบแน่นระหว่างอัตลักษณ์มลายูกับศาสนาอิสลาม:** ในมโนทัศน์ของสังคมมลายูชายฝั่งสุมาตราเหนือ การเป็นชาวมลายูผูกพันกับความเป็นมุสลิมอย่างไม่อาจแยกขาดจากกันได้ หากบุคคลใดมิได้นับถือศาสนาอิสลาม ผู้นั้นจะไม่ถูกนับว่าเป็นชาวมลายู (*they are considered non-Malays if they are not Muslims*) สถาปัตยกรรมมัสยิดหลวงและพระราชวังจึงเป็นหมุดหมายแห่งความชอบธรรมทางจิตวิญญาณและการเมืองควบคู่กัน (หน้า 452 / PAGE 6)
- **สัญวิทยาแห่งความสง่างามภูมิฐาน:** การยกใต้ถุนอาคารสูงพ้นพื้นดิน (Staged house / Elevated foundation) มีปรัชญาเพื่อ "สร้างความรู้สึกโอ่อ่าสง่างามให้แก่รูปลักษณ์ภายนอกของอาคาร และเชิดชูภาพลักษณ์บารมีของผู้ครอบครองอาคาร" (*to make a great impression on the appearance of the building and the image of its occupants*) (หน้า 452 / PAGE 6)
- **อนุสรณ์แห่งความรุ่งโรจน์ในอดีต:** พระราชวังและมัสยิดหลวงในเมดัน ลังกัต และบาตูบารา ได้รับการนิยามว่าเป็น "ประจักษ์พยานแห่งความรุ่งโรจน์ในอดีตของชาวมลายู" (*a testament to the past Malay glory*) ที่ยืนยันถึงอารยธรรมระดับสูง (หน้า 447 / PAGE 1, หน้า 449 / PAGE 3)

#### 2. แผนผังและการจัดวางเชิงพื้นที่
- **การจัดวางแกนอาคารและทิศทางลม:** ในแบบแผนสถาปัตยกรรมมลายูแนวนอน (Horizontal approach) อาคารถูกจัดวางให้สอดรับกับทิศทางลมธรรมชาติเพื่อการถ่ายเทอากาศ หรือหันหน้าเข้าหาเส้นทางสัญจรหลัก (หน้า 449 / PAGE 3)
- **ผังอาคารแบบสมมาตรทวิภาค (Bilateral Symmetry):** สถาปัตยกรรมอนุสรณ์สถานราชสำนัก ทั้งพระราชวังและมัสยิดหลวง จะใช้ผังแบบสมมาตร (Symmetrical pattern) จากมุมมองด้านหน้า เพื่อขับเน้น "ความรู้สึกเป็นทางการและสง่างามโอ่อ่า" (*the formal impression is more pronounced*) แตกต่างจากเรือนราษฎรที่เป็นผังอสมมาตร (Asymmetrical pattern) (หน้า 453, 454 / PAGE 7, 8)
- **ผังขยายตัวออกทางปีกซ้าย-ขวาของวังไมมูน:** พระราชวังไมมูนจัดวางผังสมมาตรที่มีแนวโน้มแผ่ขยายกว้างออกทางด้านซ้ายและขวา (*symmetrical composition with a tendency to widen to the right and left*) ทำให้เกิดความโอ่โถงอลังการเมื่อมองจากลานด้านหน้า (หน้า 453 / PAGE 7)
- **ผังแปดเหลี่ยมสมมาตรของมัสยิดหลวงอัลมาซุน:** ตัวอาคารมัสยิดหลวงออกแบบเป็นรูปแปดเหลี่ยมสมมาตร (Symmetrical octagonal pattern) โดยมีมุขปีกอาคารยื่นออกไปทั้ง 4 ทิศ (ใต้ ตะวันออก เหนือ ตก) ทำหน้าที่เป็นมุขระเบียงทางเข้า (Porch) ล้อมรอบโถงละหมาดกลาง (หน้า 453 / PAGE 7)
- **การจัดวางบันไดเข้าด้านข้างตามจารีต:** อาคารจารีตมลายู เช่น อาคารสภาวัฒนธรรมมลายู (TCMBS) จะจัดวางบันไดทางขึ้นไว้ "ด้านข้าง ไม่ปะทะตรงด้านหน้า" (*placement of the stairs that is sideways, not frontal*) เพื่อรักษาความเป็นส่วนตัวและมารยาทการเข้าสู่อาคาร (หน้า 454 / PAGE 8)

#### 3. การออกแบบและสถาปัตยกรรม
- **โครงสร้างไตรภาคแนวดิ่ง (Vertical Tripartite Structure):** สถาปัตยกรรมมลายูโบราณจำแนกออกเป็น 3 ส่วนอย่างเป็นระบบ:
  - *ส่วนบน (Top):* หลังคาปั้นหยา (Pyramidal roof) สำหรับเรือนพักอาศัยและวัง, หลังคาทรงโดม (Domed roof) สำหรับมัสยิด (หน้า 452, 455–456 / PAGE 6, 9–10)
  - *ส่วนกลาง (Middle):* ผนัง เสา และช่องโค้งเปิดโล่ง (Pillars and Niches) (หน้า 452, 455–456 / PAGE 6, 9–10)
  - *ส่วนล่าง (Bottom):* ใต้ถุนยกพื้นสูง (Staged / Elevated Floor) (หน้า 452, 455–456 / PAGE 6, 9–10)
- **สถาปัตยกรรมผสมผสาน 3 วัฒนธรรมของพระราชวังไมมูน (Istana Maimun):** วังไมมูนผสานอัตลักษณ์มลายูดั้งเดิมเข้ากับสถาปัตยกรรมยุโรปและเปอร์เซียอย่างกลมกลืน:
  - *อิทธิพลยุโรป:* โครงสร้างผนังก่ออิฐหนาแน่น และการเรียงรายของเสาค้ำยันแบบคลาสสิก
  - *อิทธิพลเปอร์เซีย:* การประดับยอดหลังคาด้วยโดมทรงหัวหอม ซึ่งปกติใช้เฉพาะในมัสยิด
  - *อิทธิพลมลายู:* การยกพื้นสูง ระบบหลังคาปั้นหยาซ้อนชั้น และการระบายอากาศ (หน้า 452–453 / PAGE 6–7)
  - *สถาปนิกผู้ออกแบบ:* ออกแบบโดย Theodoore van Erp สถาปนิกชาวดัตช์ ซึ่งเป็นผู้ออกแบบมัสยิดหลวงอัลมาซุนด้วยเช่นกัน (หน้า 453 / PAGE 7)
- **สถาปัตยกรรมพระราชวังเนียตลีมาลารัซ (Istana Niat Lima Laras):** วังไม้โบราณของแคว้นบาตูบารา มีความโดดเด่นด้วย:
  - หลังคาทรงปั้นหยาซ้อนชั้นหลายระดับ มุ่งสู่อักษะ 4 ทิศทาง
  - มุขพาวิลเลียนด้านหน้า (Pavilion) ที่ยื่นเด่น ขจัดความรู้สึกแบนราบของผนัง
  - ฟาซาด (Facade) ด้านหน้าที่เต็มไปด้วยส่วนโค้ง ส่วนยื่น ช่องโพรง และเสาประดับ (*rich in curves and projections, cavities and columns*) ซึ่งแตกต่างจากวังแบบยุโรปอย่างสิ้นเชิง (หน้า 453 / PAGE 7)
- **สถาปัตยกรรมมัสยิดอาซีซีแห่งลังกัต (Azizi Mosque, Langkat):** หลังคาโดมแปดเหลี่ยมขนาดใหญ่ตรงกลาง แวดล้อมด้วยโดมขนาดกลาง 3 ทิศ (หน้า ซ้าย ขวา) และโดมบริวารขนาดเล็กลดหลั่นระดับชั้น ผนังรอบอาคารเปิดเป็นช่องโค้งและเสาโปร่ง (หน้า 453–454 / PAGE 7–8)

#### 4. หมู่อาคารประกอบในวัง
- **การจำแนกประเภทอาคารตามบทบาทหน้าที่ (Typological Function):** แบ่งเป็น 3 ประเภทหลัก:
  1) *เคหสถานและพระราชมณเฑียร (Residential buildings):* วังไมมูน, วังเนียตลีมาลารัซ, และเรือนพักอาศัยราษฎร
  2) *ศาสนสถาน (Places of worship):* มัสยิดหลวง (Grand Mosque) และสุเหร่า
  3) *ศาลาว่าการและหอประชุมจารีต (Assembly hall / Custom hall / Balai Adat):* ใช้สำหรับชุมนุมและปรึกษาข้อราชการของผู้นำและชุมชน (หน้า 452 / PAGE 6, หน้า 455–456 / PAGE 9–10)
- **คอมเพล็กซ์ราชธานีแห่งรัฐสุลต่านเดลี:** พระราชวังไมมูนและมัสยิดหลวงอัลมาซุน ตั้งอยู่ใกล้เคียงกันบนถนนสายยุทธศาสตร์ (Sisingamangaraja Street และ Jalan Masjid Raya) โดยเป็นกลุ่มอาคารศูนย์กลางอำนาจคู่กันระหว่างฝ่ายอาณาจักรและฝ่ายศาสนจักร (หน้า 453 / PAGE 7)

#### 5. กำแพงวัง ป้อมค่าย และระบบรักษาความปลอดภัย
- **สถาปัตยกรรมแบบเปิดโล่งเปรียบเทียบกับป้อมค่ายยุโรป:** ฟาซาดของพระราชวังมลายู (เช่น วังเนียตลีมาลารัซ) มีลักษณะเฉพาะที่ปฏิเสธแนวกำแพงทึบตันแบบปราสาทยุโรป แต่ใช้การออกแบบที่เต็มไปด้วยช่องเว้า ช่องโค้ง ซุ้มเสา และช่องระบายลมโปร่ง เพื่อสอดรับกับสภาพแวดล้อมและความสัมพันธ์กับราษฎร (หน้า 453 / PAGE 7)
- **การยกพื้นสูงเพื่อความปลอดภัยเชิงกายภาพ:** การยกใต้ถุนสูง (Staged structure) ทำหน้าที่เป็นระบบป้องกันภัยธรรมชาติ น้ำหลากในฤดูมรสุม และสัตว์มีพิษในเขตป่าชายฝั่งทะเล (หน้า 452 / PAGE 6)

#### 6. กองทหารราชสำนักและคลังอาวุธ
- **กริชประจำราชสำนักและการลงทัณฑ์ตามจารีต:** การอ้างอิงงานศึกษาเรื่อง *Keris Bahari & Hukuman Salang* (Muhar Omtatok, 2021) สะท้อนถึงบทบาทของกริชโบราณ (Keris Bahari) ในฐานะอาวุธศักดิ์สิทธิ์ประจำราชสำนัก และธรรมเนียมการประหารชีวิตด้วยกริชยาว (Hukuman Salang) ซึ่งเป็นอำนาจสิทธิ์ขาดของสุลต่านมลายู (หน้า 460 / PAGE 14)

#### 7. ฝ่ายใน บทบาทสตรี และชีวิตชาววัง
- **วิวัฒนาการจากเรือนชุมชนสู่พระราชฐานชั้นสูง:** ผู้เขียนระบุว่าเรือนพักอาศัยของชุมชนดั้งเดิม (Communal residential houses) ที่สืบทอดกันมาหลายชั่วอายุคน คือ "ต้นแบบอ้างอิงสำหรับการพัฒนาไปสู่พระราชวังหลวง" (*reference for the development to be palaces*) โดยรักษาโครงสร้างยกพื้นและหลังคาปั้นหยาไว้ แต่ขยายขนาด เพิ่มความวิจิตรของลวดลาย และจัดสรรพื้นที่ภายในให้สอดคล้องกับพระราชวงศ์และฝ่ายใน (หน้า 454 / PAGE 8)
- **พื้นที่อยู่อาศัยสองชั้นของวังไมมูน:** ชั้นล่างของวังไมมูนถูกสร้างให้เป็นพื้นที่ใช้งานจริงอย่างทึบตัน (*massive ground floor*) รองรับกิจกรรมราชสำนักและการอยู่อาศัย ซึ่งลดทอนความรู้สึกของเรือนยกใต้ถุนสูงแบบเดิมลง แต่เพิ่มพื้นที่ใช้สอยภายใน (หน้า 453 / PAGE 7)

#### 8. ธรรมเนียม กฎระเบียบ และภาษาพิเศษราชสำนัก
- **สถาปัตยกรรมสะท้อนคุณธรรมแห่งการต้อนรับ (Hospitality):** การวางเสาและช่องเปิดจำนวนมาก (Pillars and niches) ในส่วนกลางของอาคาร มิได้มีไว้เพียงเพื่อการระบายอากาศและแสงสว่างเท่านั้น แต่เป็น "ประจักษ์พยานเชิงสังคมวิทยาที่แสดงถึงความเปิดกว้างและอัธยาศัยไมตรีของชาวมลายู" (*sociological proof of the openness and hospitality of the Malay people*) ต่อแขกผู้มาเยือนและข้าแผ่นดิน (หน้า 452 / PAGE 6)
- **จารีตการชุมนุม ณ ศาลาจารีต (Balai Adat):** หอประชุมจารีตเป็นพื้นที่ประกอบพิธีกรรมและปรึกษาข้อราชการตามกฎหมายประเพณี (*Adat*) ของผู้นำมลายู (หน้า 452 / PAGE 6)

#### 9. เครื่องราชกกุธภัณฑ์ เครื่องสูง และดนตรีศักดิ์สิทธิ์
- **รหัสสีแห่งราชสำนักและศาสนา:**  
  - *สีเหลือง (Kuning):* สีประจำราชสำนักและองค์สุลต่าน แสดงถึงเกียรติยศ อำนาจ และความเป็นเจ้าแผ่นดิน
  - *สีเขียว (Hijau):* สีแห่งศาสนาอิสลาม แสดงถึงความเจริญงอกงามและความศักดิ์สิทธิ์  
  ทั้งสองสีเป็นสีหลักเชิงสังคม-วัฒนธรรม (Socio-cultural colors) ที่ใช้ในการตกแต่งวังและงานประณีตศิลป์มลายู (หน้า 457 / PAGE 11)
- **ศิลปะการฉลุไม้โปร่ง (Ornamen Tembus):** ลวดลายฉลุประดับโปร่งแสงที่ปรากฏตามช่องลม คาน และระเบียงวัง สะท้อนภูมิปัญญาเชิงสุนทรียะที่ผสานศิลปะเข้ากับการถ่ายเทอากาศ (หน้า 454 / PAGE 8)

#### 10. พระราชพิธีบรมราชาภิเษกและการสถาปนากษัตริย์
- **ศูนย์รวมพระราชพิธีและสัญลักษณ์อำนาจอธิปไตย:** วังไมมูนและวังเนียตลีมาลารัซทำหน้าที่เป็นเวทีประกอบพระราชพิธีบรมราชาภิเษก การเฉลิมฉลองราชย์ และการรับรองทูตานุทูตต่างประเทศ ยืนยันสถานะความเป็นรัฐเอกราชและเอกภาพของชุมชนมลายู (หน้า 447, 453 / PAGE 1, 7)

#### โควตที่ 2: โครงสร้างสถาปัตยกรรมไตรภาคแนวดิ่งและความหมายเชิงสังคมวิทยา

> "Based on the structure, Malay architecture can be identified as three parts: the top, middle and bottom... On bottom part, Malay buildings are generally in the form of open stage houses or at least higher than the ground. The goal, apart from functionality, is to make a great impression on the appearance of the building and the image of its occupants." (หน้า 452 / PAGE 6)

#### โควตที่ 4: พระราชวังเนียตลีมาลารัซและคุณค่าเชิงอนุรักษ์
> **ข้อความต้นฉบับ:**  
> "Next is the Niat Lima Laras Palace architecture which is a testament to the greatness of the Malay coastal kingdom. This building is now showing its age and looks poorly maintained. It is, therefore, necessary to make conservation efforts to preserve it as it is a valuable cultural asset. The contribution of this research is limited to the preservation of its form through the production of miniatures as tourist souvenirs. The architecture of Niat Lima Laras Palace has a unique shape. A dynamic impression can be seen from the composition of panels and shapes on the walls and roof, emphasizing the existence of the pavilion which does not give a flat impression... As a reference for the development of miniature souvenirs, the main potential lies in the pyramidal roof pattern, which consists of several levels and aims at the four cardinal points. The next potential lies in the facade, which, unlike other forms of palaces, for example in Europe, is rich in curves and projections, cavities and columns." (หน้า 453 / PAGE 7)
> 
> **คำแปลภาษาไทย:**

#### โควตที่ 6: สีเชิงสังคมวัฒนธรรมมลายู (เหลือง-เขียว) และวิทยาการวัสดุ
> **ข้อความต้นฉบับ:**  
> "The coloring process takes place parallel to the batter production. Based on socio-cultural colors, the Malay colors are yellow and green. When the miniature is finished, there is no post-processing process... Technically, using cardboard is more practical, but aesthetically, wood has more potential... Miniature aesthetics as souvenir products stand in the context of preserving Malay identity in the creative industries." (หน้า 457, 460 / PAGE 11, 14)
> 
> **คำแปลภาษาไทย:**

### ส่วนที่ 6: คลังคำศัพท์เฉพาะทางจากเอกสาร (Native Terminology Glossary)

| คำศัพท์เฉพาะทาง (Native / Technical Terms) | ภาษาเดิม / รากศัพท์ | ความหมายเชิงวิชาการ | บริบทการใช้งานในราชมนเทียรศึกษา | เลขหน้าที่ปรากฏ |
| :--- | :--- | :--- | :--- | :--- |
| **Istana Maimun** | มลายู / อาหรับ (*Maymun* = เป็นมงคล) | พระราชวังไมมูน แห่งรัฐสุลต่านเดลี ในนครเมดัน สร้างขึ้นปลายคริสต์ศตวรรษที่ 19 | ตัวอย่างพระราชวังหลวงที่ผสมผสานสถาปัตยกรรมมลายู ยุโรป และเปอร์เซีย ผังสมมาตรแนวนอน | หน้า 448, 449, 452–453, 455 |
| **Istana Niat Lima Laras** | มลายู (*Niat* = เจตจำนง/บนบาน, *Lima Laras* = ห้าแขวง) | พระราชวังเนียตลีมาลารัซ วังไม้โบราณของแคว้นบาตูบารา สร้างตามคำบนบานของราชา | สถาปัตยกรรมราชสำนักไม้ริมทะเล หลังคาปั้นหยาซ้อนชั้น มุขพาวิลเลียน โบราณสถานที่เสี่ยงสูญสลาย | หน้า 449, 453, 455 |
| **Masjid Raya Al-Mashun** | มลายู / อาหรับ (*Al-Ma'shun* = ผู้ได้รับการพิทักษ์) | มัสยิดหลวงแห่งรัฐสุลต่านเดลี (Grand Mosque of Medan) | ศาสนสถานศูนย์กลางราชธานี ผังแปดเหลี่ยมสมมาตรพร้อมมุขปีก 4 ทิศ และโดมบริวารล้อมรอบ | หน้า 448, 449, 453, 456 |
| **Masjid Azizi** | มลายู / อาหรับ (*Aziz* = ทรงเกียรติ/ยิ่งใหญ่) | มัสยิดอาซีซี มัสยิดหลวงแห่งรัฐสุลต่านลังกัต ณ เมืองตันจุงปูรา | สถาปัตยกรรมโดมแปดเหลี่ยมประธานแวดล้อมด้วยโดม 3 ทิศทางและเสาซุ้มโค้งโปร่ง | หน้า 449, 453–454, 456 |
| **Atap Limas (Pyramidal Roof)** | มลายู / สถาปัตยกรรม | หลังคาทรงปั้นหยาลาดเอียง 4 ด้าน โครงสร้างรับลมมรสุม | หลังคามาตรฐานของเรือนเคหสถานและพระราชวังมลายู มักสร้างซ้อนชั้นลดหลั่นระดับ | หน้า 452, 454, 455–456, 460 |
| **Atap Kubah (Domed Roof)** | มลายู / อาหรับ (*Qubbah*) | หลังคาทรงโดม (ทรงหัวหอมหรือแปดเหลี่ยม) | สัญลักษณ์หลังคาศาสนสถาน และถูกนำมาผสมผสานในพระราชวังไมมูน | หน้า 452, 453, 455–456, 460 |
| **Rumah Panggung (Stage House)** | มลายู | เรือนยกใต้ถุนสูงพ้นระดับพื้นดินด้วยเสาไม้ | วิศวกรรมพื้นถิ่นมลายูเพื่อระบายอากาศ หนีน้ำท่วม และสร้างความสง่างามภูมิฐานแก่ผู้ครองเรือน | หน้า 452, 454, 455–456, 460 |
| **Balai Adat (Assembly / Custom Hall)** | มลายู | ศาลาว่าการจารีตประเพณี หรือหอประชุมประชาคม | อาคารสำหรับประกอบพิธีกรรมทางจารีตและการชุมนุมข้อราชการของผู้นำและประชาชน | หน้า 452, 454, 456, 460 |
| **Relung & Tiang (Niches & Pillars)** | มลายู / สถาปัตยกรรม | ซุ้มช่องโค้งเว้าและแถวเสาค้ำยันโปร่งโล่ง | การออกแบบส่วนกลางอาคารเพื่อการถ่ายเทอากาศ และสัญญะสะท้อนความเปิดกว้าง-ต้อนรับขับสู้ | หน้า 452, 453, 455–456, 460 |
| **Ornamen Tembus (Transparent Ornament)** | มลายู | ลวดลายแกะสลักหรือฉลุไม้แบบโปร่งทะลุ | มัณฑนศิลป์มลายูที่ทำหน้าที่เป็นช่องระบายอากาศและช่องรับแสงธรรมชาติ | หน้า 454 |
| **Kuning Diraja & Hijau Islam** | มลายู | สีเหลืองแห่งราชสำนัก และสีเขียวแห่งศาสนาอิสลาม | คู่สีเชิงสังคมวัฒนธรรมที่แสดงอัตลักษณ์กษัตริย์และศาสนาในงานประณีตศิลป์ราชสำนัก | หน้า 457 |
| **Seni Pariwisata (Tourism Art)** | อินโดนีเซีย (แนวคิด R.M. Soedarsono) | ศิลปะการท่องเที่ยว: จำลอง, กะทัดรัด, หลากหลาย, ลดทอนความศักดิ์สิทธิ์, ราคาประหยัด | ทฤษฎีที่ใช้ในการแปลงรหัสสถาปัตยกรรมพระราชวังโบราณสู่งานจำลองขนาดจิ๋วร่วมสมัย | หน้า 450, 458 |
| **Tepung Liat (Clay Flour / Dough)** | มลายู / หัตถศิลป์ | แป้งประดิษฐ์จากแป้งสาลี แป้งมัน กาว PVAC และสีน้ำ | วัสดุทางเลือกในการปั้นโมเดลจำลองสถาปัตยกรรมที่มีความยืดหยุ่นและให้เนื้อสัมผัสทึบ | หน้า 451, 457 |
| **Keris Bahari & Hukuman Salang** | มลายู | กริชทะเลโบราณ และการประหารชีวิตด้วยกริชตามจารีตหลวง | สัญลักษณ์พระราชอำนาจเด็ดขาดของสุลต่านมลายูและการพิทักษ์ความยุติธรรมตามจารีต | หน้า 460 |
| **Konservasi Bentuk (Form Conservation)** | มลายู / วิทยาการอนุรักษ์ | การอนุรักษ์สัญนิยมและมิติทางสัณฐานวิทยาของอาคาร | การบันทึกและจำลองสัดส่วนอาคารวังที่กำลังผุพังเพื่อรักษารูปลักษณ์ไว้ในมรดกความทรงจำ | หน้า 451, 453 |
| **Tangga Samping (Sideways Stairs)** | มลายู / สถาปัตยกรรม | บันไดทางขึ้นอาคารที่วางทแยงด้านข้าง ไม่หันตรงเข้าหาประตู | ขนบสถาปัตยกรรมมลายูเพื่อรักษาความสุภาพ ไม่ให้ผู้ขึ้นบันไดจ้องประทะสายตาคนข้างใน | หน้า 454 |
