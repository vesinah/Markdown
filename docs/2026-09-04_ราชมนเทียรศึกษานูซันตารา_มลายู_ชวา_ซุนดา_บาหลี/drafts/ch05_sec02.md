# บทที่ 5: ระบบราชมนเทียรและวังเจ้าบาหลี (Puri Bali): มณฑลจักรวาล อำนาจอธิปไตยคู่ และสถาปัตยกรรมจารีต (ภาค 2)

## 5.5 แท่นประทับปัทมาสน์ (Padmasana) บงกชจักรวาล และสถาปัตยกรรมเขาพระสุเมรุ (Meru)

### 5.5.1 ประวัติและวิวัฒนาการทางปรัชญาของแท่นปัทมาสน์ในบาหลี: จากแท่นหินบูชาบรรพบุรุษยุคเมกาลิธิก สู่การปฏิรูปศาสนาของดังฮยัง นิราร์ถะ ในศตวรรษที่ 16

วิวัฒนาการทางสถาปัตยกรรมศักดิ์สิทธิ์ในพระราชวังหลวง (Puri) และเทวสถานบาหลีมิได้เกิดขึ้นอย่างตัดขาดจากอดีต หากแต่เป็นผลลัพธ์ของการผสมผสานอย่างลงตัวระหว่างรากฐานความเชื่อดั้งเดิมแบบวิญญาณนิยมในยุคหินใหญ่ (Austronesian Megalithic Substratum) เข้ากับปรัชญาเทววิทยาฮินดู-ชวาชั้นสูงที่ถ่ายทอดมาจากเกาะชวาหลายระลอก [1] ในยุคก่อนประวัติศาสตร์และยุคบาหลีโบราณ (Bali Kina หรือ Bali Aga) ชุมชนพื้นเมืองบนเกาะบาหลีได้สถาปนาระบบการเคารพบูชาดวงวิญญาณบรรพบุรุษผู้ล่วงลับและพลังอำนาจศักดิ์สิทธิ์แห่งธรรมชาติ ผ่านการสร้างแท่นหินบูชาแบบเมกาลิธิก ซึ่งเรียกขานในจารึกใบลานโบราณว่า "เปอลีมปิต" (Pelimpit) หรือแท่นสถิต "ปาลึงกิฮ์" (Palinggih) [2] แท่นบูชาดั้งเดิมเหล่านี้ประกอบด้วยโครงสร้างสำคัญ 3 รูปแบบ ได้แก่ หินตั้งตระหง่านเดี่ยว (Menhir หรือ Sila Angadeg) เพื่อเป็นสื่อกลางเชื่อมต่อวิญญาณสวรรค์เบื้องบน, แผ่นหินโต๊ะวางขนานกับพื้นดิน (Dolmen หรือ Lempeng Magong) เพื่อเป็นแท่นวางเครื่องพลีกรรมแด่พระแม่ธรณี, และกองหินซ้อนลดหลั่นเป็นขั้นบันได (Gagumuk Maundak หรือ Punden Berundak) อันเป็นภาพตัวแทนของภูเขาศักดิ์สิทธิ์ที่เป็นทางสัญจรของดวงวิญญาณบรรพบุรุษ [3]

จุดเปลี่ยนผ่านทางประวัติศาสตร์ระลอกแรกเกิดขึ้นในคริสต์ศตวรรษที่ 11 ในรัชสมัยของพระเจ้าอุทยานะ วาร์มาเทวา (Udayana Warmadewa) เมื่อมหาโยคี มปู กุตูรัน (Mahayogi Mpu Kuturan) มหาปุโรหิตหลวงแห่งราชสำนักมะตะรัมโบราณ (Medang i Poh Pitu) บนเกาะชวา ได้เดินทางข้ามช่องแคบมายังเกาะบาหลี [4] มปู กุตูรันได้ดำเนินการปฏิรูปโครงสร้างทางศาสนาและสถาปัตยกรรมครั้งสำคัญเพื่อยุติข้อขัดแย้งระหว่างนิกายย่อยต่างๆ โดยได้สถาปนามโนทัศน์ "ปัทมภูวนะ" (Padma Bhuwana) ซึ่งบันทึกไว้ในคัมภีร์ใบลาน *ปัทมภูวนะ* (Lontar Padma Bhuwana) คัมภีร์นี้เปรียบผืนแผ่นดินเกาะบาหลีทั้งมวลประหนึ่งดอกบัวแดงขนาดยักษ์ที่ลอยเด่นอยู่เหนือน้ำ กลีบดอกเบ่งบานหงายขึ้นสู่เบื้องบนและแผ่กระจายออกสู่อัษฏทิศอย่างสมบูรณ์แบบ [5] ในการปฏิรูปครั้งนั้น มปู กุตูรันได้สถาปนาระบบเทวสถานประจำทิศทั้งแปด (Pura Kahyangan Jagat Padma Astadala) โดยมีภูเขาไฟอากุง (Gunung Agung) และมหาเทวสถานปูราเปอนาตารันอากุง เบซากิฮ์ (Pura Penataran Agung Besakih) เป็นดั่ง "เกสรใจกลางดอกบัว" (Sari Bunga) สถิตแห่งพระศิวะมหาเทพ และได้นำเอารูปแบบสถาปัตยกรรมหอคอยหลังคาซ้อนทรงสูงแบบชวาโบราณ คือ "หอเมรุ" (Meru) เข้ามาประดิษฐานครอบทับลงบนแท่นหินบูชาบรรพบุรุษดั้งเดิม [6]

อย่างไรก็ดี การก้าวสู่จุดสูงสุดของสถาปัตยกรรมแท่นประทับเกิดขึ้นในคริสต์ศตวรรษที่ 16 ท่ามกลางวิกฤตการณ์ทางการเมืองและศาสนาอันเนื่องมาจากการล่มสลายของมหาจักรวรรดิมัชปาหิตบนเกาะชวา ในรัชสมัยของสมเด็จพระดะเล็ม วาตูเร็งก็อง (Dalem Waturenggong) แห่งราชสำนักเกลเกล มหาเถรพราหมณ์ผู้เปี่ยมด้วยอภิญญาญาณ นามว่า ดังฮยัง นิราร์ถะ (Danghyang Nirartha) หรือพระราชครูเปอดันดา สักตี วาวู ราฮาวู (Pedanda Sakti Wawu Rawuh / Dwijendra) ได้เดินทางข้ามช่องแคบบาหลีเข้ามาพึ่งพระบรมโพธิสมภารในปี ค.ศ. 1537 [7] เมื่อดังฮยัง นิราร์ถะ สำรวจสภาพสังคมและศาสนาบาหลีในเวลานั้น ท่านได้มองเห็นวิกฤตการณ์สำคัญที่เปรียบดั่ง "ดอกบัวไร้เกสร" (*Bunga padma yang mekar indah merekah akan tetapi tanpa memiliki sari di tengahnya*) [8] นั่นคือ ประชาชนและราชสำนักยังคงมัวเมาอยู่กับการบูชาเทพเจ้าชั้นรอง ดวงวิญญาณบรรพชน และภูตผีปีศาจอย่างกระจัดกระจาย ขาดแกนกลางแห่งเอกเทวนิยมที่จะยึดเหนี่ยวระเบียบสังคมและอำนาจรัฐให้เป็นหนึ่งเดียว [9]

เพื่อแก้ไขวิกฤตการณ์ทางภววิทยาและเทววิทยาดังกล่าว ดังฮยัง นิราร์ถะ จึงได้ปฏิวัติระบบความเชื่อฮินดู-บาหลีสู่เอกเทวนิยมขั้นสูงสุด โดยประดิษฐ์สร้างสถาปัตยกรรมแท่นบูชารูปแบบใหม่ขึ้นเป็นครั้งแรกในประวัติศาสตร์ นั่นคือ **"แท่นปัทมาสน์" (Padmasana)** [10] แท่นปัทมาสน์ทำหน้าที่เป็นพระแท่นบัลลังก์ทิพย์ที่เปิดโล่งสู่เวิ้งฟ้า เพื่อเป็นที่ประทับแห่ง "อีดา ซังฮยัง วีธิ วะสะ" (Ida Sang Hyang Widhi Wasa) หรือพระปรมาตมันสูงสุด ซึ่งปรากฏพระองค์ในฐานะ "พระอจินไตย" (Acintya) หรือ "ซังฮยัง ปรมวิเศษ" (Sang Hyang Parama Wisesa) ผู้ทรงไร้รูป ไร้ขอบเขต ปราศจากเพศภาวะ และอยู่เหนือมโนทัศน์ปรุงแต่งของมนุษย์ [11] การประดิษฐ์แท่นปัทมาสน์มิเพียงแต่ยกระดับศาสนาบาหลีสู่ความเป็นเอกภาพทางจักรวาลวิทยาเท่านั้น หากยังกลายเป็นหมุดหมายสำคัญที่สถาปนาให้พระราชวังปูรีและเทวสถานหลวงกลายเป็นศูนย์กลางแห่งพระบารมีอำนาจศักดิ์สิทธิ์ที่เชื่อมโยงองค์พระมหากษัตริย์เข้ากับพระผู้เป็นเจ้าสูงสุดโดยตรง [12]

### 5.5.2 โครงสร้างตรีจักรวาลวิทยาของแท่นปัทมาสน์: ภุรโลก (Bhur Loka) ภุวะโลก (Bwah Loka) และสวะโลก (Swah Loka)

โครงสร้างทางสถาปัตยกรรมและประติมาวิทยาของแท่นปัทมาสน์มิได้ถูกออกแบบขึ้นตามรสนิยมความงามเชิงปัจเจก หากแต่เป็นการจำลองโครงสร้างแห่งมหาจักรวาลและสัจธรรมทางภววิทยาตามระบบ "ตรีโลก" (Tri Loka) และ "ตรีอังคะ" (Tri Angga) ซึ่งเชื่อมโยงสรีรวิทยาธรรมชาติของพืชบัวเข้ากับระเบียบแห่งเอกภพอย่างลึกซึ้ง [13] นักวิชาการด้านสถาปัตยกรรมบาหลี อี โญมัน วิดยา ปารมัธยักษา (I Nyoman Widya Paramadhyaksa) ได้ชี้ให้เห็นว่า ในภาษาสันสกฤต พืชตระกูลบัวทุกชนิดได้รับการขนานนามว่า "สโรชะ" (*Sarasija*) ซึ่งมีความหมายตรงตัวว่า "ผู้ถือกำเนิดขึ้นจากโคลนตม" [14] บัวแดงหรือปัทมะ (*Nymphaea rubra*) เติบโตขึ้นโดยการหยั่งรากลึกอยู่ในชั้นโคลนเลนใต้น้ำ ลำต้นแทงยอดผ่านชั้นน้ำอันขุ่นมัว และชูดอกคลี่บานอย่างบริสุทธิ์ผุดผ่องอยู่เหนือบ่าผิวน้ำ สรีรวิทยาการเติบโตผ่าน 3 สสาร (โคลน-น้ำ-อากาศ) จึงกลายเป็นอุปมานิทรรศน์ที่สมบูรณ์แบบที่สุดของการจำแนกมณฑลจักรวาลออกเป็น 3 ระดับชั้น [15]:

```
+---------------------------------------------------------------------------------------------------+
|                           แผนผังโครงสร้างตรีจักรวาลวิทยาของแท่นปัทมาสน์ (Padmasana)                 |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|  [ สวะโลก / SWAH LOKA ] ------------------------------------------------------------------------+  |
|  (Utama Angga / แดนสวรรค์สูงสุด)  | บัลลังก์ว่างเปล่า (Empty Throne / Kursi Singgasana)          |  |
|                                   | พนักพิงหลังสลักลายพระอจินไตย (Acintya / Siwa Raditya)       |  |
|                                   | กลีบบัวบานอัษฏดลหงายรองรับพระแท่น (Padma Mekar)              |  |
|                                   +-------------------------------------------------------------+  |
|                                                                                                   |
|  [ ภุวะโลก / BWAH LOKA ] -----------------------------------------------------------------------+  |
|  (Madya Angga / มณฑลอวกาศและมนุษย์)| เสาแท่นศิลาชะลูดสอบขึ้น (Badan Candi)                         |  |
|                                   | หน้ากาลโภมะ (Kala Bhoma) ขับไล่เสนียดจัญไร                   |  |
|                                   | นกครุฑ (Garuda) ผู้พิชิตอสูรและผู้นำน้ำอมฤต                 |  |
|                                   | เทพประจำทิศทั้งแปด (Asta Dikpala / Lokapala)                |  |
|                                   +-------------------------------------------------------------+  |
|                                                                                                   |
|  [ ภุรโลก / BHUR LOKA ] ------------------------------------------------------------------------+  |
|  (Nista Angga / พิภพใต้บาดาล)     | ฐานแท่นศิลาบาตูร์ (Batur Padmasana)                          |  |
|                                   | พญาเต่าเบอดาวังนาลา (Bedawang Nala - อัคนีใต้พิภพ)          |  |
|                                   | พญานาคราชคู่: อนันตโภคะ (ดิน/พืชผล) & วาสุกี (น้ำ/อมฤต)     |  |
|                                   +-------------------------------------------------------------+  |
|                                                                                                   |
+---------------------------------------------------------------------------------------------------+
```

#### 1. ส่วนฐาน (Nista Angga / Batur): ภุรโลก (Bhur Loka) และประติมาวิทยาค้ำจุนจักรวาล
ส่วนฐานรากของแท่นปัทมาสน์ก่อสร้างด้วยหินภูเขาไฟสีดำ (Batu Candi) หรือศิลาแลงโบราณ ทำหน้าที่เป็นภาพตัวแทนของพิภพใต้บาดาลและโลกมนุษย์ที่เต็มไปด้วยกิเลสและตัณหา ที่ฐานชั้นล่างสุดจำหลักหินเป็นรูป **"พญาเต่าเบอดาวังนาลา" (Bedawang Nala)** ในลักษณะนอนคว่ำแบกรับน้ำหนักของมหาแท่นทั้งหลังไว้บนกระดอง [16] เบอดาวังนาลาเป็นสัญลักษณ์แทนพลังงานความร้อน แมกมา และไฟใต้พิภพ (Subterranean Magmatic Fire) ซึ่งค้ำจุนโครงสร้างของเปลือกโลกมิให้ยุบตัวลง [17]

รอบกระดองของพญาเต่าเบอดาวังนาลา จำหลักเป็นรูปพญานาคราชคู่ขนาดมหึมาขดรัดรึงประสานหางและชูเศียรขึ้น ได้แก่ **"พญานาคราชอนันตโภคะ" (Sang Hyang Naga Anantabhoga)** และ **"พญานาคราชวาสุกี" (Sang Hyang Naga Basuki)** [18] ในคัมภีร์ *วาสุกีตัตตวะ* (Basuki Tattwa) และปรัชญาชวา-บาหลี อนันตโภคะเป็นตัวแทนของธาตุดิน (Prthiwi) ความมั่นคง และความอุดมสมบูรณ์ของพืชพรรณธัญญาหาร ขณะที่วาสุกีเป็นตัวแทนของธาตุน้ำ (Apah) ความชุ่มชื้น และน้ำอมฤตที่หล่อเลี้ยงสิ่งมีชีวิต [19] การรัดรึงกันระหว่างพญาเต่าและพญานาคราชคู่ ณ ฐานปัทมาสน์ จึงเป็นภาพสะท้อนของการกักเก็บและควบคุมพลังงานธรรมชาติอันเกรี้ยวกราดใต้พิภพ ให้กลายเป็นฐานรากอันสงบนิ่งและมั่นคงรองรับการสถาปนาระเบียบจักรวาล [20]

#### 2. ส่วนลำตัว (Madya Angga / Badan Candi): ภุวะโลก (Bwah Loka) และมณฑลการชำระล้าง
ส่วนลำตัวของแท่นปัทมาสน์ก่อสร้างเป็นเสาทรงสอบชะลูดขึ้นสู่เบื้องบน เปรียบดั่งก้านดอกบัวที่ชูยอดพ้นจากผืนน้ำเข้าสู่บรรยากาศ ทำหน้าที่เป็นตัวแทนของ "ภุวะโลก" (Bwah Loka หรือ Bvar Loka) อันเป็นมณฑลแห่งอวกาศ อากาศธาตุ และแดนเปลี่ยนผ่านทางจิตวิญญาณ [21]

บนพื้นผิวของเสาส่วนลำตัวนี้ ช่างแกะสลักบาหลีโบราณจะจำหลักลวดลายประติมากรรมนูนสูงที่มีนัยทางเทววิทยาอย่างเข้มข้น ด้านหน้าของลำตัวแท่นประดับด้วยใบหน้าอสูรขนาดใหญ่ เรียกว่า **"หน้ากาล" หรือ "โภมะ" (Bhoma / Kala Bhoma)** ผู้มีดวงตาเบิกโพลง เขี้ยวงอกโง้ง และแผ่พังพานพรรณพฤกษาสยายออกสองข้าง [22] โภมะทำหน้าที่เป็นทวารบาลผู้พิทักษ์มณฑลศักดิ์สิทธิ์ คอยกลืนกินความชั่วร้าย เสนียดจัญไร และสกัดกั้นมิให้พลังงานมลทิน (Kala) ล่วงล้ำขึ้นสู่เบื้องบน [23]

เหนือรูปโภมะขึ้นไป มักจำหลักเป็นรูป **"พญานกครุฑ" (Garuda)** สยายปีกกว้างอย่างเกรียงไกร ครุฑเป็นสัญลักษณ์แห่งแสงสุริยะ ความบริสุทธิ์ ผู้พิชิตนาคและอสูร และผู้นำเอาน้ำอมฤตแห่งความเป็นอมตะลงมาสู่โลก [24] นอกจากนี้ ที่มุมทั้งสี่และรอบลำตัวของแท่นยังประดับด้วยรูปเคารพของเทพเจ้าผู้พิทักษ์ทิศทั้งแปด (Asta Dikpala หรือ Lokapala) ประทับนั่งขนาบเพื่อคุ้มครองระเบียบจักรวาล [25]

#### 3. ส่วนยอด (Utama Angga): สวะโลก (Swah Loka) และบัลลังก์พระแท่นบงกชว่างเปล่า
ส่วนยอดบนสุดของแท่นปัทมาสน์คือภาพจำลองของ "สวะโลก" (Swah Loka หรือ Svar Loka) แดนสวรรค์สูงสุดอันเป็นทิพยสถานของทวยเทพและพระผู้เป็นเจ้า โครงสร้างส่วนนี้จำหลักเป็นรูปดอกบัวแดงบาน (Padma Mekar) ซ้อนกันสองชั้นอย่างวิจิตรตระการตา ได้แก่ ชั้นกลีบบัวคว่ำ (Padma Asana Lapik Arca) ประกบเข้ากับชั้นกลีบบัวหงายที่คลี่บานออกสู่อัษฏทิศ [26]

เหนือดอกบัวบานขึ้นไป สถาปัตยกรรมจะก่อรูปเป็น **"เก้าอี้พระแท่นบัลลังก์ว่างเปล่า" (Empty Throne / Kursi Singgasana)** [27] การเว้นบัลลังก์ให้ว่างเปล่าโดยปราศจากเทวรูปเคารพแบบรูปสลักมนุษย์ ถือเป็นเอกลักษณ์ทางเทววิทยาที่ลึกซึ้งที่สุดของบาหลี บัลลังก์ว่างเปล่านี้เปิดโล่งสู่ท้องฟ้าเพื่อรองรับแสงสุริยาและความไร้รูปแห่ง "พระอจินไตย" (Acintya) ผู้ทรงสถิตอยู่ทุกหนทุกแห่งแต่ไม่อาจจับต้องได้ [28]

บนพนักพิงหลังของบัลลังก์ (Sandaran Kursi Singgasana) ช่างอุนดากีจะจำหลักแผ่นทองคำหรือศิลาเป็นภาพนูนต่ำรูปองค์พระอจินไตย ในท่วงท่ายืนเหยียบอยู่บนดอกบัวบาน พระหัตถ์ทั้งสองผายออก พระวรกายเปล่งรัศมีเปลวเพลิงแผ่ซ่านรอบทิศทาง [29] ยอดบัลลังก์นี้คือจุดที่มหาปุโรหิตเปอดันดาและพระมหากษัตริย์จะน้อมอัญเชิญ "ศิวะอาทิตย์" (Siwa Raditya) มหาเทพผู้รวมแสงสุริยะเข้ากับพระศิวะ ให้เสด็จลงมาสถิตในยามประกอบพิธีกรรมหลวง [30]

นอกจากนี้ ปารมัธยักษาได้ชี้ให้เห็นสัญศาสตร์คู่ตรงข้ามเชิงดุลยภาพที่แฝงอยู่ในแท่นปัทมาสน์ นั่นคือการจับคู่ระหว่าง **"วัชระ-ปัทมะ" (Bajra-Padma)** ดุจเดียวกับปรัชญา **"ลึงค์-โยนี" (Lingga-Yoni)** [31] วัชระคือสายฟ้า ความแข็งแกร่ง แนวตั้ง ธาตุบุรุษ เบื้องบน และอำนาจเด็ดขาดแห่งกษัตริย์ ขณะที่ปัทมะคือดอกบัว ความอ่อนนุ่ม แนวนอน ธาตุสตรี เบื้องล่าง และแผ่นดินแม่ การที่แท่นปัทมาสน์ประดิษฐานอย่างมั่นคง ย่อมสะท้อนถึงการประสานรวมกันอย่างกลมกลืนระหว่างอำนาจศักดิ์สิทธิ์ของราชา (วัชระ) เข้ากับความอุดมสมบูรณ์อันบริสุทธิ์ของผืนแผ่นดินและประชาราษฎร์ (ปัทมะ) [32]

### 5.5.3 การจำแนกประเภทปัทมาสน์ตามคัมภีร์ใบลานและลำดับชั้นศักดิ์สิทธิ์: ปัทมะสารี ปัทมาสน์ ปัทมาสะนะโรบ ปัทมารัตนะ และปัทมาสน์อัคร

ในคัมภีร์สถาปัตยกรรมจารีตโบราณของบาหลี โดยเฉพาะคัมภีร์ *อัสตโกสะลา โกสะลี* (Asta Kosala Kosali) และคัมภีร์ *เทวะตัตตวะ* (Dewa Tattwa) การก่อสร้างแท่นประทับตระกูลปัทมะมิได้มีรูปแบบเดียว หากแต่ถูกจำแนกออกเป็น 5 ลำดับชั้นตามโครงสร้างทางกายภาพและระดับความศักดิ์สิทธิ์ของสถานที่ประดิษฐาน [33]:

| ลำดับชั้น | ประเภทแท่นประทับ | องค์ประกอบฐานราก (Batur) | จำนวนบัลลังก์ยอด (Singgasana) | เทพเจ้าประธานที่อัญเชิญสถิต | บริบทพื้นที่การประดิษฐาน |
|:---|:---|:---|:---:|:---|:---|
| **ชั้นที่ 1** | **ปัทมะสารี (Padmasari)** | ฐานศิลาเรียบ ไม่มีเต่าเบอดาวังนาลาและพญานาค | 1 บัลลังก์เดี่ยว | ศิวะอาทิตย์ (Siwa Raditya) / พระอจินไตย | ศาลประจำเรือนราษฎร (Sanggah Kemulan), วัดประจำครอบครัว |
| **ชั้นที่ 2** | **ปัทมาสน์ (Padmasana)** | มีเต่าเบอดาวังนาลาและพญานาคคู่รัดรึงสมบูรณ์ | 1 บัลลังก์เดี่ยว | พระอจินไตย / ซังฮยัง วีธิ วะสะ | เทวสถานประจำหมู่บ้าน (Pura Kahyangan Tiga), วังปูรีอาลิต |
| **ชั้นที่ 3** | **ปัทมาสะนะโรบ (Padmasana Rrob)** | มีเต่าเบอดาวังนาลาและพญานาคคู่รัดรึงสมบูรณ์ | 2 บัลลังก์คู่เคียงกัน | ทวิเทวะ: พระศิวะ-พระศักติ, พระสุริยะ-พระจันทร์ | เทวสถานระดับตำบล, ศาลบูชาบรรพบุรุษเจ้านายสายตรง |
| **ชั้นที่ 4** | **ปัทมารัตนะ (Padmaratna / Padma Capah)** | มีเต่าเบอดาวังนาลา พญานาคคู่ และครุฑสยายปีก | 3 บัลลังก์เรียงแถว | พระตรีมูรติ: พระพรหม-พระวิษณุ-พระศิวะ | เทวสถานประจำอำเภอ, เปอเมราจันอากุงของพระราชวังปูรี |
| **ชั้นที่ 5** | **ปัทมาสน์อัคร (Padma Agung / Catur Muka)** | มหาฐานศิลาแปดเหลี่ยม เต่านาคครุฑจตุรทิศ | 4 บัลลังก์หันสี่ทิศ หรือ 1 มหาบัลลังก์กลาง | พระปรมศิวะ สทาศิวะ ศิวะ (มหาตรีศักติ) | มหาเทวสถานจักรวาล (Pura Kahyangan Jagat / Besakih) |

[34]

การจัดลำดับศักดิ์สิทธิ์ทั้งห้านี้สะท้อนกฎเกณฑ์ทางชนชั้นและสิทธิทางพิธีกรรมอย่างเข้มงวด กล่าวคือ ราษฎรสามัญทั่วไปในหมู่บ้านได้รับอนุญาตให้สร้างได้เพียง "ปัทมะสารี" ภายในศาลประจำบ้าน (Sanggah) เท่านั้น ห้ามมิให้สร้างแท่นที่มีประติมากรรมพญาเต่าเบอดาวังนาลาและพญานาคคู่ที่ฐานรากเด็ดขาด เนื่องจากคติบาหลีถือว่า พญาเต่าและพญานาคคือสัญลักษณ์แห่งการค้ำจุนจักรวาลและแว่นแคว้น ผู้มีสิทธิ์สร้างแท่นปัทมาสน์ที่มีพญาเต่ารองรับฐานได้ ต้องเป็นระดับชุมชนจารีต (Desa Adat) ขึ้นไป หรือเป็นพระราชสิทธิพิเศษเฉพาะองค์พระมหากษัตริย์ (Raja) ในพระราชวังปูรีเท่านั้น [35]

สำหรับ "ปัทมารัตนะ" (Padmaratna) ซึ่งมีบัลลังก์ 3 ที่ประทับเรียงกัน และ "ปัทมาสน์อัคร" (Padma Agung) ซึ่งเป็นมหาแท่นบัลลังก์ยอด จะได้รับการสงวนไว้เฉพาะสำหรับมหาเทวสถานประจำเกาะ เช่น ปูราเปอนาตารันอากุง เบซากิฮ์ หรือประดิษฐานเป็นประธานสูงสุดใน "เปอเมราจัน อากุง" (Pemerajan Agung) ของพระราชวังหลวงของเจ้าผู้ครองแคว้น เพื่อเป็นศูนย์รวมแห่งบารมีอำนาจเทวราชาเหนือราชอาณาจักรทั้งมวล [36]

### 5.5.4 หอเมรุ (Pelinggih Meru): สถาปัตยกรรมเขาพระสุเมรุและกฎเกณฑ์ชั้นหลังคาซ้อน

ควบคู่ไปกับแท่นปัทมาสน์ สถาปัตยกรรมศักดิ์สิทธิ์ที่โดดเด่นและเป็นเอกลักษณ์สูงสุดอีกประการหนึ่งของราชสำนักและเทวสถานบาหลีคือ **"หอเมรุ" (Pelinggih Meru)** [37] หอเมรุคือสิ่งปลูกสร้างทรงหอคอยหลังคาซ้อนชั้นชะลูดสูงขึ้นสู่ท้องฟ้า ซึ่งสร้างขึ้นเพื่อจำลองภาพของ "เขาพระสุเมรุ" (Mahameru) แกนกลางแห่งจักรวาลวิทยาฮินดู-ชวา ที่ซึ่งทวยเทพและดวงวิญญาณของบูรพกษัตริย์ผู้ชำระบริสุทธิ์แล้วเสด็จลงมาประทับสถิต [38]

หลังคาของหอเมรุมีลักษณะพิเศษคือ มุงด้วยเส้นใยสีดำสนิทที่ได้จากต้นตาลดำหรือชิด เรียกว่า **"อีจุก" (Ijuk / Arenga pinnata)** [39] การเลือกใช้อีจุกมิได้มีเหตุผลเพียงด้านความคงทนต่อสภาพลมฝนเขตร้อนที่ยาวนานนับศตวรรษเท่านั้น หากแต่ในเชิงสัญศาสตร์ สีดำของอีจุกคือสีประจำทิศอุดร (ทิศเหนือ / Kaja) อันเป็นทิศแห่งพระวิษณุ ทิศแห่งยอดเขาศักดิ์สิทธิ์ และสัญลักษณ์แห่งน้ำอมฤตและความลึกลับแห่งจักรวาล [40]

กฎเกณฑ์ในการสร้างหอเมรุกำหนดไว้อย่างเด็ดขาดว่า จำนวนชั้นหลังคาซ้อน (Tumpang) **จะต้องเป็น "จำนวนคี่" (Ganjil) เสมอ** ได้แก่ 1, 3, 5, 7, 9, และ 11 ชั้น โดยไม่มีการสร้างหลังคาจำนวนคู่เด็ดขาด ทั้งนี้ จำนวนชั้นหลังคาคี่แต่ละระดับจะสอดคล้องกับลำดับชั้นแห่งพระบารมีของทวยเทพและบูรพกษัตริย์ที่สถิตอยู่ภายใน [41]:

1. **เมรุ 1 ชั้น (Meru Tumpang Siki):** หลังคาชั้นเดียวทรงปิรามิด ใช้สำหรับบูชาเทพารักษ์ประจำท้องถิ่น บรรพชนผู้บุกเบิกหมู่บ้าน หรือวิญญาณผู้พิทักษ์สายน้ำ
2. **เมรุ 3 ชั้น (Meru Tumpang Tiga):** หลังคาซ้อน 3 ชั้น เป็นสัญลักษณ์แห่งพระตรีมูรติ (Brahma, Wisnu, Siwa) หรือใช้เป็นที่ประทับของพระแม่แห่งทะเลสาบยอดเขาพญาบาตูร์ คือ "ภะฏารี ดานุฮ์" (Bhatari Danuh) ดังที่ปรากฏในปูรามาสเจตีและปูราเออร์เจรุก
3. **เมรุ 5 ชั้น (Meru Tumpang Lima):** หลังคาซ้อน 5 ชั้น เป็นสัญลักษณ์แห่งพระปัญจเทวตา (Panca Dewata) หรือใช้เป็นที่ประทับของ "พระบุตรชยะ" (Bhatara Putra Jaya) ผู้เป็นโอรสแห่งพระมหากูรูปศุบดี ผู้ทรงยกยอดเขาพระสุเมรุมาประดิษฐานบนเกาะบาหลี และยังเป็นแท่นประทับหลักของ "ภะฏาระ มาสเจตี" เทพแห่งมหาสมุทร
4. **เมรุ 7 ชั้น (Meru Tumpang Pitu):** หลังคาซ้อน 7 ชั้น สัญลักษณ์แห่งสัปตฤษี (Sapta Rsi) พระมหาโยคีทั้งเจ็ด หรือเทพแห่งชั้นฟ้าเจ็ดระดับ
5. **เมรุ 9 ชั้น (Meru Tumpang Sanga):** หลังคาซ้อน 9 ชั้น สัญลักษณ์แห่งเทวตานวสังฆะ (Dewata Nawa Sanga) หรือใช้เป็นศาลบูชาบูรพกษัตริย์ของราชตระกูลปูรีสายรอง
6. **เมรุ 11 ชั้น (Meru Tumpang Solas):** **หลังคาซ้อน 11 ชั้น ถือเป็นลำดับชั้นสูงสุดในระบบสถาปัตยกรรมบาหลี** สงวนไว้เฉพาะสำหรับพระมหาเทพสูงสุดแห่งยอดเขาอากุง (พระสัมภู / พระปรมศิวะ) และดวงวิญญาณแห่งสมเด็จพระมหากษัตริย์สายตรงแห่งราชวงศ์ดะเล็มเกลเกลและกลุงกุง (Dalem Gelgel / Dewa Agung Klungkung) เท่านั้น วัดหรือวังใดที่มิได้สืบสายโลหิตกษัตริย์สูงสุดจะไม่มีสิทธิ์สร้างเมรุ 11 ชั้นโดยเด็ดขาด [42]

### 5.5.5 ความสัมพันธ์เชิงพื้นที่และเชิงพิธีกรรมระหว่างปัทมาสน์ เมรุ และเปอเมราจันอากุง (Pemerajan Agung) ในพระราชวังปูรี

ภายในผังพระราชวังหลวง (Puri Agung) ของกษัตริย์บาหลี เขตพื้นที่ศักดิ์สิทธิ์สูงสุดคือ **"เปอเมราจัน อากุง" (Pemerajan Agung หรือ Pura Dalem Puri)** ซึ่งได้รับการจัดวางไว้ ณ มุมทิศตะวันออกเฉียงเหนือ หรือ **ทิศกาจา-กางิน (Kaja-Kangin)** อันเป็นจุดบรรจบระหว่างทิศภูเขาศักดิ์สิทธิ์อากุง (Kaja) กับทิศพระอาทิตย์อุทัย (Kangin) ตามแม่บทผังสังคามณฑล (Sanga Mandala) [43]

ความสัมพันธ์เชิงพื้นที่ระหว่างแท่นปัทมาสน์และหอเมรุภายในเปอเมราจัน อากุง สะท้อนโครงสร้างทางจักรวาลวิทยาและการเมืองเรื่องความชอบธรรมแห่งอำนาจอย่างแยบคาย:

ในเชิงพิธีกรรม แท่นปัทมาสน์และหอเมรุคือสถานที่ประกอบ **"พระราชพิธีสุริยเสวนา" (Surya Sewana)** ประจำวันและในวันเพ็ญวันเดือนดับ (Purnama-Tilem) ซึ่งพระมหากษัตริย์จะเสด็จมาประทับเคียงข้างพระราชปุโรหิตเปอดันดา พระองค์จะทรงเปล่งมนตราและสรงสนานด้วยน้ำศักดิ์สิทธิ์ (Tirtha) เพื่อดูดซับพลังความร้อนและแสงสว่างจากศิวะอาทิตย์ผ่านยอดปัทมาสน์ และรับพรแห่งความคุ้มครองจากวิญญาณบรรพชนในหอเมรุ แปลงสภาพพระวรกายให้กลายเป็น "เทวราชา" ผู้ทรงธรรม (Dharma Ksatriya) ก่อนจะเสด็จออกว่าราชการแผ่นดินในท้องพระโรงภายนอก [45]

## 5.6 เครือข่ายเทวสถานชลประทาน สหพันธ์ซูบัก (Subak) และกรณีศึกษาปูรามาสเจตี (Pura Masceti)

### 5.6.1 ปรัชญาไตรหิตครณะ (Tri Hita Karana) ในการจัดการชลประทานและนิเวศวิทยาการเกษตรบาหลี

การศึกษาระบบราชมนเทียรและพระราชอำนาจของกษัตริย์บาหลีไม่อาจเข้าใจได้อย่างถ่องแท้ หากปราศจากการทำความเข้าใจรากฐานทางเศรษฐกิจและนิเวศวิทยาการเกษตรที่ค้ำจุนราชสำนัก นั่นคือระบบการชลประทานนาข้าวแบบขั้นบันไดและสถาบันเหมืองฝายจารีตประเพณีที่เรียกว่า **"ซูบัก" (Subak)** [46] ซูบักมิได้เป็นเพียงองค์กรบริหารจัดการน้ำทางเทคนิควิทยาศาสตร์หรือสมาคมผู้ใช้น้ำเชิงโลกียวิสัยตามความหมายสมัยใหม่ หากแต่เป็นสถาบันทางสังคม-วัฒนธรรมและศาสนาที่มีชีวิต ซึ่งขับเคลื่อนอยู่ภายใต้ปรัชญาแม่บทสูงสุดของอารยธรรมบาหลี นั่นคือ **"ไตรหิตครณะ" (Tri Hita Karana)** หรือ "เหตุสามประการที่นำมาซึ่งความผาสุกและความเจริญสถาพรของจักรวาล" [47]

ปรัชญาไตรหิตครณะกำกับความสัมพันธ์เชิงดุลยภาพ 3 มิติในระบบชลประทานซูบักไว้อย่างแนบแน่น:
1. **มิติปารัฮยานงัน (Parahyangan):** ความสัมพันธ์อันกลมกลืนระหว่างมนุษย์กับพระผู้เป็นเจ้าและสิ่งศักดิ์สิทธิ์ แสดงออกผ่านการสถาปนา "เครือข่ายเทวสถานชลประทาน" (Water Temples) ประจำทุกหัวเลี้ยวของสายน้ำ ตั้งแต่เทวสถานประจำตาน้ำบนภูเขา (Pura Ulun Danu), ฝายทดน้ำหลัก (Pura Dam / Bedugul), คลองส่งน้ำเข้าสู่แปลงนาย่อย (Pura Ulun Swi), ไปจนถึงศาลบูชาพระแม่โพสพประจำแปลงนาของชาวนาแต่ละคน (Sanggah Catuk / Bedugul Carik) [48]
2. **มิติปาวงัน (Pawongan):** ความสัมพันธ์อันกลมกลืนและความเป็นปึกแผ่นระหว่างมนุษย์ด้วยกันเอง แสดงออกผ่านกฎบัตรจารีตประเพณีของซูบัก (Awig-awig Subak) การประชุมปรึกษาหารืออย่างสม่ำเสมอในศาลาประชาคม และการแบ่งปันน้ำอย่างเสมอภาคตามสัดส่วนพื้นที่นาโดยปราศจากการเอารัดเอาเปรียบ [49]
3. **มิติปาเลมะฮัน (Palemahan):** ความสัมพันธ์อันกลมกลืนระหว่างมนุษย์กับธรรมชาติสิ่งแวดล้อม แสดงออกผ่านการอนุรักษ์พื้นที่ป่าต้นน้ำ การรักษาระบบคลองดินและฝายหิน การจัดการหน้าดินด้วยระบบพืชหมุนเวียน และการประสานรอบการปล่อยน้ำเพื่อตัดวงจรชีวิตของแมลงศัตรูพืชโดยไม่ทำลายสมดุลทางชีววิทยา [50]

ในเชิงนิเวศวิทยาวัฒนธรรม น้ำในคติบาหลีมิได้เป็นเพียงสสารไฮโดรเจนและออกซิเจน (H2O) หากแต่เป็น **"ตีร์ถะ" (Tirtha)** หรือ "น้ำอมฤตศักดิ์สิทธิ์" ที่ไหลรินลงมาจากพระเกศาของพระศิวะบนยอดเขาพระสุเมรุ (ภูเขาไฟอากุง) และพระอุทรของพระแม่แห่งทะเลสาบ (ภะฏารี ดานุฮ์) การส่งผ่านน้ำเข้าสู่นาข้าวจึงมีสถานะเป็นพิธีกรรมทางศาสนาอันศักดิ์สิทธิ์ที่ผูกพันชีวิตของชาวนาเข้ากับพระราชอำนาจของกษัตริย์ในฐานะผู้พิทักษ์ธรรม [51]

#### 1. ทฤษฎีสถิตยศาสตร์ระบบไฮดรอลิกของคาร์ล วิตต์โฟเกล (Karl Wittfogel's Hydraulic Despotism)
ในงานชิ้นทรงอิทธิพล *Oriental Despotism: A Comparative Study of Total Power* (1957) คาร์ล วิตต์โฟเกล ได้เสนอทฤษฎีว่า สังคมเกษตรกรรมชลประทานขนาดใหญ่ในโลกตะวันออกจำเป็นต้องอาศัยกลไกของ "รัฐรวมศูนย์อำนาจเบ็ดเสร็จ" (Agro-Bureaucratic Despotism) เพื่อระดมแรงงานมหาศาลในการขุดลอกคูคลอง สร้างเขื่อน และบังคับใช้กฎหมายจัดสรรน้ำ กษัตริย์ในทัศนะของวิตต์โฟเกลจึงเป็นผู้เผด็จการทางชลประทานที่ควบคุมชีวิตและผลผลิตของราษฎรอย่างเบ็ดเสร็จเด็ดขาด [52] 

อย่างไรก็ดี เมื่อนักวิชาการนำทฤษฎีนี้มาตรวจสอบกับกรณีของบาหลี กลับพบว่าทฤษฎีของวิตต์โฟเกลล้มเหลวในการอธิบายความเป็นจริงอย่างสิ้นเชิง เนื่องจากในบาหลีโบราณ กษัตริย์ในพระราชวังปูรีมิได้มีระบบราชการชลประทานที่รวมศูนย์ และไม่ได้เป็นผู้สั่งการขุดคลองหรือควบคุมประตูระบายน้ำในชีวิตประจำวัน [53]

#### 2. ทฤษฎีเครือข่ายเทวสถานน้ำของเจ. สตีเฟน แลนซิง (J. Stephen Lansing's Water Temple Networks)
เพื่อหักล้างทฤษฎีของวิตต์โฟเกล เจ. สตีเฟน แลนซิง นักมานุษยวิทยาชาวอเมริกัน ได้ตีพิมพ์ผลงานวิจัยระดับคลาสสิก *Priests and Programmers: Technologies of Power in the Engineered Landscape of Bali* (1991, 2006) โดยเสนอว่า การจัดการน้ำในบาหลีเป็นระบบเครือข่ายแนวนอนที่ "จัดระเบียบตนเองจากล่างขึ้นบน" (Self-Organizing Bottom-Up Network) [54] 

แลนซิงพิสูจน์ให้เห็นว่า เครือข่ายเทวสถานน้ำทำหน้าที่เสมือน "คอมพิวเตอร์แบบแอนะล็อก" หรืออัลกอริทึมเชิงพิธีกรรมที่ทรงประสิทธิภาพสูงสุด ปฏิทินพิธีกรรมในวัดน้ำเป็นกลไกประสานงานให้ชาวนาหลายสิบชุมชนริมแม่น้ำสายเดียวกันทำการเพาะปลูกและปล่อยน้ำพร้อมกันเป็นระลอก เพื่อสร้างภาวะน้ำท่วมแปลงนาสลับกับภาวะแห้งแล้ง ซึ่งสามารถทำลายวงจรชีวิตของแมลงศัตรูพืชและหนูนาได้อย่างมีประสิทธิภาพโดยไม่ต้องพึ่งพาสารเคมีสมัยใหม่ [55] 

ทว่า ในการนำเสนอทัศนะดังกล่าว แลนซิงกลับลดทอนบทบาทของสถาบันกษัตริย์และพระราชวังปูรีลงอย่างมาก โดยมองว่ากษัตริย์เป็นเพียง "ผู้รับผลประโยชน์ภายนอก" หรือเป็นเพียงสัญลักษณ์ในรัฐนาฏกรรมที่แทบไม่มีอำนาจควบคุมระบบชลประทานที่แท้จริง [56]

#### 3. การวิพากษ์ของบริกิตตา เฮาเซอร์-ชอยบลิน และการรื้อฟื้นบทบาทของปูรี (Hauser-Schäublin's Critique)
การมองข้ามบทบาทของราชสำนักปูรีของแลนซิงได้รับการวิพากษ์วิจารณ์อย่างหนักหน่วงจากนักมานุษยวิทยาชาวยุโรป นำโดย บริกิตตา เฮาเซอร์-ชอยบลิน (Brigitta Hauser-Schäublin) ในงานวิจัยชิ้นสำคัญ *"The Politics of Sacred Space: Using Temple Networks in the Pre-Colonial Bali"* (2004) และงานศึกษาปี 2005 [57] 

เฮาเซอร์-ชอยบลิน ชี้ให้เห็นว่า แม้พระมหากษัตริย์ในปูรีจะมิได้ทำหน้าที่เป็นวิศวกรเปิดปิดประตูน้ำ แต่ราชสำนักปูรีได้เข้าไปผูกพันและแทรกแซงระบบเทวสถานน้ำอย่างลึกซึ้งในฐานะ **"องค์อุปถัมภ์สูงสุดและประธานฝ่ายฆราวาส" (Panganceng / Pangrajeg Karya)** [58] ปูรีใช้เครือข่ายเทวสถานน้ำระดับภูมิภาค (Kahyangan Jagat) เป็นเวทีและเครื่องมือทางการเมืองในการแผ่ขยาย "อำนาจบารมีเชิงสัญลักษณ์" (Kawibhawan) รวบรวมส่วยแรงงาน (Ayahan) และสร้างพันธมิตรข้ามแว่นแคว้น ความสัมพันธ์ระหว่างปูรีกับสหพันธ์ซูบักจึงมิใช่การสั่งการแบบเผด็จการของวิตต์โฟเกล และมิใช่การตัดขาดจากกันอย่างสิ้นเชิงของแลนซิง หากแต่เป็น **"ภาวะพึ่งพาอาศัยและดุลยภาพเชิงสถาบัน"** ที่ทั้งสองฝ่ายต่างจำเป็นต้องอาศัยซึ่งกันและกันเพื่อค้ำจุนความมั่นคงของอาณาจักร [59]

### 5.6.3 ภูมิทัศน์ศักดิ์สิทธิ์และการสถาปนาปูรามาสเจตี (Pura Masceti) ริมแม่น้ำปาเกอริซัน: ปูราณะปูรามาสเจตี มหากษัตริย์และพระเทวี

หลักฐานทางประวัติศาสตร์และจารึกวิทยาชิ้นเอกที่สะท้อนการประสานอำนาจระหว่างราชสำนักปูรีกับระบบชลประทานซูบักได้อย่างชัดเจนที่สุด คือ **"ปูรามาสเจตี" (Pura Masceti)** ซึ่งตั้งอยู่ ณ ชายฝั่งทะเลบ้านเมอดาฮัน-เกอรามัส (Desa Medahan – Keramas) อำเภอบละฮ์บาตูฮ์ (Kecamatan Blahbatuh) ในเขตอำเภอเกียนยาร์ (Gianyar) [60]

ในเชิงภูมิลักษณ์และอุทกวิทยา ปูรามาสเจติตั้งอยู่ ณ ชัยภูมิยุทธศาสตร์อันเป็นจุดบรรจบส่วนปลายสุดของแม่น้ำศักดิ์สิทธิ์ปาเกอริซัน (Hilir Lwah Pakrisan) ก่อนที่สายน้ำจะไหลลงสู่มหาสมุทรอินเดีย (Segara Kidul) [61] แม่น้ำปาเกอริซันไหลรินลงมาจากยอดเขาบาตูร์ทางทิศเหนือ (Kaja) สู่ทะเลทางทิศใต้ (Kelod) ทำให้ปูรามาสเจติทำหน้าที่เป็น **"ชุมทางแห่งพลังชีวิตจักรวาลและสถานีชลประทานศักดิ์สิทธิ์ส่วนปลาย" (Downstream Hydrological Node)** ที่เชื่อมต่อพลังน้ำจืดบนภูเขาเข้ากับน้ำเค็มในมหาสมุทรตามคติ "เญอการา-กูนุง" (Nyegara-Gunung) [62]

#### ตัวบทคัมภีร์ใบลาน *ปูราณะปูรามาสเจตี* (Purana Pura Masceti)
การสถาปนาปูรามาสเจตีได้รับการบันทึกไว้อย่างละเอียดในคัมภีร์ใบลาน *ปูราณะปูรามาสเจตี* ซึ่งได้รับการปริวรรตและวิเคราะห์โดยคณะนักโบราณคดีนำโดย อานัก อากุง เดย์ รากา (Anak Agung Gde Raka et al., 2015) [63] ตัวบทภาษากาวีโบราณเปิดฉากด้วยการประกาศหน้าที่ของกษัตริย์และผู้ปกครองทุกระดับชั้นที่จะต้องเคารพบูชาเทวสถานแห่งนี้อย่างเคร่งครัด:

> "Iki puràóa Pura Masceti kang hana ring pradeúa Mêdahan – Kêramas Blahbatuh Gianyar. Lamakana kawruha denira sang maweng rat karuhun sira sang añakradala haneng Gianyar, maring Pulina Bangsul mwah, katka tkeng wadwanira prasama. Marmmanya samangkana, apan parhyangan ika pinaka sthana Ida Sang Widhi Wasa utawya Ida Sang Hyang Parama Wisesa paradira wanehan. Juga sthana prabhawanira makadi: Bhaþàra Masceti, Bhaþàra Baruóa, Bhaþàri Danu, Bhaþàra Hulun Suwi gênah aminta nugraha karahaywan mwang kajagaddhitaning jagat, muah aminta nugraha maring Ida Bhaþàra didinya amunahakên ikang sarwwa maraóa. Mwah sthanan sira Sang Naga Wasuki apan sira stata angukuha ikang jagat." [64]

*คำแปลภาษาไทยเชิงวิชาการ:*  
"นี่คือคัมภีร์ปุราณะแห่งปูรามาสเจตี ซึ่งตั้งอยู่ ณ ตำบลเมอดาฮัน-เกอรามัส บละฮ์บาตูฮ์ เกียนยาร์ พึงเป็นที่ตระหนักรู้แก่เหล่าผู้กุมอำนาจรัฐ โดยเฉพาะอย่างยิ่งท่านผู้ถือครองวงล้อแห่งอำนาจในเกียนยาร์ (Sang Añakradala haneng Gianyar) ตลอดจนผู้ปกครองทั่วทั้งเกาะบาหลี (Sang Maweng Rat / Ratu Bali) และไพร่พลราษฎรทั้งปวง เหตุที่เป็นเช่นนั้น เพราะเทวสถานแห่งนี้เป็นที่ประทับสถิตของพระอิศวรผู้เป็นเจ้า หรือพระปรมวิเศษ อีกทั้งยังเป็นที่สถิตแห่งภาคสำแดงของพระองค์ อันได้แก่ ภะฏาระมาสเจตี, ภะฏาระบารุณา, ภะฏารีดานุฮ์, และภะฏาระฮูลุนซูวี อันเป็นสถานสำหรับทูลขอพระราชทานความร่มเย็นเป็นสุขและความเจริญสถาพรแห่งพิภพ ตลอดจนทูลขอพระเมตตาให้ทรงทำลายล้างสรรพศัตรูพืชและโรคาพยาธิทั้งปวง และยังเป็นที่สถิตของพญานาควาสุกีผู้ทรงค้ำจุนโลกนี้ให้มั่นคงอยู่เป็นนิจ" [65]

#### เทวตำนานการเผชิญหน้ากับวิกฤตภัยแล้งและการพบกันของทวิเทวะ
ปุราณะได้บันทึกถึงวิกฤตการณ์ครั้งประวัติศาสตร์ในยุคโบราณ เมื่อเกาะบาหลีต้องเผชิญกับภัยแล้งยาวนานและโรคระบาดศัตรูพืชกัดกินนาข้าวอย่างไม่หยุดหย่อน (*kemarau berkepanjangan dan hama penyakit / marana tan papagetan*) [66] นาข้าว สวนครัว และไร่เลื่อนลอยของราษฎรถูกทำลายย่อยยับด้วยฝูงหนูนา ตั๊กแตน และแมลงสิง (Walang Sangit) พระสังฮยังกูรูปศุบดี (Sang Hyang Guru Pasupati) บรมครูแห่งสากลจักรวาล จึงทรงบัญชาให้พระราชธิดา คือ **"ภะฏารี ดานุฮ์" (Bhatari Danuh)** มหาเทวีผู้สถิต ณ ทะเลสาบยอดเขาตัมปุรฮยัง (ภูเขาบาตูร์) เสด็จยาตราลงมาตรวจตราความทุกข์ยากของชาวนา [67]

พระนางเสด็จลงมาตามแนวทางน้ำจากทิศเหนือมุ่งสู่ทิศใต้ จนกระทั่งเสด็จถึงชายฝั่งทะเลใต้ ณ ปากแม่น้ำปาเกอริซัน ที่นั่น พระนางได้พบกับ **"ภะฏาระ บารุณา" (Bhatara Baruna / Bhatara Tengahing Sagara)** มหาเทพแห่งห้วงมหาสมุทร ทั้งสองพระองค์ทรงปรึกษาหารือกันเพื่อหาหนทางดับทุกข์เข็ญ และทรงมีเทวบัญชาประกาศิตลงมายังชาวบาหลีทั้งปวงว่า:

> "สมควรร่วมกันสร้างเทวสถานมาสเจตีขึ้น เพื่อเป็นที่ประทับแห่งภะฏารีดานุฮ์ (ตัวแทนแห่งน้ำจืดบนภูเขาและสตรีเพศ) และภะฏาระบารุณา (ตัวแทนแห่งน้ำเค็มในมหาสมุทรและบุรุษเพศ) เพื่อเป็นศูนย์กลางการบวงสรวงของชาวนาและเป็นหลักยึดความมั่นคงแห่งผืนนา เทวสถานแห่งนี้จำต้องได้รับการเคารพสักการะจากกษัตริย์แห่งบาหลี วรรณะกษัตริย์ ไวศยะ และชาวบาหลีทั้งมวล จงอย่าได้ตัดขาดหรือลดทอนการบวงสรวงในนาข้าว มิฉะนั้นชาวบาหลีจะต้องเผชิญกับความแห้งแล้งและทุกข์ทรมานไม่สิ้นสุด" [68]

#### การฟื้นฟูอำนาจราชวงศ์ของปูรีเกอรามัส
ในปลายคริสต์ศตวรรษที่ 17 ภายหลังการล่มสลายของราชธานีเกลเกล อันเนื่องมาจากการก่อกบฏของอังกูระห์ มรุตี (I Gusti Agung Maruti) ในปี ค.ศ. 1651 และการถูกกองทัพพันธมิตรขับไล่ออกจากเกลเกลในปี ค.ศ. 1686 ทายาทของตระกูลมรุตีได้อพยพไพร่พลและขุนนางบริวาร (Wadwa lan Pepatih) ลงมาตั้งพระราชวังแห่งใหม่ ณ **"ปูรี อากุง เกอรามัส" (Puri Agung Keramas)** [69] 

สิ่งแรกที่เจ้าผู้ครองปูรีเกอรามัสทรงกระทำเพื่อฟื้นฟูอำนาจบารมี (Kawiryyan lan Kawibhawan) และรวบรวมความจงรักภักดีของไพร่พล คือการประกาศยกให้ภะฏาระมาสเจตีเป็น "เทพารักษ์ประจำราชตระกูล" (Sungsungan Sang Natha) และนำกำลังไพร่พลร่วมมือกับราษฎรทำการบูรณปฏิสังขรณ์เทวสถานปูรามาสเจตีครั้งใหญ่ พร้อมทั้งแต่งตั้ง กี เบินเดซา เกอเดะฮ์ (Ki Bandesa Kedeh) เป็นผู้พิทักษ์วัด [70] การกระทำดังกล่าวได้สถาปนาให้ราชสกุลปูรีเกอรามัส (และต่อมาคือปูรีอากุงเกียนยาร์) กลายเป็น **"ปังงันเจ็ง / ปังราเจกการ์ยา" (Panganceng)** หรือองค์อุปถัมภ์สูงสุดของเครือข่ายเทวสถานชลประทาน ซึ่งผูกมัดอำนาจทางการเมืองของราชสำนักเข้ากับวิถีชีวิตและความอยู่รอดของชาวนาอย่างแนบแน่น [71]

#### พันธมิตร 20 ซูบักแห่งลุ่มน้ำปาเกอริซันตอนล่าง (The Federation of 20 Subaks)
พื้นที่เกษตรกรรมชลประทานที่ขึ้นตรงต่อปูรามาสเจตีครอบคลุมอาณาบริเวณกว้างใหญ่ไพศาลในเขตลุ่มน้ำปาเกอริซันตอนล่าง (Subak Pakerisan Teben) และกูนุงซารี (Subak Gunung Sari) ประกอบด้วยสหพันธ์ซูบัก 20 แห่งอย่างเป็นทางการ [73]:
1. Subak Gaga, 2. Subak Dayang, 3. Subak Diga, 4. Subak Dewa, 5. Subak Amping,
6. Subak Poh Gading, 7. Subak Betuas, 8. Subak Slukat, 9. Subak Sengauk, 10. Subak Abang,
11. Subak Dukuh, 12. Subak Tedung, 13. Subak Nengan, 14. Subak Abu, 15. Subak Celuk,
16. Subak Ceti, 17. Subak Padang Legi, 18. Subak Panjan, 19. Subak Jurit, และ 20. Subak Peling [74]

แต่ละซูบักมีหัวหน้าชลประทานที่เรียกว่า **"ปากาเสะฮ์" (Pakaseh)** เป็นผู้นำ โดยทั้ง 20 ซูบักมีสถานะเป็น **"ปาเงิมปอน / ปาเงามอง" (Pengempon / Pangamong)** ซึ่งมีพันธะทางจารีตในการดูแลรักษาความสะอาด การระดมแรงงานซ่อมแซมอาคารเทวสถาน (Ngayah) และการส่งตัวแทนเข้าร่วมประกอบพิธีกรรมหลวง ขณะที่ราชสำนักปูรีทำหน้าที่เป็น **"ปังงันเจ็ง" (Panganceng)** จัดสรรพระราชทรัพย์และเครื่องประกอบพิธีชั้นสูง [75]

#### กฎบัตรจารีตและระบบรอบการเพาะปลูก
การดำเนินงานของสหพันธ์ซูบักยึดถือกรอบกฎหมายจารีตประเพณี 4 ประการ ได้แก่ **สีมา (Sima - กฎและขอบเขตศักดิ์สิทธิ์แต่โบราณ)**, **ดฤษฏา (Drsta - ธรรมเนียมปฏิบัติของบรรพชน)**, **ศาสตรา (Sastra - ตำราพิธีกรรม)**, และ **ปาราเร็ม/ปลูตุก (Pararem / Plutuk - มติข้อตกลงของชุมชนและคู่มือพิธี)** [76]

ในด้านวิทยาการเกษตร สหพันธ์ซูบักได้สืบทอดระบบรอบการปลูกพืชศักดิ์สิทธิ์ 2 ระบบที่ท่านดังฮยัง นิราร์ถะ ได้ประสิทธิ์ประสาทไว้ [77]:
1. **เกอร์ตามอซา (Kerta Masa):** ระบบการปลูกข้าวสลับกับพืชไร่/พืชตระกูลถั่ว (Palawija) ตามฤดูกาล เพื่อตัดวงจรอาหารของแมลงศัตรูพืชและฟื้นฟูธาตุอาหารในดิน
2. **ตูละก์ซูมูร์ (Tulak Sumur):** ระบบการทำนาข้าวต่อเนื่องตลอดทั้งปีในแปลงนาที่มีน้ำอุดมสมบูรณ์เป็นพิเศษ โดยมีการควบคุมระดับน้ำในคลองส่งน้ำอย่างเคร่งครัด [78]

#### วัฏจักรพิธีกรรมหลวงและการขับไล่ศัตรูพืช (Nangluk Merana)
ปูรามาสเจตีเป็นศูนย์กลางของการประกอบพิธีกรรมเกษตรกรรมตลอดทั้งปี โดยมีพิธีสำคัญตามปฏิทินปาวูกอน (Pawukon 210 วัน) และปฏิทินจันทรคติ (Sasih) [79]:
- **พิธีเนอดุฮ์ (Neduh):** จัดขึ้นในวัน Anggara Kasih Dukut บวงสรวงขอพรให้ต้นกล้าในนาข้าวเจริญงอกงาม ปราศจากโรคระบาด
- **พิธีงูซาบา เกอตูปัต (Ngusaba Ketipat):** จัดขึ้นในวัน Anggara Kasih Kulantir ถวายข้าวต้มมัดใบมะพร้าวเพื่อขอบพระคุณพระแม่โพสพหลังการเก็บเกี่ยว
- **พิธีตาบูห์ ราห์ (Tabuh Rah / Pangaci Kalecan):** จัดขึ้นติดต่อกัน 4 วัน ณ ศาลาวานตีลัน (Wantilan) มีการชนไก่บวงสรวงโดยวางเดิมพันตามจารีตโบราณ **1,000 เกเป็ง (เหรียญจีนโบราณ Pis Bolong)** เลือดไก่ที่หยดลงสู่ผืนธรณีร่วมกับสุรากลั่น (Arak), สาโทข้าวหมัก (Berem), น้ำตาลเมา (Tuak), และน้ำบริสุทธิ์ ทำหน้าที่เป็นเครื่องสังเวยเพื่อสงบระงับความเกรี้ยวกราดของภูตผีปีศาจ (Nyomyang Bhuta Kala) มิให้ทำลายพืชผล [80]
- **พิธีอาจี มาเตตาบูฮัน เบอเร็ม (Aci Matetabuhan Berem):** ในวัน Anggara Kasih Julungwangi สมาชิกซูบักทั้ง 20 แห่ง จะต้องนำเหล้าข้าวหมักสีแดง (Berem) มาซูบักละ 1 ไห เพื่อนำไปประกอบพิธีรินหลั่งบวงสรวงลงบนพื้นดินเบื้องหน้าแท่นบูชาทุกแท่น [81]
- **มหาพิธีนังลุก เมอรานา (Nangluk Merana):** มหาพิธีกรรมระดับภูมิภาคเพื่อขับไล่ฝูงหนู แมลงสิง และตั๊กแตน โดยมีการอัญเชิญน้ำศักดิ์สิทธิ์จากทะเลมาสเจตีไปประพรมทั่วทุกแปลงนาของสหพันธ์ 20 ซูบัก [82]
- **มหาพิธีปาดูดูซันหลวงรอบ 30 ปี (Tigang Dasa Warsa / Padudusan Agung):** ตัวบทภาษากาวีโบราณระบุชัดเจนว่า *"linaksanakên ngangkên tigang daúa warûa"* คือกำหนดจัดขึ้นทุกรอบ 30 ปี เพื่อชำระล้างมลทินจักรวาลและเฉลิมฉลองสถานะกาฮยางันจากัต โดยเป็นการระดมความร่วมมือระดับสูงสุดระหว่างราชสกุลปูรีเกอรามัส/เกียนยาร์ พระสังฆราชเปอดันดาทุกนิกาย และสหพันธ์ชาวนาทั้งปวง [83]

### 5.6.5 กรณีศึกษาเปรียบเทียบ: ปูราเออร์เจรุก สุกะวาตี (Pura Kahyangan Jagat Er Jeruk Sukawati) สหพันธ์ซูบักเกอเดสุขาวตี 13 ซูบักเติมเปกัน (404.52 เฮกตาร์), กฎเกณฑ์เกอร์ตามอซา-ตูละก์ซูมูร์ และสัปตปาตาละ

เพื่อสร้างความเข้าใจเชิงลึกที่รอบด้าน การวิเคราะห์เปรียบเทียบกับเทวสถานชลประทานคู่ขนานในเขตอำเภอเกียนยาร์ คือ **"ปูรากาฮยางันจากัต เออร์เจรุก" (Pura Kahyangan Jagat Er Jeruk)** ซึ่งตั้งอยู่ริมหาดปูรณมา (Pantai Purnama) ตำบลสุขาวตี (Sukawati) ย่อมช่วยตอกย้ำโครงสร้างเชิงสถาบันดังกล่าวได้อย่างแจ่มชัด [84]

งานวิจัยของ ดร. อานัก อากุง เดย์ รากา และ ดรส. อี วายัน ซูดานา (*Pura Kahyangan Jagat Er Jeruk Desa Adat/Pakraman Sukawati, Gianyar*, 2018) ระบุว่า ปูราเออร์เจรุกได้รับการสถาปนาขึ้นตั้งแต่คริสต์ศตวรรษที่ 10 ในรัชสมัยพระเจ้าศรีเกสารี วาร์มาเทวา (Sri Kesari Warmadewa) และได้รับการยกย่องเป็นหนึ่งในมหาเทวสถาน "สัทกะฮ์ยังงัน" (Sad Kahyangan) หรือ "กาฮยางันจากัต" ประจำเกาะบาหลี [85]

#### สหพันธ์ซูบักเกอเดสุขาวตี 13 สมาคมย่อย
เช่นเดียวกับปูรามาสเจตี องค์กรผู้ดูแลและปรนนิบัติปูราเออร์เจรุกที่แท้จริงคือ **"สหพันธ์ซูบักเกอเดสุขาวตี" (Subak Gede Sukawati)** ซึ่งประกอบด้วยสมาคมย่อย (ซูบักเติมเปกัน / Subak Tempekan) จำนวน 13 แห่ง รวมสมาชิกชาวนาทั้งสิ้น 1,188 ครัวเรือน ดูแลผืนนาชลประทานกว้างใหญ่ถึง **404.520 เฮกตาร์** [86]:
1. Subak Bubun (110 คน), 2. Subak Palak (126 คน), 3. Subak Sengguan (93 คน),
4. Subak Sange (104 คน), 5. Subak Laud (72 คน), 6. Subak Somi (58 คน),
7. Subak Abasan (70 คน), 8. Subak Cau Duwur (51 คน), 9. Subak Cau Beten (96 คน),
10. Subak Juwuk (89 คน), 11. Subak Langge (92 คน), 12. Subak Babakan (82 คน),
และ 13. Subak Leba (95 คน) [87]

การบริหารงานมี **"เปอกาเสะฮ์เกอเด" (Pekaseh Gede)** เป็นผู้นำสูงสุด ประสานงานร่วมกับเปอกาเสะฮ์เติมเปกันทั้ง 13 คน โดยได้รับสิทธิประโยชน์ทางจารีต ได้แก่ การยกเว้นภาษีค่าบำรุงวัด (Luput Pakenin), การถือครองที่ดินกัลปนาเพื่อผลประโยชน์เทวสถาน (Tanah Laba Pura หรือ Catu), และระบบการปันส่วนผลผลิตข้าวในอัตรา 1 ต่อ 11 ที่เรียกว่า **"เปอนโยลาซัน" (Penyolasan)** [88]

#### ประติมาวิทยาความอุดมสมบูรณ์: พระเทวีศรี พญานาควาสุกี และพระบุตรชยะ
ภายในมณฑลของปูราเออร์เจรุก มีสถาปัตยกรรมศักดิ์สิทธิ์ที่เชื่อมโยงกับความอุดมสมบูรณ์ทางการเกษตรอย่างลึกซึ้ง:
1. **ปูรามาสเจตีและปาลึงกิฮ์เบอดูอุล (Palinggih Bedugul):** ตั้งอยู่ในมัธยมณฑล เป็นเรือนไม้ปิดทึบ สถิตแห่ง **"พระเทวีศรี" (Ida Betari Sri)** มหาเทวีแห่งข้าวและความอุดมสมบูรณ์ ซึ่งทำหน้าที่เป็นศูนย์กลางจิตวิญญาณของชาวนาซูบัก [89]
2. **ปาลึงกิฮ์สัปตปาตาละ (Palinggih Sapta Patala):** แท่นบูชาจำลองชั้นบาดาลทั้งเจ็ด สถิตแห่ง **"พญานาควาสุกี" (Sang Hyang Naga Basuki)** ในฐานะตัวแทนแห่งธาตุน้ำ (Apah) และน้ำอมฤตที่หล่อเลี้ยงผืนนาให้อุดมสมบูรณ์ [90]
3. **หอเมรุ 5 ชั้น (Meru Tumpang Lima):** วิหารประธานสูงสุดของวัด สถิตแห่ง **"พระบุตรชยะ" (Ida Bhatara Putrajaya)** เทพเจ้าผู้ทรงยกยอดเขาพระสุเมรุมาสู่เกาะบาหลี ซึ่งในคัมภีร์ *อุสะนะบาหลี-อุสะนะชวา* (Usana Bali-Usana Jawa) ระบุว่าสถิต ณ "ภูเขาเจอรุก" (Gunung Jeruk หรือหาดปูรณมา) [91]

#### บทบาทของราชตระกูลปูรีสุขาวตีในฐานะ Yajamana Welaka Karya
ในมหาพิธีกรรมครั้งประวัติศาสตร์รอบ 30 ปี เช่น มหาพิธีปาดูดูซันหลวง (Karya Padudusan Agung, Segara Kertih, Tawur Balik Sumpah Agung ค.ศ. 2019) บรรดาเจ้านายสายราชตระกูลปูรีสุขาวตีและปูรีบริวารในเขตเกียนยาร์ ได้รับการแต่งตั้งให้ทำหน้าที่เป็น **"ยะชะมานะ เวลากา การ์ยา" (Yajamana Welaka Karya)** หรือประธานฝ่ายฆราวาสและผู้อุปถัมภ์สูงสุด ได้แก่:
1. Penglingsir Puri Agung Kaleran Sukawati
2. Penglingsir Puri Agung Peliatan
3. Penglingsir Puri Agung Ubud
4. Penglingsir Puri Agung Gianyar
5. Penglingsir Puri Ageng Sukawati [92]

กรณีศึกษาของทั้งปูรามาสเจตีและปูราเออร์เจรุก ยืนยันอย่างชัดเจนว่า ความมั่นคงของราชสำนักปูรีบาหลีดำรงอยู่ได้ด้วยการถักทอสายสัมพันธ์อันศักดิ์สิทธิ์กับสหพันธ์ชาวนาซูบัก โดยปูรีทำหน้าที่เป็นร่มเงาคุ้มครองทางพิธีกรรมและความชอบธรรม ขณะที่ซูบักทำหน้าที่เป็นฐานรากการผลิตทางกายภาพที่หล่อเลี้ยงราชอาณาจักรให้เจริญรุ่งเรืองสืบเนื่องมาหลายศตวรรษ [93]

## 5.7 กองกำลังพิทักษ์ความปลอดภัยจารีตประเพณี "เปอจาลัง" (Pecalang) จากทหารรักษาพระราชวังปูรีสู่การพิทักษ์ชุมชน

### 5.7.1 ประวัติศาสตร์ นิรุกติศาสตร์ และวิวัฒนาการของเปอจาลัง: จาก *calang* สู่กองกำลังพิทักษ์พระราชวังปูรีในยุคโบราณ

ความมั่นคงและความศักดิ์สิทธิ์ของพระราชวังปูรี (Puri) และมณฑลพิธีของเทวสถานบาหลีในอดีต มิได้ดำรงอยู่ได้ด้วยอำนาจทางนามธรรมเพียงอย่างเดียว หากแต่ต้องอาศัยกลไกการรักษาความปลอดภัยที่มีประสิทธิภาพ ซึ่งผูกพันอยู่กับกองกำลังจารีตประเพณีที่มีเอกลักษณ์เฉพาะตัวสูงสุดในโลกนูซันตารา นั่นคือ **"เปอจาลัง" (Pecalang หรือ Pacalang)** [94]

ในทางศัพทมูลวิทยา (Etymology) คำว่า "เปอจาลัง" มีรากศัพท์มาจากภาษาบาหลีโบราณ คือคำว่า **"จาลัง" (*calang*)** ซึ่งมีความหมายตรงกับคำว่า *waspada* ในภาษาอินโดนีเซีย หรือตรงกับความหมายในภาษาไทยว่า "ความตื่นตัว ความระแวดระวัง มีสติรอบคอบ คล่องแคล่วว่องไว และพร้อมเผชิญเหตุตลอดเวลา" [95] ผู้ที่ได้รับการคัดเลือกให้ทำหน้าที่เป็นเปอจาลังจึงมิได้เป็นเพียงพนักงานยามหรือเจ้าหน้าที่รักษาความปลอดภัยทั่วไป หากแต่เป็นตัวแทนแห่ง "สติปัญญาและสายตาอันเฉียบแหลม" ของชุมชนและราชสำนักในการเฝ้าระวังภัยคุกคาม [96]

ในมิติทางประวัติศาสตร์นิพนธ์ นักวิชาการด้านบาหลีศึกษา เช่น อินดรียันตี (Indriyanti, 2021) และคณะผู้วิจัยนำโดย อี ปูตู ฮาดี ปรัดญานา (I Putu Hadi Pradnyana et al., 2023) ได้ชี้ให้เห็นว่า สถาบันเปอจาลังมีรากเหง้าย้อนหลังไปอย่างยาวนานหลายศตวรรษ โดยหนึ่งในข้อสันนิษฐานทางประวัติศาสตร์ที่ได้รับการยอมรับอย่างกว้างขวางระบุว่า เปอจาลังคือ **"การกลับชาติมาเกิดหรือการสืบทอดบทบาทของกองทหารพิทักษ์พระราชวังปูรี" (*reinkarnasi dari penjaga puri / kerajaan jaman dahulu*)** ในยุคระบอบราชาธิปไตยบาหลีโบราณ [97]

ในยุคที่ราชอาณาจักรบาหลี (เช่น เกลเกล, กลุงกุง, บาดุง, เกียนยาร์, ตาบานัน, และเม็งวี) ยังรุ่งโรจน์ บรรดาราชาผู้ครองปูรีจะมีกองกำลังทหารรักษาพระองค์และทหารรักษาพระราชฐาน เรียกว่า **"ไพรจูริต เปินจากา ปูรี" (Prajurit Penjaga Puri)** [98] ทหารเหล่านี้มีหน้าที่หลัก 3 ประการ:
1. การถวายอารักขาพระวรกายขององค์พระมหากษัตริย์ พระบรมวงศานุวงศ์ และบาทบริจาริกาฝ่ายใน
2. การเฝ้าระวังตามแนวกำแพงพระราชวัง ประตูซุ้มโกรีอากุง และหอกลองสัญญาณบาเลกูลกูล
3. การคุ้มกันมณฑลพระราชพิธีหลวง ทั้งพิธีบรมราชาภิเษก พิธีสมโภชเทวสถานประจำราชสำนัก และพิธีถวายพระเพลิงพระบรมศพ (Pelebon) เพื่อสกัดกั้นมิให้ผู้มีมลทินหรือศัตรูภายนอกล่วงล้ำเข้าสู่เขตอุตมะมณฑล [99]

นักมานุษยวิทยา ดาร์ลิง (Darling, 2003: 200) ได้วิเคราะห์ไว้อย่างลึกซึ้งว่า สถาบันเปอจาลังก่อกำเนิดขึ้นจากการผสมผสานอย่างกลมกลืนระหว่าง **"วัฒนธรรมเชิงพิธีกรรมอันศักดิ์สิทธิ์ของบาหลี" (Balinese ritual culture)**, **"แสนยานุภาพทางการทหารที่แฝงเร้นอยู่ในประวัติศาสตร์" (Latent militarism)**, และ **"มโนทัศน์ทางจักรวาลวิทยาและสังคมวิทยาว่าด้วยดุลยภาพความสงบเรียบร้อยของสังคม" (Cosmological harmony)** [100] การปฏิบัติหน้าที่ของเปอจาลังจึงมิใช่การใช้กำลังทางกายภาพอย่างตัดขาดจากความเชื่อ แต่เป็นการปฏิบัติการทางศาสนาและจารีตประเพณีเพื่อพิทักษ์สมดุลระหว่างโลกมนุษย์ (Sekala) กับโลกแห่งจิตวิญญาณ (Niskala) [101]

### 5.7.2 การเปลี่ยนแปลงเชิงสถาบันในยุคหลังราชอาณาจักร: การถ่ายโอนหน้าที่สู่เดซาอาดัต (Desa Adat / Pakraman) กฎหมายจารีต Awig-Awig / Pararem และ Perda No. 3/2001 Pasal 17

จุดเปลี่ยนผ่านเชิงโครงสร้างครั้งใหญ่ที่สุดของกองกำลังพิทักษ์วังปูรีเกิดขึ้นในต้นคริสต์ศตวรรษที่ 20 เมื่อกองทัพอาณานิคมดัตช์เข้าบดขยี้ราชอาณาจักรบาหลีในสงครามพลีชีพปูปูตัน (Puputan Badung ค.ศ. 1906 และ Puputan Klungkung ค.ศ. 1908) [102] อำนาจอธิปไตยทางการเมืองและการทหารของราชสำนักปูรีถูกทำลายลง กองทัพหลวงของกษัตริย์ถูกสั่งยุบเลิกและปลดอาวุธโดยเจ้าอาณานิคม 

ทว่า ในภาวะสุญญากาศแห่งอำนาจนั้น โครงสร้างและจิตวิญญาณของกองกำลังรักษาความปลอดภัยมิได้สูญสลายไป หากแต่เกิดปรากฏการณ์ **"การถ่ายโอนหน้าที่ลงสู่ฐานรากของชุมชน" (Devolution of Security Functions)** กองกำลังทหารพิทักษ์ปูรีได้แปรสภาพและกระจายตัวเข้าสู่สถาบันปกครองตนเองดั้งเดิมของชาวบาหลี นั่นคือ **"เดซาอาดัต หรือ เดซาปักรามัน" (Desa Adat / Desa Pakraman)** และสมาคมชุมชนย่อยระดับละแวกบ้าน คือ **"บันจาร์" (Banjar)** [103]

#### ฐานอำนาจตามกฎหมายจารีตและกฎหมายท้องถิ่น Perda No. 3/2001
ในระดับชุมชน ฐานอำนาจและหน้าที่ของเปอจาลังถูกกำหนดไว้อย่างเป็นลายลักษณ์อักษรใน **"อะเวิก-อะเวิก" (Awig-awig)** อันเป็นธรรมนูญจารีตประเพณีของหมู่บ้าน และ **"ปาราเร็ม" (Pararem)** หรือมติข้อตกลงร่วมของที่ประชุมชาวบ้าน [104] เปอจาลังขึ้นตรงต่อผู้นำฝ่ายบริหารของหมู่บ้าน คือ "เบินเดซาอาดัต" (Bendesa Adat) และทำงานประสานกับสภาตุลาการจารีต "เกอร์ตาซาบา" (Kerta Sabha) [105]

ต่อมาในยุคการปฏิรูปการเมืองของอินโดนีเซียหลังการล่มสลายของระบอบซูฮาร์โต (ค.ศ. 1998) รัฐบาลท้องถิ่นจังหวัดบาหลีได้ออกกฎหมายรับรองสถานะทางนิตินัยของเปอจาลังอย่างเป็นทางการ ผ่าน **กฎหมายส่วนท้องถิ่นจังหวัดบาหลี ฉบับที่ 3 ปี 2001 (Peraturan Daerah / Perda Provinsi Bali No. 3 Tahun 2001 tentang Desa Pakraman)** [106] โดยใน **มาตรา 17 (Pasal 17)** ได้ระบุขอบเขตอำนาจหน้าที่ไว้อย่างชัดเจนว่า:

> "Pacalang melaksanakan tugas-tugas pengamanan dalam wilayah desa pakraman dalam hubungan pelaksanaan tugas adat dan agama" [107]
> *(เปอจาลังมีหน้าที่ปฏิบัติภารกิจรักษาความปลอดภัยภายในเขตพื้นที่หมู่บ้านปักรามัน ในส่วนที่สัมพันธ์กับการดำเนินภารกิจทางจารีตประเพณีและศาสนา)*

การรับรองตาม Perda ฉบับนี้ ทำให้เปอจาลังมีสถานะเป็นองค์กรความมั่นคงจารีตที่ไม่เป็นทางการ (Informal Customary Security Institution) ที่ถูกต้องตามกฎหมายของรัฐ มีอำนาจในการจัดการจราจร ปิดกั้นถนนหนทางเพื่อประกอบพิธีกรรม ตรวจสอบความสงบเรียบร้อย และตรวจตราคนต่างถิ่น (Custom Security) ร่วมกับสมาพันธ์ความช่วยเหลือความมั่นคงหมู่บ้านจารีต หรือ **"บังคัมดา" (Pasikian Bantuan Keamanan Desa Adat - Bankamda)** [108]

#### การขยายบทบาทสู่เวทีโลกและข้อวิพากษ์เชิงโครงสร้าง
บทบาทของเปอจาลังได้รับการยกระดับสู่เวทีสากลอย่างเด่นชัดในการประชุมสุดยอดผู้นำกลุ่มเศรษฐกิจขนาดใหญ่ **G20 Summit 2022 ณ นูซาดูอา บาหลี** [109] รัฐบาลอินโดนีเซียได้บรรจุเปอจาลังหลายร้อยนายเข้าสู่แผนการรักษาความปลอดภัยอย่างเป็นทางการ โดยจัดวางกำลังให้อยู่ใน **"วงแหวนชั้นที่ 3" (Ring Tiga)** ซึ่งเป็นแนวป้องกันรอบนอกสุดที่ประจันหน้ากับชุมชนและนักท่องเที่ยว ขณะที่ Ring 1 และ Ring 2 สงวนไว้ให้แก่กองทัพแห่งชาติ (TNI) และตำรวจ (Polri) [110]

อย่างไรก็ดี นักวิชาการบาหลีศึกษา เช่น วายัน พี. วินเดีย (Wayan P. Windia) และ เกอเด อินดรา ปรามานา (Gede Indra Pramana, 2012) ได้ตั้งข้อสังเกตเชิงวิพากษ์ว่า การขยายบทบาทของเปอจาลังนำมาซึ่งความตึงเครียดเชิงสถาบัน 3 ประการ [111]:
1. **การขาดแคลนอาวุธยุทโธปกรณ์:** เปอจาลังปฏิบัติหน้าที่โดยปราศจากอาวุธปืนหรือเครื่องมือกำราบจลาจล ต้องอาศัยเพียง "การเอาตัวเข้าแลก" (Memasang Badan) ทางกายภาพ
2. **การแย่งชิงพื้นที่อำนาจ:** เกิดภาวะทับซ้อนและแย่งชิงพื้นที่ทำกินและการบังคับใช้กฎหมายกับเจ้าหน้าที่ตำรวจจริง
3. **ความเสี่ยงต่อการถูกครอบงำโดยกลุ่มทุน (Tunduk kepada pemodal):** ปรากฏการณ์ที่เปอจาลังถูกกลุ่มธุรกิจการท่องเที่ยว รีสอร์ตหรู หรือนักการเมืองว่าจ้างไปเป็นกองกำลังรักษาความปลอดภัยส่วนบุคคล ละทิ้งพันธกิจดั้งเดิมในการรับใช้ชุมชนจารีตและราชสำนักปูรี [112]

### 5.7.3 สัญญะวิทยาของเครื่องแต่งกาย อาวุธ และยุทธวิธี: ผ้าโพลเลง รวา บิเนดา, อูเด็ง, กริชปูซากะ, ดอกชบาแดง, และยุทธวิธีเมอปาซัง บาดัน

#### 1. ผ้าโสร่งลายตารางหมากรุกขาวดำ (Kain Poleng Rwa Bhineda)
เครื่องแบบที่เป็นเอกลักษณ์สูงสุดของเปอจาลังคือ ผ้านุ่งลายตารางสี่เหลี่ยมจัตุรัสสีขาวสลับดำ เรียกว่า **"ผ้าโพลเลง" (Kain Poleng)** [114] ในทางเทววิทยาฮินดู-บาหลี ลายตารางขาวดำนี้คือตัวแทนของปรัชญา **"รวา บิเนดา" (Rwa Bhineda)** หรือสัจธรรมแห่งทวิภาวะอันเป็นนิรันดร์ของมหาจักรวาล:
- **สีขาว:** ตัวแทนของแสงสว่าง กลางวัน ความบริสุทธิ์ เทวธรรม (Dharma) และพลังฝ่ายเทพ
- **สีดำ:** ตัวแทนของความมืดมิด ราตรี ตัณหา อธรรม (Adharma) และพลังฝ่ายอสูร (Bhuta Kala) [115]

การที่เปอจาลังนุ่งห่มผ้าโพลเลงขาวดำมิได้หมายถึงการเลือกข้างฝ่ายขาวเพื่อเข่นฆ่าทำลายฝ่ายดำ หากแต่หมายถึง **"การยืนหยัดอยู่ตรงจุดกึ่งกลางของจักรวาลเพื่อควบคุมและถ่วงดุลพลังงานทั้งสองฝ่ายให้ดำรงอยู่ในสภาวะสมดุล"** เปอจาลังจึงทำหน้าที่เป็นดั่งสะพานเชื่อมระหว่างโลกมนุษย์กับโลกทิพย์ เพื่อสะกดมิให้พลังงานฝ่ายลบเข้ามารบกวนมณฑลพิธี [116]

#### 2. ผ้าสะบัดโพลเลง (Saput Poleng) และผ้าคาดเอวสีแดง (Selendang Merah)
ทับเหนือผ้าโสร่งโพลเลง จะมีผ้าสะบัดผืนสั้น (Saput) ขลิบชายด้วยสีแดง หรือคาดทับด้วยผ้าผูกเอวสีแดงสด (Selendang / Sabuk Merah) สีแดงคือสีประจำทิศทักษิณ (ทิศใต้ / Kelod) อันเป็นทิศแห่งพระพรหมและพระอัคนี สื่อถึงพลังงานความร้อน ความเด็ดขาด และความกล้าหาญในการเผชิญหน้ากับภยันตราย [117]

#### 3. ผ้าโพกศีรษะอูเด็ง (Udeng / Destar) และดอกชบาแดงทัดหู
เปอจาลังจะต้องโพกศีรษะด้วยผ้า **"อูเด็ง" (Udeng)** ซึ่งพับและผูกปมไว้ตรงกึ่งกลางหน้าผาก ชี้ปลายขึ้นสู่เบื้องบน แสดงถึงการรวมศูนย์สมาธิ สติปัญญา และการควบคุมความคิดมิให้ฟุ้งซ่านไปตามอารมณ์ [118] 

ที่ใบหูข้างขวา เปอจาลังจะทัดดอกไม้สดสีแดงเข้ม โดยเฉพาะอย่างยิ่ง **"ดอกชบาแดง" (Bunga Pucuk Rejasa หรือ Pucuk Bang)** [119] ดอกชบาแดงเป็นพฤกษาสัญลักษณ์แห่งพระอัคนีและพลังอำนาจในการขับไล่เสนียดจัญไร การทัดดอกชบาแดงสะท้อนถึงการอุทิศตนเป็น "เปองายะฮ์" (Pengayah) หรือผู้ยอมเสียสละตนเองเพื่อพิทักษ์ศาสนา ชุมชน และราชสำนัก [120]

#### 4. พระแสงกริชศักดิ์สิทธิ์ (Keris Pusaka) และยุทธวิธี "เมอปาซัง บาดัน"
อาวุธสำคัญเพียงหนึ่งเดียวที่เปอจาลังพกพาติดตัวคือ **"พระแสงกริชศักดิ์สิทธิ์" (Keris Pusaka)** ซึ่งจะเหน็บไว้ที่ด้านหลังตรงบั้นเอวเสมอ ตามแบบแผนของนักรบวรรณะกษัตริย์ในปูรีโบราณ [121] กริชในวัฒนธรรมบาหลีมิใช่อาวุธสำหรับทำร้ายร่างกายทางกายภาพเป็นหลัก หากแต่เป็น "วัตถุมงคลประจำกาย" ที่บรรจุพลังจิตวิญญาณแห่งบรรพบุรุษและมนตราคุ้มครองกาย [122]

ในด้านยุทธวิธี เปอจาลังยึดถือหลักการ **"เมอปาซัง บาดัน" (Mepasang Badan)** หรือ "การเอาสรีระร่างกายเข้าแลก" [123] เปอจาลังจะใช้การยืนตระหง่าน การจ้องมองด้วยสายตาอันแน่วแน่ และการเจรจาด้วยวาจาอันสุภาพแต่เด็ดขาด (Soft Approach) ภายใต้เกราะกำบังแห่งผ้าโพลเลงและบารมีจารีต โดยไม่ใช้อาวุธปืนหรือกระบองทำร้ายผู้คน ยุทธวิธีนี้ทำให้เปอจาลังสามารถควบคุมฝูงชนเรือนหมื่นในงานพระราชพิธีหลวงได้อย่างสงบราบรื่น [124]

### 5.7.4 บทบาทในการควบคุมพื้นที่พิธีกรรมและมาตรการวันเญอปิ (Hari Raya Nyepi): จาตูร์ บราตา เปอนเยอเปียน และตารางเปรียบเทียบสถาบันความมั่นคงจารีตนูซันตารา

บทบาทการควบคุมพื้นที่ทางกายภาพและจิตวิญญาณที่ยิ่งใหญ่และน่าเกรงขามที่สุดของเปอจาลัง ปรากฏให้เห็นใน **"วันเญอปิ" (Hari Raya Nyepi)** หรือวันขึ้นปีใหม่ตามปฏิทินศักราชสกะ (Tahun Baru Saka) ซึ่งตรงกับวันแรม 1 ค่ำ เดือน 10 (Sasih Kedasa) [125]

ในวันเญอปิ เกาะบาหลีทั้งเกาะจะหยุดชะงักการดำเนินกิจกรรมทุกชนิด สนามบินนานาชาติ ท่าเรือ ถนนหนทาง และตลาดร้านค้าจะถูกปิดสนิทเป็นเวลา 24 ชั่วโมง (ตั้งแต่ 06.00 น. ของวันเญอปิ ถึง 06.00 น. ของวันรุ่งขึ้น) เพื่อให้ชาวบาหลีปฏิบัติธรรมตามข้อห้ามศักดิ์สิทธิ์ 4 ประการ เรียกว่า **"จาตูร์ บราตา เปอนเยอเปียน" (Catur Brata Penyepian)** [126]:
1. **อมาตี เกอนี (Amati Geni):** ข้อห้ามจุดไฟ ห้ามเปิดไฟส่องสว่าง ห้ามก่อเพลิง ห้ามใช้อุปกรณ์ที่ก่อให้เกิดประกายไฟหรือความร้อน เพื่อดับไฟแห่งกิเลสตัณหาในจิตใจ
2. **อมาตี การ์ยา (Amati Karya):** ข้อห้ามทำงาน ห้ามประกอบสัมมาอาชีพ ห้ามดำเนินกิจกรรมทางเศรษฐกิจหรือกิจการทางโลกย์ทุกชนิด เพื่อให้ร่างกายและจิตใจได้พักผ่อนและใคร่ครวญ
3. **อมาตี เลอลุงงัน (Amati Lelungan):** ข้อห้ามเดินทาง ห้ามสัญจร ห้ามออกจากเคหสถานหรือขอบเขตรั้วบ้านโดยเด็ดขาด
4. **อมาตี เลอลังกูวัน (Amati Lelanguan):** ข้อห้ามสนุกสนานรื่นเริง ห้ามจัดงานเลี้ยงสังสรรค์ ห้ามเปิดเพลงหรือโทรทัศน์ ห้ามส่งเสียงดัง เพื่อรักษาสภาวะความสงบสงัดสูงสุด [127]

ในวันดังกล่าว **เปอจาลังคือกองกำลังเพียงกลุ่มเดียวที่ได้รับอนุญาตให้เดินตรวจตราบนท้องถนนได้** พวกเขาจะเดินเท้าอย่างเงียบกริบไปตามตรอกซอกซอยและแนวพรมแดนหมู่บ้าน หากพบบ้านใดเปิดไฟเล็ดลอดออกมา หรือมีบุคคลใดฝ่าฝืนเดินออกมาบนถนน เปอจาลังจะเข้าไปตักเตือนและนำตัวกลับเข้าบ้านทันที หรือหากมีการขัดขืนอย่างรุนแรง จะถูกนำตัวไปลงโทษตามกฎหมายจารีต (Awig-awig) ของเดซาอาดัต [128]

ในเชิงจักรวาลวิทยา การลาดตระเวนของเปอจาลังในคืนวันเญอปิมีเป้าหมายเพื่อ **"แปลงสภาพเกาะบาหลีทั้งเกาะให้กลายเป็นเกาะร้างที่เงียบสงัดและมืดสนิท"** เพื่อลวงหลอกให้เหล่าภูตผีปีศาจและอสูรร้าย (Bhuta Kala) ที่กำลังลอยผ่านท้องฟ้าในวันเปลี่ยนผ่านศักราช หลงคิดว่าเกาะบาหลีไม่มีมนุษย์อาศัยอยู่อีกต่อไป แล้วลอยพ้นข้ามเกาะไปสู่ห้วงมหาสมุทรลึก การควบคุมพื้นที่ของเปอจาลังจึงเป็นปราการด่านสุดท้ายที่ปกป้องความบริสุทธิ์ของจักรวาลบาหลีไว้ได้อย่างสมบูรณ์แบบ [129]
