# บทที่ 6: บทวิเคราะห์เปรียบเทียบเชิงลึก 4 ภูมิวัฒนธรรมราชมนเทียร (Comparative Monograph: Malay, Javanese, Sundanese, Balinese Court Systems)

## 6.1 บทนำและระเบียบวิธีวิจัยเปรียบเทียบเชิงลึกข้ามวัฒนธรรม (Comparative Methodology)

การศึกษาระบบราชมนเทียรและสถาบันพระมหากษัตริย์ในภูมิภาคเอเชียตะวันออกเฉียงใต้ภาคพื้นสมุทร หรือ "โลกนูซันตารา" (Nusantara) มักเผชิญกับความท้าทายเชิงทฤษฎีและระเบียบวิธีวิจัยสองขั้วตรงข้ามที่สร้างความบิดเบือนต่อข้อเท็จจริงทางประวัติศาสตร์ ประการแรกคือ "แนวคิดแบบเอกภาพนิยมเชิงนามธรรม" (Abstract Universalism) ซึ่งพยายามจัดประเภทราชสำนักในหมู่เกาะทั้งหมดให้อยู่ภายใต้กรอบคำอธิบายเดียว เช่น คติ "เทวราช" (Devaraja) ของอินเดีย หรือคติ "มัณฑละ" (Mandala) โดยละเลยความแตกต่างอันลึกซึ้งทางภววิทยาและพัฒนาการเฉพาะถิ่น ประการที่สองคือ "แนวคิดแบบแบ่งแยกเฉพาะส่วนนิยม" (Hyper-particularism) ที่มองแต่ละวัฒนธรรมอย่างตัดขาดจากกัน ละเลยปฏิสัมพันธ์ทางทะเล การแลกเปลี่ยนทางการทูต และสายใยทางวัฒนธรรมที่เชื่อมร้อยภูมิภาคนี้เข้าด้วยกันมานานนับพันปี [1] 

บทวิเคราะห์เปรียบเทียบในบทที่ 6 นี้จึงถูกออกแบบขึ้นเพื่อก้าวข้ามข้อจำกัดดังกล่าว โดยอาศัยระเบียบวิธีวิจัยเปรียบเทียบเชิงประวัติศาสตร์และมานุษยวิทยาเชิงโครงสร้าง (Comparative Historical and Structural Anthropology) เพื่อสำรวจความสัมพันธ์อันซับซ้อนระหว่าง 4 ภูมิวัฒนธรรมราชสำนักหลัก ได้แก่ **มลายู (Melayu), ชวา (Jawa), ซุนดา (Sunda), และบาหลี (Bali)** ซึ่งต่างมีวิวัฒนาการ รอยต่อทางประวัติศาสตร์ และการปรับแปลงเชิงสถาบันที่เป็นเอกลักษณ์เฉพาะของตนเอง [2]

### 6.1.1 หลักการเปรียบเทียบแบบไม่ปะปน: ความเหมือนเชิงรูปแบบ (Morphological Parallels) vs. ความต่างเชิงรากฐานภววิทยา (Ontological Divergences)

หัวใจสำคัญของระเบียบวิธีวิจัยเปรียบเทียบในงานชิ้นนี้ คือการสถาปนา "หลักการเปรียบเทียบแบบไม่ปะปน" (Principle of Non-conflationary Comparison) เพื่อทำหน้าที่เป็นเครื่องมือคัดกรองและป้องกันข้อผิดพลาดทางวิชาการว่าด้วย **"ซิงเครติสม์ผิวเผิน" (Superficial Syncretism)** [3] ข้อผิดพลาดดังกล่าวมักเกิดขึ้นเมื่อนักวิชาการสังเกตเห็นความคล้ายคลึงกันของปรากฏการณ์ทางกายภาพภายนอก แล้วด่วนสรุปว่าระบบคิด เทววิทยา และโครงสร้างอำนาจเบื้องหลังปรากฏการณ์เหล่านั้นเป็นสิ่งเดียวกัน การวิเคราะห์เชิงวิพากษ์จำต้องแยกแยะระหว่างสองระนาบอย่างเด็ดขาด:

```
+---------------------------------------------------------------------------------------------------+
|               กรอบการวิเคราะห์เปรียบเทียบ: รูปแบบสัณฐานภายนอก ปะทะ รากฐานภววิทยาภายใน            |
+---------------------------------------------------------------------------------------------------+
|  [ ระนาบสัณฐานวิทยาภายนอก: ความเหมือนเชิงรูปแบบ ]   |  [ ระนาบภววิทยาภายใน: ความต่างเชิงรากฐาน ]  |
|  (Morphological Parallels)                          |  (Ontological Divergences)                  |
|                                                     |                                             |
|  1. ศาลาเปิดโล่งไร้ผนัง (Open Pavilion System)      |  - มลายู: บาไล (Balai) ว่าราชการ/รับเสด็จ   |
|     - Balai / Pendopo / Bale                        |  - ชวา: เปอนโดโป สะท้อนบารมีและระงับอารมณ์  |
|     - รองรับลมมรสุมและชุมนุมชน                      |  - ซุนดา: ซาเล บังหาร์ ดุลยภาพสามเส้า       |
|                                                     |  - บาหลี: บาเล พิธีกรรมตามสัดส่วนร่างกาย    |
|                                                     |                                             |
|  2. ลานสาธารณะหน้าพระราชฐาน (Grand Court Square)    |  - มลายู: ปาดัง (Padang) ชุมนุมไพร่พล/การค้า |
|     - Padang / Alun-alun / Lapangan Puputan         |  - ชวา: อาลุน-อาลุน คติโลกียะปะทะโลกุตตระ   |
|     - พื้นที่รอยต่อระหว่างวังกับเมือง                |  - ซุนดา: ลานหน้าอาลุน-อาลุน ดุลยภาพเมืองท่า |
|                                                     |  - บาหลี: ลานหน้าวัง ชุมนุมนาฏกรรมรณยัชญะ   |
|                                                     |                                             |
|  3. กำแพงและป้อมค่ายหลายชั้น (Concentric Enclosures) |  - มลายู: โกตา (Kota) ป้องกันการโจมตีทางน้ำ |
|     - Kota / Baluwarti / Beteng / Kuta Puri         |  - ชวา: บาลูวาร์ตี กำแพงสะท้อนชั้นจักรวาล    |
|     - การแบ่งโซนศักดิ์สิทธิ์และโลกียะ               |  - ซุนดา: กำแพงอิฐแดงปูนปั้นพิทักษ์ซูฟี     |
|                                                     |  - บาหลี: กำแพงคูตา กั้นเขตภูเขากับทะเล      |
+---------------------------------------------------------------------------------------------------+
```

ประการแรก **ความเหมือนเชิงรูปแบบ (Morphological Parallels)** เกิดขึ้นจากปัจจัยร่วมทางระบบนิเวศเขตร้อนชื้น (Tropical Rainforest Climate), ปัญหาทางวิศวกรรมร่วมกันในการระบายความร้อนและความชื้น, ตลอดจนการถ่ายทอดวิทยาการช่างไม้และอิฐปูนของกลุ่มภาษาตระกูลออสโตรนีเซียน (Austronesian Architectural Heritage) [4] ส่งผลให้ทั้ง 4 วัฒนธรรมมีองค์ประกอบทางกายภาพร่วมกันอย่างเด่นชัด เช่น การสร้างอาคารทรงศาลาเปิดโล่งไร้ฝาผนังทึบ (เสาและหลังคาลาดชันสูง), การจัดวางลานกว้างด้านหน้าพระราชวังเพื่อเป็นพื้นที่เปลี่ยนผ่านระหว่างฝ่ายในกับสาธารณชน, และการสร้างแนวกำแพงล้อมรอบหลายชั้นเพื่อคัดกรองการเข้าถึงตามลำดับขั้น [5]

ประการที่สอง **ความต่างเชิงรากฐานภววิทยา (Ontological Divergences)** คือระบบจักรวาลทัศน์ ปรัชญาความชอบธรรม และเทววิทยาที่สถิตอยู่เบื้องหลังรูปแบบกายภาพเหล่านั้น ซึ่งมีความแตกต่างกันอย่างมีนัยสำคัญ:
1. *ราชมนเทียรมลายู (Istana Melayu):* ขับเคลื่อนด้วยภววิทยาแบบ **เอกเทวนิยมอิสลามซุนนี (Sunni Islamic Monotheism)** ภายใต้นิติศาสตร์มัซฮับชาฟิอีและเทววิทยาอัชอารียะฮ์ ผสานเข้ากับมโนทัศน์ "เงาแห่งพระผู้เป็นเจ้าในโลกมนุษย์" (*Zillullah fi al-'Alam*) โดยแปลงสภาพอำนาจเวทมนตร์ดั้งเดิมของหมอผีหลวง (*Pawang*) ให้อยู่ใต้กรอบบุญบารมี (*Daulat*) ที่อัลลอฮ์ทรงประทานแก่องค์สุลต่าน [6]
2. *กะราตอนชวา (Kraton Jawa):* ขับเคลื่อนด้วยภววิทยาแบบ **รหัสยิกซูฟี-ฮินดูชวา (Kejawen / Wahdat al-Wujud)** ซึ่งหลอมรวมปรัชญาเอกภาพแห่งการดำรงอยู่ของอิบนุ อะรอบี เข้ากับคติเอกนิยมบริสุทธิ์ของอินเดียโบราณ จนตกผลึกเป็นมโนทัศน์ *Manunggaling Kawula Gusti* (การรวมเป็นหนึ่งระหว่างข้าแผ่นดินกับเจ้านาย/พระผู้เป็นเจ้า) ผูกโยงกับแสงฉัพพรรณรังสีแห่งสวรรค์ (*Wahyu*) และพันธสัญญาการสมรสทิพย์กับราชินีทะเลใต้ [7]
3. *กะราตอนซุนดา (Kraton Sunda):* ขับเคลื่อนด้วยภววิทยาแบบ **ไตรภาคดุลยภาพแห่งอำนาจ (Tritangtu di Buana)** ซึ่งสืบทอดมาจากคติความเชื่อดั้งเดิม *Sunda Wiwitan* และคัมภีร์ใบลานโบราณ โดยปฏิเสธอำนาจเผด็จการเบ็ดเสร็จเด็ดขาดของกษัตริย์ และวางดุลยภาพคานอำนาจอย่างเคร่งครัดระหว่าง ผู้นำจิตวิญญาณ (Resi), ฝ่ายบริหารปกครอง (Prabu), และผู้นำชุมชน/ราษฎร (Rama) ก่อนจะผสมผสานเข้ากับรหัสยศาสตร์ซูฟีชัดฏารียะฮ์ในจิเรโบนและนิติศาสตร์อิสลามในบันเติน [8]
4. *ปูรีบาหลี (Puri Bali):* ขับเคลื่อนด้วยภววิทยาแบบ **พหุเทววิทยา-ศิวะพุทธ (Siwa-Buddha Polytheism)** ภายใต้ปรัชญาธรรมชาตินิยม *Tri Hita Karana* และทวิภาวะ *Rwa Bhineda* ที่มองว่าจักรวาลดำรงอยู่ได้ด้วยการประคับประคองพลังสองขั้วตรงข้าม กษัตริย์มิได้ทรงอำนาจผ่านการบังคับบัญชาทางทหารหรือเศรษฐกิจ หากแต่ดำรงสถานะเป็น "ราชาธิบดีแห่งรัฐนาฏกรรม" (The Lord of the Theatre State) ผู้จัดแสดงพิธีกรรมอันวิจิตรเพื่อถวายเป็นเครื่องบูชาแก่ทวยเทพและพิทักษ์ระเบียบจักรวาล [9]

เพื่อเป็นแกนกลางในการวิเคราะห์เปรียบเทียบเชิงวิพากษ์อย่างเป็นระบบ งานวิจัยนี้ได้สถาปนากรอบมโนทัศน์ **"10 มิติราชมนเทียรศึกษาแห่งนูซันตารา" (The Ten Dimensions of Nusantara Royal Court Studies)** ขึ้นเป็นเกณฑ์มาตรฐาน:

```
+---------------------------------------------------------------------------------------------------+
|                     กรอบ 10 มิติราชมนเทียรศึกษาแห่งนูซันตารา (The Ten Dimensions)                 |
+---------------------------------------------------------------------------------------------------+
|  1. ภววิทยาและเทววิทยาแห่งอำนาจ (Ontology & Theology of Sovereignty)                              |
|  2. พันธสัญญาทางสังคมและความชอบธรรม (Social Contract & Royal Legitimacy)                          |
|  3. จักรวาลวิทยาและการจัดวางผังเชิงพื้นที่ (Cosmology & Spatial Morphology)                       |
|  4. แกนศักดิ์สิทธิ์และขั้วเชิงสัญลักษณ์ (Sacred Axes & Symbolic Polarities)                        |
|  5. สัณฐานวิทยาสถาปัตยกรรมและวัสดุ (Architectural Typology & Materiality)                        |
|  6. วิศวกรรมน้ำและนิเวศภูมิทัศน์ (Water Engineering & Eco-hydrology)                             |
|  7. สัตถุปัญญาและเครื่องราชกกุธภัณฑ์ (Regalia, Pusaka & Material Agency)                         |
|  8. ดุริยางค์หลวงและนาฏยพิธีกรรม (Court Musicology & Sacred Choreography)                         |
|  9. ระบบเครือญาติและการสืบราชสมบัติ (Kinship, Succession & Gender Dynamics)                       |
|  10. ภูมิรัฐศาสตร์และการปรับตัวรับมือภัยคุกคาม (Geopolitics & Colonial Encounters)                |
+---------------------------------------------------------------------------------------------------+
```

### 6.1.2 ภูมิรัฐศาสตร์และปฏิสัมพันธ์เชิงอำนาจระหว่าง 4 มณฑลวัฒนธรรม

ประวัติศาสตร์ของภูมิภาคอุษาคเนย์ภาคพื้นสมุทรคือประวัติศาสตร์แห่งการแลกเปลี่ยน ความขัดแย้ง และการดูดซับทางวัฒนธรรมผ่านเส้นทางเดินเรือข้ามสมุทร แผนที่ภูมิรัฐศาสตร์ของทั้ง 4 มณฑลวัฒนธรรมถูกกำหนดด้วยกระแสน้ำมรสุมและช่องแคบยุทธศาสตร์สำคัญสองแห่ง ได้แก่ ช่องแคบมะละกา (เชื่อมมหาสมุทรอินเดียกับทะเลจีนใต้) และช่องแคบซุนดา (เชื่อมมหาสมุทรอินเดียกับทะเลชวา) ก่อให้เกิดพลวัตทางประวัติศาสตร์สามระลอกใหญ่:

ประการแรก **เครือข่ายพาณิชย์นาวีข้ามสมุทร:** นครรัฐมลายู (เช่น มะละกา, ปัตตานี, ยะโฮร์) อาศัยชัยภูมิปากแม่น้ำควบคุมการเดินเรือระหว่างจีน อินเดีย และตะวันออกกลาง ขณะที่ราชสำนักชวาตอนกลางและตะวันออก (เช่น มาตารัม, มัชปาหิต) ผสานเศรษฐกิจเกษตรกรรมลุ่มน้ำขนาดใหญ่เข้ากับการค้าข้าวทางเรือ สุรโซวันแห่งบันเตินและกะราตอนจิเรโบนในดินแดนซุนดาทำหน้าที่เป็นจุดเชื่อมโยงระหว่างเส้นทางเดินเรือเลียบชายฝั่งตะวันตกของสุมาตรากับทะเลชวา ส่วนปูรีบาหลีเป็นสถานีการค้าฝ้าย ข้าว ทาส และเครื่องเทศทางตอนใต้ของแนวหมู่เกาะซุนดาน้อย [10] การหมุนเวียนของสินค้าเหล่านี้มิได้เกิดขึ้นในสุญญากาศ หากแต่นำมาซึ่งการแลกเปลี่ยนช่างฝีมือ ปัญญานิพนธ์ทางศาสนา และรูปแบบสถาปัตยกรรมระหว่างราชสำนักตลอดเวลา

ประการที่สอง **มรดกและความทรงจำร่วม: วงไพบูลย์แห่งมัชปาหิตและศรีวิชัย:** ก่อนการเข้ามาของอิสลาม จักรวรรดิศรีวิชัย (Srivijaya) จากเกาะสุมาตราได้วางรากฐาน "วัฒนธรรมมลายูชั้นสูง" และโครงข่ายการค้าทางทะเลที่ครอบงำช่องแคบมะละกาและคาบสมุทรมลายู [11] ต่อมาในคริสต์ศตวรรษที่ 14 มหาจักรวรรดิมัชปาหิต (Majapahit) ภายใต้การนำของมหาอัครมหาเสนาบดีคชมาดา (Gajah Mada) และคำสาบานปาลปา (Sumpah Palapa) ได้แผ่ขยายแสนยานุภาพและอิทธิพลทางวัฒนธรรมครอบคลุมทั่วทั้งนูซันตารา มัชปาหิตส่งสายเลือดกษัตริย์ศรีเกรศนา เกอปากีซัน ข้ามไปปกครองบาหลีในปี ค.ศ. 1343 ทำให้ราชสำนักบาหลียึดถือตนเองเป็น "ทายาทสายตรงผู้บริสุทธิ์ของมัชปาหิต" (Wong Majapahit) สืบมาจนปัจจุบัน [12] ในทางตรงกันข้าม ความสัมพันธ์ระหว่างมัชปาหิตกับอาณาจักรซุนดา ปาจาจารัน กลับเต็มไปด้วยบาดแผลทางประวัติศาสตร์จาก "โศกนาฏกรรมปาสุนดา บูบัต" (Tragedi Pasunda Bubat ค.ศ. 1357) ซึ่งกองทัพมัชปาหิตได้สังหารหมู่ราชวงศ์ซุนดา ณ ทุ่งบูบัต ส่งผลให้อัตลักษณ์ราชสำนักซุนดามุ่งเน้นการธำรงเอกราชและความเป็นปฏิปักษ์ต่ออำนาจชวาอย่างเหนียวแน่น [13]

ประการที่สาม **ระลอกคลื่นการเปลี่ยนผ่านทางศาสนา:** ในช่วงคริสต์ศตวรรษที่ 14 ถึง 16 การแผ่ขยายของศาสนาอิสลามได้เปลี่ยนโฉมหน้าภูมิทัศน์ความชอบธรรมของราชสำนักนูซันตาราอย่างถอนรากถอนโคน เมืองท่าชายฝั่งทะเล เช่น ปาไซ, มะละกา, เดอมัก, บันเติน, และจิเรโบน ได้รับอิสลามและยกเลิกคติเทวราชดั้งเดิม หันมารับตำแหน่ง "สุลต่าน" และ "ซูนัน" ภายใต้ร่มเงาของอัลลอฮ์ [14] การเปลี่ยนผ่านนี้แบ่งแยกโลกนูซันตาราออกเป็นสองขั้วทางศาสนา: ราชสำนักมลายู ชวา และซุนดา ได้หลอมรวมเข้าสู่อารยธรรมอิสลาม (แม้จะมีเฉดความเข้มงวดและการผสานความเชื่อเดิมที่ต่างกัน) ในขณะที่เกาะบาหลีปฏิเสธการเข้ารีต และกลายเป็นปราการด่านสุดท้ายที่รักษา อนุรักษ์ และพัฒนาอารยธรรมฮินดู-พุทธแบบชวาโบราณให้มีชีวิตชีวาสืบเนื่องต่อมาอีกหลายร้อยปี [15]

## 6.2 การเปรียบเทียบปรัชญาและรากฐานความชอบธรรมแห่งอำนาจ (Comparative Sovereignty & Royal Legitimacy)

### 6.2.1 มโนทัศน์อำนาจสูงสุดและพันธสัญญาทางสังคม (The Concept of Supreme Power & Social Contract)

สถาบันพระมหากษัตริย์ในทั้ง 4 ภูมิวัฒนธรรมมิได้สถาปนาอำนาจขึ้นบนพื้นฐานของการใช้อำนาจดิบเถื่อนทางกายภาพ (Raw Coercion) หากแต่วางอยู่บนระบบจักรวาลทัศน์และสัญญาประชาคมเชิงจารีตที่ซับซ้อน ซึ่งกำหนดสิทธิ หน้าที่ และขอบเขตแห่งอำนาจระหว่างผู้ปกครองกับผู้ใต้ปกครองไว้อย่างแยบยล:

#### 1. วัฒนธรรมมลายู (Melayu): ดาอูลัต, เดอร์ฮากา, เลือดสีขาว, และพันธสัญญาบนเขามหาเมรุ
ในโลกทัศน์มลายู พระราชอำนาจสูงสุดขององค์สุลต่านถูกนิยามผ่านคำสอนเรื่อง **"ดาอูลัต" (Daulat)** ซึ่งมีรากศัพท์มาจากภาษาอาหรับ *Dawlah* (แปลว่า การหมุนเวียนแห่งอำนาจ หรือรัฐ) แต่วัฒนธรรมมลายูได้ปรับแปลงความหมายให้กลายเป็น "พระบารมีอำนาจศักดิ์สิทธิ์อันล่วงละเมิดมิได้" [16] วอลเตอร์ วิลเลียม สกีต (Walter William Skeat, 1900) อธิบายว่า ดาอูลัตในราชสำนักมลายูดำรงอยู่ประดุจ "กระแสพลังงานเหนือธรรมชาติ" ที่แผ่ซ่านออกจากพระวรกายของกษัตริย์ เครื่องราชกกุธภัณฑ์ และราชสาส์น หากสามัญชนผู้ใดล่วงละเมิด แตะต้อง หรือทำเทียมเลียนแบบ บุคคลผู้นั้นจะต้องประสบกับภาวะ **"เกอนาเดาลัต" (*kena daulat*)** หรือ **"ตูลาฮัน" (*tulah*)** ส่งผลให้ล้มป่วยเฉียบพลัน คลุ้มคลั่ง อาเจียนเป็นโลหิต หรือถึงแก่ความตายในทันที [17]

คู่ตรงข้ามของดาอูลัตคือมโนทัศน์เรื่อง **"เดอร์ฮากา" (Derhaka)** ซึ่งหมายถึง บาปมหันต์แห่งการกบฏ ทรยศ กระด้างกระเดื่อง หรือล่วงละเมิดต่อองค์พระมหากษัตริย์ ในพงศาวดาร *มลายู ฮิกายัต ฮังตัวะฮ์* (Hikayat Hang Tuah) ฮังตัวะฮ์ได้กล่าววาทะอมตะที่สะท้อนถึงการยอมจำนนต่อดาอูลัตอย่างสิ้นเชิงว่า *"Pantang Melayu Menderhaka"* (ชาวมลายูย่อมไม่ก่อการกบฏทรยศเป็นอันขาด) แม้ตนเองจะถูกองค์สุลต่านสั่งประหารชีวิตอย่างไม่เป็นธรรมก็ตาม [18] ความชอบธรรมนี้ได้รับการเสริมส่งด้วยความเชื่อเรื่อง **"เลือดสีขาว" (Darah Putih)** ซึ่งเป็นสัญลักษณ์แห่งสายพระโลหิตบริสุทธิ์เหนือมนุษย์ปุถุชน ดังปรากฏในตำนานพระนางมะซูรีแห่งลังกาวี และการสืบสายเลือดของราชวงศ์มลายูโบราณ [19]

อย่างไรก็ตาม พระราชอำนาจมลายูมิได้เป็นอำนาจเผด็จการเบ็ดเสร็จอย่างไร้ขอบเขต หากแต่ผูกพันอยู่กับ **"พันธสัญญาดั้งเดิม" (*Wa'ad*)** ซึ่งปรากฏในคัมภีร์ *ซูลาลาตุส ซาลาติน* (Sulalat al-Salatin หรือ Sejarah Melayu) ระหว่าง **เสรีตรีภูวนะ (Sri Tri Buana / Sang Sapurba)** ปฐมกษัตริย์ผู้เสด็จจุติลงมาจากสวรรค์ กับ **เดอมัง เลอบาร์ ดาวน์ (Demang Lebar Daun)** ผู้นำชนพื้นเมืองบนเนินเขาบูกิตซีกุนตัง (Bukit Seguntang) [20] ฟาริช นูร์ (Farish Noor, 2023) ชี้ให้เห็นว่า พันธสัญญานี้คือรากฐานของ "สัญญาประชาคมมลายู" (Malay Social Contract) โดยมีข้อตกลงสองฝ่าย:
- *ฝ่ายข้าแผ่นดิน:* สัญญาว่าจะจงรักภักดีต่อองค์กษัตริย์และเชื้อพระวงศ์อย่างถึงที่สุด ไม่ก่อการกบฏ (*derhaka*) แม้กษัตริย์จะประพฤติชั่วช้าประการใด ก็ให้พระองค์เผชิญกับพระพิโรธของพระผู้เป็นเจ้าเอง
- *ฝ่ายองค์กษัตริย์:* สัญญาว่าจะไม่ลบหลู่ดูหมิ่น ประจาน หรือเหยียดหยาม (*menista*) ข้าแผ่นดิน แม้ผู้นั้นจะกระทำความผิดร้ายแรงถึงขั้นประหารชีวิต ก็ให้ประหารตามบทบัญญัติแห่งกฎหมาย แต่ห้ามประจานให้อับอายขายหน้าต่อธารกำนัลเป็นอันขาด
- *เงื่อนไขการละเมิด:* หากกษัตริย์ตระบัดสัตย์ ละเมิดสัญญาประชาคมด้วยการลบหลู่เหยียดหยามราษฎร พันธสัญญาจะถือเป็นโมฆะ พระผู้เป็นเจ้าจะถอนพระพร และอาณาจักรจะต้องประสบกับความพินาศล่มจม ดังกรณีการล่มสลายของสิงคโปร์โบราณเมื่อราชาประจานบุตรสาวของเสนาบดี [21]

#### 2. วัฒนธรรมชวา (Jawa): มานุงกาลิง กาวูลา กุสตี, วะฮ์ยู กษัตริย์, และพระสวามีทิพย์แห่งรตูคิดุล
ในกระบวนทัศน์ราชสำนักชวา อำนาจสูงสุดมิได้เกิดจากสัญญาทางกฎหมาย แต่เกิดจากความสอดคล้องกับระเบียบจักรวาล แกนกลางแห่งอภิปรัชญาชวาคือมโนทัศน์ **"มานุงกาลิง กาวูลา กุสตี" (Manunggaling Kawula Gusti)** ซึ่งแปลตามตัวอักษรว่า "การหลอมรวมเป็นหนึ่งเดียวระหว่างข้าผู้เป็นบ่าว (Kawula) กับองค์เจ้านาย (Gusti)" [22] โซมาร์ไซด์ มัวร์โตโน (Soemarsaid Moertono, 1968) และคลิฟฟอร์ด เกียร์ตซ์ (Clifford Geertz, 1960) ได้วิเคราะห์ว่า ปรัชญานี้ทำหน้าที่ใน 2 ระดับที่ซ้อนทับกัน:
1. *ระดับเทววิทยา:* เอกภาพระหว่างจิตวิญญาณมนุษย์กับพระผู้เป็นเจ้า (*Gusti Allah*) ตามแนวคิดรหัสยิกซูฟี *Wahdat al-Wujud*
2. *ระดับการเมือง:* เอกภาพอินทรียภาพ (Organic Unity) ระหว่าง "อาณาประชาราษฎร์" (*kawula*) กับ "องค์พระมหากษัตริย์" (*Gusti*) รัฐมิได้ประกอบด้วยปัจเจกชนที่แปลกแยก แต่เป็นร่างกายที่มีชีวิต กษัตริย์เปรียบเสมือนศีรษะและดวงวิญญาณ ราษฎรเปรียบเสมือนแขนขา สองฝ่ายมิอาจดำรงอยู่ได้โดยปราศจากกันและกัน [23]

ความชอบธรรมของกษัตริย์ชวาขึ้นอยู่กับการครอบครอง **"วะฮ์ยู" (Wahyu)** หรือแสงฉัพพรรณรังสีศักดิ์สิทธิ์จากสวรรค์ (โดยเฉพาะ *Wahyu Cahyo Ningrat* หรือ *Wahyu Makutha Rama*) ปีเตอร์ แครีย์ (Peter Carey, 2007) ชี้ว่า วะฮ์ยูมิใช่กรรมสิทธิ์ทางสายเลือดที่ถาวร หากแต่เป็นพลังงานจักรวาลที่เคลื่อนย้ายได้ กษัตริย์จะทรงรักษาความชอบธรรมไว้ได้ก็ต่อเมื่อพระองค์ทรงปฏิบัติสมาธิภาวนา ชำระกิเลสตัณหา (*prihatin*) และบำเพ็ญตบะ หากกษัตริย์ประพฤติเสื่อมทราม ลุ่มหลงในกามคุณ หรือละเลยความยุติธรรม วะฮ์ยูจะหลุดลอยออกจากพระราชวัง (*wahyu oncat*) ปรากฏการณ์นี้จะสะท้อนออกมาผ่านภัยธรรมชาติ ข้าวยากหมากแพง โรคระบาด และกบฏ นำไปสู่การล่มสลายของราชธานีเดิมและการก่อตั้งราชวงศ์ใหม่ที่ได้รับวะฮ์ยูดวงใหม่ [24]

ยิ่งไปกว่านั้น องค์พระมหากษัตริย์ชวา (นับแต่สมัยสุลต่านอากุงแห่งมาตารัม) ทรงสถาปนาพระนามเป็น **"ซายิดิน ปานาตากามา คาลิฟาตุลลอฮ์" (Sayidin Panatagama Kalifatullah)** หมายถึง ผู้จัดระเบียบศาสนาและตัวแทนของพระผู้เป็นเจ้าบนหน้าพิภพ พร้อมกันนั้น พระองค์ยังต้องธำรงความสัมพันธ์ลี้ลับผ่านการเป็น **"พระสวามีทิพย์" (Spiritual Consort)** ของพระนาง **กันเจ็ง ราตู คิดุล (Kanjeng Ratu Kidul)** มหาราชินีแห่งทะเลใต้ [25] ความสัมพันธ์ทางกามารมณ์ทิพย์ (Hierogamy) ซึ่งจัดแสดงผ่านระบำศักดิ์สิทธิ์ *Bedhaya Ketawang* ทำหน้าที่เป็นหลักประกันว่า ราชสำนักชวาได้รับการคุ้มครองจากอำนาจดึกดำบรรพ์แห่งท้องทะเล ควบคู่ไปกับอำนาจทางจิตวิญญาณแห่งภูเขาไฟเมอราปีและพรแห่งอัลลอฮ์ [26]

#### 3. วัฒนธรรมซุนดา (Sunda): ปรัชญาตรีตังกูดีบัวนา, ปราบูสิลิวางี, และสัญศาสตร์เสือมงคล
แตกต่างจากโครงสร้างอำนาจรวมศูนย์แบบชวา อารยธรรมซุนดาโบราณวางรากฐานอยู่บนปรัชญา **"ตรีตังกู ดี บัวนา" (Tritangtu di Buana / Tritangtu di Bumi)** ซึ่งปรากฏในคัมภีร์ใบลานโบราณ *สังหยัง สิกขากานดัง กาเรสิยัน* (Sanghyang Siksakanda ng Karesian - ค.ศ. 1518) และ *อามานัต กาลุงกุง* (Amanat Galunggung) [27] แอนดรูว์ เวสต์ (Andrew West, 2021) และ ยาคอบ ซูมาร์โจ (Jakob Sumardjo) ชี้ให้เห็นว่า ตรีตังกูคือระเบียบการแบ่งแยกและคานอำนาจ 3 สถาบันหลักอย่างเคร่งครัด:

ในระบบตรีตังกู อำนาจของกษัตริย์ (Prabu / Ratu) มีขอบเขตจำกัดเฉพาะด้านการบริหารบ้านเมืองและการทหาร (*Bayu*) แต่ไม่มีอำนาจแก้ไขหลักศีลธรรม จิตวิญญาณ (*Hedap*) ซึ่งเป็นอาณัติของสถาบันนักบวช (Resi) และไม่สามารถละเมิดจารีตประเพณี วาจาสัจจะ และสิทธิของชุมชนพื้นบ้าน (*Sabda*) ซึ่งเป็นอาณัติของสภาผู้อาวุโสและราษฎร (Rama) ได้ [28] กษัตริย์ซุนดาจึงไม่เคยมีสถานะเป็นเทวราชผู้มีอำนาจเบ็ดเสร็จเด็ดขาด หากปราบูกระทำการอยุติธรรม ละเมิดศีลธรรม หรือกดขี่ราษฎร เรสิและรามะมีอำนาจทางจารีตในการตักเตือน ปฏิเสธการยอมรับ หรือขับไล่ออกจากตำแหน่ง ดุลยภาพสามเส้านี้คือเงื่อนไขเดียวที่จะนำมาซึ่ง "ความรอดพ้นและความผาสุก" (*Kasalametan*) ของแผ่นดิน [29]

ความชอบธรรมสูงสุดของราชสำนักซุนดาผูกพันอยู่กับภาพลักษณ์ในอุดมคติของ **พระเจ้าปราบู สิลิวางี (Prabu Siliwangi)** หรือศรีบาดูกา มหาราชา (Sri Baduga Maharaja, ครองราชย์ ค.ศ. 1482–1521) แห่งปากวัน ปาจาจารัน พระองค์ทรงได้รับการยกย่องเป็นกษัตริย์ผู้ทรงธรรม เปี่ยมด้วยความเมตตา และเป็นผู้นำที่ทำให้แผ่นดินซุนดาอุดมสมบูรณ์ [30] เมื่ออาณาจักรปาจาจารันเผชิญกับการรุกราน ตำนานระบุว่าปราบูสิลิวางีมิได้ยอมแพ้หรือยอมเข้ารีตเพื่อรักษาอำนาจ หากแต่พระองค์และข้าราชบริพารผู้ภักดีได้ทรงเลือกที่จะ "อันตรธานหายไปสู่มิติเร้นลับ" (*Ngahyang*) และจำแลงพระวรกายเป็น **"เสือมงคล" (Maung Lodaya / Harimau Pajajaran)** เพื่อสถิตอยู่ในป่าศักดิ์สิทธิ์และคอยคุ้มครองลูกหลานชาวซุนดาสืบไป สัญศาสตร์เสือมงคลจึงกลายเป็นสัญลักษณ์แห่งจิตวิญญาณอิสระ ศักดิ์ศรี และความชอบธรรมที่ไม่มีวันสูญสลายของชาวซุนดา [31]

#### 4. วัฒนธรรมบาหลี (Bali): ธรรมกษัตริย์, รัฐนาฏกรรม, อำนาจอธิปไตยคู่, และมหายัญรณยัชญะ
ในเกาะบาหลี สถาบันพระมหากษัตริย์ถูกจัดวางอยู่ภายใต้กรอบวรรณะฮินดูในฐานะ **"ธรรมกษัตริย์" (Dharma Ksatriya)** ผู้มีหน้าที่ปกป้องความสงบเรียบร้อย ค้ำจุนระเบียบสังคม และพิทักษ์พระศาสนา [32] คลิฟฟอร์ด เกียร์ตซ์ (Clifford Geertz, 1980) ได้เสนอทฤษฎีระดับอนุสรณ์สถานว่าด้วย **"รัฐนาฏกรรม" (Negara: The Theatre State)** เพื่ออธิบายธรรมชาติอำนาจของราชสำนักบาหลีในคริสต์ศตวรรษที่ 19 เกียร์ตซ์ชี้ว่า รัฐบาหลีมิได้มีเป้าหมายหลักในการบริหารราชการแผ่นดิน การเก็บภาษี หรือการระดมกำลังทหารแบบรัฐสมัยใหม่ หากแต่เป้าหมายสูงสุดของรัฐคือ **"การจัดแสดงพิธีกรรมทางศาสนาอันวิจิตรตระการตา" (Ritual Spectacle)**:

> *"อำนาจรับใช้พิธีกรรม มิใช่พิธีกรรมรับใช้อำนาจ... มหกรรมอันยิ่งใหญ่แห่งชีวิตในราชสำนักมิได้เป็นเพียงเครื่องมือเสริมสร้างอำนาจทางการเมือง หากแต่มันคือสาระสำคัญของรัฐบาลเอง รัฐนาฏกรรมแห่งบาหลีคือรัฐที่การแสดงออกทางพิธีกรรมเป็นเป้าหมายสูงสุดในตัวมันเอง"* [33]

ความชอบธรรมขององค์พระมหากษัตริย์หรือ **"เดวา อากุง" (Dewa Agung)** แห่งกลุงกุงและปูรีต่างๆ จึงขึ้นอยู่กับขีดความสามารถในการจัดพระราชพิธีหลวงอย่างมโหฬาร เช่น พิธีศพหลวงเผาพระศพบนหอเมรุบาเด (*Pelebon*), พิธีฉลองวัด (*Odalan*), และพิธีบวงสรวงชำระล้างจักรวาล (*Tawur Kesanga*) ยิ่งพิธีกรรมมีความประณีต อลังการ และมีผู้เข้าร่วมมากเพียงใด พระบารมีและความศักดิ์สิทธิ์ของกษัตริย์ก็ยิ่งแผ่ไพศาลมากเพียงนั้น [34]

อย่างไรก็ตาม โครงสร้างอำนาจของบาหลีมีลักษณะเด่นประการสำคัญคือ **"ทฤษฎีอำนาจอธิปไตยคู่" (Dual Sovereignty)** ระหว่างสองวรรณะสูงสุด [35]:
1. *เดวา อากุง (Dewa Agung / วรรณะกษัตริย์ - Satriya Dalem):* ผู้ครอบครองอำนาจทางโลก การบริหาร และการทหารในมิติ **"สกล" (Sakala)** หรือโลกกายภาพที่มองเห็นได้ มีพระราชวัง "ปูรี" (Puri) เป็นศูนย์กลาง
2. *เปอดันดา (Pedanda / วรรณะพราหมณ์ - Brahmana):* ผู้ครอบครองอำนาจทางจิตวิญญาณ มนตร์พระเวท น้ำทิพย์ศักดิ์สิทธิ์ (*Tirtha*) และความบริสุทธิ์ในมิติ **"นิสกละ" (Niskala)** หรือมิติเร้นลับที่มองไม่เห็น มีเคหสถาน "กริยา" (Grya) เป็นศูนย์กลาง

กษัตริย์บาหลีไม่อาจประกอบพิธีกรรมศักดิ์สิทธิ์ได้ด้วยพระองค์เอง หากปราศจากการประสิทธิพรและการร่ายพระเวทของเปอดันดา ขณะที่เปอดันดาก็ต้องพึ่งพาการอุปถัมภ์และการคุ้มครองทางกายภาพจากกษัตริย์ ความสัมพันธ์ระหว่างปูรีและกริยาจึงเป็นดุลยภาพค้ำจุนจักรวาลที่แยกจากกันมิได้ [36]

เมื่อเผชิญกับวิกฤตการณ์แห่งความพ่ายแพ้และการรุกรานจากภายนอก ราชสำนักบาหลีมีกลไกทางจิตวิญญาณขั้นสูงสุดในการพิทักษ์ความชอบธรรม นั่นคือมโนทัศน์ **"รณยัชญะ" (Rana Yadnya)** หรือการบูชายัญชีวิตในสนามรบ ซึ่งนำไปสู่ปรากฏการณ์ **"ปูปูตัน" (Puputan)** ดังเช่น มหากาพย์ปูปูตันบาดุง (ค.ศ. 1906) และปูปูตันกลุงกุง (ค.ศ. 1908) [37] ในสายตาของชาวบาหลี การที่กษัตริย์ ราชินี ขุนนาง และไพร่พล ทรงฉลองพระองค์สีขาวบริสุทธิ์ ประดับพระแสงกริชทองคำ แล้วเสด็จพระราชดำเนินพร้อมเพรียงกันเข้าสู่แนวกระสุนปืนใหญ่ของกองทัพอาณานิคมเนเธอร์แลนด์ มิใช่ความพ่ายแพ้หรือการยอมจำนน หากแต่เป็นการประกอบ "พิธีกรรมทางศาสนาขั้นสูงสุด" เพื่อชำระล้างมลทิน ปลดปล่อยดวงวิญญาณสู่โมกษะ และรักษาเกียรติยศแห่งวรรณะกษัตริย์ไว้ชั่วนิรันดร์ [38]

### 6.2.2 ภูมิทัศน์ทางเทววิทยาและศาสนธรรม: การสังเคราะห์ความเชื่อใน 4 ราชสำนัก

#### 1. มลายู: เอกเทวนิยมบริสุทธิ์ ปราศจากรูปเคารพ แต่แฝงเวทมนตร์ปาวัง
ในราชสำนักมลายู เทววิทยาทางการคือ **อิสลามสายสุนนี (Ahl al-Sunnah wa'l-Jama'ah)** ซึ่งยึดถือนิติศาสตร์ตามมัซฮับชาฟิอี และยึดถือหลักเตาฮีด (Tawhid - เอกภาพแห่งพระผู้เป็นเจ้า) ตามแนวทางของอิหม่าม อัล-อัชอารี (Al-Ash'ari) และอิหม่าม อัล-ฆอซาลี (Al-Ghazali) [39] อิทธิพลนี้ส่งผลให้ราชสำนักมลายูปราศจากรูปเคารพ รูปปั้น หรือเทวรูปโดยสิ้นเชิง สถาปัตยกรรมพระราชวังและมัสยิดหลวงถูกขับเน้นด้วยอักษรวิจิตรภาษาอาหรับ (Calligraphy) ลวดลายเรขาคณิต และลายพรรณพฤกษา (Arabesque) [40] 

ภายใต้กรอบนี้ กษัตริย์มิใช่พระเจ้าและมิใช่อวตารของทวยเทพ แต่ทรงดำรงสถานะเป็น **"เงาแห่งพระผู้เป็นเจ้าบนหน้าพิภพ" (*Zillullah fi al-'Alam*)** พระองค์ทรงมีหน้าที่ปกครองแผ่นดินด้วยความยุติธรรมตามบทบัญญัติแห่งกฎหมายชะรีอะฮ์ [41] อย่างไรก็ดี ภายใต้เปลือกนอกแห่งออร์โธดอกซีอิสลาม ราชสำนักมลายูยังคงรักษาเครือข่ายความเชื่อดั้งเดิมของชาวออสโตรนีเซียนไว้อย่างเหนียวแน่นผ่านสถาบัน **"ปาวังดีราจา" (Pawang Diraja)** หรือหมอผีหลวงประจำราชสำนัก ผู้ทำหน้าที่ประกอบพิธีทางไสยเวท เช่น พิธีเซ่นไหว้ผีวิญญาณแห่งแผ่นดินและท้องน้ำ (*Pelesit / Jin Kerajaan*) และพิธีรักษาความศักดิ์สิทธิ์ของพลังชีวิตหรือ **"เซอมังงัต" (Semangat)** ในเครื่องราชกกุธภัณฑ์และรวงข้าวหลวง [42]

#### 2. ชวา: การประนีประนอมอันแยบยลระหว่างซูฟีกับมรดกพุทธ-ฮินดู
เทววิทยาของราชสำนักชวาแสดงถึงอัจฉริยภาพในการประนีประนอมความเชื่อที่แตกต่างกันอย่างสุดขั้ว ชวาได้รับอิทธิพลจากรหัสยศาสตร์ซูฟีสำนัก **ชัดฏารียะฮ์ (Tarekat Syattariyah)** และปรัชญา **"วะฮ์ดะตุลวูจูด" (Wahdat al-Wujud)** ซึ่งสอนว่า พระผู้เป็นเจ้าทรงสำแดงพระองค์ผ่านสรรพสิ่งในจักรวาล และมนุษย์สามารถเข้าถึงพระองค์ได้ผ่านการชำระจิตใจให้บริสุทธิ์ [43] ปราชญ์ราชสำนักชวา (เช่น ร็องโกวาร์ซีโต - Ronggowarsito) ได้นำปรัชญาซูฟีนี้มาสวมทับลงบนฐานคติ **"อทไวตะเวทานตะ" (Advaita Vedanta)** และลัทธิ **"เทวราช" (Devaraja)** ดั้งเดิมของมัชปาหิต ก่อให้เกิดระบบความเชื่อเฉพาะถิ่นที่เรียกว่า **"เกอจาเว็น" (Kejawen)** [44]

ในเกอจาเว็น องค์สุลต่านทรงดำรงสถานะเป็นทั้งกาลิฟะตุลลอฮ์ (ผู้แทนพระผู้เป็นเจ้าตามหลักอิสลาม) และทรงเป็นศูนย์กลางแห่งจักรวาลวิทยาเขาพระสุเมรุ การปฏิบัติธรรมภายในคราตนมิได้จำกัดอยู่เพียงการละหมาดตามหลักศาสนบัญญัติภายนอก (*Syariat / Lahir*) หากแต่เน้นหนักในการบำเพ็ญภาวนาภายในจิตใจ (*Hakikat / Makrifat / Batin*) พระราชพิธีสำคัญ เช่น พิธีเกอเรเบิก (Garebeg) จึงเป็นการนำเอาภูเขาอาหาร (Gunungan) ที่สะท้อนจักรวาลวิทยาฮินดู มาแจกจ่ายแก่ราษฎรในวันคล้ายวันประสูติของศาสดามุฮัมมัด (Maulid Nabi) โดยมีมัสยิดหลวง (Masjid Agung) เป็นหมุดหมายหลัก [45]

#### 3. ซุนดา: ซุนดาวิวิทัน, ญีโปฮาจี, สู่สองขั้วอิสลามจิเรโบน-บันเติน
เทววิทยาซุนดาดั้งเดิม หรือ **"ซุนดาวิวิทัน" (Sunda Wiwitan)** มีลักษณะเป็นเอกเทวนิยมธรรมชาติ โดยเคารพบูชาพระเป็นเจ้าสูงสุดนามว่า **"ซังฮยัง เกอร์ซา" (Sanghyang Kersa / Nu Ngersakeun)** ผู้ทรงเป็นปฐมเหตุแห่งสรรพสิ่ง สถิตอยู่ ณ สรวงสวรรค์ชั้นสูงสุดที่เรียกว่า *Sasaka Pusaka Buana* [46] ภายใต้ซังฮยัง เกอร์ซา เทพสตรีที่มีความสำคัญสูงสุดต่อชีวิตและเกษตรกรรมคือ **"ญี โปฮาจี ซังฮยัง อัสรี" (Nyi Pohaci Sanghyang Asri)** หรือพระแม่ข้าว ผู้สละชีวิตเพื่อให้กำเนิดพืชพันธุ์ธัญญาหารแก่มนุษยชาติ พิธีกรรมบวงสรวงพระแม่ข้าวผ่านเทศกาล *Seren Taun* จึงเป็นพันธกิจศักดิ์สิทธิ์ที่กษัตริย์และผู้นำชุมชนต้องประกอบเพื่อธำรงความอุดมสมบูรณ์ [47]

เมื่อเข้าสู่ยุคอิสลาม เทววิทยาของดินแดนซุนดาแตกตัวออกเป็นสองศูนย์กลางที่มีบุคลิกต่างกันอย่างสิ้นเชิง:
1. *ราชสำนักจิเรโบน (Cirebon):* ภายใต้การนำของซูนัน กูนุง จาตี (Sunan Gunung Jati) จิเรโบนกลายเป็นศูนย์กลางของรหัสยศาสตร์ซูฟีชัดฏารียะฮ์ มีการผสานสัญลักษณ์เต๋าและพุทธของจีนเข้ากับศิลปะอิฐแดงปูนปั้น เพื่อสื่อถึงการหลอมรวมทางจิตวิญญาณ [48]
2. *รัฐสุลต่านบันเติน (Banten):* ภายใต้สุลต่านฮาซานุดดินและสุลต่านอากุง ตีร์ตายาซา บันเตินพัฒนาไปสู่อิสลามนิติศาสตร์ที่เข้มงวด มุ่งเน้นการปฏิบัติตามหลักชะรีอะฮ์ สถาปนาระบบศาลศาสนา และส่งนักปราชญ์ไปศึกษา ณ นครมักกะฮ์ ทำให้ราชสำนักบันเตินมีความเป็นสากลนิยมอิสลามมากกว่าราชสำนักตอนใน [49]

#### 4. บาหลี: เอกภาพศิวะ-พุทธ, รวา บิเนดา, และการบูชาบรรพชน
เทววิทยาของราชสำนักบาหลีมีเอกลักษณ์โดดเด่นด้วยการสถาปนาระบบปรัชญา **"ศิวะ-พุทธ" (Siwa-Buddha)** ซึ่งมีวิวัฒนาการต่อเนื่องมาจากเกาะชวาโบราณ [50] ศาสนาฮินดูธรรมชาตินิยมในบาหลีถือว่า เทพเจ้าทั้งปวงเป็นเพียงการสำแดงรูปของพระผู้เป็นเจ้าสูงสุดพระองค์เดียว นั่นคือ **"อิดา ซังฮยัง วิดี วาซา" (Ida Sang Hyang Widhi Wasa)** หรือองค์ **"อจินไตย" (Acintya / Sang Hyang Tunggal)** ผู้ไร้รูป ไร้ขอบเขต และสถิตอยู่เหนือความเข้าใจของมนุษย์ [51]

สัจธรรมแห่งจักรวาลในสายตาชาวบาหลีถูกควบคุมด้วยกฎ **"รวา บิเนดา" (Rwa Bhineda)** หรือทวิภาวะแห่งขั้วตรงข้าม เช่น กลางวัน-กลางคืน, ดี-ชั่ว, สกปรก-บริสุทธิ์ (*Kadasan - Sukla*), และมงคล-อัปมงคล หน้าที่ของมนุษย์และราชสำนักมิใช่การทำลายล้างความมืดมิดหรือความชั่วร้ายให้หมดสิ้นไป หากแต่เป็นการ "ประคับประคองดุลยภาพ" ระหว่างสองขั้วพลังมิให้ฝ่ายใดฝ่ายหนึ่งครอบงำจักรวาล [52] 

นอกจากนี้ ราชสำนักบาหลียังผูกพันอย่างลึกซึ้งกับการบูชาบรรพบุรุษ ภายในเขตพระราชฐานปูรีทุกแห่งจะต้องมีเทวสถานประจำราชวงศ์ที่เรียกว่า **"เปอเมราจัน อากุง" (Pamerajan Agung)** ประดิษฐานแท่นบูชาหอเมรุเพื่อเป็นที่สถิตของดวงวิญญาณบูรพกษัตริย์ที่ล่วงลับไปแล้ว ซึ่งได้รับการยกระดับขึ้นสู่สถานะทวยเทพ (*Betara*) คอยคุ้มครองและประสิทธิพรให้แก่ราชวงศ์และแผ่นดิน [53]

#### 1. มลายู: สายเลือดมหาราชอิสกันดาร์ ซุลก็อรนัยน์ สู่บูกิตซีกุนตัง
ในวรรณกรรมประวัติศาสตร์ราชสำนักมลายู เช่น *ซูลาลาตุส ซาลาติน* (Sejarah Melayu) และ *ฮิกายัต มะโรงมหาวงศ์* (Hikayat Merong Mahawangsa) การอ้างสิทธิ์ความชอบธรรมมิได้หยุดอยู่เพียงดินแดนคาบสมุทร หากแต่สืบย้อนไปถึง **ราชาอิสกันดาร์ ซุลก็อรนัยน์ (Raja Iskandar Dhu'l-Qarnain / Alexander the Great)** มหาจักรพรรดิผู้พิชิตโลกซึ่งได้รับการยกย่องในคัมภีร์อัลกุรอาน [54] ริชาร์ด โอ. วินสเตดต์ (Richard O. Winstedt, 1947) วิเคราะห์ว่า การอ้างพงศาวลีนี้ทำหน้าที่เชื่อมโยงอำนาจของกษัตริย์มลายูเข้ากับประวัติศาสตร์สากลของโลกมุสลิมและอารยธรรมตะวันออกกลาง

พงศาวลีระบุว่า เชื้อสายของราชาอิสกันดาร์ได้เสด็จจุติลงมาจากสวรรค์สู่ยอด **เขาบูกิตซีกุนตัง (Bukit Seguntang)** ในเมืองปาเล็มบัง บนเกาะสุมาตรา ในรูปของเจ้าชายสามพระองค์ นำโดย **เสรีตรีภูวนะ (Sang Sapurba / Sri Tri Buana)** ปรากฏการณ์นี้เกิดขึ้นพร้อมกับความอัศจรรย์ทางธรรมชาติ ข้าวในท้องทุ่งกลายเป็นทองคำ ลำต้นกลายเป็นเงิน และใบกลายเป็นอัญมณี [55] เสรีตรีภูวนะได้สถาปนาราชวงศ์สิงคโปร์โบราณ ก่อนที่ทายาทจะอพยพมาก่อตั้งกรุงมะละกา และสืบสายพระโลหิตต่อไปยังราชสำนักเปรัก, ยะโฮร์, ปาหัง, และปัตตานี การมีสายเลือดสืบตรงจากบูกิตซีกุนตังจึงเป็นเงื่อนไขจำเป็นสูงสุดในการอ้างสิทธิ์เหนือบรมราชาภิเษกของกษัตริย์มลายู [56]

#### 2. ชวา: ยุทธศาสตร์พงศาวลีสองขั้วใน Babad Tanah Jawi
ราชสำนักชวาเผชิญกับโจทย์ทางประวัติศาสตร์ที่ซับซ้อนอย่างยิ่งในการเปลี่ยนผ่านจากยุคฮินดูสู่ยุคอิสลาม กวีและปราชญ์ราชสำนักมาตารัมจึงได้ประดิษฐ์สร้างโครงสร้าง **"พงศาวลีสองขั้ว" (Dual Genealogy)** ขึ้นในมหากาพย์ *บาบัด ตานะฮ์ ชวา* (Babad Tanah Jawi) เพื่อสร้างความชอบธรรมอันสมบูรณ์แบบไร้รอยต่อ [57]:
1. **สายซ้าย (Alur Kiri):** สืบสายเลือดฝ่ายศาสนาและจิตวิญญาณ เริ่มต้นจากปฐมมนุษย์ **นบีอาดัม (Nabi Adam)** ผ่านนบีชีษ (Sis), นบีอิบรอฮีม (Ibrahim), กษัตริย์แห่งเปอร์เซียและอาหรับ, เข้าสู่สายตระกูลของบรรดานักบุญผู้เผยแผ่ศาสนาในชวา หรือ **"วะลีซงโง" (Wali Sanga)**
2. **สายขวา (Alur Kanan):** สืบสายเลือดฝ่ายเทวะและอำนาจทางการเมือง เริ่มต้นจากเทพเจ้าสูงสุด **พระศิวะ (Sang Hyang Bathara Guru)** ผ่านมหาเทพฮินดู, วีรบุรุษแห่งมหากาพย์มหาภารตะ (โดยเฉพาะ **อรชุน**), กษัตริย์แห่งอาณาจักรโบราณ เมดัง กาฮูรีปัน สิงหาส่าหรี จนถึง **บราวิจายาที่ 5 (Prabu Brawijaya V)** มหากษัตริย์องค์สุดท้ายแห่งมัชปาหิต

สายธารแห่งพงศาวลีทั้งสองขั้วได้ไหลมาบรรจบกันอย่างสมบูรณ์ในองค์ **ปาเนิมบาฮัน เสโนปาตี (Panembahan Senapati)** ปฐมกษัตริย์แห่งราชวงศ์มาตารัมอิสลาม และได้รับการตอกย้ำในรัชสมัยของ **สุลต่านอากุง (Sultan Agung)** [58] ยุทธศาสตร์พงศาวลีนี้ทำให้กษัตริย์ชวามิได้เป็นเพียงทายาทของศาสดาอิสลามเท่านั้น หากแต่ยังทรงเป็นหน่อเนื้อเชื้อไขของเทพเจ้าฮินดูและมหาราชแห่งมัชปาหิตไปพร้อมกันอย่างกลมกลืน

#### 3. ซุนดา: สายใยปาจาจารันสู่ราชวงศ์ศักดิ์สิทธิ์จิเรโบนและบันเติน
ในโลกวัฒนธรรมซุนดา เอกสารตัวเขียนโบราณ เช่น *จาริตา ปารายางัน* (Carita Parahyangan) ได้บันทึกสายพงศาวลีอันยาวนานที่เชื่อมโยงราชสำนักปากวัน ปาจาจารัน เข้ากับอาณาจักรตารูมานคร (Tarumanagara) และอาณาจักรกาฬิงคะโบราณ โดยมี **พระเจ้าปราบู สิลิวางี** ทรงเป็นศูนย์รวมแห่งเกียรติยศและบารมีสูงสุด [59] นีนา ลูบิส (Nina Lubis, 2011) ชี้ว่า แม้อาณาจักรปาจาจารันจะล่มสลายลงจากการทำสงครามกับกองทัพมุสลิม แต่ความชอบธรรมทางสายเลือดของปราบูสิลิวางีกลับมิได้ถูกทำลายลง หากแต่ถูกหลอมรวมเข้าสู่อัตลักษณ์ของราชสำนักอิสลามใหม่อย่างแยบยล

พงศาวลี *บาบัด จิเรโบน* (Babad Cirebon) และ *เซอจาราฮ์ บันเติน* (Sejarah Banten) ระบุตรงกันว่า พระราชธิดาของปราบูสิลิวางี นามว่า **เจ้าหญิงรารา สันตัง (Rara Santang)** ได้เดินทางไปแสวงบุญ ณ นครมักกะฮ์ และได้เสกสมรสกับเจ้าผู้ครองนครในตะวันออกกลาง (Syarif Abdullah) ทรงได้รับพระนามใหม่ว่า ชารีฟะฮ์ มูดาอิม (Syarifah Muda'im) [60] พระนางได้ให้กำเนิดพระราชโอรสนามว่า **ชารีฟ ฮิดายาตุลลอฮ์ (Syarif Hidayatullah)** ซึ่งต่อมาได้เดินทางกลับมายังเกาะชวาและได้รับการสถาปนาเป็น **"ซูนัน กูนุง จาตี" (Sunan Gunung Jati)** หนึ่งในเก้าพระเกจิอาจารย์วะลีซงโง และเป็นปฐมกษัตริย์แห่งราชวงศ์จิเรโบน ซูนัน กูนุง จาตี ได้ให้กำเนิดพระโอรสคือ **สุลต่านฮาซานุดดิน (Sultan Hasanuddin)** ปฐมสุลต่านแห่งบันเติน [61] โครงสร้างพงศาวลีนี้ทำให้กษัตริย์แห่งจิเรโบนและบันเตินทรงมีความชอบธรรมสองด้านที่สมบูรณ์แบบ: ด้านหนึ่งทรงสืบสายพระโลหิตตรงจากปราบูสิลิวางี (สายเลือดแห่งแผ่นดินซุนดา) และอีกด้านหนึ่งทรงสืบสายพระโลหิตตรงจากศาสดามุฮัมมัด (สายเลือดแห่งความบริสุทธิ์ทางศาสนา)

#### 4. บาหลี: การธำรงสายเลือดบริสุทธิ์แห่งมัชปาหิต (Wong Majapahit)
ในขณะที่เกาะชวาและสุมาตราเปลี่ยนผ่านไปสู่อิสลาม ราชสำนักบาหลีกลับดำเนินยุทธศาสตร์ความชอบธรรมที่มุ่งเน้น **"ความบริสุทธิ์แห่งสายเลือดมัชปาหิต" (The Purity of Majapahit Lineage)** อย่างเคร่งครัด ชนชั้นนำบาหลีเรียกตนเองว่า **"ว็อง มัชปาหิต" (Wong Majapahit)** หรือ "คนมัชปาหิต" เพื่อจำแนกตนเองออกจากกลุ่มชนพื้นเมืองดั้งเดิมที่เรียกว่า "บาหลี อากา" (Bali Aga) [62]

ความชอบธรรมของราชสำนักบาหลีวางอยู่บนเหตุการณ์ประวัติศาสตร์ในปี ค.ศ. 1343 เมื่อสมเด็จพระมหาจักรพรรดินีแห่งมัชปาหิต (Tribhuwana Tunggadewi) ทรงส่งมหาเสนาบดีคชมาดาไปปราบเกาะบาหลี และทรงสถาปนาให้ **ศรี เกรศนา เกอปากีซัน (Sri Kresna Kepakisan)** พราหมณ์ผู้สืบสายโลหิตจากราชสำนักมัชปาหิต ข้ามไปครองราชย์เป็นกษัตริย์แห่งบาหลี ณ ราชธานีสมังงัน (Samprangan) [63] พงศาวดาร *บาบัด ดะเล็ม* (Babad Dalem) บันทึกว่า มัชปาหิตได้พระราชทานเครื่องราชกกุธภัณฑ์ศักดิ์สิทธิ์ ได้แก่ พระแสงกริชเคียอี กานดังกาวัก (Kyai Gandangkawak), มงกุฎทองคำ, และคันฉ่องสวรรค์ เพื่อเป็นสัตถุปัญญารองรับพลังดาอูลัต [64]

ต่อมาในรัชสมัยของพระราชโอรส คือ **ดะเล็ม เกอตุต งูเลซีร์ (Dalem Ketut Ngulesir)** ศูนย์กลางอำนาจได้ย้ายมายัง **ราชสำนักเกลเกล (Gelgel)** และก้าวสู่ยุคทองในรัชสมัยของ **ดะเล็ม วาตูเร็งก็อง (Dalem Waturenggong)** ซึ่งร่วมกับมหาเถรพราหมณ์ ดังฮยัง นิราร์ถะ (Danghyang Nirartha) ปฏิรูปศาสนาและสถาปัตยกรรมบาหลีทั้งหมด [65] เมื่อเกลเกลล่มสลายในปลายคริสต์ศตวรรษที่ 17 ศูนย์กลางอำนาจได้ย้ายมายัง **ราชสำนักกลุงกุง (Klungkung)** ภายใต้พระประมุขผู้ทรงราชทินนามว่า **"เดวา อากุง" (Dewa Agung)** แม้บาหลีจะแตกกระจายออกเป็น 9 แคว้นปูรีที่เป็นอิสระต่อกัน (บาดุง, ตาบานัน, เกียญญาร์, เมงวี, บูเลเล็ง, คารังอาเซ็ม, เคลมปัง, จัมบรานา, กลุงกุง) แต่เจ้าผู้ครองปูรีทุกแห่งต่างยอมรับว่า เดวา อากุง แห่งกลุงกุง คือ "ปรมราชันย์" (Primus Inter Pares) ผู้เป็นหน่อเนื้อเชื้อไขสายตรงเพียงหนึ่งเดียวของมัชปาหิตที่ไม่มีวันสูญสลาย [66]

### 6.2.4 ตารางวิเคราะห์เปรียบเทียบเชิงสังเคราะห์: ปรัชญาและความชอบธรรมแห่งอำนาจ 4 ภูมิวัฒนธรรม

เพื่อสังเคราะห์มิติทางปรัชญา เทววิทยา และความชอบธรรมทางการเมืองที่ได้วิเคราะห์มาทั้งหมด ตารางเมทริกซ์ต่อไปนี้แสดงการเปรียบเทียบเชิงโครงสร้างอย่างเป็นระบบระหว่าง 4 ภูมิวัฒนธรรมราชมนเทียรแห่งนูซันตารา:

| มิติการเปรียบเทียบ | 1. มลายู (Melayu) | 2. ชวา (Jawa) | 3. ซุนดา (Sunda) | 4. บาหลี (Bali) |
| :--- | :--- | :--- | :--- | :--- |
| **ฐานคติอำนาจสูงสุด** *(Ultimate Power)* | **ดาอูลัต (Daulat)** พลังบารมีศักดิ์สิทธิ์ที่อัลลอฮ์ประทาน แผ่รังสีผ่านพระวรกายและเครื่องราชกกุธภัณฑ์ | **มานุงกาลิง กาวูลา กุสตี** เอกภาพอินทรียภาพระหว่างราชา-ราษฎร และมนุษย์-พระเจ้า (*Wahdat al-Wujud*) | **ตรีตังกู ดี บัวนา** ไตรภาคดุลยภาพแห่งอำนาจ คานอำนาจ 3 สถาบัน ปฏิเสธอำนาจเบ็ดเสร็จ | **ธรรมกษัตริย์ในรัฐนาฏกรรม** อำนาจคือการจัดแสดงพิธีกรรม (*Theatre State*) ค้ำจุนจักรวาล |
| **ทฤษฎีความชอบธรรม** *(Legitimacy Theory)* | **เงาแห่งอัลลอฮ์ในโลก** (*Zillullah fi al-'Alam*) กษัตริย์ทรงธรรม ผสานอำนาจจิตวิญญาณปาวังหลวง | **วะฮ์ยูศักดิ์สิทธิ์ (Wahyu)** แสงฉัพพรรณรังสีสวรรค์ที่เคลื่อนย้ายได้ กาลิฟะตุลลอฮ์ + สวามีทิพย์ราตูคิดุล | **ดุลยภาพสามเส้า (Tritangtu)** ปราบูบริหารภายใต้การตรวจสอบของเรสิ (ธรรมะ) และรามะ (ราษฎร) | **อำนาจอธิปไตยคู่** (*Dual Sovereignty*) ราชาธิบดีเดวา อากุง (ทางโลก) vs เปอดันดา (จิตวิญญาณ) |
| **สายพระโลหิตศักดิ์สิทธิ์** *(Sacred Genealogy)* | **อิสกันดาร์ ซุลก็อรนัยน์** สู่เสรีตรีภูวนะบนยอดบูกิตซีกุนตัง เลือดสีขาวบริสุทธิ์ (*Darah Putih*) | **พงศาวลีสองขั้ว (Babad)** สายซ้าย (นบีอาดัม/อิสลาม) บรรจบสายขวา (พระศิวะ/อรชุน/มัชปาหิต) | **ปาจาจารันสู่สองขั้วอิสลาม** ปราบูสิลิวางี สู่ซูนัน กูนุง จาตี (สายเลือดซุนดา + สายเลือดนบีมุฮัมมัด) | **สายเลือดมัชปาหิตแท้** (*Wong Majapahit*) ศรีเกรศนา เกอปากีซัน สู่ดะเล็มเกลเกลและเดวา อากุง |
| **พันธสัญญาทางสังคม** *(Social Contract)* | **พันธสัญญา วะอัด (Wa'ad)** ราษฎรห้ามทรยศ (*derhaka*) กษัตริย์ห้ามเหยียดหยาม (*menista*) ข้าแผ่นดิน | **เอกภาพอินทรีย์ (Organic)** ราชาคือศีรษะ ราษฎรคือร่างกาย พึ่งพาอาศัยกัน หากทรยศวะฮ์ยูจะหลุดลอย | **อามานัต กาลุงกุง** สัญญาความผาสุก (*Kasalametan*) หากปราบูอยุติธรรม เรสิ-รามะถอดถอนได้ | **ยึดมั่นในหน้าที่แห่งวรรณะ** (*Swadharma*) ราษฎรร่วมพิธีกรรม กษัตริย์พลีชีพในการรบ (*Puputan*) |
| **ภูมิทัศน์เทววิทยา** *(Theological Framework)* | **อิสลามสุนนี-อัชอารียะฮ์** มัซฮับชาฟิอี ไร้รูปเคารพ แต่แฝงเวทมนตร์บรรพชนและพิธีเบอร์ฮันตู | **รหัสยิกซูฟีเกอจาเว็น** ชัดฏารียะฮ์ + มัชปาหิต กลืนกลายเทวราชสู่อินซาน คามิล (*Insan Kamil*) | **ซุนดาวิวิทัน สู่ ซูฟี-ชะรีอะฮ์** เคารพซังฮยัง เกอร์ซา และพระแม่ข้าว สู่ซูฟีจิเรโบนและนิติศาสตร์บันเติน | **ฮินดู ศิวะ-พุทธ (Acintya)** ทวิภาวะรวา บิเนดา, ไตรหิตครณะ, และการบูชาดวงวิญญาณบูรพกษัตริย์ |
| **สัญศาสตร์สัญลักษณ์** *(Dominant Symbols)* | **กริช, กลองโนบัต, ฉัตรขาว** เครื่องกกุธภัณฑ์สัตถุปัญญาเปี่ยมเซอมังงัต และคัมภีร์อัลกุรอานหลวง | **ต้นไทรคู่, ภูเขาอาหาร, ม้าศึก** หอสังกาบูวานา, ราชรถหลวง, ระบำเบอดายาเกอตาวัง, กริชคราตน | **เสือมงคล (Maung Lodaya)** การอันตรธาน (*ngahyang*), แท่นหินบวงสรวง, สระน้ำ 7 บ่อ, ลายเมฆวาดาสัน | **หอเมรุบาเด, พญานาคพันธา** แท่นปัทมาสน์บงกชจักรวาล, กริชทองคำ, ดนตรีกาเมอลันเบอบอนตัง |
| **ทัณฑ์อาถรรพ์เมื่อละเมิด** *(Violation Consequences)* | **ตูลาฮัน / เกอนาเดาลัต** อาเจียนเป็นเลือด ป่วยตายฉับพลัน แผ่นดินสูบ เรืออับปาง อาณาจักรล่ม | **วะฮ์ยูอันตรธาน (Oncat)** เกิดกลียุค ข้าวยากหมากแพง โรคระบาด แผ่นดินแตกแยก ต้องย้ายราชธานี | **การเสียดุลยภาพจักรวาล** แผ่นดินสูญสิ้นสันติสุข ภัยพิบัติธรรมชาติ ปราบูสูญสิ้นบารมีและถูกขับไล่ | **มลทินจักรวาล (Cemer)** ถูกลงทัณฑ์จากทวยเทพ ราชวงศ์ล่มสลาย ต้องชำระล้างด้วยมหายัญปูปูตัน |

การวิเคราะห์เปรียบเทียบในหัวข้อ 6.1 และ 6.2 นี้ ได้เปิดเผยให้เห็นว่า ภายใต้ความคล้ายคลึงของปรากฏการณ์ทางกายภาพภายนอกในโลกนูซันตารา ราชสำนักทั้ง 4 ภูมิวัฒนธรรมต่างมี "พิมพ์เขียวทางจิตวิญญาณและปรัชญาการเมือง" ที่แตกต่างกันอย่างลึกซึ้ง:
- **มลายู** วางอำนาจอยู่บนเส้นแบ่งทางศีลธรรมของพันธสัญญาศักดิ์สิทธิ์และการสืบสายเลือดจากราชาสากล
- **ชวา** วางอำนาจอยู่บนการดูดซับพลังงานจักรวาลและความเป็นเอกภาพทางรหัสยศาสตร์ระหว่างมนุษย์กับเบื้องบน
- **ซุนดา** วางอำนาจอยู่บนดุลยภาพสามเส้าที่ปฏิเสธอำนาจเผด็จการและเคารพต่อกฎธรรมชาติ
- **บาหลี** วางอำนาจอยู่บนเวทีนาฏกรรมแห่งพิธีกรรมอันศักดิ์สิทธิ์และการสละชีพเพื่อพิทักษ์เกียรติยศแห่งวรรณะ

รากฐานทางปรัชญาและความชอบธรรมเหล่านี้จะทำหน้าที่เป็น "กุญแจไขความจริง" ที่นำไปสู่การวิเคราะห์เปรียบเทียบในมิติต่อไป ได้แก่ ระบบพื้นที่ศักดิ์สิทธิ์และผังเมือง (ตอนที่ 6.2), สถาบันเครือญาติและบทบาทสตรีฝ่ายใน (ตอนที่ 6.3), ตลอดจนยุทธศาสตร์การรับมือกับการคุกคามของลัทธิจักรวรรดินิยมตะวันตก (ตอนที่ 6.4) ในลำดับถัดไป
