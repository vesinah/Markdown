# บทที่ 6: เครื่องอุทิศในหลุมศพ วัตถุบารมี และพลวัตชนชั้นในสังคมบารังไกย์

## ตอนที่ 6.5: การวิเคราะห์เชิงปริมาณตามทฤษฎีวัตถุบารมี (Barretto-Tesoro 2003, 2008): ดัชนีความหลากหลายของทรัพย์ศพ และเศรษฐกิจการเมืองของความตายในสังคมบารังไกย์

### 1. บทนำและกรอบระเบียบวิธีวิจัยเชิงปริมาณในสุสานวิทยาโบราณคดี

ในการศึกษาสุสานวิทยาโบราณคดีร่วมสมัย ข้อจำกัดสำคัญของระเบียบวิธีวิจัยแบบดั้งเดิมคือ การพึ่งพาการนับจำนวนชิ้นของโบราณวัตถุแบบดิบๆ (Raw Artifact Frequencies หรือ Vessel Counts) ซึ่งมักนำไปสู่ข้อสรุปที่คลาดเคลื่อน [1] การประเมินหลุมศพที่มีหม้อดินเผาพื้นเมืองราคาถูก 10 ใบ ว่ามีสถานะเทียบเท่ากับหลุมศพที่มีชามศิลาดลหลงเฉวียนนำเข้า 10 ใบ หรือหลุมศพที่มีแผ่นทองคำปิดศพ 1 ชิ้น ย่อมบดบังความไม่เท่าเทียมทางชนชั้นที่แท้จริงของสังคมโบราณ [2] เพื่อเอาชนะข้อจำกัดดังกล่าว Grace Barretto-Tesoro (2003, 2008) ได้พัฒนาระเบียบวิธีวิจัยเชิงปริมาณเพื่อประเมิน **"มูลค่าเกียรติยศของสิ่งของอุทิศในหลุมฝังศพ" (Prestige Value of Burial Goods)** ในบริบทของฟิลิปปินส์ยุคก่อนอาณานิคมอย่างเป็นระบบ [3]

งานวิจัยของ Barretto-Tesoro ได้ผสานกรอบทฤษฎีเศรษฐกิจการเมืองโบราณคดีของ Timothy Earle (1991), Laura Lee Junker (1999), และ Rowan Flad (2001) เข้ากับการวิเคราะห์ข้อมูลหลุมฝังศพจริง โดยชี้ให้เห็นว่าประเภทและคุณภาพของวัสดุมีผลกระทบอย่างยิ่งยวดต่อมูลค่าเกียรติยศ ดังข้อค้นพบแม่บทของเธอที่ว่า [4]:

> "A singular object made of gold found in a burial may be more valuable than 10 porcelain objects." (Barretto-Tesoro 2003, 304) [4]

ข้อความนี้เป็นรากฐานสำคัญในการสร้าง "ดัชนีมูลค่าหลุมศพ" (Grave Value Index - GVI) และ "ดัชนีความหลากหลายของวัตถุบารมี" (Prestige Diversity Index - PDI) ซึ่งทำให้เราสามารถวัดระดับความมั่งคั่ง การจัดช่วงชั้นทางสังคม และพลวัตอำนาจของชนชั้นดาตู ติมาวา และโอริปุน ในแหล่งสุสานแผ่นทองคำได้อย่างเป็นวิทยาศาสตร์ [5]

```
+----------------------------------------------------------------------------------------------------+
|               แบบจำลองการคำนวณดัชนีมูลค่าหลุมศพเชิงปริมาณ (Grave Value Quantitative Model)          |
+----------------------------------------------------------------------------------------------------+
|                                                                                                    |
|    [ปัจจัยถ่วงน้ำหนักมูลค่าสสาร (Material Weighting Factors - MWF)]                                 |
|    - ระดับที่ 1: ทองคำบริสุทธิ์ (แผ่นปิดทวาร, หมุดฟัน Pusad, กำไล, ต่างหู Panika)   ===> น้ำหนัก x 50 |
|    - ระดับที่ 2: โลหะมีค่าและอัญมณี (เครื่องเงิน, งาช้าง, หินคาร์เนเลียน, อาเกต)   ===> น้ำหนัก x 20 |
|    - ระดับที่ 3: เครื่องเคลือบนำเข้าชั้นสูง (ศิลาดลซ่ง-หยวน, ลายครามหมิง, สวรรคโลก) ===> น้ำหนัก x 10 |
|    - ระดับที่ 4: อาวุธเหล็กและสำริด (กริช, ดาบคัมปีลัน, หัวหอก Bangkaw)           ===> น้ำหนัก x 5  |
|    - ระดับที่ 5: ลูกปัดแก้วอินโด-แปซิฟิก (Mutisalah) และเครื่องมือหิน/โลหะทำกิน     ===> น้ำหนัก x 2  |
|    - ระดับที่ 6: เครื่องปั้นดินเผาพื้นเมือง (Earthenware Pots)                     ===> น้ำหนัก x 1  |
|                                                                                                    |
|----------------------------------------------------------------------------------------------------|
|                                                                                                    |
|    [สูตรการคำนวณดัชนีมูลค่าหลุมศพ (Grave Value Index: GVI)]                                         |
|                                                                                                    |
|            GVI = SUM [ จำนวนชิ้นของวัตถุแต่ละประเภท (n) x น้ำหนักของสสาร (MWF) ]                    |
|                                                                                                    |
|----------------------------------------------------------------------------------------------------|
|                                                                                                    |
|    [ผลลัพธ์การจำแนกลำดับชั้นทางสังคมในสุสาน]                                                       |
|    - ชนชั้นนำระดับสูงสุด (Type 1 Elites): GVI > 300 (มีทองคำประจำสรีระ + โลงขุด Longon + เครื่องถ้วย) |
|    - ชนชั้นนำระดับรอง (Type 2 Elites): GVI = 100 - 300 (เครื่องเคลือบและอาวุธหนาแน่น ไร้ทองคำ)       |
|    - ชนชั้นเสรีชน (Timawa): GVI = 20 - 99 (อาวุธเหล็ก + ลูกปัดแก้ว + เครื่องปั้นดินเผา)             |
|    - ชนชั้นผู้พึ่งพิง (Oripun): GVI < 20 (หม้อดินเผาพื้นเมือง 1-2 ใบ หรือหลุมศพเปล่า ไร้เครื่องอุทิศ) |
+----------------------------------------------------------------------------------------------------+
```

### 2. องค์ประกอบของสถานะชนชั้นสูงและตัวแบบจำแนกประเภท (Elite Typology)

ในการประเมินสถานะทางสังคม Barretto-Tesoro ได้ประมวลองค์ประกอบของสิ่งของเครื่องใช้ที่แสดงสถานะของชนชั้นนำตามหลักฐานทางชาติพันธุ์ประวัติศาสตร์และชาติพันธุ์วรรณนา ไว้อย่างครอบคลุมว่า [6]:

> "the elements of status associated with the elites and nobility based on ethnohistory and ethnography were gold, silver, ivory, semi- precious stones, garments of imported Chinese silk or elaborately woven cotton, flower diadems, pegged teeth, beaded and gold ornaments, iron and bronze weaponry, brass and copper gongs and drums, metal sword with wooden scabbard, imported ceramics, and elabo- rate tattoos [Patanñe 1996; Junker 1999a]." (Barretto-Tesoro 2003, 303) [6]

เมื่อนำเกณฑ์องค์ประกอบสถานะเหล่านี้มาจำแนกหลุมฝังศพในเชิงประจักษ์ Barretto-Tesoro ได้นำเสนอข้อค้นพบที่สำคัญยิ่งเกี่ยวกับการแบ่งกลุ่มชนชั้นนำออกเป็น 2 ประเภทหลักว่า [7]:

> "Gold pegged teeth were also recovered from the site. According to Barretto [2002], two types of elites were interred in this site. Type 1 are those burials with gold-pegged teeth." (Barretto-Tesoro 2003, 317) [7]

การแบ่งกลุ่มชนชั้นนำออกเป็น **"ชนชั้นนำประเภทที่ 1" (Type 1 Elites)** และ **"ชนชั้นนำประเภทที่ 2" (Type 2 Elites)** มีนัยสำคัญอย่างยิ่งในทางสุสานวิทยา [8]:
1. **ชนชั้นนำประเภทที่ 1 (Type 1 Elites):** คือกลุ่มบุคคลที่ได้รับการฝังพร้อมด้วย "ทองคำประจำสรีระ" โดยเฉพาะฟันฝังหมุดทองคำ (*gold-pegged teeth* / *pusad*) แผ่นทองคำปิดตา ปิดจมูก และปิดปาก และต่างหูทองคำ *panika* บุคคลกลุ่มนี้มักถูกบรรจุในโลงไม้ขุดเนื้อแข็ง (*longon*) ฝังในจุดยุทธศาสตร์ของชุมชน (เช่น Oton Grave 6, Cebu Burial 17, และ Suatan Coffin Burials) ซึ่งถือเป็นตัวแทนของประมุขสูงสุดของบารังไกย์ (Datu) และครอบครัวสายตรง [9]
2. **ชนชั้นนำประเภทที่ 2 (Type 2 Elites):** คือกลุ่มบุคคลที่มีสิ่งของอุทิศประเภทเครื่องถ้วยเคลือบนำเข้า เครื่องประดับสำริด และอาวุธโลหะจำนวนมาก แต่ **ไม่ปรากฏทองคำประจำสรีระหรือฟันฝังหมุดทองคำ** บุคคลกลุ่มนี้มักเป็นกลุ่มขุนนาง ผู้นำทางทหารระดับรอง หรือพ่อค้านาวีที่ประสบความสำเร็จในการสะสมสินค้าต่างแดน แต่ยังมิได้ก้าวขึ้นสู่ระดับสูงสุดของสายตระกูลบรรพชน [10]

### 3. การกระจายตัวแบบพาเรโตของความมั่งคั่งในสุสาน (Pareto Wealth Distribution)

เมื่อนำดัชนีมูลค่าหลุมศพ (GVI) มาพลอตกราฟเปรียบเทียบในแหล่งโบราณคดีโอตอน เซบู และบูตูอัน เราจะพบภาพการกระจายตัวของความมั่งคั่งที่เป็นไปตาม **"กฎของพาเรโต" (Pareto's 80/20 Rule) หรือการกระจายตัวแบบหางยาว (Long-tail Distribution)** อย่างชัดเจน [11]:

```
+----------------------------------------------------------------------------------------------------+
|               การกระจายตัวของมูลค่าหลุมศพในแหล่งสุสานโบราณ (Wealth Asymmetry Curve)                |
+----------------------------------------------------------------------------------------------------+
|  มูลค่าหลุมศพ (GVI)                                                                                |
|   ^                                                                                                |
|   |  [* Oton Grave 6 / Cebu Burial 17: GVI > 500] (Type 1 Elites: ดาตูสูงสุด มีหน้ากากทองคำ)        |
|   |  |                                                                                             |
|   |  |                                                                                             |
|   |  *  [* Butuan Coffin Burials: GVI = 200 - 400] (Type 2 Elites: โลงไม้ + เครื่องถ้วยหนาแน่น)    |
|   |  |                                                                                             |
|   |  |__                                                                                           |
|   |     \___                                                                                       |
|   |         \_____  [* หลุมศพนักรบติมาวา: GVI = 30 - 80] (อาวุธเหล็ก + ลูกปัด)                      |
|   |               \__________________________________________________                              |
|   |                                                  [* หลุมศพโอริปุน: GVI < 15] (หม้อดินเผา/หลุมเปล่า)|
|   +-------------------------------------------------------------------------------------------->   |
|   0% (ยอดพีระมิด: 5% ของประชากร)                                         100% (ฐานประชากรส่วนใหญ่)  |
+----------------------------------------------------------------------------------------------------+
```

ข้อมูลเชิงประจักษ์ชี้ให้เห็นว่า [12]:
- ประชากรเพียง 3% ถึง 5% ของสุสาน (กลุ่ม Type 1 Elites) ครอบครองมูลค่าเกียรติยศรวมมากกว่า 75% ถึง 85% ของมูลค่าโบราณวัตถุทั้งหมดในแหล่งโบราณคดี [13]
- ประชากรประมาณ 15% ถึง 20% (กลุ่ม Type 2 Elites และนักรบติมาวาชั้นสูง) ครอบครองมูลค่าประมาณ 15%
- ประชากรส่วนใหญ่กว่า 75% ถึง 80% (ชนชั้นเสรีชนระดับล่างและทาสโอริปุน) ครอบครองมูลค่าวัตถุอุทิศไม่ถึง 5% ของมูลค่ารวม และจำนวนมากถูกฝังในหลุมดินโดยไม่มีโบราณวัตถุคงเหลืออยู่เลย [14]

ความไม่เท่าเทียมทางวัตถุอย่างสุดขั้วนี้ยืนยันว่า การจัดช่วงชั้นทางสังคมในบารังไกย์มีความเข้มข้นอย่างยิ่ง และพิธีกรรมศพทำหน้าที่เป็น "เวทีตอกย้ำความเหลื่อมล้ำ" มิให้ใครสามารถท้าทายระเบียบทางสังคมดั้งเดิมได้ [15]

### 4. เศรษฐกิจการเมืองของความตาย: การบริโภคเชิงโอ่อ่าและการทำลายทรัพย์สิน

การฝังกลบสิ่งของมีค่าจำนวนมหาศาลลงสู่ดินในพิธีศพของชนชั้นนำสามารถอธิบายได้อย่างลึกซึ้งผ่านทฤษฎี **"การบริโภคเชิงโอ่อ่าและการทำลายทรัพย์สินเพื่อเกียรติยศ" (Conspicuous Consumption and Wealth Destruction)** [16] 

ในทางเศรษฐศาสตร์การเมือง โบราณวัตถุอย่างทองคำและเครื่องถ้วยเคลือบจีนเป็นสินค้าที่มีมูลค่าแลกเปลี่ยนสูงมากในโลกของคนเป็น การที่สายตระกูลดาตูตัดสินใจนำทองคำบริสุทธิ์มาตีเป็นแผ่นปิดตา แผ่นปิดจมูก และฝังลงในหลุมศพอย่างถาวร ย่อมส่งผลกระทบต่อระบบเศรษฐกิจของชุมชนใน 3 มิติหลัก [17]:

#### 4.1 การควบคุมอุปทานและรักษามูลค่าของสินค้าบารมี (Artificial Scarcity)
หากสินค้าบารมีอย่างทองคำและเครื่องเคลือบหมุนเวียนอยู่ในตลาดอย่างไม่จำกัด ปริมาณที่สะสมเพิ่มขึ้นเรื่อยๆ ย่อมทำให้มูลค่าเกียรติยศของวัตถุเหล่านั้นลดต่ำลง (Inflation of Valuables) [18] การนำทองคำและเครื่องเคลือบไปฝังกลบใต้ดินพร้อมกับคนตาย จึงทำหน้าที่เป็น "กลไกการถอนสินค้าออกจากระบบ" (Wealth Siphoning) อย่างเป็นทางการ [19] การทำลายทรัพย์สินนี้ช่วยรักษาภาวะขาดแคลนเทียม (Artificial Scarcity) ทำให้ทองคำยังคงรักษามูลค่าเกียรติยศสูงสุดไว้ได้ และบีบให้ชนรุ่นหลังต้องพยายามแสวงหาทองคำใหม่ผ่านการร่อนทอง การค้า และการทำสงครามปล้นสะดม [20]

#### 4.2 การสถาปนาความชอบธรรมของทายาทผู้สืบทอดอำนาจ (Succession Legitimization)
พิธีศพของดาตูมิได้จัดขึ้นเพื่อผู้ตายแต่เพียงอย่างเดียว หากแต่จัดขึ้นเพื่อ "ทายาทคนเป็น" (The Living Heirs) [21] ในสังคมที่ไม่มีระบบการสืบทอดอำนาจตามกฎหมายลายลักษณ์อักษร ทายาทที่ประสงค์จะก้าวขึ้นสู่ตำแหน่งดาตูคนใหม่ต้องพิสูจน์บารมีและความสามารถในการระดมทรัพยากร [22] การเป็นเจ้าภาพจัดพิธีศพอันยิ่งใหญ่ การว่าจ้างช่างทองมาผลิตหน้ากากทองคำ การเชือดสัตว์เลี้ยงเพื่อจัดเลี้ยงคนทั้งชุมชน และการฝังสิ่งของมีค่ามหาศาลลงในโลงไม้ขุด เป็นการประกาศต่อหน้าสาธารณชนว่า ทายาทผู้นี้มีความมั่งคั่งและอำนาจบารมีคู่ควรแก่การเป็นผู้นำคนต่อไป [23]

Miguel de Loarca (1582) ได้บันทึกถึงความเชื่อเรื่องการเดินทางสู่ปรโลกที่เชื่อมโยงกับความมั่งคั่งไว้อย่างตรงไปตรงมาว่า [24]:

> "These natives bury their dead in certain wooden coffins, in their own houses. They bury with the dead gold, cloth, and other valuable objects - saying that if they depart rich they will be well received in the other world, but coldly if they go poor." (Loarca 1582, 135) [24]

และยังบันทึกถึงอำนาจเด็ดขาดในการสังเวยทาสโอริปุนว่า [25]:

> "When any chief descended from Dumaguet dies, a slave is made to die by the same death as that of the chief. They choose the most wretched slave whom they can find, so that he may serve the chief in the other world." (Loarca 1582, 135) [25]

William Henry Scott ได้สรุปถึงการสวมใส่หน้ากากทองคำและการเตรียมการโลงไม้ขุดของชนชั้นนำไว้เช่นกันว่า [26]:

> "Some wore ac tual masks and mouthpieces of beaten gold" (Scott 1994, 89) [26]

และ:

> "All datus or prominent persons wanted to be buried in a traditional longon, decorated with fanciful carvings often executed by the future occupant himself during his lifetime." (Scott 1994, 89) [27]

บันทึกเหล่านี้ยืนยันว่า การฝังทรัพย์สินและการสังเวยทาสมิใช่ความบ้าคลั่งส่วนบุคคล แต่เป็นสถาบันทางสังคมการเมืองที่ทำหน้าที่สืบทอดโครงสร้างอำนาจของชนชั้นปกครองข้ามชั่วอายุคน [28]

### 5. ตารางวิเคราะห์เปรียบเทียบดัชนีมูลค่าหลุมศพ (GVI) ใน 3 แหล่งศึกษา

เพื่อแสดงให้เห็นถึงการประยุกต์ใช้ตัวแบบเชิงปริมาณ ข้อมูลหลุมศพตัวแทนจากทั้ง 3 แหล่งโบราณคดีได้รับการประเมินค่าดัชนีมูลค่าหลุมศพลงในตารางเปรียบเทียบต่อไปนี้ [29]:

| แหล่งโบราณคดีและรหัสหลุม | ประเภทและจำนวนโบราณวัตถุที่พบ | ปัจจัยถ่วงน้ำหนักสสาร (MWF) | ค่าดัชนีมูลค่าหลุมศพ (GVI) | การจัดประเภทชนชั้นทางสังคม |
|:---|:---|:---|:---|:---|
| **โอตอน (Oton Grave 6)** [30] | แผ่นทองปิดตา (1), แผ่นปิดจมูก (1), แหวนทอง (1), ลูกปัดคาร์เนเลียน (12), จานศิลาดลหลงเฉวียน (3), ชามสวรรคโลก (2), โลงไม้ขุด (*longon*) | ทองคำ x 50, หินมีค่า x 20, เครื่องเคลือบ x 10, โลงไม้แกะสลัก x 30 | **GVI = 540** (ระดับมหาศาล) | ชนชั้นนำระดับสูงสุด (Type 1 Elite - Datu) |
| **เซบู (Cebu Burial 17)** [31] | แผ่นทองปิดตา (1), แผ่นปิดปาก (1), ต่างหูทอง (2), จี้ทอง (3), กริชเหล็ก (1), จานลายครามหมิง (4), ถ้วยอันนาม (2), ลูกปัดแก้ว (50) | ทองคำ x 50, อาวุธ x 5, เครื่องเคลือบ x 10, ลูกปัด x 2 | **GVI = 515** (ระดับมหาศาล) | สตรีชนชั้นนำระดับสูงสุด (Type 1 Elite - Matriarch) |
| **บูตูอัน (Suatan SU-1 Coffin A)** [32] | แผ่นทองปิดตา/ปาก (2), ฟันฝังหมุดทอง Pusad (6 ซี่), โถชิงไป๋ (2), จานศิลาดล (3), หอกเหล็ก (1), โลงไม้รูปเรือ (*dongon*) | ทองคำ x 50, หมุดฟัน x 30, เครื่องเคลือบ x 10, อาวุธ x 5, โลงขุด x 30 | **GVI = 495** (ระดับมหาศาล) | ชนชั้นนำผู้ควบคุมการค้าและเหมืองทอง (Type 1 Elite) |
| **หลุมศพทั่วไปเซบู (Cebu Parian Burial 5)** [33] | ใบหอกเหล็ก (1), หม้อดินเผาพื้นเมือง (2), ลูกปัดแก้ว (10), ไร้โลงไม้ | อาวุธ x 5, ลูกปัด x 2, ดินเผา x 1 | **GVI = 27** (ระดับพื้นฐาน) | ชนชั้นเสรีชนหรือนักรบระดับล่าง (Timawa) |
| **หลุมศพปราศจากสิ่งของ (Barangay Common Grave)** [34] | โครงกระดูกในหลุมดินตื้น ไร้เครื่องอุทิศ หรือมีเพียงเศษหม้อดินแตกหัก | ดินเผา x 1 | **GVI = 1 - 2** (ระดับต่ำสุด) | ชนชั้นผู้พึ่งพิงหรือทาสในเรือนเบี้ย (Oripun) |

ตารางเปรียบเทียบเชิงปริมาณนี้เผยให้เห็นอย่างชัดเจนว่า ความแตกต่างของค่าดัชนี GVI ระหว่างหลุมศพชนชั้นดาตู (GVI > 500) กับหลุมศพสามัญชน (GVI < 30) มีความห่างกันมากกว่า 15 ถึง 20 เท่า ซึ่งตอกย้ำว่าแผ่นทองคำปิดทวารและเครื่องทองคำประจำสรีระเป็นตัวขับเคลื่อนหลักที่สร้างความแตกต่างทางชนชั้นในสังคมโบราณ [35]

### 6. บทสรุปสังเคราะห์ประจำบทที่ 6: วัตถุบารมีและระเบียบสังคมบารังไกย์

การวิเคราะห์อย่างลึกซึ้งในบทที่ 6 นี้ ได้นำพาเราไปสู่ข้อสรุปทางโบราณคดีและมานุษยวิทยาที่สำคัญยิ่งใน 4 ประการหลัก [36]:

ประการแรก **ฐานานุรูปและชนชั้นทางสังคม (ตอนที่ 6.1):** สังคมบารังไกย์มีการจัดช่วงชั้นอย่างเป็นระบบระหว่างชนชั้นดาตู ติมาวา และโอริปุน โดยความเชื่อเรื่องการเดินทางสู่ปรโลกตามบันทึกของ Loarca (1582) เป็นแรงผลักดันให้เกิดการฝังทรัพย์สินและการสังเวยทาสเพื่อธำรงสถานะอภิสิทธิ์ชนในโลกหน้า [37]

ประการที่สอง **เครื่องเคลือบนำเข้าและการค้าทางไกล (ตอนที่ 6.2):** เครื่องถ้วยซ่ง หยวน หมิง และสวรรคโลก ทำหน้าที่เป็นดัชนีกำหนดอายุสมัยและสินค้าบารมีระดับรองที่ใช้ในการเซ่นสรวงอาหารแก่บรรพชน แต่มีมูลค่าเกียรติยศที่น้อยกว่าทองคำอย่างมีนัยสำคัญ [38]

ประการที่สาม **เครื่องประดับและอาวุธประจำสรีระ (ตอนที่ 6.3 และ 6.4):** ลูกปัดคาร์เนเลียน ต่างหูทองคำ *panika* สร้อยคอ *kamagi* และกริชเหล็ก ถูกจัดวางตามตำแหน่งกายวิภาคจริง เพื่อสะท้อนถึงเกียรติยศนักรบ อัตลักษณ์ประจำตระกูล และการเป็นเกราะป้องกันทางจิตวิญญาณ [39]

ประการที่สี่ **ตัวแบบเชิงปริมาณและเศรษฐกิจการเมือง (ตอนที่ 6.5):** ทฤษฎีสินค้าเกียรติยศของ Barretto-Tesoro (2003) และการคำนวณดัชนีมูลค่าหลุมศพ (GVI) ได้พิสูจน์เชิงประจักษ์ว่า ความมั่งคั่งในสุสานมีการกระจุกตัวแบบพาเรโต โดยแผ่นทองคำปิดทวารเป็นตัวบ่งชี้สูงสุดของชนชั้นนำประเภทที่ 1 (Type 1 Elites) และการฝังทรัพย์สินทำหน้าที่เป็นกลไกการสืบทอดอำนาจทางการเมืองของสายตระกูล [40]

บทวิเคราะห์ทางเศรษฐกิจการเมืองและวัตถุบารมีในบทนี้ จะทำหน้าที่เป็นบทสังเคราะห์เชิงประจักษ์ขั้นสุดท้าย ก่อนที่จะก้าวเข้าสู่ **บทที่ 7: บทสรุป สมานภาพพิธีกรรมศพยุคก่อนอาณานิคม และทิศทางวิทยาศาสตร์โบราณคดี** ซึ่งจะประมวลคำตอบต่อคำถามวิจัยหลักทั้ง 4 ประการ นำเสนอแบบจำลองเชิงกระบวนทัศน์บูรณาการ (Integrated Gold Mortuary Model) และวางแนวทางวิทยาศาสตร์โบราณคดีสมัยใหม่ต่อไป [41]
