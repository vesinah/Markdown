#### [บทที่ 1: บทนำ บริบทประวัติศาสตร์โบราณคดี และข้อถกเถียงเรื่องหน้ากากทองคำ](file:///output/2026-10-20_สุสานแผ่นทองปิดศพฟิลิปปินส์/final/01-บทนำและบริบทประวัติศาสตร์โบราณคดี.md) (19,077.0 คำ | 247 เชิงอรรถ)
- **ตอนที่ 1.1:** ความเป็นมาและความสำคัญของปัญหา: ปริศนาทองคำปิดศพในเอเชียตะวันออกเฉียงใต้
- **ตอนที่ 1.2:** ภูมิหลังทางประวัติศาสตร์และโบราณคดียุคก่อนอาณานิคมของฟิลิปปินส์ (คริสต์ศตวรรษที่ 10–16)
- **ตอนที่ 1.3:** แหล่งโบราณคดีแกนกลาง 3 แห่ง: โอตอน (ปานาย), พลาซาอินเดเพนเดนเซีย (เซบู), และซูอาตัน/อัมบังกัน (บูตูอัน)
- **ตอนที่ 1.4:** ประวัติการค้นพบและสถานภาพการวิจัยในอดีต (Evangelista, Jocano, Hutterer, Burton)
- **ตอนที่ 1.5:** วัตถุประสงค์ คำถามวิจัย กรอบแนวคิดทฤษฎี และระเบียบวิธีวิจัยแบบบูรณาการ

#### [บทที่ 2: การฝังศพครั้งที่หนึ่งหรือครั้งที่สอง: การพิสูจน์ทางทาโฟโนมีและชีวโบราณคดี](file:///output/2026-10-20_สุสานแผ่นทองปิดศพฟิลิปปินส์/final/02-การฝังศพครั้งที่หนึ่งหรือครั้งที่สอง.md) (13,796.6 คำ | 220 เชิงอรรถ)
- **ตอนที่ 2.1:** นิยามและระเบียบวิธีวิจัยทางทาโฟโนมี (Taphonomy) ในการจำแนกลักษณะการฝังศพ
- **ตอนที่ 2.2:** หลักฐานโครงกระดูกและสัณฐานวิทยาการฝังศพที่โอตอน หลุมขุดค้นที่ 6 (Oton Grave 6)
- **ตอนที่ 2.3:** การวิเคราะห์ทางชีวโบราณคดีของสุสานพลาซาอินเดเพนเดนเซีย นครเซบู
- **ตอนที่ 2.4:** บริบทการฝังศพในโลงไม้ที่ซูอาตันและอัมบังกัน เมืองบูตูอัน
- **ตอนที่ 2.5:** ข้อสรุปทางทาโฟโนมี: การพิสูจน์ยืนยันการฝังศพครั้งแรก (100% Primary Inhumation)

#### [บทที่ 3: ปริศนาแห่งการฝังมิใช่เผา: การปฏิเสธการฌาปนกิจในพลวัตวัฒนธรรมออสโตรนีเชียน](file:///output/2026-10-20_สุสานแผ่นทองปิดศพฟิลิปปินส์/final/03-ปริศนาแห่งการฝังมิใช่เผา.md) (14,273.0 คำ | 221 เชิงอรรถ)
- **ตอนที่ 3.1:** ภูมิทัศน์ความเชื่อเรื่องความตายในเอเชียตะวันออกเฉียงใต้: การเผาศพปะทะการฝังดิน
- **ตอนที่ 3.2:** คติวิญญาณและจักรวาลวิทยาของกลุ่มประชากรตระกูลภาษาออสโตรนีเชียน (Austronesian Soul Concept)
- **ตอนที่ 3.3:** การรักษาสภาพสรีระเพื่อการเดินทางข้ามภพ (*Saad* และ *Sulad*)
- **ตอนที่ 3.4:** การใช้น้ำยางพลู (*Buyo*) และสมุนไพรในการถนอมศพโบราณ
- **ตอนที่ 3.5:** แผ่นทองคำปิดทวารในฐานะเกราะป้องกันทางอภิปรัชญาต่อปีศาจกินศพ (*Asuang*)

#### [บทที่ 4: ชัยภูมิ ภูมิทัศน์ และนิเวศวิทยาการตั้งถิ่นฐานของสุสานแผ่นทองคำ](file:///output/2026-10-20_สุสานแผ่นทองปิดศพฟิลิปปินส์/final/04-ชัยภูมิภูมิทัศน์และนิเวศวิทยาการตั้งถิ่นฐาน.md) (14,846.0 คำ | 215 เชิงอรรถ)
- **ตอนที่ 4.1:** ธรณีสัณฐานวิทยาและนิเวศวิทยาชายฝั่งของแหล่งโบราณคดีโอตอน บนเกาะปานาย
- **ตอนที่ 4.2:** ลานตะพักชายฝั่งและระบบนิเวศเมืองท่าโบราณที่พลาซาอินเดเพนเดนเซีย เซบู
- **ตอนที่ 4.3:** คันดินธรรมชาติริมแม่น้ำและที่ราบลุ่มน้ำท่วมถึงแม่น้ำอากูซัน เมืองบูตูอัน
- **ตอนที่ 4.4:** เมทริกซ์ 6 มิติเปรียบเทียบลักษณะทางอุทก-ธรณีวิทยาและการตั้งถิ่นฐาน
- **ตอนที่ 4.5:** การอ้างสิทธิ์เหนือทรัพยากรและอาณาเขตเชิงสัญลักษณ์ตามสมมติฐาน Saxe-Goldstein

#### [บทที่ 5: เรขาคณิตหลุมศพ สัณฐานวิทยาโลงไม้ การดัดแปลงสรีระ และช่างทองปิดทวาร](file:///output/2026-10-20_สุสานแผ่นทองปิดศพฟิลิปปินส์/final/05-เรขาคณิตหลุมศพสัณฐานวิทยาโลงไม้และการดัดแปลงสรีระ.md) (18,806.6 คำ | 263 เชิงอรรถ)
- **ตอนที่ 5.1:** สถาปัตยกรรมหลุมศพ ทิศทางการวางตัว และเรขาคณิตการฝัง
- **ตอนที่ 5.2:** สัณฐานวิทยาโลงไม้ท่อนเดียว (*Longon*) และเทคโนโลยีการต่อโลงด้วยสลักลิ่มไม้
- **ตอนที่ 5.3:** การดัดแปลงกะโหลกศีรษะให้ลาดแบน (*Tangad*) ในฐานะเครื่องหมายชนชั้นนำ
- **ตอนที่ 5.4:** ศิลปะการประดับฟันด้วยหมุดทองคำ (*Pusad*) และการย้อมสีฟัน
- **ตอนที่ 5.5:** เทคโนโลยีการทำแผ่นทองคำปิดตา ปิดจมูก ปิดปาก และการดุนลายจุดไข่ปลา (Repoussé)

#### [บทที่ 6: เครื่องอุทิศในหลุมศพ โครงสร้างทางสังคม และพลวัตอำนาจของชนชั้นดาตู](file:///output/2026-10-20_สุสานแผ่นทองปิดศพฟิลิปปินส์/final/06-เครื่องอุทิศในหลุมศพและพลวัตชนชั้น.md) (16,230.6 คำ | 227 เชิงอรรถ)
- **ตอนที่ 6.1:** การจำแนกประเภทและโบราณวัตถุวิทยาของเครื่องอุทิศในสุสาน (Grave Goods Assemblage)
- **ตอนที่ 6.2:** เครื่องเคลือบดินเผานำเข้าจากจีน (ซ่ง หยวน หมิง) เวียดนาม และสยาม (สวรรคโลก)
- **ตอนที่ 6.3:** เครื่องประดับทองคำ ลูกปัดหินมีค่า และเครื่องมืออาวุธโลหะ
- **ตอนที่ 6.4:** การแบ่งช่วงชั้นทางสังคม (Datu, Timawa, Oripun) และการประเมินดัชนีคุณค่าหลุมศพ (GVI)
- **ตอนที่ 6.5:** เศรษฐกิจการเมืองและการแปลงทุนพาณิชย์ข้ามสมุทรเป็นทุนสัญลักษณ์แห่งอำนาจ

#### [บทที่ 7: บทสรุป สมานภาพพิธีกรรมศพยุคก่อนอาณานิคม และทิศทางวิทยาศาสตร์โบราณคดี](file:///output/2026-10-20_สุสานแผ่นทองปิดศพฟิลิปปินส์/final/07-บทสรุปสมานภาพพิธีกรรมศพและวิทยาศาสตร์โบราณคดี.md) (12,774.4 คำ | 204 เชิงอรรถ)
- **ตอนที่ 7.1:** ประมวลสังเคราะห์คำตอบต่อคำถามวิจัยแกนกลาง 4 ประการอย่างรอบด้าน
- **ตอนที่ 7.2:** แบบจำลองเชิงกระบวนทัศน์สุสานวิทยาแผ่นทองคำแห่งฟิลิปปินส์ (The Integrated Philippine Gold Mortuary Model)
- **ตอนที่ 7.3:** การเปรียบเทียบในระดับภูมิภาคเอเชียตะวันออกเฉียงใต้ภาคพื้นสมุทรและดินแดนข้างเคียง (บรูไน ชวา บาหลี สยาม เวียดนาม จีน)
- **ตอนที่ 7.4:** การประเมินสถานภาพเอกสารขุดค้นภาคสนามและข้อจำกัดของหลักฐานโบราณคดี
- **ตอนที่ 7.5:** ทิศทางและข้อเสนอแนะวิทยาศาสตร์โบราณคดีสมัยใหม่ (Isotopes, aDNA, GC-MS, AMS $^{14}\text{C}$, และจริยธรรม)
