# อภิธานศัพท์และศัพท์เฉพาะทาง (Glossary): Trent Walker Scholarship

| ศัพท์ทางวิชาการ | คำอ่าน / ศัพท์ดั้งเดิม | นิยามและความหมายในงานของ Trent Walker |
|:---|:---|:---|
| **Bitext** | ตัวบททวิลักษณ์ | รูปแบบวรรณกรรมที่ร้อยเรียงภาษาคลาสสิก (บาลี/สันสกฤต) สลับคู่ขนานกับภาษาถิ่น (ไทย เขมร ลาว พม่า) อย่างเป็นระบบ ทำหน้าที่เป็นทั้งเครื่องมือการแปล อรรถกถา การเทศนา และฉันทลักษณ์เชิงกวีนิพนธ์ |
| **Epiphytic Literatures** | วรรณกรรมพืชอิงอาศัย | อุปมาทางพฤกษศาสตร์ที่วอล์กเกอร์สร้างขึ้น เพื่ออธิบายวรรณกรรมภาษาถิ่นที่เติบโตเกาะเกี่ยวกับภาษาบาลีประดุจพืชอิงอาศัย (เช่น กล้วยไม้ เฟิน) ซึ่งพึ่งพาต้นไม้ใหญ่โดยไม่ดูดกลืนทำลาย และสร้างระบบนิเวศทางวรรณกรรมที่งดงามร่วมกัน |
| **Smot** | ស្មូត្រ (สมูตร / สโมตร) | ศิลปะการขับขานบทกวีและลำนำธรรมะโบราณของกัมพูชา มีท่วงทำนองเอื้อนโหยหวนเพื่อถ่ายทอดหลักธรรมและเร้าอารมณ์ผู้ฟัง |
| **Saṃvega** | สํเวค (สังเวช) | ความสะเทือนใจทางธรรม อารมณ์สะพรึงกลัวต่อวัฏสงสาร ความตาย และการพลัดพราก ซึ่งทำหน้าที่เป็นพลังขับเคลื่อนสู่การปฏิบัติธรรม |
| **Pasāda** | ปสาท (ปสาทะ) | ความเลื่อมใส ความเบิกบาน ผ่องใส และความสงบระงับแห่งจิตใจอันเกิดจากการเห็นทางรอดพ้นทุกข์ ทำงานเป็นคู่ขนานกับสังเวชในบทเพลงธรรมะ |
| **Leporello Manuscript** | สมุดข่อย / สมุดไทย / ក្រាំង (กรั้ง) | เอกสารตัวเขียนกระดาษข่อยพับทบไปมา ใช้บันทึกบทสวดพระมาลัย พระอภิธรรม และบทสวดเฉพาะกิจ โดยทำหน้าที่เป็นวัตถุพิธีกรรม ณ วาระสุดท้ายแห่งชีวิต |
| **The Work of the Dying** | ภารกิจของผู้ใกล้ตาย | มโนทัศน์ที่มองว่าการตายมิใช่ภาวะเฉื่อยชา แต่เป็น " ภาระงานทางจิตและพิธีกรรม\ ที่ผู้ป่วยใกล้ตาย ชุมชน และพระสงฆ์ร่วมกันปฏิบัติผ่านเสียงสวดและคัมภีร์นำทาง |
| **Nissaya / Vohāra / Rāi wat / Samray** | นิสสัย / โวหาร / ร่ายวัด / สำราย | ชื่อเรียกจำเพาะของรูปแบบตัวบททวิลักษณ์ในแต่ละวัฒนธรรม: พม่า/ล้านนา (Nissaya), ล้านนา/ลาว (Vohāra), สยาม/ลาว (Rāi wat), กัมพูชา (Samray) |
| **Kham Luang** | คำหลวง | วรรณกรรมชั้นสูงสมัยอยุธยา (เช่น มหาชาติคำหลวง นันโทปนันทสูตรคำหลวง พระมาลัยคำหลวง) ซึ่งเป็นตัวบททวิลักษณ์ชั้นเยี่ยมผสานบาลีกับกวีนิพนธ์ไทยหลากฉันทลักษณ์ |
| **Living Phonologies** | สัทวิทยาที่มีชีวิต | มโนทัศน์ของวอล์กเกอร์ที่ศึกษาการออกเสียงภาษาบาลีสำเนียงเขมร ซึ่งสะท้อนปฏิสัมพันธ์อันซับซ้อนระหว่างอักขรวิธีตัวเขียนและการสวดท่องด้วยปากเปล่า |
| **Unified Transliteration System** | ระบบปริวรรตอักษรร่วมอุษาคเนย์ | ระบบการถอดอักษรตระกูลพราหมีในอุษาคเนย์ภาคพื้นทวีป (ไทย เขมร ลาว มอญ ไทธรรม ไทใต้คง) ที่วอล์กเกอร์สังเคราะห์ขึ้นเพื่อใช้ถอดอักษรข้ามระบบได้อย่างแม่นยำตัวต่อตัว |
| **Don Chi** | ดอนชี (ดอนจี / ยายชี) | แม่ชีในพุทธศาสนากัมพูชา ผู้ถือศีลแปดหรือสิบ และมีบทบาทสำคัญในการขับสวดสมูตร ตลอดจนการชำระหนี้บุญคุณต่อบิดามารดา |
| **Bangsokol** | បង្សុកូល (บังสุกุล) | พิธีกรรมและบทสวดพิจารณาผ้าเปื้อนฝุ่น/ซากศพ ซึ่งถูกนำมาสร้างสรรค์เป็นชื่ออุปรากรพิธีกรรมร่วมสมัยเพื่อเยียวยาบาดแผลทางจิตวิญญาณจากการฆ่าล้างเผ่าพันธุ์ |
