## 1. บทนำแม่บทและข้อมูลเชิงประจักษ์ (Master Introduction & Empirical Scope)

วิทยานิพนธ์ระดับปริญญาเอกสาขาพุทธศาสนศึกษา (Buddhist Studies) ณ มหาวิทยาลัยแคลิฟอร์เนีย เบิร์กลีย์ (University of California, Berkeley) สำเร็จในปี ค.ศ. 2018 ความยาวรวมมหาศาลถึง **1,652 หน้า** ภายใต้ชื่อเรื่อง:
> **"Unfolding Buddhism: Communal Scripts, Localized Translations, and the Work of the Dying in Cambodian Chanted Leporellos"**  
> *(คลี่พุทธศาสน์: ตัวเขียนชุมชน การแปลปริวรรตสู่ท้องถิ่น และพันธกิจแห่งผู้ใกล้ดับขันธ์ในคัมภีร์สมุดข่อยขับสวดของกัมพูชา)* [1]

งานวิจัยชิ้นนี้จัดทำขึ้นภายใต้การดูแลของคณะกรรมการวิทยานิพนธ์ชั้นนำระดับโลก 5 ท่าน:
1. **ศาสตราจารย์ ดร. Alexander von Rospatt** (ประธานกรรมการ) — ผู้เชี่ยวชาญด้านพุทธศาสนาเนปาลและคัมภีร์ภาษาสันสกฤต
2. **ศาสตราจารย์ ดร. Penelope Edwards** — ศาสตราจารย์ประวัติศาสตร์เอเชียตะวันออกเฉียงใต้และประวัติศาสตร์กัมพูชา ผู้เขียน *Cambodge: The Cultivation of a Nation*
3. **ศาสตราจารย์ ดร. Peter S. E. Jenks** — ศาสตราจารย์ด้านภาษาศาสตร์ (Linguistics) และไวยากรณ์เปรียบเทียบ
4. **ศาสตราจารย์ ดร. Olivier de Bernon** — ผู้อำนวยการฝ่ายวิจัย สำนักฝรั่งเศสแห่งปลายบุรพทิศ (EFEO) และผู้ก่อตั้งกองทุนเพื่อการอนุรักษ์เอกสารตัวเขียนกัมพูชา (FEMC)

ความโดดเด่นขั้นสูงสุดของวิทยานิพนธ์ฉบับนี้ คือการสร้างฐานข้อมูลเชิงประจักษ์ (Empirical Database) จากการลงพื้นที่ภาคสนามในประเทศกัมพูชาเป็นเวลากว่า 2 ปี (2016–2018) ร่วมกับนักวิชาการอาวุโสแห่ง EFEO/FEMC ได้แก่ Olivier de Bernon, Kun Sopheap, และ Leng Kok-An ตลอดจนผู้ช่วยวิจัยชาวกัมพูชา Muoch Khoeun และ Chhot Sopheak โดยทำการสืบค้น สำรวจ ทำความสะอาด บูรณะ ถ่ายภาพดิจิทัล และถอดอักขระเอกสารตัวเขียนสมุดข่อยเขมรโบราณ ณ หอสมุดวัดสาราวันเตโช (Vatt Sārāvăn Tejo) และอารามต่างๆ ทั่วกัมพูชา

งานวิจัยมีขอบเขตข้อมูลปฐมภูมิที่ประกอบด้วย:
- **คลังสมุดข่อยตัวเขียน (Leporellos / กรั้งเขมร) จำนวน 70 เล่มบริบูรณ์** ซึ่งวอล์กเกอร์กำหนดรหัสตั้งแต่ **UB001 ถึง UB070** (UB ย่อมาจาก *Unfolding Buddhism*)
- **คลังตัวบทสวด (Textual Corpus) ทั้งสิ้น 195 เรื่อง** ประกอบด้วยตัวบทภาษาบาลี ภาษาเขมร และภาษาไทย/สยาม ซึ่งได้รับการจัดทำฉบับตรวจชำระทางวิชาการ (Critical Editions) บันทึกคำแปรเปลี่ยน (Textual variants) ถอดอักขระเป็นอักษรโรมันสากล และแปลเป็นภาษาอังกฤษครบทั้ง 195 เรื่อง
- **ช่วงเวลาทางประวัติศาสตร์:** ครอบคลุมคริสต์ศตวรรษที่ 17 ถึงปลายศตวรรษที่ 19 (ตั้งแต่ยุคหลังพระนคร หรือ Middle Cambodia จนถึงยุคต้นอาณานิคมฝรั่งเศส)
- **ประเด็นศึกษาใจกลาง:** บทบาทของตัวเขียนและบทสวดใน **"พิธีกรรมวาระสุดท้ายของชีวิต" (End-of-Life Rites)** ได้แก่ การดูแลผู้ป่วยหนัก การสวดนำทางจิตของผู้ใกล้หมดลมหายใจ พิธีศพ และพิธีพุทธาภิเษกเบิกพระเนตรพระพุทธรูปเพื่ออุทิศส่วนกุศล

## 2. บทที่ 1: การคลี่คัมภีร์และโลกพุทธเขมร-ไท (Chapter 1: Introduction, หน้า 1–47)

### 2.1 มโนทัศน์ "Unfolding" และปรัชญาญาณวิทยา (1.1 Unfolding Buddhism)
วอล์กเกอร์เปิดบทนำด้วยการนิยามคำว่า **"Unfolding" (การคลี่ออก)** ซึ่งมิได้เป็นเพียงคำอธิบายกิริยาทางกายภาพ แต่เป็น "กรอบทฤษฎีทางญาณวิทยา" (Epistemological Framework) ที่มี 3 มิติซ้อนทับกันอย่างลึกซึ้ง:

```
+---------------------------------------------------------------------------------------------------+
|               สามมิติแห่งการคลี่คัมภีร์ (Three Dimensions of Unfolding Buddhism)                    |
+---------------------------------------------------------------------------------------------------+
|  1. มิติกายภาพของเอกสารตัวเขียน (Material Dimension):                                             |
|     - การคลี่หน้าสมุดข่อย (Leporello / กรั้ง / สมุดไทย) ที่พับทบไปมาแบบบานพับพัด (Accordion fold)    |
|     - หน้ากระดาษมิได้พลิกทีละแผ่นเหมือนหนังสือฝรั่ง แต่คลี่ขยายออกเป็นสายธารข้อความที่ยาวต่อเนื่อง    |
|     - การคลี่เผยให้เห็นความสัมพันธ์ระหว่างตัวบทหลัก (Text) กับข้อความประกอบรอบตัวบท (Paratexts)    |
|                                                                                                   |
|  2. มิติทางพิธีกรรมและผัสสะ (Ritual & Sensory Dimension):                                         |
|     - การคลี่คลายของขั้นตอนพิธีกรรมข้างเตียงคนป่วยหนัก (Deathbed Liturgy) จากความตระหนกสู่ความสงบ    |
|     - การคลี่คลายของม่านเสียงสวด (Sonic unfolding) ที่เริ่มจากบทนมัสการบาลีอันขรึมขลัง               |
|       ไหลรินสู่กวีนิพนธ์เตือนสติภาษาถิ่นที่ขับขานด้วยทำนองสโมต (Smot) อันโศกซึ้งและแจ่มใส            |
|                                                                                                   |
|  3. มิติทางประวัติศาสตร์ภูมิปัญญา (Intellectual & Historiographical Dimension):                   |
|     - การคลี่เปิดมิติใหม่ของพุทธศาสนาเถรวาทในอุษาคเนย์ ซึ่งถูกบดบังด้วยมายาคติอาณานิคมมานาน        |
|     - รื้อถอนภาพจำว่าพุทธศาสนาเป็นเพียงปรัชญานามธรรมในคัมภีร์บาลีบริสุทธิ์                           |
|     - เผยให้เห็นพุทธศาสนาที่มีชีวิตชีวา หยั่งรากในวิถีชุมชน และผูกพันกับลมหายใจสุดท้ายของมนุษย์     |
+---------------------------------------------------------------------------------------------------+
```

วอล์กเกอร์ชี้ว่า การศึกษาพุทธศาสนาในอดีตมักมองข้ามเอกสารตัวเขียนสมุดข่อยประเภทนี้ เพราะนักวิชาการชาวยุโรปมักมุ่งค้นหาเฉพาะ "พระไตรปิฎกฉบับสมบูรณ์" บนคัมภีร์ใบลาน (Palm-leaf manuscripts) และมองข้ามสมุดข่อยว่าเป็นเพียงหนังสือสวดมนต์ของชาวบ้านที่ปะปนด้วยความเชื่อนอกรีต การ "คลี่" คัมภีร์สมุดข่อย 70 เล่มในงานวิจัยนี้จึงเป็นการฟื้นคืนเสียงที่ถูกทำให้เงียบงันในประวัติศาสตร์พุทธศาสนาอุษาคเนย์

### 2.2 โลกวัฒนธรรมพุทธร่วมเขมร-ไท (1.2 Khmer-Tai Buddhism and Manuscript Culture)
ในหัวข้อ 1.2 วอล์กเกอร์ได้สร้างคุณูปการสำคัญทางประวัติศาสตร์นิพนธ์ ด้วยการเสนอแนวคิด **"โลกวัฒนธรรมพุทธร่วมเขมร-ไท" (The Khmer-Tai Buddhist Continuum / Khmer-Tai Buddhist World)** เพื่ออธิบายพลวัตทางวัฒนธรรมของภูมิภาคภาคพื้นทวีปเอเชียตะวันออกเฉียงใต้ในช่วงศตวรรษที่ 17 ถึง 19 [2]:
- **การก้าวข้ามเส้นแบ่งรัฐชาติสมัยใหม่:** เขตแดนระหว่างสยาม (อยุธยาและรัตนโกสินทร์), กัมพูชา (ละแวก อุดงค์ พนมเปญ), ลาว (ล้านช้าง), และล้านนา ในยุคก่อนสมัยใหม่มิได้เป็นพรมแดนปิดกั้นทางวัฒนธรรม แต่เป็นพื้นที่ที่มีการไหลเวียนถ่ายเทของผู้คน ตำรา คัมภีร์ และพระสงฆ์
- **เอกภาพทางอักขรวิทยา (Palaeographic Unity):** วัฒนธรรมเขมรและสยามต่างใช้ **"อักษรขอม"** (Khmer script) เป็นอักขระศักดิ์สิทธิ์ในการจารึกพระธรรมภาษาบาลีและภาษาสันสกฤต พระภิกษุชาวสยามสามารถอ่านคัมภีร์บาลีอักษรขอมของกัมพูชาได้ และพระสงฆ์เขมรก็สามารถอ่านคัมภีร์ที่จารจากราชสำนักอยุธยาได้อย่างราบรื่น
- **สมุดข่อย (Leporello) vs คัมภีร์ใบลาน (Palm Leaf):** ในขณะที่คัมภีร์ใบลาน (สาสตราสแลก / คัมภีร์ใบลานผูก) มักใช้สำหรับบันทึกพระไตรปิฎก อรรถกถา และคัมภีร์หลวงที่มีขนาดยาวเพื่อเก็บรักษาไว้ในหอไตร แต่ **"สมุดข่อย" (กรั้ง / สมุดไทย)** ทำหน้าที่เป็นคัมภีร์สำหรับ **"การพกพาไปใช้งานจริงในพิธีกรรม" (Portable Ritual Manuals)** สมุดข่อยมีความทนทาน เปิดอ่านได้รวดเร็ว สามารถวางตั้งบนตักหรือบนโต๊ะเตี้ยข้างเตียงผู้ป่วยได้สะดวก และเปิดพื้นที่ให้มีภาพวาดลายเส้นประกอบการเทศนา

### 2.3 การรื้อถอนศูนย์กลางบาลีบริสุทธิ์และโสตทัศน์ศึกษา (1.3 Manuscripts, Translation, and the End of Life)
วอล์กเกอร์วิพากษ์แนวคิดกระแสหลักในพุทธศาสนศึกษา 3 ประการ:
1. **วิพากษ์ Pali Purism (คตินิยมบาลีบริสุทธิ์):** ที่มองว่ามีเพียงตัวบทภาษาบาลีแท้เท่านั้นที่มีความสำคัญทางวิชาการ วอล์กเกอร์ชี้ว่าในชีวิตจริงของชาวพุทธเถรวาท ภาษาถิ่น (เขมร ไทย ลาว) มิได้เป็นเพียงเครื่องมือชั้นสอง แต่เป็นพื้นที่ที่พระธรรมได้รับการตีความ ปรับประยุกต์ และสร้างสุนทรียรสทางจิตวิญญาณ
2. **บุกเบิก Aural & Sonic Buddhism (พุทธศาสน์ทางเสียง):** ศาสนาพุทธมิใช่ศาสนาแห่งการอ่านเงียบๆ ในใจ (Silent reading) แต่เป็นศาสนาแห่งเสียงขับขาน (Chanted sound) เสียงสวดมีอำนาจในการเปลี่ยนแปลงสภาวะจิตใจของผู้ฟัง ก่อให้เกิดอารมณ์ทางศาสนาขั้นสูง
3. **การให้ความสำคัญกับ "วาระสุดท้ายของชีวิต":** ความตายในพุทธศาสนามิใช่เรื่องอัปมงคลที่ต้องหลีกเลี่ยง แต่เป็น "จุดทดสอบสูงสุดแห่งการปฏิบัติธรรม" การศึกษาพุทธศาสนาจึงไม่สามารถละเลยพิธีกรรมข้างเตียงคนตายและวรรณกรรมที่ใช้ขับขานในขณะจิตสุดท้ายได้

### 2.4 ระเบียบวิธีวิจัยและภาคสนาม 2 ปี ณ หอสมุดวัดสาราวันเตโช (1.4 Methods)
ในหัวข้อ 1.4 วอล์กเกอร์ได้แจกแจงระเบียบวิธีวิจัยที่ผสมผสาน 4 ศาสตร์หลัก:
- **บรรพชีวินวิทยาและวัฒนธรรมเอกสารตัวเขียน (Codicology & Manuscript Studies):** วิเคราะห์คุณสมบัติทางกายภาพ ชนิดของเยื่อกระดาษ (เปลือกข่อย/ปอสา) ความหนาแน่น การพับ สีย้อมกระดาษ ชนิดของหมึก (หมึกเขม่าดำ หมึกหรดาลสีเหลือง หมึกชาดสีแดง หมึกทอง) และรอยการใช้งาน
- **นิรุกติศาสตร์ตัวเขียนเชิงวิพากษ์ (Critical Textual Philology):** รวบรวมสำเนาตัวเขียนที่หลากหลาย (Variants) จัดทำฉบับตรวจชำระมาตรฐาน กำหนดระบบการถอดอักษรโรมันสากลที่สะท้อนทั้งอักขรวิธีโบราณและสัทวิทยาทางเสียง
- **ทฤษฎีการแปล (Translation Studies):** ใช้กรอบคิดการแปลวรรณกรรมเปรียบเทียบ วิเคราะห์กลวิธีการแปลบาลีสู่เขมรและไทย
- **มานุษยวิทยาดนตรีและศาสนพิธี (Ethnomusicology & Ritual Studies):** สัมภาษณ์พระสงฆ์ นักสวดสโมต (Smot masters) ฆราวาสผู้นำสวด (Achar) เพื่อทำความเข้าใจบริบทการใช้งานจริงในชุมชน [3]
## 3. ภาคที่ 1: ตัวเขียนเพื่อชุมชนและจังหวะแห่งพิธีกรรม (Part I: Communal Scripts)

### 3.1 บทที่ 2: คัมภีร์สมุดข่อยชุมชน (Chapter 2: Communal Manuscripts, หน้า 48–99)

#### 3.1.1 กายวิภาคสมุดข่อยตัวอย่าง UB015 (Unfolding UB015)
ในหัวข้อ 2.2 วอล์กเกอร์ได้พาผู้อ่าน "คลี่" เอกสารตัวเขียนสมุดข่อยรหัส **UB015** (จัดเก็บ ณ หอสมุดวัดสาราวันเตโช กรุงพนมเปญ อดีตคอลเลกชันของสมเด็จพระวันรัต เกน วงศ์) เพื่อแสดงให้เห็นกายวิภาคอันซับซ้อนของสมุดข่อยชุมชนเล่มจริง [4]:
- **ลักษณะทางกายภาพ:** สมุดข่อยขาว (ทำจากเยื่อเปลือกข่อยธรรมชาติ สีน้ำตาลอ่อนอมเหลือง) มีขนาดกว้าง 11.5 ซม. ยาว 36.5 ซม. หนา 93 หน้าพับ (Folded leaves) แบ่งเป็นด้านหน้า (Recto: หน้า 1a ถึง 93b) และด้านหลัง (Verso: หน้า 94a ถึง 186b)
- **การปรากฏของอาลักษณ์หลายรุ่น (Multiple Scribal Hands):** สมุดข่อยมิได้ถูกเขียนขึ้นรวดเดียวโดยคนคนเดียว แต่พบรอยมือจารอย่างน้อย 4 ลายมือที่แตกต่างกัน ซึ่งเขียนขึ้นในช่วงเวลาต่างกันตั้งแต่ปลายศตวรรษที่ 18 ถึงต้นศตวรรษที่ 19 สะท้อนว่าคัมภีร์เล่มนี้ถูกส่งต่อ ปรับปรุง และจารเพิ่มเติมโดยภิกษุและอาลักษณ์หลายรุ่นในอารามเดียวกัน
- **สารบัญและโครงสร้างตัวบทภายใน UB015:**
  - *หน้า 1a–12b:* พระปริตรมงคลสูตรและรัตนสูตร (บาลี)
  - *หน้า 13a–35b:* พระมาติกาอภิธรรม 7 คัมภีร์ (สัง วิ ธา ปุ กะ ยะ ปะ) พร้อมคำแปลสำรายสลับวลี
  - *หน้า 36a–44b:* **คิริมานนทสูตร (Girimānanda-sutta-CP)** บาลีพุทธพจน์ว่าด้วยสัญญา 10 ประการเพื่อระงับเวทนาของผู้ป่วยหนัก พร้อมเครื่องหมายกำกับเสียงสวดรูปหางวัว (*go mūtr*)
  - *หน้า 44b:* จารึกท้ายเรื่องเป็นภาษาเขมรปนไทย: `จบแล้ว` (jăp lév)
  - *หน้า 45a–53b:* **บทลาบาป "ภันเต ภควา" (lā pāp «bhante bhagavā»-k)** กวีนิพนธ์เขมรฉันท์กากคติว่าด้วยการขอขมาโทษต่อพระพุทธองค์
  - *หน้า 54a–66b:* **บททำขวัญนาค (khvān' nāg-r)** ร้อยแก้วพากย์ร่ายสำหรับพิธีบรรพชาอุปสมบท
  - *หน้า 66b:* จารึกอธิษฐานจิตของผู้จาร: `ខ្ញុំសូមปรารถนาជួបនឹងพระพุทธพระธรรมพระสงฆ์เกิดอนาคตชาติ...` (ข้าพเจ้าขอปรารถนาพบพระพุทธ พระธรรม พระสงฆ์ ในอนาคตชาติ ขออย่าให้มีอุปสรรคขัดขวาง)
  - *หน้า 67a–86a:* **ไตรลักษณสังเขปโบราณ (trailakkha(ṇ) «rūpaṃ dukkhaṃ» purāṇ-k)** กวีนิพนธ์พรรณนาอนิจจัง ทุกขัง อนัตตา และความน่าสะพรึงกลัวของความตาย
  - *หน้า 86a–93b:* **อานิสงส์อาการวัตตาสูตร (ānisaṅs ākāravattā-br)** บทสรรเสริญผลบุญของการสวดพระพุทธคุณ

#### 3.1.2 การประมวลคลังสมุดข่อย 70 เล่ม (UB001–UB070)
ในหัวข้อ 2.3 วอล์กเกอร์ได้นำเสนอผลการวิเคราะห์เชิงสถิติของสมุดข่อยทั้ง 70 เล่มในโครงการวิจัย:
- **การกระจายตัวทางภูมิศาสตร์:** สมุดข่อยส่วนใหญ่รวบรวมมาจากอารามเก่าแก่ในจังหวัดพนมเปญ, กันดาล, กัมปงจาม, กัมปงฉนัง, เสียมราฐ, พระตะบอง, และจังหวัดทางภาคใต้ของกัมพูชา
- **อายุสมัยของเอกสาร:** มีสมุดข่อย 18 เล่มที่ระบุจุลศักราช (CS) หรือพุทธศักราช (BE) ไว้อย่างชัดเจนในจารึกท้ายเรื่อง โดยเล่มที่เก่าแก่ที่สุดที่มีหลักฐานระบุปี คัดลอกในปี ค.ศ. 1792 (พ.ศ. 2335) และส่วนใหญ่อยู่ในช่วง ค.ศ. 1820–1890 ส่วนสมุดข่อยที่ไม่ระบุปี เมื่อตรวจสอบลักษณะทางภาษา อักขรวิธี และลายมือ พบว่ามีบางเล่มที่มีอายุย้อนไปถึงช่วงปลายศตวรรษที่ 17 ถึงต้นศตวรรษที่ 18
- **สภาพการอนุรักษ์:** สมุดข่อยเป็นเอกสารที่รอดพ้นจากการทำลายล้างครั้งใหญ่ในยุคเขมรแดง (1975–1979) มาได้อย่างปาฏิหาริย์ โดยชาวบ้านและพระสงฆ์ผู้มีศรัทธาได้นำไปซุกซ่อนไว้ในโพรงเพดานโบสถ์ ในไหดินเผาฝังดิน หรือลักลอบนำติดตัวไปในค่ายผู้ลี้ภัยชายแดนไทย

#### 3.1.3 เครือข่ายทางสังคม: ผู้จาร ผู้บริจาค และผู้อุทิศ (2.4 Scribes, Donors, and Dedicatees)
วอล์กเกอร์ชี้ให้เห็นว่า สมุดข่อยมิได้เกิดขึ้นจากปัจเจกบุคคลที่โดดเดี่ยว แต่เป็นผลผลิตของ **"เครือข่ายความสัมพันธ์ทางสังคมของชุมชน"** ดังที่ปรากฏในบันทึกท้ายเรื่อง (Colophons):
- **ผู้บริจาค (Donors / มหาอุบาสก-อุบาสิกา):** มักเป็นคฤหัสถ์ผู้มีฐานะ ผู้นำหมู่บ้าน หรือครอบครัวของคนป่วย ที่รวบรวมจตุปัจจัยว่าจ้างอาลักษณ์ให้จัดทำสมุดข่อยขึ้น เพื่อใช้สวดรักษาผู้ป่วย หรือสวดนำทางวิญญาณของบิดามารดาที่ล่วงลับ
- **ผู้จาร (Scribes / อาลักษณ์):** มีทั้งพระภิกษุ สามเณร และอดีตพระภิกษุที่สึกออกมาเป็นทิด (Achar) ซึ่งมีความชำนาญทั้งอักษรขอมมุลและขอมเชรียง การจารสมุดข่อยถือเป็นการบำเพ็ญ "ธรรมทาน" ขั้นสูง
- **ผู้อุทิศ (Dedicatees):** ส่วนใหญ่ระบุชื่อบิดา มารดา ปู่ย่า ตายาย ครูบาอาจารย์ หรือญาติผู้ล่วงลับ โดยมุ่งหวังให้ผลานิสงส์แห่งการสร้างคัมภีร์ช่วยปลดเปลื้องผู้วายชนม์จากนรกภูมิและนำพาไปสู่วิมานในสวรรค์ชั้นดาวดึงส์หรือดุสิต

#### 3.1.4 คำวิงวอนและจริยธรรมการรักษาคัมภีร์ (2.5 Appeals to Take Care of Manuscripts)
ปรากฏการณ์ที่น่าประทับใจยิ่งในสมุดข่อยเขมร คือการที่อาลักษณ์มักจารข้อความวิงวอนและวางกฎเกณฑ์ทางจริยธรรมในการใช้งานคัมภีร์ไว้ตอนต้นหรือตอนท้ายเล่ม:
- **ข้อห้ามทางกายภาพ:** ห้ามวางคัมภีร์ไว้บนพื้น ห้ามเหยียบข้าม ห้ามนำไปวางไว้ใต้ที่นอนหรือในที่ต่ำ ห้ามใช้นิ้วเปื้อนน้ำลายเปิดแผ่นพับ และห้ามให้เด็กเล็กนำไปฉีกเล่น
- **จริยธรรมการยืม-คืน (Borrowing Ethics):** สมุดข่อยเป็นสมบัติส่วนรวมของวัดที่ชาวบ้านสามารถยืมไปสวดที่บ้านยามมีคนเจ็บไข้ได้ป่วย อาลักษณ์จึงมักจารเตือนว่า "เมื่อยืมไปใช้สวดเสร็จแล้ว ขอให้รีบนำมาส่งคืนวัดโดยเร็ว อย่าเก็บไว้เป็นสมบัติส่วนตน เพื่อให้เพื่อนบ้านคนอื่นได้นำไปใช้สวดช่วยชีวิตในยามฉุกเฉินต่อไป ผู้ใดขโมยหรือยึดคัมภีร์ไว้ ขอให้ตกนรกอเวจี"

#### 3.1.5 คำขอขมาและขอให้ผู้รู้ช่วยแก้ไขข้อผิดพลาด (2.6 Apologies and Appeals for Correction)
อาลักษณ์โบราณมักแสดงความถ่อมตนอย่างยิ่งต่อพระธรรม โดยมักจารบทกวีสั้นๆ ขออภัยต่อความผิดพลาด:
- "ตัวข้าพเจ้าผู้จารนี้มีปัญญาน้อย ตาฝ้าฟาง มือสั่น หากมีตัวอักษรใดตกหล่น ขาดเกิน หรือวิภัตติผิดเพี้ยนไป ขอพระมหาเถระและท่านผู้รู้ทั้งหลายอย่าได้ตำหนิติเตียนเลย ขอเมตตาช่วยขูดลบและแก้ไขให้ถูกต้องด้วยเถิด เพื่อประโยชน์แห่งพระสัทธรรม"

#### 3.2.2 เจาะลึกบทสวดบาลีพุทธพจน์และบาลีนอกคัมภีร์ (3.3–3.8)
- **บทสวดบาลีพุทธพจน์ (Canonical Texts):** พระสงฆ์จะใช้สวดเพื่อสร้างฐานแห่งความศักดิ์สิทธิ์ เช่น *ธัมมจักกัปปวัตตนสูตร* (ปฐมเทศนา), *อนัตตลักขณสูตร* (การพิจารณาขันธ์ 5 ว่าไม่ใช่ตน), *รัตนสูตร* (การปัดเป่าเสนียดจัญไรและโรคภัย), และ *คิริมานนทสูตร* (การระงับเวทนาด้วยการเจริญสัญญา 10 ประการ)
- **บทสวดบาลีรจนาใหม่ (Non-Canonical Texts):** เป็นผลงานการรจนาของพระเถระในอุษาคเนย์ที่มีชื่อเสียงยิ่ง ได้แก่
  - *พระมาติกาอภิธรรม 7 คัมภีร์:* สังคณี วิภังค์ ธาตุกถา ปุคคลบัญญัติ กถาวัตถุ ยมก ปัฏฐาน (สัง วิ ธา ปุ กะ ยะ ปะ) ซึ่งเชื่อกันว่ามีพลังสูงสุดในการนำทางจิตผู้ตาย
  - *คัมภีร์ทศบารมี:* พรรณนาการบำเพ็ญบารมี 10 ทัศของพระโพธิสัตว์
  - *คาถาชินบัญชร และ พาหุงมหากา:* บทสวดพุทธชัยมงคลเพื่อคุ้มครองดวงวิญญาณจากเหล่าภูตผีและนายยมราช

#### 3.2.3 ตัวบททวิลักษณ์บาลี-เขมร (3.9–3.12)
ตัวบทในกลุ่มนี้เป็นการผสานสองภาษาเข้าสู่ฉันทลักษณ์เขมรอย่างประณีต คำบาลีหนึ่งวรรคจะถูกประกบด้วยร้อยกรองเขมรที่ขับขานรับสัมผัสกัน เช่น ในฉันท์พรหมคีติสองภาษา (II-8) คาถาบาลีจะทำหน้าที่เป็นต้นเสียง และวรรคภาษาเขมรจะทำหน้าที่ขยายความหมายเชิงเทศนา ทำให้ผู้ป่วยและญาติที่มาร่วมฟังข้างเตียงสามารถเข้าใจธรรมะได้โดยตรง

#### 3.2.4 กวีนิพนธ์ภาษาถิ่น (3.13–3.20)
บทสวดภาษาถิ่นเขมรและสยามในสมุดข่อยถือเป็นสุดยอดวรรณศิลป์ทางศาสนา:
- **ฉันท์กากคติ (-k):** จังหวะกระชับ ฉับไว ใช้สำหรับการพรรณนาภาพพญายม นายนิรยบาล และฉากการตัดสินกรรมในนรก
- **ฉันท์พรหมคีติ (-br):** ท่วงทำนองสง่างาม อ่อนช้อย ใช้สำหรับการพรรณนาพระพุทธคุณ การอธิษฐานจิต และบทสรรเสริญพระบารมี
- **กลอนสยามยานีและฉบัง (-y/ch):** ปรากฏในสมุดข่อยเขมรหลายเล่ม โดยจารด้วยอักษรไทยย่อหรืออักษรขอมสยาม เป็นบทสวดพระอภิธรรมและพระมาลัยกลอนสวด ซึ่งพระสงฆ์เขมรขับขานด้วยสำเนียงสยามได้อย่างคล่องแคล่ว สะท้อนการแลกเปลี่ยนข้ามวัฒนธรรม

#### 3.2.5 สองมิติแห่งพิธีกรรม: สวดข้างเตียงคนตาย vs พุทธาภิเษกเบิกพระเนตรพระพุทธรูป
ข้อค้นพบที่ลึกซึ้งที่สุดของบทที่ 3 คือความสอดคล้องเชิงโครงสร้างระหว่าง 2 พิธีกรรม:
1. **พิธีกรรมข้างเตียงคนตาย (Deathbed Liturgy):** มุ่งเน้นการ "ถอดถอนจิต" ของมนุษย์ออกจากร่างสังขารที่แตกดับ เพื่อนำจิตเข้าสู่อารมณ์พระนิพพานหรือสุคติภูมิ
2. **พิธีพุทธาภิเษก (Buddhābhiseka):** มุ่งเน้นการ "ประดิษฐานจิตและพระบารมี" ของพระพุทธองค์ลงในองค์พระพุทธรูปปูน โลหะ หรือไม้ เพื่อเบิกพระเนตรให้กลายเป็นรูปเคารพที่มีชีวิต
บทสวดที่ใช้ในทั้งสองพิธีกรรมเป็นบทชุดเดียวกันเกือบทั้งหมด เพราะชาวพุทธเขมร-ไทมองว่า การดับขันธ์ของมนุษย์และการกำเนิดของพระพุทธรูป ล้วนเป็นกระบวนการเปลี่ยนผ่านข้ามพรมแดนระหว่าง "โลกสังสารวัฏ" กับ "โลกุตตรธรรม" [5]
### 3.3 บทที่ 4: บทสำหรับปฏิบัติการทางเสียง (Chapter 4: Scripts for Performance, หน้า 187–254)

#### 3.3.1 ข้อความประกอบตัวบท (Paratexts) ในสมุดเขมรและสยาม (4.2)
ในบทที่ 4 วอล์กเกอร์ได้วิเคราะห์สมุดข่อยในฐานะ "บทกำกับการแสดงสด" (Scripts for Performance) โดยเน้นศึกษา **ข้อความประกอบตัวบท (Paratexts)** ซึ่งทำหน้าที่เป็นสะพานเชื่อมระหว่างตัวหนังสือที่จารอยู่บนหน้ากระดาษกับเสียงขับขานจริงในพิธีกรรม [6]:
- **ชื่อบทและคำชี้แจงหัวข้อ:** เช่น การระบุคำว่า `sūtr niṅ bāky` (สวดเป็นร้อยแก้วหรือคำกลอน), `thvœ̄ phlūv` (บทสวดนำทาง), `saṅvega` (บทสวดทำนองสังเวช)
- **การเทียบเคียงกับสมุดสวดสยาม:** วอล์กเกอร์ได้ศึกษาเปรียบเทียบสมุดข่อยเขมรกับสมุดสวดพระอภิธรรมและสมุดภาพไตรภูมิสมัยอยุธยาและรัตนโกสินทร์ตอนต้น (เช่น คอลเลกชันในหอสมุดแห่งชาติ กรุงเทพฯ และบริติชไลบรารี) พบว่าทั้งสองวัฒนธรรมใช้โครงสร้างข้อความประกอบตัวบทที่คล้ายคลึงกันอย่างยิ่ง ทั้งการใช้เครื่องหมายคั่นวรรคตอน คำสั่งบอกการเปลี่ยนทำนอง และการระบุบทบาทของพระสวดนำและพระคู่สวด

#### 3.3.2 ลำดับการจัดวางตัวบท (4.3 Textual Sequences)
การจัดเรียงลำดับบทสวดในสมุดข่อยมิได้เป็นไปโดยบังเอิญ แต่ถูกออกแบบตามขั้นตอนทางจิตวิทยาและพิธีกรรมอย่างเคร่งครัด:
1. **สมุดสวดสยาม (Siamese Sequences):** มักเริ่มต้นด้วยบทนมัสการพระพุทธเจ้า (`นะโม ตัสสะ`), บทสวดพระมาติกาอภิธรรม 7 คัมภีร์ (สัง วิ ธา ปุ กะ ยะ ปะ), พระสหัสนัย, พระวินัยสังคหะ, พระสูตรสังคหะ, แล้วตามด้วยพระมาลัยกลอนสวด
2. **สมุดข่อยเขมร (Cambodian Sequences):** มีโครงสร้างคล้ายคลึงกัน แต่มีจุดเด่นคือการสลับระหว่างบทบาลีกับกวีนิพนธ์เขมรเตือนสติ และมักจบลงด้วยบทสวดขอขมาโทษบาปกรรม (`สมาลาโทษ`) และบทอธิษฐานจิตสู่พุทธภูมิ ซึ่งเป็นขั้นตอนสุดท้ายของการเตรียมจิตก่อนดับขันธ์

#### 3.3.3 ภาพจิตรกรรมประกอบ (4.4 Illuminations)
ในสมุดข่อยเขมรและสยาม ภาพจิตรกรรมมิได้มีไว้เพียงเพื่อความสวยงาม แต่เป็น **"เครื่องมือทางทัศนสัญลักษณ์" (Visual Pedagogical Tools)** สำหรับพระสงฆ์ในการชี้นำอารมณ์ของผู้ฟัง:
- **ภาพพระมาลัยเสด็จโปรดนรกและสวรรค์:** แสดงภาพกระทะทองแดง ต้นงิ้ว นายนิรยบาลกำลังลงทัณฑ์คนบาป และภาพเทวดานางฟ้าบนวิมานชั้นดุสิต
- **ภาพอสุภกรรมฐาน:** แสดงภาพซากศพ 10 ระยะ (ศพขึ้นอืด ศพเขียวคล้ำ ศพมีน้ำเหลืองไหล ศพขาดเป็นสองท่อน ศพเหลือแต่กระดูก) เพื่อให้ผู้ป่วยและญาติได้เจริญสติเห็นความไม่เที่ยงแท้ของกายสังขาร
- **ภาพพระพุทธเจ้าปราบพญามารและเสด็จปรินิพพาน:** เพื่อเป็นอนุสติเตือนใจให้รำลึกถึงพระคุณของพระบรมศาสดาในขณะจิตสุดท้าย

#### 3.3.4 สัญลักษณ์กำกับทำนองเสียงสวด (Chanting Neumes & Rubrics)
วอล์กเกอร์ได้ค้นพบว่า ผู้จารโบราณใช้ระบบเครื่องหมายพิเศษในการกำกับการเอื้อนเสียง:
- **เครื่องหมายโคมูตร / หางวัว (Go Mūtr):** มักวางไว้ท้ายวรรคเพื่อบอกให้พระสงฆ์ "ทอดเสียงยาว" หรือ "เอื้อนเสียงสะบัดขึ้น-ลง" ในตอนท้าย
- **จุดและวงกลมกำกับจังหวะ:** เพื่อกำหนดจุดหยุดพักหายใจ (Cesura) และการรับ-ส่งเสียงระหว่างพระเถระประธานกับพระอันดับ

#### 3.3.5 คำสั่งในพิธีพุทธาภิเษกและพิธีข้างเตียงคนตาย (4.5 Ritual Instructions)
สมุดข่อยหลายเล่มมีคำแนะนำการประกอบพิธีกรรมอย่างละเอียดแทรกอยู่:
- *ในพิธีพุทธาภิเษก:* ระบุเวลาในการเริ่มสวด (ยามสาม ยามสี่), การจุดเทียนน้ำมนต์, การนำด้ายสายสิญจน์โยงจากพระหัตถ์พระพุทธรูปมายังพระสงฆ์, และการขับขานบทพุทธคุณ 108 จบจนถึงรุ่งอรุณ
- *ในพิธีข้างเตียงคนตาย:* ระบุให้ญาติจัดเตรียมดอกไม้ ธูป เทียน ใส่ในมือของผู้ป่วย นิมนต์พระสงฆ์มานั่งใกล้ศีรษะผู้ป่วย และสั่งให้พระสวดขับขานด้วยน้ำเสียงที่นุ่มนวล อบอุ่น อย่าสวดกระโชกโฮกฮาก เพื่อมิให้จิตของผู้ป่วยตกใจหรือเกิดความตระหนกกลัว [7]

## 4. ภาคที่ 2: การแปลเพื่อหยั่งรากในท้องถิ่น (Part II: Localized Translations)

### 4.1 บทที่ 5: จากมนต์ธารณีสันสกฤตสู่พระปริตรบาลี (Chapter 5: From Sanskrit Dhāraṇī to Pali Paritta, หน้า 255–316)

#### 4.1.1 กำเนิดคัมภีร์อุณหิสสวิชัย (Uṇhissavijaya) จากอุษณีษวิชยาธารณี (5.2)
บทที่ 5 นำเสนอบทวิเคราะห์เชิงนิรุกติศาสตร์ระดับมาสเตอร์พีซ ว่าด้วยการเดินทางข้ามสายธารอารยธรรมของคัมภีร์ **"อุณหิสสวิชัย" (Uṇhissavijaya)** [8]:
- **ต้นกำเนิดในมหายาน-ตันตระ:** ในอินเดียและเอเชียกลาง มีคัมภีร์ภาษาสันสกฤตที่มีชื่อเสียงยิ่งคือ *อุษณีษวิชยาธารณีสูตร* (Uṣṇīṣavijayā-dhāraṇī-sūtra, ปรากฏในพระไตรปิฎกจีน Taishō 370 แปลโดย พุทธปาละ ในศตวรรษที่ 7) มนต์ธารณีนี้มีอานุภาพสูงสุดในการช่วยสรรพสัตว์ให้รอดพ้นจากอบายภูมิและต่ออายุขัย
- **การปริวรรตสู่เถรวาทในโลกเขมร-ไท:** พระคันถรจนาจารย์ในอุษาคเนย์ได้นำโครงเรื่องและแก่นมนต์ธารณีนี้มา **"แปลงรูปเป็นภาษาบาลี"** โดยแต่งเป็นนิทานชาดกและพระปริตร กล่าวถึงเทวบุตรสุปติฏฐิตะ (Supatiṭṭhita) ผู้กำลังจะหมดอายุขัยและต้องตกนรก พระอินทร์จึงพาไปเข้าเฝ้าพระสัมมาสัมพุทธเจ้า พระพุทธองค์จึงทรงแสดงธรรมและประทานบทสวด "อุณหิสสวิชัย" เพื่อคุ้มครองชีวิต
- วอล์กเกอร์ได้เปรียบเทียบคำต่อคำระหว่างธารณีสันสกฤตเดิมกับบทบาลีอุณหิสสวิชัยในสมุดข่อย พบว่าแม้ถ้อยคำจะถูกปรับให้เข้ากับไวยากรณ์บาลี แต่ยังคงรักษาโครงสร้างทางเสียงและเป้าหมายในการ "ขับไล่มัจจุราช" ไว้อย่างครบถ้วน

#### 4.1.2–4.1.4 พระปริตรบาลีนอกคัมภีร์และคลังมหาทิพพมนต์ (5.3–5.7)
นอกจากอุณหิสสวิชัยแล้ว วอล์กเกอร์ยังได้สำรวจคลังพระปริตรบาลีนอกคัมภีร์ (Non-Canonical Pali Parittas) ในคัมภีร์ **"มหาทิพพมนต์" (Mahādibbamanta)** ของกัมพูชาและสยาม:
- พระปริตรเหล่านี้มิได้มีปรากฏในพระไตรปิฎกบาลีของศรีลังกา แต่เป็นผลงานการประพันธ์ของพระสงฆ์ในภาคพื้นทวีปเอเชียตะวันออกเฉียงใต้
- ทำหน้าที่เป็น "มนต์พิทักษ์ภัยประจำถิ่น" ที่สืบทอดพลังอำนาจแห่งธารณีโบราณมาสู่โลกเถรวาท สะท้อนการประนีประนอมอย่างชาญฉลาดระหว่างความเชื่อเรื่องมนต์ขลังศักดิ์สิทธิ์กับหลักธรรมเรื่องกรรมและการเจริญสติ

### 4.2 บทที่ 6: ร้อยแก้วทวิลักษณ์บาลี-ภาษาถิ่น (Chapter 6: Bilingual Pali-Vernacular Prose, หน้า 317–378)

#### 4.2.1 ประวัติการศึกษาตัวบททวิลักษณ์: สันนยะ นิสสัย สำราย โวหาร (6.2)
ในบทที่ 6 วอล์กเกอร์ได้ทบทวนประวัติศาสตร์การแปลพระธรรมข้ามภาษาในโลกพุทธเถรวาท [9]:
- **สิงหล:** ขนบ *สันนยะ* (Sannaya) ในศรีลังกา
- **พม่า:** ขนบ *นิสสัย* (Nissaya) ซึ่งมีอิทธิพลต่อมอญ ล้านนา และไทเขิน
- **กัมพูชา:** ขนบ *สำราย* (Samrāy / สํราย) ซึ่งใช้มาตั้งแต่ยุคพระนครตอนปลาย
- **ล้านนาและลาว:** ขนบ *นามสัททะ* (Nāmasadda), *นิสสัย*, และ *โวหาร*

#### 4.2.2 การแปลคงโครงสร้างไวยากรณ์บาลีเดิม (6.3 Original-Syntax Fully Bilingual Prose)
วอล์กเกอร์จำแนกกลวิธีการแปลร้อยแก้วทวิลักษณ์ออกเป็น 3 รูปแบบหลักอย่างเป็นระบบ:
1. **Original-Syntax (คงโครงสร้างบาลีเดิม):**
   - คำบาลีแต่ละคำจะถูกตัดบท แล้วตามด้วยคำแปลภาษาถิ่นทันที โดยเรียงลำดับตามไวยากรณ์บาลี (ประธาน - กรรม - กริยา / SOV)
   - ใช้ **คำกำกับวิภัตติไวยากรณ์ (Case Markers)** เคร่งครัด:
     - ในภาษาเขมร: ใช้คำว่า `ឯ` (ae - ปฐมา), `នូវ` (nūv - ทุติยา/กรรมตรง), `ដោយ` (doy - ตติยา/เครื่องมือ)
     - ในภาษาไทยและล้านนา: ใช้คำว่า "อันว่า" (ปฐมา), "ซึ่ง/สู่/ยัง" (ทุติยา), "ด้วย/โดย/อัน" (ตติยา)
   - รูปแบบนี้ใช้สำหรับบทสวดที่ต้องการความแม่นยำทางไวยากรณ์ขั้นสูงสุด เพื่อการเรียนการสอนพระปริยัติธรรม

#### 4.2.3 การแปลปรับเรียงประโยคตามภาษาถิ่น (6.4 Syntactically Rearranged Fully Bilingual Prose)
2. **Syntactically Rearranged (ปรับเรียงตามไวยากรณ์ภาษาถิ่น):**
   - สลายโครงสร้างบาลีเดิม แล้วจัดเรียงคำใหม่ตามไวยากรณ์ธรรมชาติของภาษาเขมรและไทย (ประธาน - กริยา - กรรม / SVO)
   - วอล์กเกอร์ยกกรณีศึกษาคัมภีร์ *รสวาหินี* (Rasavāhinī) และ *ธรรมบท* (Dhammapada) ฉบับบาลี-ล้านนาและบาลี-เขมร แสดงให้เห็นว่าผู้แปลสละความเคร่งครัดทางไวยากรณ์ลง เพื่อแลกกับความลื่นไหลทางวรรณศิลป์และความเข้าใจทันทีของผู้ฟังเทศน์

#### 4.2.4 การแปลทวิลักษณ์กึ่งสมบูรณ์ (6.5 Partially Bilingual Prose)
3. **Partially Bilingual Prose (ทวิลักษณ์กึ่งสมบูรณ์):**
   - มิได้แปลคำต่อคำทุกคำ แต่ยกเฉพาะคำบาลีที่เป็นหัวใจของเรื่องขึ้นมา 1–2 คำ แล้วรจนาความเรียงภาษาถิ่นขยายความขนาดยาว
   - ตัวอย่างคลาสสิกคือ *มหาเวสสันดรชาดก* ฉบับร่ายวัดและเทศนาสำราย และคัมภีร์ใบลานที่มีรอยจารอรรถกถาแทรกระหว่างบรรทัด (Interlinear commentaries) [9]
### 4.3 บทที่ 7: การร้อยกรองบาลีและภาษาไทสู่กาพย์กลอนเขมร (Chapter 7: Translating into Khmer Verse, หน้า 379–458)

#### 4.3.1 กลวิธี Foreignizing ด้วยภาษาบาลี (7.2)
ในบทที่ 7 วอล์กเกอร์ได้วิเคราะห์กลวิธีทางวรรณศิลป์ที่กวีเขมรใช้ในการรังสรรค์บทกวีทางศาสนาจากแหล่งข้อมูลภาษาบาลีและภาษาไท [10]:
- **การแทรกคำบาลีโดดเดี่ยวและพยางค์หัวใจ (Isolated Pali Words and Heart Syllables):** กวีเขมรจะจงใจแทรกพยางค์ "หัวใจ" คาถา (ภาษาเขมร: *paṇṭūl*; ภาษาไทย: *หัวใจ*) เช่น `ติ ติ ลัก` (ย่อจาก ติลักขณะ), `อะ สัง วิ สุ โล ปุ สะ พุ ภะ` (นวหรคุณ) หรือคำศัพท์เทคนิคอภิธรรมโดดๆ แทรกอยู่ท่ามกลางฉันทลักษณ์เขมร เพื่อสร้างคลื่นเสียงแห่งความศักดิ์สิทธิ์ที่ผู้ฟังจะรับรู้ได้ทันทีว่าเป็นถ้อยคำแห่งพุทธมนต์
- **บทนมัสการเปิดเรื่อง (Opening Invocations):** การขึ้นต้นบทกวีภาษาถิ่นด้วยคาถาบาลีสั้นๆ 1–2 บาท เช่น `นะโม ตัสสะ...` หรือ `วันทิตวา สุคะตัง นาถัง...` แล้วจึงไหลรินเข้าสู่คำกลอนเขมร เพื่อเชื่อมโยงกวีนิพนธ์ของตนเข้ากับสายธารพระธรรมของพระสัมมาสัมพุทธเจ้า
- **การบูรณาการวลีบาลีเข้าสู่ฉันทลักษณ์ (Integrated Pali Phrases):** คำบาลีได้รับการตัดแต่งพยางค์และปรับการออกเสียงให้ลงสัมผัส (Rhyme) กับคำในภาษาเขมรได้อย่างกลมกลืนตามกฎเกณฑ์ฉันท์พรหมคีติหรือฉันท์กากคติ

#### 4.3.2 กลวิธี Domestication วรรณกรรมไท: รอยพระพุทธบาทและพระบรมสารีริกธาตุ (7.3)
การค้นพบที่น่าทึ่งทางประวัติศาสตร์วรรณคดีเปรียบเทียบในบทที่ 7 คือการที่วอล์กเกอร์พิสูจน์ว่า กวีนิพนธ์เขมรว่าด้วยเรื่องศักดิ์สิทธิ์ 2 เรื่องหลัก ได้รับการแปลและดัดแปลง (Domesticated) มาจากวรรณกรรมภาษาไทย/สยาม:
1. **ตำนานรอยพระพุทธบาท (7.3.1 Domestication of the Buddha's Footprints):**
   - กวีนิพนธ์เขมรเรื่อง *ลายลักษณพระพุทธบาทเบื้องขวา* (lāy lăkṣa(ṇ) braḥ buddhapād pīöṅ2 khvā - นำเสนอฉบับตรวจชำระสมบูรณ์ใน Appendix III) ได้รับการแปลและดัดแปลงมาจากตำราพระพุทธบาทภาษาไทยสมัยอยุธยา
   - พรรณนามงคล 108 ประการบนฝ่าพระพุทธบาท แต่กวีเขมรได้ "ปรับให้เป็นเขมร" (Domestication) โดยการสอดแทรกชื่อสถานที่ศักดิ์สิทธิ์และภูมิศาสตร์ท้องถิ่นของกัมพูชาเข้าไปแทนที่
2. **ตำนานพระบรมสารีริกธาตุ (7.3.2 Domestication of the Buddha's Relics):**
   - การแปลบทสวดบูชาพระธาตุจากภาษาไทยและล้านนามาเป็นฉันท์พรหมคีติเขมร เพื่อใช้ในพิธีบรรจุพระธาตุในเจดีย์และการสวดข้างเตียงคนป่วย เพื่อให้นึกถึงพระสรีระของพระพุทธองค์เป็นอารมณ์สมาธิ

#### 4.3.3 ความเสมอภาคทางปฏิบัติการ (Performative Parity) และบทอาราธนา (7.4)
วอล์กเกอร์เสนอแนวคิด **"Performative Parity" (ความเสมอภาคทางปฏิบัติการ)** ชี้ว่า กวีผู้แปลมิได้มองว่าภาษาถิ่นด้อยกว่าภาษาบาลี:
- กวีได้รังสรรค์ให้บทกวีเขมรมีพลังดนตรี จังหวะเอื้อน และความสะเทือนอารมณ์ที่ทัดเทียมกับคาถาบาลีทุกประการ
- ดังปรากฏใน **"บทอาราธนาพระธรรมเทศนา" (Invitations for Sermons across Languages):** คาถาบาลี `พรัหมา จะ โลกาธิปตี...` ได้รับการแปลเป็นบทขับร้องภาษาถิ่นที่มีท่วงทำนองออดอ้อน อัญเชิญพระธรรมให้หลั่งรินลงมาประดุจสายฝนทิพย์ชโลมใจผู้ฟัง [10]

## 5. ภาคที่ 3: พันธกิจแห่งผู้ใกล้ดับขันธ์ (Part III: The Work of the Dying)

### 5.1 บทที่ 8: การเจริญมรณานุสติและสัจธรรมแห่งการแตกดับ (Chapter 8: End-of-Life Contemplations, หน้า 459–541)

#### 5.1.1 บทนำและมโนทัศน์มรณานุสติ (8.1)
ภาคที่ 3 ถือเป็นจุดยอดเขา (Climax) ทางจิตวิทยาศาสนาและปรัชญาของวิทยานิพนธ์ วอล์กเกอร์ได้นิยาม **"The Work of the Dying" (พันธกิจแห่งผู้ใกล้ดับขันธ์)** ว่าหมายถึง:
> "ภารกิจทางจิตวิญญาณ การเจริญสติสัมปชัญญะ และการปฏิบัติสมาธิภาวนาครั้งสำคัญที่สุดในชีวิตมนุษย์ ซึ่งต้องกระทำในขณะที่สังขารกำลังจะแตกดับ เพื่อเปลี่ยนผ่านจากความตระหนกกลัว ความห่วงหาอาลัย และความเจ็บปวดทางกาย ไปสู่จิตดวงสุดท้ายที่บริสุทธิ์ ผ่องใส และพร้อมสำหรับการปฏิสนธิในสุคติภูมิหรือการเข้าสู่มรรคผลนิพพาน" [11]

วอล์กเกอร์ได้แปลและวิเคราะห์บทกวีนิพนธ์เขมรโบราณในสมุดข่อยที่พระสงฆ์ใช้สวดกล่อมเกลาจิตใจผู้ป่วยหนักข้างเตียง โดยจำแนกภาพพจน์ทางวรรณศิลป์ออกเป็น **5 มิติแห่งสัจธรรมความตาย** อย่างลึกซึ้ง:

#### 5.1.2 มิติที่ 1: ถูกไล่ล่าโดยความชรา (8.2 Chased by Old Age)
บทกวีพรรณนาถึงความชราภาพประดุจนายพรานที่ไล่ล่าเนื้อสมัน:
- ร่างกายที่เคยสง่างาม แข็งแรง และเปล่งปลั่งในวัยหนุ่มสาว บัดนี้กลับทรุดโทรมลง ผมที่เคยดำขลับกลายเป็นสีขาวประดุจดอกเลา ผิวหนังที่เคยเต่งตึงกลับเหี่ยวย่นตกกระ สายตาที่เคยแจ่มใสกลับฝ้าฟาง ฟันที่เคยเรียบเสมอกลับหักโยกคลอน แข้งขาหมดเรี่ยวแรงไม่อาจทรงกายได้
- *เป้าหมายทางจิตวิทยา:* เพื่อเตือนให้ผู้ป่วยคลายความยึดมั่นถือมั่นในความงามและความเยาว์วัย ยอมรับความจริงว่าร่างกายนี้เป็นเพียงรังแห่งโรคและกำลังแตกสลายไปตามกฎไตรลักษณ์

#### 5.1.3 มิติที่ 2: ถูกต้อนจนมุมโดยมัจจุราช (8.3 Hounded by Death)
บทกวีชี้ให้เห็นว่า ความตายมิใช่สิ่งที่อยู่ไกลตัว แต่กำลังประชิดเข้ามาทุกขณะลมหายใจเข้าออก:
- มัจจุราชเป็นผู้ล่าที่ไร้ความปรานี ไม่อาจติดสินบนได้ด้วยทรัพย์สมบัติ แก้วแหวน เงินทอง ช้าง ม้า วัว ควาย หรือข้าทาสบริวาร
- แม้พระมหากษัตริย์ผู้ทรงเดชานุภาพ แม่ทัพผู้เกรียงไกร หรือมหาเศรษฐีผู้มั่งคั่ง ล้วนต้องยอมจำนนและทอดร่างลงสู่พื้นดินเสมอกันทั้งหมด

#### 5.1.4 มิติที่ 3: ถูกคุกคามโดยพญายมราช (8.4 Menaced by Yama)
วรรณกรรมในสมุดข่อยพรรณนาภาพของ **พญายมราช (Yama)** นายนิรยบาล และแดนนรกอย่างน่าสะพรึงกลัว:
- ยมทูตผู้มีดวงตาสีแดงประดุจถ่านเพลิง ถือโซ่ตรวนเหล็กแดงและหอกดาบมารอรับดวงวิญญาณข้างเตียง
- การเปิดบัญชีกรรม (สุวรรณบัตรและอัยยบัตร) เพื่อไต่สวนบาปและบุญที่ได้กระทำไว้ในยามมีชีวิต
- *เป้าหมายทางจิตวิทยา:* มิใช่เพื่อสร้างความสิ้นหวัง แต่เป็นการกระตุ้นให้เกิด **"โอตตัปปะ" (ความเกรงกลัวต่อบาป)** อย่างรุนแรง เพื่อให้ผู้ป่วยในวาระสุดท้ายรีบละทิ้งความโกรธ ความโลภ ความหลง และน้อมใจขอขมาบาปกรรมทันที

#### 5.1.5 มิติที่ 4: การถูกทอดทิ้งในป่าช้า (8.5 Discarded in the Forest / อสุภกรรมฐาน)
การนำหลัก **อสุภกรรมฐาน** มาประพันธ์เป็นบทสวดภาษาถิ่นพรรณนาสภาพศพของตนเอง:
- เมื่อหมดลมหายใจแล้ว ลมปราณดับ ร่างกายจะแข็งทื่อ ธาตุไฟดับ ร่างกายจะเย็นชืดประดุจท่อนไม้
- ญาติพี่น้องจะนำร่างที่ไร้วิญญาณไปทิ้งไว้ในป่าช้า ร่างกายจะขึ้นอืด พองเขียว มีน้ำเหลืองและเลือดไหลซึมออกจากทวารทั้งเก้า มีฝูงหนอนชอนไช และมีสุนัขจิ้งจอก แร้ง กา มารุมทึ้งจิกกินเนื้อหนังจนเหลือแต่โครงกระดูกสีขาวกระจัดกระจาย
- บทกวีสอนให้ผู้ป่วยมองเห็นล่วงหน้าว่า ร่างกายที่ตนเคยรักและทะนุถนอมนี้ แท้จริงแล้วไม่มีสิ่งใดน่าพิสมัยเลยแม้แต่น้อย

#### 5.1.6 มิติที่ 5: การถูกตัดขาดจากอารยธรรมและครอบครัว (8.6 Abandoned by Civilization)
การพรรณนาถึงความว่างเปล่าและความโดดเดี่ยวของผู้ตาย:
- บ้านเรือน เรือกสวน ไร่นา ยศถาบรรดาศักดิ์ บุตร ภรรยา สามี และมิตรสหายที่เคยห้อมล้อม จะต้องหยุดอยู่เพียงแค่เชิงตะกอน ไม่มีผู้ใดสามารถติดตามข้ามภพไปได้เลย
- สิ่งเดียวที่จะเป็นเพื่อนร่วมทางและเป็นเงาติดตามตนไปในปรโลก มีเพียง **"กุศลกรรม" (บุญ)** และ **"อกุศลกรรม" (บาป)** ที่ตนได้กระทำไว้ด้วยตนเองเท่านั้น

#### 5.1.7 การปฏิบัติธรรมรากฐานและการเจริญกรรมฐานโบราณข้างเตียง (8.7–8.8 Traditional Kammaṭṭhāna)
เพื่อรองรับสภาวะจิตที่ตระหนก วอล์กเกอร์ได้เจาะลึกเทคนิค **"กรรมฐานโบราณ" (Traditional Kammaṭṭhāna / Borān Kammaṭṭhāna)** ที่พระสงฆ์ใช้แนะนำผู้ป่วยข้างเตียง:
- **การกำหนดสติระงับเวทนา:** เมื่อความเจ็บปวดทางกายารุมเร้าอย่างรุนแรง พระสงฆ์จะแนะให้ผู้ป่วย "แยกจิตออกจากกาย" มองเวทนาเป็นเพียงสภาวะธรรมธรรมชาติที่เกิดขึ้น ตั้งอยู่ แล้วดับไป มิใช่ตัวตนของเรา
- **การเพ่งธาตุและพุทธคุณ:** การนึกถึงดวงแก้ว พระพุทธรูปทองคำ หรือการบริกรรมคำว่า `พุทโธ` หรือ `อะระหัง` ทุกลมหายใจเข้าออก เพื่อให้จิตรวมลงสู่จุดเดียว (เอกัคคตารมณ์) ปิดกั้นอารมณ์ฝ่ายต่ำ และเปิดทางให้จิตดวงสุดท้าย (จุติจิต) ดับลงอย่างสงบผ่องใส [11]
### 5.2 บทที่ 9: การขอขมาบาปกรรมและการตั้งจิตอธิษฐานสู่พุทธภูมิ (Chapter 9: End-of-Life Absolutions and Aspirations, หน้า 542–652)

#### 5.2.1 จากอานิสงส์สู่อธิษฐาน (9.2 From Ānisaṃsa to Adhiṭṭhāna)
ในบทที่ 9 วอล์กเกอร์ได้วิเคราะห์การเปลี่ยนผ่านทางจิตวิญญาณขั้นสูงสุดของผู้ใกล้ดับขันธ์ [12]:
- **ข้อจำกัดของ "อานิสงส์" (Ānisaṃsa):** ในชีวิตประจำวัน ชาวบ้านมักทำบุญเพื่อหวังอานิสงส์ผลบุญ เช่น ขอให้ร่ำรวย ขอให้มีรูปงาม ขอให้ได้ขึ้นสวรรค์ หรือมีอายุยืนยาว ซึ่งวอล์กเกอร์ชี้ว่ายังคงเป็นการทำบุญที่เจือด้วยตัณหาในภพภูมิ
- **การยกระดับสู่ "อธิษฐานบารมี" (Adhiṭṭhāna):** ในวาระสุดท้ายของชีวิต จิตจะต้องละวางความโลภในผลบุญโลกิยะ แล้วเปลี่ยนผ่านสู่ "อธิษฐาน" คือการตั้งจิตมั่นเด็ดเดี่ยวว่าจะใช้ผลบุญกุศลทั้งหมดเป็นพลังในการดับกิเลสและตัดวงจรแห่งการเวียนว่ายตายเกิด
- **กรณีศึกษาคัมภีร์ *อานิสงส์อาการวัตตาสูตร* ของอาจารย์ฮุน (9.2.2):** วิเคราะห์งานประพันธ์ของอาจารย์ฮุน (Hun) ในศตวรรษที่ 19 ซึ่งอธิบายว่า การสวดสรรเสริญพระพุทธคุณอาการ 32 มิใช่เพียงเพื่อให้ได้บุญไปเกิดบนสวรรค์ แต่เป็นเครื่องมือในการชำระล้างจิตให้บริสุทธิ์เพื่อเตรียมพร้อมสำหรับการเข้าสู่นิพพาน

#### 5.2.2 พิธีกรรมสมาลาโทษบาปกรรม (9.3 From Repentance to Absolution)
บทวิเคราะห์ที่ทรงคุณค่าอย่างยิ่งทางมานุษยวิทยาศาสนาในหัวข้อ 9.3 คือการศึกษาบทสวด **"สมาลาโทษบาปกรรม" (Smā lā dos pāpakamm)** [12]:
- **ความขัดแย้งในชีวิตประจำวันของชาวบ้าน:** วอล์กเกอร์ชี้ว่า โปรตีนหลักของชาวกัมพูชาและชาวอุษาคเนย์คือ "ปลา" (การจับปลา ทำปลาร้า ทำน้ำปลา) และการทำไร่ไถนาที่หลีกเลี่ยงการฆ่าสัตว์ตัดชีวิตได้ยาก ชาวบ้านทุกคนจึงตระหนักดีว่าตนเองมีบาปกรรมติดตัวจากการประกอบสัมมาอาชีวะเพื่อยังชีพ
- **อันตรายแห่ง "เวรภัย" (Verā):** ในขณะใกล้ตาย จิตมักถูกหลอกหลอนด้วยภาพของสัตว์ที่ตนเคยฆ่า ซึ่งกลายเป็น "เจ้ากรรมนายเวร" ที่มารอทวงหนี้ชีวิต
- **กลไกการปลดเปลื้องเวร (Absolution):** พระพุทธศาสนาในสมุดข่อยมิได้ปฏิเสธความจริงนี้ แต่ได้รังสรรค์บทสวด "สมาลาโทษ" ขึ้นมา เพื่อให้ผู้ป่วยได้เปล่งวาจาขอขมาลาโทษต่อสรรพสัตว์ทั้งหลาย ขออโหสิกรรม ขอให้สัตว์เหล่านั้นจงได้รับส่วนบุญกุศล และอย่าได้จองเวรจองกรรมต่อกันอีกเลย การขอขมานี้ช่วยปลดสลักความรู้สึกผิดในส่วนลึกของจิตใจ ทำให้ผู้ป่วยสามารถหมดลมหายใจได้อย่างโล่งอกและสงบสุข

#### 5.2.3 การยกระดับจิตจากพระอรหันต์สู่พุทธภูมิ (9.4 From Arhatship to Buddhahood)
ข้อค้นพบทางเทววิทยาพุทธศาสนาที่สำคัญที่สุดในวิทยานิพนธ์นี้ คือการที่วอล์กเกอร์พิสูจน์ว่า:
- ในจารึกท้ายเรื่องของสมุดข่อยเขมรยุคกลางและบทสวดวาระสุดท้าย คำอธิษฐานจิตของคนตายมิได้มุ่งหวังเพียงการบรรลุเป็นพระอรหันต์เพื่อดับกิเลสเฉพาะตน
- แต่ส่วนใหญ่ตั้งจิตปรารถนา **"พุทธภูมิ" (Buddhahood)** คือการขอสร้างบารมีต่อไปเพื่อสำเร็จเป็น **"พระสัมมาสัมพุทธเจ้า"** ในอนาคตเพื่อโปรดสรรพสัตว์ หรืออย่างน้อยที่สุดคือการขอไปเกิดในยุคของ **"พระศรีอริยเมตไตรย"** (Maitreya)
- ปรากฏการณ์นี้สะท้อนว่า อุดมการณ์พระโพธิสัตว์แบบมหายานดั้งเดิมในดินแดนพระนคร มิได้สูญหายไปหลังการเข้ามาของเถรวาท แต่ได้หลอมรวมเข้าเป็นเนื้อเดียวกับพุทธศาสนาเถรวาทแบบท้องถิ่น (Theravada Bodhisattva Ideal) อย่างแนบเนียน

#### 5.2.4 บทสวดผสมผสาน: ลาบาป "ภันเต ภควา" (9.5)
วอล์กเกอร์ได้วิเคราะห์ตัวบทกวีนิพนธ์เรื่อง **ลาบาป "ภันเต ภควา" (lā pāp «bhante bhagavā»-k)** ซึ่งแต่งด้วยฉันท์กากคติ:
- เป็นการผสานระหว่างการกราบทูลขอขมาต่อเบื้องพระพักตร์พระสัมมาสัมพุทธเจ้า ควบคู่ไปกับการตั้งจิตอธิษฐานข้ามภพ
- บทกวีเริ่มต้นด้วยคาถาบาลี `ภันเต ภะคะวา...` (ข้าแต่พระผู้มีพระภาคเจ้าผู้เจริญ) แล้วขยายจำเป็นกลอนเขมรพรรณนาถึงความผิดพลาด ความหลงผิด และกิเลสที่ตนเคยครอบงำ พร้อมทั้งขอพึ่งพระบารมีพระพุทธองค์เป็นที่พึ่งสุดท้ายประดุจเกาะกลางมหาสมุทรอันกว้างใหญ่

#### 5.2.5 จากบทสวดสู่แผ่นศิลาจารึกนครวัด (9.6 Chanted Poem to Stone Inscriptions)
การค้นพบระดับหมุดหมายทางประวัติศาสตร์และจารึกวิทยาในหัวข้อ 9.6 คือการที่วอล์กเกอร์ได้เชื่อมโยงบทสวดในสมุดข่อยเข้ากับ **ศิลาจารึกยุคหลังพระนคร ณ นครวัด** [13]:
1. **บทสวดถวายดอกไม้ *ปทุมถวายผกา* (padum thvāy phkā «khñuṃ phguṃ amrām ṭap'»-br):** บทกวีฉันท์พรหมคีติพรรณนาการประณมนิ้วทั้งสิบขึ้นเหนือเศียรเกล้าเพื่อถวายดอกบัวเป็นพุทธบูชา
2. **จารึก IMA 31 (ค.ศ. 1684) ของสมเด็จพระปรวิทู:**
   - มหาอำมาตย์แห่งกัมพูชาได้นำข้อความจากบทสวดถวายดอกไม้และบทสมาลาโทษในสมุดข่อย มาสลักลงบนผนังระเบียงนครวัด
3. **จารึก IMA 38 (ค.ศ. 1701) ของชัยนันท์ (La grande inscription d'Angkor):**
   - จารึกขนาดใหญ่ที่สุดในนครวัดยุคหลังพระนคร ซึ่งสลักบทกวีพรรณนาการสละทรัพย์สมบัติ การขอขมาบาป และการตั้งจิตอธิษฐานสู่พุทธภูมิ
   - ข้อความในจารึกศิลานี้ตรงกับบทสวดในสมุดข่อยตัวเขียน UB015 และ UB024 เกือบคำต่อคำ พิสูจน์ว่าบทสวดข้างเตียงคนตายในสมุดข่อยมิใช่เพียงวรรณกรรมพื้นบ้าน แต่เป็นวรรณคดีและอุดมการณ์ทางศาสนาชั้นสูงของราชสำนักและรัฐกัมพูชาในยุคฟื้นฟูนครวัดเป็นพุทธสถาน

### 7.3 Appendix III: สรุปสาระสำคัญ 4 ตัวบทเอกเทศนอกสมุดข่อย (หน้า 1494–1582)
ในภาคผนวกที่ 3 วอล์กเกอร์ได้นำเสนอฉบับตรวจชำระและคำแปลของ 4 วรรณกรรมชิ้นเอกที่อยู่นอกคลังสมุดข่อย 70 เล่ม แต่มีความสัมพันธ์เชิงโครงสร้างกับบทสวดวาระสุดท้ายอย่างลึกซึ้ง:
1. **คัมภีร์อุณหิสสวิชัยฉบับร้อยกรองขนาดยาว (Uṇhissavijaya Long Verse Version, หน้า 1494–1513):**
   - ประพันธ์ด้วยฉันท์พรหมคีติเขมร เล่าตำนานสุปติฏฐิตเทวบุตรอย่างพิสดาร พรรณนาภาพสวรรค์ชั้นดาวดึงส์และพระธรรมเทศนาของพระพุทธองค์ที่ช่วยชุบชีวิตเทวบุตรให้พ้นจากนรก
2. **ตำนานรอยพระพุทธบาทเบื้องขวา (Lāy lăkṣa(ṇ) braḥ buddhapād pīöṅ2 khvā, หน้า 1514–1530):**
   - กวีนิพนธ์เขมรบรรยายภาพมงคล 108 ประการบนฝ่าพระบาท ดัดแปลงจากตำราพระพุทธบาทสมัยอยุธยา ใช้สวดเพื่อกำหนดนิมิตพุทธานุสติข้างเตียงคนป่วย
3. **คัมภีร์สุบินกุมาร (Supin kumār, หน้า 1531–1577):**
   - ชาดกนอกนิบาตที่มีชื่อเสียงยิ่งในล้านนา ลาว สยาม และกัมพูชา เล่าเรื่องกุมารผู้ยอมสละชีวิตเพื่อรักษาศีลและกตัญญูต่อบิดามารดา แสดงให้เห็นอุดมการณ์ความกล้าหาญในการเผชิญหน้ากับความตายโดยไม่หวาดหวั่น
4. **บทนำวรรณคดีเรื่องตุมเตียว (Prologue to Duṃ Dāv, หน้า 1578–1582):**
   - บทไหว้ครูของพระมหาเถระโสม (Bhikkhu Som) กวีเอกแห่งกัมพูชา ซึ่งสะท้อนการใช้อักขรวิธีและฉันทลักษณ์เขมรโบราณในการสรรเสริญคุณพระรัตนตรัย [1]
