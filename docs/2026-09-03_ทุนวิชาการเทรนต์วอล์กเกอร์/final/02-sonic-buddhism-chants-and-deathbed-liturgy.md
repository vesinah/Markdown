## 1. บทนำ: พุทธศาสนาเชิงโสตทัศน์และ "การเปล่งเสียงเป็นปฏิบัติการธรรม" (Sonic Buddhism & Performative Liturgy)

ในกระแสธารการศึกษาพุทธศาสนาในโลกตะวันตก มักมีแนวโน้มที่จะมองพุทธศาสนาผ่านมิติทางตัวอักษรและมโนทัศน์เชิงปรัชญาบริสุทธิ์ (Textual & Philosophical Bias) โดยมองว่า "การปฏิบัติธรรมที่แท้จริง" มีเพียงการนั่งสมาธิภาวนาในความเงียบสงบ ส่วนพิธีกรรมการสวดมนต์ การขับขานบทกวี และการประโคมเสียงดนตรีในวัด มักถูกลดทอนคุณค่าว่าเป็นเพียง "ความเชื่อพื้นบ้าน" (Folk superstition) หรือเป็นเพียงพิธีกรรมภายนอกที่ไร้แก่นสารทางธรรม [1]

งานวิจัยของ ดร. เทรนต์ วอล์กเกอร์ (Trent Walker) ได้ท้าทายและปฏิวัติมุมมองดังกล่าวอย่างสิ้นเชิง โดยสถาปนาขอบเขตการศึกษาที่เรียกว่า **"พุทธศาสนาเชิงโสตทัศน์" (Sonic Buddhism)** ซึ่งบูรณาการมานุษยวิทยาดนตรี (Ethnomusicology), ผัสสะศึกษา (Sensory Studies), และวัฒนธรรมเอกสารตัวเขียน (Manuscript Studies) เข้าด้วยกัน วอล์กเกอร์พิสูจน์ให้เห็นว่าในประเพณีพุทธเถรวาทของเอเชียตะวันออกเฉียงใต้ (โดยเฉพาะกัมพูชา ไทย และลาว) **"เสียงสวดมิใช่เพียงพาหะส่งผ่านข้อมูล แต่เสียงสวดคือวัตถุทางจิตวิญญาณและเทคโนโลยีแห่งการตรัสรู้"** [2]

งานวิจัยชิ้นเอกของเขา ซึ่งได้รับรางวัลระดับโลก **2024 Khyentse Foundation Prize for Outstanding Translation** จากหนังสือ *Until Nirvana’s Time: Buddhist Songs from Cambodia* (2022) [3] ตลอดจนวิทยานิพนธ์ระดับปริญญาเอกขนาดยักษ์ 1,652 หน้า ณ มหาวิทยาลัยแคลิฟอร์เนีย เบิร์กลีย์เรื่อง *Unfolding Buddhism* (2018) [4] ได้เปิดเผยระบบนิเวศของประเพณีการขับขานลำนำธรรมะโบราณของกัมพูชาที่เรียกว่า **"สมูตร" (Smot / ស្មូត្រ)** และความเชื่อมโยงอันมิอาจแยกขาดกับเอกสารตัวเขียนกระดาษข่อยพับทบที่เรียกว่า **"สมุดข่อย" หรือ "กรั้ง" (Leporello / ក្រាំង)** ในฐานะเครื่องมือช่วยนำทางจิตวิญญาณ ณ วาระสุดท้ายแห่งชีวิต

## 2. ลำนำธรรมะเขมร (Smot) และสุนทรียศาสตร์แห่งอารมณ์: สังเวช (Saṃvega) และ ปสาทะ (Pasāda)

### 2.1 กำเนิดและพัฒนาการของประเพณีสมูตร (Smot)
คำว่า **"สมูตร" (Smot / ស្មូត្រ)** ในภาษาเขมร มีรากศัพท์มาจากภาษาสันสกฤตว่า *สฺโตตฺร* (Stotra) หรือภาษาบาลีว่า *สุตฺต* (Sutta) หมายถึงศิลปะและประเพณีการขับขานกวีนิพนธ์ธรรมะด้วยท่วงทำนองเอื้อนเสียงที่โหยหวนและประณีตลึกซึ้ง ประเพณีนี้สืบทอดกันมาตั้งแต่สมัยหลังพระนคร (Middle Cambodia, ศตวรรษที่ 14–15) และเฟื่องฟูอย่างยิ่งในศตวรรษที่ 17 ถึง 19 [5]

บทเพลงธรรมะสมูตรมีลักษณะเด่นทางฉันทลักษณ์คือ การประพันธ์ด้วยฉันท์เขมรโบราณ เช่น:
- **กากคติ (Kākagati):** ฉันท์ 7 คำต่อวรรค ดำเนินจังหวะประดุจกาก้าวย่าง
- **พรหมคีติ (Brahmagīti):** ฉันท์ที่มีจังหวะสง่างามประดุจเสียงขับขานของพระพรหม นิยมใช้ขับกล่อมและพรรณนาธรรมะชั้นลึก
- **พำโนล (Baṃnol) และ มัณฑูกคติ (Maṇḍukagati):** ฉันท์ที่มีจังหวะกระชั้นและเอื้อนลากยาว

### 2.2 วงจรอารมณ์คู่: การสั่นสะท้าน (Saṃvega) สู่ความผ่องใส (Pasāda)
ในสารนิพนธ์ระดับปริญญาตรีเกียรตินิยม ณ มหาวิทยาลัยสแตนฟอร์ด (2010) [6] และบทความวิจัยใน *Journal of the International Association of Buddhist Studies* (2018) [7] วอล์กเกอร์ได้วางกรอบทฤษฎีอารมณ์ในพุทธศาสนาผ่านคู่มโนทัศน์ **Saṃvega** และ **Pasāda**:

```
+-----------------------------------------------------------------------+
|            วงจรพลวัตแห่งอารมณ์ในบทเพลงธรรมะ (Affective Dynamic)          |
+-----------------------------------------------------------------------+
|                                                                       |
|   1. Saṃvega (สังเวช / ความสะเทือนใจทางธรรม)                             |
|      - อาการทางกาย: ตัวสั่นสะท้าน, น้ำตาไหล, ขนลุกชูชัน, หัวใจเต้นแรง        |
|      - มิติทางธรรม: ตระหนักถึงมรณภัย, ความไม่เที่ยง, ร่างกายเน่าเปื่อย         |
|      - มิติทางเสียง: ท่วงทำนองเอื้อนต่ำ โหยหวน สั่นเครือ (Smot Melodies) |
|                                                                       |
|                                  |                                    |
|                                  v  (ขับเคลื่อนสู่ทางรอด)              |
|                                                                       |
|   2. Pasāda (ปสาทะ / ความเลื่อมใส ผ่องใส สงบระงับ)                     |
|      - อาการทางกาย: ผ่อนคลาย, ลมหายใจสงบ, จิตใจเบิกบาน, ใบหน้าผ่องใส       |
|      - มิติทางธรรม: ระลึกถึงพระพุทธคุณ พระธรรมคุณ พระอริยสงฆ์, ทางสู่นิพพาน|
|      - มิติทางเสียง: ท่วงทำนองโปร่งเบา มั่นคง และสว่างไสว                 |
|                                                                       |
+-----------------------------------------------------------------------+
```

วอล์กเกอร์อธิบายว่า บทเพลงธรรมะเขมรไม่ได้ขับร้องเพื่อความบันเทิงและไม่ได้ขับร้องเพื่อสร้างความหดหู่ใจอย่างไร้จุดหมาย หากแต่ทำงานในลักษณะ **"การเขย่าจิตให้สะเทือน (Stirring) แล้วกล่อมเกลาจิตให้สงบระงับ (Stilling)"** [8]:
1. **ท่อนแรกของบทเพลง:** จะพรรณนาถึงความน่าสะพรึงกลัวของวัฏสงสาร ความตายที่ไม่อาจหลีกเลี่ยงได้ ซากศพที่เน่าเปื่อยถูกหนอนแทะเล็ม หรือความทุกข์ทรมานในนรก เพื่อปลุกเร้าให้เกิด **สังเวช (Saṃvega)** อย่างรุนแรงจนจิตตระหนกและละทิ้งความประมาท
2. **ท่อนหลังของบทเพลง:** เมื่อจิตเกิดสังเวชแล้ว ทำนองและเนื้อหาจะเปลี่ยนผ่านไปสู่การสรรเสริญพระคุณของพระพุทธเจ้า ชัยชนะเหนือบ่วงมาร และพระนิพพานอันเป็นเกาะที่ปลอดภัย ก่อให้เกิด **ปสาทะ (Pasāda)** คือความเลื่อมใสศรัทธา ความสว่างวาบ และความสงบระงับแห่งจิตใจ

## 3. "ภารกิจของผู้ใกล้ตาย" และเทคโนโลยีแห่งความตาย (The Work of the Dying)

หัวใจสำคัญในวิทยานิพนธ์ *Unfolding Buddhism* ของวอล์กเกอร์ คือการเสนอแนวคิดเรื่อง **"The Work of the Dying" (ภารกิจของผู้ใกล้ตาย)** [9]

วอล์กเกอร์ชี้ให้เห็นว่า ในวัฒนธรรมพุทธเขมรและสยามยุคโบราณ "การตาย" มิใช่ภาวะเฉื่อยชา (Passive state) ที่บุคคลนอนรอความตายอย่างไร้ทางสู้ หากแต่เป็น **"ภารกิจและหน้าที่ทางจิตวิญญาณขั้นสูงสุด" (Supreme Spiritual and Liturgical Task)** ที่ผู้ใกล้ตาย ชุมชน ญาติมิตร และพระสงฆ์ต้องร่วมมือกันปฏิบัติการอย่างเข้มข้น:
- ผู้ใกล้ตายต้องทำภารกิจ "ถอนจิต" ออกจากความยึดมั่นถือมั่น ขอขมาโทษต่อสรรพสัตว์ ชำระหนี้บุญคุณต่อบิดามารดา และกำหนดสมาธิภาวนา
- พระสงฆ์และญาติมิตรต้องทำหน้าที่เป็น "ประคองจิต" (Psychopomp) ผ่านการเปล่งเสียงสวดมนต์ นำทางจิตวิญญาณมิให้พลัดตกสู่อบายภูมิ และมุ่งตรงสู่สุคติภูมิหรือพระนิพพาน

```
+-----------------------------------------------------------------------+
|         ระบบนิเวศพิธีกรรมหน้าเตียงผู้ใกล้ตาย (Deathbed Liturgical Ecology)    |
+-----------------------------------------------------------------------+
|                                                                       |
|   [ พระสงฆ์ / ผู้ขับสวด ] -------- (เสียงสวด Smot / คาถาบาลี) --------+   |
|            |                                                         | |
|     (คลี่คัมภีร์สมุดข่อย)                                              | |
|            |                                                         v v
|            v                                                  [ ผู้ใกล้ตาย ]
|   [ สมุดข่อย Leporello ] <--- (ผัสสะทางสายตา: ภาพจิตรกรรมพุทธประวัติ)  (กำหนดจิต)
|   (เทคโนโลยีแห่งการระลึก)                                               |
|            ^                                                         |
|            |                                                         |
|   [ ชุมชน / ลูกหลาน / ยายชี ] --- (ขอขมา / บอกบุญ / น้อมจิตพิจารณา) ---+
|                                                                       |
+-----------------------------------------------------------------------+
```

## 4. คัมภีร์สมุดข่อยในฐานะ "วัตถุพิธีกรรมรองรับผัสสะ" (Leporellos as Affordances for Deathbed Rites)

ในบทความวิจัยตีพิมพ์ใน *Hualin International Journal of Buddhist Studies* (2024) [10] วอล์กเกอร์ได้วิเคราะห์หลักฐานทางโบราณวัตถุและเอกสารตัวเขียนสมุดข่อยสยามและเขมรอย่างละเอียด โดยประยุกต์ใช้ทฤษฎี **Affordance Theory** ของ James J. Gibson เพื่อตอบคำถามว่า: **เหตุใดพิธีกรรมหน้าเตียงผู้ใกล้ตายจึงต้องใช้ "สมุดข่อย" (Leporello / สมุดไทย) แทนที่จะเป็น "คัมภีร์ใบลาน"?**

วอล์กเกอร์ค้นพบเหตุผลเชิงโครงสร้างและผัสสะ 4 ประการ [11]:

### 4.1 ความคล่องตัวในการเปิดคลี่ (Accordion Fold Mechanism)
คัมภีร์ใบลานมีลักษณะเป็นแผ่นยาวผูกร้อยด้วยเชือก การเปิดอ่านต้องใช้สองมือประคองและพลิกทีละใบ ซึ่งไม่สะดวกในพื้นที่จำกัดข้างเตียงผู้ป่วย ในทางตรงกันข้าม **สมุดข่อย** ทำจากเยื่อเปลือกข่อยพับทบไปมา สามารถเปิดคลี่ออกได้ทันที วางตั้งบนตักหรือบนโต๊ะเตี้ยข้างเตียง สามารถกางออกเป็นแนวยาวหลายหน้าเพื่ออ่านบทสวดต่อเนื่องโดยไม่ต้องสะดุดพลิกหน้า

### 4.2 ลำดับของบทสวดพิธีกรรมที่ถูกจัดวางเฉพาะ (Curated Liturgical Sequences)
จากการสำรวจสมุดข่อย 70 ฉบับ วอล์กเกอร์พบว่า ลำดับของบทสวดในสมุดข่อยหน้าเตียงผู้ตายถูกจัดเรียงตามลำดับจิตวิทยาของความตายอย่างเป็นระบบ:
1. **บทชุมนุมเทวดาและนมัสการพระรัตนตรัย:** ปรับบรรยากาศรอบเตียงให้บริสุทธิ์
2. **บทพิจารณาสังขารและอาการ 32:** กระตุ้นเตือนให้ผู้ป่วยยอมรับความจริงของร่างกายที่กำลังแตกดับ
3. **บทพระมาลัยเสด็จโปรดนรก-สวรรค์:** ฉายภาพผลของบาปบุญเพื่อให้เกิดความเกรงกลัวต่อบาปและปรารถนาภพภูมิที่ดี
4. **บทพระอภิธรรม 7 คัมภีร์ (สังคณี ธัมมสังคณี ปัฏฐาน):** ยกระดับจิตเข้าสู่ปรมัตถธรรม กำหนดรู้จิตและรูป
5. **บทพุทธคุณและบทพาหุงมหากา:** เสริมสร้างกำลังใจและความผ่องใสในวาระจิตสุดท้าย

### 4.3 พลังแห่งภาพจิตรกรรมประกอบ (Illuminations as Visual Anchors)
สมุดข่อยสยามและเขมรมักมีภาพจิตรกรรมลงรักปิดทองหรือระบายสีอย่างวิจิตรงดงาม ภาพเหล่านี้มิได้มีไว้เพียงเพื่อความสวยงาม แต่ทำหน้าที่เป็น **"เครื่องยึดเหนี่ยวทางสายตา" (Visual Affordance)** สำหรับผู้ป่วยที่กำลังอ่อนแรง:
- พระสงฆ์หรือญาติจะกางสมุดข่อยให้ผู้ป่วยมองเห็นภาพพระพุทธเจ้าปราบพญามาลัย ภาพพระมาลัยโปรดสัตว์นรก หรือภาพทวยเทพบนสวรรค์ชั้นดาวดึงส์
- แสงสลัวของเปลวเทียนข้างเตียงที่สะท้อนกับทองคำเปลวบนหน้าสมุดข่อย ช่วยสร้างภาพจำอันงดงามให้ติดตรึงอยู่ในจิตก่อนสิ้นลม (จุติจิต)

### 4.4 บันทึกคำชี้แนะพิธีและคำขอขมา (Ritual Instructions and Colophons)
ริมขอบหรือส่วนท้ายของสมุดข่อยมักมีคำชี้แนะสำหรับผู้ขับสวด เช่น ระบุจังหวะการเอื้อนเสียง คำสั่งให้จุดธูปกี่ดอก หรือบทสวดขอขมาโทษ (Smā lā dos pāpakamm) เพื่อให้ผู้ใกล้ตายเปล่งวาจาขออโหสิกรรมต่อสรรพสัตว์

## 5. การไหลเวียนของบทสวดและร่องรอยคัมภีร์ข้ามพรมแดน: สยาม กัมพูชา และเวียดนาม

### 5.1 ประวัติศาสตร์การเดินทางข้ามแดนของบทสวด (Transnational Circulation of Liturgies)
ในบทความเรื่อง *"A Chant Has Nine Lives: The Circulation of Theravada Liturgies in Thailand, Cambodia, and Vietnam"* (2020) [12] วอล์กเกอร์ได้สร้างแผนที่การแพร่กระจายของบทสวดพิธีกรรมระหว่าง 3 วัฒนธรรม:
- บทสวดหลายบทที่คุ้นเคยในพระสงฆ์ไทย (เช่น บทสวดทำวัตรเช้า-เย็น บทสวดพระมาลัย บทสวดอภิธรรมมาติกา) มีการแลกเปลี่ยนข้ามพรมแดนกับกัมพูชาอย่างต่อเนื่องตั้งแต่สมัยอยุธยาตอนปลาย
- ในยุคฟื้นฟูหลังสงครามสมัยต้นรัตนโกสินทร์ ราชสำนักกัมพูชาของสมเด็จพระหริรักษ์รามมหาอิศราธิบดี (พระองค์ด้วง) ได้รับคัมภีร์และทำนองสวดจากกรุงเทพฯ ไปปรับใช้ ขณะเดียวกัน ทำนองสวดแบบเขมรโบราณก็ยังคงรักษาเอกลักษณ์ของตนเองไว้
- ในชุมชนชาวพุทธเชื้อสายเขมรในเวียดนามตอนใต้ (Khmer Krom ในดินแดนปากแม่น้ำโขง) บทสวดเหล่านี้ได้กลายเป็นเครื่องมือสำคัญในการธำรงอัตลักษณ์ทางวัฒนธรรมและภาษาท่ามกลางสังคมเวียดนาม

### 5.2 เสียงสะท้อนจากอดีตสันสกฤต: คาถาอุณหิสสวิชัย (The Pali Uṇhissavijaya in Cambodia)
ในงานวิจัยตีพิมพ์โดยสถาบันวิจัยนานาชาติลุมพินี (LIRI, 2018) [13] วอล์กเกอร์ได้ศึกษาคัมภีร์ **"คาถาอุณหิสสวิชัย" (Uṇhissavijaya)** ในกัมพูชา ซึ่งเป็นบทสวดยอดนิยมสำหรับพิธีต่ออายุ สะเดาะเคราะห์ และสวดให้ผู้ป่วยหนัก:
- วอล์กเกอร์สืบค้นร่องรอยทางนิรุกติศาสตร์และพบว่า บทสวดบาลีบทนี้แท้จริงแล้วมีต้นกำเนิดเชื่อมโยงกับธารณีสูตรภาษาสันสกฤตของพุทธศาสนามหายาน-ตันตระ คือ *อุษณีษวิชยธารณี* (Uṣṇīṣavijayā Dhāraṇī)
- พระสงฆ์ในอุษาคเนย์ได้แปลงธารณีภาษาสันสกฤตให้กลายเป็นบทสวดภาษาบาลี และหลอมรวมเข้าเป็นส่วนหนึ่งของหลักสูตรสวดมนต์เถรวาทอย่างแนบเนียน สะท้อนให้เห็นร่องรอยการผสมผสานทางศาสนา (Syncretism) ที่มีชีวิตอยู่ในวัฒนธรรมสวดมนต์ของภูมิภาค

## 6. กรรมฐานโบราณ (Borān Kammaṭṭhāna) และบทสวดหน้าเตียงผู้ตาย

ประเด็นที่ลึกซึ้งยิ่งในวิทยานิพนธ์ของวอล์กเกอร์ (บทที่ 8) คือการวิเคราะห์ความเชื่อมโยงระหว่างบทสวดในสมุดข่อยกับ **"ระบบกรรมฐานโบราณ" (Traditional / Borān Kammaṭṭhāna หรือพุทธศาสนาแบบโยคาวจร)** [14]

วอล์กเกอร์ชี้ให้เห็นว่า บทสวดหน้าเตียงผู้ตายมิใช่เพียงการอ้อนวอนขอพร แต่เป็นการนำทางจิตตามแผนที่กายวิภาคเชิงจิตวิญญาณของกรรมฐานโบราณ:
- การกำหนดลมหายใจเข้า-ออกควบคู่กับพุทโธ
- การกำหนดฐานจิตภายในร่างกาย (ศูนย์กลางกาย ดอกบัว 4 เหล่า จักระทั้ง 7)
- การใช้คำบริกรรมธาตุทั้งสี่ (นะ มะ พะ ธะ) เพื่อถอดถอนจิตออกจากขันธ์ 5 ในขณะที่ธาตุดิน น้ำ ลม ไฟในร่างกายกำลังแตกสลาย
- บทสวดเหล่านี้ทำหน้าที่เป็น "คู่มือเสียง" (Acoustic guide) ที่ช่วยให้จิตของผู้ป่วยไม่เคว้งคว้าง แต่สามารถกำหนดนิมิตแสงสว่างตามหลักกรรมฐานจนกระทั่งจิตดับลงอย่างสงบ

## 7. บทสรุป: มรดกทางโสตทัศน์ศึกษาของ Trent Walker

งานวิจัยของ ดร. เทรนต์ วอล์กเกอร์ ในมิติพุทธศาสนาเชิงโสตทัศน์และพิธีกรรมมรณานุสติ ได้สร้างคุณูปการที่ประเมินค่ามิได้:
1. **กอบกู้เสียงสวดและบทเพลงที่ใกล้สูญหาย:** ผ่านการบันทึกเสียงภาคสนาม การแปลกวีนิพนธ์ใน *Until Nirvana's Time* และการเผยแพร่อัลบั้มเพลงธรรมะสู่สาธารณะ
2. **เชื่อมโยงวัตถุธรรม (สมุดข่อย) เข้ากับสุนทรียภาพทางเสียง (Smot):** พิสูจน์ให้เห็นว่าเอกสารตัวเขียนโบราณมิอาจเข้าใจได้อย่างสมบูรณ์หากปราศจากการเปล่งเสียงอ่าน
3. **ฟื้นฟูปัญญาเรื่องการเผชิญความตาย:** นำเสนอองค์ความรู้ว่าด้วย "ภารกิจของผู้ใกล้ตาย" ซึ่งสามารถนำมาประยุกต์ใช้ในการดูแลผู้ป่วยระยะสุดท้าย (Palliative Care) และการเยียวยาจิตวิญญาณในโลกยุคปัจจุบัน
