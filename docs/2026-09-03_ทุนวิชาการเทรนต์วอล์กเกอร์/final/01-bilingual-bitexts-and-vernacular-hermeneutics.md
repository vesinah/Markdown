## 1. บทนำและปรัชญาญาณวิทยา: การรื้อถอนมายาคติอาณานิคมและการเปิดพรมแดน "ตัวบททวิลักษณ์"

ตลอดช่วงคริสต์ศตวรรษที่ 19 ถึงปลายคริสต์ศตวรรษที่ 20 การศึกษาประวัติศาสตร์วรรณกรรมและคัมภีร์พุทธศาสนาเถรวาทในภาคพื้นทวีปเอเชียตะวันออกเฉียงใต้ตกอยู่ภายใต้อิทธิพลของกรอบคิดแบบอาณานิคมและบูรพคดีศึกษา (Orientalism) อย่างลึกซึ้ง นักบูรพคดีชาวยุโรปยุคบุกเบิกมักให้คุณค่าสูงสุดเฉพาะพระไตรปิฎกภาษาบาลีที่บริสุทธิ์ในฐานะ "พุทธศาสนาดั้งเดิม" (Original / Pure Buddhism) และมองข้ามหรือลดทอนคุณค่าของวรรณกรรมภาษาถิ่น (Vernacular literatures) ไม่ว่าจะเป็นภาษาไทย เขมร ลาว ล้านนา มอญ หรือพม่า โดยตราหน้าวรรณกรรมที่มีการแปลคำบาลีสลับกับภาษาท้องถิ่นว่าเป็นเพียง "Crib" (สมุดเฉลยคำแปลคำต่อคำอย่างเก้ๆ กังๆ สำหรับภิกษุสามเณรที่เรียนไวยากรณ์บาลีไม่แตกฉาน) หรือจัดเป็นเพียง "Secondary derivative texts" (ตัวบทชั้นรองที่ไร้คุณค่าทางวรรณศิลป์และความคิดริเริ่ม) [1]

ดร. เทรนต์ วอล์กเกอร์ (Trent Walker) ได้สร้างคุณูปการระดับปฏิวัติกระบวนทัศน์ (Paradigm Shift) ในวงวิชาการพุทธศาสนศึกษา ประวัติศาสตร์ภูมิปัญญา และทฤษฎีวรรณคดีเปรียบเทียบ ด้วยการรื้อถอนมายาคติเชิงลำดับชั้นดังกล่าวผ่านงานวิจัยชุด "ตัวบททวิลักษณ์" (Bitexts) เริ่มตั้งแต่บทความระดับหมุดหมายใน *Journal of the American Oriental Society* (2020) [2], บทสังเคราะห์แม่บทใน *The Routledge Handbook of Theravada Buddhism* (2022) [3], งานวิเคราะห์เทศนาบาลี-เขมรใน *Journal of Indian Philosophy* (2022) [4], บทความเชิงทฤษฎีในรวมบทความของ Routledge (2024) [5], ตลอดจนบทความวิจัยว่าด้วยวรรณคดีคำหลวงสมัยอยุธยาใน *Manuscript Studies* (2026) ร่วมกับ ดร. ทศพล ศรีพุ่ม [6]

วอล์กเกอร์นิยามคำว่า **"ตัวบททวิลักษณ์" (Bitext / Bilingual Bitext)** ในบริบทพุทธศาสนาอุษาคเนย์ว่าหมายถึง:
> "งานประพันธ์ทางวรรณกรรม ศาสนา หรือวิชาการ ที่จัดวางร้อยเรียงสองภาษา—โดยทั่วไปคือภาษาคลาสสิกศักดิ์สิทธิ์ (ภาษาบาลี หรือบางกรณีคือภาษาสันสกฤต) ควบคู่กับภาษาถิ่นเอเชียตะวันออกเฉียงใต้ภาษาใดภาษาหนึ่ง—สลับคู่กันอย่างเป็นระบบ เพื่อถ่ายทอดเนื้อความ บทเทศนา อรรถกถา หรือกวีนิพนธ์เรื่องเดียวกัน โดยทั้งสองภาษามิได้แยกขาดออกจากกันเป็นสองคอลัมน์อิสระ แต่หลอมรวมเป็นหน่วยการอ่าน การตีความ และปฏิบัติการขับขานเดียวกัน" [7]

วอล์กเกอร์ชี้ให้เห็นว่า ปรากฏการณ์ตัวบททวิลักษณ์ในอุษาคเนย์ช่วง ค.ศ. 1450–1850 มิใช่หลักฐานของความเสื่อมถอยหรือการขาดทักษะภาษาบาลี หากแต่เป็น **"เทคโนโลยีทางปัญญาขั้นสูง" (Advanced Intellectual Technology)** และเป็น **"อรรถกถาที่มีชีวิตและสะสมพอกพูน" (Living and Cumulative Commentaries)** ตัวบททวิลักษณ์เป็นกลไกที่ทำให้พระธรรมคำสอนในภาษาบาลีโบราณสามารถ "หยั่งรากลึก" เข้าสู่จิตวิญญาณของผู้คนในสังคมท้องถิ่น เป็นสะพานเชื่อมระหว่างโลกคฤหัสถ์กับบรรพชิต และเป็นพื้นที่รังสรรค์นวัตกรรมทางภาษาและวรรณศิลป์ที่สำคัญที่สุดของภูมิภาคในยุคต้นสมัยใหม่ (Early Modern Period)

## 2. มิติมนุษยศาสตร์เปรียบเทียบระดับสากล: ตัวบททวิลักษณ์กับการแปลยกศัพท์ในโลกตะวันออกและตะวันตก

เพื่อยกระดับทฤษฎีตัวบททวิลักษณ์ในพุทธศาสนาอุษาคเนย์สู่วงวิชาการระดับโลก วอล์กเกอร์ได้เทียบเคียงปรากฏการณ์นี้กับประเพณีการแปลยกศัพท์ รอยจารระหว่างบรรทัด และระบบการอ่านข้อความคลาสสิก (Glossing & Vernacular Reading Traditions) ในอารยธรรมอื่นทั่วโลก ดังที่ปรากฏในงานวิจัยเปรียบเทียบร่วมสมัย เช่น งานของ Patrick Moran และ John Whitman (2022) [8] ตลอดจนข้อค้นพบทางประวัติศาสตร์ตัวเขียน:

```
+---------------------------------------------------------------------------------------------------+
|               ระบบการอ่านและแปลภาษาคลาสสิกข้ามอารยธรรม (Comparative Vernacular Reading Systems)              |
+---------------------------------------------------------------------------------------------------+
|  1. เอเชียตะวันออก (Sinographic Sphere):                                                           |
|     - ญี่ปุ่น: คุนโดะกุ (Kundoku - 訓読) — อ่านข้อความจีนตามไวยากรณ์ญี่ปุ่นทันที โดยใช้เครื่องหมายกำกับ     |
|     - เกาหลี: คูคย็อล (Gugyeol/Seokdok - 口訣/釋讀) — แทรกอักขระช่วยอ่านไวยากรณ์เกาหลีในคัมภีร์จีน           |
|     - เวียดนาม: ฮ้านเหวียต (Hán Việt - 漢越) — ระบบการออกเสียงคำยืมจีนและการเรียบเรียงวรรณกรรมโนม (Nôm)      |
|                                                                                                   |
|  2. ยุโรปยุคกลาง (Western Latin Christendom):                                                     |
|     - รอยจารระหว่างบรรทัดภาษาละติน-ภาษาถิ่น (Latin-Vernacular Interlinear Glosses)                        |
|     - เช่น รอยจารภาษาอังกฤษเก่า (Old English) หรือไอริชโบราณ แทรกระหว่างบรรทัดในพระคัมภีร์ไบเบิลภาษาละติน   |
|     - มุ่งเน้นเป็นเครื่องมือช่วยอ่านคำต่อคำ (Aids to Reading) ของนักบวชในอาราม                          |
|                                                                                                   |
|  3. เอเชียใต้และเอเชียตะวันออกเฉียงใต้ (Theravada Buddhist World):                                 |
|     - ศรีลังกา: สันนยะ (Sannaya) — แปลยกศัพท์บาลีเป็นภาษาสิงหลโบราณ                                        |
|     - พม่า/มอญ/ไทเขิน: นิสสัย (Nissaya) — บาลี-พม่า/มอญ พร้อมคำบอกวิภัตติไวยากรณ์                       |
|     - กัมพูชา: สำราย (Samray / สํราย) — บาลี-เขมร ทั้งในใบลานเทศนาและศิลาจารึก                            |
|     - สยาม/ล้านนา: นิสสัย, โวหาร, ร่ายวัด, และวรรณคดีคำหลวง (Kham Luang)                                |
|     * เอกลักษณ์: ก้าวหน้าจาก "เครื่องหมายช่วยอ่าน" สู่ "วรรณคดีเอกเทศที่มีสุนทรียภาพทางกวีนิพนธ์สมบูรณ์ในตัวเอง" |
+---------------------------------------------------------------------------------------------------+
```

### 2.1 ความแตกต่างเชิงสุนทรียศาสตร์และบทบาทหน้าที่
วอล์กเกอร์ชี้ให้เห็นความแตกต่างสำคัญระหว่างตัวบททวิลักษณ์อุษาคเนย์กับระบบอื่น:
1. **คุนโดะกุและคูคย็อลในเอเชียตะวันออก:** แม้จะเป็นระบบถอดรหัสข้อความคลาสสิกที่ยอดเยี่ยม แต่เป้าหมายหลักคือการ "แปลงประโยคจีนให้ออกเสียงเป็นภาษาท้องถิ่น" รอยจารในคัมภีร์จีนจึงทำหน้าที่เป็นดั่ง "โค้ดคอมพิวเตอร์" กำกับการอ่าน มากกว่าการเป็นบทกวีที่ประพันธ์ขึ้นใหม่
2. **รอยจารระหว่างบรรทัดในยุโรปยุคกลาง:** มีลักษณะเป็นเศษเสี้ยว (Fragmentary) มักเขียนด้วยลายมือขนาดเล็กแทรกระหว่างบรรทัดหรือริมขอบเพื่อช่วยจำคำศัพท์ มิได้ถูกออกแบบมาเพื่อการเปล่งเสียงอ่านออกเสียงคู่ขนานกันต่อหน้าสาธารณชน
3. **ตัวบททวิลักษณ์ในพุทธศาสนาอุษาคเนย์:** พัฒนาไปสู่ **"ศิลปะแห่งการประพันธ์ร่วมสองภาษา" (Co-compositional Art)** กล่าวคือ ภาษาถิ่นมิได้จำกัดอยู่เพียงร้อยแก้วอธิบายศัพท์ แต่ได้รับการร้อยกรองด้วยฉันทลักษณ์ชั้นสูง (เช่น กาพย์ยานี กาพย์ฉบัง ร่ายดั้น โคลงสี่สุภาพ หรือฉันท์พากย์เขมร) และที่สำคัญที่สุดคือ **ตัวบทถูกออกแบบมาสำหรับการขับขานจริงในพิธีกรรม (Oral Performance & Ritual Recitation)** พระสงฆ์หรือราชบัณฑิตจะขับขานบทบาลีด้วยท่วงทำนองหนึ่ง แล้วขับขานคำแปลภาษาถิ่นด้วยอีกท่วงทำนองหนึ่งสลับกันไปอย่างกลมกลืน [9]

## 3. กายวิภาคและแบบลักษณ์ของตัวบททวิลักษณ์ (Anatomy and Typology of Bitexts)

ในการวิเคราะห์เชิงโครงสร้าง วอล์กเกอร์ได้วางพิมพ์เขียวทางทฤษฎีในการทำความเข้าใจกำเนิดและแบบลักษณ์ของตัวบททวิลักษณ์ โดยจำแนกออกเป็น **3 ขั้นตอนเชิงตรรกะ (Three Logical Steps)**, **10 กลวิธีทางวรรณศิลป์ (Ten Textual Techniques)**, และ **4 โหมดหลักของการนำเสนอ (Four Presentation Modes)** [10]:

```
+---------------------------------------------------------------------------------------------------+
|                             กายวิภาคเชิงกระบวนการของตัวบททวิลักษณ์ (Bitextual Genesis)                |
+---------------------------------------------------------------------------------------------------+
|  [ขั้นที่ 1: Selection - การคัดเลือกตัวบทต้นฉบับ]                                                   |
|  - 1a. Direct Quotation: ยกคาถาหรือข้อความบาลีจากพระไตรปิฎก/อรรถกถามาตรงๆ                           |
|  - 1b. Paraphrase & Condensation: ตัดทอน รวบรัด หรือย่อความข้อความบาลีเดิมให้กระชับ                   |
|  - 1c. Interpolation: แต่งคาถาบาลีใหม่ขึ้นมาแทรก เพื่อใช้เป็นสะพานเชื่อมหรือหัวข้อธรรม               |
|                                                                                                   |
|  [ขั้นที่ 2: Analysis - การวิเคราะห์และผูกสัมพันธ์ทางภาษา]                                             |
|  - 2a. Parsing: ตัดบทและแยกหน่วยคำบาลีออกเป็นท่อนๆ เพื่อเตรียมประกบภาษาถิ่น                           |
|  - 2b. Amplification: การขยายความ พรรณนาอารมณ์ และเสริมอุปมานิทัศน์ในภาษาถิ่น                       |
|  - 2c. Rearrangement: การจัดลำดับคำใหม่จากไวยากรณ์บาลี (SOV) ให้เข้ากับไวยากรณ์ภาษาถิ่น (SVO)          |
|  - 2d. Annotation: การจารรอยอธิบายศัพท์ยาก หรือรหัสย่อทางไวยากรณ์กำกับไว้                            |
|  - 2e. Glossing: การแปลยกศัพท์คำต่อคำ โดยระบุบทบาทของวิภัตติปัจจัย                                   |
|                                                                                                   |
|  [ขั้นที่ 3: Presentation - การจัดแสดงรูปเล่มและโหมดวรรณศิลป์]                                       |
|  - 3a. Philological Mode (โหมดนิรุกติศาสตร์): มุ่งสอนไวยากรณ์ อธิบายโครงสร้างประโยค                 |
|  - 3b. Exegetical Mode (โหมดอรรถกถา): มุ่งอธิบายความหมายเชิงปรัชญาและหลักธรรมชั้นสูง                |
|  - 3c. Homiletic Mode (โหมดเทศนา): มุ่งการขับขานสั่งสอนสาธุชน พรรณนาอรรถรสทางธรรม                   |
|  - 3d. Poetic Mode (โหมดกวีนิพนธ์): มุ่งความประณีตทางฉันทลักษณ์ ดนตรีกวี และสุนทรียภาพราชสำนัก      |
+---------------------------------------------------------------------------------------------------+
```

### 3.1 โหมดนิรุกติศาสตร์ (Philological Mode)
โหมดนี้มุ่งเน้นการสอนภาษาบาลีและความถูกต้องทางไวยากรณ์ คำบาลีแต่ละคำจะถูกตัดบท (Parsing) แล้วประกบด้วยคำแปลภาษาถิ่นที่ทำหน้าที่ระบุบทบาททางไวยากรณ์ (Syntactic & Case markers):
- ในภาษาไทยและล้านนา: ใช้คำเชื่อมบอกวิภัตติที่เป็นแบบแผน เช่น
  - ปฐมาวิภัตติ (ประธาน): "อันว่า..." (ล้านนา: "อั้นว่า...")
  - ทุติยาวิภัตติ (กรรมตรง): "ซึ่ง...", "สู่...", "ยัง..."
  - ตติยาวิภัตติ (เครื่องมือ/ผู้กระทำ): "ด้วย...", "โดย...", "อัน..."
  - จตุตถีวิภัตติ (ผู้รับ): "แก่...", "เพื่อ...", "ต่อ..."
  - ปัญจมีวิภัตติ (แดนเกิด): "แต่...", "จาก...", "กว่า..."
  - ฉัฏฐีวิภัตติ (ความเป็นเจ้าของ): "แห่ง...", "ของ...", "เมื่อ..."
  - สัตตมีวิภัตติ (สถานที่/กาล): "ใน...", "เหนือ...", "ใกล้...", "ที่..."
  - อาลปนะ (คำร้องเรียก): "แน่ะ...", "ดูกร...", "ข้าแต่..."
- ในภาษาเขมร (ขนบสำราย): ใช้คำกำกับ เช่น "ឯ" (ae - ประธาน), "នូវ" (nūv - กรรมตรง), "ដោយ" (doy - ตติยา)
- ตัวอย่างเด่นชัดคือคัมภีร์ตระกูล **นิสสัย (Nissaya)** ของพม่า ล้านนา มอญ และไทเขิน และ **สำราย (Samray)** ของกัมพูชา ซึ่งทำหน้าที่เป็นแท่นพิมพ์เขียวในการเรียนการสอนพระปริยัติธรรมในอารามพุทธมานานหลายร้อยปี [11]

### 3.2 โหมดอรรถกถา (Exegetical Mode)
มิใช่เพียงการแปลศัพท์ไวยากรณ์ แต่เป็นการอธิบายความหมายเชิงปรัชญาธรรมขั้นลึกซึ้ง ผู้แต่งจะยกพุทธพจน์บาลีสั้นๆ ขึ้นมาหนึ่งประโยค แล้วรจนาความเรียงขยายความตามแนวอรรถกถาและฎีกา เช่น การอธิบายจิต เจตสิก รูป นิพพาน ในพระอภิธรรม หรือการตีความพุทธบัญญัติในพระวินัย โหมดนี้สะท้อนบทบาทของพระเถระอุษาคเนย์ในฐานะ "พระอรรถกถาจารย์รุ่นใหม่" ผู้ผลิตองค์ความรู้พุทธศาสนาในบริบทท้องถิ่น

### 3.3 โหมดเทศนา (Homiletic Mode)
ถูกออกแบบมาสำหรับการเปล่งเสียงเทศนาสดในศาสนพิธี ตัวบทจะมีการจัดวางจังหวะจะโคนให้เอื้อต่อการเอื้อนทำนองและการรับ-ส่งเสียงระหว่างพระเทศน์กับผู้ฟัง เช่น:
- ประเพณีเทศน์มหาชาติ (Vessantara Jātaka) ในสยาม ที่ใช้ "ทำนองหลวง" หรือ "ร่ายวัด"
- เทศน์หางสลึกในลาวและอีสาน
- เทศนาสำรายในกัมพูชา
การสลับเสียงระหว่างคาถาบาลีอันขรึมขลัง กับร้อยกรองภาษาถิ่นที่เต็มไปด้วยอารมณ์ความรู้สึก (เช่น ความโศกเศร้าของนางมัทรี หรือความน่าสงสารของสองกุมาร) ช่วยตรึงความสนใจและสร้างศรัทธาแก่พุทธศาสนิกชนได้อย่างทรงพลัง

### 3.4 โหมดกวีนิพนธ์ (Poetic Mode)
เป็นขั้นสูงสุดของการผสานสองภาษา ซึ่งภาษาถิ่นมิได้เป็นเพียงร้อยแก้วคำแปล แต่ได้รับการประพันธ์เป็นฉันทลักษณ์ระดับประณีตศิลป์ เช่น กาพย์ ฉันท์ โคลง ร่าย ในราชสำนักสยาม หรือฉันท์พากย์ในราชสำนักกัมพูชา ผู้แต่งต้องมีความเชี่ยวชาญทั้งฉันทลักษณ์ภาษาบาลีและฉันทลักษณ์ภาษาถิ่นอย่างเอกอุ ตัวอย่างที่สมบูรณ์แบบที่สุดคือ **วรรณคดีคำหลวง (Kham Luang)** สมัยอยุธยา [12]

## 4. ทฤษฎี "วรรณกรรมพืชอิงอาศัย" (Epiphytic Literatures: A Botanical Metaphor)

ข้อค้นพบเชิงทฤษฎีที่สร้างความตื่นตัวให้แก่วงวิชาการทฤษฎีการแปล (Translation Studies) และวรรณคดีเปรียบเทียบระดับโลก คือการที่วอล์กเกอร์ได้เสนอ **"อุปมาทางพฤกษศาสตร์" (Botanical Metaphor)** ในบทความสำคัญเรื่อง *"Epiphytic Literatures: A Botanical Metaphor for Indic-Vernacular Bitexts in Southeast Asia"* (2024) [13]

```
+---------------------------------------------------------------------------------------------------+
|               แบบจำลองเปรียบเทียบกระบวนทัศน์การแปล: ตะวันตก vs พุทธศาสนาอุษาคเนย์                    |
+---------------------------------------------------------------------------------------------------+
|  1. ทฤษฎีการแปลกระแสหลักของตะวันตก (Displacement & Binary Model):                                   |
|     - การแปลคือการ "แทนที่" ตัวบทต้นฉบับ (Target Text replaces Source Text)                       |
|     - ตัวบทแปลแยกขาดและทำหน้าที่แทนตนเองโดยสมบูรณ์ในระบบภาษาปลายทาง                                |
|     - วางอยู่บนฐานคิดแบบคู่ตรงข้าม: ต้นฉบับ vs บทแปล, เจ้าของภาษา vs ผู้แปล                       |
|                                                                                                   |
|  2. ทฤษฎีเดิมเชิงลบแบบอาณานิคม (Parasitic Model):                                                  |
|     - มองว่าภาษาถิ่นเป็น "กาฝาก" (Parasite) ที่เกาะกินและทำลายความบริสุทธิ์ของภาษาบาลี             |
|     - มองว่าการแปลแบบยกศัพท์ทำให้ภาษาบาลีสูญเสียความศักดิ์สิทธิ์และโครงสร้างไวยากรณ์ดั้งเดิม       |
|                                                                                                   |
|  3. ทฤษฎีของ Trent Walker: Epiphytic Literatures (พืชอิงอาศัย / กล้วยไม้-เฟิน-มอส):                  |
|     - [ต้นไม้ใหญ่ / Host Tree] = ภาษาบาลีหรือสันสกฤต ทำหน้าที่เป็นโครงสร้างค้ำจุนทางกายภาพ        |
|     - [พืชอิงอาศัย / Epiphytes] = ภาษาถิ่น (ไทย เขมร ลาว พม่า มอญ) เกาะเกี่ยวบนลำต้นและกิ่งก้าน    |
|     - [ความสัมพันธ์แบบเกื้อกูล]: พืชอิงอาศัยมิได้ดูดกินสารอาหาร ไม่ทำลายท่อน้ำเลี้ยง ไม่ทำให้ต้นไม้ตาย |
|     - [การสร้างระบบนิเวศใหม่]: ภาษาถิ่นสร้างพุ่มใบ ดอก ลวดลายวรรณศิลป์ ทำให้เกิด "เรือนยอดวรรณกรรม"|
|       (Literary Canopy) ที่อุดมสมบูรณ์ ผู้อ่านสัมผัสได้ถึงทั้งต้นไม้ใหญ่และกล้วยไม้พร้อมกัน         |
+---------------------------------------------------------------------------------------------------+
```

### 4.1 การวิพากษ์ทฤษฎีการแปลตะวันตก
วอล์กเกอร์ชี้ให้เห็นว่า ทฤษฎีการแปลของตะวันตก ตั้งแต่ Friedrich Schleiermacher, Walter Benjamin, ไปจนถึง Lawrence Venuti, André Lefevere และ Gayatri Spivak ล้วนวางอยู่บนสมมติฐานของการแปลแบบภาษาเดียวแทนที่ภาษาเดียว (Monolingual Replacement) ซึ่งไม่สามารถอธิบายปรากฏการณ์ตัวบททวิลักษณ์ในอุษาคเนย์ได้เลย เพราะ:
- ในตัวบททวิลักษณ์ **ตัวบทต้นฉบับ (บาลี) มิได้ถูกลบเลือนหรือแทนที่** แต่ยังคงปรากฏเคียงคู่อยู่ทุกบรรทัด
- ผู้อ่านและผู้ฟังมิได้เสพเฉพาะคำแปล แต่เสพ "เสียงขับขานภาษาบาลี" ควบคู่ไปกับ "ความหมายในภาษาถิ่น" พร้อมๆ กัน
- ความสัมพันธ์ระหว่างสองภาษามิใช่ความสัมพันธ์เชิงอำนาจที่ฝ่ายหนึ่งต้องกลืนกินอีกฝ่ายหนึ่ง แต่เป็นการดำรงอยู่ร่วมกันประดุจพืชอิงอาศัยในป่าเขตร้อนชื้นของเอเชียตะวันออกเฉียงใต้

### 4.2 มโนทัศน์ "ภาษาที่ลื่นไหล" (Liquid Language)
ในบทความเรื่อง *"Liquid Language: The Art of Bitextual Sermons in Middle Cambodia"* ในวารสาร *Journal of Indian Philosophy* (2022) [14] วอล์กเกอร์ได้ขยายความปรากฏการณ์พืชอิงอาศัยเข้าสู่มิติของสุนทรียศาสตร์ทางเสียง ในเทศนาธรรมยุคกลางของกัมพูชาและสยาม ผู้เทศน์มิได้หยุดพูดเพื่อประกาศว่า "ต่อไปนี้จะแปล" แต่กระแสเสียงจะไหลรินสลับไปมาระหว่างภาษาบาลีกับภาษาถิ่นอย่างลื่นไหล ประหนึ่งสายน้ำที่หลอมรวมเป็นสายธารเดียวกัน ผู้ฟังในอารามจะซึมซับทั้งมนต์ขลังศักดิ์สิทธิ์ของถ้อยคำพระพุทธองค์ และความสะเทือนอารมณ์ของกาพย์กลอนภาษาแม่ในคราวเดียวกัน [15]

## 5. วัฒนธรรมสมุดไทยคำหลวงสมัยอยุธยา: วรรณคดีทวิลักษณ์ชั้นสูงของราชสำนัก

การศึกษาวิจัยร่วมกันระหว่าง ดร. ทศพล ศรีพุ่ม และ ดร. เทรนต์ วอล์กเกอร์ ในบทความวิชาการเรื่อง *"Indic-Siamese Bitexts and Ayutthaya Scribal Culture: Exposition and Exegesis in Three Kham Luang Manuscripts"* ในวารสาร *Manuscript Studies* (2026) [16] ตลอดจนรายงานวิจัยฉบับสมบูรณ์ความยาว 459 หน้า เสนอต่อสำนักงานการวิจัยแห่งชาติ (วช.) ถือเป็นการค้นพบทางประวัติศาสตร์วรรณคดีและจดหมายเหตุครั้งสำคัญที่สุดชิ้นหนึ่ง

```
+---------------------------------------------------------------------------------------------------+
|               สามเอกสารตัวเขียนคำหลวงสมัยอยุธยาในฐานะตัวบททวิลักษณ์ (Three Kham Luang Leporellos)            |
+---------------------------------------------------------------------------------------------------+
|  1. มหาชาติคำหลวง (Mahāchāt kham lūang):                                                          |
|     - รังสรรค์: รัชสมัยสมเด็จพระบรมไตรโลกนาถ (ค.ศ. 1482 / พ.ศ. 2025)                               |
|     - เอกสารตัวเขียน: สมุดไทยฉบับคัดลอกปี ค.ศ. 1809 (พ.ศ. 2352) "กัณฑ์นครกัณฑ์" (Nagar kăṇḍ)     |
|     - ลักษณะ: คาถาพันบาลีประกบด้วยร้อยกรองสยาม (โคลง ฉันท์ กาพย์ ร่าย) ครบทั้ง 13 กัณฑ์             |
|                                                                                                   |
|  2. นันโทปนันทสูตรคำหลวง (Nanthopananthasut kham luang):                                          |
|     - รังสรรค์: ค.ศ. 1736 (พ.ศ. 2279) โดย เจ้าฟ้าธรรมาธิเบศร (เจ้าฟ้ากุ้ง / พระนามบวช: ศิริปาโล)   |
|     - เอกสารตัวเขียน: สมุดไทยฉบับเดียวในโลก (Codex Unicus) คัดลอกช่วง ค.ศ. 1741–1755 (หอสมุดแห่งชาติ)|
|     - รากเหง้า: ดัดแปลงจากคัมภีร์ "ฎีกาพาหุง" (Ṭīkā Bāhuṃ) ของพระพุทธสิริ พระเถระอยุธยา            |
|     - เกียรติประวัติ: ได้รับการขึ้นทะเบียนเป็น "มรดกความทรงจำแห่งโลก" (UNESCO Memory of the World) 2025!|
|                                                                                                   |
|  3. สุปรีติธรรมราชชาดกคำหลวง (Supritithammarachachadok kham luang):                               |
|     - รังสรรค์: ปลายสมัยอยุธยา (ประมาณ ค.ศ. 1736–1767 / พ.ศ. 2279–2310)                           |
|     - เอกสารตัวเขียน: สมุดไทยฉบับเดียวในโลก (Codex Unicus) สภาพชำรุดต้น-ท้าย (หอสมุดแห่งชาติ)     |
|     - ปรากฏการณ์พิเศษ: เป็นตัวบททวิลักษณ์ "สันสกฤต-สยาม" (Sanskrit-Siamese Bitext) เพียงฉบับเดียว   |
|     - ค้นพบ: คาถาสันสกฤตบางส่วนมิได้คัดลอกจากคัมภีร์โบราณ แต่ "ถูกรังสรรค์ขึ้นใหม่" ในราชสำนักอยุธยา |
+---------------------------------------------------------------------------------------------------+
```

### 5.1 กายภาพของสมุดไทยและการจัดวางหน้า (Codicology and Impagination)
วอล์กเกอร์และทศพลได้วิเคราะห์สมุดข่อย/สมุดไทย (Leporello manuscripts) ของราชสำนักอยุธยาอย่างละเอียด:
1. **การแบ่งแยกชุดอักขระ (Script Differentiation):**
   - ข้อความภาษาศักดิ์สิทธิ์ (บาลีหรือสันสกฤต) จะจารด้วย **อักษรขอมสยาม (Khmer script in Siam)** ด้วยเส้นสายที่บรรจง ชัดเจน หรือแต้มด้วยหมึกทอง
   - ข้อความภาษาไทย (คำแปลและบทพรรณนา) จะเขียนด้วย **อักษรไทยย่อหรืออักษรไทยบรรจง**
   - การแยกชุดอักษรทำให้ผู้อ่านสามารถระบุสถานะทางภววิทยาของภาษาได้ในทันทีที่กวาดสายตามองหน้าสมุดไทย
2. **เครื่องหมายกำกับวรรคตอนและโครงสร้างหน้า (Paratextual Markers):**
   - การใช้เครื่องหมายคั่นวรรคโบราณ (เช่น ฟองมัน อังคั่นเดี่ยว อังคั่นคู่ โคมูตร) เพื่อแบ่งเขตระหว่างบทบาทพุทธพจน์กับบทพรรณนาของกวี
   - การจัดวางคำบาลีไว้ตอนต้นของวรรค แล้วตามด้วยร้อยกรองสยามที่รับสัมผัสกันอย่างประณีต

### 5.2 ฟังก์ชันทางวรรณศิลป์: Exposition (การชี้แจง) และ Exegesis (การอรรถาธิบาย)
งานวิจัยชิ้นนี้พิสูจน์ว่า กวีราชสำนักอยุธยามิได้ทำหน้าที่เพียง "ผู้แปล" แต่ทำหน้าที่เป็น "นักเทววิทยาและนักปรัชญา":
- **Exposition (การชี้แจงอรรถ):** การถอดความหมายของคาถาบาลีให้แจ่มแจ้งตามหลักไวยากรณ์
- **Exegesis (การตีความเชิงลึก):** การสอดแทรกอรรถกถา อธิบายสภาวธรรม ขยายความรู้สึกทางจิตวิทยาของตัวละคร และผูกโยงเข้ากับค่านิยมของราชสำนักอยุธยา เช่น การแสดงบารมีของพระโพธิสัตว์ ความจงรักภักดี และธรรมเนียมราชประเพณี
- การค้นพบว่า *สุปรีติธรรมราชชาดกคำหลวง* มีการรังสรรค์คาถาสันสกฤตขึ้นใหม่ ยืนยันว่าราชสำนักอยุธยาช่วงปลายมีภูมิปัญญาภาษาสันสกฤตระดับสูงมากพอที่จะประพันธ์คาถาสันสกฤตขึ้นเองเพื่อเป็นแกนค้ำจุนร้อยกรองสยาม [17]

## 6. วัฒนธรรมคัมภีร์ใบลานและเอกสารหลายภาษาในเอกสารเดียว (Multilingual Palm-Leaf Manuscripts)

ประเด็นที่ ดร. เทรนต์ วอล์กเกอร์ มีความเชี่ยวชาญระดับแนวหน้าของโลก คือการศึกษาสัณฐานวิทยาและอักขรวิทยาของ **"คัมภีร์ใบลานหลายภาษาในเอกสารชิ้นเดียว" (Multilingual & Polyglot Palm-Leaf Manuscripts)** ซึ่งเชื่อมโยงโดยตรงกับบทบาทของเขาในฐานะผู้อำนวยการฝ่ายอนุรักษ์โครงการ Khmer Manuscript Heritage Project (KMHP) ของศูนย์ทรัพยากรดิจิทัลพุทธศาสน์ (BDRC) [18]

```
+---------------------------------------------------------------------------------------------------+
|               กายวิภาคเชิงกายภาพของหน้าใบลานหลายภาษา (Polyglot Palm-Leaf Anatomy)                 |
+---------------------------------------------------------------------------------------------------+
|  [ขอบซ้าย / รูร้อยเชือกที่ 1]                                         [ขอบขวา / รูร้อยเชือกที่ 2]    |
|  +---------------------------------------------------------------------------------------------+  |
|  | [รอยจารริมขอบ: ขอม/มอญ]   บรรทัด 1: ปาลีอักษรใหญ่ --- คำแปลภาษาถิ่นสลับวลี --- ปาลีอักษรใหญ่       |  |
|  | (Marginal Gloss)         บรรทัด 2: คำแปลขยายความ --- [รอยจารแทรกระหว่างบรรทัด: อักษรย่อ] ---      |  |
|  | [รหัสย่อไวยากรณ์]         บรรทัด 3: ปาลีคาถา --- ร้อยกรองภาษาถิ่นพรรณนา (ร่าย/สำราย/กาพย์) ---   |  |
|  | [เลขหน้าใบลานโบราณ]       บรรทัด 4: คำลงท้าย --- สัญลักษณ์กำกับทำนองเสียงสวด --- [รหัสเชื่อมผูก] |  |
|  +---------------------------------------------------------------------------------------------+  |
+---------------------------------------------------------------------------------------------------+
```

### 6.1 กลวิธีการจัดวางข้อความหลายภาษาบนหน้าลาน
ใบลานมีลักษณะทางกายภาพที่ยาวและแคบ (กว้างประมาณ 4.5–6 ซม. ยาวประมาณ 45–60 ซม.) โดยเฉลี่ยมีพื้นที่จารเพียง 4 ถึง 6 บรรทัด ผู้จารโบราณจึงต้องใช้ความคิดสร้างสรรค์ขั้นสูงในการจัดสรรพื้นที่:
1. **คำแปลแทรกระหว่างบรรทัด (Interlinear Glosses):** การจารข้อความบาลีด้วยตัวอักษรขนาดมาตรฐาน แล้วใช้เหล็กจารขนาดเล็กจารคำแปลภาษาถิ่น (เขมร ไทย หรือลาว) แทรกอยู่ใต้บรรทัด หรือระหว่างบรรทัดหลัก มักพบในคัมภีร์ไวยากรณ์สัทศาสตร์และคู่มือปริยัติธรรม
2. **คำแปลสลับคู่วลี (Interphrasal Alternation):** การจารคำบาลีหนึ่งท่อน แล้วตามด้วยคำแปลภาษาถิ่นทันทีในบรรทัดเดียวกัน โดยใช้เครื่องหมายคั่นวรรคโบราณ (เช่น ตีนกา อังคั่นเดี่ยว/คู่ หรือโคมูตร) เป็นตัวแบ่ง เป็นรูปแบบที่นิยมที่สุดในคัมภีร์เทศนา
3. **รอยจารอรรถกถาริมขอบลาน (Marginal Glosses & Paratexts):** บริเวณขอบซ้าย-ขวา หรือช่องว่างรอบรูร้อยสายสนอง (Peg holes) จะถูกใช้จารคำอธิบายศัพท์เฉพาะ รหัสย่อทางไวยากรณ์ หรือบันทึกช่วยจำของพระผู้เทศน์

### 6.2 คัมภีร์พหุภาษา (Trilingual and Polyglot Codices)
ในการสำรวจเอกสารตัวเขียนนับล้านหน้า วอล์กเกอร์พบว่ามีคัมภีร์ใบลานจำนวนมากที่รวบรวมมากกว่า 2 ภาษาไว้ในเอกสารชิ้นเดียวกัน:
- **คัมภีร์บาลี-ไทย-เขมร:** พบตามวัดแถบภาคกลางของสยามและเขมรตะวันตก (เสียมราฐ แบทบอง) ตัวบทแม่เป็นภาษาบาลี จารด้วยอักษรขอม มีคำแปลหลักเป็นภาษาไทย แต่มีบันทึกอรรถกถาริมขอบลานเป็นภาษาเขมร สะท้อนการแลกเปลี่ยนทางภูมิปัญญาของพระสงฆ์สองวัฒนธรรม
- **คัมภีร์บาลี-ล้านนา-พม่า:** พบในคลังคัมภีร์เชียงใหม่ ลำพูน และเชียงตุง ตัวบทแม่เป็นภาษาบาลี มีคำแปลแบบนิสสัยภาษาไทยวน แต่ใช้ศัพท์เทคนิคและระบบอ้างอิงไวยากรณ์ภาษาพม่า ซึ่งเป็นผลพวงจากการที่ล้านนาอยู่ภายใต้การปกครองของพม่าในยุคราชวงศ์ตองอู
- **คัมภีร์ปาติโมกข์บาลี-ไทใต้คงจากมณฑลยูนนาน (Pali-Dai Pātimokkha):** นำเสนอในการประชุม AAR 2024 เป็นเอกสารวินัยสงฆ์จากชายแดนจีน-พม่า-ลาว บันทึกข้อวินัยปาติโมกข์ภาษาบาลีคู่กับคำแปลและอรรถกถาภาษาไทใต้คง (Tai Dehong) โดยใช้อักษรธรรมและอักษรไทมาว สะท้อนการธำรงวินัยสงฆ์และการต่อรองเชิงอำนาจที่ชายขอบของโลกเถรวาท [19]

### 6.3 รหัสย่อและสัญลักษณ์ลับ (Abbreviations and Alphanumeric Codes)
ในปาฐกถา ณ มหาวิทยาลัยแคลิฟอร์เนีย เบิร์กลีย์ (2024) [20] วอล์กเกอร์ได้เปิดเผยระบบรหัสย่อที่ผู้จารใบลานใช้เพื่อประหยัดเนื้อที่:
- การใช้อักษรตัวแรกของคำบาลีสำคัญ (เช่น `ติ` แทน `ติโลกนาถ`, `พุ` แทน `พุทโธ`)
- การใช้สัญลักษณ์ตัวเลขแสดงลำดับหมวดธรรมในพระอภิธรรม (Matika shorthand)
- ระบบรหัสลับอ้างอิงข้ามผูก (Cross-bundle indexing) ซึ่งช่วยให้พระภิกษุสามารถค้นหาอรรถกถาเชื่อมโยงระหว่างผูกใบลานต่างๆ ในหอไตรได้อย่างรวดเร็ว

### 6.4 การอนุรักษ์ภาพดิจิทัลใบลาน (Palm-Leaf Document Image Analysis)
ความรู้เชิงลึกด้านกายภาพของใบลานที่วอล์กเกอร์ศึกษา สอดรับอย่างยิ่งกับงานวิจัยด้านวิทยาการคอมพิวเตอร์และการประมวลผลภาพเอกสารโบราณระดับสากล เช่น งานวิจัยของ Made Windu Antara Kesiman et al. (2018) เรื่อง *"Benchmarking of Document Image Analysis Tasks for Palm Leaf Manuscripts from Southeast Asia"* [21] ซึ่งศึกษาอัลกอริทึมในการรู้จำอักขระใบลาน (Binarization, Text Line Segmentation, Character Recognition) ในใบลานเขมรและบาหลี ปัญหาความเสื่อมสภาพของผิวลาน รอยขูดขีด และการจารซ้อนทับกันหลายภาษา ล้วนเป็นความท้าทายที่ต้องอาศัยการผสานระหว่าง "นักนิรุกติศาสตร์ตัวเขียน" (Philologist) อย่างวอล์กเกอร์ กับ "ผู้เชี่ยวชาญด้านดิจิทัล" ในการถอดรหัสมรดกภูมิปัญญาเหล่านี้สู่อนาคต

## 7. ประวัติศาสตร์ภูมิปัญญาตัวบททวิลักษณ์ในล้านนาและสยาม

### 7.1 ตัวบททวิลักษณ์บาลี-ไทที่เก่าแก่ที่สุดในล้านนา (15th–16th Century)
ในการประชุมวิชาการนานาชาติ SEAMEO SPAFA (2019) วอล์กเกอร์ได้นำเสนอหลักฐาน **ใบลานตัวบททวิลักษณ์บาลี-ไทที่เก่าแก่ที่สุดที่หลงเหลืออยู่ในเขตล้านนา** (คริสต์ศตวรรษที่ 15–16) จารด้วยอักษรธรรมล้านนา [22]
- การค้นพบนี้ปฏิวัติประวัติศาสตร์วรรณกรรม เพราะพิสูจน์ว่าพระสงฆ์ล้านนาได้พัฒนาเทคนิคการแปลแบบ *นิสสัย* และ *โวหาร* ขึ้นอย่างสมบูรณ์ก่อนหน้าอิทธิพลของราชสำนักอยุธยา
- มีการกำหนดระบบสัญลักษณ์กำกับไวยากรณ์ (Syntax markers) ที่เป็นเอกลักษณ์ของอักขรวิธีล้านนา ยืนยันว่าล้านนาคือหนึ่งในศูนย์กลางการผลิตตัวบททวิลักษณ์ที่ทรงอิทธิพลที่สุดในเอเชียตะวันออกเฉียงใต้

### 7.2 พระนันทปัญญาและคัมภีร์ "พิจารณาอารัมมณสังคหะ" (1638 CE)
ในการบรรยายพิเศษ ณ มหาวิทยาลัยฮัมบูร์ก (2023) [23] วอล์กเกอร์ได้เจาะลึกคัมภีร์ใบลานเรื่อง **"พิจารณาอารัมมณสังคหะ" (Bicāraṇā Ālambanasaṅgaha)** รจนาโดย **พระนันทปัญญา (Nandapañño)** พระมหาเถระแห่งนครเชียงใหม่เมื่อ ค.ศ. 1638:
- ในช่วงเวลาดังกล่าว ล้านนาอยู่ภายใต้การปกครองของราชวงศ์ตองอูแห่งพม่า แต่วงการวิชาการสงฆ์ล้านนายังคงผลิตผลงานทางปรัชญาที่ลึกซึ้ง
- พระนันทปัญญาได้นำคัมภีร์ *อภิธัมมัตถสังคหะ* มาแปลและขยายความแบบทวิลักษณ์บาลี-ล้านนา ผสานอรรถกถาบาลีเข้ากับโวหารคำเมืองอย่างแยบยล มีการอธิบายสภาวะจิตและอารมณ์ 6 ด้วยภาษิตท้องถิ่น
- งานวิจัยของวอล์กเกอร์ชี้ว่า ตัวบททวิลักษณ์ชิ้นนี้คือหลักฐานของ "อิสรภาพทางภูมิปัญญา" ของชาวล้านนาที่สามารถธำรงเอกลักษณ์ทางภาษาและความคิดของตนไว้ได้อย่างสง่างามท่ามกลางความผันผวนทางการเมือง

### 7.3 ภาษาบาลีสยาม (Siamese Pali) และคัมภีร์มหายุทธการวงศ์
ในการสัมมนา ณ มหาวิทยาลัยสแตนฟอร์ด (2022) ร่วมกับ ดร. อัสสนีย์ พูลรักษ์ และ ดร. เจียรนัย วิทิตกุล วอล์กเกอร์ได้อภิปรายปรากฏการณ์ **"ภาษาบาลีสยาม" (Siamese Pali)** ในคัมภีร์ *มหายุทธการวงศ์* (Mahāyuddhakāravaṃsa, ค.ศ. 1806) รจนาโดยสมเด็จพระพนรัตน์ วัดพระเชตุพน [24]:
- ชี้ให้เห็นว่า การที่พระสงฆ์สยามคุ้นชินกับการแต่งตัวบททวิลักษณ์มานานหลายร้อยปี ทำให้โครงสร้างไวยากรณ์ภาษาไทยได้ส่งอิทธิพลย้อนกลับไปกำหนดโครงสร้างประโยคบาลี (Calque / Syntactic borrowing)
- เกิดเป็นสำนวนภาษาบาลีเฉพาะถิ่นของสยามที่มีชีวิตชีวา ก่อนที่จะถูกแทนที่ด้วยกระบวนทัศน์บาลีบริสุทธิ์ตามแบบแผนไวยากรณ์สากลในการปฏิรูปของพระบาทสมเด็จพระจอมเกล้าเจ้าอยู่หัว (รัชกาลที่ 4)

### 7.4 การล้อเลียนตัวบททวิลักษณ์ใน "เทศนาเรื่องนิทานมิกะธุระ" ของรัชกาลที่ 5
กรณีศึกษาที่สะท้อนความฝังรากลึกของตัวบททวิลักษณ์ในวัฒนธรรมสยามได้ดีที่สุด คือพระราชนิพนธ์ในพระบาทสมเด็จพระจุลจอมเกล้าเจ้าอยู่หัว (รัชกาลที่ 5) เรื่อง *เทศนาเรื่องนิทานมิกะธุระ* [25]:
- ทรงนำเนื้อเรื่องของอุปรากรคอมเมดี้ตะวันตกเรื่อง *The Mikado* (1885) ของ Gilbert and Sullivan มาดัดแปลงเป็น "เทศนาตัวบททวิลักษณ์บาลี-ไทย"
- พระองค์ทรงให้ราชบัณฑิตแต่งคาถาบาลีแทรกเข้าไปหลังจากการแปลเนื้อเรื่องภาษาไทยเสร็จสิ้นแล้ว เพื่อล้อเลียน (Parody) ขนบการเทศน์มหาชาติ
- วอล์กเกอร์ชี้ว่า การที่รัชกาลที่ 5 ทรงเลือกใช้รูปแบบตัวบททวิลักษณ์ในการล้อเลียน แสดงให้เห็นว่าในปลายศตวรรษที่ 19 คนสยามทุกคนในสังคมคุ้นเคยกับโครงสร้างของตัวบททวิลักษณ์เป็นอย่างดี จนสามารถนำมาใช้เป็นเครื่องมือทางวรรณศิลป์เชิงขบขันและเสียดสีได้อย่างแยบคาย

## 8. ตัวบททวิลักษณ์ข้ามพรมแดน: กัมพูชา ลาว และเวียดนาม

### 8.1 ขนบ *Samray* ในกัมพูชา และจารึกศิลาทวิลักษณ์ที่ระเบียงนครวัด
ในกัมพูชา ตัวบททวิลักษณ์บาลี-เขมร หรือ **"สำราย" (Samray / สํราย)** มีบทบาทสำคัญยิ่ง ในบทความวิจัยในวารสาร *Udaya* (2020) [26] วอล์กเกอร์ได้ค้นพบว่า:
- ขนบทวิลักษณ์มิได้ปรากฏเฉพาะในคัมภีร์ใบลาน แต่ถูก **"สลักลงบนแผ่นศิลา"** ณ ระเบียงนครวัดในช่วงศตวรรษที่ 17–18
- เช่น จารึก **IMA 31 (ค.ศ. 1684)** ของสมเด็จพระปรวิทู และจารึก **IMA 38 (ค.ศ. 1701)** ของชัยนันท์ (La grande inscription d’Angkor)
- จารึกเหล่านี้สลักคาถาบาลีตัวโต แล้วตามด้วยคำแปลภาษาเขมรยุคกลางและคำอธิษฐานจิต ยืนยันว่าหลังยุคพระนคร นครวัดได้แปรสภาพเป็นพุทธสถานเถรวาทที่มีการปฏิบัติการทางภาษาแบบทวิลักษณ์อย่างสมบูรณ์

### 8.2 เทศนาอานิสงส์ทวิลักษณ์ในลาวและอีสาน
ในปาฐกถา ณ มหาวิทยาลัยมหิดล (2024) [27] วอล์กเกอร์ได้นำเสนอหลักฐานใบลานเทศนาเรื่อง **"อานิสงส์" (Ānisaṃsa)** ในดินแดนสองฝั่งโขง (ลาวและภาคอีสานของไทย):
- คัมภีร์อานิสงส์สร้างคัมภีร์ ใบลานอานิสงส์กฐิน และอานิสงส์สังฆทาน มักแต่งเป็นตัวบททวิลักษณ์
- เริ่มต้นด้วยพุทธพจน์บาลีสั้นๆ เพื่อสร้างความศักดิ์สิทธิ์ จากนั้นจึงขยายความเป็นร้อยกรองภาษาลาวที่ไพเราะ พรรณนาถึงวิมานและผลบุญที่จะได้รับ เป็นเครื่องมือขับเคลื่อนเศรษฐกิจบุญในสังคมพุทธลุ่มน้ำโขง

### 8.3 บทสวดทวิลักษณ์ในดินแดนสามเหลี่ยมปากแม่น้ำโขงของเวียดนาม
ในบทความวิจัยเรื่อง *"A Chant Has Nine Lives: The Circulation of Theravada Liturgies in Thailand, Cambodia, and Vietnam"* (2020) [28] วอล์กเกอร์ได้ติดตามการเดินทางของบทสวดพุทธเถรวาทข้ามพรมแดน:
- จากราชสำนักสยาม เข้าสู่กัมพูชา และแพร่หลายไปยังชุมชนชาวเขมรกรอม (Khmer Krom) ในแถบสามเหลี่ยมปากแม่น้ำโขง (Mekong Delta) ทางตอนใต้ของเวียดนาม
- ตัวบททวิลักษณ์บาลี-เขมรทำหน้าที่เป็น "ปราการทางวัฒนธรรม" ที่ช่วยให้ชาวพุทธเชื้อสายเขมรในเวียดนามสามารถธำรงรักษาภาษาแม่ ศาสนา และอัตลักษณ์ชาติพันธุ์ของตนไว้ได้ ท่ามกลางกระแสการกลืนกลายทางวัฒนธรรมของรัฐชาติสมัยใหม่

## 9. บทสรุปและนัยสำคัญต่อวงวิชาการมนุษยศาสตร์ระดับโลก

การศึกษาวิจัยเชิงลึกของ ดร. เทรนต์ วอล์กเกอร์ เรื่องตัวบททวิลักษณ์ อรรถศาสตร์พืชอิงอาศัย และเอกสารใบลานหลายภาษา ได้ส่งผลสะเทือนและสร้างคุณูปการอย่างไพศาลต่อวงวิชาการมนุษยศาสตร์ในระดับสากล:

```
+---------------------------------------------------------------------------------------------------+
|               คุณูปการ 4 ประการของทฤษฎีตัวบททวิลักษณ์ (Four Contributions of Bitext Theory)           |
+---------------------------------------------------------------------------------------------------+
|  1. การรื้อถอนลำดับชั้นทางภาษา (Decolonizing Language Hierarchies):                               |
|     - สลายมายาคติเรื่อง "บาลีบริสุทธิ์ vs ภาษาถิ่นชั้นรอง"                                        |
|     - ยืนยันว่าพุทธศาสนาเถรวาทดำรงอยู่ได้ด้วยการพึ่งพาอาศัยกันระหว่างภาษาศักดิ์สิทธิ์กับภาษาแม่     |
|                                                                                                   |
|  2. การสร้างกระบวนทัศน์การแปลใหม่ (New Paradigm in Translation Studies):                          |
|     - เสนอทฤษฎี "วรรณกรรมพืชอิงอาศัย" (Epiphytic Literatures) ที่ปฏิเสธการแทนที่แบบภาษาเดียว       |
|     - อธิบายการดำรงอยู่ร่วมกันของสองภาษาในตัวบทเดียวกันอย่างมีสุนทรียภาพ                          |
|                                                                                                   |
|  3. การปฏิวัติวงวรรณคดีศึกษาอยุธยาและอุษาคเนย์ (Revolutionizing Southeast Asian Literary History): |
|     - ยกระดับ "วรรณคดีคำหลวง" และ "ขนบสำราย/นิสสัย" สู่การเป็นตัวบททวิลักษณ์ชั้นสูง                 |
|     - พิสูจน์ภูมิปัญญาของกวีโบราณในการตีความหลักธรรมผ่านฉันทลักษณ์ประณีตศิลป์                     |
|                                                                                                   |
|  4. การผสานระหว่างบรรพชีวินวิทยาเอกสารตัวเขียนกับเทคโนโลยีดิจิทัล (Philology & Digital Humanities):|
|     - วางรากฐานการทำความเข้าใจคัมภีร์ใบลานหลายภาษา (Polyglot Codices)                            |
|     - เชื่อมโยงการอนุรักษ์เอกสารโบราณ (BDRC KMHP) เข้ากับการประมวลผลภาพดิจิทัล (DIA Benchmarking)   |
+---------------------------------------------------------------------------------------------------+
```

งานวิจัยของ ดร. เทรนต์ วอล์กเกอร์ จึงมิได้เป็นเพียงการศึกษาเอกสารโบราณที่ตายแล้วในหอสมุด แต่เป็นการกอบกู้ **"ประวัติศาสตร์ภูมิปัญญาที่มีชีวิต"** ของบรรพชนชาวอุษาคเนย์ แสดงให้เห็นอัจฉริยภาพของภูมิปัญญาท้องถิ่นในการแปลงเปลี่ยนถ้อยคำแห่งความหลุดพ้นในภาษาคลาสสิก ให้กลายเป็นวรรณศิลป์ เสียงสวด และวิถีปฏิบัติที่หล่อเลี้ยงจิตวิญญาณของผู้คนมานานหลายศตวรรษ
