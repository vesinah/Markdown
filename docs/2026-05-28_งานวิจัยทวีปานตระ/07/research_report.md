# รายงานสรุปผลการวิจัยทางอักษรศาสตร์และคัมภีร์พุทธศาสนา: สุวรรณภูมิ สุวรรณทวีป และสุวรรณปุระ

รายงานสรุปนี้เป็นดัชนีนำทางและประมวลภาพรวมการสืบค้นข้อมูลเชิงประจักษ์ในฐานข้อมูลคัมภีร์และพจนานุกรมประวัติศาสตร์อินเดียโบราณ เกี่ยวกับดินแดนและนครทองคำ 3 แห่ง โดยได้จัดแยกรายงานผลการวิจัยฉบับเต็มออกเป็นไฟล์เฉพาะสำหรับแต่ละคำค้นเรียบร้อยแล้ว ดังรายละเอียดด้านล่างนี้:

## 3. ข้อสังเกตทางอักษรศาสตร์และประวัติศาสตร์

* **ความแตกต่างในการประยุกต์ใช้คำ**:
  * วรรณกรรมบาลีเน้นประยุกต์ใช้คำว่า **"สุวณฺณภูมิ"** แทบทั้งหมด เพื่อสะท้อนเรื่องราวของเกาะและแผ่นดินแสวงโชคทางตะวันออก
  * วรรณกรรมสันสกฤตมีการใช้แยกกันเด่นชัด โดยนำคำว่า **"สุวรรณภูมิ"** มาใช้พรรณนาการค้าในเชิงการผจญภัยคู่กับนกยักษ์ และระบุพิกัดทิศตะวันออกเฉียงเหนือในตารางทางดาราศาสตร์ ขณะที่ใช้ **"สุวรรณทวีป"** ชี้พิกัดของเกาะที่เป็นอู่อารยธรรมฮินดู-พุทธ (เช่น ในสกันทปุราณะ และพจนานุกรมที่อ้างอิงถึงกถาสริตสาครและกมลศิลา)
  * คำว่า **"สุวรรณปุระ"** มิได้รับการยอมรับว่าเป็นที่ตั้งทางภูมิศาสตร์จริงในแวดวงพจนานุกรมดั้งเดิม แต่นิยามไว้ตรงกันว่าเป็นนครในตำนานเทพนิยายวรรณคดี (Mythical City) ที่ปรากฏในนวนิยายรักโรแมนติกโบราณ

* **เอกสารรายงานผลการวิจัยวิเคราะห์เชิงลึกแยกตามแต่ละคำค้น**:
  * ท่านสามารถคลิกลิงก์ด้านบนเพื่อตรวจสอบรายละเอียดของประโยคแวดล้อม **3-1-3** ตัวแปลบาลีสลายสนธิแยกสมาส การถอดสะกดสันสกฤตตามอักขรวิธี IAST ตลอดจนพยานหลักฐานประจักษ์พยานดิจิทัล (Live Search Verification Logs) ของแต่ละส่วนได้อย่างครอบคลุมครับ
