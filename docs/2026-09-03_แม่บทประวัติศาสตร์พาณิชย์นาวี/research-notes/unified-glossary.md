# อภิธานศัพท์แม่บทประวัติศาสตร์พาณิชย์นาวีและรัฐโบราณ (Unified Maritime History Glossary)

> **โครงการแม่บท:** `output/2026-09-03_แม่บทประวัติศาสตร์พาณิชย์นาวี`  
> **มาตรฐาน:** ระบบปริวรรตอักษร IAST สำหรับภาษาสันสกฤต และระบบทับศัพท์ประวัติศาสตร์

| ศัพท์ทางวิชาการ | ภาษาเดิม | คำอ่าน/รูปเขียนเดิม | นิยามและความสำคัญเชิงประวัติศาสตร์พาณิชย์นาวี |
|:---|:---:|:---|:---|
| **Thalassocracy** | กรีก | *thalassokratia* | รัฐสมุทรธิปไตย มหาอำนาจที่มีอำนาจควบคุมเส้นทางและเครือข่ายการค้าทางทะเล เช่น ศรีวิชัย |
| **Port-Polity** | อังกฤษ | *port-polity* | รัฐเมืองท่า รัฐโบราณที่เศรษฐกิจและการเมืองตั้งอยู่บนฐานการค้าแลกเปลี่ยนสินค้านานาชาติ |
| **Monsoon Winds** | อาหรับ/อังกฤษ | *mausim / monsoon* | ลมมรสุม ลมตะวันตกเฉียงใต้และตะวันออกเฉียงเหนือที่กำหนดจังหวะการเดินเรือในมหาสมุทรอินเดีย |
| **Dvīpāntara** | สันสกฤต | *dvīpāntara* | ทวีปานตระ ดินแดนโพ้นทะเลหรือหมู่เกาะข้ามสมุทร รากศัพท์ของคำว่า "นูซันตารา" (Nusantara) |
| **Pasisir** | ชวา/มลายู | *pasisir* | ชายฝั่งทะเล วัฒนธรรมเมืองท่าชายฝั่งของชวาตอนเหนือที่เปิดรับอิสลามและการค้าสากล |
| **Shahbandar** | เปอร์เซีย | *shāhbandar* | ชาห์บันดาร์ เจ้าท่า ข้าราชการผู้ควบคุมการค้า การจัดเก็บภาษี และการดูแลพ่อค้าต่างชาติ |
| **Entrepot** | ฝรั่งเศส | *entrepôt* | เมืองท่าศูนย์กลางการถ่ายลำสินค้า จุดพักและกระจายสินค้าโดยไม่ต้องเสียภาษีนำเข้าซ้ำซ้อน |
| **VOC** | ดัตช์ | *Vereenigde Oostindische Compagnie* | บริษัทอินเดียตะวันออกของเนเธอร์แลนด์ บรรษัทข้ามชาติแรกของโลกที่มีกองทัพและอำนาจผูกขาดการค้า |
| **Tribute System** | อังกฤษ/จีน | *Chaogong / 朝貢* | ระบบบรรณาการจิ้มก้อง ความสัมพันธ์ทางการทูตและการค้าเสรีจำแลงระหว่างราชสำนักจีนกับรัฐอุษาคเนย์ |
| **Jawi / Pegon** | มลายู/ชวา | *jāwī / pégon* | อักษรยาวีและเปกอน ระบบอักษรดัดแปลงจากอักษรอาหรับเพื่อใช้เขียนภาษามลายูและภาษาชวา |
