# บทที่ 3: การวิเคราะห์ฉันทลักษณ์บาลีตามคัมภีร์วุตโตทัยและการสแกนมาตรา
## Metrical Scansion and Prosodic Analysis of the Jinapañjara according to the Vuttodaya

---

### 3.1 บทนำ: ระบบฉันทลักษณ์บาลีและคัมภีร์วุตโตทัยของพระสังฆรักขิตเถระ

การวิเคราะห์ฉันทลักษณ์ (Prosodic and Metrical Analysis) ถือเป็นเครื่องมือชี้ขาดทางนิรุกติศาสตร์ (Philological Criterion) ที่มีความสำคัญสูงสุดในการตรวจชำระตัวบทบาลีโบราณ ดังที่ **K. R. Norman** ได้เน้นย้ำใน *Pali Philology and Textual Criticism* (JPTS XII, 1988/1991) ว่า "ความคลาดเคลื่อนทางฉันทลักษณ์คือร่องรอยที่ชัดเจนที่สุดของการดัดแปลงตัวบทโดยอาลักษณ์ (Scribal intervention)" และเป็นเกณฑ์ในการจำแนกชั้นของวรรณกรรมบาลีระหว่างยุคพระไตรปิฎกดั้งเดิมกับยุคกลาง[^1]

ในประวัติศาสตร์วรรณคดีบาลี คัมภีร์ **วุตโตทัย (*Vuttodaya* - "บ่อเกิดแห่งฉันท์")** รจนาโดย **พระสังฆรักขิตมหาเถระ (Saṅgharakkhita Thera)** ในยุคปฏิรูปสงฆ์โปลอนนารุวะ (ปลายศตวรรษที่ 12) ถือเป็นตำราฉันทศาสตร์ภาษาบาลีเล่มแรกและเล่มมาตรฐานที่สุดของพุทธศาสนาเถรวาท พระสังฆรักขิตะได้นำเอากฎเกณฑ์ฉันท์สันสกฤตจากคัมภีร์ *Vṛttaratnākara* ของ Kedārabhaṭṭa มาจัดระเบียบและประยุกต์เข้ากับระบบสัทศาสตร์ของภาษาบาลี เพื่อเป็นคู่มือมาตรฐานให้แก่พระสงฆ์สายมาคธีบริสุทธิ์ (*Suddhamāgadhikā*)[^2]

ตามคัมภีร์วุตโตทัย ระบบฉันท์บาลีจำแนกออกเป็น 2 ประเภทใหญ่:
1. **มัตตาฉันท์ (Moraic / Mātrā Metres):** ฉันท์ที่กำหนดจังหวะด้วยจำนวน "มาตรา" (Morae) โดยสระสั้น/เสียงเบา (ลหุ $\smile$) มีค่าเท่ากับ 1 มาตรา และสระยาว/เสียงหนัก (ครุ $-$, สระทีฆะ หรือสระที่มีพยัญชนะสังโยค/นิคหิตตามหลัง) มีค่าเท่ากับ 2 มาตรา
2. **วรรณฉันท์ (Syllabic / Akkhara Metres):** ฉันท์ที่กำหนดด้วยจำนวน "พยางค์" และตำแหน่งการเรียงตัวของครุ-ลหุตามระบบ **"คณะฉันท์ 8 คณะ" (Eight Gaṇas)** ได้แก่:
   - **ม-คณะ (Ma):** $---$ (ครุล้วน)
   - **น-คณะ (Na):** $\smile\smile\smile$ (ลหุล้วน)
   - **ภ-คณะ (Bha):** $-\smile\smile$ (ครุต้น)
   - **ย-คณะ (Ya):** $\smile--$ (ลหุต้น)
   - **ช-คณะ (Ja):** $\smile-\smile$ (ครูกลาง)
   - **ร-คณะ (Ra):** $-\smile-$ (ลหุกลาง)
   - **ส-คณะ (Sa):** $\smile\smile-$ (ครุท้าย)
   - **ต-คณะ (Ta):** $--\smile$ (ลหุท้าย)[^3]

### 3.2 ฉันท์ปัถยาวัตร (Pathyāvaktra / Anuṣṭubh) ในพระคาถาชินบัญชร

ตัวบทแกนกลาง 14 คาถาของพระคาถาชินบัญชรทั้งหมด แต่งด้วย **"ฉันท์ปัถยาวัตร" (Pathyāvaktra)** ซึ่งเป็นฉันท์วรรณพฤติ 8 พยางค์ต่อบาท (4 บาท = 32 พยางค์ต่อ 1 คาถา) จัดอยู่ในตระกูล **อนุษฏุภ (Anuṣṭubh / Śloka / วัตตฉันท์)**

ตามกฎของคัมภีร์วุตโตทัย (บทที่ 2 คาถาที่ 1–4) ฉันท์ปัถยาวัตรมีข้อบังคับทางฉันทลักษณ์อย่างเข้มงวดดังนี้:
1. **โครงสร้างทั่วไป (General Rule):** พยางค์ที่ 1 และ 8 ในแต่ละบาทเป็นพยางค์ไม่บังคับ (Anceps: $	imes$), พยางค์ที่ 2, 3, 4 มีความยืดหยุ่นสูง แต่ **พยางค์ที่ 5–7 ต้องรักษาลีลาจังหวะเฉพาะ**
2. **ข้อบังคับบาทคู่ (Even Pādas: บาท b และ d):** จังหวะลงท้าย (Cadence) ของพยางค์ที่ 5–7 **ต้องเป็น ช-คณะ ($\smile - \smile$) เสมอ** ตามสูตร:
   	ext{บาทคู่ (b, d)}: \quad 	imes \quad 	imes \quad 	imes \quad 	imes \quad \smile \quad - \quad \smile \quad 	imes
3. **ข้อบังคับบาทคี่ (Odd Pādas: บาท a และ c):** จังหวะลงท้ายของพยางค์ที่ 5–7 ในบาทคี่ ต้องไม่เป็น น-คณะ ($\smile\smile\smile$) และไม่เป็น ช-คณะ ($\smile-\smile$) ในปัถยาวัตรมาตรฐาน จะลงท้ายด้วย **ร-คณะ ($-\smile-$)** หรือ **ย-คณะ ($\smile--$)** หรือรูปแบบ **วิปุลา (Vipulā)** ทั้ง 6 ชนิด[^4]

`
[ผังฉันทลักษณ์ปัถยาวัตร / Pathyāvaktra Diagram]
บาท a (คี่): [ 1: x ] [ 2: x ] [ 3: x ] [ 4: x ]  |  [ 5: - ] [ 6: v ] [ 7: - ] [ 8: x ]  (ร-คณะ)
บาท b (คู่): [ 1: x ] [ 2: x ] [ 3: x ] [ 4: x ]  |  [ 5: v ] [ 6: - ] [ 7: v ] [ 8: x ]  (ช-คณะ)
บาท c (คี่): [ 1: x ] [ 2: x ] [ 3: x ] [ 4: x ]  |  [ 5: - ] [ 6: v ] [ 7: - ] [ 8: x ]  (ร-คณะ)
บาท d (คู่): [ 1: x ] [ 2: x ] [ 3: x ] [ 4: x ]  |  [ 5: v ] [ 6: - ] [ 7: v ] [ 8: x ]  (ช-คณะ)
`

### 3.3 การสแกนมาตราและครุ-ลหุ รายคาถา (Detailed Metrical Scansion of Selected Verses)

#### คาถาที่ 1: การสอบทานปาฐะและการยืดเสียงสระ (Vowel Lengthening / Dīghīkaraṇa)

- **ตัวบทฉบับสยาม ({15}$):**
  	ext{1a: } 	ext{Ja - yā - sa - nā - ga - tā - bud - dhā} \quad (--- \smile - --) \quad [8 	ext{ พยางค์}]
  	ext{1b: } 	ext{jet - vā - mā - raṁ - sa - vā - ha - naṁ} \quad (-- - - \smile - \smile -) \quad [8 	ext{ พยางค์ - ช-คณะ } \smile-\smile-]
  	ext{1c: } 	ext{Ca - tu - sac - cā - sa - bhaṁ - ra - saṁ} \quad (\smile \smile - - \smile - \smile -) \quad [8 	ext{ พยางค์}]
  	ext{1d: } 	ext{ye - pi - viṁ - su - na - rā - sa - bhā} \quad (- \smile - \smile \smile - \smile -) \quad [8 	ext{ พยางค์ - ช-คณะ } \smile-\smile-]

- **ข้อวิจารณ์ทางฉันทลักษณ์:**
  - ในบาท 1a ฉบับสยามใช้ Jayāsanāgatā ซึ่งสระ ā ตัวที่สาม (-nā-) ได้รับการยืดเสียงยาว (Dīghīkaraṇa) เพื่อให้เป็นพยางค์ครุ เมื่อเทียบกับฉบับสิงหล ({22}$) และล้านนา ({28}$) ที่ใช้ Jayāsanagatā (สระสั้น -na-) ซึ่งถูกต้องตามหลักไวยากรณ์บาลีดั้งเดิมมากกว่า การยืดเสียงในฉบับสยามสะท้อนถึงการปรับแต่งของอาลักษณ์เพื่อเน้นจังหวะสวดสาธยายทำนองสวดไทย
  - ในบาท 1b จังหวะลงท้าย sa-vā-ha-naṁ ($\smile - \smile -$) ตรงตามข้อบังคับ ช-คณะ ของบาทคู่อย่างสมบูรณ์แบบ เช่นเดียวกับบาท 1d 
a-rā-sa-bhā ($\smile - \smile -$)

#### คาถาที่ 3: สรีระมณฑลและสัมพันธภาพทางไวยากรณ์

- **ตัวบทบาลี:**
  	ext{3a: } 	ext{Si - ras - mi - pa - tiṭ - ṭhi - to - may - haṁ} \quad (\smile - \smile \smile - \smile - - -) \quad [9/8 	ext{ พยางค์ - Resolution}]
  	ext{3b: } 	ext{bud - dho - dham - mo - dvi - lo - ca - ne} \quad (- - - - \smile - \smile -) \quad [8 	ext{ พยางค์ - ช-คณะ } \smile-\smile-]
  	ext{3c: } 	ext{Saṅ - gho - pa - tiṭ - ṭhi - to - may - haṁ} \quad (- - \smile - \smile - - -) \quad [8 	ext{ พยางค์}]
  	ext{3d: } 	ext{u - re - sab - ba - gu - ṇā - ka - ro} \quad (\smile - - \smile \smile - \smile -) \quad [8 	ext{ พยางค์ - ช-คณะ } \smile-\smile-]

- **ข้อวิจารณ์ทางฉันทลักษณ์:**
  - ในบาท 3a คำว่า Sirasmi ออกเสียงพยางค์สั้นเชื่อมโยง หรือในฉบับสิงหลใช้ Sirasmiṁ te ทำให้จำนวนพยางค์ลงตัวที่ 8 พยางค์พอดี
  - บาท 3b dvi-lo-ca-ne ($\smile - \smile -$) และ 3d gu-ṇā-ka-ro ($\smile - \smile -$) รักษาจังหวะ ช-คณะ ในบาทคู่อย่างเคร่งครัด

#### คาถาที่ 8: ปมปัญหาพระนามพระเถระและการแก้ไขของอาลักษณ์ (Textual Emendation)

- **ฉบับสิงหล/ล้านนา/พม่า ({22}, L_{28}, B_{14}$):**
  	ext{8c: } 	ext{U - pā - lī - Nan - da - Sī - va - lī} \quad (\smile - - - \smile - \smile -) \quad [8 	ext{ พยางค์ - Pathyā cadence}]
- **ฉบับสยาม ({15}$):**
  	ext{8c: } 	ext{U - pā - lī - Sī - va - lī - thi - rā} \quad (\smile - - - \smile - \smile -) \quad [8 	ext{ พยางค์}]

- **ข้อวิจารณ์เชิงประจักษ์:**
  - ในฉบับดั้งเดิมระบุพระนามพระเถระ 5 องค์ที่สถิตบริเวณหน้าผาก ได้แก่ (1) ปุณณะ (2) องคุลิมาล (3) อุบาลี (4) นันทะ (5) สีวลี ซึ่งเข้าคู่คำว่า Therā pañca ime jātā (พระเถระทั้ง 5 รูปนี้) ในบาท 8d ได้อย่างสมบูรณ์
  - ฉบับสยามได้ตัดพระนาม "พระนันทะ" ออก แล้วเติมคำว่า 	hirā (ผู้มั่นคง) เข้ามาแทน ซึ่งแม้จะรักษาจำนวน 8 พยางค์และฉันทลักษณ์ปัถยาวัตรไว้ได้ แต่ทำให้เกิดความลักลั่นในความหมาย เพราะมีพระเถระปรากฏเพียง 4 รูป แต่บาทถัดไปกลับระบุว่า "พระเถระทั้ง 5" หลักฐานทางฉันทลักษณ์นี้พิสูจน์ชัดเจนว่า ปาฐะเดิมของชินบัญชรคือ Upālī Nanda-Sīvalī[^5]

### 3.4 ฉันทลักษณ์บทสรุปท้ายในฉบับสยามและฉบับสิงหล (Stanzas 15–22 Metrical Shift)

ความแตกต่างทางฉันทลักษณ์ที่โดดเด่นที่สุดเกิดขึ้นในส่วนท้ายของคัมภีร์ ซึ่งแสดงให้เห็นถึงความชำนาญทางกวีนิพนธ์ที่ต่างทิศทางกัน:

#### ก. คาถาที่ 15 ฉบับสยาม ({15}$): Deficient Triṣṭubh (11 พยางค์)
- **ตัวบท:**
  	ext{15a: } 	ext{Ic - ce - va - man - to - su - gut - to - su - rak - kho} \quad (- - \smile - - \smile - - \smile - -) \quad [11 	ext{ พยางค์}]
  	ext{15b: } 	ext{Ji - nā - nu - bhā - ve - na - ji - tu - pad - da - vo} \quad (\smile - \smile - - \smile \smile - - \smile -) \quad [11 	ext{ พยางค์}]
  	ext{15c: } 	ext{Dham - mā - nu - bhā - ve - na - ji - tā - ri - saṅ - gho} \quad (- - \smile - - \smile \smile - \smile - -) \quad [11 	ext{ พยางค์}]
  	ext{15d: } 	ext{Saṅ - ghā - nu - bhā - ve - na - ji - tan - ta - rā - yo} \quad (- - \smile - - \smile \smile - \smile - -) \quad [11 	ext{ พยางค์}]
  	ext{15e: } 	ext{Sad - dham - mā - nu - bhā - vā - pa - li - to - ca - rā - mi - ji - na - pañ - ja - re - ti} \quad [20 	ext{ พยางค์ - สรุปความ}]
- ฉันทลักษณ์เปลี่ยนจาก 8 พยางค์ปัถยาวัตร มาเป็น **ตริษฏุภ (Triṣṭubh 11 พยางค์)** ที่มีลักษณะเฉพาะเพื่อเน้นการลงจังหวะสัจกิริยา 4 ชั้น (พุทธานุภาพ, ธรรมานุภาพ, สังฆานุภาพ, สัทธรรมานุภาพ)

#### ข. คาถาที่ 15–22 ฉบับสิงหล ({22}$): กวีนิพนธ์ฉันท์วิจิตร (Kāvya Metres)
- **คาถาที่ 15:** แต่งด้วย **Upajāti (อุเปนทรวิเชียร ผสม อินทรวิเชียร 11 พยางค์)**
- **คาถาที่ 16–20:** แต่งด้วย **Vaṃśastha (วังสัฏฐฉันท์ 12 พยางค์)** และ **Vasantatilakā (วสันตดิลกฉันท์ 14 พยางค์)**
- **คาถาที่ 21:** แต่งด้วย **Sragdharā (สรัคธราฉันท์ 21 พยางค์)** ซึ่งเป็นฉันท์ขนาดยาวพิเศษที่บังคับคณะฉันท์ ม-ร-ภ-น-ย-ย-ย ($--- \quad -\smile- \quad -\smile\smile \quad \smile\smile\smile \quad \smile-- \quad \smile-- \quad \smile--$)
- การใช้ฉันท์ขนาดยาวและวิจิตรในฉบับสิงหล สะท้อนให้เห็นว่า พระสงฆ์ในศรีลังกาได้นำเอาความรู้จากคัมภีร์วุตโตทัยและสุโพธาลังการ มาพัฒนาพระคาถาชินบัญชรให้กลายเป็น "วรรณคดีพุทธกวีชั้นครู" (Masterpiece of Devotional Kāvya) ประจำเกาะลังกา[^6]
