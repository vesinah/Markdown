# บทที่ ๕: การวิเคราะห์ฉันทลักษณ์

## Chapter V: Metrical Analysis According to the Vuttodaya Rules

**แหล่งกฎฉันท์:** กฎทั้งหมดอ้างจาก *Vuttodaya* ฉบับแปลอังกฤษที่ ancient-buddhist-texts.net (ตรวจจากบทที่ ๑, ๓, ๕ ของคัมภีร์) — อนุษุป/ศโลกะ: ๘ พยางค์ต่อบาท; พยางค์ที่ ๒–๓ ห้ามลหุ-ลหุ; **บาทคี่**: พยางค์ ๕–๗ เป็น ย-คณะ (⏑−−) หรือวิปุลา (น = ⏑⏑⏑, ภ = −⏑⏑, ม = −−−, ร = −⏑−); **บาทคู่ (ปัถยา)**: พยางค์ ๕–๗ เป็น ช-คณะ (⏑−⏑); พยางค์สุดท้ายของบาทเป็นครุเสมอ ครุ = สระยาว/สระสั้นที่มีคลัสเตอร์พยัญชนะตามหลัง/สระที่มีนิคคหิต/พยางค์ท้ายบาท

### ๕.๑ ผลสแกนคาถาที่ ๑ (ฉบับฐานไทย T1; รูปละติน)

| บาท | ข้อความ | ลวดลายครุ–ลหุ | พยางค์ ๕–๗ | ประเมิน |
|---|---|---|---|---|
| ๑ข | *jayāsanāgatā buddhā* | ⏑−⏑−⏑−−− | ⏑−− (ย) | **ปัถยาบาทคี่ สมบูรณ์** |
| ๑ค | *jetvā māraṃ savāhanaṃ* | −−−−⏑−⏑− | ⏑−⏑ (ช) | **ปัถยาบาทคู่ สมบูรณ์** |
| ๑ง | *catusaccāsabhaṃ rasaṃ* | ⏑−−−⏑−⏑− | ⏑−⏑ (ช) | บาทคี่ที่ใช้ช-คณะ = รูป *javipulā* (แบบยุคคัมภีร์ ยังถือว่าถูกต้อง) |
| ๑จ | *ye piviṃsu narāsabhā* | ⏑⏑−⏑⏑−⏑− | ⏑−⏑ (ช) | **ปัถยาบาทคู่ สมบูรณ์** |

**ข้อค้นพบสำคัญข้อที่ ๑:** ปาฐะ *savāhanaṃ* ของสายไทย — ที่คติทั่วไปมักถูกประนามว่า "ผิดฉันท์ ควรแก้เป็น *sasenakaṃ*" — จริง ๆ แล้ว**ลงตัวปัถยาสมบูรณ์** (ช-คณะที่ ๕–๗: *sa-vā-ha* = ⏑−⏑) ทั้งนี้ปาฐะแยกของฉบับลังกา *savāhinī* (sa-vā-hi = ⏑−⏑) และพม่า *savāsanaṃ* (sa-vā-sa = ⏑−⏑) ก็ลงตัวเช่นกัน — ทั้งสามตระกูลปาฐะเข้ารูปช-คณะพร้อมกัน ข้ออ้างเรื่อง *sasenakaṃ* ที่เคยใช้เป็นเหตุผลของการแก้ฉันท์ ไม่มีหลักฐานใดรองรับ (ดูบันทึกการแก้ไข ข้อ ๑) และหากมีจริง การสแกน *sa-se-na* = ⏑⏑⏑ ในบาทคู่กลับไม่เข้ากับกฎบาทคู่ของวุตโตทัย

**ข้อค้นพบสำคัญข้อที่ ๒:** คาถา ๑ ทั้งสี่บาทเข้ารูปอนุษุปแบบปัถยา (ย-ช-ช(วิปุลา)-ช) — เป็นหลักฐานว่าผู้ประพันธ์ (หรือผู้ชำระ) ตั้งใจทำงานบนกฎฉันท์อย่างเข้มงวดอย่างน้อยในคาถาเปิด

### ๕.๓ แนวโน้มรวมของฉันท์ในคาถา ๔–๑๔

การสแกนคาถาที่เหลือแสดงแนวโน้มสองชั้นที่สอดคล้องกันทุกฉบับพยาน:

1. **โครงอนุษุปแข็งแรง**: คาถา ๔, ๕, ๖, ๗, ๘, ๑๐, ๑๑, ๑๔ ล้วนเป็นบาท ๘ พยางค์ และบาทคู่ส่วนใหญ่จบ ช-คณะที่ ๕–๗ (เช่น *sārīputto ca dakkhiṇe* = ที่ ๕–๗ ⏑−⏑ ✓; *matthake te* รวมเข้ารูปได้; *ujh* ฯลฯ) หรือจบด้วยวิปุลารูปยุคคัมภีร์
2. **จุดเบี่ยงที่พบซ้ำ**: (ก) พยางค์ ๒–๓ ลหุ-ลหุ ในบาทแบบ *sabbe patiṭṭhitā*, *matthake te* — สองบาทนี้เป็นลายเซ็นของฉบับทั้งหมด ไม่ใช่ความเสียหายของสายใดสายหนึ่ง; (ข) บาท ๓ค ที่ลง ภ-คณะบนบาทคู่; (ค) บาท ๑๒จ ตามที่สแกนด้านล่าง

### ๕.๔ คาถาที่ ๑๒ — ปมฉันท์ที่แท้จริงของคัมภีร์

| บาท | ปาฐะฐานไทย | ลวดลาย | ประเมิน |
|---|---|---|---|
| ๑๒ข | *jinā nānā-vara-saṃyuttā* (รูปที่แพร่ในตัวพิมพ์สมัยใหม่/D; OCR ของ T1 สอดคล้อง) | ji-nā-nā-nā-va-ra-saṃ-yut-tā = **๙ พยางค์** | **บาทเกินฉันท์ (hypermetric)** |
| | (การถอดของ T4) *jinā nāvara-saṃyuttā* "JINANA VARASAMYUTTA" | = **๘ พยางค์** (เป็นไปได้ว่า OCR ตัดพยางค์ รอตรวจตัวพิมพ์) | ลงตัวได้ |
| | (ท่าเทียบที่ T1 บันทึกไว้) *jināṇā-bala-saṃyutte* | ji-nā-ṇā-ba-la-saṃ-yut-te = **๘** | ลงตัวฉันท์ |
| ๑๒ค | *sattappākāra-laṅkatā* | sat-tap-pā-kā-ra-laṃ-ka-tā = ๘ | ช-คณะที่ ๕–๗ ✓ ปัถยาบาทคู่ |
| ๑๒ง | *vāta-pittādi-sañjātā* | vā-ta-pit-tā-di-sañ-jā-tā = ๘ | ย-คณะ ✓ ปัถยาบาทคี่ |
| ๑๒จ | *bāhirajjhat-upaddavā* | bā-hi-raj-jhat-tu-pad-da-vā = ๘ | ช-คณะ ✓ |
| ๑๒ฉ | *asesā vinayaṃ yantu* | ⏑⏑−⏑⏑−−− | ย-คณะ ✓ (๒–๓ = ⏑⏑ เบี่ยง) |
| ๑๒ช | *ananta-jina-tejasā* | ⏑−⏑⏑⏑−⏑− | ช-คณะ ✓ |

**ข้อสรุปเชิงฉันท์ (ผลการวิเคราะห์ของรายงานนี้):** ปมฉันท์ที่แท้จริงของชินบัญชรไม่ใช่คาถา ๑ แต่เป็น**บาทแรกของคาถา ๑๒** — ปาฐะฐานของสายไทย *jinā nānā-vara-saṃyuttā* เป็นบาทเกิน ๙ พยางค์ ขณะที่ท่าเทียบซึ่ง T1 บันทึกไว้ในเชิงอรรถเอง (*jināṇā-bala-saṃyutte*) และซึ่งเป็นปาฐะหลักของสายลังกา–พม่า–ล้านนา (T5–T8) ลงตัว ๘ พยางค์พอดี ทั้งนี้ห้ามสรุปข้ามไปว่า "ฉบับลังกาเก่ากว่า" — เพราะการแก้เกินฉันท์อาจเกิดในทั้งสองทาง (ผู้แต่งเดิมอาจตั้งใจอ่านยืด *jinā ṇāṇāva-ra-* เป็นสองพยางค์พิเศษ) งานที่จะตัดสินเด็ดขาดคือการเทียบลานมือโดยตรงตามที่ Kieffer-Pülz (2018) กระทำ

### ๕.๕ บทจบ (คาถา ๑๕ ของสำนวนไทย)

บทจบไม่ใช่อนุษุป — เป็นชุดวรรคยาว ๕ วรรค:

| วรรค | ข้อความ | จำนวนพยางค์ |
|---|---|---|
| ๑ | *iccevamanto sugutto surakkho* | ๑๑ |
| ๒ | *jinānubhāvena jitupaddavo* | ๑๑ |
| ๓ | *dhammānubhāvena jitārisaṅgho* | ๑๑ |
| ๔ | *saṅghānubhāvena jitantarāyo* | ๑๑ |
| ๕ | *saddhammānubhāvāpalito carāmi jinapañjare-ti* | ๑๙ (วรรคประกอบยาว) |

วรรค ๒–๔ มีลวดลาย ๑๑ พยางค์แบบ *−−⏑−⏑⏑⏑−⏑−−* (จาก *dham-mā-nu-bhā-ve-na-ji-tā-ri-saṅ-gho*) ซึ่งเป็นตระกูลเดียวกับ **ติฏฐุพ-ชะคะตี (๑๑ พยางค์)** ที่ CPD บันทึกว่าเป็นฉันท์ของคาถา ๑๕–๒๐ ในฉบับลังกา (S1) — นี่คือหลักฐานเชิงฉันท์ที่สอดคล้องกันอีกชิ้นว่า "บทจบของสำนวนไทย" กับ "บล็อกคาถาท้ายของฉบับลังกา" อยู่ในสายพันธุ์เดียวกัน

### ๕.๖ กรอบเปรียบเทียบฉันท์ระหว่างสาย (ตามบันทึก CPD และตรวจด้วยตนเอง)

| ส่วน | ฉบับลังกา S1 (CPD) | สำนวนไทย (จากการสแกน) |
|---|---|---|
| เปิด–แก่น | คาถา ๑–๑๔: ศโลกะ (อนุษุป) | คาถา ๑–๑๔: อนุษุป (ปัถยา + วิปุลายุคคัมภีร์) |
| ท้าย | คาถา ๑๕–๒๐: ติฏฐุพ-ชะคะตี; ๒๑–๒๓: วัสสันตติละกา | บทจบ ๕ วรรค ๑๑ พยางค์ (ตระกูลติฏฐุพ-ชะคะตี) + สำนวน "ฉบับเต็ม" มีบทอวยพรเพิ่ม |

ข้อจำกัดที่ต้องประกาศ: คาถา ๑๕–๒๓ ของฉบับลังกายังไม่มีตัวบทเต็มที่ถอดได้ในโครงการนี้ การประเมินฉันท์ส่วนนั้นจึงพึ่งบันทึกของ CPD อย่างเดียว
