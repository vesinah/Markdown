# บทที่ ๖: การแปลรายคาถา

## Chapter VI: Verse-by-Verse Translation

คำแปลต่อไปนี้ทำจาก**ตัวบทฐานที่ร่างชำระในบทที่ ๗ ใช้** (ฐาน T1 ฉบับวัดระฆัง เรียบร้อยเป็นรูปละตินตามอักขรวิธีบาลีปัจจุบัน) แต่ละคาถาประกอบด้วย (ก) บาลีละติน (ข) คำแปลไทยเชิงประมวลความ (ค) หมายเหตุศัพท์/ปาฐะเมื่อจำเป็น สำหรับคำแปลอังกฤษเทียบ งานที่ตรวจแล้วมีสองชุด: คำแปลของผู้วิจัยใน Maneenil (2006, หน้า ๒๐–๒๒) และถอดเสียงพร้อมคำแปลของ Thanissaro Bhikkhu (*A Chanting Guide*) ซึ่งใช้เป็นหมุดเทียบได้

---

**คาถา ๑**
> *Jayāsanāgatā buddhā, jetvā māraṃ savāhanaṃ / catusaccāsabhaṃ rasaṃ, ye piviṃsu narāsabhā.*

"พระพุทธเจ้าทั้งหลายผู้ประทับถึงพูนชัยสำนัก ชนะมารพร้อมด้วยเสนาและพาหนะ ผู้หิวโหย (พวกท่าน) ได้ดื่มรสชาติอันประเสริฐยิ่งแห่งสัจจะทั้งสี่ — พวกท่านผู้เป็นใหญ่ในมนุษย์ทั้งหลาย"

หมายเหตุ: (๑) *savāhanaṃ* แปล "พร้อมพาหนะ" ตามศัพท์ ท่าเทียบลังกา *savāhinī* ("พร้อมเสนาหญิง"? ไม่ตรง) และพม่า *savāsanaṃ* ("พร้อมอาสนะ") ยังไม่มีใครตัดสินได้โดยพจนานุกรมเดียว (๒) *catusaccāsabhaṃ* — ท่า *mataṃ* ของสายลังกา–พม่า แปลได้ราบรื่นกว่า ("รสอมตะแห่งสัจจะสี่") ซึ่งเป็นทางที่ Maneenil เองเลือกแปลเช่นนั้น ("the immortal taste of the Four Noble Truths") แม้ตัวบทฐานของเขาใช้ *sabhaṃ*

**คาถา ๒**
> *Taṇhaṅkarādayo buddhā, aṭṭhavīsati nāyakā / sabbe patiṭṭhitā mayhaṃ, matthake te munissarā.*

"พระตัณหังกรเจ้าเป็นต้น คือพระนายกทั้ง ๒๘ พระองค์ ขอพระมุนีผู้เป็นเจ้าเหล่านั้น จงประดิษฐานทุกพระองค์ ณ กระหม่อมแห่งข้าพเจ้า"

**คาถา ๓**
> *Sīse patiṭṭhito mayhaṃ, buddho dhammo dvilocane / saṅgho patiṭṭhito mayhaṃ, ure sabbaguṇākaro.*

"ขอพระพุทธเจ้าจงประดิษฐานบนศีรษะของข้าพเจ้า พระธรรมจงสถิตในดวงตาทั้งสอง ขอพระสงฆ์จงประดิษฐานในอก ผู้เป็นที่เกิดแห่งคุณทั้งปวง"

หมายเหตุ: บาทที่สองอ่าน *buddho [dhammo] dvilocane* ตามฐาน — ท่า *ทุวิโรจเน* ที่ฉบับบันทึกไว้ให้แก้เป็น "พระธรรมจงเป็นดวงตาทั้งสอง" ซึ่งไวยากรณ์เรียบร้อยกว่า (ดูบทที่ ๔ §๔.๓)

**คาถา ๔**
> *Hadaye me Anuruddho, Sārīputto ca dakkhiṇe / Koṇḍañño piṭṭhi-bhāgasmim, Moggallāno ca vāmake.*

"ขอพระอนุรุทโธจงสถิตในหทัย พระสารีบุตรทางขวา พระโกณฑัญญะข้างหลัง พระโมคคัลลานะทางซ้าย"

**คาถา ๕**
> *Dakkhiṇe savane mayhaṃ, āsuṃ Ānanda-Rāhulā / Kassapo ca Mahānāmo, ubh'āsuṃ vāma-sotake.*

"ที่หูขวาของข้าพเจ้า ขอพระอานนท์กับพระราหุลจงสถิต พระกัสสปะกับพระมหานามะ ขอทั้งสองจงสถิตที่หูซ้าย" — ร่างชำระเลือกพหูพจน์ *Rāhulā* ให้พ้องกับ *āsuṃ* (ท่าที่บันทึกใน T5–T7 และสอดคล้องไวยากรณ์; ร่างแรกเคยใช้ *Rāhulo* เอกพจน์ซึ่งขัดพจน์)

**คาถา ๖**
> *Kesanto piṭṭhi-bhāgasmim, Suriyo va pabhaṅkaro / Nisinno sirisampanno, Sobhito muni-puṅgavo.*

"ขอพระโสภิตเถระผู้ประทับ ณ ปลายเกศาทางหลัง จงเป็นดังพระอาทิตย์ผู้แผ่รัศมี ผู้ประทับด้วยความเป็นสิริมงคล ผู้เป็นหัวหน้าแห่งมุนี" — ฐาน *kesanto* (ตาม T1) พร้อมบันทึกท่า *kesante* ของสายลังกา–พม่า–น่าน

**คาถา ๗**
> *Kumārakassapo thero, mahesī citta-vādako / so mayhaṃ vadane niccaṃ, patiṭṭhāsi guṇākaro.*

"พระกุมารกัสสปะเถระ ผู้มีวาจาวิจิตรประณีต ขอท่านจงประดิษฐานนิรันดร ณ ปากของข้าพเจ้า ผู้เป็นที่เกิดแห่งคุณ" — ท่า *nāmo* ของสายลังกา–พม่า–น่าน ให้ความหมาย "ผู้มีชื่อ" ซึ่งเชื่อมกับนามเรียก "กุมารกัสสปะ" ในคัมภีร์ได้ แต่ร่างนี้คงฐาน *thero*

**คาถา ๘**
> *Puṇṇo Aṅgulimālo ca, Upāli Nanda-Sīvalī / therā pañca ime jātā, nalāṭe tilakā mama.*

"พระปุณณะ พระอังคุลิมาละ พระอุปาลี พระนันทะ พระสีวลี — พระเถระทั้งห้าองค์นี้ จงเป็นดังพิมพ์เจิมบนหน้าผากของข้าพเจ้า" — ท่าพม่า–น่าน *ime pañca mahātherā* ("อรหันต์ทั้งห้านี้") เปลี่ยนคำกริยาเป็นนาม ไม่เปลี่ยนสาระ

**คาถา ๙** (ฐาน T1 หกบาท; สายลังกา–น่านตัดบาทกลางเป็นสี่บาท)
> *Sesāsīti mahātherā, vijitā jinasāvakā / etesīti mahātherā, jitavanto jinorasā / jalantā sīlatejena, aṅgam-aṅgesu saṇṭhitā.*

"พระมหาเถระอีกแปดสิบองค์ที่เหลือ ผู้ชนะ คือศิษย์แห่งชินเจ้า พระเถระเหล่านี้ผู้ชนะ เป็นหัวใจของชินเจ้า จงส่องประกายด้วยเดชแห่งศีล สถิตในอวัยวะน้อยใหญ่ของข้าพเจ้า"

**คาถา ๑๐**
> *Ratanaṃ purato āsi, dakkhiṇe Mettasuttakaṃ / Dhajaggaṃ pacchato āsi, vāme Aṅgulimālakaṃ.*

"ขอรตนสูตรจงอยู่เบื้องหน้า เมตตสูตรทางขวา ธชัคคสูตรเบื้องหลัง อังคุลิมาลสูตรทางซ้าย" (คำกริยา *āsi* อดีตกาลเชิงพิธีกรรม "เป็นมาแล้ว")

**คาถา ๑๑**
> *Khandha-Mora-parittañ ca, Āṭānāṭiyasuttakaṃ / Ākāse chadanaṃ āsi, sesā pākāra-saṇṭhitā.*

"ขันธปริตร โมรปริตร และอาฏานาฏิยสูตร จงเป็นหลังคาคลุมเบื้องบน ส่วนที่เหลือจงประดิษฐานเป็นกำแพงล้อมรอบ"

**คาถา ๑๒**
> *Jinā nānā-vara-saṃyuttā [jināṇā-bala-saṃyutte], sattappākāra-laṅkatā / vātapittādi-sañjātā, bāhirajjhat-upaddavā.*

"พระชินเจ้าทั้งหลายผู้ร่วมด้วยคุณวิเศษนานังประการ [ท่าเทียบ: ผู้ร่วมด้วยพละญาณแห่งชินเจ้า] จงประดับเป็นกำแพงเจ็ดชั้น — อุปัทวภายในภายนอก ที่เกิดจากลมและดีเป็นต้น" — วงเล็บคือท่าเทียบที่ร่างชำระบันทึกไว้ (ดูบทที่ ๕ §๕.๔ เรื่องบาทเกินฉันท์)

**คาถา ๑๓**
> *Asesā vinayaṃ yantu, ananta-jina-tejasā / vasato me sakiccena, sadā Sambuddha-pañjare.*

"ขอให้ (อุปัทว์) เหล่านั้นหายไปสิ้นเชิงด้วยเดชแห่งชินเจ้าผู้ไร้ปลาย ขณะข้าพเจ้าประกอบกิจของตน ขอให้ข้าพเจ้าอยู่ในกรงแห่งสัมพุทธเจ้าเสมอ"

**คาถา ๑๔**
> *Jinapañjara-majjhamhi, viharantaṃ mahītale / sadā pālentu maṃ sabbe, te mahāpurisāsabhā.*

"บรรดามหาบุรุษผู้เป็นอาสภะทั้งหลาย ผู้ดำรงอยู่กลางกรงชินบัญชรบนผืนแผ่นดินนี้ ขอทั้งหลายจงคุ้มครองข้าพเจ้าสืบไป"

**บทจบ (คาถา ๑๕ สำนวนไทย)**
> *Iccevamanto sugutto surakkho / jinānubhāvena jitupaddavo / dhammānubhāvena jitārisaṅgho / saṅghānubhāvena jitantarāyo / saddhammānubhāvāpalito carāmi jinapañjare-ti.*

"เพราะเหตุนี้ อาตมาเป็นผู้รอดพ้น ผู้ถูกรักษาไว้ดี ผู้เป็นที่คุ้มครองมั่นคง — ด้วยพุทธานุภาพ ชนะอุปัทวทุกข์ ด้วยธรรมานุภาพ ชนะศัตรู ด้วยสังฆานุภาพ ชนะอันตรายทั้งปวง อาตมาผู้ได้รับคุ้มครองด้วยสัทธัมมานุภาพ พากเพียรเดินอยู่ในชินบัญชรเทอะ"

**ภาคผนวก การแปลบทอวยพรท้ายฉบับลังกา (T5) — แปลเชิงคาดการณ์**

บทปิดของ T5 ที่ปรากฏในสำนวนไทย "ฉบับเต็ม" ด้วย:

> *sabbāva maṅgala-m upaddava-dunī-nimittaṃ† / sabbīti-roga-graha-dosa-masesa-nindā† / sabbantarāya-bhaya-dussupinn'ākāsā† / buddhānubhāva-pavarena payyantu†*

"ขอโรคาพาธ อุปัทวะ โทษทางราศี ความอัปมงคล อันตราย ความกลัว และความฝันร้ายทั้งปวง จงมลายไปด้วยพุทธานุภาพอันประเสริฐ" (วนซ้ำด้วยธรรมานุภาพและสังฆานุภาพ) — † หมายเหตุ: พยางค์บางตำแหน่งถอดจาก OCR ไม่แน่นอน คำแปลนี้จึงให้เฉพาะสาระรวม ไม่ใช่การแปลคำต่อคำ

### ๖.๑ หมายเหตุเชิงวิจารณ์การแปล

1. **ตัวบทนี้ไม่มีธรรมะ** — Maneenil (หน้า ๒๔) บันทึกความสังเกตของผู้เชี่ยวชาญไว้ตรงกันว่า ชินบัญชรต่างจากบทสวดทั่วไปที่ไม่มีคำสอนแต่เป็น "การเรียกชื่อศักดิ์สิทธิ์ทั้งปวงมาสถิตบนร่าง" คำแปลจึงต้องรักษาคำกริยาเชิงพิธีกรรม (*patiṭṭhito / āsi / pālentu*) มากกว่าค้นหาแก่นธรรม
2. **ความคลุมเครือเชิงไวยากรณ์เชิงพิธี**: คาถา ๑๒–๑๔ ผันบุรุษสลับ (ชินเจ้าเป็นประธาน, ผู้สวดเป็นกรรมตัว *maṃ/me/mayhaṃ*, และ *viharantaṃ* อาการกรรก) — คำแปลไทยที่แพร่หลายมักยุบความสลับนี้จนหาย เราคงไว้เพื่อให้ผู้อ่านเห็นโครง "มณฑลบนร่าง" ที่แท้
3. **การแปลจากปาฐะผิด**: ตัวอย่างที่ชัดคือคำแปล "เจ็ดชั้นกำแพง" ของ *sattappākāra-laṅkatā* — ถ้าใช้ท่า *dhammā-pākāra-laṅkate* ของสายลังกา จะแปลได้เป็น "ประดับด้วยกำแพงธรรม" คำแปลจึงผูกกับการตัดสินปาฐะเสมอ ไม่ควรแปลจากฉบับเดียวโดยไม่ประกาศ
