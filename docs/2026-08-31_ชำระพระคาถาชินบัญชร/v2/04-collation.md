# บทที่ ๔: ตารางสอบเทียบปาฐะรายคาถา (Collation)

## Chapter IV: Synoptic Collation of Verified Witnesses

**ข้อสังเกตเบื้องต้น:** สิบเอ็ดในสิบห้าคาถา (คาถา ๒, ๔, ๕*, ๑๐ และช่วงกลางของคาถาอื่น) มีปาฐะร่วมกันทุกฉบับที่ตรวจ ความแตกต่างที่แท้จริงกระจุกอยู่ที่คาถา ๑, ๓, ๖, ๗, ๘, ๙, ๑๑ (คำสุดท้าย), ๑๒–๑๓ และบทจบ ตารางนี้บันทึกเฉพาะพยากรณ์ที่มีความต่าง หรือที่สำคัญเชิงวิเคราะห์ († = ถอดจาก OCR อ่านไม่แน่นอน)

### ๔.๖ คาถาที่ ๑๐–๑๑

คาถา ๑๐ ปาฐะร่วมทุกฉบับ (*Ratanaṃ purato āsi… Vāme Aṅgulimālakaṃ*) คาถา ๑๑ ต่างเฉพาะคำสุดท้าย:

| ท้ายบาท ๑๑ง | ฉบับ |
|---|---|
| *ปาการสัณฐิตา* (pākāra-saṇṭhitā) | T1 (หลัก), T2, T3 |
| *ปาการสัญญุตา* (pākāra-saññutā) | บันทึกปาฐะ T1; T5 ลังกา |
| *ปาการลังกุตา* (pākāra-laṅkatā) | บันทึกปาฐะ T1; T6, T7 พม่า |

**วิเคราะห์:** สามพยากรณ์ในตำแหน่งเดียว (*saṇṭhitā* "ประดิษฐาน" / *saññutā* "ชำนาญ"† / *laṅkatā* "ประดับ") — เป็นหลักฐานชัดว่าคำปลายบาทในบาทคู่ถูกแทนเพื่อลงฉันท์ และสายพม่า–ลังกาใช้คำเดียวกับบาท ๑๒ง ของสายไทย (*-laṅkatā/-laṅkate*)

### ๔.๗ คาถาที่ ๑๒–๑๓: คู่ปาฐะใหญ่ของคัมภีร์

**สายไทย (T1 ฐาน; T2, T3, D สอดคล้อง; T4 ให้รูป ๘ พยางค์ — ดูหมายเหตุ):**
> *jinā nānā-vara-saṃyuttā, sattappākāra-laṅkatā*
> *vāta-pittādi-sañjātā, bāhirajjhat-upaddavā*
> *asesā vinayaṃ yantu, ananta-jina-tejasā*
> *vasato me sakiccena, sadā Sambuddha-pañjare*

บันทึกปาฐะใน T1: บาทแรกมี "บางฉบับเป็น *ชินานพลส์ยุตุเต* บ้าง *ชินาณาขลส์ยุตุเต* บ้าง" (สองท่า = *jināṇā-bala-* / *jināṇā-khila-*†); บาทที่สอง "บางฉบับเป็น *ธมุมปาการลังกุเต* บ้าง"; บาทวาต "บางฉบับเป็น *วาตปิตตาทิ* บ้าง" (แสดงว่าตัวหลัก T1 อ่านอื่น — OCR ให้ *วาตมิตุตาทิ*†); ปัจฉิมบาท "บางฉบับเป็น *จตุกิจุเจน* บ้าง *สกุกจุเอน* บ้าง"

**สายลังกา–พม่า–ล้านนา (T5, T6, T7†, T8):**
> *jināṇā-khila/bala-saṃyutte†, dhammā-pākāra-laṅkate*
> *vasato me catukiccena†, sadā Sambuddha-pañjare*

**หมายเหตุสำคัญเรื่องจำนวนพยางค์ของบาทนี้:** การถอดของ T4 ในวิทยานิพนธ์ให้ "JINANA VARASAMYUTTA" (= ๘ พยางค์) ขณะที่รูปที่แพร่ในตัวพิมพ์สมัยใหม่และรูปที่ D พิมพ์ให้ *jinā nānā-vara-saṃyuttā* (๙ พยางค์; OCR ของ T1 สอดคล้องกับแบบเกิน) — ประเด็นนี้วิเคราะห์ต่อในบทที่ ๕ §๕.๔

**วิเคราะห์ (ข้อสันนิษฐานของผู้เรียบเรียง):** ลูกโซ่อักษรบาลี "ชินา นานาวระ..." ของสายไทย กับ "ชินาณา พละ/ขละ..." ของสายลังกา-พม่า อ่านได้สองทางจากสายอักษรเดียวกันโดยการตัดต่อคำต่างกัน — สายไทยแบ่งเป็น *jinā + nānā-vara-* ("พระชินเจ้า ร่วมด้วยคุณวิเศษนานังประการ") ส่วนสายลังกาแบ่งเป็น *jināṇā + bala/khila* ("พละ/แท่นแห่งชินญาณ") ทั้งสองทางให้ความหมายรับกันในบริบท จึงเป็นตัวอย่างคลาสสิกของ "ข้อกำหนดขอบเขตคำ" (word-division crux) ในตัวเขียนไม่มีวรรค ส่วน *vāta-pittādi* (ลม–ดี) ตรงกันทุกฉบับที่ตรวจ (แถม: ปาฐะ *วาตาตปาทิ* ที่บางสำนวนแพร่ ไม่พบในหลักฐานใดที่ตรวจแล้ว)

**ความต่างเชิงโครงสร้าง:** หนังสือสวดไทยสมัยใหม่จัดกลุ่มนี้เป็น ๓ คาถา (๑๒, ๑๓, ๑๔) บาทละสองวรรค ขณะที่ T4/D จัดเป็น ๒ หน่วยบาทละสามวรรค — เป็นความต่างเชิงการจัดพิมพ์ (editorial lineation) ไม่ใช่ความต่างปาฐะ แต่ทำให้ "จำนวนคาถา" ระหว่างสำนวนไทยไม่ตรงกันแม้ตัวอักษรเดียวกัน

### ๔.๘ คาถาที่ ๑๔ และบทจบ

คาถา ๑๔: ต่างเฉพาะสันธานกลาง: *majjhaṭṭhaṃ* (บันทึก "บางฉบับเป็น ชินปญชรมชุฒฎู†") / *majjhamhi* (D; T1 OCR *มชุณมุหิ†*) / *majjhenāhi* (T4 *MAJJHENAHI*) — ทั้งหมดเป็นการวิ่งเตลิดเพื่อเติมพยางค์ให้ครบ ๘

บทจบ ๕ วรรค (*iccevamanto… jinapañjare-ti*) ปาฐะร่วม T1, T2, T4, T5 โดยมีประเด็นสองข้อ:

| ประเด็น | พยากรณ์ | ฉบับ |
|---|---|---|
| วรรคที่ ๓ | *dhammānubhāvena **jitārisaṅgho*** | T1, T2, T4, D |
| | *…**hatārisaṅgho*** | บันทึกปาฐะ T5 ลังกา ("ฉบับนี้เป็น ซิตาริสงโค บ้าง หตาริสงุโฆ บ้าง") |
| การต่อบท | จบที่ *…carāmi jinapañjare-ti* | T1, T2, T4, T5 |
| | ต่อด้วยบทอวยพร "สัพพาวมังคละ…" สามคู่ (พุทธานุภาว-ธมมานุภาว-สังฆานุภาว *pavarena payyantu†*) และบทปิดเพิ่มเติมอีกชุด | T5 (ลังกา), และปรากฏในสำนวนไทย "ฉบับเต็ม" ที่แพร่ในหนังสือสวดมนต์ |

ข้อสังเกตสำคัญ: **บท "สัพพาวมังคละมุปัททะวะ…" ที่คนไทยรู้จักใน "ฉบับเต็ม" ตรงกับบทปิดของฉบับลังกา (T5)** — นี่เป็นหลักฐานการรับตัวบทโดยตรงระหว่างสายลังกากับสำนวนไทยยาว และควรเป็นตัวชี้วัดหลักในการศึกษาเพิ่ม
