# บันทึกผลการสืบค้นและวิเคราะห์เชิงลึก: Loop E-07

## หัวข้อ: 07: การสอบเทียบตัวบทคาถาที่ 1–3 (บทนำ การประดิษฐานพระพุทธเจ้า 28 พระองค์ และพระรัตนตรัย)**

### 5 ประเด็นวิจัยและการวิเคราะห์หลักฐานเชิงประจักษ์:
    1. ปาฐะ *Jayāsanāgatā buddhā* ($S_{15}, B_{14}$) vs *Jayāsanagatā vīrā* ($C_{22}$) vs *Jayāsanagato santo* ($L_{28}$)
    2. การเลือกใช้ศัพท์ *savāhanaṁ* (พร้อมพาหนะ) ในสยาม เทียบกับ *sasenakaṁ* (พร้อมเสนามาร) ในลังกา ล้านนา พม่า
    3. ความหมายเชิงเทววิทยาของ *Catusaccāsabhaṁ* vs *Catusaccāmataṁ* vs *Catusaccābhataṁ*
    4. การสถิตของพระพุทธเจ้า 28 พระองค์เหนือกระหม่อม (*matthake te munissarā*) ในทุกสำนวน
    5. ปาฐะสรรพนาม: *mayhaṁ/me* (คุ้มครองตนเอง) vs *te/tava/tuyhaṁ* (คุ้มครองผู้อื่นในพิธีปริตรสิงหล)
