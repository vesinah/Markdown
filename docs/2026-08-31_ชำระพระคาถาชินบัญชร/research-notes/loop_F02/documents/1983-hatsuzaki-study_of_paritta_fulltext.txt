ス リラ ン カ に 伝 承 のPARITTA
初 崎 正 純
Paritta (Sinhala; Pirit) は, ス リ ラ ン カ で 尤 も 普 及 せ る 仏 教 徒 の 儀 式 に し て,
そ れ が 世 俗 的, 宗 教 的 な も の, ま た 施 主 が 誰 で あ れ, そ の 必 要 に 応 じ て, い か
な る処 で も執 行 され る。 そ れ は ス リ ラ ン カ 放 送 公 社 (SriLanka Broadcasting Corp-
oration) が, 毎 朝 五 時 か ら 十 五 分 間, Paritta を 諦 経 し て, 一 日の プ ロ グ ラ ム を
開 始 す る点 か ら も, こ れ が 国 民 生 活 に い か に 滲 透 し て お る か が 推 量 で き る。
これ は Pali 経 典 よ り抄 出 し た 略 式 句 の 諦 詠 で あ り, 主 に 仏 教 僧 が 担 当 す る。
こ の Paritta は ‘Catubhamvarapali (Sinhala; Piruvanapotvahanse) に 納 め て あ る。
そ し て, こ れ は ビル マ, タ イ 等 の 上 座 仏 教 (Theravada Buddhist) 国 に も 普 及 し
て お る が, 今 は ス リ ラ ン カ に保 持 せ る 伝 統 的 Paritta の 研 究 に 限 る。
Pali 経 典 に 見 る Paritta は, Sanskrit の ‘Pari+√tra (譲る)’から来 た も の で,
Pali で は, そ の 接 尾 辞 が 略 し て あ る。 ま た Paritta の 儀 式 的 含 意 も 次 第 に 変 化 進
展 し た が, そ れ は 経 典 並 に 註 釈 文 献 よ り理 解 で き る。 か の Vattakajataka1)にお
け る 偶 順 は, こ れ が 尤 も 初 期 の 使 用 法 と し て挙 げ ら れ る。 そ こ で は, 現 在 分 詞
(participle) の Parittayanta が, 自 身 (attanam) を ‘護る’文 字 通 りの 意 味 で あ る。
Matapitaro......mam ekakam pahaya attanam parittayanta palata.
そ し て, Paritta の 儀 式 的 な 含 意 は, Vinayapitaka2)にも見 ら れ る が, そ れ が
い か に 発 展 し て 来 た か は, 次 の 偶 頗 に よ り十 分 説 明 し得 る。
Antarayam pariharantam tayatiti parittam, parito va sabbupaddavato tayatiti parit-
tam, mahatejavantataya sarnantato sattanam bhayam upaddavam upasaggan ca tayati
rakkhatiti va parittam3).
Paritta は 危 険 を 遠 ざ け, 守 護, 平 和, ま た 招 福 を 目 的 と し た 守 護 の 儀 式 で あ る。
現 在, ス リ ラ ン カ で 依 用 の Paritta Text (Sinhala; Pirit-pota) は, Pali 経 典 の
各 部 分 か ら蒐 集 した 二 十 九 経 で 構 成 し て お る。 そ の 古 い 名 称 は ‘Catubhapavara-
pali (Cbp.) で, 本 来 の そ れ は, 経 第 二 十 二, Atanatiya-sutta で 締 め ら れ, 他 の
七 経 は 後 世 に付 加 し た。
こ こ に, ス リ ラ ン カ に 伝 承 の Paritta を 列 挙 し, そ の 出 典 並 に 内 容 に 関 し て 要
約 せ ば, 次 の 通 りで あ る。
