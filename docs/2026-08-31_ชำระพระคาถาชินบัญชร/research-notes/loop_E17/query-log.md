# บันทึกผลการสืบค้นและวิเคราะห์เชิงลึก: Loop E-17

## หัวข้อ: 17: การดัดแปลงสัทศาสตร์และเสียงเพื่อการขับสวด (Phonetic & Metrical License)**

### 5 ประเด็นวิจัยและการวิเคราะห์หลักฐานเชิงประจักษ์:
    1. การยืดเสียงสระสั้นเป็นสระยาว (Dīghīkaraṇa): เช่น *Jayāsanāgatā* ในฉบับสยาม
    2. การย่นย่อสระยาวเป็นสระสั้น (Rassīkaraṇa) เพื่อรักษามาตราฉันท์
    3. การละนิคหิตและการแทรกสระลอย (Svarabhakti / Epenthesis)
    4. สัทลักษณะของการสวดทำนองสรภัญญะไทย vs ทำนองสิงหลคัมภีรภาพ
    5. กฎสัทศาสตร์บาลีตามคัมภีร์สัททนีติและพาลปวัตนะที่ปรากฏในชินบัญชร
