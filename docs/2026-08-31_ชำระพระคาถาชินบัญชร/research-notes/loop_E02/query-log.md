# บันทึกผลการสืบค้นและวิเคราะห์เชิงลึก: Loop E-02

## หัวข้อ: 02: การแพร่กระจายสู่ล้านนาและวรรณกรรม "ไจยะเบ็งชร"**

### 5 ประเด็นวิจัยและการวิเคราะห์หลักฐานเชิงประจักษ์:
    1. เส้นทางการถ่ายทอดคัมภีร์บาลีสายลังกาวงศ์สู่เชียงใหม่ในรัชสมัยพระเจ้าติโลกราชและพญายอดเชียงราย
    2. การวิเคราะห์เอกสารใบลานวัดสูงเม่น จ.แพร่ และประวัติการรวบรวมคัมภีร์ของครูบากัญจนอรัญญวาสีมหาเถร
    3. บทบาทของคัมภีร์ไจยะเบ็งชรในฐานะมงคลสูตรคุ้มครองเมืองและกองทัพล้านนาในเอกสารตำนานเมืองเหนือ
    4. ความเชื่อมโยงระหว่างสำนวนล้านนา 28 คาถา ($L_{28}$) กับคัมภีร์ *Jinakālamālīpakaranaṃ* ของพระรัตนปัญญาเถระ
    5. อิทธิพลของวรรณกรรมนิสสยะ (Nissaya) ล้านนาต่อการอธิบายศัพท์บาลีในบทสวดมนต์ตามงานศึกษาของ Justin McDaniel (2002)
