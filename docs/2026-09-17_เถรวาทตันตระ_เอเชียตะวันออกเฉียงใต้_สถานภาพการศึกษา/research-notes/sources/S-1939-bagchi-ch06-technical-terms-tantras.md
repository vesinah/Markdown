  - **หัวข้อย่อย 1.3 ธารณี มนตรา และอำนาจศักดิ์สิทธิ์แห่งภาษา:**

  - **หัวข้อย่อย 2.1 สรีรวิทยาเร้นลับ: จักระ (Cakras), นาทิ (Nāḍīs) และลมปราณ (Prāṇa):**

  - **หัวข้อย่อย 2.2 สัญญะทางเพศ พลังสตรี และการรวมคู่ตรงข้าม (Prajñā & Upāya / Yuganaddha):**

  - **หัวข้อย่อย 2.3 เทวตาโยคะ (Deity Yoga) และการเนรมิตพุทธสภาวะภายในกาย:**

  - **หัวข้อย่อย 4.6 ปฏิสัมพันธ์ระหว่างพุทธตันตระกับฮินดูตันตระ:**  
    *การนำไปใช้:* นำการสังเคราะห์ของบาคจิที่พิสูจน์ว่า ศัพท์เทคนิคทางตันตระทั้งในพุทธและฮินดู (เช่น ลลนา/อิทา, รสนา/ปิงคลา, อวธูตี/สุษุมณา, ศวะ, กาลี, อาลี) เป็นมรดกทางปรัชญาและสรีรวิทยาที่พัฒนามาจากรากฐานพระเวทและอุปนิษัทร่วมกัน (pp. 71–73)

### ส่วนที่ 3: สรุปสาระสำคัญเชิงวิเคราะห์และจุดยืนทางวิชาการ (Executive Academic Analysis)

#### 3.1 ธรรมชาติของศัพท์สัญลักษณ์ในตันตรศาสตร์ (pp. 61–63)
ศาสตราจารย์ ดร. ประโพธ จันทระ บาคจี เปิดบทที่ 6 ด้วยการตอกย้ำความจริงอันหนักแน่นว่า แม้นักวิชาการบางท่านจะยังคงแคลงใจต่อการมีอยู่ของ 'ศัพท์เชิงสัญลักษณ์' (Symbolical Terms) ในคัมภีร์ตันตระ แต่หลักฐานทางวรรณกรรมทั้งฝ่ายพุทธและพราหมณ์-ฮินดูได้พิสูจน์อย่างกระจ่างชัดว่า ระบบสัญญะดังกล่าวมีตัวตนอยู่จริงและเป็นกลไกชี้ขาดในการถ่ายทอดธรรมชั้นสูง บาคจิได้เลือกกลุ่มคำสำคัญที่เป็นแก่นแกนที่สุดมาวิเคราะห์ ได้แก่:
1. **จันทระ (Candra) / ศศิน (Śaśin) / รวิวรรชิตะ (Ravivarjita)**
2. **สูรยะ (Sūrya) / รวิ (Ravi) / จันทรวรรชิตะ (Candravarjita)**
3. **กาลี (Kāli — พยัญชนะขึ้นต้นด้วยตัว ก)**
4. **อาลี (Āli — สระขึ้นต้นด้วยตัว อ)**

ในวรรณกรรม *จรรยาบท* (Caryāpadas) ของเหล่ามหาสิทธา เช่น ท่านกัณหปาทะ (Kāhnapāda), สรหปาทะ (Sarahapāda), และกุกกุรีปาทะ (Kukkurīpāda) พระอาจารย์เหล่านี้ได้ประพันธ์บทเพลงโทฮาที่กล่าวถึงการ 'ทำลายล้าง' หรือ 'หลอมรวม' ดวงอาทิตย์และดวงจันทร์เข้าด้วยกัน เพื่อให้สูญเสียธรรมชาติทวิภาวะเดิมและเข้าสู่สภาวะเอกภาพแห่งมหาสุข (Mahāsukha)

#### 3.2 กายวิภาคเร้นลับและการถอดรหัสคู่ตรงข้าม 2 สาย (pp. 63–67)
บาคจิได้สืบค้นคัมภีร์อรรถกถาภาษาสันสกฤตของจรรยาบท ควบคู่ไปกับคัมภีร์ *เหรุกตันตระ* (Heruka Tantra, Chap. V) และ *คุหยสมาชตันตระ* เพื่อแสดงให้เห็นว่า คำศัพท์คู่ตรงข้ามเหล่านี้ถูกนำมาใช้แทน **เครือข่ายกายวิภาคศักดิ์สิทธิ์ (Sacred Anatomy)** ภายในร่างกายของมนุษย์:
- **เส้นลลนา (Lalanā):** สถิตอยู่ด้านซ้าย วิ่งจากลำคอลงสู่สะดือ สัมพันธ์กับ ดวงจันทร์ (Candra), สระ (Āli), ความเย็น (Śīta), ปัญญา (Prajñā), หยดอสุจิสีขาว (Akṣobhya / Śukra), และการกลืนกินลมหายใจเข้า (Lana)
- **เส้นรสนา (Rasanā):** สถิตอยู่ด้านขวา สัมพันธ์กับ ดวงอาทิตย์ (Sūrya), พยัญชนะ (Kāli), ความร้อน (Uṣṇa), วิธีการ (Upāya), เลือดสีแดง (Rakta), และการพ่นลมหายใจออก (Carana)
- **เส้นอวธูตี (Avadhūtī):** สถิตอยู่ ณ แกนกลางลำตัว เปรียบเสมือนแม่น้ำที่ไหลอยู่กึ่งกลางระหว่างแม่น้ำคงคาและยมุนา ปราศจากการแบ่งแยกผู้รับรู้และสิ่งที่ถูกรับรู้ (Grāhya-grāhaka-varjitā) เป็นที่สถิตแห่งบรมสุขที่กลืนกินมโนทัศน์แห่งกาลเวลา

#### 3.3 ตารางแม่บทแห่งทวิภาวะตันตระ (The Great Binary Tantric Matrix) (pp. 68–70)
ในหน้า 69 บาคจิได้สังเคราะห์ข้อมูลจากคัมภีร์พุทธและพราหมณ์ จัดทำเป็น **ตารางจำแนกหมวดหมู่ศัพท์เทคนิค 2 ขั้วตรงข้ามอันเป็นอนุสาวรีย์ทางวิชาการ** ดังนี้:

| มิติ / คุณลักษณะ | ฝ่ายทักษิณา (ขวา / สุริยะ / ปิงคลา / กาลี) | ฝ่ายวามะ (ซ้าย / จันทระ / อิทา / อาลี) |
|:---|:---|:---|
| **เส้นนาทิ (Nāḍī)** | รสนา (Rasanā), ปิงคลา (Piṅgalā) | ลลนา (Lalanā), อิทา (Iḍā) |
| **ดาวนพเคราะห์ (Planet)** | สูรยะ (Sūrya), รวิ (Ravi), ภาณุ (Bhānu) | จันทระ (Candra), ศศิน (Śaśin), โสมะ (Soma) |
| **แม่น้ำศักดิ์สิทธิ์ (River)** | ยมุนา (Yamunā) | คงคา (Gaṅgā) |
| **อักขรวิทยา (Phonology)** | กาลี (Kāli / วยัญชนะ - พยัญชนะ) | อาลี (Āli / สวระ - สระ) |
| **ลมหายใจ (Breath)** | ปราณ (Prāṇa / หายใจออก / คมนะ) | อปาน (Apāna / หายใจเข้า / ลนะ) |
| **เวลา (Time)** | ทิวา (Divā / กลางวัน) | ราตรี (Rātrī / กลางคืน) |
| **ธาตุสรีระ (Body Element)** | รักตะ (Rakta / เลือด / อัคนี / ไฟ) | ศุกระ (Śukra / น้ำอสุจิ / โสมะ / น้ำ) |
| **หลักธรรม (Principle)** | อุปายะ (Upāya / กรุณา / พลังขับเคลื่อน) | ปรัชญา (Prajñā / ศูนยตา / ปัญญาญาณ) |
| **ญาณวิทยา (Epistemology)** | กราหยากาศ (Grāhyākāra / สิ่งที่ถูกรู้) | กราหกากาศ (Grāhakākāra / ผู้รู้) |
| **สภาวะจิต (Mind State)** | จิตตะ (Citta / ความคิดนึกปรุงแต่ง) | อจิตตะ (Acitta / สภาวะปราศจากจิตคิด) |
| **คุณะ (Guṇa)** | รชัส (Rajas / ความเคลื่อนไหว) | ตมัส (Tamas / ความมืดบอดสงบนิ่ง) |

#### 3.4 สรีรวิทยาแห่งกาลเวลา: การหยุดลมหายใจเพื่อดับกาลเวลาในกุมภกะ (pp. 70–71)
บาคจิได้อธิบายกลไกทางจิตสรีรวิทยาที่ลึกซึ้งยิ่งว่า มโนทัศน์เรื่อง 'เวลา' (กาล) ของมนุษย์ มิได้เป็นสิ่งนามธรรมภายนอก แต่เป็น **ผลผลิตเชิงอัตวิสัย (Subjective Construction)** ที่เกิดจากการเคลื่อนไหวของลมหายใจเข้า (กลางคืน/ดวงจันทร์) และลมหายใจออก (กลางวัน/ดวงอาทิตย์) ในร่างกาย:
- เมื่อลมหายใจเข้าและออกยังคงดำเนินไป มโนทัศน์เรื่องกลางวัน-กลางคืน อดีต-ปัจจุบัน-อนาคต และโลกภายนอก ย่อมเกิดขึ้นและผูกมัดจิตไว้ในสังสารวัฏ
- เป้าหมายสูงสุดของโยคีคือ **การหยุดการทำหน้าที่ของลมทั้งสองสายนี้** ด้วยการกักลมหายใจไว้ภายใน (กุมภกะ / Kumbhaka) นำพากระแสลมปราณทั้งหมดเข้าสู่ช่องแกนกลาง (อวธูตี หรือ สุษุมณา)
- คัมภีร์ *หฐโยคประทีปิกา* (IV. 17) ยืนยันว่า: *'สูรยาจันทรมเสา กาลัง ทิวารัตริวิภาคศะห์ / โภกตรี สุษุมณา กาลัสยะ ตเทตัท รหัสยัม'* (ดวงอาทิตย์และดวงจันทร์เป็นผู้กำหนดเวลาในรูปของกลางวันและกลางคืน แต่สุษุมณาเป็นผู้กลืนกินกาลเวลานั้นเสีย นี่คือความลับอันลึกซึ้ง)
- เมื่อเวลาถูกกลืนกิน มโนทัศน์เรื่องทวิภาวะย่อมดับสูญ โยคีย่อมบรรลุถึง **สมาธิอันบริบูรณ์ (Complete Samādhi)** และประจักษ์แจ้งในสภาวะอมตะ (Nirvāṇa / Mahāsukha)

#### 3.5 รากเหง้าทางนิรุกติศาสตร์จากคัมภีร์พระเวทและอุปนิษัท (pp. 71–73)
ในส่วนท้ายของบท บาคจิได้แสดงความเหนือชั้นทางวิชาการ ด้วยการเชื่อมโยงระบบรหัสยศาสตร์ตันตระกลับไปยัง **คัมภีร์พระเวทและอุปนิษัทโบราณ** เพื่อพิสูจน์ว่า ตันตระมิได้เกิดขึ้นมาอย่างไร้รากเหง้า:
1. **ฉันโทยะอุปนิษัท (Chāndogya Upaniṣad, I. 3. 3):** บันทึกว่า ลมหายใจที่เชื่อมระหว่างปราณกับอปาน คือ 'วยานะ' (Vyāna) ซึ่งทำหน้าที่เป็น 'วาจา' (Vāc) เพราะมนุษย์ย่อมหยุดหายใจเข้าและออกในขณะที่เปล่งเสียงพูด
2. **ไอตรเอยารัณยกะ (Aitareya Āraṇyaka, II. 2. 4):** บันทึกข้อความโบราณว่า: *'วยัญชไนศจ มัตตรัง ราตรัย อัปโนติ สวไรร์ อหานิ'* (มนุษย์ย่อมเข้าถึงกลางคืนผ่านทางพยัญชนะ [วยัญชนะ] และเข้าถึงกลางวันผ่านทางสระ [สวระ])
3. **การคลี่คลายสู่กาลีและอาลี:** ข้อความในพระเวทนี้เองที่เป็นต้นกำเนิดของคำว่า **กาลี (พยัญชนะ / กลางคืน)** และ **อาลี (สระ / กลางวัน)** ในคัมภีร์ตันตระ ซึ่งถูกแปรสภาพจากปรัชญาภาษาศาสตร์แห่งพระเวท ให้กลายเป็นเทคโนโลยีทางสรีรวิทยาโยคะในการควบคุมจิตและการสร้างพุทธสรีระภายในกาย

### ส่วนที่ 4: สารบัญข้อค้นพบเชิงลึกแยกตามมิติตันตริกศึกษา (Thematic Findings with Exact Pages)

#### 1. มิติทางประวัติศาสตร์ สายธาร และบริบทสังคม-การเมือง (Historical Trajectory & Social Context)
- **การสืบทอดสายวิชาจากพระเวทสู่ตันตระ (pp. 71–73):** บาคจิพิสูจน์ว่าระบบสัญลักษณ์ตันตระ (สุริยะ, จันทระ, กาลี, อาลี, พินทุ) มิใช่สิ่งประดิษฐ์ขึ้นใหม่ตามอำเภอใจ แต่เป็นการคลี่คลายตัวอย่างเป็นระบบของปรัชญาภาษาและลมปราณที่มีรากเหง้าในวรรณกรรมพราหมณะและอารัณยกะ
- **บทบาทของสำนักมหาสิทธาในการปฏิวัติภาษา (pp. 61–64):** เหล่ามหาสิทธา 84 ท่าน ได้นำเอาสัจธรรมระดับคัมภีร์มาแต่งเป็นบทเพลงพื้นบ้าน (จรรยาบทและโทฮา) โดยใช้ภาษาสัญลักษณ์เพื่อหลบหลีกการตรวจสอบจากอำนาจรัฐและสังคมจารีต

#### 2. มิติทางคัมภีร์ เอกสารตัวเขียน และภาษาศาสตร์ (Philological & Manuscript Evidence)
- **การสอบทานตัวบทข้ามสายจารีต (pp. 64–68):** บาคจิสอบทานบทเพลงจรรยาบทของกัณหปาทะและดมพิปาทะ เข้ากับอรรถกถาสันสกฤตของมุนิทัตตะ และคัมภีร์หฐโยคะของสวาตมารามะ เพื่อสถาปนาความหมายที่ตรงกันของศัพท์เทคนิค
- **อักขรวิทยา กาลี-อาลี (pp. 71–73):** การวิเคราะห์เชิงสัทศาสตร์ที่ระบุว่า กาลี (พยัญชนะ) คือรูปสำแดงของเสียงที่มีความก้องน้อยกว่า ส่วน อาลี (สระ) คือรูปสำแดงของเสียงที่มีความก้องกังวานและได้ยินชัดเจนกว่า สอดรับกับกำเนิดจักรวาลทางเสียง (Śabda-brahman / Nāda)

#### 3. มิติทางสรีรวิทยาภายใน กายละเอียด และการจัดวางธาตุ (Internal/Subtle Body, Nāḍī, Cakra, Dhātu)
- **สรีรวิทยาของลมหายใจสองขั้ว (pp. 64–67):** ลมหายใจเข้า (Inspiration / Lana) ผ่านเส้นลลนา เชื่อมโยงกับธาตุน้ำและดวงจันทร์ ส่วนลมหายใจออก (Expiration / Carana) ผ่านเส้นรสนา เชื่อมโยงกับธาตุไฟและดวงอาทิตย์
- **การหลอมรวมพินทุสองภาค (pp. 68–69):** พินทุ (Bindu) มิใช่จุดเดี่ยว แต่ประกอบด้วย 2 องค์ประกอบ: ศุกระ (น้ำอสุจิ / มีธรรมชาติเป็นอัคนีหรือความร้อน) และ รักตะ (โลหิต / มีธรรมชาติเป็นโสมะหรือความเย็น) การรวมตัวของธาตุทั้งสองทำให้เกิดการปฏิสนธิทางจิตวิญญาณ

#### 4. มิติทางพิธีกรรม การถ่ายทอดสายวิชา และมนตรา-ยันตรา (Ritual, Initiation, Mantra, Yantra)
- **เทคนิคการสลับลมหายใจ (Prāṇāyāma) (pp. 67–68):** คัมภีร์หฐโยคประทีปิการะบุเทคนิคการสูดลมหายใจเข้าทางรูจมูกซ้าย (จันทระ) และพ่นออกทางรูจมูกขวา (สูรยะ) แล้วสลับกัน เพื่อปรับสมดุลธาตุในร่างกายก่อนเข้าสู่สมาธิขั้นสูง
- **การพายเรือข้ามแม่น้ำคงคา-ยมุนาในจิต (pp. 64–66):** บทเพลงของดมพิปาทะเปรียบการเจริญสมาธิเสมือนการพายเรืออยู่กึ่งกลางแม่น้ำสองสาย (คงคาและยมุนา) เพื่อมุ่งสู่ฝั่งแห่งมหาสุข ซึ่งเป็นภาพเปรียบเปรยของเส้นทางอวธูตี

#### 5. มิติทางพุทธปรัชญาและญาณวิทยา (Philosophical & Soteriological Dimensions)
- **การดับทวิภาวะแห่งผู้รู้และสิ่งที่ถูกรู้ (Grāhya-Grāhaka-Nirodha) (pp. 66–70):** เส้นอวธูตีคือตัวแทนของความว่างที่บริสุทธิ์จากโครงสร้างทวิภาวะ เมื่อจิตเข้าสู่อวธูตี สภาวะความเป็นประธาน (ผู้รู้) และกรรม (สิ่งที่ถูกรู้) ย่อมสลายตัว เข้าสู่ความหลุดพ้น
- **ปรัชญากาลวิทยา (Philosophy of Time) (pp. 70–71):** เวลาคือมายาภาพที่ถูกสร้างขึ้นโดยจังหวะการหายใจ การดับลมหายใจในสมาธิคือกุญแจดอกเดียวที่ไขไปสู่ความเป็นนิรันดร์

#### 6. มิติการเผชิญหน้ากับความทันสมัย การปฏิรูป หรือการเบียดขับ (Colonial Encounter, Modernist Reform, Margins)
- **การกอบกู้คุณค่าทางวิทยาศาสตร์ของโยคะตันตระ (pp. 61–73):** บาคจิแสดงให้เห็นว่า โยคะตันตระมิใช่ความงมงายหรือไสยศาสตร์ไร้เหตุผล แต่เป็นระบบ 'จิตสรีรวิทยาเชิงสังเกตการณ์' (Empirical Psycho-physiology) ที่มีทฤษฎีและขั้นตอนปฏิบัติที่แม่นยำ

#### 7. มิติการเปรียบเทียบข้ามวัฒนธรรม/ข้ามภูมิภาค (Comparative Perspectives: India, Sri Lanka, Southeast Asia)
- **ความสอดคล้องกับระบบอักขระและธาตุในโบรณกรรมฐาน (pp. 68–73):** ทฤษฎีกาลี-อาลี และการเดินลมปราณสุริยะ-จันทระในบทนี้ สอดรับอย่างน่าอัศจรรย์กับระบบ 'แม่ธาตุ' (นะ โม พุท ธา ยะ), การเดินธาตุไฟ-น้ำ-ลม-ดิน, และการเพ่งดวงแก้วในศูนย์กลางกายของคัมภีร์กรรมฐานโบราณในไทยและกัมพูชา

### ส่วนที่ 5: คลังข้อความอ้างอิงตรงและเชิงอรรถสำเร็จรูป (Verbatim Quotes & Footnote Bank)

*คลังข้อความอ้างอิงตรงจากตัวบทปฐมภูมิ Prabodh Chandra Bagchi (1939) Studies in the Tantras, Part I, Chapter VI: "Some Technical Terms of the Tantras" (pp. 61–73) สกัดตรงตามตัวสะกดจริง พร้อมคำแปลวิชาการและการวิเคราะห์เชิงอรรถ:*

#### 1. 1. การยืนยันการมีอยู่จริงของศัพท์สัญลักษณ์ในวรรณกรรมตันตระ (Chapter VI, p. 61)
> *"Though some scholars still entertain doubts as to the use of symbolical terms in the Tantras it is undeniable that such terms do exist in the Tantrik literature both Buddhist and Brahmanical. I propose here to discuss a group of such terms: Candrasurya... ravi and sasin... kali and ali."*

- **คำแปลวิชาการ:** "แม้ว่านักวิชาการบางท่านจะยังคงแคลงใจต่อการใช้คำศัพท์เชิงสัญลักษณ์ในคัมภีร์ตันตระ แต่เป็นสิ่งที่ไม่อาจปฏิเสธได้เลยว่า คำศัพท์เหล่านั้นมีตัวตนอยู่จริงในวรรณกรรมตันตระทั้งฝ่ายพุทธและฝ่ายพราหมณ์ ข้าพเจ้าขอเสนอ ณ ที่นี้ เพื่ออภิปรายถึงกลุ่มคำศัพท์ดังกล่าว ได้แก่: จันทรสูรยะ (ดวงจันทร์และดวงอาทิตย์)... รวิ และ ศศิน... กาลี และ อาลี"
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** บาคจิเปิดประเด็นสถาปนาข้อเท็จจริงทางวรรณคดีว่า ระบบสัญลักษณ์ในตันตระเป็นสิ่งที่มีระบบและเป็นสากลข้ามศาสนา
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Prabodh Chandra Bagchi, "Some Technical Terms of the Tantras," in Studies in the Tantras, Part I (Calcutta: University of Calcutta, 1939), 61.

#### 2. 2. จรรยาบทเพลงที่ 11 ของท่านกัณหปาทะ: การรวมตัวของสุริยะและจันทระ (Chapter VI, p. 61)
> *"The Caryapadas afford a good deal of evidence on the use of these terms: 1. Carya 11 (Kahnapa): kahnere ghara bhani matha uthiya / candasurya beni ghasa madalakarau padhia // 'The cottage of Kahna was broken and he rose up to the sky; having rubbed together the sun and the moon he made them into an earthen bowl.'"*

- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** การเปรียบเทียบการรวมขั้วตรงข้ามทางลมปราณเข้าเป็นภาชนะแห่งธรรมะเดี่ยวในสมาธิ
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 61.

#### 3. 3. จรรยาบทเพลงที่ 14 ของท่านธามปาทะ: การปิดกั้นสุริยะและจันทระ (Chapter VI, p. 62)
> *"Carya 14 (Dhamapada): beni pasera candasura sandhi bhandali / suja-lau sune thaharai nali // 'On both sides the sun and the moon have been bound fast together; the stalk of the gourd has been placed in the void.'"*

- **คำแปลวิชาการ:** "จรรยาบทเพลงที่ 14 (ธามปาทะ): 'ณ สองฟากฝั่ง ดวงอาทิตย์และดวงจันทร์ได้รับการผูกมัดตรึงแน่นเข้าด้วยกัน / ก้านของน้ำเต้าได้รับการสถาปนาไว้ในความว่าง (ศูนยตา) //'"

- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 62.

- **คำแปลวิชาการ:** "II. วามะ (ฝ่ายซ้าย) — ลลนา, อิทา, จันทระ, ศศิน, โสมะ, อปานะ (ลมหายใจเข้า), นิศามนะ (กลางคืน), อาลี, ศุกระ (น้ำอสุจิ), ปรัชญา, คงคา, ลนะ (การกลืนกินเข้า), ตมัส, นิวฤตติกิริยา, กราหกะ (ผู้รู้), อจิตตะ ฯลฯ"

#### 17. 17. ลมหายใจเข้าและออกในฐานะรากฐานแห่งมโนทัศน์เรื่องโลกภายนอก (Chapter VI, p. 70)
> *"The vital breath which is determined by the two functions of inspiration and expiration is the basis of life and on it, as the physiological life of the individual, depend many of his notions of the external worlds. His notion of time is absolutely dependent on it from a subjective point of view."*

- **คำแปลวิชาการ:** "ลมหายใจแห่งชีวิตซึ่งถูกกำหนดโดยการทำหน้าที่ 2 ประการของการหายใจเข้าและการหายใจออก คือรากฐานแห่งชีวิต และบนรากฐานนั้นเอง ในฐานะชีวิตทางสรีรวิทยาของปัจเจกบุคคล ย่อมเป็นที่พึ่งพาอาศัยของมโนทัศน์จำนวนมากของเขาเกี่ยวกับโลกภายนอก มโนทัศน์เรื่องกาลเวลาของเขาย่อมขึ้นต่อสิ่งนี้อย่างสัมบูรณ์จากมุมมองเชิงอัตวิสัย"
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** ทฤษฎีญาณวิทยาที่ปฏิวัติความเข้าใจ: โลกภายนอกและเวลาถูกสร้างขึ้นจากจังหวะการหายใจของสรีระ
- **เชิงอรรถสำเร็จรูป (Chicago Note):**

#### 18. 18. การหยุดลมหายใจในกุมภกะเพื่อดับมโนทัศน์แห่งเวลาและบรรลุสมาธิ (Chapter VI, p. 70)
> *"Therefore when these two functions of the air stop notion of time also disappears. The claim of the yogin is that it is possible to stop these two functions of the wind and to hold it within (kumbhaka) and through that complete samadhi can be attained."*

- **คำแปลวิชาการ:** "ดังนั้น เมื่อการทำหน้าที่ทั้งสองประการนี้ของลมหยุดนิ่งลง มโนทัศน์แห่งกาลเวลาก็ย่อมเลือนหายสูญสิ้นไปด้วย คำประกาศของโยคีคือ ย่อมเป็นไปได้ที่จะหยุดยั้งการทำหน้าที่ทั้งสองนี้ของลมปราณ และกักรั้งมันไว้ภายใน (กุมภกะ) และผ่านทางวิธีการนั้นเอง สมาธิอันบริบูรณ์ย่อมได้รับการบรรลุถึง"
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** หัวใจของการปฏิบัติโยคะ: กักลมเพื่อหยุดเวลา ดับความฟุ้งซ่าน เข้าสู่สภาวะสัมมาสมาธิ
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 70.

#### 19. 19. สุริยะและจันทระในฐานะสัญลักษณ์ของทวิภาวะที่ต้องกำจัด (Chapter VI, p. 70)
> *"The sun and the moon are really symbols of day and night and our notion of time is also based on them. The perception of the objective world is also based on them. The direct aim of the yogin is to extirpate such notions and thus to proceed towards samadhi. This is why it has been said on so many occasions that 'the Sun and the Moon are to be killed.'"*

- **คำแปลวิชาการ:** "ดวงอาทิตย์และดวงจันทร์แท้จริงแล้วคือสัญลักษณ์ของกลางวันและกลางคืน และมโนทัศน์แห่งเวลาของเราก็ตั้งอยู่บนสิ่งเหล่านั้น การรับรู้โลกเชิงรูปธรรมภายนอกก็ตั้งอยู่บนสิ่งเหล่านั้นเช่นกัน เป้าหมายโดยตรงของโยคีคือการถอนรากถอนโคนมโนทัศน์เช่นว่านั้น และก้าวรุดหน้าไปสู่สมาธิ ด้วยเหตุนี้เองจึงได้รับการกล่าวไว้ในหลายวาระว่า 'ดวงอาทิตย์และดวงจันทร์จักต้องถูกสังหารเสีย'"
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** การถอดรหัสคาถาที่ฟังดูรุนแรง: 'การฆ่าดวงอาทิตย์และดวงจันทร์' คือการหยุดลมหายใจเข้า-ออก
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 70.

#### 20. 20. กาลีและอาลีในฐานะเสียงปฐมมูลแห่งการสร้างสรรค์จักรวาล (Chapter VI, p. 71)
> *"I have left out till now the two words kali and ali or the 'consonants' and 'the vowels'. It has been said before that in the use of these two terms emphasis is laid on the sound. In the consideration of these two terms, therefore, sound has been taken to be the basis of creation as in the case of bindu and nada."*

- **คำแปลวิชาการ:** "ข้าพเจ้าได้ละเว้นไว้จนถึงบัดนี้สำหรับคำสองคำ คือ กาลี และ อาลี หรือ 'พยัญชนะ' และ 'สระ' ได้กล่าวไว้ก่อนหน้านี้แล้วว่า ในการใช้คำสองคำนี้ ความสำคัญได้รับการเน้นย้ำไปที่เรื่องของเสียง ในการพิจารณาคำสองคำนี้ ดังนั้น เสียงจึงได้รับการถือว่าเป็นรากฐานแห่งการสร้างสรรค์สรรพสิ่ง ดังเช่นในกรณีของพินทุและนาดะ"
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** ปรัชญาภาษาศาสตร์เชิงภววิทยา (Acoustic Ontology): สรรพสิ่งถือกำเนิดขึ้นจากแรงสั่นสะเทือนของเสียงศักดิ์สิทธิ์
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 71.

#### 21. 21. กาลีคือเสียงที่แผ่วเบากว่า และอาลีคือเสียงที่กังวานกว่าของมาตรกา (Chapter VI, p. 71)
> *"Extending the same analogy we may say that kali, i.e., the consonant, is the less audible expression of the matrikas whereas the ali is their more audible expression. Sound in its tendency towards expression first gives rise to the consonants and then to the vowels..."*

- **คำแปลวิชาการ:** "เมื่อขยายการเปรียบเทียบชุดเดียวกัน เราอาจกล่าวได้ว่า กาลี นั่นคือ พยัญชนะ คือรูปสำแดงที่มีความก้องน้อยกว่าของเหล่ามาตรกา (แม่บทอักขระ) ในขณะที่ อาลี คือรูปสำแดงที่ก้องกังวานได้ยินชัดเจนกว่าของพวกมัน เสียงในแนวโน้มที่มุ่งสู่การสำแดงรูป ย่อมก่อกำเนิดเป็นพยัญชนะขึ้นมาก่อน และจากนั้นจึงก่อกำเนิดเป็นสระ..."
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** การวิเคราะห์ลำดับการคลี่คลายตัวของคลื่นเสียงในการก่อกำเนิดจักรวาลทางภาษา
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 71.

#### 22. 22. อุปายะและปรัชญา: บทบาทของผู้รู้และสิ่งที่ถูกรู้ (Chapter VI, pp. 71–72)
> *"Last of all the two terms upaya and prajna raise a similar difficulty. In the Buddhist texts referred to above, it is clearly said that upaya is the grahya and prajna is the grahaka. The grahya is that which is to be understood and grahaka is that which understands."*

- **คำแปลวิชาการ:** "ท้ายที่สุด คำสองคำคือ อุปายะ และ ปรัชญา ได้ก่อให้เกิดความยุ่งยากในลักษณะเดียวกัน ในคัมภีร์พุทธศาสนาที่อ้างถึงข้างต้น ได้ระบุไว้อย่างชัดเจนว่า อุปายะ คือ กราหยะ (สิ่งที่ถูกรู้) และ ปรัชญา คือ กราหกะ (ผู้รู้) กราหยะคือสิ่งซึ่งพึงได้รับการทำความเข้าใจ และ กราหกะคือสิ่งที่ทำหน้าที่เข้าใจ"
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** การตรึงนิยามทางญาณวิทยาของสองเสาหลักแห่งพุทธตันตระ
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 71–72.

#### 23. 23. การเปรียบเทียบเครื่องบูชาในพระเวท: อิทาคือเครื่องบูชา และอัคนีคือผู้นำพา (Chapter VI, p. 72)
> *"Pingala seems to be the agni, fire, as it indicates the colour of fire (pingala) whereas ida which means 'nourishment' is taken as the personification of the offering. This offering which is meant for the gods is without any value unless it gets the help of the agni which is supposed to carry it to the proper destination. Ida is therefore the grahaka and agni is the grahya."*

- **คำแปลวิชาการ:** "ปิงคลา ดูเหมือนว่าจะเป็น อัคนี (ไฟ) เนื่องจากมันบ่งชี้ถึงสีของไฟ (ปิงคละ - สีส้มอมแดง) ในขณะที่ อิทา ซึ่งแปลว่า 'อาหารบำรุง' ได้รับการยึดถือว่าเป็นบุคลาธิษฐานของเครื่องเซ่นบูชา เครื่องบูชานี้ซึ่งจัดเตรียมไว้สำหรับทวยเทพย่อมปราศจากคุณค่าใด ๆ เว้นแต่จะได้รับความช่วยเหลือจากพระอัคนีซึ่งทำหน้าที่นำพามันไปสู่จุดหมายปลายทางที่ถูกต้อง อิทาจึงเป็นกราหกะ และอัคนีเป็นกราหยะ"
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** การรื้อฟื้นเทววิทยาการบูชายัญแห่งพระเวทมาเป็นคำอธิบายระบบโยคะตันตระ
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 72.

#### 24. 24. ลมหายใจวยานะในฉันโทยะอุปนิษัท: การรวมลมปราณและอปานะสู่วาจา (Chapter VI, p. 73)
> *"A somewhat different idea is also recorded in the Chandogya (I. 3. 3) when it is said that vyana is the combination of the prana and apana and it is the speech because inspiration and expiration stops when one speaks. Now the speech which is here said to combine in it the two motions of the vital air consists of the consonants and the vowels..."*

- **คำแปลวิชาการ:** "แนวคิดที่ค่อนข้างแตกต่างออกไปได้รับการบันทึกไว้ในคัมภีร์ฉันโทยะอุปนิษัท (I. 3. 3) เมื่อมีการระบุว่า วยานะ คือการรวมตัวกันของปราณและอปาน และมันคือ วาจา (การพูด) เพราะการหายใจเข้าและการหายใจออกย่อมหยุดนิ่งลงเมื่อบุคคลหนึ่งเปล่งเสียงพูด บัดนี้ วาจาซึ่งได้รับการกล่าวไว้ ณ ที่นี้ว่ารวมการเคลื่อนไหวทั้งสองประการของลมหายใจแห่งชีวิต ย่อมประกอบขึ้นจากพยัญชนะและสระ..."
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** หลักฐานอุปนิษัทที่เชื่อมโยงการหยุดหายใจชั่วขณะเข้ากับการเปล่งเสียงศักดิ์สิทธิ์
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 73.

#### 25. 25. พระเวทโบราณยืนยัน: พยัญชนะคือกลางคืน และสระคือกลางวัน (ไอตรเอยารัณยกะ) (Chapter VI, p. 73)
> *"A similar idea is contained in the Aitareya-Aranyaka (II. 2. 4) where it is said: vyanjanais ca matram ratrer apnoti svarair ahani — i.e., 'Night is obtained through the consonants, and day through the vowels.' In the Buddhist texts there is an echo of this ancient Vedic theory where kali and ali are explicitly identified with the moon and the sun, the night and the day."*

- **คำแปลวิชาการ:** "แนวคิดที่คล้ายคลึงกันนี้บรรจุอยู่ในคัมภีร์ไอตรเอยารัณยกะ (II. 2. 4) ซึ่งกล่าวไว้ว่า: 'วยัญชไนศจ มัตตรัง ราตรัย อัปโนติ สวไรร์ อหานิ' — นั่นคือ 'กลางคืนย่อมบรรลุถึงได้ผ่านทางพยัญชนะ และกลางวันผ่านทางสระ' ในคัมภีร์ของพุทธศาสนาย่อมมีเสียงสะท้อนของทฤษฎีพระเวทโบราณนี้ ซึ่งกาลีและอาลีได้รับการระบุอย่างแจ่มแจ้งว่าเป็นสิ่งเดียวกับดวงจันทร์และดวงอาทิตย์ กลางคืนและกลางวัน"
- **การวิเคราะห์เชิงอรรถและมิติตันตระ:** การปิดฉากบทวิจัยด้วยการพิสูจน์สายธารความต่อเนื่องทางปัญญาข้ามสหัสวรรษจากพระเวทสู่พุทธตันตระ
- **เชิงอรรถสำเร็จรูป (Chicago Note):**  
  Bagchi, "Some Technical Terms of the Tantras," 73.

### บทสรุปเชิงวิเคราะห์และคุณูปการต่อรายงานวิจัย (Analytical Synthesis)

#### 1. การวางรากฐานการถอดรหัสภาษาตันตระ (Somatic Semiotics & Tantric Hermeneutics)
งานวิจัยของ Prabodh Chandra Bagchi ใน Chapter VI: "Some Technical Terms of the Tantras" ถือเป็น **ผลงานระดับคลาสสิกที่บุกเบิกการถอดรหัสสัญญะวิทยาแห่งสรีระ (Somatic Semiotics)** ในวงวิชาการอินเดียศึกษาและพุทธศาสน์ศึกษาอย่างลึกซึ้ง บาคจิได้พิสูจน์ให้เห็นอย่างประจักษ์ชัดว่า:
- **การคลี่คลายสัญลักษณ์สู่สรีรวิทยาจริง (Embodied Metaphor):** ข้อความในบทเพลงจรรยาบทและคัมภีร์ตันตระที่ดูประหลาด ลี้ลับ หรือส่อไปในทางทำลายล้าง เช่น 'การขัดสีบดขยี้ดวงอาทิตย์และดวงจันทร์' 'การสังหารบิดามารดา' หรือ 'การพายเรือข้ามแม่น้ำคงคาและยมุนา' แท้จริงแล้วมิใช่ความเพ้อฝันหรือพฤติกรรมต่อต้านสังคม แต่เป็น **รหัสคำสอนทางเทคนิคขั้นสูง (Technical Yogic Mnemonics)** สำหรับการปฏิบัติ **ปราณายามะและกุมภกะ** เพื่อสกัดกั้นการเคลื่อนไหวของลมหายใจสองฟาก (ลลนา-รสนา) และบังคับรวมกระแสจิตเข้าสู่ช่องแกนกลาง (อวธูตี)
- **ผังแม่บทแห่งทวิภาวะตันตระ (The Binary Matrix of Tantric Polarity):** การประมวลตารางสองขั้วในหน้า 69 ของบาคจิ ซึ่งจัดกลุ่ม: ฝ่ายสุริยะ (ขวา, กาลี, รสนา, ปราณ, กลางคืน, อุปายะ, รักตะ, โลกียภพ) ตรงข้ามกับ ฝ่ายจันทระ (ซ้าย, อาลี, ลลนา, อปาน, กลางวัน, ปรัชญา, ศุกระ, นิพพาน) ถือเป็น **พิมพ์เขียวเชิงทฤษฎี (Theoretical Blueprint)** ที่ทรงพลังอย่างยิ่ง ช่วยให้นักวิจัยในยุคต่อมาสามารถเข้าใจตรรกะเบื้องหลังการจัดวางพิธีกรรม สัญลักษณ์ และมนตราในคัมภีร์ตันตระได้อย่างเป็นระบบเบ็ดเสร็จ
- **สายธารความต่อเนื่องทางประวัติศาสตร์ความคิดจากพระเวทสู่อุปนิษัทและตันตระ:** การที่บาคจิสืบค้นรากเหง้าของ กาลี-อาลี ย้อนกลับไปถึงมโนทัศน์เรื่อง วยัญชนะ (พยัญชนะ) และ สวระ (สระ) ใน *ไอตรเอยารัณยกะ* รวมถึงการอธิบายลมหายใจ วยานะ ใน *ฉันโทยะอุปนิษัท* ได้สลายภาพลวงตาทางประวัติศาสตร์ที่เคยมองว่าตันตระเป็นสิ่งแปลกปลอมนอกรีตที่ผุดขึ้นมาโดยไร้ราก หากแต่เป็นวิวัฒนาการขั้นสูงสุดของการผสานปรัชญาจักรวาลวิทยาโบราณเข้ากับสรีรวิทยาโยคะเชิงปฏิบัติการ

#### 2. คุณูปการโดยตรงต่อโครงการวิจัยเถรวาทตันตระในเอเชียตะวันออกเฉียงใต้ (Southeast Asian Tantric Theravada)
สำหรับโครงการวิจัย *สถานภาพการศึกษาเถรวาทตันตระในเอเชียตะวันออกเฉียงใต้* เอกสาร Dossier ฉบับนี้มอบ **กุญแจทองคำ (Master Key)** ในการถอดรหัสเอกสารใบลานโบราณสายโยคาวจรและกรรมฐานมัชฌิมาแบบโบราณ (Borān Kammaṭṭhāna) ในดินแดนสยาม ลาว กัมพูชา และล้านนา ดังต่อไปนี้:

1. **การถอดรหัสคัมภีร์มูลกรรมฐานและพระปฐมภาณวาร:**
   ในคัมภีร์กรรมฐานโบราณของไทยและเขมร (เช่น คัมภีร์มูลกรรมฐาน คัมภีร์สัททวิมล และคัมภีร์ธัมมกาย) ปรากฏการกำหนดจิตภาวนาตามฐานกายและลมหายใจ โดยมีการจัดคู่เทียบระหว่าง **'อัสสาสะ-ปัสสาสะ'** (ลมหายใจเข้า-ออก) กับพระธรรมหมวดต่าง ๆ รวมถึงการจับคู่อักขระบาลี สระ (อาลี) และ พยัญชนะ (กาลี) เข้ากับโครงสร้างกระดูก เส้นเอ็น และอวัยวะภายใน การค้นพบของบาคจิช่วยยืนยันว่า โครงสร้างการปฏิบัติดังกล่าวของพระสงฆ์ฝ่ายเถรวาทในเอเชียตะวันออกเฉียงใต้มิได้เกิดขึ้นอย่างโดดเดี่ยว แต่สืบทอดโครงสร้าง **Somatic Alphabetization (การสถาปนาอักขระมนตราลงบนสรีระ)** มาจากบรรยากาศทางวิชาการและโยคะร่วมสมัยกับตันตระอินเดียยุคราชวงศ์ปาละอย่างไม่ต้องสงสัย

2. **ความเข้าใจต่อปรากฏการณ์ 'ดวงธรรม' และ 'ดวงแก้วใส' ในวิชชาธรรมกายและโยคาวจร:**
   การปฏิบัติของสายโยคาวจรโบราณที่มุ่งเน้นการรวมจิตลงสู่ **'ศูนย์กลางกาย'** (สะดือหรือกลางช่องอก) จนเกิดเป็นดวงสว่างใสบริสุทธิ์ (ดวงปฐมมรรค หรือ ดวงธรรม) มีโครงสร้างคู่ขนานอย่างสมบูรณ์แบบกับมโนทัศน์เรื่อง **การรวมพินทุ (Bindu Fusion)** ของบาคจิ ซึ่งเกิดจากการรวมหยดศุกระ (ขาว) และหยดรักตะ (แดง) เข้าสู่ช่องแกนกลางเพื่อหยุดกระแสกาลเวลาและดับความกวัดแกว่งของจิต การนำกรอบวิเคราะห์ของบาคจิมาจับจะช่วยให้งานวิจัยของเราสามารถอธิบายพัฒนาการของวิชชาธรรมกายในเชิงประวัติศาสตร์ความคิดได้อย่างเป็นวิทยาศาสตร์และมีหลักฐานรองรับ

3. **การคลี่คลายปริศนาอักขระยันต์และพระคาถาในเอเชียตะวันออกเฉียงใต้:**
   ในตำราพิชัยสงคราม ตำราเลขยันต์ และสมุดข่อยโบราณของไทย การแบ่งกลุ่มยันต์ออกเป็น 'ยันต์สุริยประภา' และ 'ยันต์จันทรประภา' หรือการลงอักขระหัวใจพระไตรปิฎกขนาบข้างซ้าย-ขวา แท้จริงแล้วสะท้อนการสืบทอดมโนทัศน์เรื่อง **สูรยะ-จันทระ** และ **กาลี-อาลี** ที่บาคจิอธิบายไว้อย่างแม่นยำ การสร้าง Dossier ฉบับนี้จึงเป็นสะพานเชื่อมชิ้นสำคัญระหว่างเอกสารภาษาสันสกฤต/อปภรังศะในอินเดีย กับวรรณกรรมสมุดไทยและคัมภีร์ใบลานในภูมิภาคอุษาคเนย์

4. **ความสอดคล้องกับข้อค้นพบของนักวิชาการร่วมสมัย (Bizot, Crosby, Skilton):**
   งานของ François Bizot เรื่อง *Le Chemin de Lankā* และงานของ Kate Crosby เรื่อง *Esoteric Theravada* ล้วนชี้ให้เห็นว่าหัวใจของเถรวาทลี้ลับคือ 'การกำเนิดใหม่ของพระพุทธเจ้าภายในร่างกายของผู้ปฏิบัติผ่านลมหายใจและตัวอักษร' การศึกษาเชิงลึกของบาคจิใน Chapter VI นี้ทำหน้าที่เป็น **ต้นทางทางประวัติศาสตร์ (Genealogical Ancestor)** ที่ยืนยันว่ากระบวนการผสานอักขระ มนต์ และลมหายใจนี้ ได้รับการจัดระบบทางทฤษฎีไว้อย่างสมบูรณ์แล้วในอินเดียตั้งแต่ก่อนคริสต์ศตวรรษที่ 10–12 ก่อนที่จะแพร่กระจายเข้าสู่ลุ่มน้ำเจ้าพระยาและโขงในระลอกต่อมา
