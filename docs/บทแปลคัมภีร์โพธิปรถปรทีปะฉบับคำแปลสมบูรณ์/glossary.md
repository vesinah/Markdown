# คลังศัพท์กลาง (Glossary): โพธิปถประทีป (Bodhipathapradīpa)

คลังศัพท์เทียบเคียง 3 ภาษา (สันสกฤต - ทิเบต - จีน) พร้อมคำแปลภาษาไทยมาตรฐานวิชาการ

| ศัพท์สันสกฤต (IAST) | อักษรทิเบต (Wylie) | อักษรจีน (Traditional) | คำแปลไทยตามศัพท์ | คำแปลไทยวิชาการ |
|:---|:---|:---|:---|:---|
| **Bodhipathapradīpa** | *byang chub lam gyi sgron ma* | 菩提道燈 (Pútí Dào Dēng) | [ประทีป] [แห่งมรรคา] [สู่โพธิ] | โพธิปถประทีป (ดวงประทีปส่องทางสู่พระโพธิญาณ) |
| **Atiśa Dīpaṃkaraśrījñāna** | *mar me mdzad ye shes* | 吉祥燃燈智 (Jíxiáng Rándēngzhì) | [พระทีปังกรศรีชญาณ] | พระอติศะ มารเมดซัดเยเชส (ท่านโจโวเจ) |
| **Bodhiprabha** | *byang chub 'od* | 菩提光 (Pútíguāng) | [แสงแห่งโพธิ] | ลามะชังชุบเอิด (เจ้าชายโพธิประภา) |
| **Tri-puruṣa** | *skyes bu gsum* | 三士 (Sānshì) | [บุรุษสามจำพวก] | บุคคล 3 ระดับ / ตรีบุรุษ (ลัมริม) |
| **Adhama-puruṣa** | *skyes bu tha ma / chung ngu* | 下士夫 (Xiàshìfū) | [บุรุษผู้ต่ำสุด] | บุคคลระดับเบื้องต้น / กัลยาณชนขั้นต้น |
| **Madhyama-puruṣa** | *skyes bu 'bring ba* | 中士 (Zhōngshì) | [บุรุษปานกลาง] | บุคคลระดับกลาง / ผู้มุ่งความหลุดพ้นเฉพาะตน |
| **Uttama-puruṣa** | *skyes bu mchog / chen po* | 上士夫 (Shàngshìfū) | [บุรุษผู้อุดม/ประเสริฐสุด] | บุคคลระดับสูง / มหาบุรุษมหายาน |
| **Bodhicitta** | *byang chub kyi sems* | 菩提心 (Pútíxīn) | [จิตแห่งโพธิ] | โพธิจิต (ความปรารถนาในพระโพธิญาณ) |
| **Praṇidhicitta** | *smon pa'i sems* | 願心 / 菩提願心 (Yuànxīn) | [จิตแห่งการตั้งความปรารถนา] | ประณิธานโพธิจิต (โพธิจิตขั้นปรารถนา) |
| **Prasthānacitta** | *'jug pa'i sems* | 行心 / 菩提行心 (Xíngxīn) | [จิตแห่งการออกก้าวเดินปฏิบัติ] | ประสถานโพธิจิต (โพธิจิตขั้นดำเนินงานจริง) |
| **Śamatha** | *zhi gnas* | 止 (Zhǐ) | [ความสงบระงับ] | สมถะ (จิตตสมาธิอันสงบผ่องใส) |
| **Vipaśyanā / Prajñā** | *lhag mthong / shes rab* | 觀 / 般若 (Guān / Bōrě) | [ความเห็นแจ้ง / ปัญญา] | วิปัสสนา / ปัญญาบารมี |
| **Śūnyatā** | *stong pa nyid* | 空性 (Kōngxìng) | [ความว่างเปล่า] | สุญญตา (ความว่างจากสภาวะอัตตา) |
| **Niḥsvabhāva** | *rang bzhin med pa* | 無自性 (Wúzìxìng) | [อันปราศจากสภาวะแห่งตน] | นิห์สวภาวะ (การไร้แก่นสารแท้จริงในตัวเอง) |
| **Upāya** | *thabs* | 方便 (Fāngbiàn) | [หนทาง / อุบาย] | อุปายโกศล (อุบายวิธีเกื้อกูลสรรพสัตว์) |
| **Abhijñā** | *mngon par shes pa* | 神通 (Shéntōng) | [ความรู้ยิ่ง] | อภิญญา (ฤทธิ์ปัญญาญาณพิเศษ) |
| **Prātimokṣa** | *so sor thar pa* | 別解脫 (Biéjiětuō) | [การหลุดพ้นเฉพาะตน] | พระปาติโมกข์ (ศีลวินัยขั้นพื้นฐาน) |
| **Bodhisattva-saṃvara** | *byang chub sems dpa'i sdom pa* | 菩薩律儀 (Púsà Lǜyí) | [การสำรวมระวังแห่งพระโพธิสัตว์] | โพธิสัตว์สังวร (ศีลโพธิสัตว์) |
| **Guhyābhiṣeka** | *gsang ba'i dbang* | 密灌頂 (Mì Guàndǐng) | [การรดน้ำลึกลับ] | คุหยาภิเษก (การอภิเษกลับในตันตระ) |
| **Prajñājñānābhiṣeka** | *shes rab ye shes kyi dbang* | 慧灌頂 (Huì Guàndǐng) | [การอภิเษกแห่งปัญญาญาณ] | ปรัชญาชญาเนภิเษก |
| **Brahmacarya** | *tshangs par spyod pa* | 梵行 (Fànxíng) | [การประพฤติอย่างประเสริฐ] | พรหมจรรย์ (การเว้นเมถุนธรรมและกามคุณ) |
| **Pārājika** | *pham pa* | 他勝罪 (Tāshèngzuì) | [ความพ่ายแพ้ / อาบัติขาดจากสงฆ์] | ปาราชิก (อาบัติหนักที่สุด) |
