# คลังศัพท์กลาง (Project Glossary)

**โปรเจกต์:** palm_leaf_buddhist_manuscripts — กายภาพของคัมภีร์ใบลานในโลกพุทธศาสนา
**อัพเดตล่าสุด:** 2026-08-26

> **กฎบังคับ:** Agent ทุกตัวในโปรเจกต์นี้ต้องอ่านไฟล์นี้ก่อนเขียนหรือแปลทุกครั้ง
> ศัพท์ที่อยู่ในตารางนี้มีสถานะผูกพัน — ห้ามใช้รูปถ่ายถอดอื่น
> **นโยบายที่ผู้ใช้อนุมัติ (2026-08-26):** ใช้ศัพท์ไทยกำหนดเอง + วงเล็บโรมันในการปรากฏครั้งแรก เช่น "จารึกท้ายเล่ม (*colophon*)"

## [APPROVED] รอการยืนยัน

> รายการทั้งหมดข้างต้นเป็นข้อเสนอเริ่มต้นตามนโยบาย "ศัพท์ไทย + วงเล็บโรมัน" ที่ผู้ใช้อนุมัติเชิงนโยบาย
> หากผู้ใช้ไม่แก้ไขภายในการอนุมัติโครงร่าง (Outline Gate) ให้ยกสถานะทั้งตารางเป็น [APPROVED]
