## 1. แหล่งข้อมูลและระเบียนตัวบท
- **ชื่อคัมภีร์:** 《事師法五十頌》 1 เล่ม (卷)
- **ผู้รวบรวม:** 馬鳴菩薩集 (พระโพธิสัตว์ม่าหมิง / อัศวโฆษ รวบรวม)
- **ผู้แปล:** 西天譯經三藏朝散大夫試鴻臚少卿宣梵大師賜紫沙門臣日稱等奉詔譯 (พระจื่อเชิง / รื่อเชียง แห่งอินเดียตะวันตก ในรัชสมัยราชวงศ์ซ่งเหนือ ร่วมกับคณะแปลตามพระบรมราชโองการ)
- **หมายเลขในพระไตรปิฎก:** Taishō Shinshū Daizōkyō T1687 (T.32.1687) ≡ Koryo K1493 (高麗大藏經, K41n1493_p0612c–p0613c)
- **แหล่งไฟล์ดิจิทัล:** CBETA 2025-02-26 XML TEI P5 release

## 2. ตัวบทโศลกที่ 46–50 และบทปณิธานอุทิศส่วนกุศล (กู้คืนครบ 100%)
- **โศลกที่ 46 (T32.0777a02–03; เทียบ Skt v.45):**
  若師所教勅，或病緣不作，當作禮咨陳，斯則無其咎。
  (หากอาจารย์มีคำสั่งใด แต่ศิษย์มีเหตุเจ็บไข้จนมิอาจปฏิบัติตามได้ พึงกระทำความเคารพกราบทูลชี้แจงโดยสัจจะ การนั้นย่อมไม่มีโทษทัณฑ์)
- **โศลกที่ 47 (T32.0777a04–05; เทียบ Skt v.46–47):**
  常令師歡喜，離諸煩惱事，當勤而行之，恐繁故不述。
  (พึงกระทำให้อาจารย์เกิดความปีติยินดีเสมอ พึงเว้นขาดจากกิจอันนำมาซึ่งความรบกวนกังวลใจ พึงพากเพียรปฏิบัติในข้อนี้ ข้อธรรมอื่นนอกจากนี้เกรงว่าจะพิสดารเกินไปจึงมิได้นำมากล่าวไว้ในที่นี้)
- **โศลกที่ 48 (T32.0777a06–07; เทียบ Skt v.48):**
  彼金剛如來，親如是宣說，及餘教所明，依師獲成就。
  (พระวัชรตถาคตเจ้าได้ตรัสสอนข้อปฏิบัตินี้ไว้ด้วยพระองค์เอง และคัมภีร์ตันตระอื่นทั้งหลายก็ได้แสดงไว้แจ้งชัดว่า ความสำเร็จทางธรรมย่อมได้มาโดยการพึ่งพิงอาจารย์)
- **โศลกที่ 49 (T32.0777a08–11; เทียบ Skt v.49):**
  若弟子清淨，能歸依三寶，設使命將終，亦為宣法要，及授祕密教，令作正法器；若現相誦持，當獲根本罪。
  (หากศิษย์เป็นผู้มีจิตบริสุทธิ์ ถึงพร้อมด้วยไตรสรณคมน์ แม้ในกาลใกล้จะสิ้นอายุขัย อาจารย์ก็พึงแสดงสารธรรมสำคัญและมอบคำสอนตันตระลับ เพื่อให้เขาเป็นภาชนะรองรับธรรมที่แท้ แต่หากศิษย์แสดงตนสวดท่องมนต์ลับต่อหน้าผู้ไม่สมควร ย่อมต้องอาบัติมูลแห่งวัชรยาน)
- **โศลกที่ 50 และบทอุทิศกุศล (T32.0777a12–14; เทียบ Skt v.50):**
  若能隨順師行學，則成一切諸功德，以我所集斯善因，願與眾生速成佛。
  (หากศิษย์สามารถประพฤติปฏิบัติตามจริยาและคำสอนของอาจารย์ ย่อมสำเร็จซึ่งกุศลธรรมและคุณธรรมทั้งปวง ด้วยมูลเหตุแห่งกุศลผลบุญที่ข้าพเจ้าได้รวบรวมคัมภีร์นี้ ขอสรรพสัตว์จงบรรลุพระอนุตตรสัมมาสัมโพธิญาณโดยพลันเทอญ)

## 3. ผลการตรวจสอบตัวแปรอ่าน (Textual Variants) จาก CBETA Collation
- 恡 (T32.0776b01) — ฉบับเกาหลี (麗-CB) อ่าน 恡 (ตระหนี่) แต่ฉบับไทโช (大) อ่าน 希
- 是 (T32.0776b15) — ฉบับเกาหลีอ่าน 是 แต่ฉบับไทโชอ่าน 足
- 㰦 (T32.0776c02) — ฉบับเกาหลีอ่าน 㰦 (หาว) ฉบับไทโชอ่าน 呿 ฉบับหมิงอ่าน 欠
- 當 (T32.0776c28) — ฉบับเกาหลีอ่าน 當 ฉบับไทโชอ่าน 常
