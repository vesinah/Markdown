# รายงานการสำรวจ วิจัย และวิเคราะห์เชิงลึกทางจารึกวิทยา: โดเมนที่ 2
## จารึกยุคแรกและศูนย์กลางอำนาจชวากลาง (กูไต, ตารูมานคร, มะตะรัม-ไศเลนทร์-สัญชัย)
### โครงการวิจัย: สถานภาพการศึกษาจารึกในอินโดนีเซียและเครือข่ายเอเชียตะวันออกเฉียงใต้ภาคพื้นสมุทร

---

### ส่วนที่ 1: บัญชีวิเคราะห์หลักฐานเชิงประจักษ์และจารึกทั้งหมดในคลัสเตอร์

จากการสำรวจคลังข้อมูลจารึกวิทยาและแฟ้มเอกสารวิเคราะห์ชั้นต้นในโครงการวิจัย โดเมนที่ 2 ครอบคลุมหลักฐานจารึกปฐมภูมิทั้งประเภทจารึกศิลา (หินแอนดีไซต์ธรรมชาติ หินตัดแต่งสถาปัตยกรรม และหินผาริมน้ำ) จารึกแผ่นโลหะ (แผ่นทองแดง แผ่นเงิน แผ่นทองคำ) และวัตถุอุทิศบรรจุกรุฐานเจดีย์และเทวสถาน (Peripih) ซึ่งเป็นพยานหลักฐานการสถาปนารัฐโบราณรุ่นแรกและการก่อรูปศูนย์กลางอำนาจในเกาะบอร์เนียว เกาะชวาภาคตะวันตก และที่ราบลุ่มชวากลาง ระหว่างคริสต์ศตวรรษที่ 5 ถึงต้นคริสต์ศตวรรษที่ 10 โดยสามารถจำแนกบัญชีหลักฐานเชิงประจักษ์ตามรหัสเอกสาร (Source ID) และสารบบจารึกได้ดังนี้:

#### 1. แหล่งข้อมูลจารึกวิทยายุคแรกในกาลีมันตันและชวาตะวันตก (ศตวรรษที่ 5)
- **Source ID `S-1918-vogel-01` (J. Ph. Vogel 1918):**
  * *กลุ่มจารึกเสายูปะแห่งกูไต (Kutai Yūpa Inscriptions ca. 400–450 CE):* ประกอบด้วยเสาศิลาหินแอนดีไซต์ธรรมชาติ 7 หลัก ค้นพบ ณ มูอารา กามัน (Muara Kaman) ริมแม่น้ำมหาคัม (Mahakam River) รัฐสุลต่านกูไต กาลีมันตันตะวันออก จารึกด้วยอักษรปัลลวะยุคแรกเริ่ม (Early Pallava / Archaic Lithic Grantha) ภาษาสันสกฤตฉันทลักษณ์คลาสสิก (อนุษฏุภ และ อารยา):
    - *หลัก A (Vogel A / Kern II / พิพิธภัณฑ์แห่งชาติอินโดนีเซีย D.2a):* ฉันท์อนุษฏุภ 12 บรรทัด ระบุพงศาวลีสามชั่วรุ่น กุณฑุงคะ (Kuṇḍuṅga), อัศววรมัน (Aśvavarman) ผู้สร้างราชวงศ์ (vaṅśakartr̥), และพระเจ้ามูลวรมัน (Mūlavarman) ผู้ประกอบมหายัญพิธีพหุสุวรรณกะ (Bahusuvarṇaka yajña)
    - *หลัก B (Vogel B / Kern III / ทะเบียน D.2b):* ฉันท์อารยา 8 บรรทัด บันทึกการถวายมหาทานฝูงแม่โค 20,000 ตัว (viṅśatir gosahasrikam) ณ ลานศักดิ์สิทธิ์วปรเกศวร (Vaprakeśvara) แด่คณะพราหมณ์ผู้เดินทางข้ามสมุทรมาจากภายนอก (viprair ihāgataiḥ)
    - *หลัก C (Vogel C / Kern I / ทะเบียน D.2c):* ฉันท์อนุษฏุภ 8 บรรทัด สดุดีการถวายมหาทานยิ่งใหญ่ (bahudāna), การถวายสิ่งมีชีวิต/ข้าทาส (jīvadāna), ต้นกัลปพฤกษ์จำลอง (sakalpavr̥kṣa), และการถวายที่ดิน (sabhūmidāna)
    - *หลัก D (Vogel D / ทะเบียน D.2d):* บันทึกการเปรียบเทียบเชื้อสายพระเจ้ามูลวรมันกับท้าวสาครและภคีรถแห่งมหากาพย์อินเดีย
    - *หลัก E, F, G (ค้นพบเพิ่มเติม ค.ศ. 1940 ชำระโดย B.Ch. Chhabra 1949):* บันทึกการถวายน้ำ เนยใส งา (หลัก E), การปราบปรามกษัตริย์ข้างเคียงให้ส่งส่วย (หลัก F), และการถวายประทีปน้ำมันงาเป็นประภาคารบุญ (หลัก G)
- **กลุ่มจารึกอาณาจักรตารูมานครแห่งชวาตะวันตก (Tarumanagara Inscriptions ca. ศตวรรษที่ 5):**
  * สัมพันธ์กับพระมหากษัตริย์ปูรณวรมัน (Pūrṇavarman) จารึกด้วยอักษรปัลลวะตอนต้น ภาษาสันสกฤต: จารึกจียารูเติน (Ciaruteun / Ciampea) สลักรอยพระพุทธบาทจำลองเป็นรอยบาทของพระวิษณุ (viṣṇor iva padadvayam), จารึกตูกู (Tugu Inscription ณ จาการ์ตาเหนือ) บันทึกวิศวกรรมชลศาสตร์ขุดลอกคลองจันทราภาและคลองโกมตียาว 6,122 คันธนู (ราว 11 กิโลเมตร) ลงสู่ทะเลภายใน 21 วัน พร้อมถวายโค 1,000 ตัวแด่พราหมณ์, จารึกเกอบอนโกปี 1 (Kebonkopi I) สลักรอยเท้าช้างเอราวัณแห่งพระอินทร์ (airāvatasya padadvayam), จารึกจัมบู (Jambu / Pasir Koleangkak), และจารึกจีดังฮียัง (Cidanghiang / Munjul)

#### 2. แหล่งข้อมูลมหาจารึกและพัฒนาการราชวงศ์ชวากลาง (คริสต์ศตวรรษที่ 8 ถึง 10)
- **Source ID `S-1966-boechari-01` (Boechari 1966, 1986):**
  * *ศิลาจารึกโซโจเมร์โต (Sojomerto Inscription):* หินแอนดีไซต์ธรรมชาติ 11 บรรทัด ค้นพบที่อำเภอบาตัง ชายฝั่งตอนเหนือของชวากลาง จารึกด้วยอักษรปัลลวะปลาย/กวิยุคแรก ภาษามลายูโบราณแทรกสันสกฤต บันทึกนาม ดาปุนตะ ไศเลนทระ (Dapūnta Selendra) ผู้นับถือพระศิวะ (namah śśivāya) พระภัตตาระปรเมศวร และเทพบรรพชนฮียัง...มิฮ์ (Hiyaṅ ...-mih) ในฐานะปฐมบรรพบุรุษผู้สร้างราชวงศ์ไศเลนทร์
- **Source ID `S-1950-casparis-01` (J. G. de Casparis 1950, *Prasasti Indonesia I*):**
  * *ศิลาจารึกการังเตองะฮ์ (Karangtengah 824 CE / มหาศักราช 746):* สองภาษา (สันสกฤตฉันทลักษณ์และชวาโบราณ) บันทึกการสถาปนาพระวิหารมหาพุทธศาสนา (เวณุวนะและจินาลัย) โดยพระเจ้าสมรตุงคะ (Samaratuṅga) และเจ้าหญิงปรโมทวรรธนี (Prāmodavardhanī)
  * *ศิลาจารึกกัณดสุลี 1 (Gaṇḍasuli I 832 CE / มหาศักราช 754):* หินผาริมน้ำขนาดยักษ์ 15 บรรทัด จารึกด้วยภาษามลายูโบราณในเขตหุบเขาเตอมังกุง ชวากลาง ออกโดยเจ้าเมือง ดั่ง กรายัน ปรรตปัน ปู ปาลาร์ (Ḍang Karayān Partapān Pu Palār / Busu Plār)
  * *ศิลาจารึกศรีคาฮูลุนนัน หรือ ตรูอีเตอปุสซัน 1 และ 2 (Tru i Tepusan I & II 842 CE / มหาศักราช 764):* จารึกภาษาชวาโบราณ บันทึกพระราชโองการของพระนางศรีคาฮูลุนนัน (Śrī Kahulunnan) สละสิทธิ์ส่วยภาษีหมู่บ้านตรูอีเตอปุสซันเพื่ออุปถัมภ์ `kamūlān <i bhūmi> sambhāra` (มหาเจดีย์บุโรพุทโธ)
  * *จารึกอักษรนาครียุคต้นแห่งราตูโบโก (ค.ศ. 792):* ชิ้นส่วนจารึกหินทราย บันทึกการสร้าง "อภัยคีรีวิหาร" (Abhayagiri-vihāra) เชื่อมโยงกับลังกา
  * *จารึกกำกับภาพสลักมหากรรมวิภังค์ ณ ฐานชั้นในบุโรพุทโธ (Bedolven voet):* 160 ข้อความสั้น
- **Source ID `S-1956-casparis-01` (J. G. de Casparis 1956, *Prasasti Indonesia II*):**
  * *ศิลาจารึกศิวคฤหะ (Śivagṛha Inscription 856 CE / มหาศักราช 778):* ร้อยกรองภาษาชวาโบราณ 29 บท บันทึกสงครามกลางเมืองและการขับไล่เจ้าชายบาลปุตระ (Bālaputra) ผู้สร้างป้อมค่ายหินซ้อนร้อยชั้น (watun inatus) บนที่สูง, การสละราชสมบัติของราไก ปิกาตัน (ชาติเนิงรัต) มอบอำนาจให้ดยัฮ โลกาปาละ (ราไก กายุวังกี), การสถาปนาราชธานีเมดัง ณ มัมราติปุระ, และการผันแม่น้ำโอปักเพื่อฉลองมหาเทวสถานศิวาลัย (จันทิปรัมบานัน)
  * *ศิลาจารึกจันทิเปอโรต (Candi Perot 850 CE):* แสดงการบริหารอำนาจร่วมระหว่างราตู ราไก ปิกาตัน กับราไก ปะตะปัน ปู มะนูกู
- **Source ID `S-1994-kusen-01` (Kusen 1994, ร่วมกับ Trigangga 1994):**
  * *จารึกแผ่นทองแดงวานัวเตองะฮ์ 3 (Wanua Tengah III 908 CE / มหาศักราช 830):* แผ่นทองแดง 2 แผ่น ค้นพบที่อำเภอกาโลรัน จังหวัดเตอมังกุง บันทึกประวัติศาสตร์การจัดการที่ดินสีมาของอารามพิกาตันยาวนาน 162 ปี (ค.ศ. 746–908) เผยทำเนียบพระมหากษัตริย์มตารามโบราณ 12 พระองค์พร้อมวันขึ้นครองราชย์ที่แน่นอน และเปิดเผยรัชกาลที่สาบสูญ 4 พระองค์ รวมถึงภาวะสุญญากาศทางการเมือง 8 ปี (ค.ศ. 887–894)
- **Source ID `S-2011-griffiths-04` (Arlo Griffiths 2011):**
  * *กลุ่มจารึกกุมภโยนิแห่งราตูโบโกและเปอเร็ง (Kumbhayoni Corpus ca. 856–863 CE):* ศิลาจารึกลึงค์ราตูโบโก A–F (โดยเฉพาะ Ratu Baka F), ศิลาจารึกเปอเร็ง (Pereng / Wukiran 863 CE), และจารึกดะวังซารี (Dawangsari) สถาปนาพระนามดั้งเดิมของมหาเทวสถานปรัมบานันว่า "ลงกาปุระ" (Laṅkāpura / pūrvvaṃ laṅkapuram)
- **Source ID `S-2021-griffiths-01` (Arlo Griffiths 2021):**
  * *ศิลาจารึกภาษาสันสกฤตแห่งสังกะระ (Prasasti Śaṅkara):* แผ่นหินบุผนังปราสาทหินขัดเรียบประณีต จารึกคาถาสันสกฤต 5 บทด้วยอักษรกวิยุคแรก ชำระตัวบทหักล้างประวัติศาสตร์ชาตินิยมเดิม ยืนยันสถานะจารึกระดับเอกชนของกวีไศวนิกายผู้สร้างเทวสถานพระศิวะอุทิศกุศลแด่บิดา
- **Source ID `S-2012-acri-01` (Andrea Acri & Roy Jordaan 2012):**
  * *กลุ่มจารึกและประติมากรรมจันทิพระศิวะ ปรัมบานัน:* การถอดรหัสภาพสลักเทพ 24 องค์ (D1–D24) ร่วมกับจารึกแผ่นทองคำ 19 แผ่นในกรุเปอริปิฮ์ จันดิ Z, แผ่นเงินจารึกนาม Nirṛti ใต้ฐานพระศิวะ, และจารึกแผ่นทองแดงจานซัน (Cansan 922 CE)
- **Source ID `S-2014-acri-01` (Andrea Acri 2014):**
  * *จารึกแผ่นทองแดงซังซัง (Sangsang Copperplate 907 CE):* บันทึกมหรสพศักดิ์สิทธิ์และการแสดงตลก ขับร้อง ร่ายรำ ในพิธีสถาปนาสีมา สัมพันธ์กับภาพสลักบุโรพุทโธและปรัมบานัน
- **Source ID `S-2021-uny-01` (Arrazaq & Tanudirjo 2021) & Source ID `S-2023-brin-01` (Dwi Pradnyawan 2023):**
  * *กลุ่มจารึกจันทิเกอดูลัน (Candi Kedulan Inscriptional Complex):* โบราณสถานไศวนิกายที่จมอยู่ใต้ชั้นตะกอนลาฮาร์ภูเขาไฟเมอราปีลึก 7 เมตร พบจารึก 3 หลัก ได้แก่ จารึกปานังการัน (869 CE), จารึกสุมุนดุล (869 CE), และจารึกตลูโรน (Tlu Ron 900 CE) ยืนยันวิศวกรรมฝายทดน้ำ (ḍawuhan) ลำรางชลประทาน (wluran) และเทวสถานหลวง (parhyangan haji)
- **Source ID `S-2024-acri-02` (Savitri, Acri, & Noerwidi 2024):**
  * *วัตถุจารึกและกรุบรรจุสิ่งศักดิ์สิทธิ์กิมปูลันและริงงินลาริก:* ผอบหิน 17 ช่องพร้อมดอกบัวทองคำ 8 กลีบและแผ่นทองคำจารึก ณ จันทิกิมปูลัน (ค้นพบ ค.ศ. 2009 ใต้เถ้าภูเขาไฟเมอราปี 2.7 เมตร) และแผ่นทองคำจารึกนามเทพประจำทิศ 22 แผ่น ณ ริงงินลาริก อำเภอโบโยลาลี (ค้นพบ ค.ศ. 2016) ผ่านการวิเคราะห์ธาตุ p-XRF
- **DHARMA Master Corpus (`DHARMA-DOSS-02` และ `DHARMA-DOSS-06`):**
  * ประกอบด้วยจารึกฉบับชำระตามมาตรฐาน TEI-XML รวม 22 รายการสำคัญ เช่น จารึกกะลาซัน (Kalasan 778 CE รหัส `DHARMA_INSIDENKKalasan.xml`), จารึกมันตยาสิห์ 1–3 (Mantyasih I–III 907 CE รหัส `DHARMA_INSIDENKMantyasihI.xml`), จารึกรูกัม (Rukam 907 CE บันทึกหมู่บ้านถูกทำลายด้วยภัยพิบัติภูเขาไฟระเบิด guntur), จารึกชุดโปเลงัน (Polengan plates: Humanding, Jurungan, Mamali, Taragal, Tunahan), จารึกลินตากัน (Lintakan 919 CE), จารึกปังกูมูลัน (Panggumulan 902 CE), และจารึกแผ่นเงินแผ่นทองแดงขนาดเล็กแห่งดิเอ็งและอภัยมุขะ

### ส่วนที่ 2: วิวัฒนาการทฤษฎี ข้อถกเถียงทางวิชาการ และพรมแดนความรู้ล่าสุดถึงปี 2026

ประวัติศาสตร์นิพนธ์จารึกวิทยาว่าด้วยชวากลางและรัฐโบราณรุ่นแรกในอินโดนีเซียได้ผ่านการรื้อถอนและสร้างกระบวนทัศน์ใหม่หลายระลอกตลอดหนึ่งศตวรรษที่ผ่านมา โดยสามารถประมวลข้อถกเถียงหลักและพรมแดนความรู้ล่าสุดได้ 5 มิติสำคัญ:

#### 1. ข้อถกเถียงเรื่องกำเนิดรัฐและกระบวนการภารตภิวัตน์ (Indianization vs. Localization)
ในยุคอาณานิคม Hendrik Kern (1882) และต่อมา R.C. Majumdar (1937) ในแนวคิด Greater India มองการปรากฏของจารึกภาษาสันสกฤตในกูไตและตารูมานครว่าเป็นผลมาจากการตั้งอาณานิคมของชาวอินเดียโพ้นทะเล ทว่างานชำระตัวบทแม่บทของ J. Ph. Vogel (1918) ได้นำเสนอจุดเปลี่ยนสำคัญโดยชี้ให้เห็นความแตกต่างของพระนามสามชั่วรุ่นในจารึกเสายูปะหลัก A: พระอัยกา "กุณฑุงคะ" (Kuṇḍuṅga) เป็นนามภาษาพื้นเมืองออสโตรนีเซียนดั้งเดิมของเกาะบอร์เนียวอย่างชัดเจน ขณะที่พระราชโอรส "อัศววรมัน" (Aśvavarman) ผู้ได้รับยกย่องเป็น "ผู้สร้างวงศ์" (vaṅśakartr̥) และพระราชนัดดา "มูลวรมัน" (Mūlavarman) ทรงใช้พระนามสันสกฤตตามคติราชันย์ฮินดู Vogel จึงเสนอทฤษฎี "การซึมซับทางวัฒนธรรมอย่างสันติ" (Peaceful Penetration) ซึ่งคณะพราหมณ์ชั้นสูงเดินทางข้ามสมุทรมาประกอบพิธียัญกรรม (viprair ihāgataiḥ) ให้แก่ผู้นำพื้นเมืองที่เปิดรับวัฒนธรรมอินเดียเพื่อยกระดับความชอบธรรมทางการเมือง ยิ่งไปกว่านั้น Vogel ยังได้เสนอให้ยกเลิกการใช้คำว่า "อักษรเวงคี" (Vengi alphabet) ที่ Burnell เคยบัญญัติไว้ แล้วสถาปนาคำว่า "อักษรปัลลวะ" (Pallava script) หรือ "ครันถะศิลาแบบโบราณ" (Archaic Lithic Grantha) ขึ้นแทนที่ ซึ่งกลายมาเป็นมาตรฐานสากลของจารึกวิทยาเอเชียตะวันออกเฉียงใต้จวบจนปัจจุบัน

#### 2. วิวาทะว่าด้วยโครงสร้างราชวงศ์ชวากลาง: ทฤษฎีสองราชวงศ์ปรปักษ์ ปะทะ ทฤษฎีราชวงศ์เดียว
ตลอดช่วงครึ่งหลังของศตวรรษที่ 20 วงการประวัติศาสตร์ชวากลางถูกครอบงำด้วยข้อถกเถียงระหว่าง 2 สำนักคิด:
- *ทฤษฎีสองราชวงศ์ปรปักษ์ (Two-Dynasty Theory):* นำเสนออย่างเป็นระบบโดย J.G. de Casparis (1950, 1956) โดยต่อยอดจาก F.D.K. Bosch (1928) และ Van Naerssen (1947) ซึ่งเสนอว่าระหว่าง ค.ศ. 750–850 ชวากลางปกครองโดย 2 ราชวงศ์ที่เป็นปรปักษ์กันทางเชื้อชาติและศาสนา คือ "ราชวงศ์ไศเลนทร์" ผู้นับถือพุทธศาสนามหายาน-วัชรยาน มีอำนาจเหนือที่ราบลุ่มเกอดูและสร้างมหาศาสนสถานบุโรพุทโธ กะลาซัน เซวู ปะทะกับ "ราชวงศ์สัญชัย" ผู้นับถือฮินดูไศวนิกาย มีฐานอำนาจแถบที่ราบสูงเดียง ความขัดแย้งคลี่คลายลงด้วยการอภิเษกสมรสทางการเมืองระหว่างเจ้าหญิงปรโมทวรรธนีแห่งไศเลนทร์กับราไก ปิกาตัน แห่งสัญชัย ก่อนจะปะทุเป็นสงครามขับไล่เจ้าชายบาลปุตระใน ค.ศ. 856
- *ทฤษฎีราชวงศ์เดียวพื้นถิ่น (Single Indigenous Dynasty Theory):* เสนอโดย R.M.Ng. Poerbatjaraka (1958) และได้รับการสนับสนุนอย่างหนักแน่นโดย Boechari (1966, 1986) จากการค้นพบศิลาจารึกโซโจเมร์โต ซึ่งระบุพระนาม "ดาปุนตะ ไศเลนทระ" (Dapūnta Selendra) ว่าเป็นปฐมกษัตริย์ผู้สร้างวงศ์และนับถือศาสนาฮินดูไศวนิกาย Boechari พิสูจน์ว่าในชวากลางมีราชวงศ์ผู้ปกครองเพียงราชวงศ์เดียวคือ "ราชวงศ์ไศเลนทร์" โดยพระมหากษัตริย์ในสายตระกูลนี้ได้เปลี่ยนไปนับถือพุทธศาสนามหายานในรัชสมัยราไก ปนังกะรัน ขณะที่คำว่า "ราชวงศ์สัญชัย" (Sanjayavaṃśa) เป็นคำประดิษฐ์ยุคใหม่ที่ไม่เคยมีปรากฏในจารึกโบราณ มีเพียงการนับศักราชสัญชัย (Sañjayavarṣa) เท่านั้น

#### 3. การปฏิวัติประวัติศาสตร์ลำดับกษัตริย์: จุดเปลี่ยนจากจารึกวานัวเตองะฮ์ 3 (1994)
การค้นพบจารึกแผ่นทองแดงวานัวเตองะฮ์ 3 เมื่อปลายปี ค.ศ. 1983 และการตีพิมพ์วิเคราะห์เชิงลึกโดย Kusen (1994) ควบคู่กับการคำนวณปฏิทินดาราศาสตร์คอมพิวเตอร์โดย Trigangga (1994) ได้สั่นสะเทือนโครงสร้างประวัติศาสตร์ชวากลางอย่างถอนรากถอนโคน จารึกหลักนี้ให้ลำดับกษัตริย์มตารามโบราณ 12 รัชกาลพร้อมระบุวัน เดือน มหาศักราช และรอบวันทางจันทรคติที่ขึ้นครองราชย์อย่างแม่นยำตั้งแต่ ค.ศ. 746 ถึง 908 ข้อมูลดังกล่าวได้เปิดเผยความจริงว่า จารึกมันตยาสิห์ 1 (Mantyasih I 907 CE) ของพระเจ้าบาลิตุง ซึ่งเคยเป็นหลักฐานหลักของวงการ มิใช่ผังลำดับเครือญาติทางสายเลือด (genealogy) หากแต่เป็นเอกสารคัดสรรเพื่อสร้างความชอบธรรมทางการเมืองของกษัตริย์ โดยจารึกวานัวเตองะฮ์ 3 ได้เปิดเผยพระนามกษัตริย์ 4 พระองค์ที่ถูกจารึกมันตยาสิห์ลบเลือนออกไป ได้แก่ พระยาห์ กูลา (Dyah Gula ครองราชย์ 6 เดือน), พระยาห์ ตักวาส (Dyah Tagwas ครองราชย์ 8 เดือน), ราไก ปานุมวางัน พระยาห์ เดเวนทระ (Rake Panumwangan Dyah Dewendra ครองราชย์ 1 ปี 4 เดือน), และราไก กูรุนวางี พระยาห์ ภัทระ (Rake Gurunwangi Dyah Bhadra ครองราชย์ 28 วัน) พร้อมทั้งระบุภาวะสุญญากาศทางการเมืองยาวนานเกือบ 8 ปี (ค.ศ. 887–894) ที่แผ่นดินไร้กษัตริย์ (anāyaka ta ikanang rāt) ภายหลังราไก กูรุนวางี เสด็จหนีทิ้งราชวัง (minggat)

#### 4. การรื้อถอนเรื่องเล่าประวัติศาสตร์ชาตินิยม: กรณีจารึกสังกะระ (Griffiths 2021)
พรมแดนความรู้ที่พลิกผันอย่างถึงรากที่สุดในทศวรรษปัจจุบัน คือการชำระตัวบทศิลาจารึกภาษาสันสกฤตแห่งสังกะระ (Prasasti Śaṅkara) โดย Arlo Griffiths (2021) ซึ่งได้ทำลายโครงเรื่องประวัติศาสตร์กระแสหลักที่ Boechari (1975, 1986) วางรากฐานไว้ในแบบเรียนประวัติศาสตร์แห่งชาติอินโดนีเซีย (*Sejarah Nasional Indonesia* เล่ม 2) ที่อ้างว่า "เจ้าชายสังกะระคือราไก ปนังกะรัน ผู้ทรงละทิ้งศาสนาฮินดูไศวนิกายไปนับถือพุทธศาสนามหายาน เนื่องจากพระราชบิดาสิ้นพระชนม์ด้วยไข้พิษแปดวันโดยคุรุไศวะรักษาไม่ได้" Griffiths พิสูจน์ด้วยหลักภาษาศาสตร์และฉันทลักษณ์สันสกฤตว่า:
1. ตัวเอกในจารึกมีนามว่า "สังกะระ" (Śaṅkara) มิใช่กษัตริย์ และมิใช่บุคคลเดียวกับราไก ปนังกะรัน พระนาม Panaṅkaran ในภาษาชวาโบราณมีศัพทมูลมาจากคำว่า *sǝṅkǝr* (ขอบเขตพระบรมราชโองการ) มิได้แผลงมาจาก Śaṅkara แต่อย่างใด
2. สังกะระมิได้เปลี่ยนศาสนาไปเป็นพุทธ ข้อความในคาถาที่ 3 *so ’yan tyaktānyabhaktir jagadaśivaharāc chaṅkarāc chaṅkarākhyaḥ* เป็นสมาสพหุพพิหิ แปลว่า "ผู้ไม่มีความภักดีอื่นใด นอกเหนือไปจากพระสังกะระ (พระศิวะ)" และวลี *an-ṛta-guru-bhayas* แปลว่า "ผู้เกรงกลัวอย่างยิ่งต่อการตระบัดสัตย์" มิใช่ "กลัวครูชั่ว" (anṛta-guru) ตามที่ Boechari เข้าใจผิด
3. สังกะระสร้างเทวสถานพระศิวะเพื่ออุทิศกุศลแด่บิดาผู้ล่วงลับตามคำมั่นสัญญาด้วยทองคำ 6 สุวรรณ และจารึกหลักนี้คือ "จารึกภาษาสันสกฤตระดับเอกชน/นักบวช" (non-royal Sanskrit inscription) ซึ่งหักล้างทั้งทฤษฎีการเปลี่ยนขั้วศาสนาแบบแยกขาด (Sectarian Zero-Sum) และกรอบคิดกษัตริย์เป็นศูนย์กลาง (Royalist Bias)

#### 5. ภูมิทัศน์ศักดิ์สิทธิ์ ปรัมบานันในนาม "ลงกาปุระ" และระบบจักรวาลวิทยา 24 เทพ (2011–2026)
การค้นพบของ Arlo Griffiths (2011) เรื่อง "Imagine Laṅkapura at Prambanan" ได้สถาปนาข้อเท็จจริงใหม่ว่า มหาเทวสถานปรัมบานันมีชื่อแท้จริงในจารึกร่วมสมัยศตวรรษที่ 9 (จารึกราตูโบโก F และจารึกเปอเร็ง 863 CE) ว่า "ลงกาปุระ" หรือ "ลงกาปุระแห่งทิศบูรพา" (*pūrvvaṃ laṅkapuram*) ซึ่งเป็นการจำลองภูมิศาสตร์ศักดิ์สิทธิ์จากมหากาพย์รามายณะลงสู่แผ่นดินชวากลาง สอดรับกับการกำเนิดขึ้นของวรรณคดีกากาวินรามายณะ (KR) และบทบาทของเจ้าผู้ครองแคว้นวะไลค์ "ปู กุมภโยนิ" (Pu Kumbhayoni) ผู้เปรียบประดุจพระมหาฤษีอคัสตยะแห่งเทือกเขาวินธัย (เนินเขาราตูโบโก) ซึ่งมิใช่บุคคลเดียวกับราไก ปิกาตัน ตามที่ Casparis เคยเข้าใจผิด  
ขณะเดียวกัน Andrea Acri และ Roy Jordaan (2012) ร่วมกับหลักฐานการค้นพบวัตถุจารึกและกรุเปอริปิฮ์ล่าสุดที่จันทิกิมปูลันและริงงินลาริก (Savitri, Acri, & Noerwidi 2024) ได้พิสูจน์ระบบจักรวาลวิทยาไศวนิกายชั้นสูง 24 + 2 + 1 องค์ (โลกบาล 8 + ทิกพันธะ 8 + ทิศแทรก 8 + พระวิษณุเบื้องบน + พระพรหมเบื้องต่ำ + พระศิวะศูนย์กลาง) ซึ่งปรากฏตรงกันทั้งบนแผงภาพสลักหินจันทิพระศิวะ แผ่นทองคำจารึกใต้ฐานเทวาลัย และคัมภีร์ตูตูร์ชวาโบราณ (*Bhuvanasaṅkṣepa*, *Dharma Pātañjala*)

### ส่วนที่ 3: ข้อค้นพบใหม่และมิติที่ตกหล่นจากโครงร่างเดิม

จากการตรวจสอบโครงร่างเดิมในเอกสารแม่บท (`outline-proposal.md` บทที่ 2) พบว่ามี "จุดบกพร่องเชิงโครงสร้าง" และ "ช่องว่างทางวิชาการที่ขัดแย้งกับหลักฐานเชิงประจักษ์" อย่างมีนัยสำคัญ 6 ประการ ซึ่งจำเป็นต้องได้รับการแก้ไขและรื้อสร้างใหม่ในรายงานฉบับนี้:

1. **โครงร่างเดิมนำข้อมูลข้ามยุคสมัยและข้ามภูมิภาคมายัดเยียดรวมกันในบทเดียว:**  
   โครงร่างเดิมในบทที่ 2 นำเอาจารึกยุคแรก (กูไต, ตารูมานคร), จารึกชวากลาง (จังกัล, โซโจเมร์โต, บุโรพุทโธ, ปรัมบานัน, วานัวเตองะฮ์ 3), จารึกจักรวรรดิทางทะเลศรีวิชัยแห่งสุมาตรา (เกอดูกันบูกิต, ตาลังตูโว, โกตากาปูร์, เตลากาบาตู), จารึกการย้ายศูนย์อำนาจสู่ชวาตะวันออก (ซังงูรัน, ปูกังงัน), และจารึกยุคสิงหัดส่าหรี-มัชปาหิต มาบรรจุไว้ในบทเดียวกัน ทำให้เนื้อหาขาดเอกภาพอย่างรุนแรง และทับซ้อนกับโดเมนเฉพาะทางอื่นๆ (โดเมน 3 ศรีวิชัย และโดเมน 5 ชวาตะวันออก) อย่างไม่สมเหตุสมผล
2. **การยึดถือข้อมูลผิดพลาดเรื่องจารึกสังกะระตามประวัติศาสตร์ชาตินิยมเดิม:**  
   ในหัวข้อย่อย 2.3 ของโครงร่างเดิมระบุข้อความว่า: *"จารึกสังกะระ (Saṅkara Sanskrit Inscription, Griffiths 2021): หลักฐานปฏิวัติประวัติศาสตร์ว่าด้วยเจ้าชายสังกะระผู้ละทิ้งศาสนาพุทธกลับคืนสู่ไศวนิกาย"* ข้อความนี้ขัดแย้งกับงานวิจัยของ Griffiths (2021) โดยสิ้นเชิง เพราะ Griffiths พิสูจน์อย่างชัดเจนว่า สังกะระมิใช่เจ้าชายหรือกษัตริย์ มิใช่ราไก ปนังกะรัน และมิได้เปลี่ยนศาสนาจากพุทธกลับสู่ไศวะหรือจากไศวะไปสู่พุทธแต่อย่างใด หากแต่เป็นนักบวชไศวะที่ภักดีต่อพระศิวะมาโดยตลอด โครงร่างเดิมจึงตกค้างอยู่กับข้อผิดพลาดของ Boechari ในปี 1975
3. **การตกหล่นของมิติภูมินามวิทยา "ลงกาปุระ" และกลุ่มจารึกกุมภโยนิ:**  
   โครงร่างเดิมกล่าวถึงจันทิปรัมบานันและจารึกศิวคฤหะ (856 CE) ในเชิงสงครามกลางเมืองและการสร้างเทวสถานเท่านั้น แต่ละเลยข้อค้นพบปฏิวัติของ Griffiths (2011) เรื่องนามดั้งเดิม "ลงกาปุระ" (*Laṅkāpura*) และการจำลองภูมิศาสตร์ศักดิ์สิทธิ์ขนานกับมหากาพย์รามายณะ ตลอดจนละเลยบทบาทของกลุ่มจารึกปูกุมภโยนิแห่งแคว้นวะไลค์บนราตูโบโก ซึ่งเป็นดุลอำนาจคู่ขนานสำคัญในชวากลาง
4. **การละเลยมิติระบบจักรวาลวิทยาไศวนิกายและจารึกแผ่นทองคำกรุเปอริปิฮ์:**  
   โครงร่างเดิมมิได้บรรจุข้อค้นพบเรื่องระบบเทพ 24 องค์ของ Acri & Jordaan (2012) และงานวิจัยล่าสุดปี 2024 ของ Savitri, Acri, & Noerwidi เกี่ยวกับจารึกแผ่นทองคำกรุเปอริปิฮ์ที่จันทิกิมปูลันและริงงินลาริก ซึ่งเป็นหลักฐานสำคัญที่สุดที่เชื่อมโยงระหว่างจารึกแผ่นโลหะ คัมภีร์ไศวาคม และประติมากรรมหินสถาปัตยกรรม
5. **การขาดหายไปของมิติชลศาสตร์ ภัยพิบัติทางธรรมชาติ และจารึกค้นพบใหม่รอบภูเขาไฟเมอราปี:**  
   โครงร่างเดิมขาดมิติทางธรณีโบราณคดีและชลศาสตร์ ซึ่งในรอบสองทศวรรษที่ผ่านมามีการขุดค้นพบแหล่งโบราณสถานสำคัญที่จมอยู่ใต้เถ้าถ่านภูเขาไฟเมอราปี ได้แก่ จันทิเกอดูลัน ซึ่งค้นพบจารึกสำคัญถึง 3 หลัก (ปานังการัน 869 CE, สุมุนดุล 869 CE, และตลูโรน 900 CE) บันทึกวิศวกรรมการสร้างฝายทดน้ำ (ḍawuhan) ลำคลองส่งน้ำ (wluran) เพื่อนาข้าวและการอุปถัมภ์ศาสนสถานหลวง ตลอดจนจารึกรูกัม (Rukam 907 CE ใน DHARMA-DOSS-02) ที่บันทึกเหตุการณ์ภัยพิบัติภูเขาไฟระเบิด (guntur) ทำลายหมู่บ้านจนต้องย้ายและสถาปนาสีมาใหม่
6. **การละเลยมิติสังคม วัฒนธรรมชาวบ้าน และมหรสพศักดิ์สิทธิ์ในจารึก:**  
   โครงร่างเดิมเน้นหนักเฉพาะประวัติศาสตร์การเมืองราชสำนักระดับบน แต่ละเลยมิติทางสังคม วัฒนธรรมวิถีชีวิต มหรสพ และกลุ่มอาชีพการแสดงในพิธีสีมา (vidu, pirus, mabañol) ซึ่งสะท้อนอยู่ในจารึกซังซัง (Sangsang 907 CE) และการศึกษาของ Acri (2014)

### ส่วนที่ 4: พิมพ์เขียวโครงสร้างบทและหัวข้อย่อยฉบับปรับปรุงใหม่

เพื่อแก้ไขข้อบกพร่องเชิงโครงสร้างและบูรณาการข้อมูลเชิงประจักษ์ล่าสุดถึงปี 2026 จึงขอเสนอพิมพ์เขียวโครงสร้างบทของโดเมนที่ 2 โดยปรับปรุงชื่อบทและจัดแบ่งหัวข้อย่อยระดับลึกออกเป็น 8 ประเด็นหลักดังต่อไปนี้:

#### ชื่อบทที่เสนอใหม่ (Proposed Chapter Title):
> **บทที่ 2: รุ่งอรุณแห่งอักขรวิทยาและการก่อรูปศูนย์กลางอำนาจในชวากลาง: จากศิลายูปะกูไตและตารูมานคร สู่มหาอาณาจักรมะตะรัม-ไศเลนทร์ (คริสต์ศตวรรษที่ 5–10)**  
> *(The Dawn of Epigraphy and State Formation in Central Java: From Kutai Yūpa and Tarumanagara to the Mataram-Śailendra Imperium, 5th–10th Centuries CE)*

#### หัวข้อย่อยระดับลึก (Detailed Section Architecture):

- **2.1 รุ่งอรุณแห่งจารึกวิทยาและกระบวนการกลายเป็นอินเดียในกาลีมันตัน: กลุ่มจารึกเสายูปะแห่งกูไต (Kutai Yūpa Corpus, ca. 400–450 CE)**
  * การวิเคราะห์ตัวบทภาษาสันสกฤตฉันทลักษณ์คลาสสิกบนเสาหินแอนดีไซต์ธรรมชาติ 7 หลักแห่งมูอารา กามัน ริมแม่น้ำมหาคัม
  * การรื้อถอนมโนทัศน์ "อักษรเวงคี" สู่การสถาปนา "อักษรปัลลวะตอนต้น" ของ J. Ph. Vogel (1918)
  * สายสัมพันธ์พงศาวลีสามชั่วรุ่น: พระอัยกากุณฑุงคะ (Kuṇḍuṅga) นามพื้นเมืองบอร์เนียว สู่ท้าวอัศววรมัน (Aśvavarman) ผู้สร้างราชวงศ์ (vaṅśakartr̥) และพระเจ้ามูลวรมัน (Mūlavarman)
  * ยัญพิธีเวทพหุสุวรรณกะ (Bahusuvarṇaka yajña), ศาสนสถานศักดิ์สิทธิ์วปรเกศวร (Vaprakeśvara), และบทบาทของคณะพราหมณ์โพ้นทะเล (viprair ihāgataiḥ)
  * วัตถุวิทยาของเสายูปะ: การแปลงหน้าที่จากเสาไม้ผูกสัตว์บูชายัญตามคัมภีร์พระเวทสู่เสาอนุสรณ์หินถาวร (lithic kīrti-stambha)

- **2.2 ปริศนาตารูมานครและวิศวกรรมชลศาสตร์ชายฝั่งทะเลในชวาตะวันตก (Tarumanagara Epigraphy, ca. 5th Century CE)**
  * กลุ่มจารึกพระเจ้าปูรณวรมัน (Pūrṇavarman): จารึกจียารูเติน (รอยพระพุทธบาทจำลองเป็นรอยบาทพระวิษณุ), เกอบอนโกปี (รอยเท้าช้างเอราวัณ), จัมบู, และจีดังฮียัง
  * ศิลาจารึกตูกู (Tugu Inscription): การขุดลอกคลองจันทราภาและคลองโกมตี 6,122 คันธนูลงสู่อ่าวทะเล และการถวายทักษิณาทานโคพันตัวแก่พราหมณ์
  * สถาปัตยกรรมอักษรปัลลวะหัวกล่อง (box-head script) กับการสถาปนาอำนาจรัฐชลประทานชายฝั่งทะเลรุ่นแรกของชวา

- **2.3 ต้นกำเนิดราชวงศ์ไศเลนทร์ ภูมิทัศน์ชายฝั่ง และการจัดระเบียบศาสนธรรมในชวากลาง (The Śailendra Genesis & Early Matrix)**
  * ศิลาจารึกโซโจเมร์โต (Sojomerto Inscription): การค้นพบของ Boechari (1966) ว่าด้วย ดาปุนตะ ไศเลนทระ (Dapūnta Selendra), เทววิทยาไศวนิกาย (namah śśivāya), ผีบรรพชนฮียัง...มิฮ์ (Hiyaṅ ...-mih), และการใช้ภาษามลายูโบราณบนชายฝั่งตอนเหนือ (บาตัง)
  * การรื้อถอน "ทฤษฎีสองราชวงศ์ปรปักษ์" สู่ทฤษฎีราชวงศ์เดียวพื้นถิ่นของ Poerbatjaraka และ Boechari
  * ปริศนาจารึกจังกัล (Canggal 732 CE / มหาศักราช 654): การประดิษฐานศิวลึงค์บนภูเขาวูกีร์โดยพระเจ้าสัญชัย (Sañjaya) และการนับศักราชสัญชัย (Sañjayavarṣa)
  * การปฏิวัติประวัติศาสตร์นิพนธ์จารึกสังกะระ (Śaṅkara Inscription, Griffiths 2021): การหักล้างมายาคติเรื่องการเปลี่ยนศาสนาของราไก ปนังกะรัน, การพิสูจน์สถานะจารึกระดับเอกชนของกวีไศวนิกาย, และการอุปถัมภ์ร่วม (Joint Patronage)

- **2.4 พุทธศาสนามหายาน-วัชรยาน มหาเจดีย์บุโรพุทโธ และมณฑลศักดิ์สิทธิ์ยุคไศเลนทร์รุ่งโรจน์ (Mahāyāna-Vajrayāna & The Borobudur Nexus)**
  * จารึกกะลาซัน (Kalasan 778 CE / DHARMA XML) และจารึกเกอลูรัก (Kelurak 782 CE): การสถาปนาวิหารพระนางตาราและเทวรูปมัญชุศรีภายใต้อิทธิพลพระอาจารย์กุมารโฆษแห่งเบงกอล
  * การถอดรหัสบุโรพุทโธในฐานะ `kamūlān i bhūmisambhāra` (วิหารบรรพชนหลวงบนภูเขาแห่งการบำเพ็ญบารมี 10 ขั้น) ตามจารึกศรีคาฮูลุนนัน (ตรูอีเตอปุสซัน II 842 CE) ของ De Casparis (1950)
  * จารึกการังเตองะฮ์ (Karangtengah 824 CE): การสร้างวิหารเวณุวนะและจินาลัยโดยพระเจ้าสมรตุงคะและเจ้าหญิงปรโมทวรรธนี
  * จารึกภาษามลายูโบราณกัณดสุลี 1 (Gaṇḍasuli 832 CE): สถานภาพของภาษามลายูโบราณในฐานะภาษาราชสำนักและภาษากลางในดินแดนตอนในของชวากลาง (เตอมังกุง)
  * ปริศนาฐานชั้นในที่ถูกถมของบุโรพุทโธ (Bedolven voet) และจารึกสั้น 160 ช่องกำกับภาพสลักมหากรรมวิภังค์

- **2.5 วิกฤตการณ์การเมือง ค.ศ. 856: ป้อมค่ายบาลปุตระ การสถาปนามหาราชธานีเมดัง และมหาเทวสถานศิวาลัย (ปรัมบานัน)**
  * การถอดรหัสวรรณคดีร้อยกรองภาษาชวาโบราณในจารึกศิวคฤหะ (Śivagṛha Inscription 856 CE): ศึกป้อมหินซ้อนร้อยชั้น (watun inatus) บนที่สูงราตูโบโก และการลี้ภัยของเจ้าชายบาลปุตระสู่ราชบัลลังก์ศรีวิชัย (จารึกแผ่นทองแดงนาลันทา ค.ศ. 860)
  * การสละราชสมบัติของราไก ปิกาตัน (ชาติเนิงรัต) และการขึ้นครองราชย์ของดยัฮ โลกาปาละ (ราไก กายุวังกี)
  * การสถาปนาราชธานีแห่งใหม่ "เมดัง ณ มัมราติปุระ" (mamratipurastha maḍang kaḍatwan)
  * สถาปัตยกรรมมหาเทวสถานศิวาลัย (ปรัมบานัน) และอภิมหาวิศวกรรมชลศาสตร์ผันแม่น้ำโอปัก (luaḥ ya inaliḥhaken)

- **2.6 การจำลองภูมิศาสตร์ศักดิ์สิทธิ์ นามดั้งเดิม "ลงกาปุระ" และเครือข่ายอำนาจปูกุมภโยนิ (Laṅkāpura & The Kumbhayoni Hegemony)**
  * ข้อค้นพบเชิงปฏิวัติของ Arlo Griffiths (2011): การพิสูจน์นามดั้งเดิมของมหาเทวสถานปรัมบานันในฐานะ "ลงกาปุระแห่งทิศบูรพา" (*pūrvvaṃ laṅkapuram*)
  * การศึกษาเปรียบเทียบสองภาษาในกลุ่มจารึกกุมภโยนิ (Kumbhayoni Corpus): จารึกลึงค์ราตูโบโก A–F (856–857 CE), จารึกเปอเร็ง (Pereng 863 CE), และจารึกดะวังซารี (Dawangsari)
  * การจำลองภูมิศาสตร์มหากาพย์รามายณะ: ที่ราบสูงราตูโบโกในฐานะ "เทือกเขาวินธัย" (Vindhya) และปูกุมภโยนิแห่งแคว้นวะไลค์ในฐานะ "พระมหาฤษีอคัสตยะ"
  * ความร่วมสมัยของวรรณกรรมร้อยกรองชวาโบราณ: ความสัมพันธ์ระหว่างจารึกศิวคฤหะ จารึกกุมภโยนิ และการรจนาวรรณคดี *กากาวินรามายณะ* (Kakawin Rāmāyaṇa สรรคที่ 8)

- **2.7 มณฑลจักรวาลวิทยาไศวนิกายและเทววิทยาวัตถุบรรจุกรุฐานเทวาลัย (Cosmology & Consecration Deposits)**
  * การถอดรหัสระบบประติมานวิทยาเทพ 24 องค์บนระเบียงจันทิพระศิวะ ปรัมบานัน (Acri & Jordaan 2012): การสังเคราะห์ชุดเทพโลกบาล 8 องค์, ทิกพันธะ/นวสังคะ 8 องค์, และเทพคั่นกึ่งกลางทิศ 8 องค์
  * หลักฐานเชิงประจักษ์ใหม่จากวัตถุมงคลบรรจุกรุฐานเจดีย์ (Peripih, Savitri, Acri, & Noerwidi 2024): ผอบหิน 17 ช่องพร้อมดอกบัวทองคำ 8 กลีบแห่งจันทิกิมปูลัน และแผ่นทองคำจารึกนามเทพ 22 แผ่นแห่งริงงินลาริก โบโยลาลี
  * การตรวจพิสูจน์ทางวิทยาศาสตร์โบราณคดี: ผลการวิเคราะห์องค์ประกอบธาตุโลหะวิทยา p-XRF และ Principal Component Analysis (PCA)
  * มณฑลจักรวาล 3 มิติและการเชื่อมโยงสู่คัมภีร์ตูตูร์ชวาโบราณ (*Bhuvanasaṅkṣepa*, *Dharma Pātañjala*)

- **2.8 ลำดับกษัตริย์มตารามโบราณ ภูมิทัศน์ชลศาสตร์ และการจัดการสถาบันสีมา (Wanua Tengah III & Hydraulic Archaeology)**
  * การชำระลำดับกษัตริย์มตาราม 12–13 รัชกาลจากจารึกวานัวเตองะฮ์ 3 (Wanua Tengah III 908 CE) เทียบกับจารึกมันตยาสิห์ 1 (Mantyasih I 907 CE) โดย Kusen (1994) และ Trigangga (1994)
  * พลวัตสถาบันสีมา: ประวัติศาสตร์ 162 ปีแห่งการสถาปนา เพิกถอน และฟื้นฟูสิทธิ์ที่ดินนาอารามพิกาตัน
  * โบราณคดีชลศาสตร์และภัยพิบัติภูเขาไฟเมอราปี: กลุ่มจารึกจันทิเกอดูลัน (จารึกสุมุนดุล, ปานังการัน ค.ศ. 869, และจารึกตลูโรน ค.ศ. 900) กับวิศวกรรมฝายทดน้ำ (ḍawuhan) และคลองส่งน้ำ (wluran)
  * ภัยพิบัติทางธรรมชาติและการย้ายศูนย์กลางอำนาจ: จารึกรูกัม (Rukam 907 CE / DHARMA XML) ว่าด้วยการทำลายล้างของภูเขาไฟระเบิด (guntur) และวิถีชีวิตมหรสพในจารึกซังซัง (Sangsang 907 CE, Acri 2014)

  > "มีองค์ท่านผู้ล่วงลับสถิต ณ ฮารา พระนามของพระองค์ ทรงเป็นพระอนุชาขององค์ท่านผู้ล่วงลับสถิต ณ เมดัง พระองค์ทรงสร้างพระวิหาร ณ พิกาตัน... ครั้นถึงมหาศักราช 668 เดือนอาศวิน ขึ้น 15 ค่ำ วันปานิรวน ปาฮิง อังคาร ราไก ปานังการัน ได้ขึ้นครองราชย์ พระองค์ได้ทรงน้อมถวายที่ดินนาหลวงอันว่างเปล่า ณ วานัวเตองะฮ์ ในแคว้นพิกาตัน ให้แก่วิหาร ณ พิกาตันนั้น... ครั้นถึงมหาศักราช 706 เดือนไจตระ ขึ้น 10 ค่ำ ราไก ปานาราบัน ได้ขึ้นครองราชย์ ก็มิได้ทรงแตะต้องเปลี่ยนแปลงที่ดินนานั้น..."

##### (9) จารึกมันตยาสิห์ 1 แผ่นที่ 1 บรรทัดที่ 7–9 (Mantyasih I 907 CE, DHARMA XML)
- **ตัวบทภาษาชวาโบราณ (IAST):**
  > ...rahyaṅta rumuhun· riṁ mḍaṁ ri poḥ pitu, rakai mataryam· saṁ ratu sañjaya, śrī mahārāja rakai panaṅkaran·, śrī mahārāja rakai panuṅgalan·, śrī mahārāja rakai varak·, śrī mahārāja rakai garuṅ·, śrī mahārāja rakai pikatan·, śrī mahārāja rakai kayu vaṅi, śrī mahārāja rakai vatu humalaṁ, dyaḥ balituṁ...
- **คำแปลวิชาการภาษาไทย:**
  > "...เหล่าองค์บูรพกษัตริย์ผู้ล่วงลับแห่งเมดัง ณ โปฮ์ปิตู: ราไก มาตาราม สัง ราตู สัญชัย, พระศรีมหาราชา ราไก ปานังการัน, พระศรีมหาราชา ราไก ปานุงกาลัน, พระศรีมหาราชา ราไก วารัก, พระศรีมหาราชา ราไก การุง, พระศรีมหาราชา ราไก ปิกาตัน, พระศรีมหาราชา ราไก กายุวังกี, พระศรีมหาราชา ราไก วาตูฮูมาลัง, [และพระองค์ผู้ทรงครองราชย์บัดนี้] พระยาห์ บาลิตุง..."

#### 2. อภิธานศัพท์เฉพาะทางด้านจารึกวิทยาและประวัติศาสตร์สถาบัน (Technical Glossary)

| คำศัพท์เฉพาะทาง | ภาษาเดิม | ความหมายทางจารึกวิทยาและบริบทการใช้งานในโดเมนที่ 2 |
| :--- | :--- | :--- |
| **Yūpa (ยูปะ)** | สันสกฤต | เสาบูชายัญตามคัมภีร์พระเวท ในจารึกกูไตหมายถึงแท่งหินแอนดีไซต์ธรรมชาติสกัดหยาบที่สร้างขึ้นเป็นเสาอนุสรณ์สถานแห่งบุญนิรันดร์ (*kīrti-stambha*) |
| **Bahusuvarṇaka** | สันสกฤต | มหายัญพิธีอันมีทองคำเป็นทักษิณาทานอย่างล้นเหลือ สัมพันธ์กับโสมยัญพหุหิรัณยะ สะท้อนความมั่งคั่งมหาศาลของราชสำนักกูไตริมแม่น้ำมหาคัม |
| **Vaprakeśvara** | สันสกฤต | ลานพิธีกรรมศักดิ์สิทธิ์หรือเทวสถานแห่งพระศิวะ (Vapraka + Īśvara) ในกูไต ซึ่งต่อมาส่งอิทธิพลสู่จารึกชวาโบราณในฐานะเทพารักษ์พยานศักดิ์สิทธิ์ (*Baprakeśvara*) |
| **Vaṅśakartr̥ / Vaṃśakara** | สันสกฤต | ผู้สถาปนาพระราชวงศ์ ในจารึกกูไตใช้เฉลิมพระเกียรติท้าวอัศววรมัน และในจารึกโซโจเมร์โตใช้หมายถึงดาปุนตะ ไศเลนทระ |
| **Viprair ihāgataiḥ** | สันสกฤต | "โดยเหล่าพราหมณ์ผู้เดินทางมาถึงที่นี่" วลีสำคัญในจารึกกูไตหลัก B ยืนยันการเดินทางข้ามสมุทรของพราหมณ์จากอินเดียใต้สู่บอร์เนียว |
| **Śailendravaṃśa** | สันสกฤต | ราชวงศ์ไศเลนทร์ ("วงศ์แห่งเจ้าขุนเขา") มหาราชวงศ์ผู้ปกครองชวากลางและศรีวิชัย ผู้สร้างมหาเจดีย์บุโรพุทโธ กะลาซัน และเซวู |
| **Kamūlān** | ชวาโบราณ | ศาสนสถานต้นกำเนิดบรรพบุรุษหลวงของราชวงศ์ (ancestral origin sanctuary) แผลงมาจากรากศัพท์ *mūla* (รากเหง้า/จุดกำเนิด) |
| **Bhūmisambhāra** | สันสกฤต | การสั่งสมเสบียงบุญญาบารมีบนภูมิทั้ง 10 แห่งพระโพธิสัตว์ ปรากฏในจารึกศรีคาฮูลุนนัน ค.ศ. 842 ซึ่งเป็นที่มาทางนิรุกติศาสตร์ของชื่อ *Barabuḍur* |
| **Śivagṛha / Śiwālaya** | สันสกฤต | "ศิวเคราะห์" หรือ "ศิวาลัย" ที่สถิตแห่งพระศิวะ ปรากฏในจารึก ค.ศ. 856 หมายถึงปรางค์ประธานพระศิวะในกลุ่มมหาเทวสถานปรัมบานัน |
| **Laṅkāpura** | สันสกฤต | นามดั้งเดิมของมหาเทวสถานปรัมบานันและชุมชนโบราณแวดล้อม ปรากฏในรูป *pūrvvaṃ laṅkapuram* ในจารึกเปอเร็งและราตูโบโก F |
| **Kumbhayoni** | สันสกฤต | "ผู้ถือกำเนิดจากหม้อน้ำ" พระนามสมัญญาของพระมหาฤษีอคัสตยะ และเป็นพระนามของเจ้าผู้ครองแคว้นวะไลค์ (Pu Kumbhayoni) บนราตูโบโก |
| **Watun inatus** | ชวาโบราณ | "ก้อนหินซ้อนกันเป็นร้อยๆ ชั้น" วลีในจารึกศิวเคราะห์พรรณนาถึงป้อมปราการหินของฝ่ายเจ้าชายบาลปุตระบนที่ราบสูงราตูโบโก |
| **Anāyaka** | สันสกฤต | ภาวะสุญญากาศทางการเมือง แผ่นดินไร้ผู้นำหรือไร้กษัตริย์ปกครอง ปรากฏในจารึกวานัวเตองะฮ์ 3 ระหว่าง ค.ศ. 887–894 |
| **Minggat** | ชวาโบราณ | กิริยาเสด็จหนีทิ้งราชวัง ใช้บรรยายการสิ้นสุดรัชกาลของราไก กูรุนวางี ในจารึกวานัวเตองะฮ์ 3 ส่งผลให้เกิดความปั่นป่วนทางการเมือง |
| **Sīma / Susuk** | สันสกฤต/ชวา | เขตที่ดินกัลปนาที่ได้รับพระบรมราชานุญาตยกเว้นภาษีหลวง เพื่อนำรายได้ไปบำรุงรักษาศาสนสถานและสาธารณูปโภคอย่างถาวร |
| **Ḍawuhan** | ชวาโบราณ | ทำนบ เขื่อน หรือฝายทดน้ำสำหรับการเกษตรชลประทาน ปรากฏในจารึกสุมุนดุล ปานังการัน และตลูโรน ณ จันทิเกอดูลัน |
| **Wluran** | ชวาโบราณ | ลำรางหรือคลองส่งน้ำชลประทาน ปรากฏในจารึกตลูโรน (ค.ศ. 900) ในการผันน้ำเข้าสู่เทวสถานหลวงเกอดูลัน |
| **Guntur** | ชวาโบราณ | ภัยพิบัติธรรมชาติครั้งรุนแรงจากการปะทุระเบิดของภูเขาไฟเมอราปีและโคลนถล่ม ปรากฏในจารึกรูกัม (ค.ศ. 907) |
| **Peripih / Pripih** | ชวาโบราณ | ผอบหินหรือกรุบรรจุสิ่งศักดิ์สิทธิ์ใต้ฐานเทวสถาน บรรจุแผ่นทองคำจารึกมนตรา อัญมณีนพรัตน์ และรูปเคารพเพื่อปลุกเสกเรือนธาตุ |
| **Vidu / Pirus / Mabañol** | ชวาโบราณ | กลุ่มนักแสดง มหรสพ ขับร้อง กายกรรม และตัวตลก ในพิธีสถาปนาสีมา สัมพันธ์กับนักบวชนอกรีตสายปาศุปตะและกาปาลิกะ |
