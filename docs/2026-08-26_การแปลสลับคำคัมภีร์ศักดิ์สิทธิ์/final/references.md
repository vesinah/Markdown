# บรรณานุกรม

บรรณานุกรมรวมของรายงานฉบับนี้ คัดรวมจากเชิงอรรถท้ายบททั้งเจ็ดบทแล้วรวบรวมรายการซ้ำให้เป็นรายการเดียว จำแนกตามประเภทแหล่งข้อมูลตามมาตรฐานของโครงการ ได้แก่ แหล่งข้อมูลปฐมภูมิ 56 รายการ แหล่งข้อมูลทุติยภูมิ 228 รายการ และแหล่งข้อมูลออนไลน์ 53 รายการ เรียงตามตัวอักษรของภาษาต้นฉบับ ห้ามแปลชื่อเรื่อง
