# Project Plan: การจัดการความศักดิ์สิทธิ์ของตัวบทต้นฉบับผ่านระบบ Gloss/Interlinear และตัวบทสลับคำแปล

## โจทย์วิจัย
ประมวลสถานภาพการศึกษา (state of the art) เชิงเปรียบเทียบระดับโลก ว่าด้วยกลยุทธ์ที่ชุมชนศาสนาและผู้เผยแผ่ใช้รับมือกับ "ตัวบทศักดิ์สิทธิ์ในภาษาต้นฉบับ" เมื่อศาสนาเดินทางสู่พื้นที่ภาษา-วัฒนธรรมอื่น โดยเจาะสองกลยุทธ์หลัก:
1. **Interlinear gloss** — คำอธิบาย/คำแปลแทรกระหว่างบรรทัดของต้นฉบับเดิม (รักษาต้นฉบับบริสุทธิ์)
2. **Alternating/diglot text** — แบ่งตัวบทเดิมเป็นคำ/วรรค/ประโยค เขียนสลับกับคำแปลท้องถิ่น (สร้างตัวบทใหม่ควบคู่ต้นฉบับ)

## คำถามวิจัย 5 ข้อ
1. วิธีจัดการ "ความศักดิ์สิทธิ์" ของตัวบทภาษาดั้งเดิมควบคู่การทำให้อ่านได้ในภาษาท้องถิ่น
2. งานศึกษาเชิงเปรียบเทียบกลยุทธ์หลากหลาย
3. กรณีศึกษาตัวบทสำคัญทั่วโลก
4. ศัพท์เฉพาะ/ศัพท์วิชาการที่ต้องรู้
5. งานศึกษาสำคัญที่ต้องอ่าน + บรรณานุกรม + ลิงก์

## ขอบเขตที่ผู้ใช้อนุมัติ (/grill-me)
- รูปแบบ: รายงานวิชาการหลายไฟล์ 5-8 ไฟล์, 5,000-10,000 คำ/ไฟล์ (ผลรวมไม่ต่ำกว่า 25,000-30,000 คำ)
- การสืบค้น: มาตรฐานเต็ม Phase A (15 ลูป) + Phase B (10 ลูป) + Unbiased Agent check ทุกระยะ
- ขอบเขต: ครอบคลุมทั่วโลกสมดุล (ยุโรป, ตะวันออกกลาง, เอเชียใต้/ตะวันออก/อุษาคเนย์, อเมริกา)
