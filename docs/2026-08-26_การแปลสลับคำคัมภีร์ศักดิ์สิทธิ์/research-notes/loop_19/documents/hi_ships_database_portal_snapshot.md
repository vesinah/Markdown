## Observation relevant to Loop 19 target (A)

No database named 訓点資料データベース (or any kunten-specific database) appears on
the portal. The closest Nara-period resource is the 奈良時代古文書フルテキストデータベース,
whose own description (see companion snapshot) defines it as full text of published
documents (大日本古文書), not a database of kunten glosses.
