# Extract: AKS Encyclopedia entry — Neungeom-gyeong eonhae (with Gangyeongdogam workflow)

- Entry: 능엄경언해 楞嚴經諺解 (E0013357; new URL scheme https://encykorea.aks.ac.kr/Article/E0013357)
- Author: An Byeonghui (안병희, Seoul National University, Korean linguistics); written 1995, last revised 2023-02-07
- Fetched: 2026-08-25 (full text)

## Key facts (verbatim-derived)
- Definition: vernacular rendering (언해서) of the Song-dynasty Chinese sutra 대불정여래밀인수증요의제보살만행수능엄경; 10 vols.
- Movable-type edition 1461 (Sejo year 7), printed at 교서관 with 을해자, 400 copies; woodblock edition 1462 by 간경도감(刊經都監); reprinted from same blocks 1472 and 1495.
- Project began 1449 under Sejong, led by Prince Suyang (later Sejo); resumed when Hyoryeong-daegun asked Sejo to translate this sutra and Yeongga-jip in 1461.
- Workflow per royal prefaces (발문): Sejo supplied kugyol (구결을 달아); monk Sinmi (신미/혜각존자) adjudicated parsing (구두를 바르게); Han Gyeohui (한계희) and Kim Su-on (김수온) drafted the translation; eminent monks corrected; Sejo finalized. Separate specialists handled collation, example-sentence polishing, and hanja readings — readings per Dongguk Jeongeun annotated by 조변안 and 조지.
- The movable-type edition had errors; recalled/corrected with red ink or appended slips; woodblock edition became the norm.
- Translation style thoroughly literal (철저한 직역); layout = large-character source text WITH hangul kugyol attached first, then paired-line (쌍행) translation below.
- Orthography deliberately differs between kugyol layer and translation layer: kugyol lacks bangjeom (방점), 'ㅭ', and geojabyeongseo; translation always has bangjeom plus endings like '○디니·홀띠니', 'ᄒᆞᇙᄉᆡ·ᄒᆞᆯᄊᆡ'.
- States this formatting model was fully consistent across Gangyeongdogam's 법화경언해, 금강경언해 etc., "간경도감의 다른 언해본에 대하여 책의 형태는 물론 번역의 양식과 정서법에 걸쳐 규범이 되고 있기 때문에 매우 중요한 자료" (normative model for other Gangyeongdogam eonhae).
- Woodblock edition is described as 간경도감에서 간행된 최초의 언해본 (first eonhae printed by Gangyeongdogam).
- Holding institutions listed (movable type: Seongam Library, SNU, Yonsei, Dongguk, Tenri Univ., etc.; woodblock: SNU, Dongguk incl. 15th-c. spine titles).
- Reference list includes: EDA Toru (江田俊雄) "이조간경도감과 기간행불전" (朝鮮之圖書館 25, 1936); Ogura Shinpei 增訂朝鮮語學史 (1940); An Byeonghui 「중세어의 한글자료에 대한 종합적인 고찰」 (규장각 3, 1979).

## Note on spelling
The AKS entry uses 간경도감 (刊經都監). The task prompt's spelling "강경도감" appears to be a variant romanization artifact ("Gangyeong-Dogam" in Lee 2014's English title); the standard Korean form across sources fetched this session is 간경도감.
