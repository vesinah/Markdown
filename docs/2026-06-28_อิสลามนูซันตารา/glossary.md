# คลังคำศัพท์เฉพาะทางของโครงการวิจัย
## (Project Glossary)

คลังคำศัพท์นี้ใช้สำหรับควบคุมการสะกดและทับศัพท์คำเฉพาะทางที่เกี่ยวข้องกับการแผ่ขยายของอิสลามในภูมิภาคนูซันตาราและนครรัฐสุลต่านสงขลา เพื่อให้เกิดความสม่ำเสมอในการเขียนเนื้อหาตลอดทั้งรายงานวิจัย 20 บท ตามข้อกำหนดของระบบงาน
