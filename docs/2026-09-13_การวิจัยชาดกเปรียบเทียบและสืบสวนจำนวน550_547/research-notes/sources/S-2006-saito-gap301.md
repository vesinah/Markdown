## 鳩摩羅什の詩と『大智度論』の偈 (Kumārajīva's Poetry and the Verses in the Dàzhìdù lùn)

> **เกณฑ์มาตรฐานคุณภาพระดับสูง (Exhaustive Depth Standard ≥ 100 KB):**

### ส่วนที่ 2: แผนผังการจัดสรรเข้าสู่บทและหัวข้อย่อยอย่างละเอียด (Detailed Chapter & Section Mapping Matrix)

*ระบุอย่างละเอียดระดับย่อหน้าและข้อถกเถียงว่าเนื้อหาและข้อค้นพบจากเอกสารนี้ นำไปใช้สนับสนุนบทใดและหัวข้อย่อยใดของโครงการวิจัย ๑๒ บท พร้อมระบุข้อเสนอเชิงทฤษฎีที่จะนำไปใช้:*

1. **บทที่ ๒: สารัตถะ โครงสร้าง และวิวัฒนาการของคัมภีร์ชาดกและวรรณกรรมพุทธศาสนา**
   - **หัวข้อย่อย ๒.๓ (ชาดกในคัมภีร์ภาษาสันสกฤตและภาษาจีน):**  
     นำข้อวิเคราะห์ว่าด้วยโครงสร้างคาถาและร้อยแก้วใน *ต้าจื้อตู้ลุ่น* (『大智度論』T. 1509) ซึ่งเป็นแหล่งรวมนิทานชาดกมหายานขนาดใหญ่ที่สุดแห่งหนึ่ง (โดยเฉพาะใน ๓๔ ผูกแรก) มาใช้อธิบายการทำงานร่วมกันระหว่างนิทานชาดกที่เป็นร้อยแก้วกับคาถาสรุปธรรมะที่เป็นร้อยกรอง
   - **หัวข้อย่อย ๒.๔ (ความสัมพันธ์ระหว่างร้อยแก้วและร้อยกรองในพัฒนาการตัวบท):**  
     ใช้ข้อค้นพบของไซโตที่ว่า คาถาใน *ต้าจื้อตู้ลุ่น* มีทั้งหมด ๖๑๒ คาถา โดยมีคาถามีสัมผัส (有韻偈頌) เพียง ๑๔% และคาถาไร้สัมผัส (無韻偈頌) ถึง ๘๖% มาเป็นกรอบวิเคราะห์วิวัฒนาการของวรรณศิลป์คาถาพุทธศาสนา จากฉันทลักษณ์แบบคีตา/สโตรกะของอินเดีย สู่ฉันทลักษณ์บทกวี ๕ คำและ ๗ คำของจีนโบราณ

2. **บทที่ ๗: การแปล การถ่ายทอด และการแปรเปลี่ยนของชาดกในเอเชีย (Transmission and Translation Studies)**
   - **หัวข้อย่อย ๗.๑ (ทฤษฎีและระเบียบวิธีแปลของพระกุมารชีพ):**  
     นำคำรำพึงประวัติศาสตร์ของพระกุมารชีพที่บันทึกไว้ใน *ชูซานจ้างจี้จี๋* (出三藏記集 T. 55, p. 101c) ว่าด้วยอุปมา "การเคี้ยวข้าวป้อนผู้อื่น" (嚼飯與人) มาใช้เป็นหัวใจหลักในการวิเคราะห์ปรัชญาการแปล โดยชี้ให้เห็นความตึงเครียดระหว่าง "ความสละสลวยทางวรรณศิลป์" (文藻/藻蔚) กับ "ความถูกต้องตรงตามพระธรรมวินัย" (得大意/金言) ซึ่งส่งผลให้พระกุมารชีพตัดสินใจ "ละทิ้งสัมผัสบังคับ" (Unrhymed Translation) ในคัมภีร์พระสูตรทั้งหมด
   - **หัวข้อย่อย ๗.๓ (การเปรียบเทียบสำนักแปล: พระจือเชียน ปะทะ พระกุมารชีพ):**  
     ใช้ตารางเปรียบเทียบคาถา ๗ คำใน *วิมลเกียรตินิทเทสสูตร* ระหว่างฉบับพระจือเชียน (支謙 T. 14, p. 519c) ผู้เน้นการลงสัมผัสท้ายวรรคตามฉันทลักษณ์จีน กับฉบับพระกุมารชีพ (T. 14, p. 537c) ผู้ยืมศัพท์ของพระจือเชียนมาใช้แต่จงใจทำลายสัมผัส เพื่อพิสูจน์จุดยืนทางสุนทรียศาสตร์ที่ต่างกันอย่างสุดขั้ว

3. **บทที่ ๙: ประวัติศาสตร์คัมภีร์และระเบียบวิธีวิจัยเอกสารโบราณ (Textual Criticism and Manuscript Studies)**
   - **หัวข้อย่อย ๙.๑ (สถานะทางคัมภีร์วิทยาของต้าจื้อตู้ลุ่น: การแปลหรือการรจนา):**  
     นำข้อถกเถียงระดับโลกเรื่อง "ใครคือผู้แต่งต้าจื้อตู้ลุ่น" (ทฤษฎีเอเตียน ลาม็อตต์ [Étienne Lamotte] ว่าด้วยการเสริมเติมโดยพระกุมารชีพ ปะทะ ทฤษฎีพระนาคารชุนดั้งเดิม) มาเชื่อมโยงกับข้อค้นพบของไซโต ซึ่งพิสูจน์ผ่านกฎการตัดตัวเลือก ๔ ข้อ (Elimination Method) ว่า คาถามีสัมผัส ๑๔% ใน *ต้าจื้อตู้ลุ่น* ต้องเป็น "ผลงานรจนาขึ้นเองของพระกุมารชีพ" (羅什による述作/撰述) ซึ่งสนับสนุนทฤษฎีว่า *ต้าจื้อตู้ลุ่น* เป็นตัวบทประสม (Composite Text) ที่มีชั้นการประพันธ์ของพระกุมารชีพสอดแทรกอยู่อย่างแท้จริง
   - **หัวข้อย่อย ๙.๓ (การตรวจสอบหลักฐานใบลานและเอกสารตัวเขียนตุนหวง):**  
     ใช้การอ้างอิงเอกสารตัวเขียนโบราณตุนหวง (敦煌本『大智度論』) และฉบับวัดอิชิยามะเดระ (石山寺本) ในการยืนยันว่า คาถามีสัมผัสเหล่านี้ปรากฏมาตั้งแต่ชั้นสำเนาโบราณ มิใช่การต่อเติมโดยคนรุ่นหลังในยุคพิมพ์แกะไม้ราชวงศ์ซ่ง

4. **บทที่ ๑๒: บทสรุป สังเคราะห์ทฤษฎี และข้อเสนอแนะสำหรับการวิจัยในอนาคต**
   - **หัวข้อย่อย ๑๒.๓ (ฉันทศาสตร์เปรียบเทียบในวรรณกรรมพุทธศาสนาเอเชีย):**  
     นำข้อเสนอของไซโตว่าด้วยความแตกต่างระหว่าง "การแปลพระสูตร" (Sūtra / 經) ซึ่งต้องรักษาพุทธวจนะบริสุทธิ์ กับ "การแปลคัมภีร์ศาสตร์" (Śāstra / 論) ซึ่งเปิดโอกาสให้ผู้แปลมีอิสระในการประพันธ์บทกวี มาสร้างเป็นข้อเสนอแนะเชิงทฤษฎีสำหรับการศึกษาวรรณกรรมพุทธศาสนาในอนาคต

### ส่วนที่ 3: สรุปสาระสำคัญเชิงวิเคราะห์และจุดยืนทางวิชาการ (Executive Academic Analysis)

- **วิทยานิพนธ์และข้อถกเถียงหลักของผู้เขียน (Core Argument / Thesis):**  
  ไซโต ทาคานอบุ ได้นำเสนอบทวิเคราะห์เชิงปริมาณและฉันทศาสตร์ (Metrics and Rhyme Analysis) เพื่อไขปริศนาสถานะของคาถาใน *ต้าจื้อตู้ลุ่น* โดยมีข้อค้นพบและข้อถกเถียงหลัก ๔ ประการ:  
  ๑) *ทฤษฎีการแปลคาถาไร้สัมผัสของพระกุมารชีพ (Unrhymed Translation Principle):*  
     จากการสำรวจผลงานแปลทั้งหมดของพระกุมารชีพจำนวน ๓๕ เรื่อง ๒๙๔ ผูก (มี ๓๑ เรื่องที่ปรากฏคาถา เช่น *สัทธรรมปุณฑริกสูตร*, *วิมลเกียรติสูตร*, *มัธยมกศาสตร์*) พบว่า คาถาทั้งหมดได้รับการแปลในรูป "ร้อยกรองไร้สัมผัส" (無韻) โดยสิ้นเชิง พระกุมารชีพมีจุดยืนชัดเจนว่า การนำคาถาภาษาสันสกฤตมาบังคับให้ลงสัมผัสตามฉันทลักษณ์จีนจะทำให้เนื้อความผิดเพี้ยน ดั่งคำสารภาพต่อพระเซิงรุ่ยว่า เปรียบเสมือน "การเคี้ยวข้าวป้อนผู้อื่น ซึ่งไม่เพียงแต่จะสูญสิ้นรสชาติ แต่ยังชวนให้อาเจียน"  
  ๒) *อัจฉริยภาพทางกวีนิพนธ์จีนของพระกุมารชีพ:*  
     แม้พระกุมารชีพจะแปลคาถาในพระสูตรโดยไม่ลงสัมผัส แต่หลักฐานบทกวีจีนดั้งเดิมที่พระกุมารชีพประพันธ์ขึ้นเอง ได้แก่ บทกวี ๕ คำมอบแก่พระฝ่าเหอ (沙門法和), บทกวีมอบแก่พระลู่ซาน ฮุ่ยหย่วน (廬山慧遠), และ "บทกวีสิบอุปมา" (十喩詩) ใน *อี้เหวินเล่ยจวี้* พิสูจน์อย่างชัดเจนว่า พระกุมารชีพมีความรู้ความเชี่ยวชาญในระบบการลงสัมผัสท้ายวรรค (脚韻) และกฎเกณฑ์ฉันทลักษณ์กวีนิพนธ์จีนโบราณอย่างลึกซึ้ง  
  ๓) *ความผิดปกติเชิงสถิติในต้าจื้อตู้ลุ่น:*  
     ในบรรดาคาถา ๖๑๒ บทของ *ต้าจื้อตู้ลุ่น* มีคาถาประมาณ ๑๔% (ส่วนใหญ่อยู่ใน ๓๔ ผูกแรก) ที่มี "สัมผัสท้ายวรรคคู่" (偶數句末押韻) ถูกต้องตามตำราสัทศาสตร์จีนโบราณ (*กวั่งยวิ่น* / 廣韻) ขณะที่อีก ๘๖% เป็นคาถาไร้สัมผัส ปรากฏการณ์นี้เป็นข้อยกเว้นเพียงหนึ่งเดียวในบรรดาผลงานแปลทั้งหมดของพระกุมารชีพ  
  ๔) *ข้อสรุปว่าด้วยการรจนาขึ้นเองของพระกุมารชีพ (Kumārajīva's Original Composition):*  
     ไซโตได้ประเมินสมมติฐาน ๔ แนวทางผ่านวิธีการตัดตัวเลือก (Elimination Method) และสรุปว่า สมมติฐานที่ว่า **"พระกุมารชีพเป็นผู้ประพันธ์คาถามีสัมผัสเหล่านี้ขึ้นมาเอง แล้วสอดแทรกเข้าไปในตัวบทต้าจื้อตู้ลุ่น"** เป็นสมมติฐานที่มีความสมเหตุสมผลและสอดคล้องกับข้อเท็จจริงสูงสุด โดยมีปัจจัยสนับสนุนคือ *ต้าจื้อตู้ลุ่น* มีสถานะเป็น "คัมภีร์ศาสตร์/อรรถกถา" มิใช่ "พระสูตร" พระกุมารชีพจึงมีอิสระในการใช้โวหารกวีนิพนธ์จีนมาเสริมแต่งอรรถกถาให้วิจิตรตระการตา

- **บริบทประวัติศาสตร์นิพนธ์ ระเบียบวิธีวิจัย และการประเมินความน่าเชื่อถือเชิงวิพากษ์ (Historiography, Methodology & Source Criticism):**  
  - *ประวัติศาสตร์นิพนธ์ว่าด้วยการประพันธ์ต้าจื้อตู้ลุ่น:*  
    การศึกษาของไซโตเข้ามาร่วมในวิวาทะประวัติศาสตร์อันยาวนานว่าด้วยผู้รจนา *ต้าจื้อตู้ลุ่น* ซึ่งแบ่งออกเป็น ๓ สำนักใหญ่:  
    ๑. *สำนักจารีต:* พระนาคารชุนรจนาทั้งหมด พระกุมารชีพเป็นเพียงผู้แปล  
    ๒. *สำนักนาคารชุนทางตะวันตกเฉียงเหนือ:* เป็นผลงานของพระนาคารชุนท่านที่สองแห่งอินเดียตะวันตกเฉียงเหนือในศตวรรษที่ ๔  
    ๓. *สำนักวิพากษ์ (เอเตียน ลาม็อตต์, ริชาร์ด โรบินสัน, ฮิคารุ ชิโอะ):* *ต้าจื้อตู้ลุ่น* เป็นผลงานที่พระกุมารชีพมีส่วนร่วมในการเรียบเรียง เติมแต่ง และสอดแทรกความคิดของตนเองเข้าไปเป็นอันมาก  
    งานของไซโตได้นำเสนอหลักฐานเชิงประจักษ์ชิ้นใหม่จาก "ฉันทศาสตร์และเสียงสัมผัส" ซึ่งยืนยันว่าพระกุมารชีพมีบทบาทเป็นผู้รจนาจริงอย่างน้อยก็ในส่วนของคาถามีสัมผัส ๑๔% นี้  
  - *ระเบียบวิธีวิจัย:* ไซโตตรวจสอบระบบเสียงสัมผัสโดยใช้ตารางเสียงของคัมภีร์ *กวั่งยวิ่น* (廣韻) เทียบเคียงกับ "กลุ่มเสียงสัมผัสสมัยราชวงศ์เว่ย-จิ้น-ราชวงศ์เหนือใต้" อย่างเคร่งครัด พร้อมทั้งตรวจสอบเปรียบเทียบกับเอกสารตัวเขียนโบราณตุนหวง ทำให้ผลลัพธ์มีความแม่นยำทางภาษาศาสตร์ประวัติศาสตร์ขั้นสูงสุด

### ส่วนที่ 4: สารบัญข้อค้นพบเชิงลึกตามประเด็นหลักอย่างละเอียด (Exhaustive Thematic Findings with Exact Pages)

1. **คำรำพึงประวัติศาสตร์ของพระกุมารชีพต่อการแปลคาถา (หน้า 486 [27]):**  
   ไซโตอ้างอิงบันทึกใน *ชูซานจ้างจี้จี๋* ผูก ๑๔ (T. 55, p. 101c) ที่พระกุมารชีพกล่าวแก่พระเซิงรุ่ย (僧叡) ถึงความยากลำบากในการถ่ายทอดฉันทลักษณ์อินเดียสู่ภาษาจีน:  
   "ธรรมเนียมของประเทศอินเดียนั้นให้ความสำคัญแก่วรรณศิลป์และความไพเราะของถ้อยคำเป็นอย่างยิ่ง… เมื่อเข้าเฝ้าพระราชาก็ต้องมีบทสรรเสริญพระเกียรติ เมื่อเข้าเฝ้าพระพุทธองค์ก็ใช้วิธีการขับลำนำเป็นเกียรติยศสูงสุด คาถาทั้งหลายในพระสูตรล้วนเป็นไปตามแบบแผนนี้ทั้งสิ้น ทว่าเมื่อเปลี่ยนภาษาสันสกฤตมาเป็นภาษาจีน ความงดงามแห่งวรรณศิลป์ (藻蔚) ย่อมสูญสิ้นไป แม้จะรักษาใจความสำคัญไว้ได้ แต่ลีลาทางวรรณกรรมกลับแปลกแยกไปอย่างสิ้นเชิง สิ่งนี้เปรียบประดุจ 'การเคี้ยวข้าวป้อนผู้อื่น ซึ่งไม่เพียงแต่จะสูญสิ้นรสชาติอันโอชา แต่ยังชวนให้ผู้รับอาเจียนออกมา' (有似嚼飯與人, 非徒失味, 乃令嘔穢也)"

2. **การสำรวจเชิงสถิติในพระสูตร ๓๕ เรื่องของพระกุมารชีพ (หน้า 486 [27]):**  
   ไซโตสำรวจคัมภีร์ที่พระกุมารชีพแปลทั้งหมด ๓๕ เรื่อง ๒๙๔ ผูก (ซึ่งมี ๓๑ เรื่องที่ปรากฏคาถา) พบว่า คาถาทั้งหมดในคัมภีร์พระสูตรเหล่านั้นเป็น "คาถาไร้สัมผัส" (無韻) อย่างสิ้นเชิง พระกุมารชีพเลือกที่จะรักษารหัสยะและเนื้อความของพระธรรมวินัย มากกว่าจะพยายามฝืนแต่งให้มีสัมผัสตามฉันทลักษณ์จีน

3. **การผ่าตัดคาถาในสัทธรรมปุณฑริกสูตร: ฉันทลักษณ์ ๔ คำไร้สัมผัส (หน้า 486 [27]–485 [28]):**  
   ไซโตยกตัวอย่างคาถาใน *สัทธรรมปุณฑริกสูตร* (妙法蓮華經 T. 9, p. 23a) หมวดอุปมาเมืองมายา (化城喩品) ชี้ให้เห็นว่า แม้พระกุมารชีพจะจัดจังหวะวรรคละ ๔ คำเพื่อความสะดวกในการสวดสาธยาย (読誦) แต่คำสุดท้ายของวรรคคู่กลับไม่มีการสัมผัสเสียงสระเลยแม้แต่วรรคเดียว เช่น คำท้ายวรรคคู่ใช้: `嚴` (เสียงราบ/เกลือ), `說` (เสียงเข้า/เศษ), `類` (เสียงตก/ไข), `慧` (เสียงตก/ทั้งหมด), `然` (เสียงราบ/ก่อน), `念` (เสียงตก/เกลือ), `力` (เสียงเข้า/หน้าที่), `業` (เสียงเข้า/ใบไม้), `輪` (เสียงราบ/จริง) ซึ่งมาจากกลุ่มเสียงที่กระจัดกระจายโดยสิ้นเชิง

4. **การชนกันระหว่างสองสำนักแปล: พระจือเชียน ปะทะ พระกุมารชีพ (หน้า 485 [28]):**  
   ไซโตเปรียบเทียบคาถา ๗ คำใน *วิมลเกียรตินิทเทสสูตร* ระหว่างฉบับของพระจือเชียน (T. 14, p. 519c) สมัยสามก๊กง่อก๊ก กับฉบับของพระกุมารชีพ (T. 14, p. 537c):  
   - *ฉบับพระจือเชียน:* วางสัมผัสท้ายวรรคคู่ตามฉันทลักษณ์จีนอย่างประณีต เช่น `極` (เสียงเข้า/กลุ่มหน้าที่) สัมผัสกับ `跡` (เสียงเข้า/กลุ่มยา), `明` (เสียงราบ/กลุ่มเกิง) สัมผัสกับ `聴` (เสียงราบ/กลุ่มเกิง), `人` (เสียงราบ/กลุ่มจริง) สัมผัสกับ `尊` (เสียงราบ/กลุ่มจริง)  
   - *ฉบับพระกุมารชีพ:* แม้จะศึกษาและยืมศัพท์เฉพาะของพระจือเชียนมาใช้ แต่พระกุมารชีพกลับ "จงใจทำลายสัมผัส" ทิ้งทั้งหมด โดยใช้คำท้ายวรรคคู่ว่า `定`, `首`, `土`, `聞`, `切`, `動`, `王` ซึ่งไม่มีเสียงสัมผัสกันเลย ข้อเท็จจริงนี้พิสูจน์ว่าพระกุมารชีพมีเจตนาแน่วแน่ที่จะปฏิเสธการลงสัมผัสในงานแปลพระสูตร

5. **บทกวีจีนดั้งเดิมของพระกุมารชีพ: บทกวีมอบแด่พระฝ่าเหอ (หน้า 484 [29]):**  
   ไซโตชี้ให้เห็นหลักฐานสำคัญว่า พระกุมารชีพมีความสามารถระดับสูงในการแต่งกวีนิพนธ์จีน โดยยกคาถา ๕ คำที่พระกุมารชีพประพันธ์ขึ้นเองเพื่อมอบแก่พระฝ่าเหอ (沙門法和) บันทึกใน *เกาสังจ้วน* (T. 50, p. 332bc):  
   `心山育明徳, 流薫万由延. 哀鸞孤桐上, 清音徹九天.`  
   บทกวีนี้มีการลงสัมผัสท้ายวรรคคู่อย่างสมบูรณ์แบบระหว่างคำว่า `延` (yán / กลุ่มเสียงเซียน) กับคำว่า `天` (tiān / กลุ่มเสียงเซียน) ซึ่งเป็นข้อพิสูจน์ที่ปฏิเสธไม่ได้ว่าพระกุมารชีพแตกฉานในฉันทศาสตร์จีนโบราณ

6. **บทกวีสิบอุปมา (十喩詩) ในอี้เหวินเล่ยจวี้ (หน้า 484 [29]):**  
   นอกจากบทกวีมอบแก่พระฝ่าเหอแล้ว พระกุมารชีพยังได้ประพันธ์ "บทกวีสิบอุปมา" (十喩詩) ซึ่งได้รับการบันทึกไว้ในสารานุกรม *อี้เหวินเล่ยจวี้* ผูก ๗๖ ของโอวยางสฺวิน และได้รับการอ้างอิงอย่างกว้างขวางในอรรถกถาพุทธศาสนา เช่น *จิ้งหมิงเสฺวียนลุ่น*, *จินกังปานรั่วซู*, และ *เอ้อร์ตี้อี้* บทกวีนี้ใช้สัมผัสเสียงสระอย่างวิจิตร สะท้อนภูมิปัญญาทางปรัชญามาธยมกะที่ผสานเข้ากับวรรณศิลป์จีนชั้นสูง

7. **สถิติคาถาในต้าจื้อตู้ลุ่น: ปริศนา ๑๔% ที่มีสัมผัส (หน้า 484 [29]):**  
   จากการศึกษาร่วมกับงานวิจัยของ มิตสึโยชิ ซาเองุสะ (Mitsuyoshi Saigusa, 1966) พบว่า ใน *ต้าจื้อตู้ลุ่น* มีคาถาทั้งหมด ๖๑๒ คาถา โดยกระจุกตัวหนาแน่นใน ๓๔ ผูกแรก ในจำนวนนี้ มีคาถาประมาณ ๑๔% ที่เป็น "คาถามีสัมผัส" (有韻偈頌) ถูกต้องตามฉันทลักษณ์จีน ส่วนที่เหลืออีก ๘๖% เป็นคาถาไร้สัมผัส และคาถามีสัมผัสเหล่านี้ไม่มีส่วนใดซ้ำซ้อนกับคาถาใน *มัธยมกศาสตร์* (*จงลุ่น*) เลย

8. **ตัวอย่างคาถามีสัมผัสในต้าจื้อตู้ลุ่น ผูก ๕, ๑๓, ๒๑, ๒๓ (หน้า 483 [30]–482 [31]):**  
   ไซโตนำคาถาใน *ต้าจื้อตู้ลุ่น* มาวิเคราะห์เสียงสัมผัสอย่างละเอียด:  
   - *ผูก ๕ (p. 94ab):* ใช้สัมผัสกลุ่มเสียง `支/脂` (สระ -i): คำว่า `智`, `比`, `施`, `利`  
   - *ผูก ๑๓ (p. 161a):* คาถาพรรณนาความสุขอันเกิดจากวิเวกในป่าอารัญ มีการสัมผัสเป็นคู่ ๆ อย่างงดงาม:  
     - คู่ที่ ๑: `惡` สัมผัสกับ `樂` (เสียงเข้า/กลุ่มยา)  
     - คู่ที่ ๒: `褥` สัมผัสกับ `足` (เสียงเข้า/กลุ่มเรือน)  
     - คู่ที่ ๓: `一` สัมผัสกับ `實` (เสียงเข้า/กลุ่มเนื้อแท้)  
     - คู่ที่ ๔: `入` สัมผัสกับ `及` (เสียงเข้า/กลุ่มไหม)  
   - *ผูก ๒๑ (p. 217a):* สัมผัสกลุ่มเสียง `脂/皆/之`: `利`, `慧`, `恣`, `事`, `恣`, `異`  
   - *ผูก ๒๓ (p. 229a):* คาถาพรรณนาความไม่เที่ยงเมื่อสิ้นกัป ใช้สัมผัสกลุ่มเสียง `陽` (สระ -ang): `常`, `量`, `方`, `傷`

9. **การหักล้างสมมติฐานที่ ๑: ฝีมือของคณะผู้ช่วยแปล (หน้า 482 [31]):**  
   สมมติฐานที่ว่าคณะผู้ช่วยแปลชาวจีนเป็นผู้ขัดเกลาบทกวี ไซโตหักล้างด้วยคำนำของพระเซิงรุ่ยใน "ต้าจื้อซื่อลุ่นซวี่" (大智釋論序 T. 25, p. 57b) ซึ่งระบุชัดเจนว่า คณะทำงานตัดสินใจ "บันทึกตามคำแปลตรงตัว ไม่มีการเสริมแต่งลวดลายทางวรรณศิลป์ใด ๆ ทั้งสิ้น" (案譯而書, 都不備飾) ยิ่งไปกว่านั้น หากเป็นฝีมือผู้ช่วยแปล ย่อมไม่สามารถอธิบายได้ว่าเหตุใดคาถาอีก ๘๖% จึงถูกปล่อยให้ไร้สัมผัส และเหตุใดคัมภีร์อื่น ๆ ของพระกุมารชีพจึงไม่มีการเสริมแต่งเช่นนี้

10. **การหักล้างสมมติฐานที่ ๒: การแก้ไขโดยคนรุ่นหลัง (หน้า 482 [31]–481 [32]):**  
    สมมติฐานที่ว่ามีการแต่งเติมสัมผัสในยุคหลัง ไซโตหักล้างด้วยการตรวจสอบหลักฐานเอกสารตัวเขียนโบราณตุนหวง (Dunhuang Manuscripts) ซึ่งเป็นสำเนาคัดลอกในยุคต้น พบว่าตัวบทคาถาในฉบับตุนหวงตรงกับฉบับพระไตรปิฎกพิมพ์แกะไม้แทบทุกประการ จึงตัดความเป็นไปได้เรื่องการดัดแปลงในยุคหลังออกไป

11. **การหักล้างสมมติฐานที่ ๓: การเปลี่ยนกฎการแปลตามลำดับเวลา (หน้า 481 [32]):**  
    สมมติฐานที่ว่าพระกุมารชีพอาจเปลี่ยนใจหันมาแปลแบบลงสัมผัสในภายหลัง ไซโตหักล้างด้วย "ลำดับเวลาทางประวัติศาสตร์" (Chronological Evidence):  
    - *ต้าจื้อตู้ลุ่น* แปลระหว่างปี ค.ศ. ๔๐๒–๔๐๕ (弘始 ๔–๗)  
    - คัมภีร์ที่แปลหลังจากนั้น ได้แก่ *สัทธรรมปุณฑริกสูตร*, *วิมลเกียรติสูตร*, *ฮวาโส่วจิง* (ค.ศ. ๔๐๖), *จื้อไจ้หวังจิง* (ค.ศ. ๔๐๗), *จงลุ่น* และ *สือเอ้อร์เหมินลุ่น* (ค.ศ. ๔๐๘)  
    ปรากฏว่าคาถาทั้งหมดในคัมภีร์ที่แปลทีหลังเหล่านี้ล้วนเป็น "คาถาไร้สัมผัส" ทั้งสิ้น จึงเป็นไปไม่ได้ที่พระกุมารชีพจะเปลี่ยนกฎการแปลเป็นการถาวร

12. **ชัยชนะของสมมติฐานที่ ๔: พระกุมารชีพเป็นผู้รจนาคาถาขึ้นเอง (หน้า 481 [32]):**  
    เมื่อตัดสมมติฐานทั้งสามข้อแรกออกไป ไซโตสรุปอย่างหนักแน่นว่า คาถามีสัมผัส ๑๔% ใน *ต้าจื้อตู้ลุ่น* เกิดจาก **"การที่พระกุมารชีพเป็นผู้ประพันธ์ขึ้นมาเอง (述作/撰述)"** หรือนำคาถาเดิมมาดัดแปลงผูกขึ้นใหม่ตามฉันทลักษณ์จีน โดยเหตุผลที่ทำเช่นนี้ได้เฉพาะใน *ต้าจื้อตู้ลุ่น* เป็นเพราะคัมภีร์นี้มิใช่พระสูตร (ที่ต้องรักษาพุทธพจน์อย่างเคร่งครัด) แต่เป็น "คัมภีร์ศาสตร์/อรรถกถา" ซึ่งเปิดพื้นที่ให้พระกุมารชีพสามารถแสดงอัจฉริยภาพทางวรรณศิลป์จีน เพื่อรับใช้การอธิบายอรรถกถาธรรมได้อย่างเต็มที่

   - *ภาษาต้นฉบับ (ญี่ปุ่น):*  
     > 「仏の金言が説かれる経の漢訳では華美な修辞は戒めるべきであるが, 『大品般若経』の註疏である『大智度論』の漢訳においては, 羅什自ら有韻偈頌を述作したか, 或いは原典の偈に華美な修辞を加えて, これを実現したのではないだろうか.」
   - *คำแปลภาษาไทยเชิงวิชาการ:*  
     "ในการแปลพระสูตรซึ่งเป็นที่ประดิษฐานแห่งพระพุทธวจนะอันศักดิ์สิทธิ์ (金言) การใช้โวหารอันวิจิตรหรูหราย่อมเป็นสิ่งพึงละเว้นและต้องระมัดระวังอย่างยิ่งยวด ทว่าในการแปลคัมภีร์ *ต้าจื้อตู้ลุ่น* ซึ่งมีสถานะเป็นอรรถกถาอธิบายคัมภีร์ *มหาปรัชญาปารมิตาสูตร* พระกุมารชีพย่อมอาจเป็นผู้ประพันธ์คาถามีสัมผัสเหล่านี้ขึ้นมาด้วยตนเอง หรือมิฉะนั้นก็คือการสอดใส่โวหารอันวิจิตรเข้าไปในคาถาของต้นฉบับเดิม เพื่อให้บรรลุผลสำเร็จทางวรรณศิลป์เช่นนี้มิใช่หรือ"
   - *เชิงอรรถสำเร็จรูป Chicago Form:*  
     齊藤隆信, "鳩摩羅什の詩と『大智度論』の偈," *印度學佛教學硏究* 55, no. 1 (2006): 481.

### ส่วนที่ 6: คลังคำศัพท์เฉพาะทางและนิรุกติศาสตร์จากเอกสาร (Native Terminology & Etymology Glossary)

*รวบรวมคำศัพท์เฉพาะทางจำนวน ๓๐ คำ พร้อมการวิเคราะห์รากศัพท์และความหมายเชิงวิชาการ:*

| คำศัพท์เดิม (คันจิ/จีน/สันสกฤต) | คำอ่าน/คำแปลไทย | ความหมายเชิงวิชาการและนัยทางคัมภีร์ | เลขหน้าที่ปรากฏ |
|:---|:---|:---|:---|
| 有韻偈頌 (Rhymed Gāthā) | โหย่วอวิ้นจี้ซ่ง / คาถามีสัมผัส | คาถาพุทธศาสนาภาษาจีนที่มีการวางเสียงสัมผัสท้ายวรรคคู่ตามกฎฉันทลักษณ์กวีนิพนธ์จีน | 486, 484 |
| 無韻偈頌 (Unrhymed Gāthā) | อู๋อวิ้นจี้ซ่ง / คาถาไร้สัมผัส | คาถาพุทธศาสนาภาษาจีนที่แปลโดยไม่บังคับสัมผัส มุ่งเน้นการรักษาความหมายตรงตัว | 486, 484 |
| 脚韻 (End Rhyme) | เจี่ยวอวิ้น / สัมผัสท้ายวรรค | การบังคับให้ตัวอักษรสุดท้ายของวรรคมีเสียงสระและมาตราตัวสะกดในหมวดเสียงเดียวกัน | 485, 484 |
| 文藻 / 藻蔚 (Literary Embellishment) | เหวินเจ่า / เจ่าเว่ย / ความวิจิตรแห่งวรรณศิลป์ | โวหารอันงดงามและการประดับประดาถ้อยคำ ซึ่งพระกุมารชีพมองว่ายากจะถ่ายทอดข้ามภาษา | 486 |
| 嚼飯與人 (Chewing rice for others) | เจี๋ยฟ่านอวี่เหริน / เคี้ยวข้าวป้อนผู้อื่น | อุปมาอันลือลั่นของพระกุมารชีพ ชี้ว่าการแปลฉันทลักษณ์สันสกฤตสู่จีนทำให้สูญเสียรสชาติ | 486 |
| 廣韻 (Guangyun) | กวั่งยวิ่น | ตำราสัมภาษณ์และพจนานุกรมเสียงภาษาจีนโบราณ ใช้เป็นเกณฑ์มาตรฐานตรวจสอบสัมผัส | 486, 483 |
| 十喩詩 (Ten Simile Poem) | สืออวี้ซือ / บทกวีสิบอุปมา | กวีนิพนธ์ภาษาจีนที่พระกุมารชีพประพันธ์ขึ้นเอง อธิบายสุญญตาผ่านอุปมา ๑๐ ประการ | 484, 480 |
| 沙門法和 (Shamen Fahuo) | ซาม門ฝ่าเหอ / สมณะฝ่าเหอ | พระสหายร่วมสำนักของพระเต้าอัน ผู้ซึ่งพระกุมารชีพประพันธ์บทกวีจีนมอบให้เป็นที่ระลึก | 484 |
| 大智度論 (Mahāprajñāpāramitopadeśa, T. 1509) | ต้าจื้อตู้ลุ่น | มหาอรรถกถาอธิบายปรัชญาปารมิตา ซึ่งมีคาถามีสัมผัสปรากฏอยู่ ๑๔% | 486–480 |
| 僧叡 (Sengrui) | เซิงรุ่ย | ศิษย์เอกและผู้ช่วยแปลคนสำคัญของพระกุมารชีพ ผู้บันทึกทัศนะการแปลและเขียนบทนำ | 486, 482 |
| 支謙 (Zhi Qian) | จือเชียน | ปราชญ์ราชวงศ์ง่อก๊ก ผู้บุกเบิกการแปลคาถาพุทธศาสนาให้มีสัมผัสตามฉันทลักษณ์จีน | 485, 481 |
| 駢儷文 (Pianliwen / Parallel Prose) | เพียนลี่เหวิน / ร้อยแก้วคู่ขนาน | ลีลาวรรณกรรมจีนโบราณที่เน้นความสมดุลของคู่คำ ๔-๖ คำ และมีจังหวะดนตรี | 481 |
| 金言 (Golden Words / Buddhavacana) | จินเหยียน / พุทธวจนะอันศักดิ์สิทธิ์ | ถ้อยคำอันเป็นสัจธรรมของพระพุทธเจ้าในพระสูตร ซึ่งผู้แปลห้ามบิดเบือนเพื่อความไพเราะ | 481 |
| 述作 / 撰述 (Original Composition) | ซู่จั้ว / จ้วนซู่ / การรจนาขึ้นเอง | การที่ผู้แปลทำหน้าที่เป็นผู้ประพันธ์ตัวบทขึ้นมาใหม่ มิใช่เพียงการถ่ายทอดภาษา | 486, 481 |
| 平声 (Ping Sheng) | ผิงเซิง / เสียงราบ | วรรณยุกต์เสียงราบในภาษาจีนโบราณ นิยมใช้เป็นเสียงสัมผัสหลักในกวีนิพนธ์ | 486, 483 |
| 上声 (Shang Sheng) | สั่งเซิง / เสียงขึ้น | วรรณยุกต์เสียงขึ้นในระบบสี่เสียงของจีนโบราณ | 485 |
| 去声 (Qu Sheng) | ชวี่เซิง / เสียงตก | วรรณยุกต์เสียงตก มักใช้สลับกับเสียงราบเพื่อสร้างความหลากหลายทางดนตรี | 486, 483 |
| 入声 (Ru Sheng) | รู่เซิง / เสียงเข้า | วรรณยุกต์เสียงสั้นและมีตัวสะกดปิดตาย (-p, -t, -k) ให้ความรู้สึกเด็ดขาดกระชับ | 486, 483 |
| 仙韻 / 先韻 (Xian Rhyme) | เซียนอวิ้น / หมวดเสียงเซียน | หมวดเสียงสัมผัสสระ -an ในกวั่งยวิ่น ปรากฏในบทกวีที่พระกุมารชีพมอบแก่พระฝ่าเหอ | 484 |
| 薬韻 (Yao Rhyme) | เย่าอวิ้น / หมวดเสียงเย่า | หมวดเสียงสัมผัสเสียงเข้า ปรากฏในคาถาพรรณนาวิเวกสุขในต้าจื้อตู้ลุ่น ผูก ๑๓ | 483 |
| 屋韻 (Wu Rhyme) | อูอวิ้น / หมวดเสียงอู | หมวดเสียงสัมผัสเสียงเข้า สระ -uk ปรากฏในต้าจื้อตู้ลุ่น ผูก ๑๓ | 483 |
| 質韻 (Zhi Rhyme) | จื้ออวิ้น / หมวดเสียงจื้อ | หมวดเสียงสัมผัสเสียงเข้า สระ -it ปรากฏในคำว่า 一 และ 實 | 483 |
| 陽韻 (Yang Rhyme) | หยางอวิ้น / หมวดเสียงหยาง | หมวดเสียงสัมผัสสระ -ang ปรากฏในคาถาพรรณนาความไม่เที่ยง ผูก ๒๓ | 483 |
| 宮商 (Gong and Shang) | กงซาง | โน้ตดนตรีโบราณของจีน ใช้เปรียบเทียบกับระบบระดับเสียงและท่วงทำนองในฉันทลักษณ์ | 486 |
| 読誦 (Chanting / Recitation) | ตู๋ซ่ง / การสวดสาธยาย | วัตรปฏิบัติในการสวดท่องพระสูตร ซึ่งส่งอิทธิพลต่อการจัดจังหวะคำของพระกุมารชีพ | 486 |

| 維摩詰所說經 (Vimalakīrtinirdeśa-sūtra, T. 475) | เหวยหมัวเจี๋ยสัวซัวจิง / วิมลเกียรตินิทเทสสูตร | พระสูตรที่พระกุมารชีพยืมศัพท์ของพระจือเชียนแต่จงใจตัดเสียงสัมผัสทิ้ง | 485, 481 |

| 敦煌寫本 (Dunhuang Manuscripts) | ตุนหวงเสี่ยเปิ่น / เอกสารตัวเขียนตุนหวง | สำเนาโบราณที่ใช้เป็นหลักฐานยืนยันว่าคาถามีสัมผัสมีมาแต่ดั้งเดิม ไม่ได้ถูกแก้ในยุคหลัง | 482 |
