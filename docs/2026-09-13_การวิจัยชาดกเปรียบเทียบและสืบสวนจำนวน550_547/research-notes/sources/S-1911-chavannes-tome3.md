- **การจำแนกโครงสร้างตัวบทภายในเล่ม ๓ (Corpus Stratigraphy):**
  ๑. *จ๋าเป่าจั้งจิง* หรือ *คัมภีร์รัตนปิฎกปกิณณกะ* (*Tsa pao tsang king*, 雜寶藏經 ๑๐ ผูก, Samyukta-ratnapiṭaka-sūtra, Nanjio n° 1329 / T. 203) แปลโดยพระกิกายะ (Kikkaya / Ki-kia-ye / 吉迦夜) ร่วมกับพระถานเย่า (T'an-yao / 曇曜) ในปี ค.ศ. ๔๗๒ ภายใต้การสนับสนุนของราชสำนักเว่ยเหนือ (Northern Wei): นิทานเรื่องที่ ๔๐๐–๔๒๒ (หน้า ๑–๑๔๖ พร้อมบทสรุปเชิงวิเคราะห์นิทานก่อนเรื่องที่ ๔๐๐ ในหน้า ๑–๓)
  ๒. *คัดสรรจากเซิงจิง* หรือ *ชาตกสูตร* (*Extraits du Cheng king*, 生經 ๕ ผูก, Jātaka-sūtra, Nanjio n° 669 / T. 154) แปลโดยพระธรรมรักษะ (Dharmarakṣa / Fa-hou / 竺法護) ในปี ค.ศ. ๒๘๕ สมัยราชวงศ์จิ้นตะวันตก: นิทานเรื่องที่ ๔๒๓–๔๓๘ (หน้า ๑๔๗–๒๐๗)
  ๓. *คัดสรรจากจิงลวี่อี้เซี่ยง* หรือ *คัมภีร์รูปการประหลาดแห่งพระสูตรและพระวินัย* (*Extraits du King liu yi siang*, 經律異相 ๕๐ ผูก, Nanjio n° 1473 / T. 2121) ประมวลรวบรวมในปี ค.ศ. ๕๑๖ สมัยราชวงศ์เหลียง โดยพระป่าวชั่ง (Pao-tch'ang / 寶唱), พระเซิงหมิน (Seng-min / 僧旻) และคณะ: นิทานเรื่องที่ ๔๓๙–๔๘๙ (หน้า ๒๐๘–๒๘๒ รวม ๕๑ เรื่อง)
  ๔. *คัดสรรจากมหาปรัชญาปารมิตาสูตรศาสตร์* (*Extraits du Ta tche tou louen*, 大智度論 ๑๐๐ ผูก, Mahāprajñāpāramitopadeśa, Nanjio n° 1169 / T. 1509) นิพนธ์โดยพระนาคารชุน แปลโดยพระกุมารชีพ (Kumārajīva / 鳩摩羅什) ในปี ค.ศ. ๔๐๒–๔๐๖: นิทานเรื่องที่ ๔๙๐–๔๙๒ (หน้า ๒๘๓–๒๙๖)
  ๕. *คัดสรรจากชูเย่าจิง* หรือ *อวทานสูตรอรรถกถาธรรมบท* (*Extraits du Tch'ou yao king*, 出曜經 ๓๐ ผูก, Avadānasūtra / Udānavarga Commentary, Nanjio n° 1321 / T. 212) นิพนธ์โดยพระธรรมตราตะ นำต้นฉบับมาจากกัศมีร์โดยพระสังฆภูติ (Saṅghabhūti / 僧伽跋澄) ในปี ค.ศ. ๓๘๓ แปลโดยพระสังฆภูติร่วมกับพระจูฝัวเนี่ยน (Zhu Fonian / 竺佛念) ในปี ค.ศ. ๓๙๘–๓๙๙: นิทานเรื่องที่ ๔๙๓–๔๙๔ (หน้า ๒๙๗–๓๐๙)
  ๖. *คัดสรรจากฝ่าจวี้ปี่หยูจิง* หรือ *ธรรมบทอุปมาสูตร* (*Extraits du Fa kiu p'i yu king*, 法句譬喻經 ๔ ผูก, Dharmapada-avadāna-sūtra, Nanjio n° 1353 / T. 211) แปลโดยพระฟาจวี้ (Fa-kiu / 法炬) และพระฝ่าลี่ (Fa-li / 法立) ระหว่างปี ค.ศ. ๒๖๕–๓๑๖ สมัยราชวงศ์จิ้นตะวันตก: นิทานเรื่องที่ ๔๙๕–๔๙๗ (หน้า ๓๑๐–๓๑๗)
  ๗. *สูตรว่าด้วยพระสุบินสิบประการของพระเจ้าปเสนทิโกศล* (*Sûtra des dix rêves du roi Prasenajit*, 佛說舍衛國王十夢經 / 普法義經, Prasenajit-daśasvapna-sūtra, Nanjio n° 632 / T. 632) แปลโดยพระถานอู๋หลาน (Dharmarakṣa / T'an-wou-lan / 竺曇無蘭) ระหว่างปี ค.ศ. ๓๘๑–๓๙๕: นิทานเรื่องที่ ๔๙๘ (หน้า ๓๑๘–๓๒๕)
  ๘. *สูตรว่าด้วยอวทานของนางไน่หนี่ (อัมพปาลี) และหมอชีวก* (*Sûtra sur l'avadāna de Fille-de-Manguier [Āmrapālī] et K'i-yu [Jīvaka]*, 佛說奈女耆域因緣經 ๑ ผูก, Nanjio n° 667 / T. 553) แปลโดยพระอันซีเกา (An Shigao / Ngan Che-kao / 安世高) ระหว่างปี ค.ศ. ๑๔๘–๑๗๐ สมัยราชวงศ์ฮั่นยุคหลัง: นิทานเรื่องที่ ๔๙๙ (หน้า ๓๒๖–๓๖๑)
  ๙. *สูตรว่าด้วยมกุฎราชกุมารสุทานะ* หรือ *เวสสันดรชาดกสำนวนภาษาจีน* (*Sûtra du prince héritier Sudāna*, 太子須大拏經 ๑ ผูก, Sudānakumāra-sūtra / Vessantara Jātaka, Nanjio n° 254 / T. 171) แปลโดยสมณะเซิ่งเจียน (Cheng-kien / 聖堅) ระหว่างปี ค.ศ. ๓๘๘–๔๐๗ สมัยราชวงศ์ฉินตะวันตก: นิทานเรื่องที่ ๕๐๐ (หน้า ๓๖๒–๓๙๕)

### ส่วนที่ 2: แผนผังการจัดสรรเข้าสู่บทและหัวข้อย่อยอย่างละเอียด (Detailed Chapter & Section Mapping Matrix)
*ระบุอย่างละเอียดระดับย่อหน้า ข้อถกเถียง และชุดข้อมูลว่าเนื้อหาและข้อค้นพบจากเอกสารเล่มนี้ นำไปใช้สนับสนุนบทใดและหัวข้อย่อยใดของโครงการมหาตำราวิจัย ๑๒ บท พร้อมระบุข้อเสนอเชิงทฤษฎีที่จะนำไปใช้:*

1. **บทที่ ๑: กำเนิด พัฒนาการ และมโนทัศน์วิทยาแห่งชาดกในอินเดียโบราณ**
   - **หัวข้อย่อย ๑.๑ (การเปลี่ยนรูปของมหากาพย์และนิทานคติชนสู่นิทานธรรม):**  
     นำตัวบทตำนานพระรามฉบับพุทธศาสนาใน *จ๋าเป่าจั้งจิง* (雜寶藏經, หน้า ๑–๒) ที่ระบุชื่อท้าวทศรถ (Che-che / Daçaratha), พระราม (Lo-mo / Râma), พระลักษมณ์ (Lo-man / Lakṣmaṇa), พระภรต (P'o-lo-t'o / Bharata), และพระสัตรุด (Tueur d'ennemis / Śatrughna) ไปใช้วิเคราะห์การปรับแปลงมหากาพย์รามายณะของฮินดูให้กลายเป็นชาดกพุทธศาสนา โดยตัดทอนองค์ประกอบสงครามและการลักพาตัวนางสีดาออกไป แล้วมุ่งเน้นเฉพาะประเด็นความกตัญญู ความจงรักภักดีระหว่างพี่น้อง และการสละราชสมบัติของพระภรตผู้ประดิษฐานฉลองพระบาทของพระรามไว้บนบัลลังก์เพื่อถวายความเคารพทุกเช้าค่ำ สะท้อนให้เห็นกลยุทธ์ของพุทธศาสนายุกต์แรกในการกลืนซับวรรณกรรมกระแสหลักของอินเดียมาเป็นเครื่องมือสั่งสอนธรรม
   - **หัวข้อย่อย ๑.๓ (พัฒนาการของทานบารมีขั้นปรมัตถ์และการสละเลือดเนื้อ):**  
     ใช้เรื่องเล่าเจ้าชายเฉือนเนื้อตนเองวันละส่วนเพื่อช่วยบิดามารดาที่หลงทางในทะเลทราย (หน้า ๒–๓) และเรื่องมกุฎราชกุมารสุทานะบริจาคช้างเผือก บุตรธิดา และภรรยา (เรื่องที่ ๕๐๐, หน้า ๓๖๒–๓๙๕) ในการวิเคราะห์แนวคิด "มหาทาน" และ "สัจกิริยา" (Act of Truth) ที่พระโพธิสัตว์ทรงอธิษฐานฟื้นฟูร่างกายและสถาปนาสัจธรรม ชี้ชัดว่าแกนกลางของชาดกในอินเดียโบราณคือการทดสอบจิตใจด้วยความทุกขเวทนาขั้นสูงสุดเพื่อสั่งสมสัมมาสัมโพธิญาณ

2. **บทที่ ๒: ธรรมเนียมชาดกในพุทธศาสนานิกายยุคแรก: ความร่วมและความต่างระหว่าง ๑๘ นิกาย**
   - **หัวข้อย่อย ๒.๑ (สายธารวรรณกรรมชาตกสูตรของนิกายธรรมคุปตกะและสรวาสติวาท):**  
     นำตัวบทจาก *เซิงจิง* (生經, Sheng jing / Jātaka-sūtra, เรื่องที่ ๔๒๓–๔๓๘, หน้า ๑๔๗–๒๐๗) ที่แปลโดยพระธรรมรักษะแห่งตุนหวง (ค.ศ. ๒๘๕) ไปใช้วิเคราะห์ลักษณะเฉพาะของคัมภีร์ชาดกฝ่ายสันสกฤตของนิกายยุคแรก โดยเฉพาะโครงสร้างคาถา (Gāthā) และการดำเนินเรื่องที่ยังคงรูปแบบร้อยแก้วผสมร้อยกรองแบบดั้งเดิม แสดงให้เห็นว่าก่อนการสถาปนาอรรถกถาชาดกบาลี ๕๕๐ เรื่อง ธรรมเนียมสันสกฤตมีประมวลชาดกที่เป็นเอกเทศของตนเอง
   - **หัวข้อย่อย ๒.๓ (การสืบทอดนิทานเปรียบเทียบในคัมภีร์อรรถกถาธรรมบทข้ามนิกาย):**  
     นำตัวบทจาก *ชูเย่าจิง* (出曜經, เรื่องที่ ๔๙๓–๔๙๔, หน้า ๒๙๗–๓๐๙) ซึ่งเป็นอรรถกถาอุทัยนวรรค/ธรรมบทของสำนักสรรวาสติวาทสายกัศมีร์ มาเปรียบเทียบกับ *ฝ่าจวี้ปี่หยูจิง* (法句譬喻經, เรื่องที่ ๔๙๕–๔๙๗, หน้า ๓๑๐–๓๑๗) ของสำนักธรรมคุปตกะ ชี้ให้เห็นว่าแต่ละนิกายมีการผูกเรื่องอวทานประกอบบทคาถาธรรมบทด้วยเรื่องเล่าที่แตกต่างกันอย่างสิ้นเชิง แม้จะมุ่งอธิบายคาถาบทเดียวกันก็ตาม

3. **บทที่ ๓: จุดตัดและการปะทะสังสรรค์ระหว่าง "ชาดกเถรวาท" กับ "อุดมการโพธิสัตว์ของมหายาน"**
   - **หัวข้อย่อย ๓.๒ (การปรับสถานะของอัครสาวกและพระอรหันต์ในวรรณกรรมอวทาน):**  
     วิเคราะห์เรื่องราวใน *จิงลวี่อี้เซี่ยง* (經律異相, เรื่องที่ ๔๓๙, หน้า ๒๐๘–๒๑๓) ว่าด้วยการวิวาทระหว่างพี่น้อง ๔ คนในการแบ่งมรดก ซึ่งพระสารีบุตรไม่อาจตัดสินได้ จึงนำไปเฝ้าพระพุทธองค์ พระพุทธองค์ทรงยกเรื่องอดีตชาติของกษัตริย์ผู้ต้องการน้ำนมแม่ราชสีห์มารักษาโรค แล้วเกิดการวิวาทระหว่างอวัยวะ (ตา หู เท้า ลิ้น) ชี้ให้เห็นการตอกย้ำว่าพระอรหันตสาวกมีปัญญาจำกัดในการหยั่งรู้อดีตกรรมและวิบาก มีเพียงพระสัมมาสัมพุทธเจ้าผู้ทรงสัพพัญญุตญาณเท่านั้นที่สามารถคลี่คลายปมกรรมได้อย่างแท้จริง
   - **หัวข้อย่อย ๓.๔ (มโนทัศน์โพธิสัตว์ในมหาปรัชญาปารมิตาสูตรศาสตร์):**  
     นำตัวบทจาก *ต้าจื้อตู้ลุ่น* (大智度論, เรื่องที่ ๔๙๐–๔๙๒, หน้า ๒๘๓–๒๙๖) ของพระนาคารชุน ไปใช้วิเคราะห์การที่ปรัชญามหายานหยิบยืมตำนานพื้นบ้านและอวทาน (เช่น ต้นกำเนิดของเมืองราชคฤห์และกำเนิดของพระเจ้าชราสันธ์) มาเป็นอุปมาเพื่ออธิบายเรื่องสุญญตาและมหาปัญญาบารมี

4. **บทที่ ๔: วิวัฒนาการและการประมวลรวบรวมคัมภีร์ชาดกบาลี: จากคาถา สู่ อรรถกถาชาตกัฏฐกถา ๕๔๗/๕๕๐ เรื่อง**
   - **หัวข้อย่อย ๔.๒ (การเปรียบเทียบคาถาชาดกในเซิงจิงกับชาดกบาลี):**  
     นำคาถาสุภาษิตใน *เซิงจิง* เรื่องที่ ๔๒๗ (หน้า ๑๖๗) และเรื่องที่ ๔๒๘ (หน้า ๑๗๓) ว่าด้วยมิตรภาพระหว่างสุนัขจิ้งจอกกับกา/นกยูง ("Sincères et loyaux sont les vrais amis...") ไปสอบเทียบกับคาถาใน *ชัมพุกชาดก* (Jambuka-jātaka, ชาดกบาลีลำดับที่ ๓๓๕) และ *อันตชาดก* (Anta-jātaka, ชาดกบาลีลำดับที่ ๒๙๕) เพื่อพิสูจน์ว่าคาถาโบราณในภาษาจีนเป็นคำแปลตรงตัวของคาถาภาษาสันสกฤต/ปรากฤตที่สืบทอดมาร่วมกันกับภาษาบาลี
   - **หัวข้อย่อย ๔.๔ (การสืบสวนร่องรอยการตัดทอนและขยายความในร้อยแก้ว):**  
     ใช้ข้อสังเกตของ Chavannes ที่ชี้ว่าร้อยแก้วของ *เซิงจิง* มีความคลุมเครือและบางตอนแปลอย่างกระท่อนกระแท่น สะท้อนว่าตัวบทภาษาสันสกฤตดั้งเดิมเน้นการท่องจำคาถา ส่วนร้อยแก้วเปิดโอกาสให้ผู้สวดหรือผู้แปลขยายความตามบริบทท้องถิ่น ซึ่งเป็นเหตุผลสำคัญที่ทำให้รายละเอียดร้อยแก้วของฝ่ายบาลีและฝ่ายจีนมีความแตกต่างกัน

5. **บทที่ ๕: ธรรมเนียมชาดกและอวทานนอกบาลีในเอเชียใต้และเอเชียกลาง: ภาษาสันสกฤต ปรากฤต และวัฒนธรรมคันธาระ**
   - **หัวข้อย่อย ๕.๑ (โบราณคดีและจารึกวิทยาถ้ำหยุนกังกับคัมภีร์จ๋าเป่าจั้งจิง):**  
     ใช้ข้อมูลเชิงลึกในเชิงอรรถของ Chavannes (หน้า ๑, เชิงอรรถที่ ๑) ที่ระบุความเชื่อมโยงระหว่างพระถานเย่า (T'an-yao / 曇曜) ผู้แปล *จ๋าเป่าจั้งจิง* กับการเป็นผู้อำนวยการขุดเจาะและแกะสลักพุทธศิลป์ถ้ำหินหยุนกัง (Yungang Grottoes / 雲岡石窟) ภายใต้ราชวงศ์เว่ยเหนือ เพื่อสร้างข้อถกเถียงว่า วรรณกรรมอวทานใน *จ๋าเป่าจั้งจิง* มิได้เป็นเพียงตัวบทคัมภีร์ หากเป็น "คู่มือเชิงสัญลักษณ์และภาพตัวแทน" (Iconographic Program) ที่ถูกนำไปสลักเป็นภาพนูนต่ำบนหน้าผาหินทรายในศตวรรษที่ ๕
   - **หัวข้อย่อย ๕.๓ (การสืบทอดตำนานหมอชีวกและมหาวิทยาลัยตักศิลา):**  
     นำตัวบท *สูตรว่าด้วยอวทานของนางไน่หนี่และหมอชีวก* (เรื่องที่ ๔๙๙, หน้า ๓๒๖–๓๖๑) ไปใช้วิเคราะห์สภาพภูมิศาสตร์ประวัติศาสตร์และประวัติศาสตร์การแพทย์โบราณในเอเชียใต้และเอเชียกลาง ชี้ให้เห็นบทบาทของมหาวิทยาลัยตักศิลา (Taxila / Takkasilā) ในฐานะศูนย์กลางวิทยาการทางการแพทย์และศัลยกรรมระดับโลกโบราณ

6. **บทที่ ๖: วรรณกรรมชาดกในเอเชียตะวันออก: พระไตรปิฎกภาษาจีน ทิเบต และการแผ่ขยายสู่อารยธรรมซินิก**
   - **หัวข้อย่อย ๖.๒ (การจัดประมวลสารานุกรมพุทธศาสนาในสมัยราชวงศ์เหลียง):**  
     ศึกษาวิธีวิทยาการคัดเลือกและจัดหมวดหมู่นิทานใน *จิงลวี่อี้เซี่ยง* (經律異相, เรื่องที่ ๔๓๙–๔๘๙, หน้า ๒๐๘–๒๘๒) ของพระป่าวชั่ง ชี้ให้เห็นความพยายามของปัญญาชนจีนโบราณในการหลอมรวมนิทานชาดกและวินัยเข้ากับโลกทัศน์แบบสารานุกรมเชิงขงจื๊อ เพื่อถวายแด่จักรพรรดิเหลียงอู่ตี้ (Emperor Wu of Liang) สำหรับใช้เป็นคลังปัญญาในการบริหารราชการแผ่นดิน
   - **หัวข้อย่อย ๖.๔ (วิวัฒนาการการแปลจากยุคฮั่นถึงยุคราชวงศ์เหนือใต้):**  
     เปรียบเทียบสำนวนการแปลตั้งแต่ยุคอันซีเกา (ศตวรรษที่ ๒) ในเรื่องที่ ๔๙๙, ธรรมรักษะ (ศตวรรษที่ ๓) ในเรื่องที่ ๔๒๓–๔๓๘, จนถึงกุมารชีพและถานเย่า (ศตวรรษที่ ๕) แสดงให้เห็นวิวัฒนาการของภาษาจีนพุทธศาสนาที่เปลี่ยนผ่านจากการยืมศัพท์เต๋า (เก๋ออี้ / 格義) ไปสู่การสร้างระบบศัพท์บัญญัติและการถอดเสียงภาษาสันสกฤตที่แม่นยำ

7. **บทที่ ๗: ชาดกและอวทานในคัมภีร์พระวินัย (Vinaya Literature) ในฐานะแหล่งกำเนิดและที่สถิตของนิทานธรรม**
   - **หัวข้อย่อย ๗.๒ (นิทานชดเชยกรรมและการบัญญัติสิกขาบทในจิงลวี่อี้เซี่ยง):**  
     วิเคราะห์นิทานเรื่องที่ ๔๔๐ (หน้า ๒๑๓–๒๑๔) ว่าด้วยพระภิกษุผู้ยอมถูกทุบตีจนบาดเจ็บสาหัสเพื่อปกป้องนกหงส์/นกกระเรียนที่กลืนไข่มุกของช่างทองเข้าไป และนิทานเรื่องที่ ๔๔๙–๔๕๐ (หน้า ๒๒๗–๒๒๙) ว่าด้วยการรักษาศีล ๕ ของอุบาสก นำไปใช้เป็นหลักฐานแสดงการทำงานร่วมกันระหว่างนิทานอุปมากับจิตสำนึกทางวินัยปฏิบัติ
   - **หัวข้อย่อย ๗.๔ (การปราบยักษ์และรากษสกับการจัดระเบียบสังคมอารามิก):**  
     นำเรื่องการปราบยักษ์อาฬวกะ (เรื่องที่ ๔๑๑, หน้า ๙๘–๑๑๒) และการโปรดนางยักษิณีหารีตี (เรื่องที่ ๔๑๓–๔๑๔, หน้า ๑๑๕–๑๑๗) ใน *จ๋าเป่าจั้งจิง* ไปใช้อธิบายพิธีกรรมการพลีทานอาหารให้แก่ยักษ์และอมนุษย์ในอารามพุทธศาสนา ซึ่งกลายมาเป็นธรรมเนียมปฏิบัติมาตรฐานในพระวินัยของทุกนิกาย

8. **บทที่ ๘: ธรรมเนียมชาดกในเอเชียตะวันออกเฉียงใต้: สยาม พม่า ลาว เขมร และปัญญาสชาดก**
   - **หัวข้อย่อย ๘.๑ (มหาชาติเวสสันดรเปรียบเทียบระหว่างสำนวนบาลีกับมหาชาติภาษาจีน):**  
     นำตัวบท *สูตรว่าด้วยมกุฎราชกุมารสุทานะ* (เรื่องที่ ๕๐๐, หน้า ๓๖๒–๓๙๕) มาเปรียบเทียบคำต่อคำกับ *มหาเวสสันดรชาดก* (Vessantara-jātaka, ชาดกบาลีลำดับที่ ๕๔๗) และมหาชาติคำหลวงของสยาม วิเคราะห์ความต่างของชื่อตัวละคร เช่น พระเวสสันดรเป็น "สุทานะ" (Sudāna), นางมัทรีเป็น "มันตี" (Man-ti / Maddī), ชาลีเป็น "เยลี่" (Ye-li / Jāli), พราหมณ์ชูชก, และเขาวงกตเป็น "เขาตั้นเท่อ" (Dangte / Vankagiri / 檀特山) เพื่อสืบค้นสายธารการแพร่กระจายของมหาชาติข้ามอารยธรรม
   - **หัวข้อย่อย ๘.๓ (นิทานสุบินทำนายกลียุคในภูมิภาคอุษาคเนย์):**  
     นำเรื่อง *สุบินสิบประการของพระเจ้าปเสนทิโกศล* (เรื่องที่ ๔๙๘, หน้า ๓๑๘–๓๒๕) ไปเปรียบเทียบกับ *มหาสุบินชาดก* (ชาดกบาลีลำดับที่ ๗๗) และคัมภีร์ทำนายฝันโบราณในราชสำนักอยุธยาและล้านช้าง ชี้ให้เห็นว่าโครงสร้างนิทานทำนายความเสื่อมถอยของสังคมและศาสนาทำหน้าที่เป็นวรรณกรรมวิพากษ์การเมืองและเตือนสติผู้ปกครองในเอเชียอาคเนย์อย่างต่อเนื่อง

9. **บทที่ ๙: ศิลปกรรม โบราณคดี และจารึกวิทยาว่าด้วยชาดกข้ามวัฒนธรรม**
   - **หัวข้อย่อย ๙.๑ (ภาพสลักพุทธประวัติและชาดก ณ ถ้ำหยุนกังและตุนหวง):**  
     เชื่อมโยงตัวบท *จ๋าเป่าจั้งจิง* กับภาพสลักนูนต่ำในถ้ำหยุนกัง ถ้ำหลงเหมิน และจิตรกรรมฝาผนังถ้ำมั่วเกาแห่งตุนหวง โดยเฉพาะภาพมหาทานของพระสุทานะ (เวสสันดร) ภาพนางหารีตีอุ้มทารก และภาพการสละเนื้อตนเองช่วยพ่อแม่ เพื่อยืนยันว่าตัวบทที่ Chavannes แปลคือต้นฉบับทางเทววิทยาที่กำกับช่างศิลป์โบราณในการรังสรรค์มหาพุทธศิลป์
   - **หัวข้อย่อย ๙.๓ (การสัญจรของลวดลายศิลปกรรมข้ามทวีป: จากคันธาระสู่ลุ่มแม่น้ำฮวงโห):**  
     วิเคราะห์ภาพสะท้อนทางศิลปกรรมที่ได้รับอิทธิพลศิลปะเกรโก-พุทธ (Greco-Buddhist art) แห่งคันธาระที่ไหลเวียนผ่านเส้นทางสายไหมเข้ามาปรากฏในรายละเอียดของฉาก ปราสาท และเครื่องแต่งกายของบุคคลในนิทานอวทาน

10. **บทที่ ๑๐: ประวัติศาสตร์นิพนธ์และการศึกษาวิจัยเชิงวิพากษ์ระดับสากล ๗ ภาษา**
    - **หัวข้อย่อย ๑๐.๑ (การประสานพลังวิชาการระหว่าง Chavannes, Sylvain Lévi และ Édouard Huber):**  
      ประเมินบทบาทของสำนักฝรั่งเศสในการบูรณาการจีนวิทยาเข้ากับภารตวิทยา Chavannes ได้ใช้เชิงอรรถดึงข้อค้นพบของ Sylvain Lévi เกี่ยวกับตำนานพระรามและพระเวสสันดร และข้อค้นพบของ Édouard Huber เกี่ยวกับต้นฉบับสันสกฤตของ *ทิวยาวทาน* และนิทานเปรียบเทียบ มาสร้างระเบียบวิธีวิจัยแบบสหวิทยาการที่ไม่มีสำนักวิชาการใดเทียบเคียงได้ในยุคนั้น
    - **หัวข้อย่อย ๑๐.๔ (การเปรียบเทียบวรรณกรรมข้ามวัฒนธรรม: พุทธศาสนากับคติชนกรีกและอียิปต์):**  
      วิเคราะห์ข้อเสนอสะท้านวงการของ Chavannes ในเรื่องที่ ๔๙๘ (หน้า ๓๑๘–๓๑๙) ที่นำนิทานสุบินเรื่องคนฟั่นเชือกแล้วมีสัตว์กัดกินปลายเชือก ไปเชื่อมโยงกับตำนานกรีกโบราณเรื่อง "อ็อกนอส" (Oknos) ในภาพวาดของโพลีกโนตุส (Polygnotus) ตามบันทึกของเปาซาเนียส (Pausanias) และพิธีกรรมอียิปต์โบราณที่เมืองอะแคนธัส (Akanthos) ตามบันทึกของไดโอดอรุส ซิคุลุส (Diodorus Siculus) แสดงให้เห็นการเดินทางของนิทานคติชนสากลตั้งแต่ลุ่มน้ำไนล์ ทะเลอีเจียน สู่ลุ่มน้ำคงคาและแม่น้ำฮวงโห

11. **บทที่ ๑๑: การสืบสวนปัญหานิทานคู่ขนาน (Parallels), นิทานซ้ำซ้อน (Duplicates), และความคลาดเคลื่อนของจำนวน ๕๕๐/๕๔๗ เรื่อง**
    - **หัวข้อย่อย ๑๑.๒ (การกระจายตัวของนิทานเดี่ยวในฐานะหลักฐานการประกอบสร้างสารบบชาดก):**  
      ใช้นิทานเรื่องสัตว์ใน *เซิงจิง* (เช่น ลิงกับจระเข้/เต่า เรื่องที่ ๔๒๕, หน้า ๑๕๕–๑๖๖) และ *จิงลวี่อี้เซี่ยง* (เรื่องที่ ๔๘๖, หน้า ๒๗๘) มาสืบสวนคู่ขนานกับ *วานรินทชาดก* (ชาดกบาลีลำดับที่ ๕๗) และ *มกสชาดก* ชี้ให้เห็นว่า นิทานเรื่องเดียวกันถูกจัดเข้าสู่สารบบบาลีในฐานะ "ชาดก" แต่อยู่ในสารบบจีนในฐานะ "พระสูตร" (Sūtra) หรือ "อวทาน" (Avadāna) สิ่งนี้เป็นกุญแจสำคัญที่พิสูจน์ว่า จำนวน ๕๕๐ หรือ ๕๔๗ เรื่องของฝ่ายบาลีมิใช่ตัวเลขสัมบูรณ์ทางประวัติศาสตร์ หากเป็นผลลัพธ์ของการจัดหมวดหมู่เชิงสถาบันของสำนักมหาวิหารในลังกา
    - **หัวข้อย่อย ๑๑.๔ (การแปรผันของจำนวนสุบินจาก ๑๖ สู่ ๑๐ ประการ):**  
      สืบสวนข้อเท็จจริงที่ว่า ในขณะที่คัมภีร์ฝ่ายบาลี (*มหาสุบินชาดก*, ชาดกบาลีลำดับที่ ๗๗) ระบุพระสุบินของพระเจ้าปเสนทิโกศลไว้ ๑๖ ประการ แต่ตัวบทภาษาจีนโบราณของพระถานอู๋หลาน (เรื่องที่ ๔๙๘, หน้า ๓๑๘–๓๒๕) และฉบับเอกตตรอาคมกลับบันทึกไว้เพียง ๑๐ ประการ ความแตกต่างนี้สะท้อนกระบวนการขยายตัวของวรรณกรรมในชั้นอรรถกถาบาลีที่แต่งเติมสุบินเพิ่มขึ้นอีก ๖ ประการในยุคหลัง

12. **บทที่ ๑๒: บทสังเคราะห์ ทฤษฎีวิพากษ์ และขอบฟ้าใหม่ของชาดกศึกษา**
    - **หัวข้อย่อย ๑๒.๑ (ทฤษฎีการกลายรูปของมโนทัศน์ความตายและการรักษาความบริสุทธิ์ของจิต):**  
      สังเคราะห์บทเรียนจาก *ชูเย่าจิง* เรื่องเจ้าชายวีตโศก (Chan-jong / Vītāśoka, เรื่องที่ ๔๙๓, หน้า ๒๙๗–๓๐๙) ที่พระเจ้าอโศกทรงใช้นักดาบเงื้อดาบจ่อคอตลอด ๗ วัน เพื่อพิสูจน์ว่าความตระหนักรู้ในมรณานุสติสามารถดับกามราคะได้อย่างสิ้นเชิง สร้างข้อเสนอเชิงทฤษฎีว่า วรรณกรรมชาดกและอวทานทำหน้าที่เป็น "เทคโนโลยีทางจิตวิญญาณ" (Spiritual Technology) ในการปรับเปลี่ยนพฤติกรรมมนุษย์ผ่านประสบการณ์จำลองทางวรรณศิลป์
    - **หัวข้อย่อย ๑๒.๓ (ทฤษฎีมหาทานบารมีกับการรื้อถอนพันธะทางโลก):**  
      สังเคราะห์มหากาพย์พระสุทานะ (เวสสันดร, เรื่องที่ ๕๐๐) ในฐานะจุดสุดยอดของจริยศาสตร์พุทธศาสนา ที่การสละสิ่งอันเป็นที่รักสูงสุด (บุตรและภรรยา) มิใช่การละเลยหน้าที่ทางครอบครัว หากเป็นการทดสอบขั้นเด็ดขาดในการทำลายอวิชชาและความยึดมั่นใน "ความเป็นเจ้าของ" (อัตตานุทิฏฐิ) เพื่อเปิดทางสู่พระสัมมาสัมโพธิญาณที่จะกลับมาปลดปล่อยสรรพสัตว์ทั้งปวง

### ส่วนที่ 3: สรุปสาระสำคัญเชิงวิเคราะห์และจุดยืนทางวิชาการ (Executive Academic Analysis)

- **วิทยานิพนธ์และข้อถกเถียงหลักของผู้เขียน (Core Argument / Thesis):**  
  เอดัวร์ ชาวานน์ (Édouard Chavannes) ได้นำเสนอข้อถกเถียงเชิงประวัติศาสตร์วรรณกรรมและเทววิทยาพุทธศาสนาใน *Cinq cents contes et apologues* เล่มที่ ๓ (๑๙๑๑) ไว้อย่างแหลมคมและเป็นรากฐานสำคัญ ๕ ประการ:  
  ๑) *คัมภีร์รัตนปิฎกปกิณณกะ (Tsa pao tsang king) ในฐานะสะพานเชื่อมระหว่างพุทธศิลป์ถ้ำหยุนกังกับวรรณกรรมอวทาน:*  
     Chavannes ได้เปิดเผยข้อเท็จจริงทางประวัติศาสตร์ชิ้นเอกในหน้า ๑ (เชิงอรรถที่ ๑) ว่า พระถานเย่า (T'an-yao / 曇曜) ผู้ร่วมแปล *จ๋าเป่าจั้งจิง* ในปี ค.ศ. ๔๗๒ ภายใต้การสนับสนุนของจักรพรรดิแห่งราชวงศ์เว่ยเหนือ แท้จริงแล้วคือภิกษุผู้เป็นหัวเรี่ยวหัวแรงหลักในการริเริ่มโครงการแกะสลักพุทธสถานถ้ำหินหยุนกัง (Yungang Grottoes) ทางตะวันตกของเมืองต้าถง Chavannes ชี้ว่า พระถานเย่ามิได้เป็นเพียงผู้เผยแพร่วรรณกรรมอวทานในราชสำนักเว่ยเหนือเท่านั้น หากแต่เป็น "มหาศิลปินผู้ให้แรงขับเคลื่อนอันทรงพลังและแปลกใหม่อย่างยิ่งแก่งานประติมากรรมทางศาสนาในภาคเหนือของจีน" ข้อถกเถียงนี้สร้างข้อสรุปว่า นิทานอวทานใน *จ๋าเป่าจั้งจิง* คือคลังข้อมูลภาพและมโนทัศน์ที่ถูกแปรเปลี่ยนเป็นงานศิลปกรรมหินสลักอันยิ่งใหญ่ของเอเชียตะวันออก  
  ๒) *การปรับแปลงมหากาพย์นอกพุทธสู่วรรณกรรมชาดก: กรณีศึกษารามเกียรติ์ฉบับพุทธ (The Buddhist Reshaping of the Rāma Epic):*  
     ในหน้า ๑–๒ Chavannes ได้สรุปความนิทานเรื่องท้าวทศรถและพระราม ซึ่งสอดคล้องกับข้อค้นพบของ Sylvain Lévi (๑๙๐๓) ชี้ให้เห็นว่าพุทธศาสนามิได้ปฏิเสธมหากาพย์ฮินดู หากแต่ทำการ "ถอดรหัสและประกอบสร้างใหม่" (Deconstruction and Reconstruction) โดยกำจัดการรบราฆ่าฟัน มหากาพย์ยักษ์ทศกัณฐ์ และการลักพาตัวนางสีดาออกไป แล้วขับเน้นเฉพาะคุณธรรมความกตัญญูกตเวทิตา ความรักระหว่างพี่น้อง และความยุติธรรมในการสละราชสมบัติ การที่พระภรตนำฉลองพระบาทของพระรามมาประดิษฐานบนบัลลังก์และกราบไหว้เช้าค่ำเป็นเวลา ๑๒ ปี ได้กลายมาเป็นตัวแบบของจริยธรรมขงจื๊อที่ลงรอยกับคำสอนเรื่องกตัญญุตาธรรมของพุทธศาสนาอย่างแนบเนียน  
  ๓) *สารานุกรมพุทธศาสนาสมัยราชวงศ์เหลียงในฐานะคลังอรรถาธิบายข้ามคัมภีร์ (Jinglü yixiang as an Encyclopedic Narrative Matrix):*  
     ในการแปลชุดนิทาน ๕๑ เรื่องจาก *จิงลวี่อี้เซี่ยง* (經律異相, นิทานเรื่องที่ ๔๓๙–๔๘๙, หน้า ๒๐๘–๒๘๒) Chavannes ชี้ให้เห็นว่า คัมภีร์ที่รวบรวมขึ้นในปี ค.ศ. ๕๑๖ โดยพระป่าวชั่งและพระเซิงหมิน เป็นพยานหลักฐานแห่งความพยายามของพระสงฆ์จีนในการจัดระเบียบนิทานชาดก อวทาน และเรื่องเล่าจากพระสูตรและพระวินัยที่กระจัดกระจายอยู่ในคัมภีร์หลายร้อยเล่มให้กลายเป็นระบบสารานุกรม นิทานเหล่านี้ทำหน้าที่เป็นเครื่องมือเทศนาธรรมและเป็นคลังปัญญาที่ตอบคำถามทางจริยศาสตร์ นิติศาสตร์ และการปกครองของรัฐโบราณ  
  ๔) *การเดินทางข้ามอารยธรรมของนิทานคติชน: วงรอบสากลจากกรีก อียิปต์ สู่พุทธศาสนา (The Global Migration of Folkloric Motifs):*  
     ในการวิเคราะห์ *สูตรว่าด้วยพระสุบินสิบประการของพระเจ้าปเสนทิโกศล* (เรื่องที่ ๔๙๘, หน้า ๓๑๘–๓๒๕) Chavannes ได้สร้างคุณูปการระดับปฏิวัติวงการคติชนวิทยาเปรียบเทียบ โดยพิสูจน์ว่า นิทานสุบินข้อที่ ๕ ว่าด้วยชายฟั่นเชือกแล้วมีแกะ/ชะมดแอบกินปลายเชือก ตรงกับตำนานกรีกโบราณเรื่อง "อ็อกนอส" (Oknos) ที่ปรากฏในภาพจิตรกรรมฝาผนังแดนบาดาลของโพลีกโนตุส ณ เมืองเดลฟี ตามที่เปาซาเนียสบันทึกไว้ และยังปรากฏเป็นพิธีกรรมเชิงสัญลักษณ์ในเมืองอะแคนธัส ประเทศอียิปต์ ตามบันทึกของไดโอดอรุส ซิคุลุส Chavannes เสนอว่า นิทานอุปมามิใช่สมบัติผูกขาดของชาติพันธุ์ใด หากเป็น "มรดกทางปัญญาร่วมของมนุษยชาติ" ที่หมุนเวียนและแลกเปลี่ยนกันผ่านเส้นทางการค้าโบราณ  
  ๕) *พระสุทานะ (เวสสันดร) ในฐานะจุดยอดสุดแห่งทานบารมีในสารบบพุทธฝ่ายเหนือ:*  
     การที่ Chavannes ปิดท้ายชุดนิทานห้าร้อยเรื่องด้วย *สูตรว่าด้วยมกุฎราชกุมารสุทานะ* (เรื่องที่ ๕๐๐, หน้า ๓๖๒–๓๙๕) เป็นการตอกย้ำว่า ไม่ว่าในฝ่ายเถรวาทบาลีหรือฝ่ายสันสกฤต-จีน นิทานเวสสันดรคือ "มหาชาดก" (The Great Jātaka) ที่มีความสำคัญสูงสุดในฐานะบทสรุปแห่งการบำเพ็ญทานบารมีขั้นปรมัตถ์ Chavannes ได้วิเคราะห์การถอดเสียงชื่อเฉพาะ เช่น "สุทานะ" (Sudāna / 須達拏) ซึ่งผู้แปลภาษาจีนเข้าใจว่าหมายถึง "ผู้มีมหาทานอันประเสริฐ" แต่นักนิรุกติศาสตร์อย่าง Foucher และ Sylvain Lévi ชี้ว่าอาจแปลงมาจากรูปศัพท์ "Sudanta" (ผู้มีทนต์อันงาม หรือผู้ฝึกตนดีแล้ว) การวิเคราะห์นี้เปิดมิติใหม่ในการศึกษาวิวัฒนาการของตัวบทมหาชาติข้ามภาษา

- **บริบทประวัติศาสตร์นิพนธ์ ระเบียบวิธีวิจัย และการประเมินความน่าเชื่อถือเชิงวิพากษ์ (Historiography, Methodology & Source Criticism):**  
  - *จุดยืนทางประวัติศาสตร์นิพนธ์ของสำนักบูรพคดีศึกษาฝรั่งเศส (The French Orientalist School):*  
    Édouard Chavannes ดำรงตำแหน่งศาสตราจารย์แห่งกอแลฌเดอฟร็องส์ในช่วงรอยต่อศตวรรษที่ ๑๙–๒๐ ซึ่งเป็นยุคทองของวิชาการบูรพคดีศึกษาฝรั่งเศส Chavannes ได้นำระเบียบวิธีวิจัยประวัติศาสตร์เชิงวิพากษ์ (Historical-Critical Method) มาผสานเข้ากับนิรุกติศาสตร์ภาษาจีนโบราณ เขาปฏิเสธแนวคิดที่ถือว่าคัมภีร์ภาษาบาลีเป็นตัวแทนแต่เพียงหนึ่งเดียวของพุทธศาสนาดั้งเดิม และพิสูจน์ให้วงการวิชาการยุโรปประจักษ์ว่า พระไตรปิฎกภาษาจีนได้เก็บรักษาตัวบทพุทธศาสนาอินเดียยุคแรก (ศตวรรษที่ ๒–๕) ที่สูญหายไปแล้วในดินแดนต้นกำเนิดไว้อย่างซื่อตรงและสมบูรณ์แบบที่สุด  
  - *เครือข่ายวิชาการและการสอบทานข้ามวัฒนธรรม (Scholarly Network and Cross-Verification):*  
    ในเล่ม ๓ Chavannes ได้ร่วมมืออย่างใกล้ชิดกับนักวิชาการชั้นนำระดับโลก เช่น Sylvain Lévi (ผู้เชี่ยวชาญภาษาสันสกฤตและวรรณกรรมพุทธศาสนา), Édouard Huber (ผู้ค้นพบและแปลตัวบทเปรียบเทียบจากเอกสารตัวเขียนสันสกฤตในเอเชียกลาง), Alfred Foucher (บิดาแห่งการศึกษาศิลปะคันธาระ), และอ้างอิงงานแปลบาลีของ T. W. Rhys Davids, V. Fausböll, และ H. Oldenberg การทำงานร่วมกันข้ามสาขาวิชาเช่นนี้ทำให้เชิงอรรถของ Chavannes กลายเป็น "เหมืองทองคำทางวิชาการ" ที่เชื่อมโยงภาษาจีน สันสกฤต บาลี ทิเบต กรีก และละติน เข้าด้วยกันอย่างเป็นระบบ  
  - *การวิพากษ์ความน่าเชื่อถือและข้อจำกัดของตัวบท (Source Criticism and Textual Limitations):*  
    Chavannes แสดงความโปร่งใสทางวิชาการอย่างสูงในการประเมินคุณค่าของตัวบทแปลภาษาจีน ตัวอย่างเช่น ในบทนำของ *เซิงจิง* (生經, หน้า ๑๔๗, เชิงอรรถที่ ๑) Chavannes วิจารณ์อย่างตรงไปตรงมาว่า สำนวนแปลของพระธรรมรักษะ (Fa-hou / 竺法護) ในปี ค.ศ. ๒๘๕ นั้น "บกพร่องจนถึงขั้นอ่านไม่เข้าใจในหลายจุด" (cette traduction est défectueuse au point d’être enหลายจุด inintelligible) ทำให้เขาตัดสินใจเลือกแปลเฉพาะบางเรื่องที่สามารถสกัดความหมายทางประวัติศาสตร์วรรณกรรมได้อย่างชัดเจนเท่านั้น นอกจากนี้ ใน *จิงลวี่อี้เซี่ยง* Chavannes ยังชี้ให้เห็นความยากลำบากในการสืบค้นแหล่งกำเนิดดั้งเดิมของตัวบท เนื่องจากคัมภีร์ต้นฉบับหลายเล่มได้สูญหายไปตามกาลเวลา

### ส่วนที่ 4: สารบัญข้อค้นพบเชิงลึกตามประเด็นหลักอย่างละเอียด (Exhaustive Thematic Findings with Exact Pages)
*วิเคราะห์เจาะลึก ๑๒ ประเด็นหลัก โดยอธิบายบริบท ตัวบทเปรียบเทียบ นัยทางเทววิทยา ประวัติศาสตร์วรรณกรรม พร้อมระบุเลขหน้าหนังสือจริงกำกับทุกข้อ:*

1. **การกำเนิดของพุทธศิลป์ถ้ำหยุนกังกับวรรณกรรมอวทาน: พระถานเย่าและการปฏิรูปศาสนาใต้ร่มเงาราชวงศ์เว่ยเหนือ (บทนำจ๋าเป่าจั้งจิง, หน้า ๑):**  
   ในเชิงอรรถเปิดเล่มของ *จ๋าเป่าจั้งจิง* (雜寶藏經, Samyukta-ratnapiṭaka-sūtra, หน้า ๑, เชิงอรรถที่ ๑) Chavannes ได้สร้างข้อค้นพบที่เชื่อมโยงประวัติศาสตร์วรรณกรรมเข้ากับประวัติศาสตร์ศิลปะและโบราณคดีอย่างลึกซึ้ง โดยระบุว่า พระถานเย่า (T'an-yao / 曇曜) ผู้ร่วมแปลคัมภีร์นี้กับพระกิกายะ (Ki-kia-ye) ในปี ค.ศ. ๔๗๒ ภายใต้พระบรมราชโองการของจักรพรรดิแห่งราชวงศ์เว่ยเหนือ คือบุคคลเดียวกับที่เป็น "ผู้อำนวยการและผู้ริเริ่มงานศิลปกรรมอันยิ่งใหญ่ในการเจาะสกัดหน้าผาหินสร้างเป็นวัดถ้ำพุทธศาสนา ณ ถ้ำหยุนกัง (Yungang Grottoes) ทางตะวันตกของเมืองต้าถงฝู" (le promoteur du grand travail artistique qu'on fit pour aménager en temples bouddhiques les grottes dans le roc situées à Yun-kang) ตามที่มีบันทึกใน *ซวี่เกาเซิงจ้วน* (續高僧傳) และ *เว่ยซู* (魏書, บรรพ ๑๑๔) Chavannes ชี้ชัดว่า พระถานเย่าดำรงสถานะเป็นทั้งผู้เผยแผ่วรรณกรรมอวทานในราชสำนักเว่ยเหนือ และเป็นมหาศิลปินผู้ขับเคลื่อนประติมากรรมพุทธศาสนาให้เฟื่องฟูอย่างทรงพลังในภาคเหนือของจีน ตัวบท *จ๋าเป่าจั้งจิง* จึงมิใช่วรรณกรรมกระดาษที่แยกขาดจากโลกทางกายภาพ หากแต่เป็น "พิมพ์เขียวทางเทววิทยา" (Theological Blueprint) ที่ถูกถ่ายทอดลงสู่ภาพสลักนูนต่ำในถ้ำหยุนกัง เพื่อฟื้นฟูศรัทธาของประชาชนภายหลังการกวาดล้างพุทธศาสนาในรัชสมัยพระเจ้าไท่อู่ตี้

2. **มหากาพย์รามายณะในครรภ์พุทธศาสนา: พระราม พระภรต และฉลองพระบาททองคำบนบัลลังก์ (บทนำจ๋าเป่าจั้งจิง, หน้า ๑–๒):**  
   ใน *จ๋าเป่าจั้งจิง* (หน้า ๑–๒) บันทึกตำนานพระรามฉบับพุทธศาสนาโบราณ โดยระบุชื่อกษัตริย์ท้าวทศรถ (Che-che / Daçaratha) และพระราชโอรส ๔ พระองค์จากมเหสี ๔ องค์ ได้แก่ พระราม (Lo-mo / Râma), พระลักษมณ์ (Lo-man / Lakṣmaṇa), พระภรต (P'o-lo-t'o / Bharata), และพระสัตรุด (Tueur d'ennemis / Śatrughna) มเหสีองค์ที่สามฉวยโอกาสตอนพระราชาประชวร บังคับให้ตั้งพระภรตขึ้นเป็นกษัตริย์ พระรามและพระลักษมณ์จึงถูกเนรเทศเดินดงเป็นเวลา ๑๒ ปี แต่พระภรตผู้มีคุณธรรมสูงส่งปฏิเสธที่จะครองราชย์และประสงค์จะคืนอำนาจให้พระราม พระรามปฏิเสธที่จะกลับก่อนครบกำหนด ๑๒ ปี พระภรตจึงขอรับ "ฉลองพระบาท" (sandales) ของพระราม นำมาประดิษฐานไว้บนพระราชบัลลังก์ และกราบไหว้ทุกเช้าค่ำประดุจพระเชษฐาประทับอยู่ต่อหน้า จนกระทั่งครบ ๑๒ ปี พระรามจึงกลับมาครองราชสมบัติ Chavannes อ้างอิงบทวิเคราะห์ของ Sylvain Lévi (๑๙๐๓) ชี้ให้เห็นว่า นิทานเรื่องนี้เป็นการหยิบยืมโครงสร้างมหากาพย์รามายณะมาดัดแปลงเป็น "นิทานแสดงความกตัญญูและความสมานฉันท์ในครอบครัว" ตามโลกทัศน์พุทธศาสนาที่สอดรับกับจริยธรรมจีน โดยตัดทอนสงคราม การฆ่ายักษ์ และความขัดแย้งเชิงกามารมณ์ออกไปจนหมดสิ้น

3. **มหาทานแห่งการเฉือนเนื้อตนเองเลี้ยงดูบิดามารดาและพลังแห่งสัจกิริยา (บทนำจ๋าเป่าจั้งจิง, หน้า ๒–๓):**  
   ตัวบทในหน้า ๒–๓ เล่าเรื่องราวกษัตริย์ผู้ถูกเสนาบดีหลัวโหวชิว (Lo-heou-k'ieou) ก่อกบฏสังหารพร้อมโอรส ๕ พระองค์ โอรสองค์ที่หกพร้อมพระชายาและบุตรน้อยได้รับคำเตือนจากเทวดาจึงหลบหนีเข้าสู่ทะเลทราย เสบียงอาหารหมดลงหลังจาก ๗ วัน พระบิดาคิดจะสังหารพระชายาเพื่อนำเนื้อมากินประทังชีวิต แต่บุตรน้อยได้กราบทูลขอสละชีวิตตนเอง โดยขอให้บิดามารดาเฉือนเนื้อจากร่างกายของตนวันละส่วนเพื่อเป็นอาหารเดินทาง จนกระทั่งเหลือเนื้อ ๓ ชิ้นสุดท้าย บิดามารดากินคนละชิ้นและเหลือชิ้นสุดท้ายไว้ให้บุตรน้อยก่อนจะเดินโซเซไปถึงหมู่บ้าน ท้าวสักกเทวราช (Çakra Devendra) จำแลงกายเป็นหมาป่าหิวโซมาขอเนื้อชิ้นสุดท้าย เด็กน้อยก็สละให้โดยไม่ลังเล เมื่อท้าวสักกะคืนร่างเป็นเทวดาและถามว่า "ท่านเสียใจหรือไม่ที่สละเนื้อให้บิดามารดา?" เด็กน้อยตอบว่า "ข้าพเจ้ามิเคยมีความเสียใจแม้แต่น้อย หากถ้อยคำนี้เป็นสัจจะ ขอให้ร่างกายของข้าพเจ้าจงกลับคืนดีดังเดิมเถิด!" ทันใดนั้น ร่างกายของเด็กน้อยก็กลับสมบูรณ์บริสุทธิ์ดังเดิม นิทานเรื่องนี้สะท้อนโครงสร้างทางเทววิทยาเรื่อง "สัจกิริยา" (Saccakiriya) และทานบารมีขั้นอุกฤษฏ์ ซึ่งส่งอิทธิพลอย่างมหาศาลต่อวรรณกรรมกตัญญูในเอเชียตะวันออก

4. **การบำเพ็ญทานต่อสงฆ์และการถวายผ้าจีวรของพระนางมหาปชาบดีโคตมี (เรื่องที่ ๔๐๖, หน้า ๔๖–๕๓):**  
   ใน *จ๋าเป่าจั้งจิง* (เรื่องที่ ๔๐๖, หน้า ๔๖–๕๓) บันทึกเรื่องราวเมื่อพระนางมหาปชาบดีโคตมี (Ta-ngai-tao / Mahāprajāpatī) ทรงทอผ้ากาสาวพัสตร์ด้วยพระหัตถ์ของพระนางเองอย่างประณีตวิจิตร แล้วนำมาน้อมถวายแด่พระสัมมาสัมพุทธเจ้า แต่พระพุทธองค์กลับทรงปฏิเสธที่จะรับไว้เฉพาะพระองค์ และมีพุทธบัญชาให้พระนางนำผ้านั้นไปถวายแด่ "ภิกษุสงฆ์" (Saṅgha) พระอานนท์ได้กราบทูลถามว่าเหตุใดจึงไม่ทรงรับผ้าจากพระมาตุจฉาผู้ทรงมีพระคุณยิ่ง พระพุทธองค์ทรงตรัสตอบว่า *"การถวายทานเจาะจงเฉพาะบุคคล (ปาฏิบุคลิกทาน) แม้ต่อพระพุทธเจ้า ย่อมมีอานิสงส์ไม่เทียบเท่าการถวายทานแด่สงฆ์ผู้เป็นส่วนรวม (สังฆทาน)"* Chavannes ชี้ให้เห็นว่า ตัวบทตอนนี้มีความสำคัญอย่างยิ่งยวดต่อประวัติศาสตร์นิติศาสตร์และเทววิทยาพุทธศาสนา เพราะเป็นการสถาปนา "ความเป็นสถาบันของสังฆะ" ให้มีความศักดิ์สิทธิ์และมีสถานะเหนือกว่าตัวบุคคล แม้บุคคลนั้นจะเป็นพระสัมมาสัมพุทธเจ้าในเชิงกายภาพก็ตาม

5. **การเปลี่ยนรูปของอสูรและยักษ์สู่ธรรมบาล: อวทานการปราบยักษ์อาฬวกะและนางยักษิณีหารีตี (เรื่องที่ ๔๑๑, ๔๑๓, หน้า ๙๘–๑๑๗):**  
   Chavannes แปลและวิเคราะห์ตำนานการปราบอมนุษย์สองตนที่โด่งดังที่สุดในพุทธประวัติ ในเรื่องที่ ๔๑๑ (หน้า ๙๘–๑๑๒) คือการเผชิญหน้าระหว่างพระพุทธองค์กับ "ยักษ์แห่งถิ่นทุรกันดาร" (K'ouang-ye / Āṭavaka) ซึ่งเรียกร้องให้พระพุทธองค์ตอบปัญหาธรรมะอันลึกซึ้ง เมื่อยักษ์พ่ายแพ้ต่อพุทธปัญญา จึงยอมมอบกุมารที่ตนกำลังจะกินใส่ลงในบาตรของพระพุทธเจ้า (กุมารนั้นจึงได้นามว่า ขว้างเหย่โส่ว / K'ouang-ye-cheou) และในเรื่องที่ ๔๑๓ (หน้า ๑๑๕–๑๑๗) คือเรื่อง "นางหารีตี" (Hārītī / 鬼子母神) ภริยาของพญาอสูรปัญจิกะ (Pâñcika) นางมีบุตรถึง ๑๐,๐๐๐ คน แต่กลับชอบลักพาตัวเด็กทารกของชาวเมืองไปกิน พระพุทธองค์จึงทรงนำ "ปิังกละ" (Piṅgala) บุตรคนสุดท้องที่นางรักที่สุดไปซ่อนไว้ใต้บาตรศิลา นางหารีตีเหาะค้นหาทั่วจักรวาลนานถึง ๗ วันก็ไม่พบ จึงมาร้องไห้คร่ำครวญต่อพระพุทธองค์ พระพุทธองค์จึงทรงตักเตือนว่า *"ท่านมีบุตรหมื่นคน สูญเสียไปเพียงคนเดียวยังเจ็บปวดปานนี้ มนุษย์ทั้งหลายมีบุตรเพียงคนหรือสองคน เมื่อท่านจับบุตรของเขาไปกิน ความทุกข์ของบิดามารดาเหล่านั้นจะยิ่งใหญ่เพียงใด!"* เมื่อนางสำนึกผิด พระพุทธองค์ทรงให้รับศีล ๕ และบัญญัติให้ภิกษุสงฆ์ในอารามแบ่งส่วนอาหารโปรยทานให้นางและบุตรทุกวัน Chavannes ชี้ว่า เรื่องเล่านี้คือรากฐานของพิธีกรรมทางศาสนาและคติการบูชาเทพารักษ์คุ้มครองเด็กในวัดพุทธทั่วเอเชีย

6. **ความคลุมเครือเชิงคัมภีร์และคุณค่าทางประวัติศาสตร์ของ "เซิงจิง" (ชาตกสูตรฉบับธรรมรักษะ): คาถาสุภาษิตและนิทานสัตว์ (เรื่องที่ ๔๒๓–๔๓๘, หน้า ๑๔๗–๒๐๗):**  
   ในส่วนคัดสรรจาก *เซิงจิง* (生經, T. 154) Chavannes บันทึกข้อวิจารณ์เชิงประวัติศาสตร์วรรณกรรมที่สำคัญยิ่งในหน้า ๑๔๗ โดยระบุว่า แม้สำนวนแปลของพระธรรมรักษะในปี ค.ศ. ๒๘๕ จะมีความยากและข้อผิดพลาดทางไวยากรณ์ แต่ตัวบทได้เก็บรักษาเค้าโครงของชาดกสันสกฤตยุคโบราณไว้อย่างน่าอัศจรรย์ เช่น ในเรื่องที่ ๔๒๕ (หน้า ๑๕๕–๑๖๖) เล่าเรื่องมิตรภาพระหว่างลิงกับเต่า ซึ่งภรรยาของเต่าอยากกินหัวใจลิง (ตรงกับ *วานรินทชาดก* และ *สุงสุมารชาดก* ชาดกบาลีลำดับที่ ๕๗ และ ๒๐๘) และในเรื่องที่ ๔๒๘ (หน้า ๑๗๓) ที่สุนัขจิ้งจอกกับกากล่าวสรรเสริญยกย่องซึ่งกันและกันเพื่อแบ่งซากสัตว์กิน Chavannes ชี้ให้เห็นว่า นิทานสัตว์ใน *เซิงจิง* เป็นพยานหลักฐานว่าโครงเรื่องชาดกในอินเดียโบราณได้แพร่หลายข้ามวัฒนธรรมในรูปของนิทานคติธรรมก่อนที่จะถูกจำแนกเข้าสู่สารบบบาลีอย่างเป็นทางการ

7. **วิวาทะแห่งสรีระกับการจัดสรรความชอบธรรม: นิทานน้ำนมแม่ราชสีห์และการแย่งมรดกในจิงลวี่อี้เซี่ยง (เรื่องที่ ๔๓๙, หน้า ๒๐๘–๒๑๓):**  
   ใน *จิงลวี่อี้เซี่ยง* (經律異相, เรื่องที่ ๔๓๙, หน้า ๒๐๘–๒๑๓) พระพุทธองค์ทรงระงับข้อพิพาทของพี่น้อง ๔ คนผู้แย่งชิงมรดก โดยทรงยกนิทานอดีตชาติของพระเจ้าเหว่ยหลิว (Wei-leou) ผู้ประชวรหนักและแพทย์สั่งให้ปรุงยาด้วย "น้ำนมแม่ราชสีห์" ชายหนุ่มคนหนึ่งอาสาไปรีดนมแม่ราชสีห์จนสำเร็จ แต่เมื่อนำกลับมารักษาพระราชา อวัยวะในร่างกายของเขากลับเกิดวิวาทะกัน เท้าอ้างว่า *"หากข้าพเจ้าไม่ก้าวเดิน ท่านจะไปถึงถ้ำราชสีห์ได้อย่างไร?"* ตาอ้างว่า *"หากข้าพเจ้าไม่มองเห็น ท่านจะเห็นราชสีห์ได้อย่างไร?"* มืออ้างว่า *"หากข้าพเจ้าไม่รีดนม ท่านจะได้น้ำนมมาอย่างไร?"* แต่ในที่สุด ลิ้นกล่าวว่า *"ข้าพเจ้าเพียงแต่กล่าวคำเท็จต่อพระราชาคำเดียวว่า นี่คือน้ำนมสุนัข พวกท่านทั้งหมดก็ต้องถูกประหารชีวิต!"* อวัยวะทั้งปวงจึงยอมจำนนต่ออำนาจแห่งลิ้น พระพุทธองค์ทรงอุปมาว่าความสำเร็จของมนุษย์เกิดจากการประสานพลังของหลายปัจจัย ผู้ใดที่หลงคิดว่าตนเองสำคัญแต่ผู้เดียวย่อมนำมาซึ่งความพินาศ ชาดกเรื่องนี้สะท้อนปรัชญาการเมืองโบราณเรื่องความร่วมมือในสังคมและอันตรายของวจีกรรม

8. **สัญศาสตร์แห่งความว่างเปล่าและมายาการทางโลก: มงกุฎฟองน้ำของเจ้าหญิงในจิงลวี่อี้เซี่ยง (เรื่องที่ ๔๔๗, หน้า ๒๒๓–๒๒๕):**  
   นิทานเรื่องที่ ๔๔๗ ใน *จิงลวี่อี้เซี่ยง* (หน้า ๒๒๓–๒๒๕) เล่าถึงพระราชธิดาผู้เห็นฟองน้ำผุดขึ้นบนผิวน้ำระหว่างฝนตก มีประกายแวววาวงดงามดั่งอัญมณี นางจึงกราบทูลพระบิดาว่า *"หม่อมฉันปรารถนาจะได้ฟองน้ำเหล่านั้นมาร้อยทำเป็นมงกุฎประดับศีรษะ หากไม่ได้ หม่อมฉันจะยอมตาย"* พระราชาทรงเกรงใจพระธิดาจึงสั่งให้นายช่างทองฝีมือเอกมาร้อยมงกุฎฟองน้ำ นายช่างทราบดีว่าเป็นสิ่งที่เป็นไปไม่ได้ จึงใช้อุบายกราบทูลเจ้าหญิงว่า *"ข้าพระองค์มีความชำนาญในการร้อยมงกุฎ แต่ไม่อาจทราบว่าพระองค์ทรงโปรดฟองน้ำลูกใด ขอเชิญเจ้าหญิงเสด็จไปทรงเลือกช้อนฟองน้ำขึ้นมาด้วยพระองค์เองเถิด แล้วข้าพระองค์จะร้อยถวายในทันที"* เจ้าหญิงทรงพยายามเอามือช้อนฟองน้ำ แต่เมื่อสัมผัส ฟองน้ำก็แตกสลายมลายไปในพริบตา เมื่อทรงพยายามทั้งวันจนเหน็ดเหนื่อย เจ้าหญิงจึงได้สติและตระหนักว่าฟองน้ำเป็นสิ่งไร้แก่นสาร พระพุทธองค์ทรงนำเรื่องนี้มาแสดงธรรมว่า รูป เสียง กลิ่น รส และความสุขทางโลกีย์ก็เปรียบเสมือนฟองน้ำอันว่างเปล่า ผู้มีปัญญาไม่พึงหลงใหลยึดติด

9. **ภูมิศาสตร์ประวัติศาสตร์และปกรณัมวิทยาแห่งราชคฤห์: กำเนิดพระเจ้าชราสันธ์ในมหาปรัชญาปารมิตาสูตรศาสตร์ (เรื่องที่ ๔๙๐, หน้า ๒๘๓–๒๘๗):**  
   ใน *ต้าจื้อตู้ลุ่น* (大智度論, เรื่องที่ ๔๙๐, หน้า ๒๘๓–๒๘๗) พระนาคารชุนได้อธิบายที่มาของชื่อเมือง "ราชคฤห์" (Rājagṛha / Wang-chô-tch'eng / 王舍城) โดยยกตำนานกษัตริย์แห่งมคธผู้มีพระโอรสประสูติออกมามีศีรษะเดียวแต่มี ๒ ใบหน้า และมี ๔ แขน ผู้คนถือว่าเป็นกาลกิณี พระราชาจึงสั่งให้ผ่าร่างทารกออกเป็นสองซีกแล้วนำไปทิ้งในป่าช้า นางรากษสีชื่อ "ชรา" (Li-lo / Jarā) เดินผ่านมาเห็น จึงนำชิ้นส่วนทั้งสองซีกมาประกบเข้าด้วยกันและให้นมดื่ม ร่างนั้นจึงประสานสนิทกลายเป็นมนุษย์สมบูรณ์ ทารกนั้นเติบโตขึ้นกลายเป็นกษัตริย์ผู้ทรงอานุภาพทั่วมหากาฬนามว่า "พระเจ้าชราสันธ์" (Jarasandha / 折羅散陀) และได้สถาปนาพระราชวังขึ้น ณ หุบเขาที่มีภูเขา ๕ ลูกล้อมรอบ จึงได้ชื่อว่าเมืองราชคฤห์ (ที่สถิตแห่งพระราชา) Chavannes ชี้ให้เห็นว่า ตัวบทตอนนี้เป็นการเชื่อมโยงตำนานมหากาพย์มหาภารตะเข้ากับภูมิศาสตร์ศักดิ์สิทธิ์ของพุทธศาสนา แสดงให้เห็นว่าพระพุทธศาสนามิได้แยกขาดจากบริบทวรรณคดีคลาสสิกของอินเดีย

10. **จิตวิทยาแห่งมรณานุสติกับการกำราบกามราคะ: พระเจ้าอโศก เจ้าชายวีตโศก และเพชฌฆาตถือดาบในชูเย่าจิง (เรื่องที่ ๔๙๓, หน้า ๒๙๗–๓๐๙):**  
    ใน *ชูเย่าจิง* (出曜經, เรื่องที่ ๔๙๓, หน้า ๒๙๗–๓๐๙) เจ้าชายวีตโศก (Chan-jong / Vītāśoka) พระอนุชาของพระเจ้าอโศกมหาราช ไปพบพวกพราหมณ์บำเพ็ญตบะทรมานกายกลางแดดฝน กินใบไม้วันละใบ แต่พราหมณ์เหล่านั้นสารภาพว่า เมื่อเห็นกวางผสมพันธุ์กันในป่า กามราคะก็ยังกำเริบขึ้นมา เจ้าชายจึงเกิดมิจฉาทิฐิดูหมิ่นพระภิกษุสงฆ์ในพุทธศาสนาว่า *"พวกสมณะศากยบุตรฉันภัตตาหารอันประณีต นอนบนเตียงหนานุ่ม นุ่งห่มผ้าเนื้อดี ไฉนเลยจะสามารถระงับกามราคะได้?"* พระเจ้าอโศกทรงทราบจึงทรงใช้อุบายจัดฉาก โดยมอบราชสมบัติให้พระอนุชาครองบัลลังก์อย่างเต็มที่มีนางสนมกำนัลปรนเปรอตลอด ๗ วัน แต่ทรงสั่งให้นายทหารสวมเกราะถือดาบคมกริบยืนคุมอยู่ข้างกาย โดยประกาศว่าเมื่อครบ ๗ วันจะสั่งประหารชีวิตทันที เมื่อครบกำหนด พระเจ้าอโศกตรัสถามว่า *"ตลอด ๗ วันที่ผ่านมา เจ้าได้ยินเสียงดนตรีอันไพเราะและเห็นความงามของหญิงระบำหรือไม่?"* เจ้าชายกราบทูลทั้งน้ำตาว่า *"ข้าแต่พระราชา หม่อมฉันมิได้ยินและมิได้เห็นสิ่งใดเลย เพราะสายตาของหม่อมฉันจับจ้องอยู่แต่คมดาบ และหูของหม่อมฉันได้ยินแต่เสียงระฆังที่บอกเวลาว่าความตายกำลังใกล้เข้ามาทุกขณะ!"* พระเจ้าอโศกจึงทรงตรัสสอนว่า *"ความกลัวตายเพียงชาติเดียวยังสามารถดับกามราคะของเจ้าได้ถึงเพียงนี้ แล้วไฉนเหล่าพระภิกษุสงฆ์ผู้พิจารณาเห็นภัยในสังสารวัฏ พิจารณาเห็นความตายที่จะมาถึงทุกลมหายใจเข้าออก และพิจารณาเห็นไฟนรกอันน่าสะพรึงกลัว จึงจะไม่สามารถดับกามราคะในจิตใจได้เล่า?"* เจ้าชายจึงทรงเลื่อมใสและขอบวชจนบรรลุธรรม

11. **พระสุบินสิบประการของพระเจ้าปเสนทิโกศลกับการเชื่อมโยงข้ามทวีปสู่อารยธรรมกรีก-อียิปต์ (เรื่องที่ ๔๙๘, หน้า ๓๑๘–๓๒๕):**  
    ใน *สูตรว่าด้วยพระสุบินสิบประการของพระเจ้าปเสนทิโกศล* (เรื่องที่ ๔๙๘, หน้า ๓๑๘–๓๒๕) พระพุทธองค์ทรงทำนายพระสุบินที่เป็นสัญลักษณ์แห่งความเสื่อมถอยในอนาคต (กลียุค/สมัยมรรคผลเสื่อม) โดยเฉพาะสุบินข้อที่ ๕ ว่าด้วยชายคนหนึ่งกำลังฟั่นเชือกอยู่ แต่มีแกะตัวเมียแอบกินปลายเชือกที่ฟั่นเสร็จไปเรื่อยๆ ทรงทำนายว่า ในอนาคตสามีจะทำงานหนักหาเงินทองมาได้ แต่ภรรยาที่เกียจคร้านและมีชู้จะแอบนำทรัพย์สินไปบำเรอชายอื่นจนหมดสิ้น Chavannes ได้ทำเชิงอรรถอันทรงคุณค่าระดับตำนาน (หน้า ๓๑๘–๓๑๙) โดยอ้างอิงบทความของ Rouse (๑๘๙๐) และ Frazer (๑๘๙๗) ชี้ว่า นิทานนี้ตรงกับตำนานกรีกโบราณเรื่อง "อ็อกนอส" (Oknos) ที่เปาซาเนียส (Pausanias, X, 29, 2) บันทึกไว้ว่าเป็นภาพวาดของโพลีกโนตุส ณ ถ้ำเทวพยากรณ์เดลฟี ซึ่งเป็นภาพชายนั่งฟั่นเชือกโดยมีลาตัวเมียคอยแทะกินเชือกอยู่ข้างหลัง จนชาวไอโอเนียนมีภาษิตว่า "เขากำลังฟั่นเชือกของอ็อกนอส" เพื่อหมายถึงการทำงานที่สูญเปล่า และยังตรงกับบันทึกของไดโอดอรุส ซิคุลุส (Diodorus Siculus, I, 97) ว่าในเมืองอะแคนธัสของอียิปต์โบราณมีพิธีกรรมแสดงละครตำนานอ็อกนอสเช่นเดียวกัน ข้อค้นพบนี้เป็นหลักฐานชิ้นเอกของการแพร่กระจายนิทานคติชนร่วมระหว่างอารยธรรมอินเดีย เฮลเลนิสติก และอียิปต์โบราณ

12. **มหาชาติเวสสันดรฉบับพระสูตรภาษาจีน: มกุฎราชกุมารสุทานะและการถวายบุตรภรรยาเป็นทานบารมี (เรื่องที่ ๕๐๐, หน้า ๓๖๒–๓๙๕):**  
    เรื่องที่ ๕๐๐ ซึ่งเป็นเรื่องสุดท้ายของมหากาพย์การแปล ๕๐๐ เรื่องของ Chavannes คือ *สูตรว่าด้วยมกุฎราชกุมารสุทานะ* (太子須大拏經, T. 171, หน้า ๓๖๒–๓๙๕) แปลโดยสมณะเซิ่งเจียนแห่งราชวงศ์ฉินตะวันตก ตัวบทนี้คือคู่ขนานที่สมบูรณ์ที่สุดของ *มหาเวสสันดรชาดก* พระสุทานะ (Sudāna) พระโอรสแห่งแคว้นเชอปัว (Che-po / Śibi) ทรงบริจาคช้างเผือกมงคลเดินบนดอกบัว (Sudānayāna) ให้แก่พราหมณ์แคว้นศัตรู ทำให้ชาวเมืองโกรธแค้น พระบิดาจึงเนรเทศไปอยู่ ณ เขาตั้นเท่อ (Dangte / Vankagiri / 檀特山) ระหว่างทางทรงบริจาครถม้าและม้าแก่พราหมณ์ จนต้องอุ้มบุตรจูงภรรยาเดินด้วยเท้า เมื่อประทับในป่า พราหมณ์ใจร้าย (ชูชก) มาทูลขอพระโอรสและพระธิดา (เยลี่ / Jāli และกัณหา) พระสุทานะทรงผูกข้อมือบุตรมอบให้ พราหมณ์ใช้กิ่งไม้เฆี่ยนตีจนเลือดไหลอาบร่าง พระนางมันตี (Maddī) ถูกสัตว์ร้าย (สิงโต เสือ เสือดาว ที่ท้าวสักกะแปลงมา) ขวางทางไว้ เมื่อกลับมาไม่พบบุตรก็ทรงร่ำไห้จนสลบแน่นิ่งไป จากนั้นท้าวสักกะจำแลงเป็นพราหมณ์มาทูลขอพระนางมันตี พระสุทานะก็ทรงบริจาคให้อีก ท้าวสักกะจึงคืนร่างและถวายพระนางคืน พร้อมประสาทพรให้พระอัยกาไถ่ตัวพระนัดดาทั้งสอง และยกขบวนมารับพระสุทานะกลับไปครองราชย์ Chavannes ได้วิเคราะห์การถอดเสียงชื่อตัวละครและการเปรียบเทียบกับภาพสลักคันธาระ ชี้ให้เห็นว่าเรื่องเล่าพระเวสสันดรเป็นแกนกลางแห่งมโนทัศน์โพธิสัตว์ที่หยั่งรากลึกในทุกนิกายของโลกพุทธศาสนา

Sylvain Lévi a traduit ce conte (*Mélanges Kern*, Leide, 1903, pp. 279-281) et y a signalé une des formes de la légende de Râma. » (Tome III, p. 2 et n. 1)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "พระภรต (P'o-lo-t'o) อย่างน้อยที่สุดก็ได้รับมอบฉลองพระบาทมาจากพระราม; พระองค์ทรงนำฉลองพระบาทนั้นไปประดิษฐานไว้บนพระราชบัลลังก์ และทรงกราบไหว้เบื้องหน้าฉลองพระบาทนั้นทั้งเวลาเช้าและเวลาค่ำ ประหนึ่งว่าพระองค์ได้ประทับอยู่ต่อหน้าพระเชษฐาของพระองค์อย่างแท้จริง เมื่อล่วงพ้นกำหนดสิบสองปี พระราม (Lo-mo) และพระลักษมณ์ (Lo-man) จึงเสด็จกลับคืนสู่มาตุภูมิ และพระภรตก็ทรงรีบเร่งถวายราชสมบัติคืนแด่พระรามโดยพลัน — ศาสตราจารย์ ซิลแว็ง เลวี ได้เคยแปลนิทานเรื่องนี้ไว้แล้ว (*Mélanges Kern*, Leiden, 1903, หน้า 279-281) และได้ชี้ให้เห็นว่านี่คือรูปแบบหนึ่งของตำนานพระราม"
- **บทวิเคราะห์ทางนิรุกติศาสตร์และคติชนเปรียบเทียบ:**  
  ข้อความนี้แสดงให้เห็นขนบ "ปาทุกา" (Pādukā) หรือการบูชารอยเท้า/ฉลองพระบาท ซึ่งในอินเดียโบราณถือเป็นสัญลักษณ์แทนองค์กษัตริย์หรือพระศาสดา ตัวบทใน *จ๋าเป่าจั้งจิง* ได้ตัดทอนองค์ประกอบสงครามและการชิงนางสีดาของรามายณะออกไป เพื่อขับเน้นเฉพาะประเด็นความจงรักภักดีระหว่างพี่น้อง (ภราดรธรรม) ซึ่งสอดคล้องกับคุณธรรม "ตี้" (悌 / ความรักเคารพพี่น้อง) ของลัทธิขงจื๊อ ทำให้ชาดกเรื่องนี้ได้รับการยอมรับอย่างกว้างขวางในสังคมจีน

#### ข้อความที่ ๓: อวทานการโปรดนางยักษิณีหารีตีและการซ่อนบุตรไว้ใต้บาตร
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « La mère des fils-démons était méchante et cruelle ; elle tuait les enfants des hommes pour s’en repaître... L’Honoré du monde prit alors le fils Pin-k'ia-lo (Piñgala) et le plaça au fond de son bol (pâtra). La mère des fils-démons parcourut le monde entier et, pendant sept jours, rechercha (Piñgala) sans le trouver... Le Buddha lui dit : « Vous avez dix mille fils ; vous n'en avez perdu qu'un seul et vous êtes déjà si affligée ; les hommes n’ont qu'un, ou deux, ou trois fils, et vous les leur prenez pour les tuer et les manger; comment n’auraient-ils pas de la douleur ? » » (Tome III, p. 115, N° 413)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "มารดาแห่งเหล่าบุตรอสูร (นางยักษิณีหารีตี) เป็นผู้มีจิตใจชั่วร้ายและโหดเหี้ยม นางเที่ยวฆ่าบุตรของมนุษย์เพื่อนำมาเป็นอาหารของตน... พระผู้มีพระภาคเจ้าจึงทรงนำบุตรคนสุดท้องชื่อปิังกละ (Pin-k'ia-lo / Piñgala) ไปประดิษฐานไว้ที่ก้นบาตร (pâtra) ของพระองค์ มารดาแห่งเหล่าบุตรอสูรเที่ยวออกค้นหาไปทั่วทั้งสากลโลกตลอดเจ็ดวันโดยไม่อาจค้นพบ... พระพุทธองค์จึงตรัสแก่นางว่า: 'ท่านมีบุตรถึงหมื่นคน สูญเสียไปเพียงคนเดียว ท่านยังโศกเศร้าถึงเพียงนี้ ส่วนมนุษย์ทั้งหลายมีบุตรเพียงคนเดียว สองคน หรือสามคนเท่านั้น แต่ท่านกลับแย่งชิงบุตรของพวกเขาไปฆ่าและกินเป็นอาหาร ไฉนเลยพวกเขาจะไม่เจ็บปวดทรมานเล่า?'"
- **บทวิเคราะห์ทางเทววิทยาและประวัติศาสตร์พิธีกรรม:**  
  เรื่องเล่านี้ใน *จ๋าเป่าจั้งจิง* เป็นต้นแบบของการเปลี่ยนบทบาทของเทวนารีสายดุร้าย (Chthonic/Devouring Mother) ให้กลายเป็นเทพีผู้อภิบาลเด็กและการคลอดบุตร (Protective Deity / Child-giving Mother) พระพุทธองค์มิได้ทรงทำลายล้างนางหารีตีด้วยอิทธิฤทธิ์ หากแต่ทรงใช้ "กระบวนการสะท้อนทางจิตวิทยา" (Empathic Reflection) ให้นางสัมผัสถึงความเจ็บปวดของมารดาผู้อื่น จนเกิดความเมตตาและยอมรับไตรสรณคมน์

  Édouard Chavannes, *Cinq cents contes et apologues extraits du Tripitaka chinois et traduits en français*, tome III (Paris: Ernest Leroux, 1911), 115.

#### ข้อความที่ ๔: คาถาสรรเสริญปัญญาและการตัดความสงสัยในเซิงจิง
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « Être avisé est la première (des vertus); — (cette vertu) peut trancher tous les doutes, — résoudre les cas difficiles à décider, — défaire avec accord les nœuds formés par de vieilles haines ; — elle peut, en ayant recours à des moyens appropriés aux circonstances, — faire que les hommes obtiennent ce qui leur est dû. — Tous, en la voyant, sont joyeux — et la célèbrent unanimement. » (Tome III, p. 167, N° 427)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "การเป็นผู้มีปัญญาเฉลียวฉลาด ย่อมเป็นเลิศที่สุด (ในบรรดาคุณธรรมทั้งปวง); — (คุณธรรมนี้) ย่อมสามารถตัดความสงสัยทั้งมวลให้ขาดลงได้, — ย่อมสามารถคลี่คลายกรณีอันยากลำบากต่อการตัดสินชี้ขาด, — ย่อมสามารถแก้เงื่อนปมแห่งความเคียดแค้นชิงชังแต่เก่าก่อนให้ลงเอยด้วยความสมานฉันท์; — ย่อมสามารถอาศัยกุศโลบายอันสอดคล้องกับกาละเทศะ, — ทำให้มนุษย์ทั้งหลายได้รับสิ่งที่สมควรได้รับ. — ชนทั้งปวงเมื่อได้ประจักษ์ ย่อมมีความแช่มชื่นยินดี — และพร้อมเพรียงกันแซ่ซ้องสรรเสริญ"
- **บทวิเคราะห์ทางนิรุกติศาสตร์และปรัชญาญาณวิทยา:**  
  คาถานี้จาก *เซิงจิง* (生經, แปลโดยพระธรรมรักษะ ค.ศ. ๒๘๕) สะท้อนนิยามของ "ปัญญา" (Prajñā / 智慧) ในฐานะเครื่องมือทางจริยศาสตร์และการประนีประนอมทางสังคม คำว่า "กุศโลบายอันสอดคล้องกับกาละเทศะ" ตรงกับมโนทัศน์ "อุปายโกศล" (Upāyakausalya) ซึ่งเป็นหัวใจสำคัญของพุทธศาสนายุกต์เปลี่ยนผ่าน ที่มองว่าปัญญาที่แท้จริงมิใช่เพียงการรู้แจ้งความจริงเชิงนามธรรม หากต้องสามารถนำมาประยุกต์ใช้เพื่อดับความขัดแย้งในโลกียวิสัยได้

  Édouard Chavannes, *Cinq cents contes et apologues extraits du Tripitaka chinois et traduits en français*, tome III (Paris: Ernest Leroux, 1911), 167.

#### ข้อความที่ ๕: คาถาสรรเสริญมิตรภาพอันจอมปลอมระหว่างสุนัขจิ้งจอกกับกาในเซิงจิง
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « Le chacal répondit encore en chantant cette gâthâ : Sincères et loyaux sont les vrais amis ; — nous nous louons l'un l'autre avec une parfaite sincérité ; — moi et vous, ô monceau d'or pur, — qu'on ne se permette pas de demander si nous sommes d'une nature mauvaise ! » (Tome III, p. 173, N° 428)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "สุนัขจิ้งจอกจึงตอบกลับด้วยการขับร้องคาถานี้ว่า: ความจริงใจและจงรักภักดีคือเครื่องหมายของมิตรแท้; — เราต่างสรรเสริญเยินยอกันและกันด้วยความจริงใจอันบริสุทธิ์; — ตัวข้าพเจ้าและท่าน โอ ขุมทองคำอันบริสุทธิ์ผุดผ่อง, — ไฉนเลยผู้ใดจะบังอาจมาตั้งคำถามว่าพวกเรามีชาติกำเนิดและสันดานอันชั่วช้าเล่า!"
- **บทวิเคราะห์ทางนิรุกติศาสตร์เปรียบเทียบกับบาลี:**

#### ข้อความที่ ๖: วิวาทะแห่งอวัยวะและอำนาจชี้ขาดของลิ้นในจิงลวี่อี้เซี่ยง
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « Le génie de la langue dit alors : « Vous contestez en invoquant de vaines raisons ; ce mérite me revient à moi seule... Si j'avais dit au roi : « Ce n'est pas du lait de lionne, c'est du lait de chienne », le roi vous aurait tous fait mettre à mort ; comment auriez-vous pu conserver votre vie ? C'est donc moi seule qui ai tout le mérite. » » (Tome III, p. 209, N° 439)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "เทวดาผู้รักษาลิ้นจึงกล่าวขึ้นว่า: 'พวกท่านทั้งหลายต่างโต้เถียงกันโดยยกเหตุผลอันไร้สาระ; ความชอบในเรื่องนี้ย่อมตกเป็นของข้าพเจ้าแต่เพียงผู้เดียว... หากข้าพเจ้ากราบทูลพระราชาไปว่า: 'นี่มิใช่น้ำนมของแม่ราชสีห์ หากแต่เป็นน้ำนมของแม่สุนัข' พระราชาก็คงจะมีรับสั่งให้ประหารชีวิตพวกท่านทั้งหมดไปแล้ว; แล้วพวกท่านจะสามารถรักษาชีวิตรอดอยู่ได้อย่างไร? ดังนั้น ข้าพเจ้าแต่เพียงผู้เดียวจึงเป็นผู้มีคุณความชอบทั้งหมด'"
- **บทวิเคราะห์ทางสัญศาสตร์และจริยศาสตร์:**  
  นิทานอุปมาเรื่องอวัยวะวิวาทกัน (The Fable of the Belly and the Members / The Dispute of the Body Parts) เป็นนิทานปรัชญาสากลที่ปรากฏทั้งในวรรณกรรมกรีกโบราณของอีสป และวรรณกรรมอียิปต์โบราณ แต่ใน *จิงลวี่อี้เซี่ยง* ตัวบทได้รับการปรับแปลงให้เข้ากับบริบทกรรมนิยมของพุทธศาสนา โดยชี้ว่า "วจีกรรม" (คำพูดผ่านลิ้น) มีอำนาจชี้ขาดในการสร้างความอยู่รอดหรือความพินาศแก่ชีวิต มนุษย์จึงต้องสำรวมระวังวาจาเป็นสำคัญ

#### ข้อความที่ ๗: สุญญตาธรรมและมงกุฎฟองน้ำในจิงลวี่อี้เซี่ยง
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « La fille du roi dit au roi : « Je désire avoir les bulles qui sont sur l'eau afin qu'on m'en fasse un diadème pour ma tête. »... L'artisan dit : « Je sais faire des diadèmes, mais je ne sais pas distinguer les bulles qui sont bonnes ou mauvaises... Prenez vous-même celles qui sont belles et apportez-les moi. » La fille du roi voulut prendre les bulles, mais aussitôt qu'elle les touchait, elles se brisaient. » (Tome III, pp. 223–224, N° 447)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "พระราชธิดากราบทูลพระราชาว่า: 'หม่อมฉันปรารถนาจะได้ฟองน้ำที่ลอยอยู่เหนือน้ำ เพื่อนำมาร้อยทำเป็นมงกุฎประดับพระเศียรของหม่อมฉัน'... นายช่างจึงกราบทูลว่า: 'ข้าพระองค์รู้วิธีทำมงกุฎ แต่ข้าพระองค์ไม่อาจจำแนกได้ว่าฟองน้ำลูกใดดีหรือเลว... ขอพระองค์จงทรงเลือกช้อนฟองน้ำที่งดงามขึ้นมาด้วยพระองค์เอง แล้วนำมามอบให้แก่ข้าพระองค์เถิด' พระราชธิดาทรงพยายามจะจับฟองน้ำ แต่ทันทีที่พระหัตถ์สัมผัส ฟองน้ำเหล่านั้นก็แตกสลายไป"
- **บทวิเคราะห์ทางอภิปรัชญาและพุทธญาณวิทยา:**  
  อุปมาเรื่อง "ฟองน้ำ" (Phenapinda / 水泡) เป็นอุปมาคลาสสิกที่ปรากฏใน *ผาณปิณฑสูตร* (สังยุตตนิกาย ขันธวารวรรค) เพื่ออธิบายว่า "รูปขันธ์เปรียบเสมือนกลุ่มฟองน้ำ" (फेणपिण्डูปมं रूपं) ที่ไม่มีแก่นสาร ไม่มีความคงทนถาวร นิทานใน *จิงลวี่อี้เซี่ยง* ได้แปรเปลี่ยนพระสูตรเชิงปรัชญาให้กลายเป็นนิทานเชิงพฤติกรรมศาสตร์ เพื่อแสดงให้เห็นความเขลาของมนุษย์ที่พยายามยึดเหนี่ยวสิ่งที่ไม่เที่ยงและไม่มีตัวตนมาเป็นเครื่องประดับแห่งอัตตา

#### ข้อความที่ ๘: มรณานุสติกับการกำราบราคะ: เพชฌฆาตถือดาบของพระเจ้าอโศกในชูเย่าจิง
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « À partir d'aujourd'hui, mettez votre cuirasse et prenez vos armes ; tenez à la main une épée affilée et allez dire au prince Chan-jong : « Ô prince, ne savez-vous pas qu’au bout de sept jours, le terme arrivera ? Livrez-vous donc de toutes vos forces aux satisfactions des cinq sens... Si vous ne le faites pas, je vous trancherai la tête avec cette épée. »... Au bout de sept jours... Le prince dit : « Je n'ai rien vu, rien entendu ; je n'ai vu que cette épée affilée et je n'ai entendu que la cloche ! » » (Tome III, pp. 300–301, N° 493)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "'นับตั้งแต่วันนี้เป็นต้นไป จงสวมเกราะและถืออาวุธของเจ้า; จงถือดาบอันคมกริบไว้ในมือแล้วไปบอกแก่เจ้าชายซ่านหรง (วีตโศก) ว่า: โอ เจ้าชาย ท่านมิรู้หรือว่าเมื่อสิ้นสุดเจ็ดวัน วาระสุดท้ายของท่านจะมาถึง? ฉะนั้นจงเสพสุขในกามคุณทั้งห้าอย่างเต็มกำลังของท่านเถิด... หากท่านไม่ทำตาม ข้าพเจ้าจะตัดศีรษะของท่านด้วยดาบเล่มนี้'... เมื่อล่วงพ้นเจ็ดวัน... เจ้าชายกราบทูลว่า: 'หม่อมฉันมิได้เห็นสิ่งใด และมิได้ยินสิ่งใดเลย; หม่อมฉันเห็นแต่เพียงดาบอันคมกริบเล่มนี้ และได้ยินแต่เพียงเสียงระฆังเท่านั้น!'"
- **บทวิเคราะห์ทางจิตวิทยาพุทธศาสนาและอรรถกถาธรรมบท:**  
  นิทานตอนนี้ใน *ชูเย่าจิง* (出曜經, T. 212) สอดคล้องกับเรื่องราวของพระวีตโศกใน *ทิวยาวทาน* (Divyāvadāna, Vītāśokāvadāna) และสะท้อนทฤษฎีจิตวิทยาชั้นสูงของพุทธศาสนาว่า จิตของมนุษย์ไม่อาจเสพกามารมณ์ได้เมื่อถูกครอบงำด้วย "มรณภัย" (ความกลัวตายอันเฉพาะหน้า) มรณานุสติจึงมิใช่เพียงการมองโลกในแง่ร้าย หากเป็นเทคนิคทางจิตวิญญาณในการรื้อถอนตัณหาและกามราคะอย่างเฉียบพลัน
- **เชิงอรรถ Chicago สำเร็จรูป:**  
  Édouard Chavannes, *Cinq cents contes et apologues extraits du Tripitaka chinois et traduits en français*, tome III (Paris: Ernest Leroux, 1911), 300–301.

#### ข้อความที่ ๙: วัวที่ถูกจูงไปสู่โรงฆ่าสัตว์และมายาการแห่งชีวิตในฝ่าจวี้ปี่หยูจิง
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « Le boucher charge chaque jour un homme de les mener hors de ville et de chercher de bonne eau et d'excellents pâturages afin qu’ils deviennent gros et grands ; puis on choisit les plus gras d’entre eux et on les lui amène chaque jour pour qu’il les tue ; plus de la moitié d’entre eux ont été ainsi tués ; cependant ceux qui restent ne se sont aperçus de rien ; ils sont justement en train de se donner des coups de corne, de bondir et de mugir... Pour les hommes il en va de même. Ils ne pensent qu'à leur moi et ne connaissent pas l'impermanence universelle. » (Tome III, p. 310, N° 495)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "คนฆ่าโคสั่งให้คนงานต้อนฝูงโคออกไปนอกเมืองทุกวัน เพื่อหาน้ำอันใสสะอาดและทุ่งหญ้าอันอุดมสมบูรณ์ เพื่อให้พวกมันอ้วนท้วนเติบใหญ่; จากนั้นเขาก็จะคัดเลือกตัวที่อ้วนที่สุดในบรรดาพวกมัน แล้วจูงมาให้เขาฆ่าทุกๆ วัน; ฝูงโคมากกว่าครึ่งหนึ่งถูกฆ่าตายไปเช่นนี้แล้ว; ถึงกระนั้น โคตัวที่เหลืออยู่กลับมิได้ตระหนักรู้ถึงสิ่งใดเลย; พวกมันกำลังขวิดเขาสลับกัน กระโดดโลดเต้น และร้องมอๆ อย่างร่าเริง... สำหรับมนุษย์ทั้งหลายก็เป็นเช่นเดียวกัน พวกเขาคิดคำนึงอยู่แต่เรื่องอัตตาตัวตนของตน และหารู้จักความไม่เที่ยงแท้สากลไม่"
- **บทวิเคราะห์ทางวรรณศิลป์และธรรมบทอุปมา:**  
  ข้อความนี้เป็นบทอธิบายคาถาธรรมบทว่าด้วยความตายและความไม่เที่ยง (อนิจจัง) โดยใช้ภาพสะท้อนชีวิตประจำวันของโรงฆ่าสัตว์ในสังคมอินเดียโบราณ ภาพฝูงโคที่หยอกล้อและขวิดกันอย่างเพลิดเพลินโดยไม่รู้ว่าตนเองกำลังจะถูกเชือดทีละตัว ทำหน้าที่เป็น "กระจกเงาส่องความหลงผิดของมนุษย์" (Metaphor of Existential Ignorance) ที่หมกมุ่นอยู่กับการแก่งแย่งลาภยศสรรเสริญ ทั้งที่ความตายกำลังคืบคลานเข้ามาทุกขณะ
- **เชิงอรรถ Chicago สำเร็จรูป:**  
  Édouard Chavannes, *Cinq cents contes et apologues extraits du Tripitaka chinois et traduits en français*, tome III (Paris: Ernest Leroux, 1911), 310.

#### ข้อความที่ ๑๐: สุบินทำนายกลียุคและการเชื่อมโยงกับตำนานกรีกโบราณเรื่องอ็อกนอส
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « Cinquièmement il vit en songe un homme qui fabriquait une corde ; derrière l’homme se trouvait un mouton; le mouton mangeait la corde... Rouse a été le premier à signaler le parallélisme de ce texte avec une légende grecque: décrivant la peinture des enfers par Polygnote, Pausanias dit: « Plus loin, un homme est assis; une inscription nous apprend qu'il s'appelle Oknos. Il est représenté tenant une corde ; auprès de lui se tient une ânesse qui dévore furtivement la corde à mesure qu’il la tresse... Pour moi, je sais que les Ioniens disent d’un homme occupé à une tâche inutile : « Il tresse la corde d'Oknos. » » » (Tome III, pp. 318–319, N° 498, n. 2)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "ประการที่ห้า พระองค์ทรงพระสุบินเห็นชายคนหนึ่งกำลังฟั่นเชือกอยู่; ข้างหลังชายผู้นั้นมีแกะตัวหนึ่ง; แกะนั้นคอยกัดกินเชือกที่ฟั่นเสร็จ... เราส์ (Rouse, 1890) เป็นบุคคลแรกที่ชี้ให้เห็นความสอดคล้องคู่ขนานของตัวบทนี้กับตำนานกรีกโบราณ: ในการพรรณนาภาพจิตรกรรมแดนบาดาลโดยโพลีกโนตุส เปาซาเนียสได้กล่าวไว้ว่า: 'ถัดออกไป มีชายนั่งอยู่คนหนึ่ง; จารึกบอกให้เรารู้ว่าเขาชื่ออ็อกนอส (Oknos) เขาถูกวาดไว้ในท่าถือเชือก; ข้างๆ ตัวเขามีลาตัวเมียยืนอยู่ ซึ่งคอยแอบกินเชือกอย่างลับๆ ในขณะที่เขาฟั่นเชือกไปเรื่อยๆ... สำหรับข้าพเจ้า ข้าพเจ้ารู้ว่าชาวไอโอเนียนมักกล่าวถึงคนที่กำลังทำงานอันไร้ประโยชน์ว่า: เขากำลังฟั่นเชือกของอ็อกนอส'"
- **บทวิเคราะห์ทางประวัติศาสตร์เปรียบเทียบข้ามวัฒนธรรม:**  
  เชิงอรรถนี้ของ Chavannes เป็นตัวอย่างอันยอดเยี่ยมของวิชาการสายภารตวิทยา-คลาสสิกศึกษาเปรียบเทียบ การที่ภาพสัญลักษณ์ "คนฟั่นเชือกแล้วมีสัตว์กัดกิน" ปรากฏทั้งใน *มหาสุบินชาดก* (บาลีลำดับที่ ๗๗), *สิบสุบินสูตร* (ภาษาจีน T. 632), จิตรกรรมกรีกโบราณ ณ เมืองเดลฟี และพิธีกรรมอียิปต์โบราณ ณ เมืองอะแคนธัส ยืนยันว่ามีการแลกเปลี่ยนคติชนวิทยาข้ามทวีปตั้งแต่ยุคก่อนคริสตกาลผ่านเส้นทางการค้าของจักรวรรดิเปอร์เซียและกองทัพพระเจ้าอเล็กซานเดอร์มหาราช
- **เชิงอรรถ Chicago สำเร็จรูป:**  
  Édouard Chavannes, *Cinq cents contes et apologues extraits du Tripitaka chinois et traduits en français*, tome III (Paris: Ernest Leroux, 1911), 318–319, n. 2.

#### ข้อความที่ ๑๑: ปุพพกรรมและการอุบัติในดอกมะม่วงของนางอัมพปาลี
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « La bhiksunt nommée « Fille-de-manguier » dit au Buddha : « Ô Honoré du monde, je me rappelle que, dans une vie antérieure... je naquis en bas, dans ce monde, je ne fus pas issue d’un fœtus, mais, pendant quatre-vingt onze kalpas, je naquis dans une fleur de manguier; je fus belle et fraîche et je connus toujours mes existences antérieures. Maintenant j'ai rencontré l'Honoré du monde qui a ouvert pour moi l'œil de la sagesse. » » (Tome III, pp. 326–327, N° 499)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "ภิกษุณีผู้มีนามว่า 'ธิดาแห่งต้นมะม่วง' (นางอัมพปาลี) ได้กราบทูลพระพุทธองค์ว่า: 'ข้าแต่พระผู้มีพระภาคเจ้า หม่อมฉันระลึกได้ว่า ในอดีตชาติอันยาวนาน... เมื่อหม่อมฉันมาจุติเบื้องล่างในโลกนี้ หม่อมฉันมิได้ถือกำเนิดขึ้นจากครรภ์มารดา (โอปปาติกะ/อโยนิชะ) แต่ตลอดเก้าสิบเอ็ดกัป หม่อมฉันได้อุบัติขึ้นภายในดอกของต้นมะม่วง; หม่อมฉันเป็นผู้มีความงดงามสดชื่น และระลึกชาติในอดีตได้อยู่เสมอ บัดนี้หม่อมฉันได้มาพบพระผู้มีพระภาคเจ้า ผู้ทรงเปิดดวงตาแห่งปัญญาให้แก่หม่อมฉันแล้ว'"
- **บทวิเคราะห์ทางเทววิทยาและวรรณกรรมอวทาน:**  
  ตัวบทจาก *ฝัวซัวไน่หนี่ฉียวี่อินหยวนจิง* (佛說奈女耆域因緣經, T. 553, แปลโดยพระอันซีเกา ค.ศ. ๑๔๘–๑๗๐) สะท้อนความเชื่อเรื่อง "อุปปาติกกำเนิด" ของบุคคลพิเศษในพุทธศาสนา นางอัมพปาลีมิได้เกิดจากครรภ์มนุษย์แต่ผุดเกิดในดอกมะม่วงเพื่อรักษาความบริสุทธิ์จากมลทินแห่งครรภ์ นิทานนี้ทำหน้าที่อธิบายสถานะคู่ขนานของนางในฐานะคณิกาหลวงแห่งแคว้นวัชชีผู้มีบทบาทอุปถัมภ์สงฆ์และบรรลุเป็นพระอรหันตภิกษุณีในบั้นปลายชีวิต
- **เชิงอรรถ Chicago สำเร็จรูป:**  
  Édouard Chavannes, *Cinq cents contes et apologues extraits du Tripitaka chinois et traduits en français*, tome III (Paris: Ernest Leroux, 1911), 326–327.

#### ข้อความที่ ๑๒: มหาทานแห่งเวสสันดรชาดกภาษาจีน: การบริจาคช้างเผือกและมโนทัศน์มหายาน
> **ข้อความภาษาฝรั่งเศสต้นฉบับ:**  
> « Le prince héritier Siu-ta-na (Sudâna)... déclara qu'il désirait obtenir le mahâyâna. Le religieux lui dit : « Tels étant vos mérites, vous obtiendrez le mahâyâna avant longtemps. »... Le Buddha dit à Ânanda : « Telle est la manière dont j'ai pratiqué la charité dans une de mes existences antérieures. Le prince-héritier Siu-ta-na (Sudâna), c’est moi-même. » » (Tome III, pp. 378, 395, N° 500)

- **คำแปลภาษาไทยเชิงวิชาการ:**  
  "มกุฎราชกุมารซิวต้านา (สุทานะ / พระเวสสันดร)... ทรงประกาศว่าพระองค์ทรงปรารถนาที่จะบรรลุถึงซึ่งมหายาน (มหาโพธิญาณ). นักบวชผู้นั้นจึงกล่าวแก่พระองค์ว่า: 'ด้วยบุญบารมีอันยิ่งใหญ่เช่นนี้ของท่าน ท่านย่อมจะบรรลุมหายานได้ในเวลาอีกไม่ช้า'... พระสัมมาสัมพุทธเจ้าตรัสแก่อานนท์ว่า: 'นั่นคือแบบอย่างที่ตถาคตได้เคยบำเพ็ญมหาทานบารมีในอดีตชาติภพหนึ่งของตถาคต มกุฎราชกุมารสุทานะในกาลนั้น ก็คือตัวตถาคตนี้เอง'"
- **บทวิเคราะห์ทางนิรุกติศาสตร์และมหายานศึกษา:**  
  ใน *ไท่จื่อซิวต้านาจิง* (太子須大拏經, T. 171) Chavannes ชี้ให้เห็นการสอดแทรกคำว่า "มหายาน" (Mahāyāna / 大乘) ลงในบทสนทนาระหว่างพระสุทานะกับดาบสในป่า แสดงให้เห็นร่องรอยการปรับแปลงวรรณกรรมชาดกของสายสาวกยานให้กลายมาเป็นวรรณกรรมเชิดชู "โพธิสัตวมรรคแบบมหายาน" อย่างชัดเจน การบำเพ็ญทานอันยิ่งยวดจนถึงขั้นสละบุตรและภรรยาได้รับการตีความใหม่ว่ามิใช่เพื่ออรหัตผลเฉพาะตน แต่เพื่อการบรรลุสัมมาสัมโพธิญาณที่จะกลับมาขนถ่ายสรรพสัตว์ข้ามห้วงโอฆสงสาร
- **เชิงอรรถ Chicago สำเร็จรูป:**  
  Édouard Chavannes, *Cinq cents contes et apologues extraits du Tripitaka chinois et traduits en français*, tome III (Paris: Ernest Leroux, 1911), 378, 395.

### ส่วนที่ 6: คลังคำศัพท์เฉพาะทางและนิรุกติศาสตร์จากเอกสาร (Native Terminology & Etymology Glossary)

| 羅摩 (*Lo-mo* / Rāma) | หลัวหมัว / พระราม | ตัวละครเอกในมหากาพย์รามายณะที่ถูกผนวกรวมเข้าสู่วรรณกรรมชาดกในฐานะอดีตชาติของพระพุทธองค์ผู้ทรงความชอบธรรม | หน้า ๑–๒ |

| 般闍迦 (*Pan-chü-kia* / Pāñcika) | พานจวีกวา / ปัญจิกะ | ขุนพลยักษ์/อสูร สามีของนางหารีตี ผู้เป็นแม่ทัพแห่งท้าวกุเวรและผู้พิทักษ์ทรัพย์สมบัติ | หน้า ๑๑๕ |
| 曠野鬼 (*K'ouang-ye-kuei* / Āṭavaka) | ขว้างเหยี่ยกุ่ย / ยักษ์อาฬวกะ | ยักษ์ดุร้ายแห่งป่าเปลี่ยวผู้กินเนื้อมนุษย์ พ่ายแพ้ต่อพุทธปัญญาในการตอบปัญหาธรรม และยอมถวายตัวเป็นอุบาสก | หน้า ๙๘–๑๑๒ |
| 生經 (*Cheng king* / Jātaka-sūtra) | เซิงจิง / ชาตกสูตร | ประมวลชาดก ๕ ผูก แปลโดยพระธรรมรักษะ (Dharmarakṣa) ในปี ค.ศ. ๒๘๕ บันทึกนิทานสัตว์และคาถาโบราณข้ามนิกาย | หน้า ๑๔๗–๒๐๗ |
| 經律異相 (*King liu yi siang*) | จิงลวี่อี้เซี่ยง | สารานุกรมรวมนิทานและเรื่องประหลาดจากพระสูตรและพระวินัย ๕๐ ผูก ประมวลโดยพระป่าวชั่งในราชสำนักเหลียง (ค.ศ. ๕๑๖) | หน้า ๒๐๘–๒๘๒ |
| 大智度論 (*Ta tche tou louen*) | ต้าจื้อตู้ลุ่น / มหาปรัชญาปารมิตาสูตรศาสตร์ | มหาอรรถกถาปรัชญาปารมิตา ๑๐๐ ผูก รจนาโดยพระนาคารชุน แปลโดยพระกุมารชีพ อุดมด้วยนิทานอุปมาและตำนานโบราณ | หน้า ๒๘๓–๒๙๖ |
| 王舍城 (*Wang-chô-tch'eng* / Rājagṛha) | หวังเซ่อเฉิง / ราชคฤห์ | เมืองหลวงแห่งแคว้นมคธ ตำนานในต้าจื้อตู้ลุ่นระบุว่าสร้างขึ้นโดยพระเจ้าชราสันธ์ ผู้ถูกผ่าสองซีกแล้วนางยักษ์ชรานำมาประสานกัน | หน้า ๒๘๓–๒๘๗ |
| 折羅散陀 (*Jarasandha*) | เจ๋อหลัวส่านถัว / พระเจ้าชราสันธ์ | กษัตริย์มหาภารตะผู้ทรงอานุภาพแห่งแคว้นมคธ กำเนิดจากการประสานร่างโดยนางรากษสีชรา นำมาอธิบายที่มาของเมืองราชคฤห์ | หน้า ๒๘๓ |
| 出曜經 (*Tch'ou yao king* / Avadānasūtra) | ชูเย่าจิง / อวทานสูตร (ธรรมบท) | คัมภีร์อรรถกถาธรรมบทสายสรรวาสติวาท นำมาจากกัศมีร์ แปลโดยพระสังฆภูติและพระจูฝัวเนี่ยน (ค.ศ. ๓๙๘–๓๙๙) | หน้า ๒๙๗–๓๐๙ |

| 舍衛國王十夢經 (*Che mong king*) | สือเมิ่งจิง / พระสุบินสิบประการ | พระสูตรว่าด้วยสุบินทำนายความเสื่อมถอยของพระพุทธศาสนาและสังคมในอนาคตของพระเจ้าปเสนทิโกศล แปลโดยพระถานอู๋หลาน | หน้า ๓๑๘–๓๒๕ |
| 繩 (*Corde* / Oknos myth) | เชือก / ตำนานอ็อกนอส | นิทานสุบินข้อ ๕ ว่าด้วยคนฟั่นเชือกแล้วมีสัตว์แอบกิน Chavannes เทียบเคียงกับตำนานกรีกโบราณเรื่อง Oknos และพิธีในอียิปต์ | หน้า ๓๑๘–๓๑๙ |

| 白象 (*Éléphant blanc* / Sudānayāna) | ช้างเผือกมงคล | ช้างแก้วคู่บารมีของพระสุทานะที่เดินบนดอกบัว ผู้เป็นต้นเหตุให้พระองค์ถูกเนรเทศเนื่องจากพระราชทานให้แคว้นคู่แข่ง | หน้า ๓๖๖–๓๗๐ |
