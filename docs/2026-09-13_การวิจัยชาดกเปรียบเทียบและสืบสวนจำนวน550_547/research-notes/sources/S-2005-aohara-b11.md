### ส่วนที่ ๒: แผนผังการจัดสรรเข้าสู่บทและหัวข้อย่อย (Chapter & Section Mapping Matrix)

*การจัดสรรข้อมูลหลักฐาน ข้อค้นพบ และกรอบวิพากษ์จากเอกสารเข้าสู่โครงสร้างรายงานวิจัย ๑๒ บท:*

- **บทที่ ๓: ภววิทยาแห่งกรรมและมโนทัศน์พระโพธิสัตว์ในนิกายสรวาสติวาท (Ch03 - Focal Chapter)**
  - *หัวข้อย่อย ๓.๑ กลไกทางภววิทยาของอวิชญัปติรูป (avijñapti-rūpa / 無表色) และกรรมที่มองไม่เห็น:* การศึกษาวิเคราะห์มโนทัศน์อวิชญัปติกรรมในฐานะรูปธรรมประเภทพิเศษ (subtle non-communicative matter) ที่ไม่สื่อแสดงออกภายนอกและไม่กระทบสัมผัส แต่ดำรงอยู่จริงตามปรมัตถ์ (dravyasat / 實有) ทำหน้าที่เป็นตัวกลางในการกักเก็บพลังศักยภาพทางศีลธรรม (karmic potentiality) ทำให้การกระทำที่ผ่านพ้นไปแล้วยังคงส่งผลต่อเนื่องในขันธสันดาน (หน้า ๘๗๖ [๑๒๙])
  - *หัวข้อย่อย ๓.๒ โครงสร้างการจัดหมวดหมู่สังวร ๓ ประการ (saṃvara / 律儀) และสภาวะตรงข้าม:* วิเคราะห์ระบบการจำแนกอวิชญัปติกรรมออกเป็น สังวร (saṃvara / 律儀), อสังวร (asaṃvara / 不律儀), และเนวสังวรนาสังวร (naivasaṃvara-nāsaṃvara / 非律儀非不律儀) ตลอดจนการแบ่งย่อยสังวรออกเป็น ปาติโมกขสังวร (prātimokṣa-saṃvara / 別解脱律儀), ธยานสังวร (dhyāna-saṃvara / 静慮律儀), และอนาสราวสังวร (anāsrava-saṃvara / 無漏律儀) (หน้า ๘๗๖ [๑๒๙], ๘๗๔ [๑๓๑])
  - *หัวข้อย่อย ๓.๓ สภาวะจิตตานุปริวรรติน (cittānuparivartin / 随心轉) กับศีลในอริยมรรค:* การทำความเข้าใจสถานะทางภววิทยาของธยานสังวรและอนาสราวสังวร ซึ่งเป็นรูปธรรมที่เกิด ดับ และหมุนเวียนไปตามกระแสจิต (随心轉身語無表) แตกต่างจากปาติโมกขสังวรซึ่งเป็นรูปที่ถือกำเนิดขึ้นจากวิชญัปติกรรมภายนอก (表所起) (หน้า ๘๗๔ [๑๓๑])
  - *หัวข้อย่อย ๓.๔ โบราณคดีตัวบทในคัมภีร์อภิธรรมยุคแรกเริ่ม (The Earliest Abhidharma Stratum):* การสืบค้นประวัติศาสตร์ความคิดผ่าน *ธรรมขันธปาทศาสตร์* (法蘊足論 / Dharmaskandha) และ *สังคีติปริยายปาทศาสตร์* (集異門足論 / Saṅgītiparyāya) ซึ่งพบว่าคำว่า "อวิชญัปติกรรม" ปรากฏเพียงตำแหน่งเดียวในแต่ละคัมภีร์ คือในบทอธิบายองค์มรรคสาม ได้แก่ สัมมาวาจา สัมมากัมมันตะ และสัมมาอาชีวะ (正語・正業・正命) (หน้า ๘๗๕ [๑๓๐]–๘๗๓ [๑๓๒])

- **บทที่ ๕: บารมีและพุทธภูมิศาสตร์: การสั่งสมบารมีข้ามภพชาติของพระโพธิสัตว์ (Ch05)**
  - *หัวข้อย่อย ๕.๒ กลไกทางอภิธรรมในการธำรงมหาปณิธานและการสืบต่อกุศลกรรมข้ามสังสารวัฏ:* ตอบโจทย์ปัญหาสำคัญทางเทววิทยาพุทธศาสนาว่า พระโพธิสัตว์ในชาดกสามารถรักษาปณิธานแห่งการตรัสรู้และสั่งสมกุศลสมภารข้ามภพชาติได้อย่างไร โดยที่ความตั้งใจเดิมไม่สูญหายไปตามมรณจิต นิกายสรวาสติวาทอาศัยมโนทัศน์ "อวิชญัปติรูป" และ "สังวร" ในการอธิบายว่า กุศลเจตนาในการสละชีวิต อวัยวะ หรือทรัพย์สินเพื่อบารมีธรรม ได้ก่อให้เกิดกระแสพลังแห่งอวิชญัปติรูปที่เกาะเกี่ยวอยู่ในสันดาน ทำหน้าที่ป้องกันบาปและเหนี่ยวนำให้พระโพธิสัตว์ยังคงดำเนินอยู่ในครรลองแห่งพระโพธิญาณในทุกภพชาติ (หน้า ๘๗๖ [๑๒๙], ๘๗๓ [๑๓๒])
  - *หัวข้อย่อย ๕.๕ การปฏิญาณสมาทานศีลและมหาปณิธานในฐานะเนวสังวรนาสังวรหรือสังวรพิเศษ:* การวิเคราะห์สถานะของมหาปณิธานโพธิสัตว์ (bodhisattva-praṇidhāna) ซึ่งอยู่นอกเหนือจากปาติโมกขสังวรของพระสาวก แต่อาศัยกลไกของอวิชญัปติกรรมในการประทับรอยทางจิตวิญญาณอย่างถาวร (หน้า ๘๗๖ [๑๒๙], ๘๗๓ [๑๓๒])

- **บทที่ ๑: ความเป็นมาและกรอบทฤษฎีชาดกเปรียบเทียบ (Ch01)**
  - *หัวข้อย่อย ๑.๔ ทฤษฎีกรรม เจตนา และร่องรอยแห่งศีลธรรมในพุทธปรัชญา:* การเปรียบเทียบเชิงมโนทัศน์คำว่า "สังวร" (saṃvara) ระหว่างพุทธศาสนากับศาสนาเชน (Jainism) ซึ่งในศาสนาเชน สังวรคือการสกัดกั้นการหลั่งไหลเข้าของธุลีแห่งกรรม (āsrava-nirodha) ส่วนในพุทธศาสนาฝ่ายสรวาสติวาท สังวรได้ถูกแปรสภาพเป็นรูปธรรมประเภทอวิชญัปติที่คอยปกป้องจิตใจ (หน้า ๘๗๖ [๑๒๙])

- **บทที่ ๑๐: ประวัติศาสตร์นิพนธ์และการศึกษาวิจัยเชิงวิพากษ์ระดับสากล ๗ ภาษา (Ch10)**
  - *หัวข้อย่อย ๑๐.๔ การศึกษาวิจัยคัมภีร์อภิธรรมสรวาสติวาทโดยสำนักพุทธศาสน์ศึกษาญี่ปุ่น:* การประเมินข้อเสนอเชิงปฏิวัติของ โนริซาโตะ อาโอฮาระ ที่นำเอาข้อค้นพบของ มิตสึโอะ ซาโต (佐藤密雄), เคนริว มิตสึโทโมะ (三友健容), และ เคียวโช ทานากะ (田中教照) มาสังเคราะห์จนเกิดภาพจำลองใหม่ว่า มโนทัศน์อวิชญัปติมิได้มีรากฐานมาจากศีลวินัยระดับกายภาพ แต่กำเนิดมาจาก "อนาสราวสังวร" ในอริยมรรค (หน้า ๘๗๕ [๑๓๐], ๘๗๒ [๑๓๓])

### ส่วนที่ ๓: สรุปสาระสำคัญเชิงวิเคราะห์และจุดยืนทางวิชาการ (Executive Academic Analysis)

#### ๑. วิทยานิพนธ์และข้อถกเถียงหลักของผู้เขียน (Core Argument / Thesis)
- **การรื้อถอนสมมติฐานเดิมเรื่องจุดกำเนิดของอวิชญัปติกรรม:** โนริซาโตะ อาโอฮาระ ได้นำเสนอข้อถกเถียงที่ท้าทายกรอบความเข้าใจดั้งเดิมในวงวิชาการพุทธศาสน์ศึกษา โดยชี้ว่าที่ผ่านมานักวิชาการส่วนใหญ่ เช่น มิตสึโอะ ซาโต (佐藤密雄 1971) มักด่วนสรุปว่า "อวิชญัปติรูป" (無表色) หรือ "อวิชญัปติกรรม" (無表業) ถือกำเนิดขึ้นมาเพื่อเป็น "ศีลขันธ์" หรือ "ศีลสรีระ/ศีลสมาทาน" (戒體 / śīla-śarīra) สำหรับรองรับปาติโมกขสังวร (別解脱律儀) ของภิกษุสงฆ์ในพระวินัยปิฎก ทว่า อาโอฮาระได้ชี้ให้เห็นข้อเท็จจริงสำคัญทางนิรุกติศาสตร์และประวัติศาสตร์ตัวบทว่า คำว่า "อวิชญัปติ" (無表) ไม่เคยมีปรากฏในพระสูตรและพระวินัยดั้งเดิมแม้แต่แห่งเดียว ตรงกันข้าม คำว่า "สังวร" (律儀 / saṃvara แปลว่า การยับยั้ง การป้องกัน) กลับเป็นคำโบราณที่มีใช้อย่างแพร่หลายทั้งในพระไตรปิฎกฝ่ายเถรวาท สรวาสติวาท และคัมภีร์ของศาสนาเชน
- **หลักฐานตัวเขียนในสองคัมภีร์อภิธรรมชั้นเก่าแก่ที่สุด:** จากการสืบค้นตัวบทอภิธรรมหกบาท (六足論) รุ่นแรกสุด ได้แก่ *ธรรมขันธปาทศาสตร์* (Dharmaskandha / 法蘊足論 ของพระมหาเมาทคัลยานะ) และ *สังคีติปริยายปาทศาสตร์* (Saṅgītiparyāya / 集異門足論 ของพระสารีบุตร/พระมหาเกาษฐิละ) อาโอฮาระพบหลักฐานประจักษ์ชัดว่า คำว่า "อวิชญัปติกรรม" (無表業) ปรากฏเพียง "แห่งเดียวเท่านั้น" ในแต่ละคัมภีร์ คือในบริบทของการอธิบายองค์มรรค ๓ ประการ ได้แก่ สัมมาวาจา (正語) สัมมากัมมันตะ (正業) และสัมมาอาชีวะ (正命) ซึ่งอยู่ในหมวดอริยมรรคมีองค์แปด (八聖道) และหมวดสิกขาบทสิบประการของพระอเสขะ (十無學法)
- **ทฤษฎีวิวัฒนาการความคิดจากอนาสราวสังวรสู่อวิชญัปติ:** อาโอฮาระสรุปเป็นวิทยานิพนธ์หลักว่า จุดเริ่มต้นทางความคิดของอวิชญัปติกรรมมิได้มาจากศีลปาติโมกข์ระดับโลกิยะภายนอก หากแต่ถือกำเนิดมาจาก "อนาสราวสังวร" (無漏律儀) หรือศีลที่เกิดร่วมกับอริยมรรคในขณะพิจารณาอริยสัจสี่ (四諦現觀) ซึ่งเป็นสภาวะที่ปัญญาอันบริสุทธิ์ (無漏智) ทำหน้าที่สกัดกั้นวจีทุจริตและกายทุจริตอย่างเด็ดขาด สภาวะนี้เป็น "จิตตานุปริวรรติน" (cittānuparivartin / 随心轉) คือเกิดดับและแปรไปตามจิต เมื่ออภิธรรมิกชนในยุคแรกพยายามอธิบายสภาวะการละเว้นบาปอันมองไม่เห็นนี้ จึงได้นำคำโบราณคือ "สังวร" (律儀) เข้ามาใช้ ต่อมาเมื่อระบบปรัชญาของนิกายสรวาสติวาทต้องการจัดจำแนกสภาวะตรงข้ามคือ "อสังวร" (不律儀 เช่น การปฏิญาณตนเป็นโจรหรือพรานล่าสัตว์) และ "เนวสังวรนาสังวร" (非律儀非不律儀 กรรมที่เป็นกลางอื่น ๆ) ซึ่งไม่อาจนำมารวมไว้ใต้ร่มของคำว่า "สังวร" ได้ จึงได้สร้างคำบัญญัติครอบจักรวาลขึ้นมาใหม่ นั่นคือ "อวิชญัปติกรรม" (無表業)

#### ๒. บริบทประวัติศาสตร์นิพนธ์และการประเมินความน่าเชื่อถือ (Historiography & Source Criticism)
- **วิธีวิทยาทางประวัติศาสตร์ตัวบทเปรียบเทียบ (Comparative Textual Stratigraphy):** ความน่าเชื่อถือของบทความนี้เกิดจากการใช้วิธีวิทยาเปรียบเทียบตัวบทข้ามสายจารีตอย่างเคร่งครัด อาโอฮาระนำบทอธิบายสัมมาวาจาใน *ธรรมขันธปาทศาสตร์* และ *สังคีติปริยายปาทศาสตร์* ไปเทียบเคียงกับคัมภีร์อภิธรรมชั้นหลังอย่าง *ปรกรณปาทศาสตร์* (品類足論 / Prakaraṇapāda) และ *คัมภีร์มหาอภิธรรมวิภาษา* (大毘婆沙論 / Mahāvibhāṣā), คัมภีร์ฝ่ายบาลีเถรวาทอย่าง *คัมภีร์วิภังค์* (Vibhaṅga) และ *ธัมมสังคณี* (Dhammasaṅgaṇī), ตลอดจนพระสูตรดั้งเดิมใน *มัชฌิมาคม* (中阿含經) และ *สังยุกตาคม* (雜阿含經)
- **การวินิจฉัยปัญหาการแทรกคำในชั้นหลัง (Interpolation):** ข้อค้นพบเชิงวิพากษ์ที่สำคัญยิ่งคือ ในบรรดาคัมภีร์ทั้งหมด มีเพียงคัมภีร์อภิธรรมของสรวาสติวาทเท่านั้นที่เพิ่มคำว่า "สังวร" (律儀) เข้าไปในรายการคำไวพจน์ของการละเว้นบาป และมีเพียงสองคัมภีร์ยุคแรก (*ธรรมขันธ์* และ *สังคีติปริยาย*) เท่านั้นที่มีคำว่า "無表業" (อวิชญัปติกรรม) ปรากฏอยู่ท้ายสุด แต่ใน *ปรกรณปาทศาสตร์* กลับไม่มีคำนี้ อาโอฮาระตั้งสมมติฐานว่า คัมภีร์อภิธรรมหกบาทมีการปรับปรุงแก้ไข (edited and updated) อย่างต่อเนื่องภายในสำนักสรวาสติวาทจนถึงยุคคลาสสิก คำว่า "無表業" จึงน่าจะเป็นคำที่บรรณาธิการรุ่นหลังแทรกเสริมเข้ามา (interpolated) ในคัมภีร์รุ่นแรก เพื่อรองรับทฤษฎีอวิชญัปติที่ตกผลึกแล้วในยุคมหาอภิธรรมวิภาษา

#### ๓. นัยสำคัญต่อการศึกษาวรรณกรรมชาดกและมโนทัศน์พระโพธิสัตว์
- **กลไกการสั่งสมบารมีข้ามภพชาติ (Trans-temporal Accumulation of Pāramī):** ในวรรณกรรมชาดก พระโพธิสัตว์ต้องทรงสละพระชนม์ชีพ อวัยวะ ดวงตา หรือพระราชโอรสธิดาซ้ำแล้วซ้ำเล่า หากจิตและรูปกายในชาตินั้นดับสูญไปอย่างสิ้นเชิง ย่อมเกิดปัญหาทางภววิทยาว่า "ผลแห่งการเสียสละและมหาปณิธานนั้นเกาะเกี่ยวสืบทอดอยู่ ณ ที่ใด?" นิกายสรวาสติวาทซึ่งไม่ยอมรับแนวคิดเรื่อง "อาลยวิตถาร/อาลยวิชญาณ" (ālayavijñāna) ของนิกายโยคาจาร หรือแนวคิด "จิตตสันตานพีชะ" (bīja) ของนิกายเสาตรันติกะ จึงต้องอาศัย "อวิชญัปติรูป" (無表色) ในฐานะรูปปรมัตถ์ที่มองไม่เห็น เป็นตัวรับภาระในการธำรงรักษา "สังวรแห่งมหาปณิธาน" ข้ามสังสารวัฏ เพื่อให้บารมีธรรมทั้งสิบประการสามารถประมวลรวมกันจนนำไปสู่การบรรลุอนุตตรสัมมาสัมโพธิญาณได้จริง
- **การถกเถียงเรื่องสังวรและการไม่เสื่อมสลายแห่งมรรคผลของพระโพธิสัตว์:** ในคัมภีร์ *อภิธรรมโกศภาษยะ* (Abhidharmakośabhāṣya บทที่ ๔) พระวสุพันธุได้วิพากษ์มติของฝ่ายไวภาษิกะ-สรวาสติวาทอย่างดุเดือดว่า หากอวิชญัปติเป็นรูปธรรมที่แท้จริง เหตุใดจึงไม่สามารถกระทบสัมผัสได้ พระสังฆภัทระใน *顺正理論* (Nyāyānusāra) และ *顯宗論* (Samayapradīpikā) จึงได้อรรถาธิบายเพิ่มเติมว่า อวิชญัปติรูปเป็นรูปที่เกิดจากมหาภูตรูปในอดีต ทำหน้าที่ป้องกันกระแสบาปอย่างต่อเนื่องประดุจเขื่อนที่ยังคงกั้นน้ำอยู่แม้ผู้สร้างเขื่อนจะจากไปแล้ว ซึ่งคำอธิบายนี้สอดรับอย่างยิ่งกับพฤติกรรมของพระโพธิสัตว์ในชาดก ที่แม้จะกำเนิดเป็นสัตว์เดรัจฉาน (เช่น ช้างฉัททันต์ วานรพญาวานร หรือพญานาคภูริทัตต์) แต่ "อวิชญัปติสังวร" ยังคงทำหน้าที่เหนี่ยวนำให้พระองค์รักษาศีลจนยอมสละชีวิตโดยไม่ทำร้ายศัตรู
- **การปะทะสังสรรค์ระหว่างโมเดลทางภววิทยา ๓ สำนักใหญ่:** 
  ๑) *โมเดลสรวาสติวาท (Sarvāstivāda Physicalist Model):* อธิบายการสืบต่อของกุศลกรรมผ่าน "อวิชญัปติรูป" (無表色) ซึ่งเป็นสสารอันประณีตที่มีอยู่จริงตามปรมัตถ์ ดำรงอยู่ในสภาวะทั้งสามกาล (sarvadā asti)
  ๒) *โมเดลเสาตรันติกะ (Sautrāntika Seed Model):* ปฏิเสธอวิชญัปติรูปว่าเป็นเพียงบัญญัติธรรม (prajñaptisat) และอธิบายการสืบต่อของกรรมผ่าน "พีชะ" (bīja / พืชพันธุ์แห่งกรรม) และ "วาสนา" (vāsanā / ความเคยชินที่อบร่ำ) ในกระแสจิตตสันตาน
  ๓) *โมเดลเถรวาท (Theravāda Kammic-Causal Model):* ปฏิเสธอวิชญัปติรูปเช่นกัน โดยจัดให้วิรตี (การงดเว้น) เป็นเจตสิกธรรม และอธิบายการข้ามภพชาติด้วย "กัมมปัจจัย" และ "อุปนิสสยปัจจัย" ในกระแสจิตภวังค์

### ส่วนที่ ๔: สารบัญข้อค้นพบเชิงลึกตามประเด็นหลัก พร้อมเลขหน้าจริง (Thematic Findings with Exact Pages)

๑. **การจำแนกประเภทสามประการของอวิชญัปติกรรมในอภิธรรมสรวาสติวาท (หน้า ๘๗๖ [๑๒๙]):**
   - อวิชญัปติกรรม (avijñapti-karma / 無表業) ถือเป็นสภาวะธรรมที่เป็นเอกลักษณ์เฉพาะของนิกายสรวาสติวาท จำแนกออกเป็น ๓ กลุ่มใหญ่ ได้แก่:
     ๑) สังวร (saṃvara / 律儀) ได้แก่ สภาพธรรมที่ทำหน้าที่สำรวม ยับยั้ง และป้องกันบาปอกุศลทางกายและวาจา
     ๒) อสังวร (asaṃvara / 不律儀) ได้แก่ พันธะหรือความตั้งใจอย่างต่อเนื่องในการประกอบอกุศลกรรม เช่น บุคคลที่ยึดอาชีพเป็นนายพราน คนฆ่าสัตว์ โจร หรือเพชฌฆาต
     ๓) เนวสังวรนาสังวร (naivasaṃvara-nāsaṃvara / 非律儀非不律儀) ได้แก่ กรรมที่เป็นกลาง ๆ ซึ่งเกิดขึ้นจากการทำความดีหรือความชั่วเป็นครั้งคราว โดยมิได้สมาทานศีลและมิได้ปฏิญาณตนในมิจฉาชีพ

๒. **การจำแนกย่อยของสังวรสามระดับ: กามธาตุ รูปธาตุ และอนาสรวธรรม (หน้า ๘๗๖ [๑๒๙]):**
   - ภายใต้หมวด "สังวร" อภิธรรมิกชนฝ่ายสรวาสติวาทจำแนกย่อยออกเป็น ๓ ประเภท:
     ๑) ปาติโมกขสังวร (prātimokṣa-saṃvara / 別解脱律儀) คือ ศีลที่ผูกมัดในกามธาตุ (欲界繫) เพื่อละเว้นอกุศลกรรมบถเป็นรายข้อ
     ๒) ธยานสังวร (dhyāna-saṃvara / 静慮律儀) คือ ศีลที่เกิดขึ้นพร้อมกับสมาธิในชั้นปฐมฌานขึ้นไปในรูปธาตุ (色界繫)
     ๓) อนาสราวสังวร (anāsrava-saṃvara / 無漏律儀) คือ ศีลอันบริสุทธิ์ไร้อาสวะที่เกิดขึ้นพร้อมกับอริยมรรค (無漏道) เพื่อตัดขาดกิเลสอย่างเด็ดขาด

๓. **ความแตกต่างระหว่างประวัติศาสตร์คำว่า "อวิชญัปติ" กับ "สังวร" (หน้า ๘๗๖ [๑๒๙]):**
   - อาโอฮาระชี้ให้เห็นความแตกต่างเชิงประวัติศาสตร์อย่างลึกซึ้ง: ในขณะที่คำว่า "อวิชญัปติ" (無表) ไม่เคยปรากฏในคัมภีร์พระสูตรดั้งเดิมเลย แต่คำว่า "สังวร" (律儀 / saṃvara) กลับเป็นคำโบราณที่มีใช้อย่างกว้างขวางทั้งในพระสูตรและพระวินัย
   - ความหมายดั้งเดิมของ *saṃvara* คือ "การยับยั้ง" (抑制) หรือ "การป้องกัน" (防護) ซึ่งพระปรมารถ (真諦) ได้แปลเป็นภาษาจีนโบราณว่า "護" (การคุ้มครอง)
   - สังวรยังเป็นคำสำคัญยิ่งในวัตรปฏิบัติของศาสนาเชน (Jainism) ในฐานะกลไกปิดกั้นช่องทางมิให้กรรมชั่วหลั่งไหลเข้ามาสู่จิต

๔. **ธรรมชาติของสังวรในฐานะสิ่งที่ไม่สื่อแสดงออกภายนอก (หน้า ๘๗๖ [๑๒๙]):**
   - ผู้ที่รักษาศีลจนสามารถระงับบาปอกุศลได้ ย่อมมีสภาวะภายในที่ได้รับการปกป้องคุ้มครอง ซึ่งความแตกต่างระหว่างผู้มีศีลกับผู้ไม่มีศีลนี้ ไม่ใช่สิ่งที่จะสามารถมองเห็นได้ด้วยตาเปล่าจากรูปลักษณ์ภายนอก (そ うでない者との区別が表面的に見えるものではない)
   - ลักษณะธรรมชาติดังกล่าวของสังวรจึงมีคุณสมบัติของการเป็น "อวิชญัปติ" (สิ่งที่ไม่มีการแสดงออก หรือสิ่งที่มองไม่เห็น) อยู่ในตัวเองโดยสภาพ

๕. **ความมุ่งหมายของพระอภิธรรมิกชนต่อ "มรรควิถี" ยิ่งกว่าศีลเบื้องต้น (หน้า ๘๗๖ [๑๒๙]–๘๗๕ [๑๓๐]):**
   - ความสนใจหลักของเหล่าพระอภิธรรมิกชนมิได้หยุดอยู่เพียงแค่สิกขาบทวินัยเบื้องต้น (入門的な戒律) เช่น ปาติโมกขสังวร แต่พุ่งเป้าไปที่ "อริยมรรคและการตัดกิเลส" (聖道論)
   - เมื่อพระโยคาวจรเจริญฌานสมาธิและพัฒนาอนาสรวมรรคเพื่อตัดกิเลส ตัวมรรควิถีนั้นเองย่อมมีอำนาจในการยับยั้งอกุศลกรรมได้อย่างทรงพลังที่สุด
   - เหล่าอภิธรรมิกชนจึงขนานนามพลังยับยั้งนี้ว่า "ธยานสังวร" และ "อนาสราวสังวร" และนำมาประดิษฐานไว้เคียงข้างปาติโมกขสังวรในฐานะแกนกลางของการจัดประเภทอวิชญัปติกรรม

๖. **หลักฐานการปรากฏเพียงจุดเดียวของอวิชญัปติกรรมในสองคัมภีร์อภิธรรมยุคแรก (หน้า ๘๗๕ [๑๓๐]):**
   - จากการตรวจสอบของ เคนริว มิตสึโทโมะ (三友健容 1976) และการยืนยันซ้ำของอาโอฮาระ พบว่าทั้ง *ธรรมขันธปาทศาสตร์* (法蘊足論, Taisho 26, 481c20–482a3) และ *สังคีติปริยายปาทศาสตร์* (集異門足論, Taisho 26, 452c21) มีการใช้คำว่า "無表業" เพียงจุดเดียวเท่านั้นในแต่ละคัมภีร์
   - ใน *ธรรมขันธ์* ปรากฏในบทอธิบาย สัมมาวาจา สัมมากัมมันตะ และสัมมาอาชีวะ ของอริยมรรคมีองค์แปด
   - ใน *สังคีติปริยาย* ปรากฏในบทอธิบาย อเสขสัมมาวาจา อเสขสัมมากัมมันตะ และอเสขสัมมาอาชีวะ ในหมวดสิกขาบทสิบประการของพระอเสขะ

๗. **ลักษณะเด่นของทฤษฎีอริยมรรคแปดในนิกายสรวาสติวาท (หน้า ๘๗๕ [๑๓๐]–๘๗๔ [๑๓๑]):**
   - ตามการวิจัยของ เคียวโช ทานากะ (田中教照 1980, 1993) อริยมรรคมีองค์แปดในพระสูตรดั้งเดิมมีทั้งที่เป็นโลกิยะ (สาสรวะ) และโลกุตตระ (อนาสรวะ) แต่ในระบบอภิธรรมของนิกายฝ่ายเหนือ (สรวาสติวาท) ได้เน้นหนักเฉพาะ "อนาสรวอัษฎางคิกมรรค" ในฐานะหนทางแห่งการพิจารณาอริยสัจสี่ (四諦現觀)
   - องค์มรรคทั้งแปดเกิดขึ้นได้ด้วย "อำนาจแห่งการพิจารณาไตร่ตรองธรรมที่ประกอบร่วมกับอนาสรวมนสิการ" (無漏作意相應思擇力) ซึ่งเป็นหน้าที่ของ "อนาสรวปัญญา" (無漏慧) ในการจำแนกธรรม

๘. **สัมมาวาจา สัมมากัมมันตะ และสัมมาอาชีวะ ในฐานะกลุ่มธรรมชุดเดียวกัน (หน้า ๘๗๔ [๑๓๑]):**
   - องค์มรรคทั้งสามนี้ได้รับการอธิบายด้วยโครงสร้างข้อความและคำไวพจน์เดียวกันทั้งหมด:
     - สัมมาวาจา คือการละเว้นวจีทุจริต ๔ ที่นำไปสู่มิจฉาชีพ ตลอดจนวจีทุจริตอื่น ๆ
     - สัมมากัมมันตะ คือการละเว้นกายทุจริต ๓ ที่นำไปสู่มิจฉาชีพ ตลอดจนกายทุจริตอื่น ๆ
     - สัมมาอาชีวะ คือการละเว้นกายทุจริตและวจีทุจริตที่เกี่ยวข้องกับการเลี้ยงชีพโดยมิชอบ
   - ในตอนท้ายของคำไวพจน์ที่แสดงการละเว้น มีการระบุคำว่า "สังวร" (律儀) และปิดท้ายด้วย "กายวจีอวิชญัปติกรรม" (無表語業 / 無表身業)

๙. **สถานะจิตตานุปริวรรตินของอนาสราวสังวร (หน้า ๘๗๔ [๑๓๑]):**
   - อนาสราวสังวรและธยานสังวรมีสถานะเป็น "ธรรมที่เป็นไปตามจิต" (cittānuparivartin / 随心轉) คือเกิดขึ้นพร้อมกับจิต ดับพร้อมกับจิต และแปรเปลี่ยนไปตามจิต แตกต่างจากปาติโมกขสังวรซึ่งเป็นรูปที่เกิดจากการแสดงออกทางกายวาจา (表所起)
   - ดังที่ *มหาอภิธรรมวิภาษา* (大毘婆沙論 เล่ม ๒๗, หน้า ๗๒๖b) ระบุว่า สัมมาวาจา สัมมากัมมันตะ และสัมมาอาชีวะ คือ "จิตตานุปริวรรติน เกิดจากกุศลมูลสาม เป็นกายวจีอวิชญัปติ" (正語・業・命. 即随心轉. 三根所發. 身語無表)
   - ข้อเท็จจริงนี้พิสูจน์ว่า จุดกำเนิดของมโนทัศน์อวิชญัปติกรรมในคัมภีร์ยุคแรก มุ่งหมายถึง "อนาสราวสังวร" โดยตรง

๑๐. **การสอบทานเชิงเปรียบเทียบกับวิภังคปกรณ์ของเถรวาทและพระสูตรอาคม (หน้า ๘๗๔ [๑๓๑]–๘๗๓ [๑๓๒]):**
    - เมื่อเปรียบเทียบบทอธิบายสัมมาวาจากับ *คัมภีร์วิภังค์* (Vibhaṅga, p. 106) และ *ธัมมสังคณี* (Dhammasaṅgaṇī, p. 63) ฝ่ายบาลี พบคำไวพจน์ตรงกันหลายคำ เช่น *arati, virati, paṭivirati, veramaṇī, akiriyā, akaraṇaṃ, anajjhāpatti, velā-anatikkamo, setughāto*
    - คำไวพจน์เหล่านี้ตรงกับภาษาจีน เช่น 遠離, 不作, 堤塘 (ทำนบกั้น) ซึ่งมีรากฐานมาจากพระสูตรโบราณ เช่น *มัชฌิมาคม* (T1.469a29) และ *สังยุกตาคม* (T2.203c1)
    - ทว่า มีเพียงคัมภีร์ฝ่ายสรวาสติวาทเท่านั้นที่มีการแทรกคำว่า "律儀" (สังวร) และมีเพียง *ธรรมขันธ์* กับ *สังคีติปริยาย* เท่านั้นที่เติมคำว่า "無表業" ลงไปในตอนท้าย

๑๑. **กลไกการก่อรูปของมโนทัศน์อวิชญัปติจากการขยายขอบเขตสังวร (หน้า ๘๗๓ [๑๓๒]):**
    - ในขั้นแรก คำว่า "สังวร" ถูกนำมาใช้เพื่อผสานรวบรวมการยับยั้งกายกรรมและวจีกรรมเข้าสู่ระบบอภิธรรม แต่เมื่อระบบต้องอธิบายสภาวะ "อสังวร" (ความไร้การสำรวม) และ "เนวสังวรนาสังวร" (กรรมที่ไม่ใช่ทั้งสองอย่าง) ย่อมไม่สามารถนำสภาวะเหล่านั้นมาบรรจุใต้คำว่าสังวรได้
    - บรรดาพระอภิธรรมิกชนจึงได้ประดิษฐ์สร้างคำศัพท์ใหม่ที่มีความเป็นนามธรรมและครอบคลุมยิ่งกว่า นั่นคือคำว่า "อวิชญัปติ" (สิ่งที่มองไม่เห็น/ไม่สื่อแสดงออก) ขึ้นมาแทนที่

๑๒. **กระบวนการชำระและขัดเกลาคัมภีร์อภิธรรมหกบาทในประวัติศาสตร์ (หน้า ๘๗๓ [๑๓๒]–๘๗๒ [๑๓๓]):**
    - อาโอฮาระเสนอว่า คัมภีร์อภิธรรมหกบาท (六足論) มิได้ถูกจารึกจนตายตัวในทันที แต่ทำหน้าที่เป็นตำราอ้างอิงประกอบการศึกษาของสำนักสรวาสติวาท ที่ได้รับการปรับปรุงแก้ไข (revised and updated) ให้สอดรับกับการพัฒนาของทฤษฎีอภิธรรมตลอดเวลาจนถึงยุคของพระเสวียนจั้ง (玄奘)
    - การปรากฏของคำว่า "無表業" ใน *ธรรมขันธ์* และ *สังคีติปริยาย* จึงเป็นหลักฐานของการแก้ไขตัวบทในชั้นหลังเพื่อผสานความคิดเรื่องอวิชญัปติกรรมให้เป็นเอกภาพทั่วทั้งนิกาย

๑. **ว่าด้วยมโนทัศน์อวิชญัปติกรรมและการจำแนกสังวรในจารีตสรวาสติวาท:**
   - **ข้อความต้นฉบับ (ภาษาญี่ปุ่น):**  
     「説一切有部に特有の概念である無表(avijñapti)業は, 律儀(saṃvara)・不律儀(asaṃvara)・非律儀非不律儀(naivasaṃvara-nāsaṃvara)の三種に分類され, さらに律儀は別解脱律儀(prātimokṣa-saṃvara)・静慮律儀(dhyāna-saṃvara)・無漏律儀(anāsrava-saṃvara)の三種に区分される。無表業についてはこれまで, その実有論議や業の潜勢力としてのあり方, あるいは無表色の概念, 無表の語の意味など, さまざまな角度から論じられてきたが, この律儀等の無表業の分類については, 触れられることが少なかったように思われる。しかし, 無表の語や概念が経典などでは見られないのに対して, 律儀という言葉は古くから経典や律蔵でも使用されてきたものである。」 (หน้า ๘๗๖ [๑๒๙])
   - **คำแปลภาษาไทยเชิงวิชาการ:**

๒. **ว่าด้วยความหมายดั้งเดิมของคำว่าสังวรและการเชื่อมโยงกับศาสนาเชน:**
   - **ข้อความต้นฉบับ (ภาษาญี่ปุ่น):**  
     「律儀という翻訳語そのものも不可解であるが, 原語saṃvaraは, 『抑制』あるいは『防護』を意味し, 真諦は『護』と訳す。経典や律蔵では, 別解脱律儀, すなわち個別に煩悩を断じて解脱へ向かう素地を作るための戒(欲界繋の戒)を表わすことが多い。戒律を守って悪業が抑制され, 防護された状態は, そうでない者との区別が表面的に見えるものではない。そこに律儀が無表(avijñapti)すなわち『表示されない』業として思考される要素を持ちあわせている。また, 律儀(saṃvara)は, ジャイナ教の実践の概念としても重要な用語でもあり, その関連からも示唆的である。」 (หน้า ๘๗๖ [๑๒๙])
   - **คำแปลภาษาไทยเชิงวิชาการ:**  
     "แม้ว่าคำแปลภาษาจีนว่า 'ลวี่อี๋' (律儀) จะดูเข้าใจยากในตัวเอง แต่คำศัพท์เดิมในภาษาสันสกฤตคือ saṃvara นั้น มีความหมายว่า 'การยับยั้ง' หรือ 'การป้องกันคุ้มครอง' ซึ่งพระปรมารถ (真諦) ได้แปลไว้ว่า 'ฮู่' (護 / การคุ้มครอง) ในคัมภีร์พระสูตรและพระวินัย คำนี้มักใช้สื่อถึงปาติโมกขสังวร นั่นคือ ศีลขั้นพื้นฐานเพื่อตัดกิเลสเป็นรายข้อเพื่อสร้างรากฐานไปสู่ความหลุดพ้น (ศีลอันเนื่องด้วยกามธาตุ) สภาวะที่บุคคลรักษาศีลจนอกุศลกรรมถูกยับยั้งและได้รับการปกป้องคุ้มครองไว้นั้น เป็นสภาวะที่ไม่สามารถมองเห็นความแตกต่างจากผู้ที่มิได้รักษาศีลได้จากรูปลักษณ์ภายนอก ด้วยเหตุนี้ สังวรจึงมีองค์ประกอบที่ทำให้ถูกคิดคำนึงในฐานะ 'อวิชญัปติ' นั่นคือ กรรมที่ 'ไม่สื่อแสดงออกภายนอก' อนึ่ง คำว่า สังวร (saṃvara) ยังเป็นคำศัพท์ที่สำคัญยิ่งในมโนทัศน์เชิงวัตรปฏิบัติของศาสนาเชน ซึ่งความเชื่อมโยงในจุดนี้นับว่าให้ข้อคิดที่ลึกซึ้งยิ่ง"
   - **บทวิเคราะห์เชิงวิพากษ์:** การชี้ให้เห็นรากศัพท์ saṃvara ที่หมายถึงการสกัดกั้นบาป และเปรียบเทียบกับปรัชญาเชน แสดงให้เห็นว่าพุทธศาสนารับเอาคำว่าสังวรมาจากบรรยากาศร่วมของยุคสมณะ แล้วนำมาพัฒนาเป็นระบบภววิทยาภายในจิตสำนึก
   - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**  
     Norisato Aohara, "Shoki Ubu ronsho ni okeru muhyō to ritsugi," *Journal of Indian and Buddhist Studies* 53, no. 2 (2005): 876 [129].

๓. **ว่าด้วยความสนใจของพระอภิธรรมิกชนต่อพลังการยับยั้งในอริยมรรค:**
   - **ข้อความต้นฉบับ (ภาษาญี่ปุ่น):**  
     「一方でアビダルマ論師たちの関心事は, 入門的な戒律よりも, 実際に煩悩を断じ修めていく聖道論である。禅定を修め, 無漏道を発揮して, 煩悩を断つ際に, 道そのもののもつ悪業への抑制力に着目したとしても不思議ではない。それらを静慮律儀(欲界繋の戒), 無漏律儀(無漏の戒)と呼び, 別解脱律儀と並べ無表業の分類の中心に据えたのである。」 (หน้า ๘๗๖ [๑๒๙])
   - **คำแปลภาษาไทยเชิงวิชาการ:**  
     "ในอีกด้านหนึ่ง สิ่งที่เหล่าพระอภิธรรมิกชนให้ความสนใจอย่างแท้จริง มิใช่สิกขาบทวินัยเบื้องต้น หากแต่เป็นทฤษฎีว่าด้วยอริยมรรค (聖道論) อันเป็นกระบวนการตัดกิเลสและฝึกอบรมจิตใจในการปฏิบัติจริง จึงมิใช่เรื่องแปลกประหลาดแต่อย่างใดที่เมื่อท่านเหล่านั้นบำเพ็ญฌานสมาธิและพัฒนาอนาสรวมรรคจนตัดกิเลสได้ ย่อมจะพุ่งความสนใจไปที่ 'อำนาจในการยับยั้งบาปอกุศลที่มีอยู่ในตัวอริยมรรคนั้นเอง' ท่านจึงได้เรียกขานพลังเหล่านี้ว่า ธยานสังวร (ศีลในสมาธิ) และอนาสราวสังวร (ศีลไร้อาสวะ) และนำมาประดิษฐานเคียงข้างปาติโมกขสังวร ในฐานะแกนกลางของการจัดหมวดหมู่อวิชญัปติกรรม"
   - **บทวิเคราะห์เชิงวิพากษ์:** ข้อความนี้เปิดเผยแรงจูงใจเบื้องหลังของอภิธรรมิกชน ว่าระบบศีลของฝ่ายเหนือถูกยกระดับจากการปฏิบัติตามกฎวินัยภายนอก ไปสู่การเป็นพลังทางจิตวิญญาณภายในอริยมรรค
   - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**  
     Norisato Aohara, "Shoki Ubu ronsho ni okeru muhyō to ritsugi," *Journal of Indian and Buddhist Studies* 53, no. 2 (2005): 876 [129].

๔. **ว่าด้วยตัวบทคัมภีร์ธรรมขันธปาทศาสตร์ว่าด้วยสัมมาวาจาและอวิชญัปติวจีกรรม:**
   - **ข้อความต้นฉบับ (ภาษาจีนคัมภีร์):**  
     「云何正語. 謂聖弟子. 於苦思惟苦. 乃至於道思惟道. 無漏作意相應思擇力故. 除趣邪命語四悪行. 於餘語悪行所得無漏遠離・勝遠離・近遠離・極遠離・寂静・律儀・無作・無造・棄捨・防護・船筏・橋梁・堤塘・牆塹・於所制約不踰不踰性・不越不越性・無表語業. 是名正語。」 (『法蘊足論』 大正蔵 26, 481c20–482a3; หน้า ๘๗๕ [๑๓๐])

     "สัมมาวาจาเป็นไฉน? ตอบว่า ได้แก่การที่พระอริยสาวก พิจารณาเห็นทุกข์โดยความเป็นทุกข์ ... จนถึงพิจารณาเห็นมรรคโดยความเป็นมรรค อาศัยพลังแห่งการไตร่ตรองวินิจฉัยธรรมที่ประกอบร่วมกับอนาสรวมนสิการ ละเว้นวจีทุจริต ๔ ประการอันชักนำไปสู่มิจฉาชีพ สภาวะแห่งการละเว้นอันปราศจากอาสวะ การละเว้นอย่างประเสริฐ การละเว้นอย่างใกล้ชิด การละเว้นอย่างยิ่งยวด ความสงบระงับ สังวร ความไม่กระทำ ความไม่สร้าง การสลัดทิ้ง การป้องกัน นาวา สะพาน ทำนบ คันกั้น การไม่ก้าวล่วงและสภาวะแห่งการไม่ก้าวล่วงต่อข้อบัญญัติ การไม่ละเมิดและสภาวะแห่งการไม่ละเมิด ตลอดจนวจีอวิชญัปติกรรม อันพึงได้รับจากการละเว้นวจีทุจริตที่เหลือเหล่านั้น สภาวะนี้แลเรียกว่า สัมมาวาจา"
   - **บทวิเคราะห์เชิงวิพากษ์:** ตัวบทนี้แสดงให้เห็นการเรียงร้อยคำไวพจน์อันยาวเหยียด ซึ่งสะท้อนการนำเอาคำอุปมาโบราณ (เช่น สะพาน คันกั้นน้ำ) มาบรรจบกับคำศัพท์เทคนิคทางอภิธรรมชั้นสูง (เช่น 律儀 และ 無表語業)
   - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**  
     *Dharmaskandha* [法蘊足論], T 26, no. 1537, 481c20–482a3; cited in Norisato Aohara, "Shoki Ubu ronsho ni okeru muhyō to ritsugi," *Journal of Indian and Buddhist Studies* 53, no. 2 (2005): 875 [130].

๕. **ว่าด้วยตัวบทคัมภีร์สังคีติปริยายปาทศาสตร์ว่าด้วยอเสขสัมมาวาจา:**
   - **ข้อความต้นฉบับ (ภาษาจีนคัมภีร์):**  
     「云何無學正語. 答諸聖弟子. 於苦思惟苦. 於集思惟集. 於滅思惟滅. 於道思惟道. 無學作意相應簡擇力故. 除趣邪命語四悪行. 於餘語悪行所得. 無學遠離・勝遠離・近遠離・極遠離・寂静・律儀・無作・無造・棄捨・防護・不行・不犯・船筏・橋梁・堤塘・牆塹・於所制約不踰不踰性・不越不越性・無表語業. 是名無學正語。」 (『集異門足論』 大正蔵 26, 452c21; หน้า ๘๗๕ [๑๓๐])
   - **คำแปลภาษาไทยเชิงวิชาการ:**  
     "อเสขสัมมาวาจาเป็นไฉน? ตอบว่า บรรดาพระอริยสาวกทั้งหลาย พิจารณาเห็นทุกข์โดยความเป็นทุกข์ พิจารณาเห็นสมุทัยโดยความเป็นสมุทัย พิจารณาเห็นนิโรธโดยความเป็นนิโรธ พิจารณาเห็นมรรคโดยความเป็นมรรค อาศัยพลังแห่งการเลือกเฟ้นธรรมที่ประกอบร่วมกับอเสขมนสิการ ละเว้นวจีทุจริต ๔ ประการอันชักนำไปสู่มิจฉาชีพ สภาวะแห่งการละเว้นของพระอเสขะ การละเว้นอย่างประเสริฐ การละเว้นอย่างใกล้ชิด การละเว้นอย่างยิ่งยวด ความสงบระงับ สังวร ความไม่กระทำ ความไม่สร้าง การสลัดทิ้ง การป้องกัน ความไม่ประพฤติล่วง ความไม่ละเมิด นาวา สะพาน ทำนบ คันกั้น การไม่ก้าวล่วงและสภาวะแห่งการไม่ก้าวล่วงต่อข้อบัญญัติ การไม่ละเมิดและสภาวะแห่งการไม่ละเมิด ตลอดจนวจีอวิชญัปติกรรม อันพึงได้รับจากการละเว้นวจีทุจริตที่เหลือเหล่านั้น สภาวะนี้แลเรียกว่า อเสขสัมมาวาจา"
   - **บทวิเคราะห์เชิงวิพากษ์:** ความสอดคล้องกันแทบจะคำต่อคำระหว่างธรรมขันธ์และสังคีติปริยาย ยืนยันว่าในยุคแรกเริ่ม สรวาสติวาทมีแม่แบบทางภาษาที่แน่นอนในการอธิบายศีลของพระอริยเจ้า
   - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**

๖. **ว่าด้วยมหาอภิธรรมวิภาษากับการกำหนดสถานะจิตตานุปริวรรตินขององค์มรรคสาม:**
   - **ข้อความต้นฉบับ (ภาษาจีนคัมภีร์และภาษาญี่ปุ่น):**  
     「無漏律儀は, 静慮律儀とともに随心転(cittānuparivartin)といわれ, 表所起すなわち表業から生ずる別解脱律儀と区別される。具体的には無漏道中の身・語業に関わるもので, 『婆沙論』(大正27.726b29-c3)に, 『八道支者. 謂正見・正思惟・正語・正業・正命・正精進・正念・正定. 正見即慧. 正思惟即尋. 正語・業・命. 即随心轉. 三根所發. 身語無表. 餘三如名即心所性.』 と説かれるように, 八聖道中の正語・正業・正命として位置づけられるものである。まさに初期論書の無表業の用例は, 無漏律儀を示しているのである。」 (หน้า ๘๗๔ [๑๓๑])
   - **คำแปลภาษาไทยเชิงวิชาการ:**  
     "อนาสราวสังวรนั้นได้รับการจัดให้เป็นสภาวะที่เป็นไปตามกระแสจิต (cittānuparivartin / 随心轉) เช่นเดียวกับธยานสังวร ซึ่งแตกต่างอย่างชัดเจนจากปาติโมกขสังวรที่ถือกำเนิดขึ้นจากวิชญัปติกรรม (表所起) หากกล่าวให้เป็นรูปธรรม อนาสราวสังวรย่อมเกี่ยวข้องกับกายกรรมและวจีกรรมที่ดำเนินอยู่ท่ามกลางอนาสรวมรรค ดังที่ *มหาอภิธรรมวิภาษา* (大毘婆沙論 เล่ม ๒๗, ๗๒๖b๒๙–c๓) ได้แสดงไว้ว่า: 'องค์มรรคทั้งแปด ได้แก่ สัมมาทิฏฐิ สัมมาสังกัปปะ สัมมาวาจา สัมมากัมมันตะ สัมมาอาชีวะ สัมมาวายามะ สัมมาสติ สัมมาสมาธิ สัมมาทิฏฐิคือปัญญา สัมมาสังกัปปะคือวิตก สัมมาวาจา สัมมากัมมันตะ และสัมมาอาชีวะ คือสภาวะที่เป็นไปตามจิต (จิตตานุปริวรรติน) ซึ่งกำเนิดจากมูลรากทั้งสาม เป็นกายอวิชญัปติและวจีอวิชญัปติ ส่วนอีกสามประการที่เหลือก็เป็นเจตสิกธรรมตามชื่อ' ตัวอย่างการใช้คำว่าอวิชญัปติกรรมในคัมภีร์อภิธรรมยุคแรกเริ่มจึงชี้ชัดอย่างแท้จริงว่า มุ่งหมายถึงอนาสราวสังวรนั่นเอง"
   - **บทวิเคราะห์เชิงวิพากษ์:** ตัวบทจากมหาอภิธรรมวิภาษานี้ถือเป็นกุญแจดอกสำคัญที่สุด ที่เชื่อมโยงอภิธรรมยุคแรกเข้ากับระบบอภิธรรมคลาสสิก โดยยืนยันว่าศีลในมรรคแปดคืออวิชญัปติรูปที่ดำเนินไปตามจิต
   - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**  
     *Mahāvibhāṣā* [大毘婆沙論], T 27, no. 1545, 726b29–c3; cited in Norisato Aohara, "Shoki Ubu ronsho ni okeru muhyō to ritsugi," *Journal of Indian and Buddhist Studies* 53, no. 2 (2005): 874 [131].

๗. **ว่าด้วยตัวบทคัมภีร์ปรกรณปาทศาสตร์ที่ไม่มีคำว่าอวิชญัปติกรรม:**
   - **ข้อความต้นฉบับ (ภาษาจีนคัมภีร์):**  
     「正語云何. 謂聖弟子等. 於苦思惟苦. 於集思惟集. 於滅思惟滅. 於道思惟道. 除趣邪命語四悪行. 於餘語悪行. 由決擇力所引. 無漏遠離・止息・各別遠離・寂静・律儀・不作・不造・不行・不犯・不毀分限・堤塘・橋梁・船筏・棄捨軌則・不違・不越・不違越住. 是名正語。」 (『品類足論』 大正蔵 26, 722a17; หน้า ๘๗๔ [๑๓๑])
   - **คำแปลภาษาไทยเชิงวิชาการ:**  
     "สัมมาวาจาเป็นไฉน? ตอบว่า ได้แก่การที่เหล่าพระอริยสาวก พิจารณาเห็นทุกข์โดยความเป็นทุกข์ พิจารณาเห็นสมุทัยโดยความเป็นสมุทัย พิจารณาเห็นนิโรธโดยความเป็นนิโรธ พิจารณาเห็นมรรคโดยความเป็นมรรค ละเว้นวจีทุจริต ๔ ประการอันชักนำไปสู่มิจฉาชีพ สภาวะแห่งการละเว้นอันปราศจากอาสวะที่ชักนำมาโดยพลังแห่งการวินิจฉัยธรรม ความสงบระงับ การละเว้นเฉพาะส่วน ความสงบ สังวร ความไม่กระทำ ความไม่สร้าง ความไม่ประพฤติ ความไม่ละเมิด การไม่ทำลายขอบเขต ทำนบ สะพาน นาวา ระเบียบแห่งการสละทิ้ง การไม่ฝ่าฝืน การไม่ก้าวล่วง และการตั้งมั่นในการไม่ก้าวล่วงฝ่าฝืน อันมีต่อวจีทุจริตที่เหลือเหล่านั้น สภาวะนี้แลเรียกว่า สัมมาวาจา"
   - **บทวิเคราะห์เชิงวิพากษ์:** การที่ปรกรณปาทศาสตร์ซึ่งรจนาโดยพระวสุมิตร มีคำว่า "律儀" แต่กลับ "ไม่มี" คำว่า "無表語業" ปิดท้ายรายการ เป็นหลักฐานเชิงประจักษ์ว่าในสายตัวเขียนของปรกรณปาทศาสตร์ยังมิได้มีการเติมคำว่าอวิชญัปติกรรมลงไป
   - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**  
     *Prakaraṇapāda* [品類足論], T 26, no. 1542, 722a17; cited in Norisato Aohara, "Shoki Ubu ronsho ni okeru muhyō to ritsugi," *Journal of Indian and Buddhist Studies* 53, no. 2 (2005): 874 [131].

๘. **ว่าด้วยตัวบทภาษาบาลีในคัมภีร์วิภังค์ของฝ่ายเถรวาท:**
   - **ข้อความต้นฉบับ (ภาษาบาลี):**  
     "tattha katamā sammāvācā? yā catūhi vacīduccaritehi ārati virati paṭivirati veramaṇī akiriyā akaraṇaṃ anajjhāpatti velā-anatikkamo setughāto sammāvācāmaggamaṅgaṃ maggapariyāpannaṃ: ayaṃ vuccati sammāvācā." (*Vibhaṅga*, p. 106; หน้า ๘๗๔ [๑๓๑]–๘๗๓ [๑๓๒])
   - **คำแปลภาษาไทยเชิงวิชาการ:**  
     "ในบรรดาองค์มรรคเหล่านั้น สัมมาวาจาเป็นไฉน? ความงด ความเว้น ความเว้นเฉพาะ ความเว้นขาด ความไม่กระทำ ความไม่สร้าง สภาวะแห่งการไม่ก้าวล่วงละเมิด การไม่ก้าวล่วงขอบเขต ทำนบกั้น จากวจีทุจริต ๔ ประการ อันเป็นองค์แห่งมรรค เป็นสัมมาวาจาที่นับเนื่องในมรรค สภาวะนี้เรียกว่า สัมมาวาจา"
   - **บทวิเคราะห์เชิงวิพากษ์:** ตัวบทบาลีนี้แสดงให้เห็นโครงสร้างร่วมดั้งเดิมตั้งแต่ยุคก่อนแยกนิกายอย่างชัดเจน โดยคำว่า *setughāto* (ทำนบกั้น) ตรงกับคำว่า 堤塘 ในภาษาจีนอย่างสมบูรณ์ แต่ฝ่ายบาลีไม่มีทั้งคำว่า *saṃvara* และ *avijñatti* ในบริบทนี้
   - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**  
     *Vibhaṅga*, ed. C.A.F. Rhys Davids (London: Pali Text Society, 1904), 106; cited in Norisato Aohara, "Shoki Ubu ronsho ni okeru muhyō to ritsugi," *Journal of Indian and Buddhist Studies* 53, no. 2 (2005): 874 [131]–873 [132].

๙. **ว่าด้วยข้อความคู่ขนานในคัมภีร์ธัมมสังคณี:**
   - **ข้อความต้นฉบับ (ภาษาบาลี):**  
     "katama tasmiṃ samaye sammāvācā hoti? yā tasmiṃ samaye catūhi vacīduccaritehi ārati virati paṭivirati veramaṇī akiriyā akaraṇaṃ anajjhāpatti velā-anatikkamo setughāto sammāvācāmaggamaṅgaṃ maggapariyāpannaṃ: ayaṃ tasmiṃ samaye sammāvācā hoti..." (*Dhammasaṅgaṇī*, p. 63ff.; หน้า ๘๗๒ [๑๓๓] เชิงอรรถที่ ๘)
   - **คำแปลภาษาไทยเชิงวิชาการ:**  
     "ในสมัยนั้น สัมมาวาจาเป็นไฉน? ความงด ความเว้น ความเว้นเฉพาะ ความเว้นขาด ความไม่กระทำ ความไม่สร้าง สภาวะแห่งการไม่ก้าวล่วงละเมิด การไม่ก้าวล่วงขอบเขต ทำนบกั้น จากวจีทุจริต ๔ ประการ ในสมัยนั้น อันเป็นองค์แห่งมรรค เป็นสัมมาวาจาที่นับเนื่องในมรรค สภาวะนี้ย่อมเป็นสัมมาวาจาในสมัยนั้น..."
   - **บทวิเคราะห์เชิงวิพากษ์:** ข้อความในธัมมสังคณียืนยันความมั่นคงของสำนวนบาลีสายเถรวาท ว่านิยามสัมมาวาจาด้วยคำแสดงการละเว้น (virati) โดยไม่จำเป็นต้องแปลงสภาวะการละเว้นให้กลายเป็นรูปธรรมภายนอกเหมือนสรวาสติวาท
   - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**  
     *Dhammasaṅgaṇī*, ed. Edward Müller (London: Pali Text Society, 1885), 63; cited in Norisato Aohara, "Shoki Ubu ronsho ni okeru muhyō to ritsugi," *Journal of Indian and Buddhist Studies* 53, no. 2 (2005): 872 [133], n. 8.

๑๐. **ว่าด้วยการคลี่คลายทางทฤษฎีจากคำว่าสังวรสู่การบัญญัติคำว่าอวิชญัปติกรรม:**
    - **ข้อความต้นฉบับ (ภาษาญี่ปุ่น):**  
      「つまり, 正語・正業・正命の解釈における, 身語の悪行からの遠離・不作・防護という既成の解釈に『律儀』という概念が導入され, それが最終的に『無表業』として位置づけられたということである。そして, ここでの律儀は, 上述のように無漏律儀としての意味を有していたと考えられる。ここで律儀はすでに身・語の二業に限定されている。『律儀』の語は, 初期の段階でまだ無表業という概念がなかったとき, 身・語二業の抑制ということをアビダルマ的に統一すべく導入された言葉であろう。しかし, 不律儀・非律儀非不律儀などに考察が及ぶと, どうしても律儀でないものを律儀の語で収束することはできず, 『無表業』なる新たな統一概念を作り出したものと推測される。」 (หน้า ๘๗๓ [๑๓๒])
    - **คำแปลภาษาไทยเชิงวิชาการ:**  
      "กล่าวโดยสรุปก็คือ ในบทอธิบายสัมมาวาจา สัมมากัมมันตะ และสัมมาอาชีวะ มโนทัศน์เรื่อง 'สังวร' (律儀) ได้ถูกนำมาผนวกรวมเข้ากับกรอบการตีความเดิมที่ว่าด้วยการละเว้น (遠離) การไม่กระทำ (不作) และการป้องกัน (防護) บาปกรรมทางกายและวาจา และในท้ายที่สุด สภาวะนั้นจึงได้รับการกำหนดสถานะให้เป็น 'อวิชญัปติกรรม' (無表業) ทั้งนี้ สังวร ณ ที่นี้ย่อมมีความหมายในฐานะอนาสราวสังวรอย่างไม่ต้องสงสัย สังวรในบริบทนี้ถูกจำกัดวงไว้เฉพาะกายกรรมและวจีกรรมสองประการเท่านั้น ในชั้นแรกเริ่มขณะที่ยังมิได้มีการสถาปนามโนทัศน์เรื่องอวิชญัปติกรรมขึ้นมา คำว่า 'สังวร' น่าจะถูกนำมาใช้เพื่อผสานรวบรวมการยับยั้งกายกรรมและวจีกรรมเข้าสู่ระบบอภิธรรม ทว่า เมื่อการพิจารณาทางทฤษฎีขยายพรมแดนไปสู่สภาวะอสังวร (การไม่สำรวม) และเนวสังวรนาสังวร ย่อมเป็นไปไม่ได้ที่จะนำสิ่งที่ไม่ใช่สังวรมาผนวกรวมไว้ใต้ร่มของคำว่าสังวรได้ ด้วยเหตุดังกล่าว จึงสามารถสันนิษฐานได้ว่า บรรดาพระอภิธรรมิกชนจึงได้ประดิษฐ์สร้างมโนทัศน์เอกภาพใหม่อันครอบคลุมยิ่งกว่าขึ้นมา ซึ่งได้แก่คำว่า 'อวิชญัปติกรรม'"
    - **บทวิเคราะห์เชิงวิพากษ์:** นี่คือบทสรุปอันเป็นหัวใจของวิทยานิพนธ์ของอาโอฮาระ ที่อธิบายกระบวนการพัฒนาปรัชญาภาษาและภววิทยาของนิกายสรวาสติวาทได้อย่างเป็นเหตุเป็นผลที่สุด
    - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**  
      Norisato Aohara, "Shoki Ubu ronsho ni okeru muhyō to ritsugi," *Journal of Indian and Buddhist Studies* 53, no. 2 (2005): 873 [132].

๑๑. **ว่าด้วยประวัติศาสตร์การแก้ไขและปรับปรุงคัมภีร์อภิธรรมหกบาทในสำนักสรวาสติวาท:**
    - **ข้อความต้นฉบับ (ภาษาญี่ปุ่น):**  
      「筆者は, 六足論は成立時期には前後の相違はあったとしても, 教科別の参考書的に相互補完されつつ, 有部思想の深化とともに, ある時代までは改訂され続けたと考える。その事情は, 著者が特定され権威のあった『発智論』とは異なるであろう。現存する玄奘訳は, すべて玄奘時代の有部が『同じ時代』に用いていた現役の参考書であったことを考慮せねばならない。少なくとも初期の『法蘊足論』と『集異門足論』は, 古くからVibhaṅgaやDhammasaṅgaṇīとの類似が指摘されているように, その原形の論書が分派以前から存在し, 有部的に改訂されたものであることだけは間違いない。その改訂は, かなり後代まで続いたのではなかろうか。」 (หน้า ๘๗๒ [๑๓๓] เชิงอรรถที่ ๑๐)
    - **คำแปลภาษาไทยเชิงวิชาการ:**  
      "ผู้เขียนพิจารณาเห็นว่า แม้คัมภีร์อภิธรรมหกบาท (六足論) จะมีช่วงเวลาของการก่อตั้งที่แตกต่างกันก่อนและหลัง แต่คัมภีร์เหล่านี้ได้ทำหน้าที่เกื้อหนุนเสริมซึ่งกันและกันประดุจตำราอ้างอิงแยกตามรายวิชา และได้รับการปรับปรุงแก้ไข (revised) อย่างต่อเนื่องไปพร้อมกับการพัฒนาความคิดที่ลึกซึ้งขึ้นของนิกายสรวาสติวาทจนถึงยุคสมัยหนึ่ง ซึ่งสถานการณ์เช่นนี้ย่อมแตกต่างจาก *ชญานปรัสถานศาสตร์* (發智論) ซึ่งมีผู้ประพันธ์ที่ระบุตัวตนชัดเจนและมีอำนาจสิทธิ์ขาด เราต้องคำนึงถึงข้อเท็จจริงที่ว่า คัมภีร์ฉบับแปลของพระเสวียนจั้งที่หลงเหลืออยู่ในปัจจุบัน ล้วนเป็นตำราอ้างอิงที่พระสงฆ์นิกายสรวาสติวาทในยุคของเสวียนจั้งยังคงใช้งานจริงอยู่ใน 'ยุคสมัยเดียวกัน' อย่างน้อยที่สุด คัมภีร์ยุคแรกเริ่มอย่าง *ธรรมขันธปาทศาสตร์* และ *สังคีติปริยายปาทศาสตร์* ดังที่มีผู้ชี้ให้เห็นความคล้ายคลึงกับ *วิภังค์* และ *ธัมมสังคณี* มาช้านาน ย่อมมีตัวบทต้นฉบับดั้งเดิมดำรงอยู่ตั้งแต่ก่อนการแยกนิกายอย่างไม่ต้องสงสัย และได้รับการปรับปรุงแก้ไขตามแนวทางของสรวาสติวาทในภายหลัง ซึ่งการปรับปรุงแก้ไขดังกล่าวน่าจะดำเนินสืบเนื่องมาจนถึงยุคหลังอย่างมากทีเดียว"
    - **บทวิเคราะห์เชิงวิพากษ์:** เชิงอรรถนี้มีคุณค่าทางประวัติศาสตร์นิพนธ์อย่างมหาศาล เพราะเตือนสตินักวิชาการมิให้มองคัมภีร์จีนของพระเสวียนจั้งเป็นภาพตัวแทนของยุคพุทธกาล แต่ต้องมองเป็นผลผลิตของการสั่งสมทางวิชาการที่ถูกชำระมานับศตวรรษ
    - **รูปแบบการอ้างอิงเชิงอรรถ (Footnote):**  
     Norisato Aohara, "Shoki Ubu ronsho ni okeru muhyō to ritsugi," *Journal of Indian and Buddhist Studies* 53, no. 2 (2005): 872 [133], n. 10.

| samyag-ājīva (正命) | สัมมาอาชีวะ | การเลี้ยงชีพชอบ การละเว้นกายทุจริตและวจีทุจริตที่เกี่ยวเนื่องด้วยมิจฉาชีพ | หน้า ๘๗๕ [๑๓๐], ๘๗๔ [๑๓๑] |
| aṣṭāṅgika-mārga (八聖道) | อริยมรรคมีองค์แปด | ทางอันประเสริฐแปดสาย ในอภิธรรมสรวาสติวาทจัดเป็นอนาสรวธรรมที่ดำเนินไปในการพิจารณาอริยสัจสี่ | หน้า ๘๗๕ [๑๓๐], ๘๗๔ [๑๓๑] |
| aśaikṣa-dharma (十無學法) | อเสขธรรมสิบประการ | สภาวะธรรมขั้นสูงสุดของพระอรหันต์ผู้ไม่ต้องศึกษาอีกต่อไป ปรากฏในสังคีติปริยายปาทศาสตร์ | หน้า ๘๗๕ [๑๓๐] |
| dravyasat (実有) | ทรัพยสัต (ปรมัตถสภาวะ) | สภาพธรรมที่มีอยู่จริงโดยเนื้อแท้ตามปรมัตถ์ เป็นหลักการพื้นฐานที่สรวาสติวาทยืนยันต่ออวิชญัปติรูป | หน้า ๘๗๖ [๑๒๙] |
| śīla-śarīra (戒體) | ศีลสรีระ (ศีลขันธ์) | ร่างกายหรือตัวตนแห่งศีลที่ประทับอยู่ในสันดานภายหลังการสมาทานศีล มักเทียบเคียงกับอวิชญัปติรูป | หน้า ๘๗๒ [๑๓๓] |
| Dharmaskandha (法蘊足論) | ธรรมขันธปาทศาสตร์ | หนึ่งในคัมภีร์อภิธรรมหกบาทรุ่นแรกของสรวาสติวาท มีความเก่าแก่ร่วมสมัยกับคัมภีร์วิภังค์ของฝ่ายบาลี | หน้า ๘๗๕ [๑๓๐], ๘๗๒ [๑๓๓] |
| Saṅgītiparyāya (集異門足論) | สังคีติปริยายปาทศาสตร์ | คัมภีร์อภิธรรมรุ่นแรกที่จัดหมวดหมู่ธรรมตามลำดับหมวดหนึ่งถึงหมวดสิบตามแนวสังคีติสูตร | หน้า ๘๗๕ [๑๓๐], ๘๗๒ [๑๓๓] |
| Prakaraṇapāda (品類足論) | ปรกรณปาทศาสตร์ | คัมภีร์อภิธรรมหกบาทชั้นหลัง รจนาโดยพระวสุมิตร มีการจัดระบบหมวดหมู่ธรรมที่รัดกุมยิ่งขึ้น | หน้า ๘๗๔ [๑๓๑], ๘๗๒ [๑๓๓] |
| Jñānaprasthāna (發智論) | ชญานปรัสถานศาสตร์ | คัมภีร์ศูนย์กลางอันเปรียบเสมือนลำตัวของอภิธรรมสรวาสติวาท รจนาโดยพระกาตยายนีบุตร | หน้า ๘๗๒ [๑๓๓] |
| Mahāvibhāṣā (大毘婆沙論) | มหาอภิธรรมวิภาษา | คัมภีร์อรรถกถามหาปรัชญาของสำนักกัศมีร์-คันธาระ ประมวลมติอภิธรรมคลาสสิกของสรวาสติวาท | หน้า ๘๗๔ [๑๓๑], ๘๗๓ [๑๓๒] |
| Abhidharmakośa-bhāṣya | อภิธรรมโกศภาษยะ | คัมภีร์อภิธรรมชิ้นเอกของพระวสุพันธุ วิพากษ์มติสรวาสติวาทจากมุมมองเสาตรันติกะ | หน้า ๘๗๒ [๑๓๓] |
| Nyāyānusāra (順正理論) | อภิธรรมชุนเจิ้งหลี่ล lun | คัมภีร์อภิธรรมแก้ต่างของพระสังฆภัทระ เพื่อปกป้องมติสรวาสติวาทจากการวิพากษ์ของพระวสุพันธุ | หน้า ๘๗๒ [๑๓๓] |
| Samayapradīpikā (顯宗論) | อภิธรรมเสี่ยนจงล lun | คัมภีร์ย่อความของพระสังฆภัทระ แสดงหลักการที่แท้จริงของนิกายสรวาสติวาท | หน้า ๘๗๒ [๑๓๓] |
| Vibhaṅga | คัมภีร์วิภังค์ | คัมภีร์ลำดับที่สองในพระอภิธรรมปิฎกภาษาบาลีของฝ่ายเถรวาท มีโครงสร้างอธิบายมรรคแปดคู่ขนานกับธรรมขันธ์ | หน้า ๘๗๔ [๑๓๑], ๘๗๒ [๑๓๓] |
| Dhammasaṅgaṇī | คัมภีร์ธัมมสังคณี | คัมภีร์ลำดับแรกในพระอภิธรรมปิฎกบาลี แสดงการประมวลสภาวธรรมจิต เจตสิก รูป นิพพาน | หน้า ๘๗๒ [๑๓๓] |
| setughāta (堤塘) | เสตุฆาต (ทำนบ/คันกั้น) | คำอุปมาในอภิธรรม หมายถึงสภาวะที่สกัดกั้นบาปอกุศลมิให้หลั่งไหลข้ามเข้ามาในจิตสันดาน | หน้า ๘๗๔ [๑๓๑], ๘๗๓ [๑๓๒] |
| āsrava-nirodha (漏尽 / 防護) | อาสวขยะ / สังวรในศาสนาเชน | สภาวะการปิดกั้นและทำลายกระแสแห่งอาสวะกิเลสมิให้เกาะเกี่ยวจิตวิญญาณ | หน้า ๘๗๖ [๑๒๙] |
| bodhisattva-praṇidhāna (菩薩誓願) | โพธิสัตวประณิธาน | มหาปณิธานในการตรัสรู้เป็นพระพุทธเจ้า ธำรงอยู่ข้ามภพชาติด้วยกลไกแห่งอวิชญัปติกรรม | หน้า ๘๗๖ [๑๒๙], ๘๗๓ [๑๓๒] |
| pāramī / pāramitā (波羅蜜多) | บารมี / ปารมิตา | การบำเพ็ญกุศลสมภารขั้นยิ่งยวดของพระโพธิสัตว์ในชาดก อาศัยสังวรในการรักษาความบริสุทธิ์ของกรรม | หน้า ๘๗๖ [๑๒๙] |
