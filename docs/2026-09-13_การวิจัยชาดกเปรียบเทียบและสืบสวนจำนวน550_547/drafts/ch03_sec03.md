# บทที่ ๓: จุดตัดและการปะทะสังสรรค์ระหว่าง "ชาดกเถรวาท" กับ "อุดมการโพธิสัตว์ของมหายาน"

## ๓.๓ วิภาษวิธีทางอภิปรัชญาและญาณวิทยา (Divergent Metaphysical & Epistemological Hermeneutics)

### บทนำ: รอยแยกทางอภิปรัชญาและญาณวิทยาในมโนทัศน์เรื่องชาดกและพระโพธิสัตว์

การศึกษาเปรียบเทียบวรรณกรรมชาดกระหว่างสายจารีตเถรวาทบาลีกับสายจารีตมหายานสันสกฤต มิได้เป็นเพียงการสำรวจความผันแปรของโครงเรื่อง โครงสร้างทางฉันทลักษณ์ หรือลีลาทางวรรณศิลป์เท่านั้น หากแต่หัวใจสำคัญอันเป็นแก่นแกนของการแยกสายธารทางความคิดในประวัติศาสตร์พุทธปรัชญา คือ "วิภาษวิธีทางอภิปรัชญาและญาณวิทยา" (Divergent Metaphysical and Epistemological Hermeneutics) ซึ่งวางรากฐานอยู่บนคำถามมูลฐานว่า สภาวะความเป็นจริงของพระโพธิสัตว์คืออะไร พระองค์ทรงเวียนว่ายตายเกิดในสังสารวัฏภายใต้กฎเกณฑ์ทางภววิทยาแบบใด และการบำเพ็ญบารมีอันยิ่งยวดข้ามภพชาตินั้น ดำเนินไปด้วยกระบวนการรับรู้และสภาวะจิตระดับใด [1]

ในสายตาของจารีตเถรวาทสำนักมหาวิหารแห่งเกาะลังกา ชาดกคือ "ประวัติศาสตร์เชิงประจักษ์แห่งวิบากกรรม" (Empirical History of Karmic Retribution) พระโพธิสัตว์ทรงมีสถานะเป็นสิ่งมีชีวิตผู้มีขันธ์ ๕ อย่างแท้จริง ทรงดำเนินชีวิตอยู่ภายใต้กฎแห่งกรรมสัจนิยม (Karmic Realism) และยังคงดำรงสภาวะเป็น "กัลยาณปุถุชน" ตราบจนกระทั่งประทับ ณ ควงไม้มหาโพธิ์ พระองค์ทรงมีความเจ็บปวด เสวยทุกขเวทนาจริงทางกายภาพ และยังทรงมีโอกาสพลาดพลั้งกระทำอกุศลกรรมอันนำมาซึ่งเศษวิบากกรรมข้ามภพชาติ [2] ทว่า ในสายธารความคิดของพุทธศาสนานิกายมหายานและนิกายโลกุตรวาท (Lokottaravāda) ยุคต้น กระบวนทัศน์ทางอภิปรัชญาได้ถูกปฏิวัติไปสู่ระนาบใหม่ ชาดกมิได้เป็นเพียงบันทึกอัตชีวประวัติเชิงประสบการณ์นิยมของบุคคลเฉพาะราย หากแต่ถูกยกระดับเป็น "ภาพสำแดงแห่งปรมัตถสัจจะ" (Manifestation of Ultimate Truth) พระโพธิสัตว์ทรงก้าวพ้นแรงเหวี่ยงของสังสารวัฏไปสู่สภาวะเหนือโลก (Lokottara) การเวียนว่ายตายเกิดและการเสวยทุกข์ในชาดกกลายเป็นเพียง "พุทธลีลาจำแลง" หรือการคล้อยตามโลกสมมุติ (Lokānuvartana) เพื่อเป็นอุบายในการสั่งสอนเวไนยสัตว์ [3]

ยิ่งไปกว่านั้น ในมิติของญาณวิทยา จารีตมหายานได้พัฒนาหลักการ "ไตรโกฏิปริสุทธิ์" (Trikoṭi-pariśuddhi) หรือ "ตรีมณฑลปริสุทธิ์" (Trimaṇḍalapariśuddhi) ซึ่งกำหนดว่า การบำเพ็ญบารมีโดยเฉพาะมหาทานจะก้าวสู่ขั้นปรมัตถ์ได้ ก็ต่อเมื่อจิตของผู้บำเพ็ญประจักษ์แจ้งในศูนยตาสภาวะ (Śūnyatā) คือการรู้แจ้งว่า ผู้ให้ ผู้รับ และสิ่งที่ให้ ล้วนว่างเปล่าจากแก่นสารสวภาวะ [4] ควบคู่ไปกับการปฏิบัติจิตตภาวนาชั้นสูงว่าด้วย "การเปลี่ยนตนเป็นผู้อื่น" (Parātmaparivartana) ตามทัศนะของพระศานติเทวะ ซึ่งรื้อถอนอัตตาตัวตนและแปรเปลี่ยนร่างกายให้กลายเป็นทรัพย์สินสาธารณะของสรรพสัตว์มาแต่ปฐม [5] วิภาษวิธีระหว่างสองขั้วความคิดนี้จึงกลายเป็นจุดตัดทางปรัชญาที่ทรงพลังและลึกซึ้งที่สุดในคลังวรรณกรรมพุทธศาสนาอินเดียโบราณ

### ๑. กรรมและบารมี: สัจนิยมแห่งวิบากกรรม ปะทะ ไตรโกฏิปริสุทธิ์และสุญญตา

ความขัดแย้งทางปรัชญาด่านแรกที่ปรากฏอย่างเด่นชัดในการตีความชาดก คือคำถามว่าด้วยธรรมชาติของกรรม (Karma) วิบาก (Vipāka) และกลไกการสั่งสมบุญญบารมี (Pāramī / Pāramitā) ข้ามภพชาติ ซึ่งระหว่างเถรวาทกับมหายานได้ยึดถือกฎเกณฑ์ทางภววิทยาที่แตกต่างกันอย่างสิ้นเชิง

```
+-----------------------------------------------------------------------------------------+
|                  การเปรียบเทียบภววิทยาแห่งกรรมและบารมีระหว่างสองสายจารีต                      |
+-----------------------------------------------------------------------------------------+
| มิติเชิงวิเคราะห์ | ฝ่ายเถรวาทบาลี (Theravāda)             | ฝ่ายมหายานสันสกฤต (Mahāyāna)         |
+-------------------+---------------------------------------+-------------------------------------+
| ฐานทางภววิทยา     | สัจนิยมแห่งวิบากกรรม (Karmic Realism)  | สุญญตาวาทและมายาการ (Śūnyatāvāda)   |
| สภาวะจิตผู้ให้     | มหากุศลจิตสัมปยุตด้วยปัญญาและเจตนา      | ปรัชญาปารมิตา / ไตรโกฏิปริสุทธิ์     |
| สถานะของทานวัตถุ  | สสารและอวัยวะที่มีอยู่จริงตามปรมัตถธรรม | ศูนยภาพ ปราศจากสวภาวะ (Niḥsvabhāva) |
| กลไกการสะสมบารมี  | การสะสมรูปธรรมบุญญสมภารในชวนจิต       | การเข้าถึงศูนยตาและการอุทิศโพธิจิต   |
| ผลลัพธ์สูงสุด     | มหาบุรุษผู้ตรัสรู้ตัดขาดสังสารวัฏ       | พระธรรมกายอันไร้จุดเริ่มต้นและสิ้นสุด |
+-----------------------------------------------------------------------------------------+
```

#### ๑.๑ สัจนิยมแห่งวิบากกรรม (Karmic Realism) ในพุทธปรัชญาเถรวาท: เจตนา ขันธ์ ๕ และการสะสมบุญญสมภาร

ในระบบอภิปรัชญาของนิกายเถรวาทสำนักมหาวิหาร พระคันถรจนาจารย์ได้สถาปนาระบบอธิบายชาดกบนรากฐานของ "สัจนิยมแห่งวิบากกรรม" (Karmic Realism) อย่างเคร่งครัด ดังที่ปรากฏในงานศึกษาเชิงวิพากษ์ของ เนโอมี แอปเปิลตัน (Naomi Appleton) [6] โครงสร้างของชาดกบาลีมิได้ถูกสร้างขึ้นบนพื้นที่ของความเปรียบเชิงอุปมานิทัศน์ (Allegory) หากแต่ถูกถือว่าเป็น "ข้อเท็จจริงทางประวัติศาสตร์จิตวิทยา" ที่เกิดขึ้นจริงในกระแสธารแห่งขันธ์ ๕ ของบุคคลผู้หนึ่งซึ่งกำลังมุ่งหน้าสู่ความเป็นพระสัมมาสัมพุทธเจ้า

แกนกลางแห่งสัจนิยมนี้วางอยู่บนหลักพุทธพจน์ดั้งเดิมที่ว่า *"เจตนาหํ ภิกฺขเว กมฺมํ วทามิ"* (ภิกษุทั้งหลาย เรากล่าวว่าเจตนานั่นแลเป็นกรรม) พระพุทธโฆษาจารย์ได้นำเอาระบบอภิธรรมเข้ามาประดิษฐานไว้ในอรรถกถาชาดก (*Jātakaṭṭhavaṇṇanā*) และคัมภีร์ *วิสุทธิมรรค* (*Visuddhimagga*) โดยอธิบายว่า บารมีทั้ง ๑๐ ประการ (ทศบารมี) มิใช่อำนาจลึกลับภายนอก หากคือ "มหากุศลเจตนา" (Mahākusala-cetanā) ที่เกิดขึ้นในชวนจิตของพระโพธิสัตว์ ซึ่งประกอบพร้อมด้วยมหากุศลจิต ๘ ดวง ที่สัมปยุตด้วยญาณและอสังขาริกหรือสสังขาริก [7] ทุกครั้งที่พระโพธิสัตว์ทรงบริจาคทาน รักษาศีล หรือเจริญปัญญา กัมมปัจจัยและอุปนิสสยปัจจัยจะถูกจารึกไว้ในสันดานจิต สั่งสมเป็น "บุญญสมภาร" (Puññasambhāra) และ "ญาณสมภาร" (Ñāṇasambhāra) ข้ามภพชาติตามกระบวนการของวิถีจิตและภวังคจิต

ผลลัพธ์ประการสำคัญของสัจนิยมแห่งวิบากกรรมในเถรวาท คือการยืนยันสถานะความเป็น **"กัลยาณปุถุชน"** (Noble Worldling) ของพระโพธิสัตว์ พระโพธิสัตว์ในชาดกบาลียังมิใช่พระอริยบุคคล พระองค์ยังมิได้ละสังโยชน์แม้แต่ข้อเดียว อวิชชา ตัณหา และอุปาทานยังคงแฝงเร้นอยู่ในอนุสัย ด้วยเหตุนี้ พระโพธิสัตว์จึงยังคงอยู่ภายใต้กฎเหล็กของปฏิจจสมุปบาทและกรรมวัฏเช่นเดียวกับสรรพสัตว์ทั้งปวง ดังที่แอปเปิลตันได้ชี้ให้เห็นว่า ในชาดกบาลีหลายสิบเรื่อง พระโพธิสัตว์มิได้ทรงสมบูรณ์แบบไร้ที่ติ พระองค์เคยทรงแสดงความโง่เขลา (Foolish Bodhisatta) เคยตัดสินใจผิดพลาด เคยดื่มสุรา เคยพูดมุสาวาทด้วยความจำเป็น และเคยกระทำอกุศลกรรมอันส่งผลให้ต้องไปเสวยวิบากในทุคติภูมิ [8]

ตัวอย่างเชิงประจักษ์ที่สะท้อนสัจนิยมแห่งกรรมอย่างรุนแรงที่สุด ปรากฏในคัมภีร์ *เถราปทาน* หมวด *ปุพพกัมมปิโลติกาปทาน* (Pubbakammapilotika-apadāna) ซึ่งบันทึก "เศษกรรมเก่าอันเป็นริ้วรอยชั่วร้าย" ของพระสัมมาสัมพุทธเจ้าในพระชาตินี้ พระพุทธองค์ทรงเปิดเผยว่า แม้จะทรงบรรลุพระสัพพัญญุตญาณอันประเสริฐแล้ว แต่วิบากแห่งอกุศลกรรมที่เคยทรงกระทำไว้ในอดีตชาติตอนเป็นพระโพธิสัตว์ยังคงตามมาส่งผลทางสรีระร่างกายอย่างไม่อาจหลีกเลี่ยงได้:

> ในอดีตชาติเมื่อเราเกิดเป็นมาณพหนุ่ม ได้กล่าวดูหมิ่นพระสาวกของกัสสปพุทธเจ้า ด้วยเศษกรรมนั้น ในชาตินี้เราจึงต้องบำเพ็ญทุกรกิริยาอันไร้ผลอยู่นานถึง ๖ ปี... ในอดีตชาติเมื่อเราเกิดเป็นหมอยา ได้แกล้งถ่ายยาให้ลูกชายเศรษฐีตาย ด้วยเศษกรรมนั้น ในชาตินี้เราจึงต้องป่วยด้วยโรคปักขันทิกาพาธ (ลงพระโลหิต)... ในอดีตชาติเราได้ขว้างก้อนหินใส่พระปัจเจกพุทธเจ้า ด้วยเศษกรรมนั้น ในชาตินี้พระเทวทัตจึงกลิ้งก้อนหินลงมาจนสะเก็ดหินกระทบพระบาทของเราจนห้อพระโลหิต [9]

หลักฐานนี้พิสูจน์ว่า ในทัศนะของเถรวาท กฎแห่งกรรมมีอำนาจเป็นภววิทยาเด็ดขาดสูงสุดที่ครอบงำจักรวาล แม้แต่พระโพธิสัตว์ผู้ยิ่งใหญ่ก็ไม่อาจยกเว้นตนเองออกไปจากอำนาจของวิบากกรรมได้ การบำเพ็ญบารมีจึงเป็นการ "สู้รบและชดใช้หนี้กรรมจริง" ท่ามกลางกระแสคลื่นแห่งสังสารวัฏอันเจ็บปวด

นอกจากนี้ ในคัมภีร์ *อัฏฐสาลินี* (Atthasālinī: อรรถกถาพระธัมมสังคณี) พระพุทธโฆษาจารย์ได้วางนิยามของ "บารมี" ไว้อย่างรัดกุมตามนัยอภิธรรม โดยจำแนกระดับของบารมีออกเป็น ๓ ลำดับขั้นตามความเข้มข้นของการเสียสละ ได้แก่:
๑) **บารมี (Pāramī):** การบำเพ็ญขั้นสามัญ โดยการสละทรัพย์สิน วัตถุภายนอก บุตร และภรรยา (พาหิรทาน)
๒) **อุปบารมี (Upapāramī):** การบำเพ็ญขั้นกลาง โดยการสละอวัยวะ เลือด เนื้อ และสรีรส่วนใดส่วนหนึ่ง (อังคทาน)
๓) **ปรมัตถบารมี (Paramattha-pāramī):** การบำเพ็ญขั้นสูงสุด โดยการสละชีวิตของตนเองเพื่อธรรม (ชีวิตทาน / อัชฌัตติกทาน) [10]

การจำแนกเช่นนี้ยืนยันว่า การสั่งสมบารมีของเถรวาทเป็นกระบวนการ "ชั่งน้ำหนักเชิงปริมาณและคุณภาพของเจตนา" (Quantitative and Qualitative Weight of Volition) พระโพธิสัตว์ต้องทรงสละสิ่งที่มีมูลค่าทางชีววิทยาและโลกียวิถีจริง เพื่อแลกกับมหากุศลธรรมอันทรงพลังที่จะส่งผลให้จุติและปฏิสนธิในภพภูมิที่สูงขึ้นเรื่อย ๆ จนกระทั่งบรรลุพุทธภาวะในชาติสุดท้าย [11]

#### ๑.๒ มหาปรัชญาปารมิตาและหลักการไตรโกฏิปริสุทธิ์ (Trikoṭi-pariśuddhi)

ในทางตรงกันข้าม พุทธปรัชญาฝ่ายมหายานมองว่า ทัศนะเรื่องกรรมและบารมีของฝ่ายเถรวาท แม้จะมีความงดงามทางศีลธรรม แต่ยังคงตกอยู่ในกับดักของ "อัตตาธิปไตยและสวภาวทิฏฐิ" (Self-Referential Substantialism) เนื่องจากยังมองว่ามี "ตัวตนผู้ให้" ที่กำลังสะสม "ก้อนบุญ" เพื่อมุ่งหวัง "ผลการตรัสรู้เฉพาะตน" ในอนาคต

มหายานจึงได้ทำการปฏิวัติกระบวนทัศน์ทางญาณวิทยาครั้งใหญ่ผ่านวรรณกรรมหมวด *ปรัชญาปารมิตาสูตร* (Prajñāpāramitā Sūtras) และคัมภีร์อรรถกถามาดรเกียรติ เช่น *มหาปรัชญาปารมิตาศาสตร์* (Mahāprajñāpāramitā-śāstra / ต้าจื้อตู้ลุ่น) ที่ระบุว่ารจนาโดยพระนาคารชุน โดยสถาปนามโนทัศน์เรื่อง **"ไตรโกฏิปริสุทธิ์" (Trikoṭi-pariśuddhi)** หรือ **"ตรีมณฑลปริสุทธิ์" (Trimaṇḍalapariśuddhi)** ขึ้นเป็นมาตรฐานชี้ขาดความแท้จริงของบารมี [12]

คำว่า "ตรีมณฑล" หรือ "ไตรโกฏิ" หมายถึง องค์ประกอบ ๓ ส่วนของกระบวนการให้ทาน ได้แก่:
๑) **ทายก (Dāyaka):** ตัวบุคคลผู้กระทำการให้ทาน
๒) **ปฏิคาหก (Pratigrāhaka):** บุคคลหรือสิ่งมีชีวิตผู้รับทาน
๓) **ไทยธรรม หรือ เทยวัตถุ (Deya):** สิ่งของ เลือด เนื้อ หรือชีวิตที่ถูกนำมาบริจาค

ตามทัศนะของมหายาน หากบุคคลใดให้ทานโดยที่จิตยังมีความยึดมั่นถือมั่นว่า "ตัวฉันเป็นผู้ให้" บุคคลนั้นกำลังตกเป็นทาสของ *อัตมทิฏฐิ* (Ātmadṛṣṭi); หากเขายังมองเห็นว่า "ผู้นั้นเป็นผู้รับทานที่ต่ำต้อยหรือน่าสงสาร" เขากำลังตกเป็นทาสของ *สัตตทิฏฐิ* (Sattvadṛṣṭi); และหากเขายังมองว่า "วัตถุชิ้นนี้เป็นของมีค่าที่ฉันได้สละไป" เขากำลังตกเป็นทาสของ *ธรรมทิฏฐิ* (Dharmadṛṣṭi) การให้ทานที่ยังเจือปนด้วยนิมิตหมาย ๓ ประการนี้ ถูกจัดเป็นเพียง "โลกิยทาน" (Laukika-dāna) ซึ่งให้ผลเป็นวิบากสมบัติในสังสารวัฏเท่านั้น แต่ไม่อาจนับเป็น "ทานปารมิตา" (Dāna-pāramitā) ได้เลย [13]

ทานบารมีจะก้าวขึ้นสู่ความเป็น "ปารมิตา" (การข้ามพ้นสู่ฝั่งโน้น) ได้อย่างแท้จริง ก็ต่อเมื่อจิตของผู้บำเพ็ญสัมปยุตด้วย *ปรัชญาปารมิตา* (Prajñāpāramitā) นั่นคือ การรู้แจ้งแทงตลอดว่า องค์ประกอบทั้ง ๓ ส่วนล้วนเป็น **"ศูนยตา" (Śūnyatā)** ว่างเปล่า ปราศจากแก่นสารสาระในตัวเอง (Svabhāva-śūnya / Niḥsvabhāva) ปราศจากการปรุงแต่งทางมโนกรรม (Nirvikalpa) และไม่ยึดติดในเครื่องหมายนิมิตใด ๆ (**อนิมิตตธรรม - Animitta**) ปราศจากการตั้งความปรารถนาเพื่อผลตอบแทนทางโลกียะ (**อปรณิหิตธรรม - Apraṇihita**) [14]

พระศานติเทวะ (Śāntideva) ได้ประมวลคำสอนนี้ไว้อย่างคมกริบในคัมภีร์ *สิกษาสมุจจัย* (*Śikṣāsamuccaya*) โดยอ้างอิงจาก *อวตังสกสูตร* และ *รัตนกูฏสูตร* ว่า พระโพธิสัตว์เมื่อทรงสละชีวิตและร่างกาย พระองค์มิได้ทรงมองเห็นความเจ็บปวดว่าเป็นของตนเอง เพราะทรงประจักษ์แจ้งว่า ทั้งร่างกาย ผู้รับ และจิตผู้รู้ ล้วนเป็นเพียงกระแสมายาการที่ปราศจากเจ้าของ ดังข้อความที่ว่า:

> พระโพธิสัตว์ผู้ตั้งมั่นในไตรโกฏิปริสุทธิ์ ย่อมสละร่างกายดุจการสละท่อนไม้หรือก้อนหินลงสู่ป่าช้า พระองค์มิได้ทรงสำคัญหมายว่า "ข้าพเจ้ากำลังให้" มิได้สำคัญหมายว่า "ผู้นี้กำลังรับ" และมิได้สำคัญหมายว่า "สิ่งนี้คือกายของข้าพเจ้า" การให้เช่นนี้จึงเป็นอิสระจากตัณหา มานะ และทิฏฐิอย่างสิ้นเชิง [15]

#### ๑.๓ การวิเคราะห์เชิงมานุษยวิทยาทานเปรียบเทียบ: ทฤษฎีของ Reiko Ohnuma

เพื่ออธิบายความตึงเครียดทางอภิปรัชญานี้ให้กระจ่างชัดขึ้น ศาสตราจารย์ เรโกะ โอนุมะ (Reiko Ohnuma) ได้นำเอากรอบทฤษฎีมานุษยวิทยาว่าด้วย "ของขวัญและทาน" (Anthropology of the Gift) ของ มาร์แซล โมสส์ (Marcel Mauss), โจนาธาน แพร์รี (Jonathan Parry), และ ฌักส์ แดร์ริดา (Jacques Derrida) มาวิเคราะห์ตัวบทชาดกสละอวัยวะและร่างกาย (Dehadāna) ในวรรณกรรมพุทธศาสนาอินเดีย [16]

โอนุมะชี้ให้เห็นว่า ในทฤษฎีดั้งเดิมของ Marcel Mauss การให้ของขวัญย่อมก่อให้เกิด "พันธะสามประการ" (The Triple Obligation) เสมอ นั่นคือ พันธะในการให้ (to give), พันธะในการรับ (to receive), และพันธะในการตอบแทน (to reciprocate) ทว่า ในเชิงปรัชญาของ Jacques Derrida การให้ทานที่แท้จริงและบริสุทธิ์ (The Pure Gift) แทบจะเป็นสิ่งที่เป็นไปไม่ได้ในโลกแห่งความเป็นจริง เพราะทันทีที่ผู้ให้ "ตระหนักรู้" ว่าตนกำลังให้ หรือผู้รับ "รู้สึกเป็นหนี้บุญคุณ" ทานนั้นจะถูกดึงกลับเข้าสู่ระบบเศรษฐกิจแห่งการแลกเปลี่ยนผลประโยชน์ทางจิตวิทยาและศีลธรรมทันที [17]

ในจุดนี้ โอนุมะได้เสนอว่า วรรณกรรมชาดกของพุทธศาสนาได้พยายามประดิษฐ์สร้างระบบการให้ทานที่ก้าวข้ามพันธะแห่งการแลกเปลี่ยน โดยจำแนกการให้ทานในคัมภีร์พุทธออกเป็น ๓ มิติเชิงโครงสร้างสัมพันธ์ (ดู Table 3 ใน Ohnuma 2007, หน้า ๑๖๔):

```
+-----------------------------------------------------------------------------------------+
|                  เมทริกซ์การจำแนกทาน ๓ มิติ ตามข้อเสนอของ Reiko Ohnuma                    |
+-----------------------------------------------------------------------------------------+
| มิติของทาน        | ลักษณะการให้ / ทิศทาง              | บริบททางศาสนาและคัมภีร์           |
+-------------------+-----------------------------------+---------------------------------+
| ๑. Giving Up      | การถวายทานขึ้นสู่ "เนื้อนาบุญ"     | ถวายแด่พระพุทธ พระสงฆ์ สถูปเจดีย์ |
|                   | (Ascending / Puṇyakṣetra)         | หวังอานิสงส์ผลบุญข้ามภพชาติ     |
+-------------------+-----------------------------------+---------------------------------+
| ๒. Giving Down    | การสงเคราะห์ทานลงสู่ "ผู้ตกทุกข์"  | ให้แก่ยาจก คนยากไร้ สัตว์หิวโหย   |
|                   | (Descending / Kṛpaṇa)             | ขับเคลื่อนด้วยกรุณาธรรมสงสาร     |
+-------------------+-----------------------------------+---------------------------------+
| ๓. Giving Up²     | การสละร่างกายและชีวิตเพื่อก้าวข้าม  | สรีรทาน (Dehadāna) ขั้นอุกฤษฏ์   |
| (Transcendental)  | สังสารวัฏ (Trans-systemic Exit)   | บรรลุศูนยตาและพระสัพพัญญุตญาณ     |
+-------------------+-----------------------------------+---------------------------------+
```

๑) **Giving Up (การถวายขึ้น):** เป็นรูปแบบทานพื้นฐานของคฤหัสถ์ โดยการมอบสิ่งของให้แก่บุคคลที่มีสถานะทางศีลธรรมสูงกว่า เช่น พระภิกษุสงฆ์ หรือสถูปเจดีย์ (Dakṣiṇīya / Puṇyakṣetra) การให้นี้มีเป้าหมายเพื่อ "เก็บเกี่ยวผลบุญ" (Puñña) ข้ามภพชาติ เป็นการลงทุนทางเศรษฐกิจแห่งกรรมที่คาดหวังผลตอบแทนอันอุดมสมบูรณ์ในสวรรค์หรือความมั่งคั่งในโลกหน้า

๒) **Giving Down (การสงเคราะห์ลง):** เป็นการให้ทานแก่ผู้ที่มีสถานะต่ำกว่าตนเอง เช่น ยาจก วณิพก คนอนาถา หรือสัตว์เดรัจฉานผู้หิวโหย (Kṛpaṇa / Dīna / Anātha) การให้นี้มิได้มุ่งหวังผลบุญจากการเป็นเนื้อนาบุญของผู้รับ หากแต่ถูกขับเคลื่อนด้วย "กรุณาจิต" (Karuṇā) ทว่าในมิติสังคม ทานชนิดนี้มักตอกย้ำโครงสร้างลำดับชั้นทางอำนาจระหว่างผู้มีอันจะกินกับผู้ด้อยโอกาส

๓) **Giving Up² (การสละเพื่อก้าวข้ามสังสารวัฏ):** นี่คือจุดที่ "เดหทาน" (Dehadāna: การสละศีรษะ ดวงตา เลือด และเนื้อ) ในชาดกเข้ามาทำลายล้างระบบเศรษฐกิจของทานทั้งหมด โอนุมะเสนอว่า เมื่อพระโพธิสัตว์สละสรีระร่างกายของพระองค์ พระองค์ทรงกระทำในลักษณะที่ซ้อนทับกัน: พระองค์ทรง "สงเคราะห์ลง" (Giving Down) ให้แก่พราหมณ์ขอทานที่ละโมบ หรือแม่เสือหิวโซที่กำลังจะกินลูกของตน แต่ในขณะเดียวกัน การสละนั้นกลับกลายเป็นการ "ถวายขึ้นสู่ระดับอภิมหาปรมัตถ์" (Giving Up²) สู่พระโพธิญาณ [18]

ในมิตินี้ มหายานได้ใช้หลักไตรโกฏิปริสุทธิ์เข้ามา "ปลดเปลื้อง" เดหทานออกจากการเป็นธุรกรรมทางกรรม (Karmic Transaction) ของเถรวาท เดหทานในมหายานมิใช่การแลกเปลี่ยนเลือดเนื้อเพื่อแลกกับลักษณะมหาบุรุษ ๓๒ ประการแบบสัจนิยม หากแต่เป็นการประกาศอิสรภาพขั้นเด็ดขาดเหนือมายาคติเรื่อง "ตัวตน" (Ātman) พระโพธิสัตว์ทรงทำลายสัญญะแห่งการครอบครองทางโลกอย่างราบคาบ จนไม่มีสิ่งใดหลงเหลือให้เป็นของตนเองอีกต่อไป [19]

### ๒. สภาวะจิตและกายาของพระโพธิสัตว์: ปุถุชนเสวยวิบาก ปะทะ นิรมาณกายจำแลง (Nirmāṇakāya)

รอยแยกทางอภิปรัชญาประการที่สองที่สืบเนื่องมาจากเรื่องกรรม คือทัศนะว่าด้วย "ธรรมชาติของกายาและสภาวะจิต" ของพระโพธิสัตว์ขณะกำลังเผชิญหน้ากับความทุกข์ทรมานอันแสนสาหัสในชาดก ว่าความเจ็บปวดทางกายภาพนั้นเป็นสภาวะจริงแท้ หรือเป็นเพียงมายาภาพที่สำแดงขึ้นเพื่อสั่งสอนชาวโลก

#### ๒.๑ กายวิภาคแห่งความเจ็บปวด: สรีรทุกข์เชิงประสาทสัมผัสของพระโพธิสัตว์ในจารีตเถรวาท

ในวรรณคดีชาดกบาลีของฝ่ายเถรวาท ตัวบทอรรถกถาได้บันทึกภาพการสละอวัยวะและชีวิตของพระโพธิสัตว์ไว้อย่างสมจริง มีเลือดเนื้อ มีกลิ่นคาว และมีความเจ็บปวดทางประสาทสัมผัส (Physical suffering and visceral agony) อย่างถึงพริกถึงขิง พระโพธิสัตว์มิได้ทรงใช้เวทมนตร์หรือพลังจิตสะกดให้ความเจ็บปวดหายไป หากแต่ทรงเผชิญหน้ากับความทรมานนั้นด้วยขันธ์ ๕ ของมนุษย์และสัตว์ธรรมดา

หลักฐานเชิงประจักษ์อันทรงพลังปรากฏใน *สิวราชชาดก* (Sivi Jātaka, Ja 499) เมื่อพระเจ้าศิวิทรงตัดสินพระทัยพระราชทานดวงพระเนตรทั้งสองข้างแก่พราหมณ์ชราผู้มาทูลขอ ตัวบทอรรถกถาพรรณนาขั้นตอนการผ่าตัดของแพทย์หลวงนามว่าสีวกะไว้อย่างน่าสยดสยอง:

> หมอสีวกะบดโอสถขนานหนึ่งแล้วทาที่ดวงพระเนตรข้างขวา เส้นเอ็นพระเนตรได้ขาดออก ดวงพระเนตรได้หลุดถลนออกมาห้อยอยู่ที่พระปราง (แก้ม) ความเจ็บปวดอันกล้าแข็งได้เกิดขึ้นแก่พระมหาบุรุษ โลหิตได้ไหลหลั่งออกมาท่วมพระพักตร์และฉลองพระองค์ พระราชาทรงเอาพระหัตถ์ประคองดวงพระเนตรที่ห้อยอยู่นั้นไว้ แล้วตรัสสั่งว่า "สหายสีวกะ จงตัดเส้นเอ็นที่เหลือเสียเถิด อย่าชักช้าเลย!" [20]

ในฉากนี้ พระโพธิสัตว์มิได้ทรงพ้นไปจากความเจ็บปวด พระองค์ทรงเสวย "ทุกขเวทนา" อย่างแสนสาหัสทางประสาทสัมผัส ทว่าสิ่งที่ค้ำจุนพระองค์ไว้มิใช่การไร้ความรู้สึก แต่คือ "พละกำลังแห่งจิตใจ" ที่ประกอบด้วย **สัจจบารมี, อธิษฐานบารมี, และขันติบารมี** ทรงข่มความเจ็บปวดทางกายไว้ด้วยกำลังแห่งพระสัพพัญญุตญาณปณิธาน

เช่นเดียวกันใน *สสปัณฑิตชาดก* (Sasa Jātaka, Ja 316) เมื่อพระโพธิสัตว์เสวยพระชาติต่างกระต่าย ทรงตัดสินใจกระโจนเข้าสู่กองไฟร้อนระอุเพื่อย่างเนื้อของตนเป็นอาหารแก่พราหมณ์ (ซึ่งคือท้าวสักกะปลอมกายลงมา) แม้ในท้ายที่สุดไฟนั้นจะไม่ไหม้พระโพธิสัตว์ด้วยอำนาจการทดสอบของท้าวสักกะ แต่ในจิตสำนึกของกระต่ายโพธิสัตว์ ขณะที่ตัดสินใจกระโจนลงไปนั้น พระองค์ทรงเตรียมพร้อมที่จะ "ถูกเผาทั้งเป็นและมอดไหม้ดับสูญจริง" [21] และใน *ฉัททันตชาดก* (Chaddanta Jātaka, Ja 514) เมื่อพญาช้างฉัททันต์ถูกพรานโสณุดรยิงด้วยลูกศรอาบยาพิษ พญาช้างได้เอาอกดันต้นไม้ใหญ่เพื่อทรงกายไว้ ทนทุกขเวทนาแสนสาหัส แล้วทรงเอางวงจับเลื่อยช่วยพรานเลื่องางามทั้งสองข้างของตนจนเลือดสด ๆ พุ่งทะลักออกจากโพรงปาก ก่อนที่จะขาดใจตายด้วยความเจ็บปวด [22]

ความเจ็บปวดในชาดกเถรวาทจึงเป็น "ของจริง" ที่พิสูจน์ความเด็ดเดี่ยวแห่งจิตมนุษย์ หากพระโพธิสัตว์มิได้รู้สึกเจ็บปวด การสละอวัยวะย่อมไร้ซึ่งคุณค่าทางจริยธรรม เพราะการให้สิ่งที่ไม่ทำให้ตนเองต้องสูญเสียหรือเจ็บปวด ย่อมไม่อาจเรียกว่าเป็นการเสียสละขั้นสูงสุดได้

#### ๒.๒ ปรัชญาโลโกตตรวาท นิรมาณกาย และโลกานุวรรตนะ (Lokānuvartana)

ทว่า ในสายจารีตของนิกายมหาสังฆิกะ-โลโกตตรวาท (Mahāsāṃghika-Lokottaravāda) และพุทธศาสนามหายานยุคต่อมา นักคิดฝ่ายเหนือมองว่า ทัศนะที่ให้พระพุทธเจ้าหรือพระโพธิสัตว์ต้องมาเสวยทุกขเวทนาทางกายภาพอย่างน่าเวทนานั้น เป็นความคิดที่ "ลดทอนความบริสุทธิ์แห่งพุทธภาวะ" (Theological Degradation)

จากการศึกษาเอกสารตัวเขียนใบลานโบราณภาษาภาษาสันสกฤตผสม คัมภีร์ *มหาวัสตุ* (*Mahāvastu*) โดย คาตาร์ชีนา มาร์ชีเนียก (Katarzyna Marciniak, 2014) [23] ได้เปิดเผยหลักฐานสำคัญว่า นิกายโลโกตตรวาทได้สถาปนาระบบเทววิทยาที่แยกขาดจากเถรวาทอย่างชัดเจน คัมภีร์มหาวัสตุประกาศตั้งแต่บรรทัดแรก ๆ ว่า พระสัมมาสัมพุทธเจ้าทรงเป็น **"โลกุตตระ" (Lokottara: อยู่เหนือโลก)** มาแต่ปฐมกาล พระวรกายของพระองค์มิได้ประกอบขึ้นจากมหาภูตรูป ๔ ที่แปดเปื้อนด้วยกรรมกิเลสแบบปุถุชน พระองค์ปราศจากความหิว ความกระหาย ความเหน็ดเหนื่อย ความเจ็บป่วย และความแก่ชรา [24]

ปรากฏการณ์ทุกอย่างที่พระพุทธองค์และพระโพธิสัตว์ทรงแสดงในโลกมนุษย์ เช่น การประสูติ การเจริญเติบโต การเสวยพระชาติในกำเนิดสัตว์เดรัจฉาน การถูกลูกศรยิง หรือการถูกเฉือนเนื้อ เป็นเพียง **"โลกานุวรรตนะ" (*lokānuvartana*)** นั่นคือ การอนุโลมคล้อยตามโลกสมมุติ หรือการแสดงละครชีวิตตามครรลองโลก (Docetic Display) เพื่อประโยชน์ในการสั่งสอนเวไนยสัตว์ [25] ดังข้อความสำคัญในมหาวัสตุที่ระบุว่า:

> พระพุทธเจ้าทั้งหลายทรงอยู่เหนือโลก การกระทำทั้งปวงของพระองค์ในโลกเป็นเพียงโลกานุวรรตนะ... พระองค์มิได้ทรงมีความเจ็บปวดใด ๆ แต่ทรงแสดงอาการดุจเจ็บปวด เพื่อให้สรรพสัตว์ตระหนักถึงภัยแห่งวัฏสงสาร [26]

เมื่อแนวคิดนี้พัฒนาเข้าสู่มหายาน ได้ถูกจัดระบบเป็น **"ทฤษฎีตรีกาย" (Trikāya)** อย่างสมบูรณ์:
๑) **ธรรมกาย (Dharmakāya):** กายแห่งสัจธรรมอันติมะ ไร้รูป ไร้การเกิดดับ เป็นสภาวะบริสุทธิ์นิรันดร์
๒) **สัมโภคกาย (Saṃbhogakāya):** กายทิพย์แห่งความสุขอันไพศาล ที่สำแดงแก่เหล่าพระมหาโพธิสัตว์ในพุทธเกษตร
๓) **นิรมาณกาย (Nirmāṇakāya):** กายจำแลงทางกายภาพที่ส่งลงมาอุบัติในโลกมนุษย์และภพภูมิต่าง ๆ เพื่อโปรดสัตว์ [27]

ภายใต้ร่มเงาแห่งตรีกายวิทยา พระโพธิสัตว์ที่ปรากฏในชาดก จึงมิใช่ปุถุชนผู้กำลังสะสมบุญแบบลองผิดลองถูก หากแต่คือการสำแดงของ "นิรมาณกาย" พระโพธิสัตว์ระดับสูง (ผู้บรรลุตั้งแต่ อจลภูมิ หรือภูมิที่ ๘ ในระบบทศภูมิ Daśabhūmi ขึ้นไป) ทรงข้ามพ้นวิบากกรรมแบบโลกียะไปแล้ว พระองค์ทรงกระทำกรรมที่เรียกว่า **"อสัตยกรรม"** (กรรมที่ปราศจากวิบากผูกมัด) จิตของพระองค์ดำรงอยู่ในมหาสมาธิและสันติสุขตลอดเวลา

ดังนั้น ในมหายาน เมื่อพระเจ้าศิวิสละพระเนตร หรือเมื่อพระสุเมธดาบสทอดกายบนโคลนตม พระองค์มิได้ทรงเสวยทุกขเวทนาจริงทางจิตวิญญาณ หากแต่ทรงดำรงอยู่ใน "กรุณาญาณอันเต็มเปี่ยม" การหลั่งพระโลหิตและการฉีกขาดของเนื้อหนัง เป็นเพียงภาพสำแดงแห่งนิรมาณกายที่ถูกจัดวางไว้อย่างประณีต เพื่อเป็นสะพานเชื่อมระหว่างความว่างเปล่าแห่งศูนยตากับจิตใจของสรรพสัตว์ที่ยังยึดมั่นในรูปกาย [28]

```
+-----------------------------------------------------------------------------------------+
|                  เปรียบเทียบมโนทัศน์สรีรกายและเวทนาของพระโพธิสัตว์                            |
+-----------------------------------------------------------------------------------------+
| มิติเปรียบเทียบ   | เถรวาทบาลี (Karmic Realism)           | โลโกตตรวาท-มหายาน (Docetic Theory)  |
+-------------------+---------------------------------------+-------------------------------------+
| ธรรมชาติแห่งสรีระ  | รูปขันธ์ที่เกิดจากกรรม จิต อุตุ อาหาร    | นิรมาณกายจำแลง (Nirmāṇakāya)        |
| สภาวะแห่งเวทนา    | ทุกขเวทนาทางประสาทสัมผัสเกิดขึ้นจริง    | โลกานุวรรตนะ / ไม่เสวยทุกข์จริง       |
| กลไกทางจิตวิญญาณ  | ข่มเวทนาด้วยขันติและอธิษฐานจิต         | ดำรงในมหาสมาธิและศูนยตาวิหาร        |
| สถานะการข้ามพ้นกรรม| ยังเป็นปุถุชน ตกอยู่ใต้แรงเหวี่ยงกรรม  | เป็นอสัตยกรรม ก้าวพ้นสังสารวัฏแล้ว  |
| เป้าหมายการสละกาย  | สั่งสมมหากุศลเจตนาเพื่อพุทธภูมิ        | สำแดงพุทธลีลาเพื่อสั่งสอนเวไนยสัตว์ |
+-----------------------------------------------------------------------------------------+
```

#### ๒.๓ ปริศนาความย้อนแย้งแห่งร่างกาย (The Body Paradox): อสุภะ ปะทะ โอสถทิพย์แห่งมหาบุรุษ

ในมิติของอภิปรัชญาว่าด้วยสรีระ โอนุมะได้นำเสนอข้อค้นพบอันแหลมคมเกี่ยวกับ "ความย้อนแย้งแห่งร่างกาย" (The Body Paradox) ที่ปรากฏร่วมกันในวรรณกรรมชาดกทุกสายจารีต [29] นั่นคือ ตัวบทชาดกได้นำเสนอภาพของร่างกายพระโพธิสัตว์ใน ๒ ขั้วที่ขัดแย้งกันอย่างสุดขีด:

- **ขั้วที่ ๑: ร่างกายในฐานะ "อสุภะ" (Asubha):** พระโพธิสัตว์ทรงพิจารณาสรีระร่างกายของพระองค์ตามหลักวิปัสสนากรรมฐานดั้งเดิม ว่าเป็นถุงหนังที่บรรจุของเน่าเหม็น ปฏิกูล ๓๒ ประการ เป็นรังของหนอนและโรคาพยาธิ ไร้แก่นสารแตกดับง่าย และเป็นสิ่ง "อกตัญญู" (คาถา ๑.๒๒ ใน *ชาตกมาลา* ของพระอารยศูระ) ซึ่งแม้จะคอยทะนุถนอม ป้อนข้าว ป้อนน้ำ อาบน้ำชำระล้างเพียงใด ในท้ายที่สุดมันก็ทรยศด้วยการแก่ เจ็บ และตาย พระองค์จึงทรงสละร่างกายนี้ทิ้งไปประดุจการถ่มน้ำลาย ทิ้งก้อนเสลด หรือทิ้งขยะเปียกลงสู่พื้นดิน [30]

- **ขั้วที่ ๒: ร่างกายในฐานะ "มหาปุริสลักขณะและโอสถทิพย์" (Auspicious Body & Tasty Flesh):** ทว่าในทางตรงกันข้าม ตัวบทกลับพรรณนาว่า พระวรกายของพระโพธิสัตว์เป็นสรีระอันศักดิ์สิทธิ์ งดงามผุดผ่องดั่งทองคำชโลมด้วยน้ำทิพย์ เป็นบ่อเกิดแห่งมหาปุริสลักขณะ ๓๒ ประการ และที่น่าอัศจรรย์ยิ่งคือ ในชาดกหลายเรื่อง เช่น *ไมตรีพลชาดก* (Maitrībala-jātaka) ในชาตกมาลาของพระอารยศูระ และ *มณิจูฑาชาดก* (Maṇicūḍa-jātaka) เมื่อพระโพธิสัตว์ทรงกรีดพระวรกายเพื่อสละเลือดและเนื้อให้แก่ยักษ์ ๕ ตนที่หิวโหย เลือดและเนื้อของพระองค์กลับมี **"รสชาติหวานหอมประณีตดุจน้ำอมฤต" (Tasty and Nectar-like Flesh)** สามารถรักษาโรคร้าย บรรเทาความหิวกระหาย และเปลี่ยนจิตใจอันดุร้ายของเหล่ายักษ์ให้กลายเป็นจิตที่เปี่ยมด้วยศีลธรรมทันที [31]

โอนุมะชี้ให้เห็นว่า ความย้อนแย้งนี้สะท้อน "ญาณวิทยาเชิงสัญญะ" ของพุทธศาสนา: พระโพธิสัตว์ทรงใช้สรีระร่างกายที่เป็น "ของไร้ค่าทางโลกียะ" (อสุภะ) ทำหน้าที่เป็น "เงินตราทางจิตวิญญาณ" (Spiritual Currency) เพื่อเข้าซื้อสิ่งที่มีค่าสูงสุดอันเป็นอมตะ นั่นคือ **"พระธรรมกาย" (Dharmakāya)** และการที่เนื้อหนังของพระองค์มีรสหวานหอม ย่อมเป็นหลักฐานว่า ในกระบวนทัศน์ของชาดก คุณธรรมและความบริสุทธิ์มิใช่นามธรรมที่ล่องลอย แต่ได้ "สลักเสลาและแปรเปลี่ยนโครงสร้างทางกายภาพ" ของสรีระให้กลายเป็นยาวิเศษเพื่อการปลดปล่อยสรรพสัตว์ [32]

### ๓. ทฤษฎีการเปลี่ยนตนเป็นผู้อื่น (Parātmaparivartana) และปรัชญาแห่งสรีรทาน (Dehadāna)

จุดยอดสูงสุดของวิภาษวิธีทางญาณวิทยาในวรรณกรรมชาดกสายมหายาน คือการสืบสาวทฤษฎีจิตตภาวนาว่าด้วย "การสละตนเองให้แก่ผู้อื่นอย่างสิ้นเชิง" ซึ่งนำไปสู่การรื้อถอนเส้นแบ่งระหว่าง "อัตตา" (ตนเอง) กับ "ปรัตถะ" (ผู้อื่น) จนหมดสิ้น

#### ๓.๑ วิภาษวิธีแห่งอัตตาใน *โพธิสัตวจรรยาวตาร* ของพระศานติเทวะ

ในคัมภีร์ *โพธิสัตวจรรยาวตาร* (*Bodhicaryāvatāra*) ผลงานชิ้นเอกของพระศานติเทวะ (Śāntideva, พุทธศตวรรษที่ ๑๓ แห่งมหาวิทยาลัยนาลันทา) เราจะพบการวางรากฐานทางปรัชญาจริยศาสตร์ที่ลึกซึ้งและเฉียบคมที่สุด ว่าด้วยมโนทัศน์คู่แฝด: **"ปรมาตมสมตา" (Parātmasamatā: ความเสมอภาคเท่าเทียมกันระหว่างตนเองกับผู้อื่น)** และ **"ปรมาตมปริวรรตนะ" (Parātmaparivartana: การโอนย้ายแลกเปลี่ยนตนเองกับผู้อื่น)** [33]

พระศานติเทวะได้ตั้งคำถามเชิงญาณวิทยาเพื่อทำลายโครงสร้างของ "อัตตาประโยชน์นิยม" (Ethical Egoism) ไว้อย่างสะเทือนอารมณ์ในบทที่ ๘ คาถาที่ ๙๐–๙๘ โดยทรงเริ่มจากการชี้ว่า สิ่งมีชีวิตทั้งปวงมีความปรารถนาในความสุขและเกลียดกลัวความทุกข์เหมือนกันทั้งหมด เมื่อเป็นเช่นนั้น เหตุใดเราจึงต้องขวนขวายเพื่อความสุขของตนเองเพียงฝ่ายเดียว แต่กลับเพิกเฉยต่อความทุกข์ของผู้อื่น?

จากนั้น พระศานติเทวะได้ทำการหักล้างข้อโต้แย้งที่ว่า "ความทุกข์ของผู้อื่นมิได้เกิดขึ้นในตัวฉัน ฉันจึงไม่จำเป็นต้องไปแบกรับ" ด้วยการยกอุปมาเรื่อง "มิติแห่งกาลเวลา" (Temporal Dimensions of Selfhood) ดังปรากฏในบทวิเคราะห์อันลือลั่นของ ปีเตอร์ ฟาร์ริงตัน (Peter Farrington, 2008) และ พอล วิลเลียมส์ (Paul Williams, 1998) [34] ซึ่งศานติเทวะได้รจนาไว้ว่า:

> *yady anyo nānubhāvyaḥ syāt kasmāt te parirakṣyate |  
> nāgāmikāyaduḥkhān me bādhā tat kena rakṣyate ||*  
> 
> "หากท่านกล่าวว่า ความทุกข์ของผู้อื่นมิได้เบียดเบียนข้าพเจ้า ข้าพเจ้าจึงไม่จำเป็นต้องปกป้องเขา  
> เช่นนั้นแล้ว ความทุกข์ของร่างกายในอนาคต (เช่น เมื่อแก่ชราหรือในชาติหน้า) ก็มิได้เบียดเบียนข้าพเจ้าในปัจจุบันขณะนี้เลย  
> แล้วเหตุใดข้าพเจ้าจึงต้องไปกังวลและขวนขวายปกป้องมันเล่า?" (*Bodhicaryāvatāra* 8.97) [35]

พระศานติเทวะชี้ให้เห็นอย่างทะลุปรุโปร่งว่า ร่างกายในวัยชราหรือในภพชาติหน้า ก็เป็น "สิ่งอื่น" (Other) ที่แยกขาดจากร่างกายในปัจจุบันขณะไม่ต่างจากร่างกายของคนอื่น การที่เรายอมทำงานหนักในวันนี้เพื่อเก็บเงินไว้ใช้ยามแก่ชรา ทั้งที่ตัวเราในวัยชรายังมิได้เกิดขึ้น ย่อมพิสูจน์ว่า เรากำลังยอมรับการโอนย้ายความทุกข์ข้ามมิติเวลาได้ เช่นนั้นแล้ว การปฏิเสธไม่ยอมช่วยเหลือผู้อื่นโดยอ้างว่าเป็น "คนละคนกัน" จึงเป็นเพียงภาพลวงตาของอวิชชา

ผลสรุปทางญาณวิทยาของศานติเทวะคือ: **"ความทุกข์จำต้องถูกขจัดปัดเป่า เพียงเพราะมันคือความทุกข์!" (Duḥkha is to be prevented simply because it is duḥkha)** มิใช่เพราะมันเป็นทุกข์ของฉัน หรือเป็นทุกข์ของผู้อื่น ความทุกข์ไม่มีเจ้าของ ไม่มีป้ายชื่อติดอยู่ เมื่อเห็นความทุกข์เกิดขึ้นที่ใด ย่อมเป็นหน้าที่ของจิตที่ตื่นรู้จะต้องเข้าไปดับทุกข์นั้น [36]

จากฐานคิดนี้ จึงนำไปสู่การปฏิบัติขั้นสูงสุดคือ **ปรมาตมปริวรรตนะ (Parātmaparivartana)** นั่นคือ การเอาจิตใจของตนเองไปสวมทับในร่างของผู้อื่น นำเอาความทุกข์ ความยากจน และความเจ็บปวดของสรรพสัตว์มาเป็นของตน และโอนย้ายความสุข บุญบารมี และความสะดวกสบายทั้งหมดของตนมอบให้แก่ผู้อื่นอย่างไม่มีเงื่อนไข [37]

#### ๓.๒ จากทฤษฎีภาวนาสู่มหากรณีศึกษาสรีรทาน (Dehadāna) ในวรรณกรรมชาดก

เมื่อนำกรอบคิดเรื่อง *Parātmaparivartana* ของพระศานติเทวะ มาส่องสะท้อนวรรณกรรมชาดกสละอวัยวะและร่างกาย (Dehadāna) เราจะพบมิติความหมายใหม่ที่พลิกโฉมหน้าการอ่านชาดกไปอย่างสิ้นเชิง: **พระโพธิสัตว์มิได้ทรงมองว่า พระองค์กำลัง "สละสิ่งของที่เป็นของพระองค์ให้แก่ผู้อื่น" หากแต่ทรงมองว่า "ร่างกาย เลือด และเนื้อนี้ เป็นของผู้อื่นมาตั้งแต่ต้นแล้ว!"**

ในงานศึกษาของ ดร. ชคทิศ จันทระ มิศระ (Jagdish Chandra Mishra, 2004) และ แฮ็นดริก เกิร์น (Hendrik Kern, 1891/1914) เกี่ยวกับคัมภีร์ *ชาตกมาลา* (*Jātakamālā*) ของพระอารยศูระ [38] ได้แสดงให้เห็นว่า พระอารยศูระได้นำเอาอุดมการณ์นี้มาเป็นแกนกลางในการเรียบเรียงชาดก ๓๔ เรื่อง โดยเฉพาะ ๔ มหากรณีศึกษาสำคัญ:

๑) **วยาฆรีชาดก (Vyāghrī-jātaka: เรื่องที่ ๑ ในชาตกมาลา):**  
พระอารยศูระจงใจเลือกนำเรื่องการสละร่างให้แม่เสือหิวขึ้นเป็นปฐมบทของคัมภีร์ เพื่อประกาศจุดยืนทางอภิปรัชญานี้ เมื่อพราหมณ์หนุ่มผู้เป็นพระโพธิสัตว์พบเห็นแม่เสือผอมโซกำลังจะจับลูกอ่อนของตนกินเป็นอาหาร พระองค์มิได้ทรงลังเลแม้แต่น้อย พระองค์ทรงส่งศิษย์ออกไปหาอาหาร แต่แท้จริงแล้วทรงตั้งพระทัยจะใช้ร่างกายตนเองเป็นเครื่องสังเวย พระองค์ทรงเปล่งอุทานว่า ร่างกายนี้เป็นสิ่งเปื่อยเน่า ปราศจากแก่นสาร การได้ใช้มันเพื่อช่วยชีวิตแม่เสือและลูกเสือ ย่อมเป็นการเปลี่ยน "สิ่งปฏิกูลไร้ค่าให้กลายเป็นยานพาหนะแห่งมหาโพธิญาณ" พระองค์จึงทรงกระโจนจากหน้าผาลงไปกระแทกพื้นจนแหลกเหลวเพื่อให้แม่เสือกินเนื้อได้สะดวก [39]

๒) **ศิวีชาดก (Śibi-jātaka: เรื่องที่ ๒ ในชาตกมาลา):**  
เมื่อท้าวสักกะปลอมเป็นพราหมณ์ตาบอดมาขอพระเนตร พระเจ้าศิวีมิได้ทรงมองเห็นว่าดวงตาเป็นทรัพย์สมบัติส่วนพระองค์ ขณะที่พระองค์ทรงควักพระเนตรออก พระองค์ได้ทรงประกาศคาถาอันเป็นหมุดหมายแห่งพุทธศาสตร์มหายานว่า:

> *nāyaṃ yatnaḥ sārvabhaumatvam āptuṃ  
> naiva svargaṃ nāpavargaṃ na kīrtim |  
> trātuṃ lokān ity ayaṃ me prayatnaḥ...*  
> 
> "ความเพียรพยายามในการควักดวงตานี้ มิใช่เพื่อมุ่งหวังความเป็นพระเจ้าจักรพรรดิ  
> มิใช่เพื่อสวรรค์ มิใช่เพื่อความหลุดพ้นเฉพาะตน (อปวรรคะ/โมกษะ) และมิใช่เพื่อชื่อเสียงเกียรติยศ  
> แต่ความเพียรนี้ มีขึ้นเพื่อช่วยเหลือรื้อขนสรรพสัตว์ในโลกทั้งปวงให้พ้นทุกข์!" (*Jātakamālā* 2.28) [40]

คาถานี้คือการปฏิเสธเป้าหมายแห่งการดับทุกข์เฉพาะตนตามอุดมคติพระอรหันต์ดั้งเดิมอย่างสิ้นเชิง และยืนยันว่าการสละอวัยวะมิใช่ธุรกรรมแลกเปลี่ยน แต่เป็นการอุทิศชีวิตเพื่อสรรพสัตว์ตามหลักปรมาตมปริวรรตนะ

๓) **ไมตรีพลชาดก (Maitrībala-jātaka: เรื่องที่ ๘ ในชาตกมาลา):**  
เมื่อยักษ์ ๕ ตนที่ถูกเนรเทศเข้ามาในพระนครและไม่สามารถกินอาหารมนุษย์ได้เนื่องจากอำนาจบารมีของพระราชาไมตรีพล พวกมันจึงขอเลือดและเนื้อสด ๆ จากพระราชา พระเจ้าไมตรีพลทรงยินดีอย่างยิ่ง ทรงให้แพทย์เปิดเส้นพระโลหิต ๕ จุด แล้วทรงปาดเนื้อของพระองค์ให้เหล่ายักษ์เคี้ยวกินสด ๆ ตัวบทพรรณนาว่า พระราชาทรงมองดูยักษ์ดื่มเลือดของพระองค์ด้วยความปีติยินดีประดุจมารดาเฝ้ามองบุตรดื่มน้ำนมจากอก [41] สรีระของพระองค์มิได้เป็นของพระองค์อีกต่อไป แต่ได้กลายเป็น "อาหาร" ที่แจกจ่ายให้แก่สิ่งมีชีวิตที่หิวกระหาย

๔) **หัสตีชาดก (Hasti-jātaka: เรื่องที่ ๓๐ ในชาตกมาลา):**  
พญาช้างโพธิสัตว์พบกลุ่มผู้หลงทาง ๗๐๐ คนกำลังจะอดตายในทะเลทรายทุรกันดาร พญาช้างได้บอกทางให้พวกเขาเดินไปยังเชิงหน้าผา แล้วพระองค์ทรงวิ่งอ้อมไปกระโจนหน้าผาลงมาตายเพื่อให้ศพของตนเป็นอาหาร ทรงสั่งเสียไว้ก่อนตายว่า จงกินเนื้อของข้าพเจ้าเพื่อประทังชีวิต และจงนำลำไส้ใหญ่ของข้าพเจ้าไปล้างและเป่าลมทำเป็นถุงบรรจุน้ำ เพื่อใช้เดินทางข้ามทะเลทรายต่อไป [42] พญาช้างได้สละแม้กระทั่ง "อวัยวะภายใน" ให้กลายเป็นเครื่องมือเอาชีวิตรอดของผู้อื่นอย่างสมบูรณ์แบบ

นอกจากนี้ ในวรรณกรรมฝ่ายสันสกฤต เช่น *ทิวยาวทาน* (Divyāvadāna 32) เรื่อง *รูปาวดีอวทาน* (Rūpyāvatī-avadāna) ยังได้ขยายขอบเขตของเดหทานข้ามพรมแดนเพศสภาพ (Gender Boundaries) โดยเล่าถึงนางรูปาวดีผู้เฉือนเต้านมทั้งสองข้างของตนเองให้แก่หญิงยากจนที่กำลังหิวโซจนคิดจะกินลูกอ่อนของตน การสละเต้านมซึ่งเป็นสัญลักษณ์สูงสุดแห่งความเป็นสตรีและมารดา ได้ถูกยกระดับผ่านการตั้งสัจกิริยา จนทำให้นางสามารถ "สลายอิตถินทรีย์และสถาปนาปุริสินทรีย์" กลายเป็นบุรุษเพื่อบำเพ็ญพุทธภูมิ [43]

#### ๓.๓ สัจกิริยา (Satyakriyā) ในฐานะญาณวิทยาเชื่อมภววิทยา: พลังแห่งสัจจะและความสั่นสะเทือนแห่งจักรวาล

ในตอนท้ายของเรื่องเล่าเดหทานทุกเรื่อง ไม่ว่าจะเป็นฝ่ายบาลีหรือฝ่ายสันสกฤต วิกฤตการณ์มักได้รับการคลี่คลายผ่านกลไกทางญาณวิทยาที่สำคัญยิ่ง นั่นคือ **"สัจกิริยา" (Satyakriyā / Saccakiriyā) หรือ สัจจาธิษฐาน** [44]

เมื่อพระโพธิสัตว์ทรงสละอวัยวะ เลือด หรือเนื้อเสร็จสิ้น และทรงเผชิญหน้ากับความพิกลพิการหรือความตาย ท้าวสักกะหรือบุคคลรอบข้างมักจะเข้ามาทูลถามว่า พระองค์ทรงกระทำไปด้วยความเศร้าโศก เสียดาย หรือความทะยานอยากในโลกียสมบัติหรือไม่ พระโพธิสัตว์จะทรงตั้งจิตมั่นและเปล่ง "วาจาสัจ" ออกมาว่า:

> "ด้วยสัจวาจานี้ หากเจตนาในการสละดวงตา (หรือเลือดเนื้อ) ของข้าพเจ้า มิได้เป็นไปเพื่อผลประโยชน์ส่วนตน มิได้เป็นไปเพื่อสวรรค์หรือเทวโลก แต่เป็นไปเพื่อพระสัพพัญญุตญาณเพื่อรื้อขนสรรพสัตว์อย่างแท้จริงแล้วไซร้ ขอให้ดวงตาของข้าพเจ้าจงกลับคืนมาเป็นปกติเถิด!" [45]

ทันทีที่พระองค์ทรงประกาศสัจวาจานี้ กฎธรรมชาติและระเบียบจักรวาลจะตอบสนองทันที เกิดแผ่นดินไหวสะเทือน ๖ ประการ (Ṣaḍvikāram) ฝนดอกไม้ทิพย์โปรยปรายลงมาจากฟากฟ้า และอวัยวะที่สูญเสียไปจะงอกประสานกลับคืนมาอย่างสมบูรณ์ หรือพระองค์จะทรงได้รับ "ดวงตาทิพย์แห่งปัญญา" (Dhammacakkhu / Prajñācakṣu) ที่สว่างไสวยิ่งกว่าดวงตาเนื้อเดิมนับพันเท่า [46]

โอนุมะและแอปเปิลตันได้วิเคราะห์ตรงกันว่า สัจกิริยามิใช่การอ้อนวอนขอพรจากพระเจ้าหรือสิ่งศักดิ์สิทธิ์ภายนอก หากแต่เป็น **"กลไกทางภววิทยา" (Ontological Mechanism)** ในพุทธปรัชญา ที่ยืนยันว่า: เมื่อ "ความจริงในระดับจิตใจ" (สัจจะแห่งมหาปณิธานที่ไม่เห็นแก่ตัว) ดำรงอยู่อย่างบริสุทธิ์หมดจด ๑๐๐% ความจริงทางจิตนั้นย่อมมีอำนาจเหนือ "ความจริงระดับกายภาพ" สัจกิริยาจึงทำหน้าที่เป็นสะพานเชื่อมระหว่างญาณวิทยา (ความตระหนักรู้ในความจริง) เข้ากับภววิทยา (การเปลี่ยนแปลงโครงสร้างทางกายภาพของโลก) อย่างน่าอัศจรรย์ [47]

### บทสังเคราะห์: จุดบรรจบและรอยแยกนิรันดร์ระหว่างสองมหาปรัชญา

จากการศึกษาวิเคราะห์วิภาษวิธีทางอภิปรัชญาและญาณวิทยาในวรรณกรรมชาดกข้ามสายจารีต เราสามารถประมวลภาพรวมความแตกต่างเชิงกระบวนทัศน์ระหว่างพุทธศาสนาฝ่ายเถรวาทบาลีกับฝ่ายมหายานสันสกฤต ได้ดังตารางสังเคราะห์ต่อไปนี้:

```
+-----------------------------------------------------------------------------------------+
|                  ตารางสังเคราะห์เปรียบเทียบกระบวนทัศน์ชาดกระหว่างสองสายจารีต                  |
+-----------------------------------------------------------------------------------------+
| มิติเชิงปรัชญา    | เถรวาทบาลี (Theravāda Mahāvihāra)      | มหายานสันสกฤต (Mahāyāna Tradition)  |
+-------------------+---------------------------------------+-------------------------------------+
| ๑. สถานะทางภววิทยา| สัจนิยมแห่งวิบากกรรม (Karmic Realism)  | สุญญตาวาทและมายาการ (Śūnyatāvāda)   |
| ของพระโพธิสัตว์   | - กัลยาณปุถุชน มีขันธ์ ๕ แท้จริง        | - พระโพธิสัตว์ระดับสูง / นิรมาณกาย  |
|                   | - ทำบาปได้ มีข้อผิดพลาด เสวยเศษกรรม    | - อสัตยกรรม ก้าวพ้นแรงเหวี่ยงกรรม   |
+-------------------+---------------------------------------+-------------------------------------+
| ๒. ญาณวิทยาแห่งทาน| เจตนาและบุญญสมภารเชิงรูปธรรม          | ไตรโกฏิปริสุทธิ์ (Trikoṭi-pariśuddhi)|
|                   | - ชั่งน้ำหนักเจตนาในชวนจิต            | - ว่างเปล่าจาก ผู้ให้ ผู้รับ สิ่งที่ให้ |
|                   | - หวังพุทธภูมิเป็นผลลัพธ์สูงสุด        | - ปราศจากนิมิต (Animitta)           |
+-------------------+---------------------------------------+-------------------------------------+
| ๓. สรีรทุกข์และกายา| สรีรทุกข์ทางประสาทสัมผัสเป็นของจริง     | โลกานุวรรตนะ (Lokānuvartana)        |
|                   | - เจ็บปวด เลือดไหล ทรงข่มด้วยขันติ      | - พุทธลีลาจำแลง ไม่เสวยทุกข์จริง    |
|                   | - กายเนื้อมีขีดจำกัดตามธรรมชาติ         | - กายคือโอสถทิพย์ / รสหวานหอม       |
+-------------------+---------------------------------------+-------------------------------------+
| ๔. ปรัชญาแห่งการสละ| สละสิ่งของภายนอกและอวัยวะของตนเอง      | ปรมาตมปริวรรตนะ (Parātmaparivartana)|
|                   | - สละเพื่อแลกกับบารมีธรรม              | - ทำลายอัตตา: กายนี้เป็นของผู้อื่น   |
|                   | - แยกตนเองออกจากผู้อื่นชัดเจน          | - โอนย้ายทุกข์สุข สลายเส้นแบ่งตัวตน |
+-------------------+---------------------------------------+-------------------------------------+
| ๕. บทบาทของสัจกิริยา| ยืนยันความสัตย์จริงแห่งจิตใจ           | อำนาจภววิทยาแห่งโพธิจิต             |
|                   | - ฟื้นฟูอวัยวะและได้รับดวงตาทิพย์      | - สัจจะแห่งศูนยตาสั่นสะเทือนจักรวาล |
+-------------------+---------------------------------------+-------------------------------------+
```

อย่างไรก็ดี แม้ว่าในระดับอภิปรัชญาและญาณวิทยา สายธารทั้งสองจะดูประหนึ่งว่าแยกขาดจากกันอย่างสุดขั้ว ระหว่าง "สัจนิยมเชิงวิบากกรรมของมนุษย์ผู้ดิ้นรน" กับ "มหามายาการอันบริสุทธิ์ของพระพุทธสภาวะเหนือโลก" ทว่า ในระดับของ "จริยศาสตร์และการปฏิบัติ" (Praxis and Ethical Import) วรรณกรรมชาดกของทั้งสองสายกลับบรรจบลง ณ จุดเดียวกันอย่างน่าอัศจรรย์

ทั้งเถรวาทและมหายานต่างใช้เรื่องเล่าชาดกเพื่อกระตุกเตือนจิตสำนึกของมนุษย์ให้ตระหนักถึง "ความไร้แก่นสารของความเห็นแก่ตัว" ชาดกทำหน้าที่เป็นคลังแสงทางศีลธรรมที่ปฏิเสธความละโมบ การสะสมทรัพย์สิน และการหลงใหลในเรือนร่าง พระโพธิสัตว์ไม่ว่าจะในฐานะกัลยาณปุถุชนผู้หลั่งเลือดด้วยความเจ็บปวด หรือในฐานะนิรมาณกายผู้สำแดงพุทธลีลา ล้วนเป็นแบบอย่างอันสูงสุดของ **"ความรักและความเสียสละอันไร้ขอบเขต" (Boundless Altruism)** ซึ่งยืนหยัดเป็นประทีปส่องสว่างท่ามกลางความมืดมนของสังสารวัฏตลอดสองสหัสวรรษที่ผ่านมา [48]
