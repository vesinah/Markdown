4. ศัพท์เฉพาะ/ศัพท์วิชาการที่ต้องรู้
5. งานศึกษาสำคัญที่ต้องอ่าน พร้อมข้อมูลบรรณานุกรมและลิงก์เข้าถึงเนื้อหาเต็ม

## โครงร่างบท (Outline Proposal - ฉบับเบื้องต้นก่อน Foraging Loops)

> หมายเหตุ: โครงร่างนี้จะได้รับการปรับปรุงใหม่หลังสืบค้นจนอิ่มตัว แล้วนำเสนอผ่าน Outline Gate อีกครั้งก่อนเขียนร่างจริง

1. **บทที่ 1: บทนำ สถานภาพการศึกษา และระเบียบวิธี** — ปรากฏการณ์ต้นฉบับศักดิ์สิทธิ์เดินทางข้ามภาษา ทบทวนวรรณกรรมวิจัย (historiography) ขอบเขต และระเบียบวิธีการศึกษาต้นฉบับเขียน (manuscript studies)
2. **บทที่ 2: ประเภทวิทยาและศัพท์วิชาการ** — typology ของกลยุทธ์: interlinear gloss, nissaya, chaya, kunten/kundoku, eonhae, 'grel ka, diglot/bilingual manuscript, hybrid translation; ศัพท์วิชาการครบชุดพร้อมคำถ่ายถอดไทย
3. **บทที่ 3: เถรวาทบาลีในอุษาคเนย์** — nissaya พม่า ไทย ล้านนา เขมร; การคัดลอกคัมภีร์บาลีพร้อมคำแปลแทรก; กรณีศึกษาตัวบทสำคัญ
4. **บทที่ 4: พุทธศาสนาเอเชียตะวันออก** — kunten/kundoku ญี่ปุ่น, eonhae เกาหลี, เวียดนาม; คัมภีร์จีน-สันสกฤตคู่ภาษา; ทันกุต/ซีเซีย
5. **บทที่ 5: ทิเบต มองโกเลีย และเอเชียกลาง** — 'grel ka/dbu med ทิเบต, การแปลคัมภีร์มองโกเลีย, อุยกูร์, คันธารี; กรณีศึกษา Dunhuang manuscripts
6. **บทที่ 6: เปรียบเทียบข้ามศาสนาและสังเคราะห์** — gloss ละติน-แวร์นาคูลาร์ในคริสต์ศาสนา, Masorah, อัลกุรอานคู่ภาษา, ธรรมเนียมเวท; สังเคราะห์ปัจจัยกำหนดรูปแบบ ช่องว่างวิจัย และบรรณานุกรมแนะนำ
