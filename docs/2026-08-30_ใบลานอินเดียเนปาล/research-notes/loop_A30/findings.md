## สรุปข้อค้นพบ A-30
1. **ใบลานอินเดียใต้เก่าสุดที่ยืนยันผ่าน Crossref ใน session นี้: ยังไม่พบ** — งานที่ทันสมัยที่สุดเกี่ยวกับการระบุชนิดพืช+แหล่งวัสดุ (Poliakova/Ciotti 2024–2026) ใช้ sample จาก Hamburg/EFEO แต่ไม่ประกาศ "เก่าสุด" อย่างเป็นทางการ; งานเชิงพันธุ์ไม้+epigraphy (Tamil-Brāhmī, 200 BCE–300 CE) ไม่ใช่ palm-leaf ที่เหลือถึงปัจจุบัน
2. **วิธี dating มาตรฐานที่พบจริง 3 ชั้น:** (ก) colophon วันที่/ศักราช (1334/1435/1493 ใน S-337; Nishāṭ 1163 AH ใน A-29) — ทรงพลังที่สุดเมื่อมีอยู่; (ข) palaeography — จำแนก variety อักษร (Rath 2012 Grantha) + หลัก "งานเขียนมีอายุ = folium ใหม่สุด" (S-336); (ค) radiocarbon — invasive, ใช้เมื่อไม่มี colophon, ต้องระวังความต่างอายุของ folia (Bakhshālī 224–993 CE ครอบคลุม 3 ช่วง) + การปนเปื้อน
3. **หลักสำคัญจาก Bakhshālī (S-336):** radiocarbon วัดอายุวัสดุ ไม่ใช่งานเขียน — การนำช่วง 14C เก่าสุด (224–383 CE) ไปเรียกว่า "อายุคัมภีร์" ถูกกลุ่ม Sanskritists ชี้ว่าเป็นการตีความผิด → มีผลโดยตรงกับ palm-leaf ที่ใช้ใบเก่าเขียนทีหลัง
4. **พันธุ์ไม้หลัก (ยืนยันผ่าน S-339):** Borassus flabellifer L. + Corypha umbraculifera L. (บวก Corypha utan/gebanga ฝั่ง Java ใน S-337) — phytolith assemblage แยกชนิดได้ → เปิดทาง provenance วัสดุ
5. **Pigment/SEM-EDX (S-338):** สำหรับ MSS 18th–19th c. การระบุอายุใน field ยังเป็น owner statement — ช่องว่างมาตรฐานการ dating ที่โปรเจกต์ควร note
