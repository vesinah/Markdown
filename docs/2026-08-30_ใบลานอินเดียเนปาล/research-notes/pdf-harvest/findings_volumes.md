## ข้อค้นพบรวม 5 ประเด็น

1. **ภูมิอากาศกำหนด "ความไม่เท่ากัน" ของหลักฐาน pothi อย่างเป็นระบบ (ch9):** South India (ชื้น) → MSS เก่า >300–400 ปีหายาก (S-440 quote 2); เนปาล (อบอุ่นแห่งเดียว) → รอด ~13 ศตวรรษ เล่มเก่าสุด 828 CE (S-444 quote 1); เอเชียกลาง (แห้ง) → ใบลาน 3rd–7th c. รอดแต่เป็นของ "นำเข้า" (S-440 quotes 3–4) ตาราง ch9 ควรมีแถว "survival bias per region" อย่างชัดเจน
2. **อักษรและเลขหน้าเป็นมาร์กเกอร์ภูมิภาคของ pothi ได้ (ch2):** grantha = อักษรเฉพาะสันสกฤตที่อยู่คู่ (biscriptual) กับ tamil/telugu และมี 5 สายย่อยผูกกับราชวงศ์/พื้นที่ (S-441); ตำแหน่ง folio-number ต่างกันใต้ (recto ซ้าย) vs เหนือ (verso = śṛṅkapṛṣṭha) (S-441 §4) — ใช้จัดสาย MSS ที่ไม่มี colophon
3. **Colophon คือเครื่องมือ dating ชั้นที่ 2–3 ไม่ใช่แค่บันทึกวันที่ (ch7+ch9):** (i) ต้องอ่านผ่านระบบปฏิทินจริง (60-year cycle กำกวม ±60n, luni-solar, วันเริ่มตามพระอาทิตย์ขึ้น — S-441/S-442); (ii) โครงสร้าง colophon ขยายตัวตามเวลา (scribe→commissioner→witnesses→titles→บุญกุศล) = relative dating ของสูตรเอง (S-443/Baums); (iii) องค์ประกอบที่ไม่ใช่วันที่ก็ล็อกช่วงได้ — janmakuṇḍalī ใน MSS ล็อกได้ "at most a few decades" (S-442 quote 3), eulogistic colophon เชิดชูกษัตริย์ครองราชย์สั้น ๆ เช่น Rudradeva (S-445 quote 3)
4. **C14 ไม่ใช่คำตอบสำหรับใบลานใต้ (ch9):** Rath ยืนยันชัดว่า C14 "leaves a considerable margin" และมักไม่เพิ่มข้อมูลเหนือการประเมินอื่น (S-441 quote 4) — แนวทางเดียวกัน Harimoto re-dating Add.1702 เป็น mid-8th c. ด้วย palaeography+chronology ล้วน ไม่มี lab (S-444) → dating pipeline ควรเรียง palaeography → colophon/calendrics → horoscope → lab เป็นขั้นสุดท้าย
5. **Vidhāna/ritual sources เป็น "คู่มือ codicology" ที่คนวิจัย MSS ยังไม่เคยอ่านขนานกัน (ch2):** Devīpurāṇa 91.37–39 ระบุสเปกใบลาน-ปก-เชือกครบ (S-445 quote 1); śārayantraka = เชือกกลางเล่มใบลาน (S-445 quote 2); ปกไม้ภายในสลักภาพเคารพบูชา (S-445 quote 4) — เชื่อม textual description กับ physical codicology ได้โดยตรง และ Śivadharma corpus เนปาล (NAK 1-1075 ฯลฯ) คือ set ทดสอบที่มีทั้งใบลาน+ปกไม้+colophon ราชสำนักครบ
