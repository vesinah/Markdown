# แผนงาน: รายงานวิชาการระดับสูงคัมภีร์ Gurupañcāśikā (คุรุปัญจาสิกา)

## ข้อมูลโปรเจกต์
- **ประเภท:** รายงานวิชาการ (8-10 ไฟล์หลัก) + ภาคบทแปลคัมภีร์ 3 ฉบับ (Output 6 ชั้นครบทุกบท)
- **ความยาวเป้าหมาย:** เนื้อรายงานหลัก 8-10 ไฟล์ x 5,000-10,000 คำ/ไฟล์ + บทแปล 3 ไฟล์ (สันสกฤต 50 บท, จีน T1667, ทิเบต bla ma lnga bcu pa)
- **วันที่เริ่ม:** 2026-08-25
- **มาตรฐานอ้างอิง:** Chicago/Turabian Notes-Bibliography
- **การถ่ายถอด:** คุรุปัญจาสิกา (ผู้ใช้กำหนด) + IAST/Wylie/พินยิน มาตรฐาน

## โครงร่างบทเบื้องต้น (Outline - จะยืนยันอีกครั้งที่ Outline Gate)

1. **01-บทนำ** — ภูมิหลัง ขอบเขต ระเบียบวิธี สถานะของตัวบท
2. **02-ตัวบทและโครงสร้าง** — โครงสร้าง 50 บท แบ่งเนื้อหา มาตรวัด ฉันทลักษณ์ ตัวบทสันสกฤตและสถานะการอนุรักษ์
3. **03-ประวัติและประเด็นผู้แต่ง** — ข้อถกเถียง Nāgārjuna/Aśvaghoṣa, ยุคสมัย, บริบทตันตระอินเดีย
4. **04-การสืบทอดสู่ทิเบตและจีน** — การแปลทิเบต, การแปลจีนโดย日稱, สายสืบทอด Atiśa/Vikramaśīla
5. **05-อรรถกถาและพัฒนาการ** — Tsongkhapa rnam bshad, อรรถกถาอื่น, การตีความ
6. **06-การใช้งานในพิธีและการฝึก** — บทสวดประจำวัน, guru yoga, 4 นิกายทิเบต
7. **07-งานวิชาการสากล** — งานวิจัย 8 ภาษา (EN/DE/FR/ZH/JA/KO/HI/SKT)
8. **08-การศึกษาเปรียบเทียบ** — เปรียบเทียบตัวบท 3 ภาษา จุดต่างสำคัญ
9. **09-สรุปและช่องว่างงานวิจัย**
10. **references.md** — บรรณานุกรมรวม
