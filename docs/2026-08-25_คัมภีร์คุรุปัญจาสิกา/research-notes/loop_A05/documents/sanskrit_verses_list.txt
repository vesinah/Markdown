Skt v1 : abhiṣekāgralabdho hi vajrācāryastathāgataiḥ / daśadiglokadhātusthaistrikālametya vandyate
Skt v2 : trikālaṃ parayā bhaktyā sapuṣpāñjalimaṇḍalaiḥ / paryupāsyo guruḥ śāstā śirasā pādavandanāt
Skt v3 : saddharmādīn puraskṛtya gṛhī vā navako 'pi vā / vandyo vratadharairbuddhyā lokāvadyāvahānaye
Skt v4 : sukhāsanaṃ samutthānamarthakriyādigauravam / sarvameva vratī kuryāt tyaktvā cārcanavandanam
Skt v5 : prāk śiṣyācāryasaṃbandhaḥ kāryaḥ parīkṣya sūribhiḥ / samānasamayabhraṃśo doṣo hi guruśiṣyayoḥ
Skt v6 : niṣkṛpaṃ krodhanaṃ krūraṃ stabdhaṃ laghumasaṃyatam / svotkarṣakaṃ ca no kuryād guruṃ śiṣyaṃ ca buddhimān
Skt v7 : dhīro vinīto matimān kṣamāvānārjavo 'śaṭhaḥ / mantratantraprayogajñaḥ kṛpāluḥ śāstrakovidaḥ
Skt v8 : daśatattvaparijñātā maṇḍalālekhyakarmavit / mantravyākhyākṛdācāryaḥ prasannaḥ syājjitendriyaḥ
Skt v9 : taṃ nāthaṃ yo 'vamanyeta śiṣyo bhūtvā sacetanaḥ / sarvabuddhāpamānena sa nityaṃ duḥkhamāpnuyāt
Skt v10 : ītyupadravacauraiśca grahajvaraviṣādibhiḥ / mriyate 'sau mahāmūḍho gurupādābhinindakaḥ
Skt v11 : rājavātānalavyālairḍākinījalataskaraiḥ / vighnairvināyakaiścāpi mārito narakaṃ vrajet
Skt v12 : na kuryāccittasaṃkṣobhamācāryasya kadācana / yadā karoti duṣprajño narake pacyate dhruvam
Skt v13 : narakā ye samākhyātā avīcyādyā bhayānakāḥ / tatra vāsaḥ samākhyāta ācāryasya hi nindanāt
Skt v14 : tasmāt sarvaprayatnena vajrācāryaṃ mahāgurum / pracchannavarakalyāṇaṃ nāvamanyet kadācana
Skt v15 : yatheṣṭadakṣiṇādānād gurubhaktaṃ sagauravam / uktā jvarādayastāpā na bhūyaḥ prabhavanti hi
Skt v16 : adeyaiḥ putradārādyairasubhirvā nijairapi / sevyaḥ svasaṃvarācārya kiṃ punarvibhavaiścalaiḥ
Skt v17 : yataḥ sudurlabhaṃ vastu kalpāsaṃkhyeyakoṭibhiḥ / buddhatvamudyogavate dadātīhaiva janmani
Skt v18 : nityaṃ svasamayaḥ sādhyo nityaṃ pūjyāstathāgatāḥ / nityaṃ ca gurave deyaṃ sarvabuddhasamo hyasau
Skt v19 : yadyadiṣṭataraṃ loke viśiṣṭarameva vā / tattaddhi gurave deyaṃ sadaivākṣayamicchatā
Skt v20 : datte 'smai sarvabuddhebhyo dattaṃ bhavati śāśvatam / tasmācca puṇyasaṃbhāraḥ saṃbhārād bodhiruttamā
Skt v21 : te śiṣyāḥ karuṇotsargaśīlakṣāntiguṇānvitāḥ / ye nānyatvaṃ kalpayanti gurorvajradharasya ca
Skt v22 : caityabhaṅgādibhītyāpi gurośchāyāṃ na laṅghayet / pādukāsanayānāderlaṅghanasya tu kā kathā
Skt v23 : śrūyād yatnād gurorājñāṃ hṛṣṭacitto mahāmatiḥ / aśaktaḥ śrāvayet tasmā upapattyā tvaśaktitām
Skt v24 : guroḥ siddhiṃ samāpnoti guroḥ svargaṃ guroḥ sukham / tasmāt sarvaprayatnena gurorājñāṃ na laṅghayet
Skt v25 : svātmavacca gurordravyaṃ guruvacca tadaṅganām / svajanāniva tallokān paśyennityaṃ samāhitaḥ
Skt v26 : śayyārohamagrayānamuṣṇīṣādyupabandhanam / na kuryādāsane pādaṃ kaṭihastaṃ ca sannidhau
Skt v27 : suptena vā niṣaṇṇena na stheyamutthite gurau / dakṣaścotsāhasampannastatkāryeṣu sadā bhavet
Skt v28 : śleṣmādīnāṃ parityāgaḥ pādaprasāraṇaṃ tathā / caṅkramaṇaṃ vivādaṃ ca na kuryāt purato guroḥ
Skt v29 : saṃvāhanaṃ nartanaṃ ca na gānaṃ na ca bādanam / bahu saṃlapanaṃ cāpi na kuryāt purato guroḥ
Skt v30 : natvāsanāt samuttheyaṃ niṣattavyaṃ ca bhaktitaḥ / niśyapsu sabhaye mārge prārthyāgre gamanaṃ caret
Skt v31 : nāṅgāni cālayed dhīmān na jṛmbhādi samāśrayet / nāṅgulisphoṭanaṃ kuryāt puraḥ paśyati śāstari
Skt v32 : pādayoḥ kṣālanaṃ cāṅgaproñchābhyañjanamardanam / pūrvaṃ praṇamya kartavyaṃ tataḥ kuryād yadādiśet
Skt v33 : [āvhānādau gurornāmni pūjyapādādi yojayet / anyadā śraddhayā brūyāt sādaraistu viśeṣaṇaiḥ
Skt v34 : ādiśyatām, kariṣyāmi, pravadet sāñjalirgurum / śrutvādeśaṃ cāvicālya yathādiṣṭaṃ tathā caret
Skt v35 : hāse kāse samutpanne kareṇācchādayenmukham / tadante mṛdubhirvarṇaiḥ svābhiprāyaṃ nivedayet
Skt v36 : vinītaḥ purato bhūyāt sajjo vastrādibandhanaiḥ / bhūjānuḥ sāñjaliḥ śrotuṃ yācayet tu trivārakam
Skt v37 : satkāryaṃ sarvadā kuryānnirahaṅkāracetasā / trapayā pāpabhītyā saṃvṛto navavadhūriva
Skt v38 : na vilāsamayīṃ ceṣṭāṃ kuryāt śāstari saṃmukhe / anyaccaivaṃvidhaṃ karma suparīkṣya tyajed bhṛśam
Skt v39 : pratiṣṭhāyāṃ maṇḍale ca home vā śiṣyasaṃgrahe / ākhyānādau gurorvāse nityaṃ kuryācca sannidhim
Skt v40 : pratiṣṭhādau labhyate yat tatsarvaṃ gurave 'rpayet / tena dattaṃ ca gṛṇhīyāt svayaṃ cānyāṃśca toṣayet
Skt v41 : guruśiṣye svaśiṣyatvaṃ na vidadhyāt kadācan / svaśiṣyaṃ vyāvṛtaṃ kuryāt satkārāderguroḥ puraḥ
Skt v42 : ācāryo yatsvayaṃ dadyād gururvā yat pradāpayet / praṇamya dhīmatā grāhyaṃ baddhāñjalipuṭena tat
Skt v43 : avismṛtaḥ sarvacaryāṃ yatnāt kurvan svabāndhavān / avismṛternirākuryāt premṇā hṛṣṭena cetasā
Skt v44 : anujñāto guroḥ kāryaṃ śraddhālurnācared yadi / rugṇastu kuśale citte naivaṃ bhavati pāpabhāk
Skt v45 : kimanyad, gurutoṣāya yacchakyaṃ tatsamācaret / caryā kāryā prayatnena na kadāpyavahelayet
Skt v46 : sarvathā sarvadā siddhirācārya yānugāminī / gururvajradharasyokterārādhyaḥ sarvavastubhiḥ
Skt v47 : śiṣyaḥ śuddhāśayo bhūtvā triratnaṃ śaraṇaṃ vrajet / guroradhītyānupaṭhet kuryādutsargameva ca
Skt v48 : tato mantrādidānena kṛtvā saddharmapātrakam / paṭhecca dhārayeccāpi mūlāpattīścaturdaśa
Skt v49 : gurumanugataśiṣyasyānavadyasya kṛtvā sakalasuhitavṛddhiṃ saṃcitaṃ yanmayedam / kuśalapadamanantaṃ tena vai sarvasatvāḥ vijitasugatabhāvā drāk susiddhiṃ labheyuḥ
