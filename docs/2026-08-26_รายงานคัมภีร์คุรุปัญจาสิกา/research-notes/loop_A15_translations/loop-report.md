# Loop A15: บรรณานุกรมคำแปลสมัยใหม่ของ Gurupañcāśikā (bla ma lnga bcu pa; Toh 3721; T1687)

วันที่สำรวจ: 26 สิงหาคม 2026 | วิธีการ: websearch + webfetch | เก็บเอกสารต้นฉบับไว้ที่ ./documents/

## สรุปภาพรวม

Gurupañcāśikā มีคำแปลสมัยใหม่ยืนยันแล้วอย่างน้อย 10 ภาษา: อังกฤษ (หลายสำนวน), จีน (หลายสำนวน), ญี่ปุ่น, เกาหลี, ฮินดี, ฝรั่งเศส, สเปน, รัสเซีย, เวียดนาม (บางสำนวนเป็นเว็บ/PDF) ข้อค้นพบสำคัญคือ **ไม่พบคำแปลภาษาไทยโดยสิ้นเชิง** ทั้งในรูปเล่มและเว็บ ซึ่งเป็นเหตุผลเชิงประจักษ์ที่สนับสนุนความจำเป็นของโครงการแปลไทยของเรา นอกจากนี้ยังไม่พบคำแปลมองโกลสมัยใหม่ที่ตีพิมพ์

## ข้อค้นพบเชิงลบ (Negative findings) — มีค่าเทียบเท่าข้อค้นพบเชิงบวก

1. **ไทย: ไม่พบคำแปลใด ๆ** ทั้งเล่มและเว็บ ทดสอบหลายคำค้น (คุรุปัญจาสิกา / คำภีร์ครูห้าสิบบาท / แปลไทย วัดไทยทิเบต / อัศวโฆษะ + 50 คาถา / ปฐพีวินิจ) พบเฉพาะสื่อวัชรยานทั่วไปภาษาไทย (เช่น คำภีร์ภาวนากรม สำนักพิมพ์สวนเงินมีมา; sadhana จาก samyetranslations.org) แต่ไม่มี Gurupañcāśikā — **ยืนยันช่องว่างสำคัญและเป็นเหตุผลหลักของโครงการแปลไทยของเรา**
2. **มองโกเลีย:** ไม่พบคำแปลมองโกลสมัยใหม่ที่ตีพิมพ์ (มีเพียงบริบทคานจูร์/ดันจูร์เชิงประวัติศาสตร์ ไม่ได้ระบุตัวเล่ม)
3. **เยอรมัน:** ไม่พบคำแปลเยอรมันฉบับสมบูรณ์ของบทราก (มีเพียงสื่อ guru-yoga ทั่วไป; ต้องตรวจเพิ่มใน loop_A05)
4. **Berzin / studybuddhism.com:** ไม่พบคำแปลบทรากฉบับสมบูรณ์แยกต่างหากบนเว็บไซต์ — บทบาทของ Berzin คือการทบทวนฉบับ LTWA 1992 (E2) และเป็นผู้แปล/บรรณาธิการปริมาณ Mahamudra 1978 (E3)
5. **法尊法師 แปล《事師五十頌釋》ของ宗喀巴: ไม่พบหลักฐานทางบรรณานุกรม** ว่า法尊แปลงานนี้ (รายชื่อผลงานแปลของท่านที่พบไม่รวมเรื่องนี้; ไม่พบการพิมพ์โดย中国佛教协会) ข้อสันนิษฐานเดิมใน brief จึงไม่ได้รับการยืนยัน — คำแปลจีนสายทิเบตของคอมเมนตารีที่พบจริงคือ 湯薌銘 (C2) และ 索達吉 (C3)
