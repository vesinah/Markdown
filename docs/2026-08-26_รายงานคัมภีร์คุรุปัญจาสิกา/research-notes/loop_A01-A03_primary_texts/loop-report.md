## A02: ตัวบทจีน 事師法五十頌

- **ยืนยันหมายเลข Taishō:** T1687 (T vol. 32) — ยืนยันผ่าน CBETA Online (cbetaonline.dila.edu.tw/zh/T1687) และ merit-times ระบุ "收於大正藏第三十二冊" (ห้ามใช้ T1667)
- **ชื่อเต็ม:** 事師法五十頌 (馬鳴菩薩集) — Shī shī fǎ wǔshí sòng "ห้าสิบโศลกว่าด้วยหลักปฏิบัติต่ออาจารย์"
- **ผู้รวบรวม:** 馬鳴菩薩 (Aśvaghoṣa) — สอดคล้องกับโคลอฟอนสันสกฤต
- **ผู้แปล:** 西天譯經三藏朝散大夫試鴻臚少卿宣梵大師賜紫沙門臣日稱等奉詔譯 — พระ日稱 (Rìchēng) และคณะ แปลตามพระบรมราชโองการยุคซ่ง
- **แหล่ง XML:** CBETA XML P5 repo github.com/cbeta-org/xml-p5 (T/T32/T32n1687.xml)
- **โครงสร้าง:** บทนำ 4 บรรทัด + 50 โศลก (4 บรรทัด/โศลก 5 อักษร ยกเว้นบทเปิด-ปิดใช้ 7 อักษร) + บทสรุป 2 บรรทัด + colophon
- **ประเด็นวิกฤติ:** Taishō note: 此頌宋本元本宮本俱闕 = ฉบับซ่ง/หยวน/กง ไม่มีคำโคลอฟอนนี้; variant readings 大 vs 明 หลายจุด (เก็บไว้ใน XML 校注)
- **ไฟล์เก็บ:** `documents/T32n1687-cbeta-xml-p5-raw.xml`, `documents/T1687-clean-text.txt`

## A03: ตัวบททิเบต བླ་མ་ལྔ་བཅུ་པ (bla ma lnga bcu pa)

- **หมายเลข:** Derge Tengyur TD3721 (rgyud 'grel, vol. TSU); Peking T2543 (ยืนยันผ่าน Sakya Research Centre S5714); 84000 = toh3721
- **หัวเรื่องทิเบตบันทึกชื่อสันสกฤตว่า:** GU RU PANYTZA BIM SHI KA (= *guru-pañca-viṃśika*) ขณะที่ชื่อทิเบตแปลว่า "ห้าสิบ [บท] แห่งคุรุ" — ความคลาดเคลื่อน viṃśika (20s) vs ñcāśikā (50) เป็นประเด็นวิชาการสำคัญ (Schaeffer & van der Kuijp 2009 อ้างถึง)
- **โคลอฟอน:** BLA MA LNGA BCU PA SLOB DPON CHEN PO RTA DBYANGS KYIS MDZAD PA RDZOGS SO = ผู้แต่ง rtadbyangs (Aśvaghoṣa)
- **ผู้แปล:** RGYA GAR GYI MKHAN PO PADM'A KA RA WA RMA (Padmākaravarman) + ZHU CHEN GYI LO TZ'A BA DGE SLONG RIN CHEN BZANG PO (Rinchen Zangpo)
- **แหล่ง eText:** Asian Legacy Library TENGYUR.zip (all-library-docs.s3.us-west-2.amazonaws.com/TENGYUR.zip) ไฟล์ `Tengyur/02 RGYUD.../VOL 78 (TSU)/TD03721_BLA MA LNGA BCU PA.txt`
- **สถานะ:** เก็บครบทั้งเล่ม (Wylie/ACIP transliteration) — หัวเรื่อง+นโม+50 บท+colophon
- **หมายเหตุ:** ตัวบท Unicode script เต็มเล่มยังไม่พบแหล่งเปิดเผยที่ยืนยันได้ (BDRC API down, Oslo Peking Tripitaka บล็อก, dharmanexus-tibetan repo ยังไม่ public, 84000 ยังไม่เผยแพร่) — ใช้ Wylie transliteration ตามมาตรฐาน tibetan-translation skill
- **ไฟล์เก็บ:** `documents/TD3721-bla-ma-lnga-bcu-pa-ALL.txt`
