## ขอบเขตงานตามคำสั่งผู้ใช้ (User Requirements)

1. รายงานการค้นคว้าระดับสูงว่าด้วยคัมภีร์ Gurupañcāśikā: เนื้อหาโดยสรุป โครงสร้างเนื้อหา ประวัติ พัฒนาการ การใช้งาน การสืบทอด
2. ทบทวนงานวิชาการสากล 8 ภาษา: อังกฤษ เยอรมัน ฝรั่งเศส จีน ญี่ปุ่น เกาหลี ฮินดี สันสกฤต
3. บทแปลคัมภีร์ทั้งเล่มภาษาไทย 3 ฉบับ:
   - **ฉบับสันสกฤต** — อิงตัวบท DSBC https://www.dsbcproject.org/canon-text/content/221/914 ตาม skill `sanskrit-translation`
   - **ฉบับจีน** — ต้องค้นหาตัวบทเต็มภาษาจีน (คาดการณ์ T1667 事師法五十頌 แปลโดย 日稱 ยุคซ่ง — ต้องยืนยันจาก CBETA) ตาม skill `chinese-translation`
   - **ฉบับทิเบต** — ต้องค้นหาตัวบทเต็มภาษาทิเบต བླ་མ་ལྔ་བཅུ་པ (bla ma lnga bcu pa) ตาม skill `tibetan-translation`
