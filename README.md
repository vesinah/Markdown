## คุณสมบัติเด่น (Key Features)
1. **Mozilla PDF.js Canvas Engine**: เรนเดอร์ PDF ด้วย HTML5 Canvas ปลอดภัย ไม่ถูกบล็อกโดย Chrome Sandbox
2. **ขยายโฟลเดอร์ `final` เป็นค่าเริ่มต้น**: กางเฉพาะโฟลเดอร์เป้าหมายและเส้นทางบรรพบุรุษอัตโนมัติ
3. **ปุ่มควบคุมไซด์บาร์**: แยกปุ่ม "เฉพาะ final" และ "พับทั้งหมด" ชัดเจน
4. **ฟอนต์ Noto Serif Thai**: ให้อารมณ์อ่านหนังสือ พร้อมปุ่ม `A-`, `A`, `A+` ปรับขนาดแบบเรียลไทม์
5. **เชิงอรรถสองทิศทาง (Bidirectional Footnotes)**: ลิงก์ `[xx]` / `[^xx]` ไปยังคำอธิบาย และกด `↩` กลับมาที่ข้อความเดิมพร้อมไฟกระพริบ
6. **ไม้บรรทัดและเส้นขอบเขตเนื้อหา (Interactive Ruler & Margin Guides)**: ลากขยาย-หดขอบกระดาษซ้ายขวาได้อิสระ ดับเบิลคลิกเพื่อรีเซ็ต พร้อมระบบจางลงอัตโนมัติ (Auto-Fading) เมื่อไม่ได้ใช้งาน
7. **ระบบบุ๊คมาร์คและคอมเมนต์ (Bookmarks & Comments)**: ไฮไลต์ข้อความเพื่อบุ๊คมาร์คหรือเขียนคอมเมนต์ พร้อมแผงขวาแบบ 2 แท็บ (ระดับเอกสาร / ทั้งโปรแกรม) เปิด-ปิดได้ด้วยปุ่มข้างปุ่ม `?` หรือกด `Alt+B` บันทึกลง IndexedDB ผูกกับชื่อไฟล์+ขนาดไฟล์ หากไฟล์หายแล้วนำกลับมา (ชื่อและขนาดตรงกัน) จะกู้คืนไฮไลต์อัตโนมัติ — ใช้เทคนิค Text Quote Anchor ทนต่อการแก้ไขไฟล์เล็กน้อย
8. **ระบบรีเฟรชรายการไฟล์ (Manual Workspace Refresh)**: ปุ่มรีเฟรชบนไซด์บาร์และคีย์ลัด `Alt + R` สำหรับสแกนโฟลเดอร์ใหม่แบบ In-Memory ทันทีเมื่อมีการเพิ่ม/ลบ/แก้ไขไฟล์ในโฟลเดอร์ที่นำเข้า โดยไม่ต้องปิดเปิดโปรแกรมใหม่ พร้อมปุ่มรีเฟรชประจำแต่ละโฟลเดอร์หลักใน Tree
9. **ระบบเรียงลำดับตามชื่อและวันที่ (Sort by Name & Date)**: ปุ่มเรียงลำดับตามชื่อ (ก-ฮ / ฮ-ก) และเรียงลำดับตามวันที่ (ใหม่-เก่า / เก่า-ใหม่) มีผลครอบคลุมทั้งโฟลเดอร์/เส้นทาง (path) และไฟล์ภายในทุกระดับ คั่นด้วยเส้นแบ่ง Divider หน้าปุ่มรีเฟรช พร้อมระบบจดจำรูปแบบการเรียงลำดับอัตโนมัติ
10. **ระบบ UI/UX โหมดสมาร์ทโฟนเต็มรูปแบบ (Smartphone Portrait Mode)**: แถบนำทางด้านล่างถนัดมือนิ้วโป้งแบบ Thumb-Zone Glassmorphism Dock (ไฟล์, สารบัญ, ธีม/ฟอนต์, บุ๊คมาร์ค, บ้านแมว) พร้อม Smart Auto-Hide สไลด์ซ่อนอัตโนมัติเมื่อเลื่อนอ่านเนื้อหา, ระบบ Off-Canvas Drawers (ไซด์บาร์ไฟล์กว้าง 350px และสารบัญกว้าง 340px) พร้อมการ์ดคลังงานวิจัย 6,066 รายการแบบ 2 แถว แสดงชื่อเต็ม 100% ไร้การตัดทอน โดยยังคงรักษาเลย์เอาต์เดสก์ท็อปเดิมไว้ครบถ้วน 100% (Zero Desktop Regression)
